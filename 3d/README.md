# 3D Reference and Technique Library

This directory supports `packs/3d-immersive-web/` with structured style, source, reference, technique and licence records.

The Refs.Gallery collection contains 0 public project links/metadata records captured at the recorded retrieval. It stores no copied screenshots, source code, models, textures or proprietary media.

Use `python scripts/select-3d-references.py "<brief>"` to shortlist records. A reference is not a reuse licence.
