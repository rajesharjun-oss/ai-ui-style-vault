## High-value lessons

1. Use one dominant cinematic interaction and keep secondary sections lighter.
2. Sticky media stages work well for narrative progression.
3. Scroll-scrub video is easier to prototype; image sequences give more precise frame control.
4. Framer Motion or equivalent DOM animation belongs around semantic content, not instead of it.
5. Liquid-glass overlays can preserve text/control readability over moving media.
6. Use poster/static fallbacks, reduced-motion states and mobile degradation.
7. End cinematic sequences by handing the user back to a conventional task flow such as menu, pricing, form, product configurator or checkout.
8. Reference designs for direction only; do not reproduce another site's exact composition.

## Dodo Yaba application

For the Dodo Yaba cinematic build, the strongest applicable patterns are:

- sticky media stage;
- scroll-scrub or image-sequence ingredient assembly;
- chapter progress;
- camera-like object movement;
- masked ingredient placement;
- media-to-commerce handoff;
- dynamic price/configurator interaction;
- reduced-motion fallback.
