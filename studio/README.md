# Vault Studio Foundation

Vault Studio is the future human-facing browser for the same machine-readable intelligence used by agents.

Run:

```bash
python scripts/vault-agent.py studio-index
```

to generate `studio/catalog-index.json` from canonical domain packs, section recipes, interactive effects and reference patterns.

The future UI can show business purpose, compatible sections/domains, runtime, performance tier, mobile/reduced-motion behavior, controls, implementation skill and provenance. Browsing a visually attractive effect never makes it eligible for the current business; the research gate and semantic selector remain authoritative.
