# Animated Delete Button

A compact destructive-action button with a trash/paper click animation and a completed state.

## Use When

Use for delete or remove actions in file managers, carts, admin tools, and compact task interfaces.

## Agent Rules

- Animate only on click, not page load.
- Disable duplicate clicks while pending.
- For real destructive actions, confirm or undo where appropriate and show success only after backend confirmation.
- Keep the visible label; do not make destructive actions icon-only.
