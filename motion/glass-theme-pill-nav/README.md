# Glass Theme Pill Nav

A warm translucent pill navigation bar with a sliding active capsule and a real light/dark theme toggle.

## Use When

Use for compact navigation in consumer products, wellness tools, mobile-like shells, and playful landing-page sections.

## Agent Rules

- The active pill must move only after user selection.
- The theme button must actually change theme state and recompute the pill position.
- Keep glass contrast readable and touch targets large.
- Do not use it for dense enterprise primary navigation without adaptation.
