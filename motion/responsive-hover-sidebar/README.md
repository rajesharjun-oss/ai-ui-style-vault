# Responsive Hover Sidebar

A dark collapsible sidebar where labels reveal on hover, focus, or explicit toggle, with a strong active item state.

## Use When

Use for dashboards, portals, admin panels, file managers, and settings-heavy web apps.

## Agent Rules

- Labels must be accessible on hover, focus, and mobile.
- Every navigation item must be keyboard operable and wired to real routing or state.
- Prefer readable expanded state on small screens.
- Keep source-video text and code frames out of preview UI.

## Files

- `index.html`: standalone preview.
- `pattern.json`: machine-readable library entry.
- `verification-notes.md`: screenshot/code-frame verification summary.
