# Motion

This folder helps agents build landing pages and motion graphics websites professionally from the AI UI Style Vault.

Current contents: 512 motion-relevant style references, 34 high-signal motion systems, 346 references with preview video links, 10 reusable motion patterns, and 7 official implementation-resource links.

## Files

- `motion-catalog.json`: machine-readable motion references generated from style metadata and remote preview-video links.
- `MOTION_REFERENCES.md`: human-readable list of motion-heavy style references, patterns, and implementation resources.
- `LANDING_PAGE_MOTION_GUIDE.md`: professional guidance for landing-page motion, motion graphics websites, performance, accessibility, and library choice.

## How Agents Should Use This

1. Read the target repo and brief.
2. Run `scripts/select-vault-style.ps1` to choose the visual system.
3. Run `scripts/select-motion-references.ps1` to choose motion direction.
4. Read the selected style folders and this motion guide.
5. Build original motion with user-provided, owned, generated, or clearly licensed assets only.
6. Test reduced motion, performance, keyboard access, mobile layout, and visual overlap.

## Media Policy

The vault stores remote media links for research and inspiration. It does not vendor Refero videos, screenshots, logos, or protected media.
