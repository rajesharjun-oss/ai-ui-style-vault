# Motion

This folder helps agents build landing pages and motion graphics websites professionally from the AI UI Style Vault.

Current contents: 512 motion-relevant style references, 34 high-signal motion systems, 346 references with preview video links, 22 reusable motion patterns, 7 official implementation-resource links, 11 standalone local motion entries plus 1 combined preview gallery, 30 curated premium motion source entries, and 300 MotionSites prompt/background references.

## Files

- `motion-catalog.json`: machine-readable motion references generated from style metadata and remote preview-video links.
- `MOTION_REFERENCES.md`: human-readable list of motion-heavy style references, patterns, and implementation resources.
- `LANDING_PAGE_MOTION_GUIDE.md`: professional guidance for landing-page motion, motion graphics websites, performance, accessibility, and library choice.
- `PREMIUM_MOTION_SOURCES.md`: curated external sources for premium inspiration, licensed assets, 3D tools, Lottie/Rive assets, and implementation examples.
- `premium-motion-sources.json`: machine-readable premium motion source catalog.
- `MOTIONSITES_PROMPT_REFERENCES.md`: MotionSites prompt-card and animated-background references for AI-builder prompt direction.
- `motionsites-prompt-catalog.json`: machine-readable MotionSites prompt/background reference catalog.
- `code-candy-interactions/`: combined visual preview gallery for the Code Candy auth/nav/menu entries.
- `code-candy-hover-expanding-login/`: neon conic-gradient login/signup card that expands on hover/focus and switches auth modes on click.
- `team-carousel-slider/`: dark editorial profile carousel with featured member stage, side cards, controls, pause, and reduced-motion behavior.
- `modern-timed-destination-cards/`: cinematic timed destination cards with manual selection, progress rail, pause/play, and static reduced-motion fallback.
- `responsive-hover-sidebar/`: collapsible dark sidebar where labels reveal on hover, focus, or explicit toggle.
- `glass-theme-pill-nav/`: translucent pill navigation with a user-triggered sliding active capsule and theme toggle.
- `animated-delete-button/`: click-triggered destructive action microinteraction with pending, success, keyboard, and reduced-motion states.
- `svg-path-particle-reveal/`: SVG path sampling pattern for moon, logo, constellation, and premium WebGL-style particle reveals.

## How Agents Should Use This

1. Read the target repo and brief.
2. Run `scripts/select-vault-style.ps1` to choose the visual system.
3. Run `scripts/select-motion-references.ps1` to choose motion direction.
4. Run `scripts/select-premium-motion-sources.ps1` when external premium inspiration, licensed motion assets, 3D scenes, Lottie/Rive files, or implementation examples are needed.
5. Read the selected style folders, this motion guide, and selected premium source notes.
6. For stateful UI interactions and premium reveal moments, prefer the specific local folders: `motion/code-candy-auth-slanted-overlay/`, `motion/code-candy-hover-pill-menu/`, `motion/code-candy-floating-indicator-nav/`, `motion/code-candy-auth-overlay-slide/`, `motion/code-candy-hover-expanding-login/`, `motion/team-carousel-slider/`, `motion/modern-timed-destination-cards/`, `motion/responsive-hover-sidebar/`, `motion/glass-theme-pill-nav/`, `motion/animated-delete-button/`, or `motion/svg-path-particle-reveal/`.
7. Build original motion with user-provided, owned, generated, open-source-permitted, or clearly licensed assets only.
8. Test reduced motion, performance, keyboard access, mobile layout, and visual overlap.

## Media Policy

The vault stores remote media links and source links for research and inspiration. It does not vendor Refero videos, MotionSites prompt text, screenshots, logos, protected media, animation previews, template previews, generated outputs, copied code, or licensed assets.
