# Premium Motion Sources

Use this catalog when a landing page or motion graphics website needs more external inspiration, licensed assets, reusable motion components, or implementation examples beyond the captured Refero style bundles.

Current contents: 30 curated sources across award galleries, landing-page galleries, implementation showcases, React/component motion, interactive 3D tools, Lottie/Rive libraries, and licensed video/template marketplaces.

## Agent Rules

- Use inspiration sources for choreography, pacing, section rhythm, and interaction ideas only.
- Use asset marketplaces only after confirming the license for the exact asset.
- Store source links and notes, not copied videos, preview files, screenshots, logos, or exact animation sequences.
- Build original motion from the target product, user-provided assets, generated assets, owned assets, open-source-permitted code, or clearly licensed media.
- Always include reduced-motion behavior for autoplay, scroll scenes, looping animation, canvas, WebGL, Rive, Lottie, and video.
