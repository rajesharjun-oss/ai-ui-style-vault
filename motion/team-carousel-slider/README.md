# Team Carousel Slider

A dark editorial team carousel with one large featured profile and supporting profile cards to the side.

## Use When

Use for agency, studio, event, portfolio, or about-page sections where people need more presence than a flat grid.

## Agent Rules

- Keep every card clickable and keyboard operable.
- Autoplay is optional and must include controls, pause behavior, and reduced-motion handling.
- Use owned, generated, or licensed portraits in production.
- Do not copy screenshot portraits, tutorial headings, code frames, or social overlays.

## Files

- `index.html`: standalone preview.
- `pattern.json`: machine-readable library entry.
- `verification-notes.md`: screenshot/code-frame verification summary.
