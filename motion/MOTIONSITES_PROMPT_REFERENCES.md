## Agent Use Rules

- Run `scripts/select-prompt-references.ps1` when the brief asks for an AI-builder prompt direction, full landing page prompt scaffold, section composition prompt, app prompt, or animated background strategy.
- Use selected references as direction for original work. Do not copy MotionSites prompt text, premium content, screenshots, videos, assets, or generated site output into this vault or a client project unless separately licensed.
- If a selected reference is marked `premium`, visit MotionSites and confirm access/license before using any copyable prompt or asset.
- Pair prompt references with `motion/LANDING_PAGE_MOTION_GUIDE.md`, `motion/MOTION_REFERENCES.md`, and selected visual style bundles.
- Always define responsive behavior, reduced-motion fallback, performance budget, and source/license notes in `VAULT_SELECTION.md`.
