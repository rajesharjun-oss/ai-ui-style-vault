# Code Candy Hover Pill Menu

A compact pill menu where icon labels expand on hover or keyboard focus. It never moves automatically.

## Use When

Use for compact product navigation, editor toolbars, dashboard rails, floating controls, and polished SaaS interaction surfaces.

## Agent Rules

- Hover and focus are the only expansion triggers.
- Every icon button must have an accessible label.
- Keep dimensions stable so expanded labels do not push surrounding layout around.
- Do not make this a hover-only interaction; keyboard focus must reveal labels too.
- Preserve reduced-motion behavior with instant or very short state changes.
