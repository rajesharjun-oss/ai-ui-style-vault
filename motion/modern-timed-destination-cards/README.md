# Modern Timed Destination Cards

A full-bleed destination hero where compact cards rotate into the main stage with a visible progress rail.

## Use When

Use for travel, hospitality, editorial, event, campaign, or product-story heroes where timed visual rotation supports discovery.

## Agent Rules

- Show progress when the hero changes automatically.
- Provide manual card selection and pause/play controls.
- Disable timed cycling for reduced-motion users.
- Use owned, generated, or licensed imagery in production.
- Do not copy screenshot footage, tutorial headings, code frames, or social overlays.

## Files

- `index.html`: standalone preview.
- `pattern.json`: machine-readable library entry.
- `verification-notes.md`: screenshot/code-frame verification summary.
