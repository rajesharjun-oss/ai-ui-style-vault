### Animated Delete Button

- ID: `animated-delete-button`
- Local files: `motion/animated-delete-button/index.html`, `motion/animated-delete-button/pattern.json`, `motion/animated-delete-button/verification-notes.md`
- Best for: destructive actions, file managers, cart item removal, admin tools, confirmation microinteractions
- Use when: A project needs a compact destructive-action button where the trash icon animates on click and resolves into a clear completed state.
- Preferred stack: CSS keyframes, semantic button, vanilla JavaScript, SVG icon animation
- Reduced motion: Skip the trash/paper animation and update the label/state immediately after the action resolves.
- Avoid: triggering destructive work without confirmation when needed; fake success before backend confirmation; long blocking animation; icon-only destructive buttons without labels; autoplaying the delete animation
- Agent rule: use server-confirmed success before showing permanent deleted state in production, and disable duplicate clicks while pending.
