## What was copied into this repository

The Vault stores **our own machine-readable abstractions** of each source: source identity, pinned commit, licence status, reusable interaction principles, experience architecture, state model, runtime tier, fallback strategy and selection signals.

The source repositories themselves are not mirrored. Their protected branding, artwork, media, copy and exact compositions are not imported. For MIT sources, an implementation agent may selectively vendor the minimum necessary source files into a target project after preserving notices and auditing asset/plugin licences.

## Why this is more useful than cloning

An agent can now ask for an experience such as “continuous product storytelling” or “browse and inspect a premium collection.” The selector chooses an architecture based on the actual business profile and goal, then generates a Skill.md contract. The source remains provenance and research evidence rather than a hard-coded design identity.
