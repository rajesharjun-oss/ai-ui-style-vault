## Use This When

Use this style for scheduling tools, productivity products, booking flows, calendar interfaces, workflow utilities, developer productivity pages, and focused SaaS dashboards that need to feel precise, direct, and easy to trust.

## Core Idea

Cal.com is a disciplined monochrome system softened by rounded forms and a friendly custom headline font. Most of the UI lives in black, white, and grays. Color is intentionally absent except for rare informational blue and integration logo colors. Actions are binary and clear: solid black pills, ghost pills, and compact rectangular header CTAs.
