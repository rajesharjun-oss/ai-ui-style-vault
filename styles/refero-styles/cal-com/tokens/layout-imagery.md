# Layout And Imagery

## Layout

- Use a centered 1200px max-width layout.
- Keep generous horizontal breathing room.
- Use 96px between major sections.
- Hero pattern: headline stack plus a scheduling widget or product UI visual.
- Below the hero, use centered headings with 3-column feature card grids.
- Alternating text-and-product sections also fit the style.
- Keep all visuals contained in cards; avoid full-bleed imagery.

## Imagery

Use:

- Calendar widgets.
- Booking panels.
- Availability grids.
- Meeting type cards.
- Product screenshots.
- Integration logos.
- Small workflow UI modules.

Avoid:

- Lifestyle photos.
- Abstract art.
- Decorative illustration.
- Full-bleed image bands.
- Colorful decorative background systems.
