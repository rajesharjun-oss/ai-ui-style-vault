# Guidelines

## Do

- Use Cal Sans weight 600 for headings 20px and above.
- Keep the core UI monochrome.
- Use pill buttons for primary and secondary page CTAs.
- Use 12px radius for cards and large containers.
- Use 8px radius for header CTAs and inputs.
- Use subtle diffuse shadows for card separation.
- Use Action Blue only for rare links or information highlights.
- Use product UI and integration logos as the main imagery.
- Keep layout centered and structured.

## Do Not

- Do not add new core UI colors.
- Do not use sharp corners.
- Do not use font weights above 600.
- Do not use gradients on buttons or card backgrounds.
- Do not use heavy borders for card separation.
- Do not set body text in Cal Sans.
- Do not use lifestyle photography.
- Do not let integration logo colors spread into buttons, nav, or backgrounds.
