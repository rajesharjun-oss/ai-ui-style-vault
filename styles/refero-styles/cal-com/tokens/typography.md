# Typography

## Font Roles

| Font | Role | Weight | Sizes |
| --- | --- | --- | --- |
| Cal Sans | Headings only | 600 | 20px, 24px, 48px, 64px |
| Cal Sans UI Variable Light | Body and primary UI text | 300 | 14px, 16px, 18px |
| Inter | Small labels and dense UI | 400, 500, 600 | 10px, 12px, 14px, 16px |
| Matter | Captions and metadata | 400 | 10px, 12px, 14px |

## Type Scale

| Role | Size | Weight | Line Height | Letter Spacing | Token |
| --- | --- | --- | --- | --- | --- |
| Caption | 12px | 400 | 1.4 | -0.24px | `--text-caption` |
| Body Small | 14px | 500 | 1.5 | -0.2px | `--text-body-sm` |
| Body | 16px | 300 | 1.5 | -0.19px | `--text-body` |
| Subheading | 18px | 300 | 1.4 | -0.2px | `--text-subheading` |
| Heading Small | 20px | 600 | 1.3 | 0.2px | `--text-heading-sm` |
| Heading | 24px | 600 | 1.3 | 0.24px | `--text-heading` |
| Heading Large | 48px | 600 | 1.1 | 0.48px | `--text-heading-lg` |
| Display | 64px | 600 | 1.1 | 0.64px | `--text-display` |

## Typography Rules

- Use Cal Sans only for headings.
- Do not use weights above 600.
- Keep body copy light and compact.
- Use tight negative tracking for body and caption text.
- Use positive tracking for Cal Sans headings.
- Use Inter for dense calendar controls and fine UI labels.
