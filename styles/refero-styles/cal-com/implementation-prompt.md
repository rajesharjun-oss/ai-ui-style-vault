# Implementation Prompt

Build in the Cal.com style: a compact light scheduling interface with a strict monochrome palette, rounded CTAs, soft card shadows, and product UI as the main visual.

Use these rules:

- Page background: `#f4f4f4`.
- Card background: `#ffffff`.
- Primary CTA: `#101010` background and `#ffffff` text.
- Headline text: `#242424`.
- Body text: `#242424`.
- Secondary text: `#6b7280`.
- Borders and dividers: `#e5e7eb`.
- Rare blue accent: `#0099ff` for information links only.
- Headline font: Cal Sans, weight 600, for 20px and above.
- Body font: Cal Sans UI Variable Light or Inter Light, weight 300, with tight negative tracking.
- Utility UI font: Inter for small labels and calendar controls.
- Display: 64px, weight 600, line-height 1.1, tracking 0.64px.
- Heading large: 48px, weight 600, line-height 1.1.
- Body: 16px, weight 300, line-height 1.5, tracking -0.19px.
- Page CTAs: 9999px radius, about 12px 24px padding.
- Header CTA: 8px radius, about 8px 16px padding.
- Cards: white, 12px radius, 24px padding, subtle diffuse shadow.
- Scheduling widget: white, 12px radius, 16px padding, subtle shadow.
- Max width: 1200px.
- Section gap: 96px.

Design the screen around the product. Use a large headline and a scheduling widget or calendar UI as the hero visual. Follow with centered section headings, 3-column feature cards, and product UI blocks.

Avoid:

- New accent colors.
- Gradients.
- Lifestyle photos.
- Abstract illustrations.
- Heavy borders on cards.
- Sharp corners.
- Font weights above 600.
- Body copy set in Cal Sans.

The result should feel practical and exact: a scheduling product that is almost black and white, softened by pills, 12px cards, light shadows, and friendly Cal Sans headings.
