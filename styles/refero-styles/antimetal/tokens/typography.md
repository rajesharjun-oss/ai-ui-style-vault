# Typography

## Font Families

| Role | Family | Fallback |
|------|--------|----------|
| Display and headings | `Test Signifier` | `Noto Serif`, Georgia, serif |
| Body and UI | `Geist` | `Inter`, system-ui, sans-serif |
| Section markers | `Geist Mono` | `JetBrains Mono`, ui-monospace |

## Scale

| Token | Size | Weight | Line height | Tracking | Use |
|-------|------|--------|-------------|----------|-----|
| Caption | 10px | 400 | 1.2 | 1px | Mono labels and section numbers |
| Body Small | 14px | 400-500 | 1.5 | -0.01em | Buttons, nav, utility copy |
| Body | 16px | 400 | 1.5 | -0.01em | Main copy |
| Subheading | 20px | 400 | 1.5 | 0 | Serif subheads |
| Heading Small | 24px | 400 | 1.2 | 0 | FAQ questions |
| Heading | 36px | 400 | 1.1 | 0 | Section headings |
| Heading Large | 48px | 400 | 1.1 | -1.008px | Large headings |
| Display | 54px | 400 | 1.1 | -1.998px | Hero display |

## Rules

- Never bold Test Signifier.
- Let regular-weight serif type carry authority.
- Use Geist for all interaction and body text.
- Use mono only for uppercase numbered markers and metadata.
- Keep large headings tight and body copy calm.
