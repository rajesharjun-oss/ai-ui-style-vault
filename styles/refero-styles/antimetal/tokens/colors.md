# Colors

## Neutrals

| Name | Hex | Use |
|------|-----|-----|
| Bistre | `#1a1614` | Primary text, dark CTA fill, active strokes |
| Ash | `#2a2724` | Dark hover states and timestamp chips |
| Slate | `#53504c` | Tertiary labels and quiet emphasis |
| Graphite | `#66635f` | Secondary text, nav labels, support copy |
| Flint | `#a8a7a1` | Muted helper text and disabled chrome |
| Parchment | `#d7d7d0` | Page canvas |
| Quill | `#e3e3de` | Hairlines, ghost borders, nav capsule fill |
| Cream | `#f7f6f3` | Primary content surfaces |
| Bone | `#fdfcfa` | Elevated card surface |

## Accent

| Name | Hex | Use |
|------|-----|-----|
| Chartreuse Whisper | `#e2e67d` | Tiny accent dot, badge, or highlight |

## Color Behavior

- Keep the page warm and achromatic.
- Use chartreuse only once or twice per viewport.
- Avoid pure white for large surfaces.
- Avoid pure black for main text.
- Use dashed low-opacity Bistre for dividers.
