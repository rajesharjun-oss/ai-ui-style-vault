# Implementation Prompt

Build a polished editorial SaaS interface in the Antimetal style.

Use a warm parchment canvas (`#d7d7d0`) with cream content surfaces (`#f7f6f3`) and near-white elevated blocks (`#fdfcfa`). Keep the palette almost achromatic. Use `#1a1614` for text and dark CTA fill, `#66635f` for secondary text, and `#e2e67d` only as a tiny accent.

Set all display and heading text in `Test Signifier` at weight 400. Do not bold the serif. Use `Geist` for body, nav, and buttons. Use `Geist Mono` for uppercase section markers with generous tracking.

Layout should be centered at 1200px max width, with 120px section gaps, 40px card padding, and 16px element gaps. Cards are almost rectangular with 4px radius. Buttons are pill-shaped. The navigation is a large 82px radius capsule with translucent warm fill and subtle blur.

Use dashed 1px dividers at low opacity for accordions, separators, and editorial rules. Pair every dark pill CTA with a quieter ghost outlined button. Add editorial details such as numbered sections, drop caps, pull quotes, and restrained video thumbnails.

Avoid pure white, pure black, loud accent colors, large chartreuse surfaces, gradients, heavy shadows, and typical card-heavy SaaS decoration.
