# Spacing And Shape

## Spacing

| Purpose | Value |
| --- | --- |
| Density | Comfortable |
| Base unit | 4px |
| Page max width | 1200px |
| Section gap | 64px |
| Card padding | 24px |
| Element gap | 8px to 20px |

## Radius

| Element | Value |
| --- | --- |
| Buttons | 8px |
| Inputs | 8px |
| Cards | 12px |
| Tags | 9999px |

## Elevation

Resting cards are flat. Focused or active controls may use:

```css
box-shadow: rgb(15, 119, 255) 0 0 0 1px,
  rgba(12, 43, 100, 0.32) 0 1px 2px 0,
  rgba(12, 43, 100, 0.32) 0 6px 16px 0;
```
