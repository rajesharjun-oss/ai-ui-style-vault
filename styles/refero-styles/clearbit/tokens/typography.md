# Typography

## Font

- Primary: InterVar
- Fallback: Inter variable, system-ui, sans-serif
- Weights: 400, 500, 600, 700

## Type Scale

| Role | Size | Weight | Line Height | Letter Spacing | Token |
| --- | --- | --- | --- | --- | --- |
| Caption | 14px | 400 | 1.43 | 0.056px | `--text-caption` |
| Body | 16px | 400 | 1.5 | 0.128px | `--text-body` |
| Subheading | 18px | 400 | 1.5 | 0.252px | `--text-subheading` |
| Heading Small | 32px | 600 | 1.25 | 0.512px | `--text-heading-sm` |
| Heading | 56px | 600 | 1.25 | 1.008px | `--text-heading` |
| Display | 64px | 600 | 1.25 | 1.152px | `--text-display` |

## Typography Rules

- Use the same typeface for nav, body, headings, buttons, labels, and cards.
- Use positive letter spacing. The display signature is opened tracking, not compressed display type.
- Use weight 500 or 600 for headings, not heavy 700 blocks.
- Keep body text at 16px when possible and never below 14px.
- Use Midnight Ink for headings and body; use Slate for supporting copy.
