## Use This When

Use this style when an AI agent needs to build a quiet B2B data, enrichment, CRM, intelligence, analytics, or infrastructure product page. It works best for product-led marketing where the interface screenshots and data records are the main visual proof.

## Core Idea

Clearbit is a blueprint-like product system on white and pale lavender surfaces. The palette is almost achromatic: Midnight Ink carries most text and structure, while Electric Blue and Cobalt Surface are reserved for focus, checkmarks, and a single primary action. Depth comes from pale section tints, thin borders, and a blue focus ring instead of card shadows.
