# Implementation Prompt

Build in the Clearbit style: a light B2B data-product interface on white paper with pale lavender product zones, deep navy text, thin borders, and one blue accent.

Use these rules:

- Canvas: `#ffffff`.
- Product sections: `#f5f3ff`.
- Primary text and headings: `#091135`.
- Secondary text: `#36394a`.
- Borders: `#e1e9f0`.
- Accent and focus: `#0f77ff`.
- Filled action: `#127ee3`.
- Typeface: InterVar or Inter variable fallback.
- Display type: 64px, weight 600, line-height 1.25, tracking 1.152px.
- Heading type: 56px or 32px, weight 600, line-height 1.25, positive tracking.
- Body: 16px, weight 400, line-height 1.5.
- Cards: white, 12px radius, 1px Frost Border, 24px padding, no resting shadow.
- Buttons and inputs: 8px radius.
- Pills: 9999px radius.
- Layout: centered 1200px max width, 64px section gaps, 8px to 20px element gaps.

Design a product-led page or interface. The hero should be text-first and centered on white. Feature sections should alternate between copy and floating product UI cards over Lavender Wash. Use product screenshots, enrichment rows, customer data cards, score badges, and attribute tables as the visual language.

Avoid:

- Decorative 3D renders.
- Stock photography.
- Heavy gradients.
- Multicolor accent systems.
- Drop-shadow card stacks.
- Negative letter spacing.
- Pure black for paragraphs.

The result should feel like a calm, high-trust data product: precise, white, navy, and almost monochrome, with blue used only when the interface needs to speak.
