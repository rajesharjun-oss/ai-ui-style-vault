# Typography

## Fonts

- Primary: `NB International Pro`
- Primary fallback: `Inter Tight`, `General Sans`, `Switzer`, `ui-sans-serif`, `system-ui`
- Mono: `NB International Mono Pro`
- Mono fallback: `JetBrains Mono`, `IBM Plex Mono`, `ui-monospace`, `monospace`

## Primary Behavior

Use the primary sans for everything: display, headings, body, navigation, buttons, labels, and product UI. Weight 400 is the rule for display and major headings. Weight 700 is reserved for button text and compact labels.

The signature is tight negative tracking at every size, especially the 66px display size.

## Mono Behavior

Use the mono sparingly for tabular metadata, clinical labels, technical annotations, and micro-copy.

## Scale

| Role | Size | Line Height | Weight | Tracking |
| --- | ---: | ---: | ---: | ---: |
| Caption | 11px | 1.5 | 400 | -0.005em |
| Body | 15px | 1.5 | 400 | -0.005em |
| Body Large | 17px | 1.4 | 400 | -0.009em |
| Subheading | 19px | 1.4 | 400 | -0.009em |
| Heading Small | 22px | 1.25 | 400 | -0.012em |
| Heading | 30px | 1.2 | 400 | -0.013em |
| Heading Large | 45px | 1.13 | 400 | -0.015em |
| Display | 66px | 1 | 400 | -0.025em |

## Rules

- Do not set display headings in weight 700.
- Use line-height 1 for display.
- Increase tracking compression as text gets larger.
- Use mono only for clinical and technical detail moments.
- Keep paragraph text compact but readable.
