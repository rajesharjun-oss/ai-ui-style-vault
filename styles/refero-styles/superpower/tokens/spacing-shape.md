# Spacing And Shape

## Spacing

| Purpose | Value |
| --- | --- |
| Density | compact |
| Base unit | 4px |
| Page max width | 1200px |
| Section gap | 75px |
| Card padding | 19px |
| Element gap | 11px |

## Scale

`4px`, `8px`, `11px`, `16px`, `19px`, `24px`, `28px`, `60px`, `75px`

## Radius

| Element | Value |
| --- | --- |
| Small cards | 5px |
| Icons and check squircles | 7.5px |
| Cards | 15px |
| Floating nav | 15px |
| Pills | 9999px |
| Buttons | 9999px |

## Shadow

Use no heavy shadows. The only allowed shadow is a faint 2px utility shadow.

```css
--shadow-subtle: rgba(0, 0, 0, 0.05) 0px 2px 2px 0px;
```
