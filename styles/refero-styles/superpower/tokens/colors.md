# Colors

## Palette

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Sunrise Coral | `#fc5f2b` | `--color-sunrise-coral` | Filled action pills, brand marks, active states |
| Coral Glow | `linear-gradient(88deg, #fc5f2b, #ff8b64 90%, #ffffff)` | `--gradient-coral-glow` | One-off membership card wash |
| Pure Black | `#000000` | `--color-pure-black` | Logo wordmark and deepest contrast borders |
| Carbon Black | `#18181b` | `--color-carbon-black` | Primary text, floating nav fill, headings, icon strokes |
| Zinc Gray | `#71717a` | `--color-zinc-gray` | Body text, secondary copy, muted metadata |
| Ash Gray | `#a1a1aa` | `--color-ash-gray` | Tertiary text, inactive borders, disabled states |
| Mist Gray | `#e4e4e7` | `--color-mist-gray` | Hairline borders, dividers, card outlines |
| Fog Gray | `#f4f4f5` | `--color-fog-gray` | Subtle surface elevation and muted backgrounds |
| Paper White | `#ffffff` | `--color-paper-white` | Page background, card surfaces, text on dark images |

## Usage

Keep the interface mostly neutral. Sunrise Coral should appear as a low-frequency action and brand accent, not as broad decoration. The Coral Glow gradient is reserved for the membership card visual only.
