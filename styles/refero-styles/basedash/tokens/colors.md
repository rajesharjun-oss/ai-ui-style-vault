# Colors

## Accent

| Name | Value | Token | Use |
| --- | --- | --- | --- |
| Lavender Pulse | `#9984d8` | `--color-lavender-pulse` | Violet outline accent, chart data, focus edges, and small UI signals |
| Mint Signal | `#3fcb7f` | `--color-mint-signal` | Positive state, validation, green chart data, and short status labels |

## Neutrals

| Name | Value | Token | Use |
| --- | --- | --- | --- |
| Void Black | `#000000` | `--color-void-black` | Page canvas, hero background, deepest surface |
| Carbon Card | `#050607` | `--color-carbon-card` | Elevated card and panel surfaces |
| Graphite | `#333333` | `--color-graphite` | Deep borders and separators |
| Steel Gray | `#808080` | `--color-steel-gray` | Borders, dividers, icon strokes, disabled text |
| Ash Gray | `#b3b3b3` | `--color-ash-gray` | Secondary body text and helper copy |
| Bone White | `#e8eaee` | `--color-bone-white` | Subtle light washes and secondary light elements |
| Ghost White | `#ffffff` | `--color-ghost-white` | Primary text and filled CTA background |

## Application Notes

- Use `#000000` as the dominant canvas.
- Use `#050607` for cards only when a slight surface lift is needed.
- Use white sparingly but decisively: primary text and primary CTA background.
- Use violet and mint as data accents, not decorative color blocks.
- Use gray borders with low opacity when possible so the page stays quiet.
