# Spacing And Shape

## Spacing

| Purpose | Value |
| --- | --- |
| Base unit | 4px |
| Button vertical padding | 12px |
| Button horizontal padding | 20px |
| Small gap | 8px |
| Default gap | 16px |
| Card padding | 16px to 20px |
| Hero copy max width | 640px |
| Page max width | 1200px |
| Section gap | 80px to 120px |
| Large section gap | 128px |

## Radius

| Element | Value |
| --- | --- |
| Fine detail | 1px |
| Buttons | 6px |
| Cards and images | 16px |
| Pills and badges | 999px |

## Notes

- The button radius is intentionally smaller than pill-heavy systems: keep it at 6px.
- Cards round more generously at 16px so containers feel softer than tools.
- Use large vertical gaps and centered content rather than dense marketing blocks.
