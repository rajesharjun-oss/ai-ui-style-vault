# Components

## Filled Primary Button

- Background: `#ffffff`
- Text: `#000000`
- Font: Inter, 14px, 500
- Radius: 6px
- Padding: 12px 20px
- Border: none
- Shadow: none

Use for one primary action per section.

## Ghost Text Button

- Background: transparent
- Text: `#ffffff`
- Font: Inter, 14px, 500
- Border: none
- Hover: underline or subtle opacity shift

Use for secondary actions paired with the primary CTA.
