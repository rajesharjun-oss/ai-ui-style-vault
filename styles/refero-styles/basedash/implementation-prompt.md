# Implementation Prompt

Use the Basedash style for this UI.

Create a dark, premium data-product interface on a pure black canvas (`#000000`). Use near-black cards (`#050607`) and restrained gray structure. Primary text is white, secondary text is ash gray, and the primary CTA is a white filled pill with black text. Do not use a colored CTA.

Typography:

- Use Inter for all functional UI: nav, buttons, forms, labels, tables, cards, captions, and body copy.
- Use tight functional tracking around `-0.03em`.
- Use a refined display serif only for the hero h1 and large section headings. Target 48px, 400 weight, line-height 1.
- Use an old-style serif only for testimonial pull quotes if needed.

Color:

- Canvas: `#000000`.
- Cards: `#050607`.
- Borders: `#333333` and `#808080`.
- Secondary text: `#b3b3b3`.
- Primary text and CTA background: `#ffffff`.
- Data accents: violet `#9984d8` and mint `#3fcb7f`.

Layout:

- Use a transparent top navigation around 64px tall.
- Build a centered hero stack: small pill badge, serif headline, muted subhead, button row, trust line, and large dark product mockup.
- Keep the hero copy max width around 640px and the main page max width around 1200px.
- Use 80px to 120px section spacing.
- Build product sections with centered copy, restrained card grids, dashboard mockups, testimonial pairs, and dense integration logo rows.

Components:

- Filled primary button: white background, black text, 14px Inter medium, 6px radius, 12px 20px padding.
- Ghost button: transparent, white text, no border, subtle underline or opacity change on hover.
- Badge: pill shape, transparent dark fill, 1px gray border, 13px Inter medium.
- Card: `#050607`, 16px radius, subtle gray border only when needed.
- Dashboard mockup: dark interface, violet and mint charts, black fade at edges.

Avoid decorative illustrations, lifestyle photos, full-surface gradients, bright colored CTAs, heavy shadows, and generic blue SaaS styling. The final result should feel like an elegant internal data command center.
