# Basedash

AI-ready Refero style bundle for Basedash.

- Source: https://styles.refero.design/style/77b723ca-9583-4349-9b5e-2ef8b4fde002
- Reference site: https://www.basedash.com
- Captured: 2026-07-28
- Theme: dark
- Mood: midnight data terminal with frosted type
- Industry: data tools, internal tools, database workflow

## Use This Style For

- Dark SaaS product landing pages centered on dashboards or admin tools
- AI data workspace concepts that need to feel quiet, technical, and premium
- Analytics, database, workflow, and operations tools
- Interfaces where product screenshots, charts, and status details are the main visual material

## Files

- `source.md` records the source URL and capture context.
- `DESIGN.md` is the main human-readable design reference.
- `implementation-prompt.md` is a direct prompt for an AI coding agent.
- `style.json` is a structured summary for indexing and retrieval.
- `tokens/` contains focused notes for colors, type, spacing, components, guidelines, layout, and imagery.
- `code/` contains CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` reserves the screenshot slot for manual or automated captures.

## Core Signature

Basedash is a pure-black command surface. The system uses almost no chroma: white text and white filled pill buttons do the heavy work, while violet and mint are reserved for data, charts, status, and focus. Inter carries the functional UI with tight tracking; a single serif display face gives the hero and large section headings their editorial precision.
