# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Base unit | `4px` |
| Density | `roomy` |
| Page max width | `1280px` |
| Section gap | `112px` |
| Card padding | `28px` |
| Element gap | `18px` |

## Spacing Tokens

Use `4`, `8`, `10`, `12`, `14`, `16`, `18`, `20`, `24`, `28`, `32`, `40`, `48`, `56`, `64`, `72`, `88`, `112`, and `140`.

## Radius

| Element | Radius |
|---|---:|
| Buttons | `999px` |
| Tags | `999px` |
| Cards | `28px` |
| Images | `32px` |
| Inputs | `999px` |
| Sections | `40px` |
| Stickers | `50%` or irregular circle |

## Shape Rules

- Use pill geometry for actions, tags, and inputs.
- Use generous card and image radius for food-catalog warmth.
- Use circular or sticker-like badges sparingly.
- Avoid sharp enterprise cards and sterile square inputs.
- Keep shadows minimal; use poster-like color layers instead.
