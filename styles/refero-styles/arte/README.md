# arte*

AI-ready Refero style bundle for arte*.

- Source: https://styles.refero.design/style/2f94c1f0-cd23-4bf1-95f3-0e531174c4f4
- Reference site: https://www.makearte.ca
- Captured: 2026-07-28
- Theme: mixed
- Mood: farmers market poster meets catalog drop
- Industry: food, consumer goods, grocery, specialty retail

## Use This Style For

- Food, grocery, market, cafe, pantry, and specialty retail sites
- Product catalogs that need warmth, appetite, and editorial charm
- Brand pages that mix poster-like display type with modern commerce components
- Interfaces with rounded product cards, sticker badges, warm paper surfaces, and produce colors

## Files

- `source.md` records the source URL and capture context.
- `DESIGN.md` is the main human-readable design reference.
- `implementation-prompt.md` is a direct prompt for an AI coding agent.
- `style.json` is a structured summary for indexing and retrieval.
- `tokens/` contains focused notes for colors, type, spacing, components, guidelines, layout, and imagery.
- `code/` contains CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` reserves the screenshot slot for manual or automated captures.

## Core Signature

arte* is a warm market-poster commerce style: tomato red display type, black-bean dark panels, cream paper backgrounds, olive and mint produce accents, rounded catalog cards, pill CTAs, and sticker-like price or promo moments.
