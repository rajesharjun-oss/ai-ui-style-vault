# Implementation Prompt

Build in the Supabase style: a dark developer-tool interface on a single Obsidian canvas with grayscale surfaces, border-only elevation, Circular typography, pill controls, 16px cards, and one phosphor green accent.

Use these rules:

- Page canvas: `#121212`.
- Illustration wells: `#0d0d0d`.
- Primary text: `#fafafa`.
- Secondary text: `#b4b4b4`.
- Muted text: `#898989`.
- Icon strokes and line art: `#4d4d4d`.
- Input borders: `#393939`.
- Card borders: `#2e2e2e`.
- Nested surfaces: `#242424`.
- Primary green: `#3ecf8e`.
- Link green: `#00c573`.
- Pressed green border: `#1f4b37`.
- Deep green wash: `#006239`.
- Font: Circular, with Inter or Manrope fallback.
- Code font: Source Code Pro, with JetBrains Mono fallback.
- Display: 72px Circular 400, line-height 1, tracking -0.504px.
- Body: 16px Circular 400, line-height 1.5, tracking -0.112px.
- Card heading: 18px Circular 500, line-height 1.38.
- Code snippets: 12px Source Code Pro 400, line-height 1.33, tracking 0.1em.
- Buttons and tags: 9999px radius.
- Cards: 16px radius.
- Inputs: 8px radius.
- Card padding: 24px.
- Section gap: 64px to 96px.
- Page max width: 1200px.
- No shadows.
- No gradients.

Design structure:

1. Fixed 64px top nav on Obsidian with Supabase logo, muted nav links, GitHub stars pill, sign-in ghost button, and green start button.
2. Centered hero with announcement pill, 72px headline, one green line or keyword, 16px subtitle, and two pill buttons.
3. Quiet monochrome logo cloud.
4. Feature card grids with 1px Charcoal borders and Void illustration wells.
5. Product showcase cards with wireframe diagrams, database grids, terminal snippets, and product screenshots.
6. Masonry testimonial cards.

Avoid:

- Extra accent colors.
- Light page backgrounds.
- Card shadows.
- Glow rings.
- Gradients.
- Large green section fills.
- Bold typography.
- Photography.

The result should feel like a polished midnight IDE, with every green pixel acting like a caret, not decoration.
