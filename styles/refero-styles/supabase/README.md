## Use This When

Use this style for developer tools, database products, API platforms, infrastructure dashboards, CLI-adjacent products, observability pages, docs-driven launches, and technical SaaS pages that should feel terminal-native and quietly confident.

## Core Idea

Supabase is a near-black developer-tool system with monochrome UI surfaces and one vivid green pulse. The canvas stays Obsidian, surfaces are separated by 1px borders instead of shadows, buttons are pills, cards are 16px rounded rectangles, and every green pixel must earn its place as a CTA, highlighted keyword, logo mark, or active state.
