## Capture Notes

The Refero page describes Supabase as a dark Dev Tools design system built from a single near-black canvas, grayscale structure, and a narrow green accent vocabulary. It uses Circular for almost all UI typography and Source Code Pro only for inline code or terminal snippets.

The AI-useful pieces to preserve are:

- Obsidian `#121212` is the only page canvas.
- Snow `#fafafa` is the dominant foreground.
- Phosphor Green `#3ecf8e` is rare punctuation for CTAs, logo, active state, and emphasized text.
- Mint Pulse `#00c573` is a quieter link or inline green.
- Card structure is border-based, usually `#2e2e2e`.
- No card shadows, no gradients, and no alternate canvas colors.
- Buttons and announcement chips are 9999px pills.
- Cards are 16px radius, inputs are 8px radius.
- Circular tops out at weight 500.
- Letter spacing stays around `-0.007em`.
