# Typography

## Font Roles

| Font | Role | Weights | Sizes |
| --- | --- | --- | --- |
| Circular | All UI, nav, body, buttons, headings, display | 400, 500 | 12px to 72px |
| Source Code Pro | Code and terminal snippets only | 400 | 12px |

## Type Scale

| Role | Font | Size | Weight | Line Height | Letter Spacing | Token |
| --- | --- | --- | --- | --- | --- | --- |
| Caption | Circular | 12px | 400 | 1.5 | -0.084px | `--text-caption` |
| Body Small | Circular | 14px | 400 | 1.43 | -0.098px | `--text-body-sm` |
| Body | Circular | 16px | 400 | 1.5 | -0.112px | `--text-body` |
| Subheading | Circular | 18px | 400 | 1.38 | -0.126px | `--text-subheading` |
| Heading Small | Circular | 24px | 500 | 1.33 | -0.168px | `--text-heading-sm` |
| Heading | Circular | 36px | 400 | 1.2 | -0.252px | `--text-heading` |
| Display | Circular | 72px | 400 | 1 | -0.504px | `--text-display` |
| Code | Source Code Pro | 12px | 400 | 1.33 | 0.1em | `--text-code` |

## Typography Rules

- Circular 400 is the normal voice.
- Circular 500 is the loudest allowed weight.
- Do not use 600 or 700.
- Keep tracking around `-0.007em`.
- Use size, green emphasis, and spacing instead of heavier weights.
- Use Source Code Pro only for code-like content.
