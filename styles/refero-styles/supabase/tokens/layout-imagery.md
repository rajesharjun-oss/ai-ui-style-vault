# Layout And Imagery

## Layout

- Full-width Obsidian page.
- Center content in a 1200px max-width container.
- Fixed 64px nav at the top.
- Centered hero with a 72px display headline.
- Use one green hero line or keyword.
- Pair a green pill button with a ghost pill button.
- Use 64px to 96px section gaps.
- Use centered text sections and 2x2 or 4-column feature grids.
- Use masonry layout for testimonials.
- Avoid visible section dividers.

## Imagery

Use:

- Wireframe diagrams.
- Database grids.
- Network node diagrams.
- Technical line art.
- Product screenshots in dark frames.
- Source Code Pro terminal snippets.
- Thin stroke icons.

Illustration wells should use Void background, Graphite strokes, and very small Phosphor Green details.

Avoid:

- Photography.
- Lifestyle imagery.
- Glossy 3D.
- Gradients.
- Decorative blobs.
- Large green surfaces.
