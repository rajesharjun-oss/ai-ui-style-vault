# Implementation Prompt

Build a polished GitHub-style interface: a dark developer observatory with near-black surfaces, translucent glass cards, Mona Sans typography, violet radial atmosphere, synthetic product imagery, and one Terminal Green primary CTA.

Use Deep Void (`#0d1117`) as the main canvas and Abyss (`#000000`) for hero or terminal contexts. Use Snow (`#ffffff`) for primary headings and high-contrast UI, Pearl (`#a4aea6`) for body copy, Slate Edge (`#21262d`) for borders, and Obsidian (`#151a22`) for dark inputs and controls. Use Terminal Green (`#08872b`) only for the single filled primary CTA per screen. Use Sky (`#8dd6ff`) for low-frequency link and icon accents. Use Ultraviolet (`#8c93fb`) only for rare highlighted card borders. Violet and purple should mostly appear as blurred radial gradient atmosphere.

Typography should use Mona Sans for nearly everything. The display headline should be 64px, weight 425, line-height 1.08, with -0.035em tracking. Body text should be 16px, weight 400, line-height 1.5. Use Mona Sans Mono for 12px uppercase tags, nav micro-labels, and code-adjacent metadata with 0.015em tracking.

Layout should be a full-bleed dark page with centered 1200px content. Start with a slim transparent nav, then a centered hero over a violet radial glow, an email/CTA row with Terminal Green primary button, and product evidence in IDE or browser frames. Follow with section header blocks, tab navigation pills, translucent card grids, selected cards with Ultraviolet borders, customer proof, and a four-column footer.

Components should follow the shape rules: action buttons use 6px radius, major glass cards use 24px radius, images and device frames use 16px radius, nav/tag pills use 60px or fully rounded radius. Cards should use rgba white fills from 0.06 to 0.2, 1px low-opacity borders, backdrop blur around 20px, and no drop shadows.

Before finishing, check that:

- There is only one filled Terminal Green CTA per screen.
- No blue or violet color is used as the primary action fill.
- Major cards are translucent glass with 24px radius.
- Buttons use 6px radius and nav pills use 60px radius.
- Display type uses Mona Sans weight 425, not ordinary bold.
- Product imagery is synthetic, IDE-based, or code-based, not lifestyle photography.
