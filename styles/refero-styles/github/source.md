## Notes

This bundle summarizes the Refero style page into implementation-ready guidance. It is not a verbatim archive. The style is a dark developer-observatory system: near-black canvas, translucent glass panels, violet radial atmosphere, Mona Sans variable typography, synthetic 3D/product imagery, and one terminal-green primary action.

## What To Preserve

- Deep Void page canvas with Abyss hero and terminal surfaces.
- Mona Sans for UI and display text.
- Mona Sans Mono for uppercase micro-labels and code-adjacent metadata.
- Terminal Green as the only filled primary CTA color.
- Violet gradient halo behind hero and illustrations.
- Glass cards using rgba white fills and 1px borders, not opaque panels.
- 24px card radius, 16px image radius, 6px action radius, 60px pill radius.
- Product evidence through IDE/browser frames and code UI, not photography.
