## Use This When

Use this style when a product should feel developer-native, atmospheric, technical, and quietly powerful. It works well for developer platforms, AI coding products, cloud infrastructure, security tooling, automation platforms, and product pages with code or IDE evidence.

The important constraint is that color is surgical. Terminal Green marks the one primary CTA. Violet and purple exist as ambient halos and rare highlighted borders. Sky blue is a cool text/icon accent. Everything else is near-black glass, gray borders, and Mona Sans typography.
