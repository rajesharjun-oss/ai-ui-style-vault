# Components

## Primary CTA Button

- Terminal Green fill.
- Snow text.
- No border.
- 6px radius.
- 6px 20px padding.
- Mona Sans 16px weight 400.
- Use for the one highest-intent action only.

## Ghost Button

- Transparent fill.
- Snow text or border.
- 0px radius for compact icon buttons.
- 60px radius for text pills.
- Used for secondary actions and navigation-adjacent controls.

## Pill Button Or Nav Tag

- Transparent fill.
- Snow text.
- 1px Snow or low-opacity Snow border.
- 60px radius.
- 8px 16px padding.
- Used for tab navigation, topics, filters, and category selectors.

## Outlined Action Button

- Dark translucent fill.
- Sky text.
- Snow border.
- 6px radius.
- 6px 20px padding.
- Use beside the green CTA as a lower-pressure action.

## Email Input Field

- Transparent or Obsidian fill.
- Slate Edge border.
- 6px to 8px radius.
- Pearl placeholder.
- 16px Mona Sans text.
- Can sit inline with CTA.

## Glass Surface Card

- rgba white fill from 0.06 to 0.2.
- 1px low-opacity white or Slate Edge border.
- 24px radius.
- Backdrop blur around 20px.
- No box shadow.

## Featured Card

- Glass surface.
- Ultraviolet 1px border.
- 24px radius.
- Use sparingly for selected or highlighted cards.

## Top Navigation Bar

- About 64px high.
- Transparent background.
- White logo.
- Mona Sans nav links.
- Dropdown chevrons.
- Obsidian search field.
- Sign-in/up actions on the right.

## Section Header Block

- Optional 3D icon at top.
- Mona Sans 40px weight 460 headline.
- Pearl body text at 18px.
- Max width around 640px.
- Centered.

## Tab Navigation Row

- Horizontal row of 60px pill buttons.
- Active state can use Snow fill or stronger border.
- Inactive state stays transparent.
- Use about 32px gap before tab content.

## Hero Gradient Banner

- Radial violet gradient.
- Blur around 60px.
- Positioned behind hero copy and illustrations.
- No hard edge.

## IDE Or Device Frame

- Browser or IDE chrome.
- Traffic-light dots.
- Tab labels and code editor content.
- 8px outer radius.
- 6px inner panel radius.

## Footer Link Grid

- Deep Void background.
- Four columns.
- Snow 16px/600 headings.
- Pearl 14px/400 links.
- 12px vertical link spacing.
