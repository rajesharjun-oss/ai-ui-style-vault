# Layout And Imagery

## Layout

Use a full-bleed dark page with centered content blocks around 1200px. The canvas itself has no max-width.

Suggested order:

1. Slim transparent navigation.
2. Centered hero over violet radial glow.
3. Inline email or CTA cluster.
4. Product IDE/browser frame.
5. Section header with optional 3D icon.
6. Pill-tab navigation.
7. Glass card grid.
8. Customer proof or logos.
9. Four-column footer link grid.

## Composition

The page should feel dark and inhabited, not empty. Use gradient atmosphere, translucent cards, product frames, and synthetic character or blob illustrations to create depth.

## Imagery

Use:

- IDE screenshots
- browser chrome frames
- code editor panels
- synthetic rounded 3D characters
- line icons
- gradient halos
- constellation-like arrangements

## Avoid

- People photography.
- Office photography.
- Opaque white cards.
- Heavy 3D scenes unrelated to product.
- Generic SaaS illustration packs.
- Flat black sections with no atmospheric depth.
