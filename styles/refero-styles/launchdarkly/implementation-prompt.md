# Implementation Prompt

Build a dark developer-tool landing page inspired by LaunchDarkly.

Use `#0e0e0e` as the page background and `#191919` as the main card, nav, code, and footer surface. Use `#2c2c2c` for dense list separators, `#414042` for elevated panel borders, and `rgba(255,255,255,0.1)` for subtle hairlines. Use `#ffffff` for main text, `#d1d3d4` for tertiary text, and `#a7a9ac` for secondary copy.

Use `#405bff` as the filled primary CTA color and `#7084ff` as the headline accent, outline accent, and gradient endpoint. Use the linear gradient `linear-gradient(179deg, #405bff 1.06%, #7084ff 123.42%)` for hero text accent washes and ambient card glows. Use `#3dd6f5` only as a rare atmospheric cyan glow.

Use a custom grotesk such as Sohne, Inter, Geist, or Space Grotesk for interface and display type. Use a mono font such as Sohne Mono, JetBrains Mono, IBM Plex Mono, or Geist Mono for code, SDK names, and technical labels. Set hero headlines around 84px to 100px, weight 500, line-height 1.0 to 1.09.

Use 30px radius for buttons, tags, tabs, and cards. Use 60px radius for the floating nav pill. Use 10px radius for large form inputs. Use 32px to 48px card padding, 16px to 24px element gaps, and 80px to 120px section gaps.

Build these primitives: floating nav pill, Voltage Blue primary CTA, hero email capture input with blue glow, segmented tab control, feature checklist, product screenshot panel, code snippet block, SDK/resource card, logo strip, and ghost violet outline action.
Avoid:

- Do not use square corners or small 4px to 8px radii on user-facing components.
- Do not use drop shadows for normal elevation; use glow instead.
- Do not introduce additional accent colors.
- Do not use white or gray for primary action buttons.
- Do not center-align body copy or feature lists.
- Do not use display headline line-height above 1.5.
- Do not put dark product screenshots on the page.
