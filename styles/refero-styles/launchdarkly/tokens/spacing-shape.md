# Spacing And Shape Tokens

## Spacing

| Purpose | Value |
| --- | --- |
| Density | comfortable |
| Base unit | `8px` |
| Max width | `1200px` |
| Section gap | `80px` to `120px` |
| Card padding | `32px` to `48px` |
| Element gap | `16px` to `24px` |

## Borders And Elevation

- Default dark border: `1px solid rgba(255,255,255,0.1)`.
- Card border: `1px solid #414042`.
- Floating nav shadow: `0 4px 20px rgba(0,0,0,0.45)`.
- Hero input glow: `0 0 40px rgba(64,91,255,0.25)`.
- Prefer glow over drop shadows.
