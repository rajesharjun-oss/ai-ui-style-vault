# Color Tokens

## Brand

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Signal Violet | `#7084ff` | `--color-signal-violet` | Hero headline accent, link underlines, outline actions, icon glows, gradient endpoint. |
| Voltage Blue | `#405bff` | `--color-voltage-blue` | Primary CTA fill, tag outline accent, focused UI edges. |
| Plasma Cyan | `#3dd6f5` | `--color-plasma-cyan` | Rare radial glow and atmospheric secondary endpoint. |

## Neutrals

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Midnight Ink | `#0e0e0e` | `--color-midnight-ink` | Page canvas and deepest background. |
| Carbon | `#191919` | `--color-carbon` | Nav pill, cards, code blocks, footer, button surfaces. |
| Smoke | `#2c2c2c` | `--color-smoke` | List dividers and row separators. |
| Graphite | `#414042` | `--color-graphite` | Elevated panel outlines, card borders, secondary surfaces. |
| Steel | `#58595b` | `--color-steel` | Input borders and inactive form fields. |
| Slate | `#6d6e71` | `--color-slate` | Muted helper text and disabled labels. |
| Fog | `#a7a9ac` | `--color-fog` | Secondary text, subtle borders, placeholder copy. |
| Ash | `#d1d3d4` | `--color-ash` | Tertiary text, icon strokes, light dividers. |
| Paper | `#ffffff` | `--color-paper` | Primary text, heading fills, icon strokes, white product screenshots. |

## Gradients And Glow

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Signal Gradient | `linear-gradient(179deg, #405bff 1.06%, #7084ff 123.42%)` | `--gradient-signal` | Ambient hero/card glow and brand wash. |
| Blue Glow | `0 0 40px rgba(64,91,255,0.25)` | `--glow-blue` | Hero form halo and product card glow. |
| Violet Glow | `0 0 40px rgba(112,132,255,0.19)` | `--glow-violet` | Decorative edge glow and accent panels. |

## Rules

- Use Voltage Blue for filled primary actions.
- Use Signal Violet for headline accents, outlines, and glows.
- Use Plasma Cyan rarely and only for atmosphere.
- Do not introduce green, red, yellow, or extra accent colors for normal UI.
