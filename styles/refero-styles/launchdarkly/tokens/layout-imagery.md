# Layout And Imagery

## Layout Grammar

LaunchDarkly uses a full-bleed dark canvas with centered 1200px content containers. The hero is tall and centered, while feature and product sections become left-aligned and more operational.

## Common Layouts

- Hero with two-line headline, violet second line, subtext, and glowing email capture form.
- Floating nav pill fixed near the top center.
- Quiet logo strip with grayscale partner logos.
- Tabbed feature section with two-column text and product screenshot.
- Code integration section with code panel and explanatory copy.
- Three-column resource card grid.
- Product screenshot panels rendered as bright white cards on dark.

## Imagery

- Use bright product screenshots, code snippets, SDK examples, customer logos, and technical UI fragments.
- Avoid lifestyle photography, decorative 3D art, and unrelated illustration.
- Product UI should be readable and bright.
- Code should be treated as a visual asset.

## Motion

- Use subtle `180ms` to `240ms` UI transitions.
- Glow can pulse very slightly, but avoid playful animation.
- Keep transitions technical and controlled.
