# Implementation Prompt

Build a UI in the Legora style.

Create a warm legal-editorial interface with parchment canvas, whisper-light serif display headlines, tight humanist body copy, black micro-radius buttons, monochrome logos, and pastel product panels. It should feel like a legal journal with product evidence, not a colorful SaaS landing page.

Use these hard rules:

- Page canvas: `#fefefc`.
- Main text: `#0a0a0a`.
- Solid CTA fill: `#000000`.
- Secondary text: `#6b6b6b`.
- Tertiary text/dividers: `#444444`.
- Placeholder/disabled tint: `#98a7aa`.
- Sage wash panel: `#ebf5ed`.
- Slate product panel: `#bdd4f0`.
- Do not use pure white `#ffffff` as a page surface.
- Do not introduce saturated red, blue, green, or purple brand colors.
- Use Rhymes Display 300 for display headlines.
- Display headline: 88px, line-height 0.95, letter-spacing -1.76px.
- Use Suisse Intl 450 for body text at 14px to 16px with -0.01em tracking.
- Use one solid black button per viewport at most.
- Buttons and tags use 2px radius.
- Cards and inputs use 8px radius.
- Do not use pill buttons.
- Do not use drop shadows or elevated cards.
- Use accent washes only as large panels, never small chips or buttons.
- Partner logos must be monochrome at 60 to 70 percent opacity.

Build a full-bleed dark cinematic hero with a centered lower-third Rhymes Display headline in parchment text. Beneath it, return to parchment and create a partner logo row, a narrow editorial intro, a three-column feature grid with pastel-tinted product panels, and a two-column legal product section. Keep everything flat, quiet, and typographic.
