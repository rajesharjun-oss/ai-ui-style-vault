# Colors

| Token | Value | Use |
| --- | --- | --- |
| `--legora-parchment` | `#fefefc` | Page canvas, card surfaces, light-section backgrounds |
| `--legora-ink` | `#000000` | Solid CTA fill, dark borders, inverted UI separators |
| `--legora-graphite` | `#0a0a0a` | Body text, heading strokes, dark surface accents |
| `--legora-iron` | `#444444` | Tertiary text and intermediate dividers |
| `--legora-smoke` | `#6b6b6b` | Secondary body copy, subdued borders, captions |
| `--legora-verdigris-wash` | `#ebf5ed` | Sage product panels and calm active washes |
| `--legora-slate-mist` | `#bdd4f0` | Cool product-preview panels and background links |
| `--legora-pewter-haze` | `#98a7aa` | Disabled fills, placeholders, empty illustration frames |

## Usage Rules

- Keep the page canvas at `#fefefc`.
- Use black as CTA fill and structural ink only.
- Use Graphite for readable text when pure Ink feels harsh.
- Use Verdigris Wash and Slate Mist as broad surface panels only.
- Do not introduce saturated brand color.
- Do not show logos in native brand colors.
