# Spacing And Shape

## Spacing

| Token | Value | Use |
| --- | ---: | --- |
| `4` | 4px | Micro spacing |
| `6` | 6px | Fine UI spacing |
| `8` | 8px | Eyebrow gap, card radius |
| `10` | 10px | Element gap, button vertical padding |
| `12` | 12px | Input padding and compact spacing |
| `16` | 16px | Cookie card padding |
| `20` | 20px | Local text stack |
| `24` | 24px | Card padding, button horizontal padding |
| `32` | 32px | Section-local grouping |
| `36` | 36px | Local layout spacing |
| `40` | 40px | Large local spacing |
| `48` | 48px | Two-column gap low end |
| `56` | 56px | Large visual spacing |
| `64` | 64px | Two-column gap high end |
| `80` | 80px | Section gap |
| `160` | 160px | Large page breathing room |
| `max-width` | 1200px | Page container |

## Radius

| Token | Value | Use |
| --- | ---: | --- |
| `tag` | 2px | Tags and small labels |
| `button` | 2px | Solid and ghost buttons |
| `card` | 8px | Feature cards and cookie banner |
| `input` | 8px | Form fields |

## Shape Rules

- Buttons use 2px micro-radius.
- Do not use 0px buttons.
- Do not use fully rounded buttons.
- Cards and inputs use 8px.
