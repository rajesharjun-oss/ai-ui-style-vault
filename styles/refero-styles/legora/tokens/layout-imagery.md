# Layout And Imagery

## Layout

- Use a full-bleed dark cinematic hero.
- Return to centered 1200px parchment content below the hero.
- Place the hero headline in the lower third, centered.
- Use a partner logo row immediately after the hero.
- Use a narrow editorial intro paragraph, around 60 percent of container width.
- Use a three-column feature grid with tall pastel panels.
- Use wider two-column text and product sections.
- Keep 80px vertical spacing between major sections.
- Use compact local gaps around 10px.

## Imagery

Use:

- One dark cinematic still in the hero.
- Legal/product UI mockups in pastel panels.
- Document lists.
- Search overlays.
- Monochrome partner logos.
- Thin 1.5px line icons.

Avoid:

- Multiple full-bleed photos.
- Stock lifestyle imagery.
- Decorative illustration.
- Saturated UI art.
- Native-color partner logos.
- Product surfaces with drop shadows.
