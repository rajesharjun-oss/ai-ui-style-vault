# AI Implementation Prompt

Build a polished, responsive interface in the Dovetail style.

The interface should feel like a dark research command center: graphite canvas, charcoal panels, pale text, compact typography, thin borders, tag pills, video evidence cards, transcripts, and one soft indigo action color.

Core rules:

- Use `#0a0a0a` as the deepest page canvas.
- Use `#111111`, `#1e1e1e`, and `#2d2d2d` as stepped surfaces.
- Use `#fafafa` and `#ffffff` for primary text and strong foreground.
- Use `#a3a3a3` for secondary copy and metadata.
- Use `#8b7cf6` for the primary CTA, selected state, focus ring, and active markers.
- Use Inter for product text and JetBrains Mono only for timestamps, labels, and technical metadata.
- Use 8px radius for buttons, cards, inputs, and nav items.
- Use 9999px radius only for tags and pills.
- Avoid shadows, gradients, decorative imagery, and extra accent colors.

Recommended layout:

1. Dark app shell with top nav and thin border.
2. Left sidebar or filter column for projects, tags, or sources.
3. Main research grid with evidence cards, video previews, tags, and metadata.
4. Detail panel with transcript rows, selected quote highlights, timestamps, and insight notes.
5. Dashboard cards with metrics, charts, and compact list rows.
6. Primary indigo CTA for the most important workflow action.

Make the result feel focused, analytical, credible, and product-real.
