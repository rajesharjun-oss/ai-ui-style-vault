# Dovetail

Dark research command center: a nearly black product UI with stepped charcoal surfaces, compact Inter typography, JetBrains Mono metadata labels, soft indigo accents, and structure built from borders instead of shadows.

Use this style when you want a research repository, customer insights platform, analytics workspace, AI review tool, or operations dashboard to feel focused, dense, and trustworthy without becoming visually loud.

## Files

- `source.md`: Source URL, reference site, capture notes, and scope.
- `DESIGN.md`: Human-readable design breakdown.
- `implementation-prompt.md`: Prompt for an AI builder to implement the style.
- `style.json`: Structured design metadata.
- `tokens/`: Markdown token notes by category.
- `code/`: CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md`: Placeholder for future manual screenshots.

## Quick Use

1. Use `Graphite` as the page canvas.
2. Use stepped charcoal surfaces for cards, inputs, and nested panels.
3. Use `Soft Indigo` as the only interactive accent.
4. Use Inter for most text and JetBrains Mono only for timestamps, labels, and metadata.
5. Use 8px radii for cards, buttons, and inputs.
6. Use 1px borders and subtle surface shifts instead of shadows.
