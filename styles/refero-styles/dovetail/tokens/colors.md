# Colors

| Name | Value | Token | Role |
|---|---:|---|---|
| Graphite | `#0a0a0a` | `--color-graphite` | Page canvas and deepest application background |
| Obsidian | `#111111` | `--color-obsidian` | Main cards, elevated surfaces, input backgrounds |
| Charcoal | `#1e1e1e` | `--color-charcoal` | Nested panels, hover states, secondary fills |
| Slate | `#2d2d2d` | `--color-slate` | Active rows, separators, toolbar surfaces |
| Iron | `#3a3a3a` | `--color-iron` | Stronger borders and disabled controls |
| Silver | `#a3a3a3` | `--color-silver` | Secondary text, metadata, muted descriptions |
| Pearl | `#fafafa` | `--color-pearl` | Primary text and high-contrast icon strokes |
| White | `#ffffff` | `--color-white` | Strongest foreground, logos, selected icon details |
| Soft Indigo | `#8b7cf6` | `--color-soft-indigo` | Primary CTA, selected states, active markers |
| Indigo Glow | `#a78bfa` | `--color-indigo-glow` | Hover/active accent and subtle glow detail |
| Muted Purple | `#6d5dd3` | `--color-muted-purple` | Secondary accent for tags, charts, inactive accent states |

## Guidance

- Keep Graphite dominant.
- Use Obsidian, Charcoal, and Slate as stepped surfaces.
- Use Pearl and White for text hierarchy.
- Use Soft Indigo sparingly for action and selection.
- Do not introduce gradients or extra accent colors.
