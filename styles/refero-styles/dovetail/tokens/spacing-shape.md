# Spacing And Shape

## Spacing

| Purpose | Value | Notes |
|---|---:|---|
| Density | compact | Research command-center rhythm |
| Base unit | 4px | Token foundation |
| Max width | 1280px | Product/marketing surfaces |
| Sidebar width | 240px to 280px | App shell or filter panel |
| App gap | 12px to 20px | Cards, filters, panel groups |
| Card padding | 16px to 20px | Research cards and metric tiles |
| Section gap | 64px to 96px | Marketing/product sections |
| Button padding | 8px 12px | Compact action controls |
| Tag padding | 4px 10px | Metadata pills |

## Shape

| Element | Radius | Notes |
|---|---:|---|
| Buttons | 8px | Default action shape |
| Cards | 8px | Research and metric cards |
| Inputs | 8px | Search/filter controls |
| Nav items | 8px | Sidebar rows |
| Media tiles | 10px to 12px | Video thumbnails |
| Tags | 9999px | Metadata and status pills |

## Elevation

- Card shadows: none.
- Inputs: no shadow.
- Use 1px borders and stepped dark fills.
- Modal overlays can use a subtle shadow only when needed.
