## Capture Notes

This bundle paraphrases the Refero style reference into implementation notes for AI-assisted UI building. It preserves the style intent, color roles, typography behavior, spacing, component recipes, layout rhythm, and visual constraints without copying the source text wholesale.

## What To Preserve

- Warm parchment page canvas.
- Monochrome UI with photography as the only real color.
- Gill Sans-like humanist sans for headings and body.
- Fira Mono for uppercase labels, badges, nav, and metadata.
- Large wordmark hero.
- Hairline borders, no shadows, no gradients.
- Sharp image and card geometry, with only 5px badge corners.
