# Implementation Prompt

Build a polished editorial travel interface inspired by the Kobu Refero style system.

Use warm parchment paper, monochrome UI, full-bleed property photography, Gill Sans-style editorial type, Fira Mono labels, 1px hairline borders, and almost no conventional product chrome. Photography should be the only expressive color.

## Required Style Decisions

- Page background: Parchment `#f9f5f2`.
- Main text, icons, and hairlines: Obsidian `#242429`.
- Body copy: Graphite `#3e3e3e`.
- Muted labels: Ash Gray `#919191`.
- Card and badge surface: Gallery White `#ffffff`.
- Maximum contrast: Ink Black `#000000` or Charcoal Deep `#070707`.
- No chromatic UI accent.
- No colored CTA buttons.
- No gradients.
- No shadows.
- Cards, images, buttons, and nav: 0px radius.
- Badges: 5px radius.
- Page max width: 1440px.

## Typography Direction

Use a Gill Sans-like humanist sans for all headings, body copy, wordmarks, and section text. Use Fira Mono for nav, badges, category labels, metadata, and prices.

Set the main KOBU-style wordmark at 64px, weight 500 or 400, line-height 1. Use Fira Mono labels at 10px to 12px with wide 0.167em to 0.183em tracking.

## Layout Direction

Create:

- A full-width parchment page.
- A top navigation bar with Fira Mono category links, centered wordmark, and search icon.
- A huge display wordmark as the hero anchor.
- Large full-bleed property photographs.
- Property cards with image first, no card box, and tight text rows below.
- Right-aligned prices and View All links.
- Minimal footer with a single top hairline.

## Avoid

- Colored CTAs or accent buttons.
- Gradients, glows, shadows, and overlays.
- Rounded image cards.
- Filled icon buttons.
- Decorative illustrations.
- Stock icon sets.
- New neutral colors.
- Typography outside the Gill Sans plus Fira Mono pairing.
