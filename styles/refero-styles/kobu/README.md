- Reference site: https://kobu.co
- Captured: 2026-07-28
- Theme: light
- Mood: monochrome travel gazette on warm parchment

## Use This When

Use this style for travel portfolios, boutique hotels, villas, retreats, architecture journals, destination guides, hospitality directories, gallery-like property listings, and editorial sites where photography should be the only expressive color.

## Core Idea

Kobu is austere on purpose. A warm parchment canvas, monochrome typography, full-bleed travel photography, hairline borders, no shadows, no gradients, and no colored CTAs create a printed guidebook feeling. The oversized KOBU wordmark is the hero gesture; the rest of the interface stays quiet.
