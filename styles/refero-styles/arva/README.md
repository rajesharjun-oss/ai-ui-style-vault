# Arva

AI-ready Refero style bundle for Arva.

- Source: https://styles.refero.design/style/15846be3-8df8-42e4-a05c-d9395dcec369
- Reference site: https://arva.com
- Captured: 2026-07-28
- Theme: light
- Mood: pastoral editorial magazine spread on a cream field
- Industry: agriculture, climate, regenerative supply chains, sustainability

## Use This Style For

- Agriculture, climate, nature, regenerative supply chain, and sustainability sites
- Editorial landing pages that need a printed-magazine feel rather than SaaS chrome
- Warm product pages with field photography, forest bands, pill CTAs, and pastel testimonial cards
- Brand systems where earth-tone restraint should feel premium and trustworthy

## Files

- `source.md` records the source URL and capture context.
- `DESIGN.md` is the main human-readable design reference.
- `implementation-prompt.md` is a direct prompt for an AI coding agent.
- `style.json` is a structured summary for indexing and retrieval.
- `tokens/` contains focused notes for colors, type, spacing, components, guidelines, layout, and imagery.
- `code/` contains CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` reserves the screenshot slot for manual or automated captures.

## Core Signature

Arva is pastoral editorial web design: bone paper canvas, deep forest green structural bands, rare vivid lime announcement strips, Reckless serif headlines, Inter UI text, giant pill buttons, and quilted pastel content cards over warm agricultural photography.
