# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Density | `comfortable` |
| Page max width | `1200px` |
| Section gap | `50px` |
| Card padding | `30px` |
| Element gap | `8px` |
| Forest banner padding | `80px` or more |
| Footer top padding | `110px` or more |

## Spacing Tokens

Use `5`, `6`, `8`, `9`, `10`, `12`, `15`, `20`, `24`, `27`, `30`, `38`, `40`, `50`, `64`, and `193`.

## Radius

| Element | Radius |
|---|---:|
| Cards | `20px` |
| Links | `26px` |
| Hero cards | `30px` |
| Inputs | `33px` |
| Buttons | `100px` |
| Nav pills | `110px` |

## Shape Rules

- Oversized pills are a signature. Preserve them.
- Use 20px and larger radii for cards.
- Do not use 4px to 8px radii for primary surfaces.
- Inputs should feel pill-like, not box-like.
- Avoid shadows; use color and shape for separation.
