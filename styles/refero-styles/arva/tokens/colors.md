# Colors

## Palette

| Name | Value | Token | Role |
|---|---:|---|---|
| Forest Ink | `#07503f` | `--color-forest-ink` | Primary brand surface, nav, header, footer, dividers, filled CTA |
| Vivid Lime | `#e8fe85` | `--color-vivid-lime` | Marquee strip, announcement bar, rare promotional micro-accent |
| Bone | `#f1efdf` | `--color-bone` | Page canvas and warm paper base |
| Pure White | `#ffffff` | `--color-pure-white` | Card surfaces, input fills, button text, icon backgrounds |
| Ash Gray | `#efefef` | `--color-ash-gray` | Secondary card surface and subtle section divider |
| Charcoal | `#212529` | `--color-charcoal` | Primary body text, headings on light surfaces, icon strokes |
| Graphite | `#353535` | `--color-graphite` | Secondary text, link borders, button borders, quiet outlines |
| Pewter | `#6d6d6d` | `--color-pewter` | Muted helper text, tertiary buttons, low-emphasis copy |
| Sky Card | `#b2cee7` | `--color-sky-card` | Pastel testimonial or category tile |
| Peach Card | `#fceace` | `--color-peach-card` | Warm pastel testimonial or category tile |
| Sage Card | `#e6ecd5` | `--color-sage-card` | Soft green testimonial or category tile |
| Moss | `#c3cda7` | `--color-moss` | Subtle borders, input outlines, internal dividers |

## Usage

- Use Bone as the base background for light sections.
- Use Forest Ink as the dark structural surface and primary action.
- Use Vivid Lime rarely, mainly as a full-width marquee or tiny promo accent.
- Use Pure White as a layer on top of Bone, not as the whole canvas.
- Use the pastel card colors in rows like a quilted field sequence.
- Use Charcoal for readable text and Moss or Graphite for borders.
