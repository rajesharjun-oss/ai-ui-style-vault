# AI Implementation Prompt

Build a warm pastoral editorial interface inspired by Arva.

Use a bone paper canvas, deep forest green structural bands, vivid lime only for a promotional marquee, soft pastel card tiles, Reckless serif headings, Inter UI/body text, oversized pill buttons, and full-bleed agricultural photography. The result should feel organic, printed, spacious, and editorial rather than like a generic SaaS dashboard.

Requirements:

- Use Bone as the base background for every light section. Do not use pure white as the page canvas.
- Use Forest Ink for the header, nav, section banners, footer, and primary filled actions.
- Use Vivid Lime only for a full-width marquee strip, announcements, or tiny promo accents.
- Use the pastel surfaces as one-card-per-color tiles in rows, not as random decoration.
- Use Reckless or a high-quality serif substitute for headings at 24px and above.
- Use Inter or DM Sans for nav, labels, body, badges, buttons, and forms.
- Use 100px radius on buttons, 110px on nav pills, 33px on inputs, and 20px on cards.
- Avoid shadows. Create separation with surface color shifts, not elevation.
- Use full-bleed field, crop, farmer, or landscape photography with warm natural color.
- Avoid extra saturated colors, hard 4px buttons, centered body paragraphs, heavy filters, abstract graphics, and dashboard-dense layouts.

Hero recipe:

Create a full-viewport landscape photography hero. Use a centered white Reckless headline at 57px to 80px. Place two 100px-radius pill buttons below: a Forest Ink filled primary action and a transparent outlined secondary action. Add a small Inter scroll cue at the bottom center.

Quilt card recipe:

Create a 3-column testimonial or partner row on a Bone canvas. Each card uses one pastel surface, 20px radius, 30px padding, centered logo, Inter body quote, author name in Inter 600, and small role text. Do not use shadows.
