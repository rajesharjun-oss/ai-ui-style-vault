# Implementation Prompt

Use the Reflect Notes style language for this UI.

Create a dark, calm thinking environment: near-black violet canvas, lilac-white text, one sparse lavender accent, inset rim-light glass panels, medium-weight editorial headings, a floating nav pill, and product screenshots that feel like notes floating in a constellation.

Core rules:

- Use `#030014` as the page background. Do not use pure black.
- Use `#060317` for cards, nav pill, and elevated panels.
- Use `#10093a` for highest surfaces, hover states, and deep violet control fills.
- Use `#f4f0ff` for headings and primary UI text.
- Use `#a8a6b7` for body text and secondary labels.
- Use `#918ea0` for metadata, inactive controls, and helper copy.
- Use `#9382ff` only for links, active states, focus rings, and small accent icons.
- Use `#5046e4` for compact filled CTA surfaces only when needed.
- Use AeonikPro weight 500 for all headings at 24px and above.
- Use Inter V weight 400 for body and 500 for buttons or labels.
- Do not use 600 or 700 weights.
- Use inset white or violet glow for elevation; do not use drop shadows.
- Use 5px radius for buttons and inputs, 16px for cards/screenshots, 32px for badges, and 999px only for the nav pill.
- Use the cosmic gradient only on accent text or thin strokes.

Recommended structure:

- Floating centered nav pill with logo, links, login, and compact CTA.
- Centered hero with AI badge pill, 72px AeonikPro headline, Inter subtitle, and wide product screenshot.
- Subtle star field behind the hero.
- Feature grid with outline icons, no visible card backgrounds, and compact copy.
- Testimonial cards on Midnight Surface with inset glow and small avatars.
- Section headers centered with optional AI badge.
- Aurora dividers used sparingly.

Avoid:

- Bright colorful UI.
- Pure black backgrounds.
- Pure white body copy.
- Drop shadows.
- Bold headings.
- Large gradient fills.
- Semantic status colors.
- Lifestyle photography or 3D renders.

The result should feel like a focused cosmic note-taking app, not a generic dark dashboard.
