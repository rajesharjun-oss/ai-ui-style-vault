# Colors

| Name | Hex / Value | Use |
| --- | --- | --- |
| Void Canvas | `#030014` | Page background, hero canvas, deepest surface layer |
| Midnight Surface | `#060317` | Elevated surface, card backgrounds, nav pill, panels |
| Deep Indigo | `#10093a` | Most elevated surface, hover states, prominent panels, deep button surface |
| Steel | `#54525f` | Deepest muted text, disabled labels, dark-mode border contrast |
| Dusk | `#72707b` | Secondary borders, inactive icon strokes, subtle background tints |
| Fog | `#918ea0` | Tertiary text, metadata, helper text, inactive controls, border lines |
| Ash | `#a8a6b7` | Secondary body text and card labels |
| Mercury | `#cdccd0` | Bright dividers, subtle borders, light-on-dark surface tints |
| Lilac White | `#f4f0ff` | Primary text, headings, icons, high-contrast UI elements |
| Pearl | `#ffffff` | Text on violet-filled elements and maximum contrast headlines, used sparingly |
| Lavender Accent | `#9382ff` | Links, active icons, focus rings, gradient endpoints, highlight punctuation |
| Iris | `#5046e4` | Supporting violet accent for buttons, decorative details, and low-frequency emphasis |
| Cosmic Gradient | `linear-gradient(90.01deg, #e59cff 0.01%, #ba9cff 50.01%, #9cb2ff 100%)` | Accent text and thin decorative strokes only |
| Aurora | `linear-gradient(180deg, rgba(183,164,251,0) 0%, #b7a4fb 50%, #8562ff 100%, rgba(133,98,255,0) 100%)` | Divider lines and edge highlights only |

## Palette Rules

- Use Void Canvas instead of pure black.
- Use Lilac White or Ash for readable text.
- Use Lavender Accent as punctuation only.
- Use Iris for compact buttons and decorative emphasis, not broad backgrounds.
- Use gradients only on text and thin strokes.
- Avoid semantic status colors.
