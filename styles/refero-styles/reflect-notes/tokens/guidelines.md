# Guidelines

## Do

- Set the page background to Void Canvas.
- Use body text in Ash or Lilac White.
- Use AeonikPro 500 at 48px to 72px for headings.
- Use 5px radius for buttons, inputs, and interactive elements.
- Use 16px radius for cards and screenshots.
- Use 32px radius for pill badges.
- Use 999px only for the nav container.
- Apply inset rim-light glows instead of drop shadows.
- Use Lavender Accent only for links, active states, focus rings, and small accent icons.
- Use Cosmic Gradient only on text and thin strokes.

## Do Not

- Do not use pure black for the canvas.
- Do not use bold or extra-bold weights.
- Do not use drop shadows.
- Do not add accent color to large fills or backgrounds.
- Do not use gradient button fills or section backgrounds.
- Do not use pure white for body copy.
- Do not introduce semantic red, green, or yellow status colors.
- Do not introduce a second accent hue.

## AI Implementation Notes

- If the UI feels too flat, add inset glow and surface contrast, not shadows.
- If it feels too colorful, remove every accent except Lavender Accent and the gradient text.
- If it feels like a dashboard, reduce chrome and make the product screenshot or note content the focal point.
- If the hero feels empty, add subtle stars, not decorative illustration.
