## Use This Style For

- Notes apps, personal knowledge tools, AI writing spaces, focused productivity tools, and thinking environments.
- Interfaces that should feel calm, dark, intelligent, and slightly cosmic without becoming decorative.
- Product-led pages where a single app screenshot, feature grid, and testimonial cards carry the story.

## Design Memory

Reflect Notes is a dark observatory for thinking. The base is a near-black violet canvas, not pure black. Text is lilac-white, accents are sparse lavender, and panels feel like dark glass because elevation comes from inset rim-light glows instead of drop shadows. AeonikPro headings stay medium-weight, while Inter V handles functional UI.
