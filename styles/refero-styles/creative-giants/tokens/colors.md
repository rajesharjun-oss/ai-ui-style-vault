# Colors

| Name | Hex | Use |
| --- | --- | --- |
| Bone White | `#fffef7` | Page canvas, card surfaces, text on dark accents, warm paper tone |
| Ink Black | `#000000` | Text, icons, black menu pill, strong contrast details |
| Graphite | `#666666` | Secondary body text, captions, metadata, helper copy |
| Ash | `#aaaaaa` | Input borders, inactive links, tertiary dividers, quiet outlines |
| Charcoal Scale | `#4d4c4a` | Warm gray for borders and rare dark footer or gradient track |
| Magenta Bloom | `#8a0467` | Pink supporting accent, editorial borders, low-frequency emphasis |
| Forest Teal | `#03624c` | Saturated accent for card frames, strokes, and duotone treatments |
| Powder Blue | `#a5c8eb` | Soft card background, cool wash, muted illustration fill |
| Candy Pink | `#ffacea` | Pastel card surface, high-key editorial tint |
| Mint Wash | `#a5ebd6` | Pastel card surface, calm cool accent block |
| Navy Ink | `#101731` | Deep accent card surface and rare inverted text ground |
| Signal Yellow | `#ffd001` | Tiny badges, tag pills, hover state, sporadic high-chroma highlight |

## Palette Rules

- Use Bone White as the only page background.
- Use Ink Black for primary text and the main pill control.
- Use chromatic colors in trace amounts: borders, small fills, single cards, badges, and hover moments.
- Never use a chromatic fill for the primary CTA.
- Do not introduce default browser blue links.
