# Spacing And Shape

## Spacing

| Purpose | Value |
| --- | --- |
| Density | Comfortable |
| Base unit | 8px |
| Section gap | 64px |
| Card padding | 24px |
| Element gap | 8px |

Scale: 8px, 16px, 24px, 32px, 48px, 64px, 80px, 112px.

## Shape

| Element | Radius |
| --- | --- |
| Cards | 0px |
| Images | 0px |
| Buttons | 1440px |
| Tags | 1440px |
| Pills | 1440px |

## Shadows

- Default shadow: none.
- Rare dark-surface outline: `rgba(255, 255, 255, 0.2) 0px 0px 0px 1px`.

## Rhythm

- Use whitespace as the primary separator.
- Keep section gaps at 48px to 64px.
- Use 24px padding for accent cards and editorial information blocks.
- Reserve radius for interactive pills only.
