# Implementation Prompt

Use the Creative Giants style language for this UI.

Create an oversized editorial poster interface on a warm cream canvas. The page should feel like a production studio contact sheet: one huge light-weight headline, one strong image, quiet metadata, and almost invisible navigation chrome.

Core rules:

- Use `#fffef7` as the only page background.
- Use Ink Black `#000000` for primary text, icons, and black pill controls.
- Use Switzer if available; otherwise use Inter or Sohne with 300 and 400 weights.
- Set all major headlines at weight 300.
- Push hero or poster statements to 64px to 84px with tight tracking.
- Use body and UI controls at weight 400.
- Keep display statements to one or two lines.
- Use 1440px radius for buttons, menu controls, tags, and category pills.
- Use 0px radius for cards and images.
- Do not use shadows, floating panels, or rounded editorial cards.
- Use color only in small hits: magenta, teal, powder blue, candy pink, mint, navy, and signal yellow.

Recommended structure:

- Header with a small studio eyebrow, a circular mark, and a black pill Menu button.
- First viewport dominated by an enormous thin display headline.
- A full-width or full-bleed hero photograph with small lower-left metadata.
- Editorial project/news cards in a simple grid, image first and copy below.
- Occasional chromatic accent cards, never more than one in a row.
- Footer on the same cream canvas with a hairline divider.

Avoid:

- Heavy navigation bars.
- Rounded cards or rounded images.
- Gradient backgrounds.
- Bold display type.
- CTA colors other than black or transparent.
- Default browser blue links.
- Dense SaaS-like panels.

The result should feel like a coded art-book spread, not a marketing landing page.
