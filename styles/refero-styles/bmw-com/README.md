## Use This When

Use this style when an interface should feel like a premium product gallery instead of an app shell. It works best for automotive, hardware, luxury goods, architecture, industrial design, photography-heavy launches, and any screen where the product image should be treated as the main interface.

The key idea is restraint. The UI almost disappears: white canvas, near-black text, no accent color, no rounded surfaces, no card chrome, and no shadows. Product photography carries color, drama, and atmosphere.

## Implementation Snapshot

Build a single-column page with a plain white header, full-bleed product imagery, a centered ultra-light display heading, text-only links, and one dark footer band. Avoid decorative controls. If an element can be plain text, make it plain text.
