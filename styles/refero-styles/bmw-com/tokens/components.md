# Components

## Top Navigation Bar

- White background.
- No border, shadow, blur, or sticky treatment.
- Left side: brand mark plus tagline with a 12px gap.
- Right side: plain text links and a simple search icon.
- Text: 16px, weight 400, Carbon.

## Full-Bleed Hero Image

- Width: 100vw.
- Radius: 0px.
- Border: none.
- Shadow: none.
- Overlay UI: none.
- Best for closeup product photography.

## Display Section Heading

- Center aligned.
- 60px display size.
- 300 weight.
- Carbon color.
- One use per page or major section.
- Pair with a small centered text link beneath.

## Inline Action Link

- Text-only.
- 16px regular weight.
- Carbon color.
- Optional ASCII chevron or icon.
- No pill, border, filled background, or accent color.

## Dark Footer Band

- Full viewport width.
- Carbon background.
- White text.
- Centered 1200px inner container.
- Four plain text columns.
- 45px to 56px vertical padding.

## Language Switcher

- Plain horizontal text links.
- 24px spacing between items.
- No flags, badges, separators, or active pills.

## Footer Links

- White text on Carbon.
- 16px regular.
- No hover background.
- Use underline or slight weight shift if an interactive state is needed.
