# Amrit Palace

Source: Refero Styles

Reference site: https://amritpalace.com  
Captured: 2026-07-28

Amrit Palace is a spiced parchment gallery: warm beige canvas, dark restaurant photography, whisper-weight serif headings, sharp editorial geometry, and rare saffron punctuation. It feels like a curated dining room translated into a quiet web interface.

Use this folder as an AI implementation brief. The most useful files are:

- `DESIGN.md` for the full style interpretation.
- `implementation-prompt.md` for a copy-ready prompt to hand to an AI builder.
- `style.json` for structured metadata.
- `code/css-variables.css` for CSS custom properties and component recipes.
- `code/tailwind-v4.css` for Tailwind v4 theme tokens.
- `code/design-tokens.json` for machine-readable tokens.

Core cues:

- Canvas: `#d8cbb8` Parchment.
- Text: `#2c2c2c` Onyx Warm, never pure black.
- Accent: `#d49653` Saffron Glow, used only for stars, active states, and small punctuation.
- Borders: `#b6ab9c` Warm Stone hairlines.
- Display: TT Ramillas Variable, uppercase, weight 300, very tight tracking.
- UI/body: Satoshi 500, compact and uppercase for nav/buttons.
- Cards/images/sections: 0px radius.
- Buttons/tags/inputs: 3px radius.
- Layout: full-bleed photographic hero, then parchment editorial spreads with 120-160px section gaps.

This is best for restaurant sites, fine-dining menus, hospitality pages, venue portfolios, catering pages, and editorial food content.
