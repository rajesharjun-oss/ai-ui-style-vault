# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Density | compact |
| Max width | 1440px |
| Section gap | 120px to 160px |
| Card padding | 28px |
| Element gap | 12px to 16px |

## Scale

`4, 5, 6, 7, 8, 10, 12, 16, 17, 20, 24, 28, 32, 42, 92, 206`

## Radii

| Element | Value |
|---|---:|
| Cards | 0px |
| Sections | 0px |
| Image containers | 0px |
| Tags | 3px |
| Inputs | 3px |
| Buttons | 3px |

## Shape Rules

- Keep all cards and imagery sharp.
- Use 3px only for controls.
- Do not add card shadows.
- Use 1px dividers for structure.
