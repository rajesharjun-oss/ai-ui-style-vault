# Typography

## TT Ramillas Variable

- Token: `--font-tt-ramillas-variable`
- Fallback: Cormorant Garamond, Playfair Display, DM Serif Display
- Weight: 300
- Sizes: 22px, 26px, 50px, 65px, 69px, 115px
- Line height: 0.80, 0.85, 0.90, 1.00, 1.20
- Letter spacing: -0.04em to -0.03em at display sizes
- Role: all display and section headings.

## Satoshi

- Token: `--font-satoshi`
- Fallback: Inter, DM Sans, Manrope
- Weights: 500, 700
- Sizes: 12px, 13px, 14px, 15px, 42px, 199px
- Role: navigation, buttons, body copy, labels, captions, and the hero wordmark.

## Rules

- Never bold TT Ramillas.
- Use uppercase on large headings.
- Keep body text within 13px to 16px.
- Use Satoshi 700 for emphasis instead of bolding the serif.
