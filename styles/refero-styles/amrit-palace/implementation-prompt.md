# AI Implementation Prompt

Build a polished UI in the Amrit Palace style.

Use a warm restaurant editorial system: `#d8cbb8` Parchment canvas, `#2c2c2c` Onyx Warm text, `#b6ab9c` hairline rules, and one sparse saffron accent, `#d49653`, for star ratings, active states, and tiny punctuation. The page should feel like a fine-dining menu or gallery wall, not a card-heavy app.

Typography:

- Use TT Ramillas Variable-style serif for all display and section headings.
- Keep serif headings at weight 300.
- Use uppercase and tight negative tracking on all headings 50px and above.
- Use Satoshi-style sans for nav, buttons, body, labels, and captions.
- Do not use the serif for small body text.

Layout:

- Use full-bleed sections.
- Start with a dark photographic restaurant hero and transparent navigation.
- Transition into parchment content sections with 120px to 160px section gaps.
- Keep body copy left-aligned in editorial columns.
- Use horizontal testimonial rows, menu item spreads, and 1px divider rules.

Components:

- Ghost button: transparent fill, 1px border, 3px radius, uppercase Satoshi 14px/500.
- Text link: uppercase Satoshi, no border, underline on hover.
- Testimonial card: same Parchment background as canvas, 0px radius, no border, no shadow.
- Section divider: 1px Warm Stone line.
- Menu item: transparent container, sharp image, dish name, compact description.

Strict rules:

- Do not round cards or images.
- Do not add box shadows.
- Do not add a second accent color.
- Do not use pure black text.
- Do not use filled saffron buttons.
- Do not use CSS gradients for atmosphere; use photography.
