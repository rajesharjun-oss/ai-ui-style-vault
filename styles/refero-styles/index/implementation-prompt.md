# Implementation Prompt

Build a dark schematic interface in the Index style.

Use `#000000` as the page canvas and `#1c1c1c` as the lifted section or hero surface. The interface should look like a blueprint or wireframe drawn on a backlit drafting table. Structure every major section with 1px dashed containment lines. Avoid drop shadows; depth comes only from surface changes and border drawing.

Use Raveo Variable for all main typography. Headlines at 32px and above must use weight 1000, especially the 70px hero display with line-height 1.1 and letter-spacing around -0.04em. Use Raveo 400 for body text and Geist Mono 9px to 12px for uppercase eyebrow chips, version labels, and step markers.

Use only one chromatic accent: `#7089ba`. Reserve it for annotation details such as check icons, data nodes, wireframe line art, and tiny highlight washes. Do not use it for filled buttons, full backgrounds, or large text.

Use a 1200px max-width layout, 80px section gaps, 24px card padding, and 10px element gaps. Buttons and tags are fully pill-shaped at 100px radius. Feature tiles can use 20px radius and icon containers can use 50px radius. Actions should be outline pills with white borders and no fill.

Avoid bright colors, normal SaaS gradients, filled CTA buttons, heavy shadows, glossy cards, and decorative illustrations that are not wireframe-like.
