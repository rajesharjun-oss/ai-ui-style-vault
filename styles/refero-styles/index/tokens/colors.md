# Colors

## Core Palette

| Name | Hex | Use |
|------|-----|-----|
| Void | `#000000` | Page background, deep canvas, structural ink |
| Carbon | `#1c1c1c` | Elevated surfaces, hero spotlight, section fill |
| Graphite | `#4d4d4d` | Tertiary borders and disabled outlines |
| Steel | `#808080` | Secondary body text, muted borders, metadata |
| Ash | `#ababab` | Helper text, captions, tertiary text |
| Paper | `#ffffff` | Primary text, logo, active text, button borders |
| Periwinkle Annotation | `#7089ba` | Check icons, data nodes, wireframe line accents |

## Color Behavior

- Keep the interface achromatic except for periwinkle.
- Use periwinkle as annotation, never brand fill.
- Use Paper for strong strokes and text.
- Use Carbon to lift surfaces off Void.
- Avoid greens, reds, oranges, gradients, and colorful UI states.
