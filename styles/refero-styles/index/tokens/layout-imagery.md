# Layout And Imagery

## Layout

- Max width: 1200px.
- Section gap: 80px.
- Use dashed frames as the main page rhythm.
- Combine centered hero text with left-aligned feature panels.
- Keep body copy left-aligned outside the hero.

## Imagery

- Use geometric wireframe modules.
- Use data nodes, check icons, stippled dots, gears, boxes, funnels, and pipeline-like forms.
- Keep line work periwinkle or white.
- Avoid filled illustrations and gradients.

## Source

- Refero page: https://styles.refero.design/style/7f8c0c07-86e9-4b7c-a042-a7563b169143
- Reference site: https://index.app

## Direction

The page should feel like technical architecture drawn in real time. Every section is a measured frame; every color mark should feel like an annotation.
