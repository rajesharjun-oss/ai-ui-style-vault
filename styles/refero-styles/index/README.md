## Use This When

Use this style when a product should feel architectural, technical, minimal, and schematic. It works well for AI workflow tools, data products, automation software, technical landing pages, and products that need a wireframe-like dark interface with strong typographic presence.

The key behavior is extreme reduction: matte black surfaces, dashed containment lines, huge Raveo display type at weight 1000, outlined pill actions, mono eyebrow chips, and one muted periwinkle accent used only as annotation.

## Implementation Snapshot

Build a dark blueprint interface with Void canvas, Carbon section surfaces, dashed 1px containment, 70px Raveo 1000 headlines, Geist Mono micro labels, 100px pill outline buttons, 20px feature tiles, 50px icon containers, a 1200px max-width, 80px section gaps, and #7089ba used only for annotation accents.
