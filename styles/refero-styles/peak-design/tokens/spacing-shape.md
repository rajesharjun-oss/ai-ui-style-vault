# Spacing And Shape

## Spacing

| Purpose | Value |
| --- | --- |
| Density | comfortable |
| Base unit | 4px |
| Max width | 1440px |
| Section gap | 80px |
| Card padding | 24px |
| Element gap | 24px |

## Scale

`4px`, `8px`, `12px`, `16px`, `20px`, `24px`, `32px`, `40px`, `48px`, `64px`

## Radius

| Element | Value |
| --- | --- |
| Nav | 4px |
| Inputs | 4px |
| Buttons | 4px |
| Cards | 8px |
| Images | 8px |
| Rounded buttons | 32px |
| Badges | 9999px |
| Filter pills | 9999px |

## Shape Rules

- Use 4px for structural UI.
- Use 8px for product cards and images.
- Use 9999px only for badges and category filter pills.
- Do not soften the whole interface with large radii.
