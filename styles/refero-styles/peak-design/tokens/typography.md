# Typography

## Body Font

Name: `Geist`

Fallbacks: Inter, Sohne, Helvetica Neue, system-ui, sans-serif

Role: body copy, product titles, descriptions, form inputs, link text, footer content.

Rules:

- Use 16px and 1.5 line height for body copy.
- Use 400 for regular body.
- Use 600 or 700 for product names and inline emphasis.
- Do not use this as the main display voice when the serif is needed.

## Display Serif

Name: `Exposure-style serif`

Fallbacks: Playfair Display, GT Super, Tiempos Headline, Georgia, serif

Role: hero and section-display headlines.

Rules:

- Use only at 40px and above, preferably 48px and above.
- Keep weight at 400.
- Use tight negative tracking.
- Do not use for UI, body, labels, inputs, or product details.

## Condensed Label Font

Name: `Bryant-style condensed sans`

Fallbacks: Druk Wide, Inter Display Bold, Neue Haas Grotesk Display Bold, sans-serif

Role: navigation labels, category filters, button text, eyebrows, section tags, and secondary headings.

Rules:

- Always uppercase.
- Use 700 weight.
- Use positive tracking.
- Never use mixed case.

## Mono Font

Name: `Geist Mono`

Fallbacks: JetBrains Mono, IBM Plex Mono, monospace

Role: SKUs, product specs, and aligned technical micro-data.
