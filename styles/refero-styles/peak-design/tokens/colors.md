# Colors

## Accent

| Name | Value | Role |
| --- | --- | --- |
| Ember Red | `#cc2e39` | Rare sale, urgency, or brand punctuation accent. |

## Neutrals

| Name | Value | Role |
| --- | --- | --- |
| True Black | `#000000` | Maximum contrast blocks and strokes. |
| Obsidian | `#0c0c0c` | Deep editorial panels and image overlays. |
| Carbon Ink | `#1a211e` | Primary text, icons, dark panels, and key borders. |
| Slate | `#363537` | Navigation text and mid-weight borders. |
| Pewter | `#4e4e4e` | Supporting neutral and badge fills. |
| Graphite | `#606562` | Muted body text, metadata, and secondary nav. |
| Ash Border | `#cccfcd` | Hairline borders and input edges. |
| Mist | `#e0e0e0` | Dividers and structural separators. |
| Fog | `#eef1f0` | Subtle input and secondary surface fills. |
| Paper White | `#ffffff` | Canvas, product grids, cards, and light sections. |

## Rules

- Keep the system monochrome except for rare Ember Red.
- Use Ember Red once per viewport at most.
- Use Carbon Ink or Obsidian for dark panels.
- Use Paper White for product grids.
- Use hairlines and whitespace instead of colored containers.
