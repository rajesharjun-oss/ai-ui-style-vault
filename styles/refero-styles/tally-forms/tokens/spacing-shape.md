# Spacing And Shape

## Spacing

| Purpose | Value | Notes |
|---|---:|---|
| Density | comfortable | Simple maker-tool rhythm |
| Base unit | 8px | Main spacing rhythm |
| Max width | 1200px | Centered layout |
| Element gap | 8px | Form blocks and compact controls |
| Card padding | 24px | Template and feature cards |
| Section gap | 64px to 96px | Major vertical rhythm |
| Hero padding | 80px to 96px | First screen |
| Button padding | 8px 14px | Compact action controls |
| Input padding | 10px 12px | Form fields |

## Shape

| Element | Radius | Notes |
|---|---:|---|
| Buttons | 7px | Source signature UI radius |
| Inputs | 7px | Forms and editor controls |
| Tags | 7px | Status and category labels |
| Cards | 10px | Product cards and templates |
| Doodles | 9999px or organic | Decorative only |

## Elevation

Soft card shadow:

```css
0 1px 1px rgba(0, 0, 0, 0.12),
0 3px 9px rgba(61, 59, 53, 0.10)
```

Use light borders first, shadows second.
