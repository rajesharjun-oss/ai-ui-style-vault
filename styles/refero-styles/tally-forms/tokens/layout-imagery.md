# Layout And Imagery

## Layout Pattern

The core page structure is:

1. Simple header with logo, nav links, and Action Blue CTA.
2. Centered hero with large Inter headline and short support copy.
3. Product/editor preview card.
4. Doodle cluster around hero or empty state.
5. Template and feature card grid.
6. Response graph or analytics card.
7. Clean footer with muted links.

## Grid

- Use max width around 1200px.
- Use 64px to 96px between major sections.
- Use 24px padding inside major cards.
- Use 8px rhythm inside form blocks and controls.
- Stack cards cleanly on mobile.

## Imagery

Use:

- Product screenshots.
- Form builder UI.
- Template previews.
- Response charts.
- Simple hand-drawn doodles.
- Lightweight celebratory shapes.

Avoid:

- Glossy 3D art.
- Stock office photography.
- Dark hero scenes.
- Complex illustration systems.
- Corporate dashboard walls.
