# Colors

| Name | Value | Token | Role |
|---|---:|---|---|
| Graphite Ink | `#37352f` | `--color-graphite-ink` | Primary text, headings, strong labels, editor text |
| Paper | `#ffffff` | `--color-paper` | Main cards, form fields, editor surfaces |
| Warm Paper | `#f7f6f3` | `--color-warm-paper` | Alternate page canvas, muted sections, builder background |
| Line Gray | `#e9e9e7` | `--color-line-gray` | Borders, dividers, input outlines |
| Mist Gray | `#ebebec` | `--color-mist-gray` | Hover fills and inactive subtle surfaces |
| Soft Gray | `#787774` | `--color-soft-gray` | Secondary text, metadata, placeholders |
| Action Blue | `#0b6bcb` | `--color-action-blue` | Primary buttons, links, selected states, focus accents |
| Blue Tint | `#eaf3ff` | `--color-blue-tint` | Selected row or soft action background |
| Sun Yellow | `#ffeaa7` | `--color-sun-yellow` | Doodle fills, cheerful highlights, background shapes |
| Warm Orange | `#f5a623` | `--color-warm-orange` | Decorative highlight and expressive accent |
| Electric Magenta | `#f81ce5` | `--color-electric-magenta` | Hero expression, radial accents, doodles |
| Lime Pop | `#c3ff43` | `--color-lime-pop` | Expressive doodle accent |
| Soft Purple | `#8b5cf6` | `--color-soft-purple` | Gradient and doodle accent only |

## Guidance

- Use Action Blue for real UI actions.
- Use Graphite Ink for text rather than hard black.
- Use Paper and Warm Paper as the main surfaces.
- Use Magenta, Yellow, Lime, Purple, and Orange only for doodles and celebratory accents.
- Do not promote decorative colors into form controls.
