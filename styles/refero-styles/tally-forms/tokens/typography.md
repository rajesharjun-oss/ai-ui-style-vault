# Typography

Primary family: `"Inter", system-ui, sans-serif`

## Roles

| Role | Size | Weight | Line Height | Tracking | Use |
|---|---:|---:|---:|---:|---|
| Micro | 12px | 500 | 1.33 | 0 | Metadata, tiny labels |
| UI | 14px | 500 | 1.43 | 0 | Buttons, nav, tags |
| Body | 16px | 400 | 1.6 | 0 | Main body copy and form text |
| Body Large | 18px | 400 | 1.47 | -0.01em | Intro copy |
| Card Title | 24px | 600 | 1.25 | -0.02em | Template and feature cards |
| Section Heading | 42px | 700 | 1.06 | -0.04em | Product sections |
| Hero | 64px | 700 | 1.04 | -0.04em | First-screen headline |

## Guidance

- Use Inter everywhere.
- Keep body text readable and calm.
- Use heading weight and tight tracking for emphasis.
- Do not add decorative or handwritten fonts.
