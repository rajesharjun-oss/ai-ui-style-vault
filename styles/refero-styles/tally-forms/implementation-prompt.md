# AI Implementation Prompt

Build a polished, responsive interface in the Tally Forms style.

The product should feel like a clean digital notebook with playful doodles: warm paper surfaces, Inter typography, simple form-builder cards, compact 7px controls, blue primary actions, and bright magenta/yellow/lime shapes used only for decorative personality.

Core rules:

- Use Inter for all text.
- Use `#37352f` for primary text.
- Use `#ffffff` and `#f7f6f3` for cards and page surfaces.
- Use `#e9e9e7` for borders and dividers.
- Use `#787774` for secondary copy and placeholders.
- Use `#0b6bcb` for primary actions, links, selected states, and focus.
- Use magenta, yellow, lime, purple, and orange only for doodles, hero expression, and celebration.
- Use 7px radius for buttons, inputs, and tags.
- Use 10px radius for cards.
- Use soft borders and subtle shadows, not glossy depth.

Recommended layout:

1. Simple header with logo, text nav links, and blue CTA.
2. Centered hero with large Inter headline, short supporting copy, and a blue primary action.
3. Product/editor preview card showing form blocks or a form-building canvas.
4. Doodle cluster near the hero or empty state, not inside functional controls.
5. Template or feature grid using white cards, 10px radius, and subtle shadow.
6. Response/analytics card with blue chart accent and compact labels.
7. Clean footer with quiet text links.

Make it feel approachable, fast, friendly, and practical.
Avoid:

- Do not use decorative fonts.
- Do not make controls fully pill-shaped.
- Do not use Magenta, Lime, Yellow, Purple, or Orange as primary UI actions.
- Do not use heavy shadows or glassmorphism.
- Do not introduce extra saturated accent systems.
- Do not make the UI feel like a dense enterprise dashboard.
