# Tally Forms

Notebook doodles on warm paper: a friendly form-builder style with Notion-like typography, warm paper surfaces, compact 7px controls, soft shadows, blue action states, and playful magenta/yellow doodles used only for expression.

Use this style when you want a form builder, survey tool, creator utility, no-code product, onboarding flow, or light productivity app to feel approachable, handmade, and still highly functional.

## Files

- `source.md`: Source URL, reference site, capture notes, and scope.
- `DESIGN.md`: Human-readable design breakdown.
- `implementation-prompt.md`: Prompt for an AI builder to implement the style.
- `style.json`: Structured design metadata.
- `tokens/`: Markdown token notes by category.
- `code/`: CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md`: Placeholder for future manual screenshots.

## Quick Use

1. Use Inter everywhere.
2. Use `Graphite Ink` for text and `Paper`/`Warm Paper` for surfaces.
3. Use `Action Blue` for primary actions, links, and selected states.
4. Use 7px radius for buttons, inputs, and tags.
5. Use 10px radius for cards.
6. Keep doodle colors and gradients decorative, not functional.
