# Layout And Imagery

## Layout

- Use a centered 1200px content track.
- Keep sections full-width and dark.
- Separate major sections with 96px gaps and hairline dividers.
- Hero is text-led, not image-led.
- Use square bordered panels for service and feature grids.
- Use partner wordmark strips without cards.
- Use vertical dividers to create editorial grid rhythm.

## Imagery

- Use abstract technical motifs and thin-line icons.
- Use compass-like marks in Compass Gold.
- Use schematic UI fragments sparingly.
- Avoid stock photography.
- Avoid large screenshots.
- Avoid decorative gradients and light blobs.

## Composition Rules

- Let typography, borders, and spacing carry the design.
- Use white pill CTAs as the main interaction signal.
- Use gold and green as micro-accents only.
- Keep panels flat and sharp.
- Prefer structured rows and grids over decorative cards.
