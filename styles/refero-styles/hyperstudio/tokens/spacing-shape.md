# Spacing And Shape

## Core Values

| Purpose | Value |
|---------|-------|
| Density | compact |
| Base unit | 4px |
| Max width | 1200px |
| Section gap | 96px |
| Card padding | 24px |
| Element gap | 8px |
| Hero vertical padding | 144px |
| Grid panel padding | 36-48px |

## Radius

| Element | Value | Token |
|---------|-------|-------|
| Cards | 0px | `--radius-cards` |
| Grid panels | 0px | `--radius-grid-panels` |
| Nav items | 8px | `--radius-nav-items` |
| Buttons | 9999px | `--radius-buttons` |

## Shape Rules

- Cards and grid panels stay sharp.
- Buttons and paired inputs use pill radius.
- Nav items may use 8px radius for small hover targets.
- Do not apply rounded card styling.
