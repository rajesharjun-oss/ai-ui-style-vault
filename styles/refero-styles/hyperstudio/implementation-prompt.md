# Implementation Prompt - Hyperstudio Style

Build an original UI using the Hyperstudio Refero style as visual direction.

Create a dark editorial-tech studio interface: near-black canvas, white typography, Faint Line grid borders, square service panels, white pill CTAs, one Compass Gold icon accent, and tiny Pulse Green status dots. The result should feel precise, sober, and studio-grade, not like a flashy AI landing page.

## Must Preserve

- Obsidian `#03050c` as the main background.
- Paper `#ffffff` as the primary text and CTA fill.
- White alpha borders such as `#ffffff2b`.
- Aeonik-style type with weight 400 for headings and body.
- Hero display around 67px with line-height 1.01 and tight negative tracking.
- 0px radius for cards and grid panels.
- 9999px radius for buttons and pill inputs.
- Compass Gold `#b49c46` only for icons and tiny marks.
- Pulse Green `#98ff38` only for small status dots.
- Flat surfaces with no shadows or gradients.
- Hairline grid structure for section rhythm.

## Avoid

- Copying Hyperstudio logos, screenshots, page copy, exact layouts, or proprietary branded assets.
- Gradients, glow effects, glassmorphism, or colorful AI blobs.
- Rounded cards.
- Gold CTA fills.
- Green as a broad brand accent.
- Extra accent colors.
- Image-heavy marketing sections.
- Heavy borders or drop shadows.

## Component Direction

Lead with a text-first hero, compact white pill CTA, and optional status dot. Structure the page with square bordered panels, service rows, and wordmark strips. Let borders, spacing, and typography create the design, not decorative imagery.
