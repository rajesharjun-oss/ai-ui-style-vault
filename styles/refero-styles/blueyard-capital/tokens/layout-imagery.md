# Layout And Imagery

## Layout

- Page model: full-bleed sections with centered or left-aligned content.
- Max width: about 1200px.
- Hero: centered headline in the upper third.
- Artwork: large 3D object in the lower half, bleeding off the bottom edge.
- Navigation: tiny stacked wordmark top-left and square hamburger top-right.
- Section rhythm: white canvas alternating with Ash Veil or Polar Blue bands.
- Vertical padding: about 90px per section.
- Card grids: one, two, or three columns with 5px to 12px gaps.

## Imagery

Use:

- Rendered spheres.
- Planetary forms.
- Particle-based celestial objects.
- Abstract 3D forms.
- Soft apricot-to-white atmospheric washes.

Avoid:

- Photography.
- Product screenshots.
- Framed hero images.
- Decorative icon packs.
- Colorful gradients inside UI components.

## Composition Notes

The hero artwork should behave like a printed cover plate. It can be cropped by the viewport and should not need a caption. The page should feel calm and spacious even when the artwork is large.
