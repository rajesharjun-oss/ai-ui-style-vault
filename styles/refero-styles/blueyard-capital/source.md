## Capture Notes

This bundle paraphrases the Refero style reference into implementation notes for AI-assisted UI building. It preserves the system intent, color roles, typography behavior, spacing, component recipes, layout rhythm, and visual constraints without copying the source text wholesale.

## What To Preserve

- Pure white canvas with warm near-black typography and borders.
- Instrument Sans as the only typeface.
- Aggressively tight letter spacing.
- Sharp 0px radius on every UI element.
- Pale chromatic tints used only for cards, borders, or surface bands.
- No shadows, glows, or conventional elevation.
- A large uncaptioned 3D artwork as the hero anchor.
