## Use This When

Use this style for premium hardware launches, cinematic product pages, luxury device showcases, sports-tech products, watch or wearable pages, and marketing experiences where a single product object should dominate the screen.

## Core Idea

Apple Watch Ultra 3 is a dark showroom system. A titanium object floats on pure black, SF Pro type carries almost all hierarchy, and one filled Apple Blue button is the only saturated action color. The page alternates black feature stages with white detail bands, using 28px photo cards, 36px buttons, and 980px nav pills.
