# Layout And Imagery

## Layout Model

- Center the main content in a 1200px max-width container.
- Use full-bleed sections that alternate between Canvas White, Cream Wash, Charcoal, and Midnight Indigo.
- Hero is stacked and centered: headline, support copy, email capture, and product/video proof.
- Feature sections use 3-4 column grids with flat pastel cards.
- Testimonial sections use dark full-bleed panels with compact quote cards.
- Footer is dark, centered, and CTA-led.
- Navigation is sticky with a frosted/blurred transition on scroll.

## Imagery

- Prefer hand-drawn line illustration, especially loose rocket or spaceship motifs.
- Use warm radial gradient washes behind hero content.
- Use dark-framed video/product screenshot containers.
- Use monochrome customer logo grids on white.
- Keep photography minimal; the system relies more on illustration, gradient atmosphere, product UI, and logos.

## Avoid

- Heavy decorative shadows.
- Photo-heavy hero sections.
- Pastels as confetti with no information role.
- Rigid enterprise dashboard density.
- Dark surfaces without white/Ash text hierarchy.
