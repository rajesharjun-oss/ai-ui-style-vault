# Colors

## Brand

| Name | Hex | Token | Usage |
|---|---:|---|---|
| Phoenix Orange | `#e8400d` | `--color-phoenix-orange` | Brand accent, hero gradient origin, marketing highlights |
| Midnight Indigo | `#10054d` | `--color-midnight-indigo` | Deep brand surfaces and high-contrast feature areas |

## Neutrals

| Name | Hex | Token | Usage |
|---|---:|---|---|
| Ink | `#111111` | `--color-ink` | Text, headings, primary button fill |
| Canvas White | `#ffffff` | `--color-canvas-white` | Page background, cards, reversed text |
| Cream Wash | `#f6f5f3` | `--color-cream-wash` | Soft sections and secondary surfaces |
| Charcoal | `#272625` | `--color-charcoal` | Dark testimonial cards and footer sections |
| Ash | `#6d6c6b` | `--color-ash` | Muted copy, labels, helper text |
| Stone | `#b1b1af` | `--color-stone` | Dividers, hairlines, placeholders |
| Pearl | `#ecebea` | `--color-pearl` | Subtle button fills and hover states |
| Indigo Deep | `#2e2460` | `--color-indigo-deep` | Dark forms or inputs on indigo sections |

| Canary Yellow | `#ffef99` | `--color-canary-yellow` | Category card surface |
| Soft Violet | `#e2ddfd` | `--color-soft-violet` | Category card surface |
| Aqua | `#99fff9` | `--color-aqua` | Gradient endpoint and hero wash |

## Behavior

- Use Canvas White and Cream Wash as the page base.
- Use Phoenix Orange sparingly for brand and hero moments.
- Use pastel colors as solid category fills only.
- Use Midnight Indigo or Charcoal for full-bleed dark contrast.
- Avoid pure black; use Ink.
