# Spacing And Shape

## Spacing

| Purpose | Value | Notes |
|---|---:|---|
| Page max width | 1200px | Centered main container |
| Section gap | 80-120px | Major vertical rhythm |
| Card padding | 20px | Feature cards, pastel tiles, logo cards |
| Element gap | 8-12px | Button rows, stacked labels, compact UI |
| Input height | 48px | Email capture field |

## Radius

| Element | Value | Notes |
|---|---:|---|
| Buttons | 8px | Primary, neutral, and ghost buttons |
| Cards | 12px | Feature, testimonial, logo, pastel tiles |
| Inputs | 12px | Email capture and dark form fields |
| Badges | 9999px | Pills and small labels |
| Small details | 4px | Tiny UI details only |

## Depth

- Pastel category cards are flat.
- Standard white cards should use hairlines or no shadow.
- Featured cards may use a very soft ambient shadow.
- Dark section contrast should do more work than elevation.
