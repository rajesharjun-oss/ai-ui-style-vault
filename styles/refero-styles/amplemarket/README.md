# Amplemarket

AI-ready Refero style bundle for Amplemarket.

- Source: https://styles.refero.design/style/db451eca-8de6-43a9-a5d5-35271befdffd
- Reference site: https://www.amplemarket.com
- Captured: 2026-07-28
- Theme: light
- Mood: sunlit workspace with scattered confetti
- Industry: SaaS, sales automation, AI, productivity, outbound operations

## Use This Style For

- Sales, AI, productivity, and workflow SaaS sites that should feel friendly rather than corporate
- Product pages that need a white/cream editorial canvas with flat pastel taxonomy cards
- Interfaces where strong black typography, compact radii, and one orange brand accent should carry the identity
- Landing pages that mix playful illustration, video/product frames, customer logo grids, and dark testimonial bands

## Files

- `source.md` records the source URL and capture context.
- `DESIGN.md` is the main human-readable design reference.
- `implementation-prompt.md` is a direct prompt for an AI coding agent.
- `style.json` is a structured summary for indexing and retrieval.
- `tokens/` contains focused notes for colors, type, spacing, components, guidelines, layout, and imagery.
- `code/` contains CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` reserves the screenshot slot for manual or automated captures.

## Core Signature

Amplemarket is a light, approachable SaaS system: Canvas White, Cream Wash, Ink text, Phoenix Orange brand moments, Midnight Indigo and Charcoal dark bands, Labil Grotesk Variable throughout, 8px buttons, 12px cards, flat pastel category tiles, and almost no decorative elevation.
