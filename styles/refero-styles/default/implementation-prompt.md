# Implementation Prompt

Build a polished dark infrastructure UI in the Default style.

Use a near-black canvas (`#0b0c0e`) with Graphite cards (`#131416`) and Charcoal secondary surfaces (`#1f1f21`). Use Inter variable for all display, body, labels, buttons, and UI chrome. Enable `font-feature-settings: "ss01" 1, "ss03" 1`.

Headlines must stay weight 400 at 32px and above. Use 52px to 64px display text with tight tracking. Body and UI copy should be compact, with 13px to 18px text and negative letter spacing where appropriate.

Use a 1080px max-width container, 96px section gaps, 28px card padding, and 8px element gaps. Cards use 12px radius; buttons and pills use 10px radius. Edges are 0.5px hairlines with low-alpha white or dark strokes. Avoid heavy shadows.

Primary CTAs use Bone (`#f2f2f2`) fill with Ink (`#333333`) text. Never use blue as the primary CTA fill. Signal Blue (`#3b82f6`) is reserved for links, active nav states, icons, selected card borders, and focus affordances. Green and red are supporting accents only.

Design should feel like mission control: product panels, workflow node cards, dark tables, compact nav, subtle separators, and restrained active states. Avoid generic SaaS blue buttons, oversized marketing sections, glossy gradients, and bold display type.
