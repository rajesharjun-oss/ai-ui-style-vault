## Use This When

Use this style when a product should feel technical, compact, calm, and infrastructure-grade. It works well for developer tools, workflow automation, internal systems, observability, AI operations, cloud products, and control-room dashboards that need density without visual noise.

The key behavior is restraint inside darkness: near-black canvas, subtle surface steps, 0.5px hairlines, light Inter headlines at weight 400, off-white primary CTA pills, and Signal Blue reserved for links, active states, icons, and focus rings.
