# Colors

## Neutrals

| Name | Hex | Use |
|------|-----|-----|
| Void | `#0b0c0e` | Deepest page canvas and terminal background |
| Graphite | `#131416` | Primary card surface, panels, table rows |
| Charcoal | `#1f1f21` | Secondary surface, borders, rails, dividers |
| Ink | `#333333` | CTA text and subdued labels |
| Smoke | `#3c3d3e` | Button borders and separators |
| Steel | `#71717a` | Muted body text and helper text |
| Fog | `#858687` | Secondary text and inactive nav |
| Ash | `#9d9e9f` | Placeholder and disabled text |
| Chalk | `#cececf` | Secondary table and body text |
| Bone | `#f2f2f2` | Primary CTA fill |
| Snow | `#ffffff` | Primary headings, active text, icon fills |

## Brand And Signal

| Name | Hex | Use |
|------|-----|-----|

| Arc Blue | `#60a5fa` | Informational text and workflow node accents |
| Ring Blue | `#93c5fd` | Focus rings and selection outlines |
| Mint | `#4ade80` | Green outline accents and focused edges |
| Fern | `#22c55e` | Green wash and soft supporting emphasis |
| Coral | `#f87171` | Red supporting accent |
| Ember | `#ea580c` | Orange chip in mockups |
| Iris | `#314ef0` | Brand chip tint in screenshots |

## Color Behavior

- Use Bone for primary CTA fill.
- Do not use blue for large CTA backgrounds.
- Keep Signal Blue for links, active states, icons, and rings.
- Keep the page almost entirely neutral.
- Use green/red/orange only as small signal marks.
