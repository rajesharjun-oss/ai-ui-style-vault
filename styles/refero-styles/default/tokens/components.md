# Components

## Primary Pill Button

- Background: `#f2f2f2`.
- Text: `#333333`.
- Radius: 10px.
- Compact height and padding.
- Do not use blue or green for primary CTA fill.

## Secondary Button

- Transparent or Graphite surface.
- Border: 0.5px `#3c3d3e` or low-alpha white.
- Text: Snow, Chalk, or Fog depending on emphasis.
- Radius: 10px.

## Card

- Background: `#131416`.
- Border: 0.5px solid low-alpha white or Charcoal.
- Radius: 12px.
- Padding: 28px.
- Avoid heavy drop shadows.

## Workflow Node Card

- Background: `#131416`.
- Radius: 8.77px.
- Padding: 12px.
- Border: 0.5px solid rgba(255,255,255,0.08).
- Title: 12px Inter 500 in Snow.
- Description: 10px Inter 400 in Fog.

## Navigation Header

- Height: 72px.
- Transparent dark background.
- Backdrop blur around 6px.
- Bottom border: 0.5px rgba(255,255,255,0.07).
- Nav items: 14px Inter 400.
- Right side can include login and a secondary pill.

## Active States

- Use Signal Blue for active nav, selected borders, links, and icon fills.
- Use Ring Blue for focus outlines.
- Use hover states as subtle surface lifts, not bright fills.
