# Layout And Imagery

## Layout

- Max width: 1080px.
- Section gap: 96px.
- Compact product-first density.
- Use dark card grids, workflow diagrams, tables, and panels.
- Keep navigation thin, calm, and sticky or fixed if needed.

## Imagery

- Use product screenshots and mockups.
- Show workflow nodes, automations, tables, and operational panels.
- Add thin blue rings, active borders, and icon fills.
- Keep imagery matte and subdued.

## Source

- Refero page: https://styles.refero.design/style/eeeb6ac9-fc07-4965-935a-e1989ed831f1
- Reference site: https://www.default.com

## Direction

The page should feel like a technical command center. The experience should be dense but calm, with the product doing the visual work.
