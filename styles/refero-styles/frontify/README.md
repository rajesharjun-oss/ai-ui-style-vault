# Frontify

AI-ready Refero style bundle for Frontify.

- Source: https://styles.refero.design/style/8f42603d-7ff9-446e-99a3-6bdd1f388ae5
- Reference site: https://www.frontify.com
- Captured: 2026-07-28
- Theme: light
- Mood: warm atelier with orange punctuation
- Industry: brand management, creative operations, design systems, DAM, SaaS

## Use This Style For

- Brand-management, digital-asset, design-system, and creative-operations products
- Editorial SaaS pages that need a premium museum-catalog calm
- Interfaces where cream, white, ink, and one orange accent should do nearly all the work
- Product storytelling that alternates dark editorial hero moments with quiet cream sections

## Files

- `source.md` records the source URL and capture context.
- `DESIGN.md` is the main human-readable design reference.
- `implementation-prompt.md` is a direct prompt for an AI coding agent.
- `style.json` is a structured summary for indexing and retrieval.
- `tokens/` contains focused notes for colors, type, spacing, components, guidelines, layout, and imagery.
- `code/` contains CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` reserves the screenshot slot for manual or automated captures.

## Core Signature

Frontify is a warm editorial SaaS system: cream canvas, white cards, ink hairlines, dark teal hero sections, Cranny display type, ABC Diatype UI text, 8px card radius, 24-40px pill buttons, no shadows, and Signal Orange used only as small functional punctuation.
