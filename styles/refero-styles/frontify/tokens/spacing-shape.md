# Spacing And Shape

## Spacing

| Purpose | Value | Notes |
|---|---:|---|
| Density | comfortable | Editorial breathing room |
| Base unit | 8px | Every layout value should snap to this |
| Max width | 1200px | Centered page container |
| Section gap | 80px | Major rhythm between content groups |
| Card padding | 32px | Product cards and panels |
| Element gap | 8-16px | UI controls, tag rows, breadcrumbs |

## Radius

| Element | Value | Notes |
|---|---:|---|
| Cards | 8px | Flat, precise, not bubbly |
| Images | 18px | Editorial media softness |
| Nav pills | 32px | Header controls |
| Large buttons | 40px | Primary hero CTAs |
| Small buttons | 24px | Compact action pills |
| Tags | 9999px | Metadata chips |

## Border And Depth

- Use 1px borders with Ink or Pale Stone.
- Use neutral surface shifts instead of shadows.
- Keep card corners at 8px; do not round the whole interface into soft capsules.
