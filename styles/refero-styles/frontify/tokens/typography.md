# Typography

## Families

| Role | Preferred Font | Fallbacks | Notes |
|---|---|---|---|
| Display | Cranny | Fraunces, Playfair Display, DM Serif Display | High-contrast serif for hero and section headings |
| UI and body | ABC Diatype | Inter, Sohne, GT America, Arial | Navigation, buttons, forms, labels, body copy |
| Secondary body | Satoshi | DM Sans, Manrope, Arial | Optional support for compact body moments |
| Heavy display | Cabinetgrotesk | Cabinet Grotesk, General Sans, Arial | Use sparingly for numerals or strong emphasis |

## Rules

- Use Cranny only for display moments.
- Use ABC Diatype for all interface grammar.
- Keep UI text slightly tracked out.
- Keep long body copy left-aligned.
- Avoid over-weighted serif headlines; the mood comes from light contrast, not boldness.
