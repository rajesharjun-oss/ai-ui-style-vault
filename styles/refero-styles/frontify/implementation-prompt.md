# Implementation Prompt

Build a polished, responsive interface in the Frontify Refero style.

Use a warm editorial SaaS visual system: Warm Parchment `#f0f0eb` page canvas, Gallery White `#ffffff` cards, Ink `#111110` text and hairlines, Deep Teal `#042a2b` for full-bleed hero/editorial sections, and Signal Orange `#ff3b00` only for tiny functional punctuation.

Typography must feel like a premium brand-management site. Use `Cranny` or a high-contrast serif fallback for display headlines, weight 300-400. Use `ABC Diatype` or an Inter-like fallback for body, nav, buttons, labels, breadcrumbs, and product UI. Add slight positive tracking to UI text.

Layout rules:

- Center content in a 1200px max-width container.
- Use 80px section gaps and generous cream space.
- Use 8px card radius, 18px image radius, 24-40px pill button radius.
- Use 1px Ink or Pale Stone borders instead of shadows.
- Start with a dark teal hero with a large serif headline, short sans support copy, and two pill buttons.
- Follow with logo strips, feature heading blocks, asset-grid cards, upload/drop-zone panels, and media-library previews.

Component rules:

- Buttons are pill-like but precise, not bubbly.
- Ghost buttons use transparent fill and hairline borders.
- Product/media cards are white, flat, and bordered.
- Asset thumbnails can overlap or rotate by 2-3 degrees.
- Orange should be a dot, icon, small active state, or tiny CTA control, never a full section.

Do not use heavy shadows, glassmorphism as a main system, bright multi-color palettes, blue/purple SaaS gradients, oversized rounded cards, or Cranny for body text.
