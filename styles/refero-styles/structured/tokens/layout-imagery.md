# Layout And Imagery

## Layout

- Use full-bleed sections with no ordinary max-width content container.
- Hero uses a tiny centered type cluster above a huge cropped wordmark.
- Middle section can use a full-bleed painting with one centered notched product card.
- Feature section uses Ink background, centered 94px serif heading, and a 3-column circular vignette grid.
- Header is minimal: logo mark left, one text link right.
- Section rhythm alternates light, dark, light.

## Imagery

- Use Renaissance and Baroque oil-painting imagery.
- Use full-bleed painting panels and circular painting crops.
- Avoid modern photography, stock imagery, product screenshots, and abstract graphics.
- Let imagery be atmospheric rather than explanatory.
- Keep full-bleed images unframed and unrounded.

## Composition Rules

- Use hard transitions between Putty and Ink.
- Use huge cropped typography as visual material.
- Use one black pill CTA per viewport.
- Use hexagons and circles as the main geometric motifs.
- Keep decorative load inside typography and paintings.
