# Implementation Prompt - Structured Style

Build an original UI using the Structured Refero style as visual direction.

Create a Renaissance-gallery finance interface on warm putty paper. Use a giant serif wordmark, stark black feature rooms, compact black pill CTAs, classical painting imagery, circular vignettes, and hexagonal indicators. The result should feel like a premium museum folio for a financial product, not a standard crypto dashboard.

## Must Preserve

- Putty `#c4c3b6` as the dominant light canvas.
- Ink `#000000` for dark rooms, text, borders, and filled CTAs.
- Bone `#e7e5e4` for elevated light surfaces.
- Paper `#ffffff` only for reverse text and rare white marks.
- Davinci-style serif display at 52px and above.
- 374px cropped hero wordmark with 0.84 line-height and tight tracking.
- Helvetica Now style utility type for nav, labels, stats, and buttons.
- Compact pill CTA geometry: 28.8px radius and 9px 17px padding.
- Classical painting imagery only.
- Circular crops for feature imagery.
- Hexagonal indicators as secondary geometry.
- Flat surfaces with no shadows or gradients.
- Hard alternation between Putty and Ink sections.

## Avoid

- Copying Structured logos, exact artwork, financial claims, page copy, screenshots, or proprietary layouts.
- Saturated accent colors.
- Modern SaaS gradients, glass effects, shadows, or glowing cards.
- Stock photography, product screenshots, or generic illustrations.
- Serif body text below 34px.
- Heavy nav bars or many menu items.
- Standard 4px, 8px, or 12px component radius where the system specifies 9px or 28.8px.

## Component Direction

Lead with a small functional center cluster above a huge cropped serif wordmark. Follow with a full-bleed classical painting section and a centered black notched product card. Use a black feature section with circular painting vignettes and hexagonal indicators.
