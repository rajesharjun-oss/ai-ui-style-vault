# Component Recipes

## Primary CTA Button

- Background: `#4e9ad9`.
- Text: `#ffffff`.
- Font: Figtree, 16px, weight 600.
- Padding: 12px 20px.
- Radius: 24px.
- Border: none.
- Hover: optional blue-tinted shadow.

## Ghost / Outlined Button

- Background: transparent.
- Text: `#0b3658`.
- Radius: 24px.
- Padding: 8px 16px.
- Font: Figtree, weight 600.
- Hover: `#e6f1fa` wash.

## Text Link

- Color: `#4e9ad9` or `#0b3658` depending on context.
- Weight: 400-600.
- Underline: 1px `#dde7ee` or transparent.
- No background.

## Hero Search Input

- Background: `#ffffff`.
- Border: `1px solid #dde7ee`.
- Radius: 24px.
- Padding: 16px 20px.
- Font: Figtree 16px, weight 400.
- Left icon: `#486984`.
- Right shortcut chip: `#e6f1fa`, 5px radius.
- Focus shadow: `0px 4px 32px rgba(11, 54, 88, 0.08)`.

## Toggle Switch

- Pill container with two labels.
- Active text: `#0b3658`, weight 700.
- Inactive text: `#486984`, weight 400.
- Active fill: `#e6f1fa`.
- Radius: 24px container, 20px segment.

## Company Card

- Background: `#ffffff`.
- Radius: 20px.
- Shadow: `0px 12px 48px rgba(11, 54, 88, 0.08)`.
- Padding: 20px.
- Top image: full width, 20px radius.
- Logo: 40px square.
- Name: Figtree 16px, weight 700, `#0b3658`.
- Meta row: Figtree 14px, `#486984`.
- Status badge: `#e6f1fa` background, `#4e9ad9` text, 5px radius.
- Response text: `#42b3b1`, weight 600.

## Dark CTA Banner

- Full-bleed background: `#0b3658`.
- Headline: 48-56px, Figtree 800, white.
- Subtext: 18px, `#dde7ee`.
- CTA: Signal Blue fill, white text, 24px radius.

## Filter Chip

- Background: white.
- Border: `1px solid #dde7ee`.
- Radius: 8px.
- Padding: 8px 16px.
- Font: Figtree 14px, weight 600, `#0b3658`.

## Footer Link Column
