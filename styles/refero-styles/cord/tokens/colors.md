# Color Tokens

## Palette

| Token | Value | Role |
|---|---:|---|
| Midnight Harbor | `#0b3658` | Primary text, headings, logo grounding, dark CTA banner |
| Signal Blue | `#4e9ad9` | Primary action, logo wordmark, active nav, selected states |
| Slate Channel | `#486984` | Secondary text, muted icons, outlined links |
| Pale Steel | `#688dac` | Tertiary text and meta labels |
| Sea Fog | `#dde7ee` | Card borders, image borders, dividers, underlines |
| Ice Tint | `#e6f1fa` | Hover wash, active toggle fill, status badges, tinted input surfaces |
| Light Mist | `#c8d8e4` | Disabled or secondary button fill |
| Canvas White | `#ffffff` | Page background, card surface, button text |
| Active Teal | `#42b3b1` | Presence, live, and response-status signals |

## Surface Stack

| Level | Name | Value | Purpose |
|---|---|---:|---|
| 0 | Canvas | `#ffffff` | Open white page background |
| 1 | Ice Tint | `#e6f1fa` | Tinted grouping wash and active fill |
| 2 | Card | `#ffffff` | Company cards, search field, chips |
| 3 | Dark Banner | `#0b3658` | Full-bleed CTA section |

## Usage

- Use `#0b3658` instead of black.
- Use `#4e9ad9` for primary actions and active states.
- Use `#dde7ee` for borders and hairlines.
- Use `#e6f1fa` as a gentle surface wash.
- Use `#42b3b1` only for status or presence.

## Avoid

- Do not add a second accent.
- Do not use Signal Blue for large headings or body copy.
- Do not use black text.
- Do not turn Active Teal into a brand accent.
