## Style Summary

cord.com is an airy recruiting-marketplace style: white canvas, navy-first typography, one bright signal-blue action color, Figtree heavy display type, pill inputs, rounded company cards, and photo-led job discovery. The palette feels maritime and calm, with a single full-bleed navy CTA banner as the main contrast moment.

Use this style when an AI needs a polished job board, recruiting marketplace, startup hiring grid, talent search page, or soft SaaS landing page with human company photography.

## What To Borrow

- Midnight Harbor `#0b3658` for all primary text instead of pure black.
- Signal Blue `#4e9ad9` only for logo, primary CTA, and active states.
- Figtree as the single type family, with 800-weight stamped hero headlines.
- 100px hero display type with tight tracking.
- White canvas and wide centered hero flow.
- 24px radius search inputs and buttons.
- 20px radius company cards and images.
- Blue-tinted shadows using rgba values based on `#0b3658`.
- Photo-led company cards with authentic team imagery.
- Dark navy CTA banner near the page end.

## Avoid

- Adding a second brand accent.
- Using pure black for body or heading text.
- Using sharp card or button corners.
- Adding generic gray shadows.
- Using light display weights.
- Making Signal Blue a body-text or headline color.
- Repeating the dark CTA banner throughout the page.
