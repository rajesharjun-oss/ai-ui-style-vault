## What To Preserve

Cosmos is a visual discovery system where the interface behaves like a quiet gallery wall. The root canvas is warm linen, the UI chrome is black, white, and warm gray, and the only strong color should come from the images users collect. Typography is the main brand cue: a single soft serif-influenced custom face, set light and tight at display sizes.

## What To Avoid Copying

Do not copy the original logo, exact collage, product screenshots, marketing copy, or gallery layout. Use the tokens and rules to create original galleries, moodboards, creative collections, image feeds, editorial pages, or visual search tools.

## Build Context

This bundle is meant for AI-assisted UI implementation. Use the markdown files for design intent, and use the `code/` files for direct token import when building with CSS variables or Tailwind v4.
