# Implementation Prompt

Create an original light visual discovery or moodboard interface inspired by the Cosmos Refero style.

Use a warm linen root background `#f7f5f3`, ink text `#0d0d0d`, white paper cards `#ffffff`, muted body text `#6e6a69`, and helper text `#9a9796`. Do not introduce CTA accent colors. The only strong color should come from user images.

Use a single serif-influenced display family such as cosmosOracle, GT Super, Fraunces, Cormorant Garamond, or Georgia. Use weight 350 for large hero/display type, 400 for body, and 500 for labels/buttons. Keep display tracking tight: about `-3.7px` at 74px, `-2.32px` at 58px, and near zero at small sizes.

Build these elements:

- A top floating pill nav with white fill, faint black border, logo mark, links, centered search, theme toggle, and auth actions.
- A centered hero with a small uppercase eyebrow, a 74px whisper-weight serif headline, and a paired button row.
- Scattered image tiles around the hero, sized roughly 60px to 140px, using 12px radius and small rotations.
- A 16px-radius wide media/video container with photographic poster imagery.
- A 3-column image-first feature grid with 24px gaps and 18px labels.
- Optional AI content overlay card with white surface, 12px radius, small text, and neutral action buttons.

Do not copy Cosmos brand assets, exact screenshots, page copy, or proprietary layouts. Generate a new gallery/feed/moodboard screen that borrows only the mood, token relationships, and component logic.
