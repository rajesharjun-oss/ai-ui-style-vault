# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Density | `comfortable` |
| Base unit | `4px` |
| Max width | `1280px` |
| Section gap | `80px` |
| Card padding | `16px` |
| Element gap | `24px` |

## Scale

`4px`, `8px`, `16px`, `20px`, `24px`, `32px`, `40px`, `48px`, `72px`, `200px`

## Radius

| Element | Value |
|---|---:|
| Cards | `16px` |
| Inputs | `16px` |
| Buttons | `16px` |
| Image tiles | `12px` |
| Video container | `16px` |
| Floating nav pill | `9999px` |

## Elevation

- Normal cards: no shadow.
- Buttons: no shadow.
- Nav pill: no shadow.
- Depth comes from surface contrast and image placement.
- Use Paper White over Linen Canvas rather than shadow stacks.
