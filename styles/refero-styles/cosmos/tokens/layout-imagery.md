# Layout And Imagery

## Layout Patterns

- Top floating pill nav with one navigation surface.
- Centered hero stack with eyebrow, display headline, and button pair.
- Floating image tiles around the hero, positioned free-form.
- Wide media/video block below the hero.
- Strict 3-column feature grid with 24px gaps.
- Generous 80px or larger vertical rhythm between major sections.
- Content well around 1280px.

## Imagery

- Imagery is the primary product material, not decoration.
- Use curated photos, clippings, film stills, creative references, and saved media.
- Floating hero tiles should be varied in size and subject.
- Feature cards should lead with edge-to-edge imagery.
- Use minimal line icons only when needed: search, play, theme, social.
- Avoid illustration systems, decorative gradients, 3D renders, and colored UI motifs.

## Responsive Notes

- On mobile, reduce hero display size and keep tile count lower.
- Keep the nav pill usable; collapse links if needed but preserve the single-pill idea.
- Stack feature cards vertically below tablet width.
- Avoid cramming too many tiny floating images around mobile hero text.
