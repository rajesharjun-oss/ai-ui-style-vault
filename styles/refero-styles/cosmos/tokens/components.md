# Components

## Primary Filled Button

- Role: Main action.
- Background: `#0d0d0d`
- Text: `#ffffff`
- Radius: `16px`
- Padding: `16px 24px`
- Font: cosmosOracle, `16px`, weight `500`
- Border: none.
- Shadow: none.

## Secondary Outlined Button

- Role: Paired secondary action.
- Background: `#ffffff`
- Text: `#0d0d0d`
- Border: `1px solid rgba(13, 13, 13, 0.15)`
- Radius: `16px`
- Padding: `16px 24px`
- Size should match the filled button.

## Pill Navigation Bar

- Role: Top-level navigation.
- Background: `#ffffff`
- Border: `1px solid rgba(13, 13, 13, 0.1)`
- Radius: `9999px`
- Shadow: none.
- Contains logo, 1-2 text links, centered search, theme toggle, and auth actions.
- Place near the top edge as one floating unit.

## Search Input

- Background: transparent inside nav pill.
- Border: none.
- Placeholder: `#6e6a69`
- Text: `#0d0d0d`
- Font: cosmosOracle at `16px`, weight `400`
- Include a small ink-black magnifier icon.

## Floating Image Tile

- Role: Hero collage.
- Image size: `60px` to `140px`
- Radius: `12px`
- Crop: cover.
- Border: none.
- Shadow: none.
- Position around the centered hero with small rotations.

## Feature Image Card

- Role: Image-led feature.
- Image: edge-to-edge with `16px` radius.
- Label: `18px`, weight `400`, Ink Black.
- Gap from image to label: `16px`.
- No border, no background, no shadow.
- Use in a 3-column grid with `24px` gap.

## Video Container

- Width: up to `1280px`
- Aspect: `16:9`
- Radius: `16px`
- Image/poster fills the container.
- Use white overlay text only when it sits over imagery.
- Optional central dot-cluster loader.

## AI Content Detection Overlay

- Width: about `280px`
- Background: `#ffffff`
- Radius: `12px`
- Title: `16px`, weight `500`, Ink Black.
- Body: `14px`, Stone.
- Actions: small neutral text buttons plus one black filled action.

## Text Link With Play Icon

- Text: Ink Black.
- Font: `18px`, weight `400`.
- Icon: small play triangle.
- No underline by default.
- Use as a quiet tertiary media CTA.

## Theme Toggle

- Size: `32px`
- Shape: circle on hover.
- Border: none.
- Icon-only.
- Sits inside the nav cluster before auth controls.

## Eyebrow Label

- Font: cosmosOracle, weight `500`.
- Size: `15px` to `16px`.
- Text: uppercase.
- Tracking: `0`.
- Use above hero display type like a stamp.

## Dot Cluster Logo

- Use a small monochrome cluster mark.
- Color: Ink Black.
- Avoid using colored brand marks in the UI chrome.
