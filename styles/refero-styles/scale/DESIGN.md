# Scale Style Reference

## Creative Direction

Create a serious enterprise AI interface with cinematic authority. The top of the page should feel like a high-stakes photographic AI platform. The middle should become a black data/model space with fine wireframe lines. The bottom should resolve into crisp white enterprise software surfaces.

## Visual Priorities

1. Start with full-bleed photography under a black overlay.
2. Use pure black for the hero frame, wireframe sections, and primary CTAs.
3. Use white and near-white surfaces for product sections.
4. Keep accents tiny and analytical, mostly inside charts, model tags, status dots, and graph nodes.
5. Use thin borders, not decorative gradients, for enterprise product UI.
6. Use Suisse Intl for UI and editorial copy.
7. Use Suisse Intl Mono for metrics, model IDs, code, and data labels.
8. Keep everything gridded, precise, and sober.

## Screen Composition

Use a top nav over the hero, a large full-bleed photographic hero with white text, a black transition band containing wireframe/model visuals, then white sections with dashboards, cards, tables, case-study blocks, and product panels. Let the dramatic part live above the fold; let the product sections behave like credible enterprise software.

## Material Language

The design is not glassy or bubbly. Use flat black, flat white, 1px borders, 12px to 16px cards, and precise spacing. Large dark sections can use faint wireframe glows, but ordinary product UI should be almost monochrome.

## AI Implementation Notes

When generating a UI from this style, ask for a full page rather than a single dashboard. The most important thing is the dark-to-light transition. If creating an app screen only, use the white product UI language with black CTAs, thin borders, mono metrics, and tiny category colors.
