## What To Preserve

Scale uses a deliberate page arc: dark cinematic hero, pure-black model/wireframe section, then bright enterprise product UI. The interface is mostly monochrome. Green, blue, violet, amber, and red appear only as tiny analytical/category marks, not as general brand decoration.

## What To Avoid Copying

Do not copy the original logo, exact hero photograph, product screenshots, diagrams, customer marks, copy, or page sequence. Use the token system and component logic to create original enterprise AI, data tooling, model evaluation, or analytics screens.

## Build Context

This bundle is meant for AI-assisted UI implementation. Use the markdown files for design intent, and use the `code/` files for direct token import when building with CSS variables or Tailwind v4.
