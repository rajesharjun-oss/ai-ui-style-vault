# Implementation Prompt

Create an original enterprise AI or data infrastructure interface inspired by the Scale Refero style.

Use a mixed dark-to-light composition. Open with a full-bleed photographic or cinematic dark hero using a black overlay and white text. Follow with a pure-black wireframe/model visualization band. Resolve into bright white enterprise product sections with crisp cards, thin borders, charts, tables, and analytical UI panels.

Use these tokens:

- Pure black: `#000000`
- Near black: `#050505`
- White: `#ffffff`
- Paper: `#fafafa`
- Cloud: `#f6f6f6`
- Mist border: `#e6e6e6`
- Ash text: `#6f6f6f`
- Signal green: `#19d27f`
- Model blue: `#3f7dff`
- Data violet: `#7b61ff`
- Warning amber: `#ffb547`
- Error red: `#ff5a5f`

Use Suisse Intl for headings, body, nav, and UI, and Suisse Intl Mono for data labels, metrics, code, and model IDs.

Build these elements:

- Over-hero nav with white text and a black or transparent CTA.
- Full-bleed photographic hero with white headline, short body copy, and one filled CTA.
- Pure-black model/wireframe band with faint blue/violet node glow.
- White product cards with `1px solid #e6e6e6` borders and 16px radius.
- Analytical dashboard panels with charts, model evaluation rows, status chips, and mono metrics.
- Case-study or customer proof cards with white surfaces and restrained text.

Do not copy Scale brand assets, exact screenshots, page copy, customer marks, or proprietary diagrams. Generate a new enterprise AI screen that borrows only the mood, token relationships, and component language.
