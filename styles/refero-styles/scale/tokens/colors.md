# Colors

## Brand

| Name | Value | Token | Role |
|---|---:|---|---|
| Pure Black | `#000000` | `--color-pure-black` | Global hero and terminal canvas, black CTAs, high-contrast copy on light |
| Scale White | `#ffffff` | `--color-scale-white` | Card surfaces, light-mode page background, inverse hero type |
| Signal Green | `#19d27f` | `--color-signal-green` | Small data highlights, graph nodes, progress accents, success state |
| Model Blue | `#3f7dff` | `--color-model-blue` | AI/model category tags, chart highlights, hover accents |
| Data Violet | `#7b61ff` | `--color-data-violet` | Secondary chart/category accent and wireframe glow points |

## Neutrals

| Name | Value | Token | Role |
|---|---:|---|---|
| Near Black | `#050505` | `--color-near-black` | Image overlay, dark nav, footer panels |
| Graphite | `#111111` | `--color-graphite` | Dark cards in wireframe sections |
| Steel | `#333333` | `--color-steel` | Dark dividers and borders on black |
| Ash | `#6f6f6f` | `--color-ash` | Secondary text on light and dark |
| Mist | `#e6e6e6` | `--color-mist` | Light dividers, card borders, form lines |
| Cloud | `#f6f6f6` | `--color-cloud` | Light gray product sections and alternate backgrounds |
| Paper | `#fafafa` | `--color-paper` | Large light surface backgrounds |

## Accents

| Name | Value | Token | Role |
|---|---:|---|---|
| Warning Amber | `#ffb547` | `--color-warning-amber` | Chart warnings and status markers only |
| Error Red | `#ff5a5f` | `--color-error-red` | Destructive and error states only |
| Success Green | `#19d27f` | `--color-success-green` | Success and progress state |

## Effects

```css
--gradient-hero-overlay: linear-gradient(180deg, rgba(0, 0, 0, 0.15) 0%, rgba(0, 0, 0, 0.82) 100%);
--gradient-wireframe: radial-gradient(circle at center, rgba(63, 125, 255, 0.22), rgba(0, 0, 0, 0) 60%);
```
