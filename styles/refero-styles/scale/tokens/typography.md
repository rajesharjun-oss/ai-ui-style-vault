# Typography

## Families

| Family | Token | Role |
|---|---|---|
| Suisse Intl | `--font-suisse-intl` | Headings, body, navigation, buttons, enterprise UI |
| Suisse Intl Mono | `--font-suisse-intl-mono` | Metrics, model IDs, data labels, code, table numerics |

## Substitutes

- Sans substitute: Inter, Helvetica Neue, Arial, or Geist Sans.
- Mono substitute: IBM Plex Mono, JetBrains Mono, SFMono-Regular, or ui-monospace.

## Type Scale

| Role | Size | Line Height | Weight | Tracking | Use |
|---|---:|---:|---:|---:|---|
| Caption | `12px` | `1.5` | `500` | `0.06em` | Uppercase labels, overlines, small data categories |
| Body Small | `14px` | `1.55` | `400` | `0` | Compact UI copy |
| Body | `16px` | `1.6` | `400` | `0` | Main body copy |
| Lead | `20px` | `1.45` | `400` | `-0.01em` | Hero support and section intros |
| Heading Small | `28px` | `1.18` | `500` | `-0.03em` | Card and section headings |
| Heading | `48px` | `1.05` | `500` | `-0.05em` | Major section headings |
| Display | `72px` | `0.96` | `500` | `-0.06em` | Hero display |

## Rules

- Keep typography sober and technical.
- Use mono only for data, metrics, model IDs, code, and table numerics.
- Avoid decorative serif or playful type.
- Use tight tracking for large headings, not for small UI text.
