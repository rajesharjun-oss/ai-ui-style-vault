## Borders And Elevation

```css
--border-light: 1px solid #e6e6e6;
--border-dark: 1px solid rgba(255, 255, 255, 0.14);
--shadow-product: 0 16px 48px rgba(0, 0, 0, 0.08);
```

Use shadows sparingly. Enterprise product sections should mostly be defined by borders and background contrast.
