# Playful

AI-ready Refero style bundle for Playful.

- Source: https://styles.refero.design/style/f93ac72e-73b2-4b2c-80eb-351ddfa56f4d
- Reference site: https://www.playful.so
- Captured: 2026-07-28
- Theme: light
- Mood: sunlit paper notebook with hot-pink highlighter
- Industry: AI apps, consumer productivity, playful product tools

## Use This Style For

- Warm product landing pages with friendly editorial energy
- AI tools that need to feel creative, approachable, and tactile
- Waitlist pages with a strong single CTA and email capture
- Product showcases based on app tiles, FAQ cards, and playful 3D illustration

## Files

- `source.md` records the source URL and capture context.
- `DESIGN.md` is the main human-readable design reference.
- `implementation-prompt.md` is a direct prompt for an AI coding agent.
- `style.json` is a structured summary for indexing and retrieval.
- `tokens/` contains focused notes for colors, type, spacing, components, guidelines, layout, and imagery.
- `code/` contains CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` reserves the screenshot slot for manual or automated captures.

## Core Signature

Playful is a warm cream product notebook with one vivid magenta highlighter. It uses Inter everywhere, especially huge heavy italic display headlines, then softens the page with 44px cards, 99px pill inputs and buttons, deep diffused card shadows, and friendly 3D app-tile illustrations.
