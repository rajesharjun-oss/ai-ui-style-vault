# Implementation Prompt

Use the Playful style for this UI.

Create a light, warm, editorial product page on Oat Canvas (`#f6f2ee`). Use Hot Magenta (`#ff2e95`) as the only chromatic accent. It may appear in the primary CTA, logo, links, and small accent strokes, but should not become a large flat background except for a soft gradient highlight section.

Typography:

- Use Inter everywhere.
- Use Inter 700 or 900 italic for display headlines at 70px to 79px.
- Display line-height should be 1.0 with barely tightened tracking.
- Use Inter 400 for body copy at 16px to 18px.
- Use Inter 500 or 600 for labels, captions, nav items, and FAQ questions.
- Do not use upright heavy display headlines; the italic slope is the brand signature.

Color:

- Background: `#f6f2ee`.
- Primary text: `#111111` or `#000000`.
- Secondary text: `#0f172a`.
- Cards: `#ffffff`.
- Borders: `#e8e5e0`, `#e2dcd6`, or `#414040` for input borders.
- Icons and helper text: `#848383`.
- Accent and primary action: `#ff2e95`.

Layout:

- Use a centered max-width around 1200px.
- Use about 113px between major sections.
- Hero stack: giant italic headline, muted subtext, email and CTA pill composite, tilted app-tile row.
- Include a full-width black category nav band with white labels.
- Include a soft magenta-to-cream gradient band with a single centered headline.
- FAQ should use a two-column layout: label and heading on the left, accordion cards on the right.

Components:

- Primary CTA: Hot Magenta fill, 99px radius, 14px 24px padding, Inter 600 at 16px.
- Email composite: white 99px pill container holding Oat Canvas input and magenta CTA.
- Card and app tile: Paper White, 44px radius, `0 32px 80px rgba(0,0,0,0.22), 0 2px 8px rgba(0,0,0,0.08)`.
- App tiles: 140px to 180px square, slightly tilted and overlapping, with centered soft 3D illustration.
- FAQ card: Paper White, 44px radius, same shadow, Inter 600 italic question, Stone chevron.
- Category nav: black full-width band, white Inter 500 labels, horizontal spacing around 28px.

Avoid extra accent colors, cold white page backgrounds, sharp corners, glassmorphism, text shadows, button shadows, and photographic hero imagery. The result should feel like a warm notebook with a single vivid highlighter.
