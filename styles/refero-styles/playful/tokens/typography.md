# Typography

## Families

| Role | Font | Fallback | Use |
| --- | --- | --- | --- |
| Primary | Inter | Arial, ui-sans-serif, system-ui | All display, body, nav, labels, cards, inputs, and buttons |
| Degradation | Arial | Inter | Some system fallback button and input contexts |

## Weights

| Weight | Role |
| --- | --- |
| 400 | Body copy |
| 500 | Captions and nav labels |
| 600 | Buttons, FAQ questions, subheads |
| 700 | Display headings and logo |
| 900 | Maximum-impact display headings |

## Type Scale

| Token | Size | Weight | Line height | Tracking |
| --- | --- | --- | --- | --- |
| Caption | 13px | 500 | 1.4 | -0.026px |
| Body | 16px | 400 | 1.5 | -0.032px |
| Body Large | 18px | 400 | 1.5 | -0.036px |
| Subheading | 26px | 600 or 700 | 1.23 | -0.052px |
| Heading Small | 30px | 600 or 700 italic | 1.2 | -0.06px |
| Display | 79px | 700 or 900 italic | 1 | -0.158px |

## Rules

- Display headlines must be italic.
- Prefer one display headline per section.
- Keep body text quiet and centered when it supports a hero.
- Do not stack more than two type weights on the same screen.
- Use OpenType features `ss01` and `cv11` when available.
