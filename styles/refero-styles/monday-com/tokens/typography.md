# Typography

## Family

- Primary: Poppins.
- Fallback: Manrope, DM Sans, Plus Jakarta Sans, Arial, sans-serif.
- Use one family across nav, body, headings, buttons, badges, and product UI.

## Weights

- 300: large display headlines.
- 400: body, standard headings, supporting copy.
- 500: buttons, labels, badges, product UI.
- 700: nav and strong product labels where needed.

## Usage

- Use weight 300 only for large, friendly display moments.
- Use 500 to 700 where a product UI label or navigation item needs confidence.
- Use negative tracking for large display type.
- Use positive tracking only for tiny uppercase labels.
- Keep the type rounded, geometric, and approachable.
