# Spacing And Shape

## Spacing

| Purpose | Value |
| --- | --- |
| Density | Comfortable |
| Base unit | 8px |
| Max width | 1200px |
| Section gap | 64px |
| Card padding | 24px |
| Element gap | 8px |

Scale: 8px, 16px, 24px, 32px, 40px, 48px, 64px, 80px, 96px.

## Shape

| Element | Radius |
| --- | --- |
| Navigation controls | 6px |
| Badges | 6px |
| Inputs | 6px |
| Images | 12px |
| Cards | 24px |
| Buttons and CTAs | 160px |
| Avatars | Full circle |

## Elevation

- Board mockup: `rgba(205, 208, 223, 0.4) 0px 2px 48px 0px`.
- Featured card: `rgba(0, 0, 0, 0.15) 0px 5px 45px 0px`.
- Active AI card: `rgba(0, 0, 0, 0.15) 0px 4px 40px 0px`.
- Inset emphasis: `rgb(0, 0, 0) 0px -2px 0px 0px inset`.

## Rhythm

- Use 64px between major sections.
- Use 24px inside cards.
- Keep CTA padding compact and pill-like.
- Let product mockups overlap or peek beyond section boundaries.
