## Palette Rules

- Use Monday Violet for the main action on each screen.
- Keep pastel colors as surfaces, not body text colors.
- Use Prism for the mark, dividers, and loading states only.
- Use hero text gradients sparingly.
- Keep large copy on Ink rather than pure black.
