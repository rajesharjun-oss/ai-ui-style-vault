# Implementation Prompt

Use the monday.com style language for this UI.

Create a light productivity SaaS interface that feels like a white workshop with pastel sticky notes: generous whitespace, warm near-black text, violet primary actions, Poppins typography, rounded cards, pill CTAs, and product board mockups as the main proof.

Core rules:

- Use `#f5f6f8` for soft page bands and `#ffffff` for cards, nav, and input surfaces.
- Use `#6161ff` as the only marketing CTA and brand-panel color.
- Use `#333333` for primary text and `#535768` for secondary text.
- Use Poppins for all headings, body, buttons, badges, and product UI.
- Set display headlines at 48px to 64px, weight 300, with tight negative tracking.
- Use weight 500 to 700 for buttons, nav labels, badges, and product UI labels.
- Use 160px radius for every button and CTA.
- Use 24px radius for cards, 12px for images, and 6px for badges, inputs, and compact product controls.
- Use pastel colors only as surfaces for feature cards, highlight bands, and product tiles.
- Use gradient text only in hero headlines.
- Use the conic prism gradient only for logo marks, dividers, and loading states.

Recommended structure:

- Sticky white navigation with logo left, links center, and dual CTAs right.
- Centered hero with large Poppins display text, a gradient text phrase, one primary pill CTA, and optional secondary outlined pill.
- Social-proof logo strip with monochrome wordmarks.
- Alternating feature sections with text on one side and floating board mockup cards on the other.
- Pastel feature grid with 24px cards and compact icons.
- AI/productivity feature using a 50/50 split with a violet brand panel and a white product mockup card.

Avoid:

- Square buttons or 4px-radius CTAs.
- Pastel colors on long text or icons.
- Heavy shadows or dark dashboard styling.
- Lifestyle photography and human portraits.
- New CTA colors outside violet.
- Too many adjacent pastel colors in one row.

The result should feel friendly, polished, productive, and clearly product-led.
