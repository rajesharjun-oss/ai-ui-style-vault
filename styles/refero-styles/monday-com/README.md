## Use This Style For

- SaaS landing pages, productivity tools, collaboration dashboards, and workflow products.
- Interfaces that need to feel friendly, organized, playful, and still conversion-focused.
- AI assistant/productivity launches where real product UI mockups should be the hero.
- Feature grids, trust strips, board previews, and split text-plus-product sections.

## Design Memory

monday.com is a white-canvas SaaS language with one clear brand action color: violet. The friendliness comes from Poppins, pill CTAs, 24px cards, pastel feature surfaces, and product board mockups that float above the page edge. It feels like a clean workshop covered in soft sticky notes, not a cold enterprise dashboard.
