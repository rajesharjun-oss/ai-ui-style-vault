# Typography

## Font

- Primary: PP Neue Montreal
- Fallback: Inter, General Sans, or Sohne-style sans
- Weights: 350, 400
- Global tracking: `-0.0200em`

## Type Scale

| Role | Size | Weight | Line Height | Letter Spacing | Token |
| --- | --- | --- | --- | --- | --- |
| Caption | 10px | 350 | 12px | -0.2px | `--text-caption` |
| Micro | 12px | 350 | 14.4px | -0.24px | `--text-micro` |
| Button Label | 13px | 400 | 15.6px | -0.26px | `--text-button-label` |
| Small Body | 14px | 350 | 16.8px | -0.28px | `--text-small-body` |
| Body | 16px | 350 | 19.2px | -0.32px | `--text-body` |
| Subheading | 18px | 350 | 21.6px | -0.36px | `--text-subheading` |
| Heading | 27px | 350 | 32.4px | -0.54px | `--text-heading` |

## Typography Rules

- Weight 350 is the default for all text.
- Weight 400 is only for tiny button or icon labels.
- Never use weight 500, 600, 700, or heavier.
- Use tight tracking uniformly.
- Use size changes for hierarchy, not weight changes.
- Keep multi-line paragraphs left-aligned.
- Use stylistic alternates when available: `ss01`, `ss02`, `cv01`, `cv11`.
