## Borders

Use hairlines only:

- Structural: `0.5px solid rgba(0, 0, 0, 0.06)`
- Soft structural: `0.5px solid rgba(0, 0, 0, 0.04)`
- Interactive: `0.5px solid #0071e3`

Never use borders thicker than 1px for normal UI.

## Elevation

No shadows. Use tone contrast between Off-White and Pure White.
