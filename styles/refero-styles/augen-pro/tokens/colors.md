# Colors

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Off-Black | `#0f1012` | `--color-off-black` | Primary text, hero and footer backgrounds, icon fills |
| Pure Black | `#020201` | `--color-pure-black` | Secondary text, hard emphasis, maximum contrast details |
| Steel Gray | `#5e5e5e` | `--color-steel-gray` | Muted body text, captions, inactive labels |
| Ash Gray | `#8f8f8f` | `--color-ash-gray` | Disabled text, tertiary helper text, low-emphasis labels |
| Off-White | `#f2f2f4` | `--color-off-white` | Page canvas and large light fills |
| Pure White | `#fdfdfd` | `--color-pure-white` | Elevated panels, nav pills, inputs, cards |
| Signal Blue | `#0071e3` | `--color-signal-blue` | Links, tag borders, interactive outlines, small icons |

## Color Rules

- Use Off-White for the page canvas.
- Use Pure White for elevated panels.
- Use Off-Black for primary text on light surfaces.
- Use Pure White text on dark footer surfaces.
- Use Signal Blue only as text, icon, border, or focus edge.
- Never use Signal Blue as a filled background.
- Do not add green, orange, yellow, or other UI accent colors.
