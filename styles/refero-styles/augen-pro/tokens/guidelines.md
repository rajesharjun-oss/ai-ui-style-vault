# Guidelines

## Do

- Use weight 350 by default for all text.
- Use 400 only for tiny button or icon labels.
- Use Signal Blue only as text, border, icon, or focus edge.
- Use 54px radius for large content cards.
- Use 9999px radius for tags and link pills.
- Maintain 90px to 100px section gaps.
- Use Off-Black on light surfaces.
- Use Pure White text on dark surfaces.
- Use floating pills for nav and controls.
- Use `-0.0200em` letter spacing everywhere.
- Use white-tone shifts and hairline borders for elevation.

## Do Not

- Do not use drop shadows.
- Do not fill buttons or tags with Signal Blue.
- Do not use font weights above 400.
- Do not center-justify long body text.
- Do not add decorative gradients, patterns, or image backgrounds.
- Do not introduce extra accent colors.
- Do not exceed 1200px content width.
- Do not use full-width nav bars.
