## Use This When

Use this style for high-end consumer tech, AI hardware, neural interfaces, medical-adjacent products, premium device pages, research labs, clinical product launches, and interfaces that need to feel weightless, precise, and expensive.

## Core Idea

Augen Pro is a clinical-white system with whisper-weight typography, huge negative space, floating pills, rounded white-tone cards, and a single electric blue used only as text or outline. The design should feel like a high-end keynote spread: quiet, centered, surgical, and almost shadowless.
