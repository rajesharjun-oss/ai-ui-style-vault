# Implementation Prompt

Build in the Augen Pro style: a clinical-white premium tech interface with whisper-weight typography, huge negative space, floating pill controls, rounded white-tone cards, and Signal Blue used only as a wireframe accent.

Use these rules:

- Page canvas: `#f2f2f4`.
- Elevated panels: `#fdfdfd`.
- Primary text: `#0f1012`.
- Emphasis text: `#020201`.
- Muted text: `#5e5e5e`.
- Disabled or tertiary text: `#8f8f8f`.
- Accent: `#0071e3`, text and borders only.
- Dark footer: `#0f1012`, with `#fdfdfd` text.
- Typeface: PP Neue Montreal, with Inter, General Sans, or Sohne-style fallback.
- Default font weight: 350.
- Tiny button or icon label weight: 400.
- Never use weights above 400.
- Letter spacing: `-0.0200em` everywhere.
- Heading: 27px, weight 350, line-height 32.4px.
- Body: 16px, weight 350, line-height 19.2px.
- Caption: 10px, weight 350, line-height 12px.
- Content max width: 1200px.
- Section gap: 90px to 100px.
- Card padding: 69px.
- Element gap: 6px.
- Nav pill radius: 10px.
- Button radius: 26px.
- Large card radius: 54px.
- Body container radius: 63px.
- Tag and link pill radius: 9999px.
- Hairline borders: 0.5px solid rgba(0, 0, 0, 0.06).
- No shadows.

Design structure:

1. Floating centered nav pill around 34px from the top.
2. Full-viewport hero with sparse text bottom-left and one high-fidelity 3D render centered-right.
3. Small Signal Blue text links and outline tags.
4. Rounded Pure White content cards on Off-White canvas.
5. Editorial sections with 90px to 100px vertical breathing room.
6. Full-width dark footer band.

Avoid:

- Blue filled buttons.
- Drop shadows.
- Bold text.
- Decorative gradients or patterns.
- Full-width nav bars.
- Center-justified long body paragraphs.
- Extra accent colors.
- Dense dashboard layouts.

The result should feel clinical, quiet, engineered, and premium.
