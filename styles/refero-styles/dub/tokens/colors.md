# Color Tokens

## Brand

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Electric Blue | `#0066ff` | `--color-electric-blue` | Primary CTA, link highlights, active nav, brand accent. |
| Midnight | `#0a0a0a` | `--color-midnight` | Primary text, dark surfaces, logo mark. |

## Neutrals

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Snow | `#ffffff` | `--color-snow` | Cards, nav, modal surfaces, page background. |
| Rice Paper | `#fafafa` | `--color-rice-paper` | Subtle page bands, hover states. |
| Porcelain | `#f5f5f5` | `--color-porcelain` | Muted card fills. |
| Mist | `#f4f4f5` | `--color-mist` | Secondary backdrop, code preview surfaces. |
| Cloud | `#e5e5e5` | `--color-cloud` | Borders, dividers, inactive strokes. |
| Ash | `#a3a3a3` | `--color-ash` | Icons, muted captions, meta labels. |
| Graphite | `#737373` | `--color-graphite` | Secondary body text, disabled labels. |
| Charcoal | `#525252` | `--color-charcoal` | Strong captions, secondary nav. |
| Steel | `#262626` | `--color-steel` | Subheadings, card titles. |

## State And Analytics

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Growth Green | `#16a34a` | `--color-growth-green` | Success states, positive charts, completed status. |
| Warning Amber | `#f59e0b` | `--color-warning-amber` | Caution badges, setup reminders. |
| Danger Red | `#ef4444` | `--color-danger-red` | Destructive actions, error states. |
| Purple Flux | `#8b5cf6` | `--color-purple-flux` | Rare analytics accent and chart series. |

## Rules

- Use Electric Blue for primary action and active product states only.
- Keep normal surfaces white, rice-paper, or porcelain.
- Use Cloud borders for card and table structure.
- Use green, amber, red, and purple only as state or chart colors.
