# Dub

Source: https://styles.refero.design/style/b0d80806-b724-4ed1-a1d1-074edd3c9bc9

Product/site reference: https://dub.co

## Snapshot

- **Mood:** Porcelain SaaS: rice-paper whites, hairline gray architecture, and one precise blue action color.
- **Theme:** Light, product-led, dashboard-ready, growth-focused.
- **Core grammar:** White and near-white surfaces, 1px Cloud borders, Satoshi display, Inter UI, 24px pill CTAs, 16px cards, restrained analytics colors.
- **Best for:** SaaS landing pages, analytics dashboards, link-management tools, pricing pages, admin panels, product-led startup sites.

Dub is a clean SaaS system where the product UI is the visual authority. The page uses white and rice-paper sections, structured dashboard cards, compact tables, analytics panels, and one sharp blue for primary action. It avoids loud decoration and gets polish from spacing, borders, type hierarchy, and product screenshots.

## Fast Build Notes

- Use `#ffffff` and `#fafafa` as the main surfaces.
- Use `#0066ff` only for primary CTAs, active states, and important links.
- Use `1px #e5e5e5` borders on cards, tables, inputs, and controls.
- Use 24px pill CTAs, 16px cards, 12px inputs, and 9999px badges.
- Use Satoshi for display and headings; Inter for body and UI.
- Let product screenshots, dashboards, charts, and tables carry the visual story.
