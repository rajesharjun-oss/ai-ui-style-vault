# Implementation Prompt

Build a clean product-led SaaS interface inspired by Dub.

Use `#ffffff` as the main surface and `#fafafa` as a rice-paper section background. Use `#e5e5e5` as the main 1px border for cards, tables, inputs, and controls. Keep shadows absent or extremely subtle, such as `0 1px 2px rgba(0,0,0,0.05)`.

Use `#0066ff` as the single primary action and active-state color. Use it for primary CTAs, selected nav states, important links, and chart highlights. Do not flood sections with blue or use it for every icon.

Use Satoshi or Plus Jakarta Sans for hero and display headings. Use Inter for body text, nav, labels, cards, tables, forms, and dashboard UI. Keep body text compact and clear: 14px to 16px. Use 72px display type for hero moments, 48px for major headings, and 30px for card or section headings.

Use 24px pill-shaped CTAs, 16px cards, 12px inputs, and 9999px badges. Build components around product workflows: dashboard cards, analytics charts, pricing cards, table rows, link rows, feature pills, sticky nav, and product mockup frames.

Avoid gradients, heavy shadows, glassmorphism, serif fonts, dark hero sections, lifestyle photos, and decorative illustration. Use product screenshots, dashboard mockups, charts, tables, metric tiles, and link cards as the visual system.
