# Dub Design Notes

Dub is a precise light SaaS system. It relies on white, rice-paper neutrals, hairline borders, compact product typography, and a single electric blue action color. It is polished without being decorative: product screenshots, analytics cards, and table-like UI do most of the visual work.

## Visual Principles

- Keep most surfaces white or rice-paper.
- Use blue as a product/action signal, not general decoration.
- Use borders for structure and shadows only as tiny interaction or mockup cues.
- Let dashboard and analytics UI become the main imagery.
- Keep the system crisp, practical, and conversion-oriented.
- Use neutral cards and restrained chart accents.

## Color System

Electric Blue is the brand action color. Midnight and Steel carry dark hierarchy. Snow, Rice Paper, Porcelain, Mist, and Cloud form the interface architecture. Green, amber, red, and purple exist only as state or analytics colors.

## Typography

Use Satoshi for display and headings, especially hero copy. Use Inter for body, nav, labels, cards, tables, and all dashboard UI. Display type can be bold and tight, while the product UI stays compact and clear.

## Layout

Use a `1200px` max-width container with an 80px section rhythm. Common sections include hero plus product mockup, logo rows, bento cards, pricing cards, analytics panels, feature grids, and table-heavy product previews.

## Elevation

Cards are mostly shadowless. Use `1px #e5e5e5` borders for structure. A tiny `0 1px 2px rgba(0,0,0,0.05)` shadow is acceptable for primary CTAs and active/hover moments.
