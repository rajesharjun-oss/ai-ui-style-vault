# Vivid+Co

Source: Refero Styles  
URL: https://styles.refero.design/style/8875b14e-c59a-492f-8780-8027a480f21c  
Reference site: https://vividand.co  
Captured: 2026-07-28

Vivid+Co is a cinematic dark agency style: obsidian canvas, near-white typography everywhere, enormous Neue Montreal display type, almost no UI chrome, and one RGB prism artifact as the only chromatic voice. It should feel sculptural, restrained, and optical.

Use this folder as an AI implementation brief. The most useful files are:

- `DESIGN.md` for the full style interpretation.
- `implementation-prompt.md` for a copy-ready prompt to hand to an AI builder.
- `style.json` for structured metadata.
- `code/css-variables.css` for CSS custom properties and component recipes.
- `code/tailwind-v4.css` for Tailwind v4 theme tokens.
- `code/design-tokens.json` for machine-readable tokens.

Core cues:

- Canvas: `#101010` Obsidian.
- Dark surface: `#495764` Graphite Veil.
- Primary text/UI: `#fffdf9` Bone White.
- Muted metadata: `#6f879c` Fog Blue.
- Hairlines: `#403f3f` Ash Border.
- Decorative black: `#000000` Pure Black for artwork and glyph fills only.
- Prism colors: `#ff2a2a`, `#2a7fff`, `#2aff2a` only inside the glass/prism hero artifact.
- Typography: Neue Montreal everywhere, mostly weight 400.
- Display scale: 105px and 136px, line-height 1.00 to 1.01, tight tracking.
- Shape: buttons 0px, nav outline 5px, cards 15px, rare tags 9999px.
- Depth: no shadows; use dark surface contrast, hairlines, and the prism artifact.

This is best for creative agencies, brand studios, cinematic portfolios, art direction pages, experimental landing pages, and high-end studio case-study indexes.
