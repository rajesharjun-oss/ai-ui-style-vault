# Implementation Prompt

Build a cinematic dark creative-agency interface in the Vivid+Co style.

Use Obsidian (`#101010`) as the full page canvas and Graphite Veil (`#495764`) only as a cool dark content surface. Use Bone White (`#fffdf9`) for almost all text, navigation, links, and interactive elements. Use Fog Blue (`#6f879c`) only for muted metadata and service labels. Use Ash Border (`#403f3f`) only for rare hairline dividers and the footer rule. RGB colors (`#ff2a2a`, `#2a7fff`, `#2aff2a`) belong only inside the prism/glass hero artifact. Do not use them for UI, badges, links, hover states, or backgrounds.

Use Neue Montreal or a close Sohne/Inter/General Sans fallback for the entire interface. Weight 400 is the default for headings, body, nav, links, and footer. Use weight 700 only for rare 36px subheadings. Display headings should be 105px to 136px, line-height 1.00 to 1.01, with -0.02em tracking. Let huge scale create authority; do not bold the display type.

Use a 4px base unit, 1440px max width, 108px section gaps, 20px card padding if a card is unavoidable, and about 7px micro gaps. Buttons usually have 0px radius. The outlined contact button uses 5px radius. Cards can use 15px radius. Pill tags at 9999px are rare. Do not use shadows.

Expected components:

- Top nav: wordmark left, uppercase ghost links right, and one outlined Contact button.
- Ghost nav link: transparent, Bone White text, uppercase 14px to 15px, no border, no underline.
- Outlined Contact button: transparent, 1px Bone White border, 5px radius, 9px by 15px padding.
- Display headline block: Bone White, Neue Montreal 105px to 136px, weight 400, tight tracking, stacked across the viewport.
- Prism artifact: 4 to 6 glass cubes with black cores, white specular highlights, and RGB-split red/cyan/lime caustic edges.
- Hero lead paragraph: 18px to 22px, line-height 1.5, max-width around 440px.
- Case-study title link: 33px, weight 400, tight tracking, no underline, optional Fog Blue hover.
- Footer: one Ash Border hairline, two-column metadata, compact Bone White text.

The page should feel optical, still, high-end, and stark. Avoid filled CTAs, colored badges, gradients, stock photos, product screenshots, card grids, pricing tables, heavy animation, and broad color systems.
