# Implementation Prompt

Build the UI in the Max Yinger Refero style.

Create a compact midnight engineer terminal. Use one warm carbon canvas, bone-white text, corner-anchored content clusters, technical labels, a blocky digital time/readout, and a single central 3D artifact. The page should feel like a live creative-engineering cockpit, not a landing page.

Color rules:

- Background: `#12130f`.
- All visible text: `#e4dfda`.
- Secondary divider/chrome if absolutely needed: `#3c3c38`.
- Rose glow: `#f5c2c8`, only as edge-light on the 3D object.
- Do not use pure white or pure black.
- Do not add new accent colors.

Typography rules:

- Telemetry labels use Arbeit Technik-like mono at 12px, line-height 15px, letter-spacing -0.6px.
- Hero display uses Inline VF-like blocky type at 80px, line-height 56px, weight 400.
- Body/prose uses Arbeit Contrast-like text at 16px, line-height 20px.
- Do not use bold, semibold, or multiple font weights.
- Do not use line-height above 1.25.

Layout rules:

- Full-bleed edge-to-edge page.
- No max-width container.
- Top-left: compact wordmark.
- Bottom-left: time readout, local/status labels, short bio.
- Bottom-right: stacked or clustered social pill links.
- Center: one 3D isometric artifact.
- Use 4px gaps, 8px secondary gaps, and 12px cluster padding.

Component rules:

- Social/external links are transparent pill buttons with 9999px radius and Bone Glow text.
- Inline links use a 2px underline and 2px radius.
- Content clusters have no background, no border, no shadow, and no card fill.
- The 3D artifact has no container, no mask, no shadow, no panel, and no border.

Avoid standard nav bars, cards, feature sections, marketing CTAs, large paragraphs, icons, stock imagery, gradients, glass panels, box shadows, and centered column layouts.
