# Spacing And Shape

## Layout Values

| Purpose | Value |
| --- | --- |
| Density | compact |
| Base unit | 4px |
| Section gap | 64px |
| Card padding | 12px |
| Element gap | 4px |

## Spacing Scale

| Name | Value | Token |
| --- | --- | --- |
| 4 | 4px | `--spacing-4` |
| 8 | 8px | `--spacing-8` |
| 12 | 12px | `--spacing-12` |
| 64 | 64px | `--spacing-64` |

## Radius

| Element | Value | Token |
| --- | --- | --- |
| buttons | 9999px | `--radius-buttons` |
| tags | 9999px | `--radius-tags` |
| links | 2px | `--radius-links` |
| cards | 0px | `--radius-cards` |

## Shape Rules

- Interactive social controls are full pills.
- Inline links use 2px radius.
- Content clusters and cards have no visible rounding because they have no visible container.
- No visual card frame should appear.
