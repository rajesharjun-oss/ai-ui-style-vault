# Components

## Pill Link Button

Transparent social/external link button with 9999px radius, Bone Glow text, no border, no fill, and 12px telemetry type. Use edge placement.

## Underlined Inline Link

Inline Arbeit Contrast link with Bone Glow text and a 2px underline. Use 2px radius and no color hover state.

## Telemetry Label

Arbeit Technik-style 12px all-caps label with -0.6px tracking and 15px line-height. Use for labels, status, location, and time context.

## Digital Time Readout

Inline VF-style 80px display with 56px line-height. Can pair with a smaller 30px suffix.

## Masthead Wordmark

Blocky 30-40px wordmark in Bone Glow, positioned top-left.

## 3D Hero Artifact

Central isometric object in Bone Glow with Rose Quartz Bloom edge-lighting. No container, mask, border, or shadow.

## Cluster Card

No visual card. A tight stack of labels and text separated by 4px to 8px gaps.

## Performance Annotation

12px telemetry metric next to the time readout or artifact. Keep it compact and monospaced.
