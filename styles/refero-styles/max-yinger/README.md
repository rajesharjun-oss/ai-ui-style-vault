# Max Yinger

AI-ready Refero style bundle for a compact midnight engineer terminal: warm bone text on carbon, corner-anchored content, 4px rhythm, 12px telemetry labels, blocky display type, and one central 3D artifact with soft rose edge-lighting.

## Source

- Refero style: https://styles.refero.design/style/a7891223-a93e-4731-a1aa-4079f1ee928b
- Reference site: https://yinger.dev
- Captured: 2026-07-28
- Theme: dark

## Use This When

- You need a personal portfolio, realtime 3D lab, creative engineer site, experimental terminal, or compact developer identity page.
- The UI should feel like a live cockpit rather than a marketing page.
- You can support the look with a single strong 3D artifact and very disciplined typography.

## Bundle Contents

- `DESIGN.md` - complete AI style reference.
- `implementation-prompt.md` - drop-in prompt for AI implementation.
- `style.json` - structured metadata and searchable summary.
- `tokens/` - colors, typography, spacing, components, guidelines, layout, and imagery.
- `code/` - CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` - screenshot capture notes.

## Implementation Notes

Use this as an inspiration reference, not as an official Max Yinger brand kit. Do not copy logos, exact 3D assets, copy, custom fonts, or original page layouts unless you have rights to use them.
