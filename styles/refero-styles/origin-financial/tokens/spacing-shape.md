# Spacing And Shape

## Spacing

- Density: comfortable
- Base unit: 4px
- Max content width: 1200px
- Section gap: 80px
- Card padding: 32px
- Element gap: 12px

## Scale

`4px`, `8px`, `12px`, `16px`, `20px`, `24px`, `32px`, `40px`, `48px`, `60px`, `68px`, `100px`, `120px`, `140px`

## Shadow

Use shadow sparingly.

```css
--shadow-lg: rgba(0, 0, 0, 0.2) 0px 18px 20px 0px;
```

Most depth should come from black-to-gray surface steps, not drop shadows.
