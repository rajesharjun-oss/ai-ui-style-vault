# Colors

## Brand And Data

| Name | Value | Use |
|---|---:|---|
| Iris Gleam | `#847dff` | Primary chromatic accent, category panels, selected data moments |
| Cyan Signal | `#00b3dd` | Chart lines, sparklines, forecasting indicators |
| Pale Iris | `#d1c9ff` | Soft violet panels and quiet category washes |
| Deep Iris | `#4b49aa` | Dark violet panels, hover states, deeper category modules |
| Orchid Bloom | `#dd90d8` | Spending, lifestyle, and warm category cards |
| Periwinkle | `#90b8f0` | Advisory, couples, planning, and calm category cards |

## Neutrals

| Name | Value | Use |
|---|---:|---|
| Void | `#000000` | True black controls, icon fills, text on white CTAs |
| Abyss | `#090a0b` | Deep section tone and shadowed dark pockets |
| Obsidian | `#0f1011` | Primary page canvas |
| Graphite | `#2e2e2e` | Product cards, phone modules, dark raised panels |
| Steel | `#3f4041` | Hover and pressed secondary surfaces |
| Fog | `#6a6b6b` | Disabled and deeply muted text |
| Ash | `#9f9fa0` | Body text, descriptions, secondary links |
| Silver | `#cacaca` | Inverted stat cards and light panels |
| Cloud | `#f5f5f7` | Soft white display headings |
| Pure | `#ffffff` | Primary text and primary action fill |

## Rules

- Keep body copy at Ash or Fog, not Pure.
- Use Pure for headlines, nav, icons, and critical CTA states.
- Use chromatic colors as large semantic surfaces or data signals.
- Do not turn Cyan Signal into a general text/link color.
- Do not use gradients for buttons, text, or feature cards.
