# Origin Financial

Origin Financial is a dark, gallery-like finance style system: near-black surfaces, huge quiet serif headlines, white primary actions, and saturated color panels that make money categories feel curated instead of corporate.

- Source: https://styles.refero.design/style/c60f05ff-2420-4a24-92db-80c4b6a74683
- Reference site: https://www.useorigin.com
- Captured: 2026-07-28
- Theme: dark
- Best for: personal finance, wealth planning, investing dashboards, premium fintech, AI financial copilots

## Use This When Building

Use a near-black full-bleed page with a centered oversized serif statement. Keep most UI monochrome, then use one of the chromatic category colors as a large card or data signal. Do not sprinkle color everywhere. White-on-black is the main action language, and muted gray text should carry the body copy.
