# Implementation Prompt

Build a UI in the Ramp style.

Use a light editorial finance aesthetic: warm off-white canvas, white cards, thin grey borders, near-black type, and exactly one vivid yellow-green accent. The interface should feel like a polished business publication merged with a serious finance product.

Use these hard rules:

- Canvas: `#f4f2f0`.
- Card and panel surface: `#ffffff`.
- Main text: `#0c0a08`.
- Muted text: `#6d6c6b`.
- Borders: `#e5e7eb`.
- Dark sections: `#1a1919`.
- Only accent: `#e4f222`.
- Use the accent only for primary buttons, live counters, active nav/state indicators, and money/action signals.
- Use `lausanne` as the first font choice, then `Inter`, `IBM Plex Sans`, `Sohne`, `Arial`, `sans-serif`.
- Set font weight to `400` everywhere.
- Enable `font-feature-settings: "ss01";`.
- Do not use bold or semibold.
- Do not use card shadows.
- Do not introduce extra accent colors.
- Do not use rounded pills.
- Do not center long text blocks.

Build the page with a 1200px max-width centered container, left-aligned typography, generous vertical sections, and flat card components. Buttons should be rectangular with 6px radius. Inputs should use 10px radius. Cards should use 16px radius and 1px hairline borders.

Use product screenshots, UI mock frames, charts, finance panels, and grayscale logo grids as the visual language. Avoid stock photos, decorative illustrations, and gradient backgrounds.

Create a hero with large tight display text, a primary highlighter button, an outlined secondary action, and a big browser-style product screenshot. Add a dark full-width counter band with small uppercase labels and white values. Keep all interactions crisp, quiet, and focused.
