# Colors

| Token | Value | Use |
| --- | --- | --- |
| `--ramp-highlighter-yellow` | `#e4f222` | Primary CTA fill, active state, live money signal |
| `--ramp-ink` | `#0c0a08` | Main text, headings, outlines, icon color |
| `--ramp-obsidian` | `#1a1919` | Dark panels, footer, live counter strip |
| `--ramp-ash` | `#6d6c6b` | Secondary text, labels, captions |
| `--ramp-smoke` | `#d3d3d3` | Subtle surfaces, quiet borders, skeletons |
| `--ramp-hairline` | `#e5e7eb` | Card borders, grid lines, dividers |
| `--ramp-bone` | `#f4f2f0` | Page canvas, hover fills, wash cards |
| `--ramp-paper` | `#ffffff` | Cards, modals, panels, text on dark |

## Usage Rules

- Use `#e4f222` sparingly and only where the user should notice action or money movement.
- Keep brand surfaces mostly black, white, off-white, and grey.
- Use `#1a1919` for inverted areas instead of using `#0c0a08` as a large background.
- Borders should usually be `#e5e7eb`.
- Wash areas can use `#f4f2f0`, especially inside white cards or page bands.
