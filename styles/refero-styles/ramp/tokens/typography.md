# Typography

## Family

```css
font-family: "lausanne", Inter, "IBM Plex Sans", Sohne, Arial, sans-serif;
font-weight: 400;
font-feature-settings: "ss01";
```

## Rules

- Use one font family.
- Use weight `400` everywhere.
- Never use bold or semibold for hierarchy.
- Use size, line height, spacing, and placement for emphasis.
- Keep type left aligned.
- Use uppercase only for micro labels and utility text.

## Scale

| Token | Size | Line Height | Letter Spacing | Use |
| --- | ---: | ---: | ---: | --- |
| `micro` | 10px | 2.2 | 0.018em | Eyebrows, table labels, counter labels |
| `small` | 13px | 1.4 | 0 | Nav, captions, compact links |
| `body` | 16px | 1.5 | 0 | Body copy and forms |
| `body-large` | 18px | 1.45 | 0 | Short intro copy |
| `subheading` | 20px | 1.3 | 0 | Section supporting heads |
| `heading-small` | 24px | 1.17 | 0 | Card and module headings |
| `heading` | 28px | 1.14 | 0 | Section headings |
| `heading-large` | 40px | 1.05 | 0 | Major page headings |
| `display` | 64px | 1.0 | 0 | Hero headline |
