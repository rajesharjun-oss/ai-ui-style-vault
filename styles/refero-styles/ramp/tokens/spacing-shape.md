# Spacing And Shape

## Spacing

| Token | Value | Use |
| --- | ---: | --- |
| `base` | 4px | Underlying spacing unit |
| `xs` | 8px | Tight element gap |
| `sm` | 12px | Compact row gap |
| `md` | 16px | Standard component spacing |
| `lg` | 20px | Card internal padding low end |
| `xl` | 24px | Card internal padding high end |
| `2xl` | 32px | Dense section grouping |
| `3xl` | 40px | Hero/form grouping |
| `4xl` | 48px | Large block rhythm |
| `section` | 64px | Minimum section gap |
| `section-lg` | 128px | Generous editorial band |
| `max-width` | 1200px | Page container |

## Radius

| Token | Value | Use |
| --- | ---: | --- |
| `tag` | 6px | Tags and compact labels |
| `button` | 6px | Primary, outline, and ghost buttons |
| `input` | 10px | Inputs and form controls |
| `wash-card` | 12px | Soft callout blocks |
| `card` | 16px | Product cards, testimonials, panels |

## Shape Rules

- Avoid 4px radius.
- Avoid fully rounded pill geometry.
- Keep buttons rectangular and crisp.
- Let hairline borders define structure.
