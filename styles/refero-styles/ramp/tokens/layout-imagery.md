# Layout And Imagery

## Layout

- Use a 1200px max-width container centered in full-bleed bands.
- Keep headings and copy left aligned.
- Build a large hero with text and product UI, not a marketing split card.
- Let the product screenshot carry the visual interest.
- Use generous light sections interrupted by a dark full-width metric strip.
- Use two-column feature sections on desktop.
- Use stacked single-column sections on mobile.
- Keep content rhythm editorial: clear starts, clean whitespace, and thin dividers.

## Imagery

Use:

- Product screenshots.
- Browser window frames.
- Card, expense, accounting, and finance dashboard UI.
- Grayscale customer logos.
- Dark UI screenshot moments inside an Obsidian section.

Avoid:

- Illustration systems.
- Stock photos.
- Decorative gradients.
- Abstract blobs.
- Extra-color chart palettes unless data truly requires them.
