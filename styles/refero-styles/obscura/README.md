## Style Summary

Obscura is an 8-bit arcade interface floating on soft cloud paper. It uses Jersey 10 pixel typography for display moments, Manrope for readable product copy, Cloud Mist as the full-page sky canvas, and one loud Signal Orange CTA color. Pixel clouds, mascot details, soft blue-tinted card shadows, and rounded app mockups keep the mood playful rather than fortress-like.

Use this style when an AI needs a light SaaS or privacy product page that feels approachable, game-like, and friendly without losing functional clarity.

## What To Borrow

- Cloud Mist `#e3f1fe` as the full-bleed page canvas.
- Signal Orange `#ff5e24` as the single loud action and emphasis color.
- Jersey 10 for display headings at 36px and above only.
- Manrope for body copy, buttons, nav, links, and UI text.
- Pixel cloud sprites as section dividers and corner accents.
- Feature cards with white surface, 12px radius, 16px padding, blue-tinted border and shadow.
- App-window mockups with traffic-light dots and soft rounded frames.
- A dark Ember Crust footer as the only dark surface.

## Avoid

- Using Jersey 10 for body text or nav labels.
- Adding a second brand color.
- Turning Cloud Mist into a tiny accent instead of the full canvas.
- Using orange as a large page background.
- Sharp brutalist cards.
- Overly serious security visuals.
- Smooth vector cloud illustrations.
