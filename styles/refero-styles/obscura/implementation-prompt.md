# AI Implementation Prompt

Build the UI in the Obscura style: a light, playful privacy SaaS page that feels like an 8-bit arcade console floating on cloud paper.

Use Cloud Mist `#e3f1fe` as the full-page background, Paper White `#ffffff` for cards, Graphite Ink `#232629` for text, and Signal Orange `#ff5e24` as the only vivid accent. The mood should be privacy-as-playfulness, not privacy-as-fortress.

Core rules:

- Use Jersey 10 only for display headings at 36px and above.
- Use Manrope Variable for body copy, nav, buttons, labels, and all readable UI.
- Use a centered hero stack: two-line pixel headline, short paragraph, one orange CTA, and optional ghost platform links.
- Use Signal Orange for one primary CTA per screen, link hovers, active nav, and small emphasis.
- Use Cloud Mist as the full-bleed canvas, not just a card fill.
- Use 8px spacing base, 1200px page max width, 48px section gaps, 16px card padding, and 16px element gaps.
- Use 6px radius for interactive controls.
- Use 12px radius for feature cards, 16px for large app cards, 24px for images, and 32px for feature panels.
- Use feature cards with white surface, 1px Cloud Mist border, soft blue-tinted shadow, Jersey heading, Manrope body, and a small pixel illustration.
- Use pixel cloud sprites as decorative dividers and corner accents.
- Use a large centered app-window mockup with traffic-light dots and status pills.
- Use Ember Crust `#6c3200` only for the footer or rare dark brand block.

Avoid Jersey 10 for body text, extra accent colors, huge orange backgrounds, smooth vector clouds, dark fortress security motifs, and generic SaaS gradients.

The result should feel soft, playful, readable, and pixel-branded.
