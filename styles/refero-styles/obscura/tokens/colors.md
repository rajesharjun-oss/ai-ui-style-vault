# Colors

## Palette

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Signal Orange | `#ff5e24` | `--color-signal-orange` | Primary CTA, hero emphasis, active nav, link hover, card accent |
| Ember Crust | `#6c3200` | `--color-ember-crust` | Footer background and rare dark brand block |
| Cloud Mist | `#e3f1fe` | `--color-cloud-mist` | Page canvas, card wash, secondary borders, pixel art fill |
| Graphite Ink | `#232629` | `--color-graphite-ink` | Primary text, nav links, icon strokes, body copy |
| Paper White | `#ffffff` | `--color-paper-white` | Cards, app chrome, nav background |
| Slate Pencil | `#5c6066` | `--color-slate-pencil` | Secondary text and muted icons |
| Ash Mist | `#989ea4` | `--color-ash-mist` | Tertiary text, placeholders, disabled details |
| Blush Shadow | `#dbced0` | `--color-blush-shadow` | Warm-tinted shadow base |
| Midnight Ink | `#101828` | `--color-midnight-ink` | Strong text and high-contrast CTA text |

## Color Behavior

Obscura uses one true accent: Signal Orange. Cloud Mist is atmosphere, not a blue accent system.

Use Signal Orange for:

- Primary CTA fill.
- One hero emphasis phrase.
- Link hover underline.
- Active nav state.
- Card accent borders.
- Status pill fill.

Use Cloud Mist for:

- Page canvas.
- Pixel cloud sprites.
- Card borders.
- Secondary button borders.
- Active sidebar backgrounds inside app mockups.

Use Ember Crust for:

- Footer only.
- Rare dark brand block.

## Forbidden Color Moves

- No second vivid accent.
- No large orange page fills.
- No dark fortress security palette.
- No generic gradient hero.
- No full-color sprite palette beyond the defined colors.
