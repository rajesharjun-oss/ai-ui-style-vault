# Guidelines

## Do

- Use Jersey 10 for every display heading at 36px and above.
- Keep one Signal Orange filled CTA per screen.
- Let Cloud Mist be the full-bleed page atmosphere.
- Use Manrope for all readable UI and body copy.
- Use 6px radius on interactive elements.
- Reserve 12px or more for cards and app mockups.
- Place 1-2 pixel cloud sprites in section corners.
- Use soft blue-tinted shadows for floating cards.
- Apply orange-ring inset shadow only to active nav or focused primary actions.

## Do Not

- Do not use Jersey 10 for body text, button labels, or nav links.
- Do not introduce a second brand color.
- Do not treat Cloud Mist as a blue accent.
- Do not apply Signal Orange to large background fills.
- Do not use smooth vector clouds.
- Do not use dark fortress-style security visuals.
- Do not add hard horizontal dividers where cloud sprites can separate sections.

## Implementation Priorities

1. Set the Cloud Mist page canvas.
2. Build a centered hero with Jersey 10 display type.
3. Add one filled Signal Orange CTA.
4. Place pixel cloud sprites around hero and section gaps.
5. Build feature cards with Paper White, 12px radius, and soft shadow.
6. Add a large app-window mockup.
7. End with an Ember Crust footer.

## Common Failure Modes

- The design becomes unreadable when Jersey 10 is used for small UI.
- It loses personality without pixel sprites.
- It becomes generic SaaS if the Cloud Mist canvas is replaced by white.
- It becomes noisy if orange appears everywhere.
