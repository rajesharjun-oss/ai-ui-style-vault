# Layout And Imagery

## Page Structure

1. Top nav with logo, centered links, and account cluster.
2. Centered hero on Cloud Mist.
3. Pixel cloud cluster divider.
4. Large app-window mockup.
5. Feature sections alternating between text and card/mockup.
6. Two- or three-column feature card grids.
7. Final CTA band.
8. Ember Crust footer.

## Grid

- Max width: 1200px.
- Hero: single-column centered.
- Feature explanations: 2-column text plus card.
- Card grids: 2 or 3 columns desktop.
- Mobile: single-column stack.

## Pixel Art Direction

Use:

- 16x16 or 32x32 base pixel grids.
- Flat fills.
- 1px darker outline.
- No anti-aliasing.
- Pixel clouds, small pixel cat or robot, tiny status icons.

Avoid:

- Smooth vector clouds.
- 3D mascots.
- Gradient sprites.
- Over-detailed pixel scenes.

## Composition

Let the clouds act as dividers. Keep the hero simple: headline, short copy, CTA, and platform options. Save most complexity for the product mockup and feature cards.
