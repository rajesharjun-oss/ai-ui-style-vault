# Components

## Primary CTA Button

- Background: `#ff5e24`.
- Text: `#101828` or white depending on contrast context.
- Font: Manrope 500, 16px.
- Radius: 6px.
- Padding: 8px 16px for compact, 16px 32px for large.
- Icon: optional white or dark arrow to the right.
- Shadow: orange-tinted inset plus 1px orange outer ring.

Use this filled treatment for the main CTA. Do not outline the primary action.

## Secondary Outlined Button

- Background: transparent.
- Border: 1px solid `#e3f1fe`.
- Text: `#232629`.
- Font: Manrope 500, 16px.
- Radius: 6px.
- Shadow: soft Cloud Mist outer shadow.

## Ghost Text Link

- Background: none.
- Border: none.
- Text: Graphite Ink.
- Font: Manrope 500, 14-16px.
- Hover: Signal Orange underline.
- Active: orange text plus 1px orange inset ring shadow.

## Hero Section

- Background: Cloud Mist.
- Layout: centered stack.
- Headline: Jersey 10, 96px desktop, two lines.
- Headline color: first line Graphite Ink, second line Signal Orange.
- Body: Manrope 400, 16px, Slate Pencil, max width around 560px.
- CTA: centered primary orange button.
- Decoration: pixel cloud sprites drifting near edges.

## Feature Card

- Background: Paper White.
- Border: 1px solid Cloud Mist.
- Radius: 12px.
- Padding: 16px.
- Shadow: soft blue-tinted stack.
- Heading: Jersey 10, 36-48px, Graphite Ink.
- Body: Manrope 400, 16px, Slate Pencil.
- Illustration: 40-60px pixel icon above the heading.

## App Window Mockup

- Radius: 12-16px.
- Background: Paper White.
- Header: macOS-style red, yellow, green traffic-light dots.
- Sidebar: active item gets Cloud Mist pill background.
- Main panel: white status card.
- Status: connected pill in Signal Orange with small check icon.
- Disconnect: ghost button in pale red or pink.

## Status Pill

- Font: Manrope 500, 14px.
- Radius: 6px.
- Padding: 6px 12px.
- Connected: Signal Orange fill, white or dark text depending on contrast.
- Disconnected: soft coral/pink fill with dark text.
- Icon: small check or cross at left.

## Pixel Cloud Sprite

- Style: hand-authored 8-bit pixel art.
- Base grid: 16x16 or 32x32.
- Colors: Cloud Mist, Paper White, Slate Pencil outline.
- Outline: 1px darker tone.
- Anti-aliasing: forbidden.
- Placement: 2-3 sprites per section, off-center, drifting into corners.

## Navigation Bar

- Background: transparent or Paper White.
- Border: none.
- Logo: lowercase Manrope 700 in Graphite Ink.
- Links: Manrope 500, 14px.
- Right cluster: ghost account link plus orange CTA.
- Active nav: orange inset ring.
- Sticky shadow: none.

## Footer Block

- Background: Ember Crust.
- Text: white and warm cream.
- Font: Manrope 400-500, 14px.
- Padding: 48px top and bottom.
- Full width.
