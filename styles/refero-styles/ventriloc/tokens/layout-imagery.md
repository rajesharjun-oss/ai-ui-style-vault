# Layout And Imagery

## Layout

- Use a centered 1200px max-width container.
- Use 80px section gaps.
- Hero: two-column split with headline and CTAs left, overlapping dashboard cards right.
- Header: brand left, centered floating pill nav, dark contact button right.
- Sections alternate Canvas White and Ash.
- Use tall, spacious report-like layouts rather than dense dashboards.

## Imagery

- Treat charts and data widgets as imagery.
- Use line graphs, stat cards, circular progress rings, and dashboard cards.
- Use Ember Orange and Brass only for thin chart strokes and tiny data accents.
- Use partner logos in monochrome Graphite.
- Avoid lifestyle photography, stock photos, and decorative hero illustrations.
- Use monoline Graphite icons sparingly.

## Composition Rules

- Let whitespace and surface bands carry hierarchy.
- Use orange as a tiny functional signal.
- Keep data cards flat and precise.
- Do not over-decorate empty space.
- Increase spacing before adding new visual elements.
