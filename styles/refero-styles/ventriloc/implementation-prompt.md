# Implementation Prompt - Ventriloc Style

Build an original UI using the Ventriloc Refero style as visual direction.

Create a warm, report-like data product interface. Use a white paper canvas, warm-gray section bands, flat dashboard cards, precise typography, and only one orange accent used as punctuation. The page should feel like an editorial data observatory, not a colorful generic SaaS page.

## Must Preserve

- Graphite `#202020` as the main text and button color.
- Canvas White `#ffffff` and Ash `#efefef` as the main surfaces.
- Ember Orange `#ff682c` only for link underlines, chart highlights, and small accents.
- Brass `#816729` only as muted secondary chart/caption accent.
- PolySans-style headings at weight 400 only.
- Inter body/UI text at weights 400, 500, and 600.
- Display headline around 66px with 0.91 line-height and tight tracking.
- 0px square buttons.
- 200px pill nav.
- `6px 0px 0px` asymmetric featured cards.
- 20px rounded data widgets.
- No shadows; use surface contrast and whitespace.
- 80px section gaps and 20px element gaps.

## Avoid

- Copying Ventriloc logos, exact dashboards, chart data, screenshots, page copy, or proprietary layouts.
- Orange filled CTA buttons.
- Bold PolySans-style headings.
- Extra accent colors like blue, green, or purple.
- Symmetric rounding on all cards.
- Box shadows, glows, gradients, or glass effects.
- Crowded dashboard density.

## Component Direction

Start with a two-column hero: precise headline and square CTAs on the left, flat overlapping data cards on the right. Use surface bands and sparse chart widgets to tell the story. Let orange appear only in tiny, functional highlights.
