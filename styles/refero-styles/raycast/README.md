# Raycast

AI-ready Refero style bundle for a dark developer power-tool interface: near-black canvas, Inter typography, neutral download CTAs, restrained coral brand accents, glass navigation, and tactile "keyboard key" inset card treatments.

## Source

- Refero style: https://styles.refero.design/style/3b6a17f0-3bdf-418c-a95e-0b89e5a8b2f8
- Reference site: https://raycast.com
- Captured: 2026-07-28
- Theme: dark

## Use This When

- You need a polished productivity, launcher, command palette, devtool, AI assistant, extension marketplace, or Mac-native product surface.
- The UI should feel powerful and minimal without becoming cold enterprise software.
- You want a dark product site with one warm brand accent and neutral CTAs.

## Bundle Contents

- `DESIGN.md` - complete AI style reference.
- `implementation-prompt.md` - drop-in prompt for an AI implementation agent.
- `style.json` - structured metadata and searchable summary.
- `tokens/` - colors, typography, spacing, components, guidelines, layout, and imagery.
- `code/` - CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` - screenshot capture notes.

## Implementation Notes

Use this as an inspiration reference, not as an official Raycast brand kit. Do not copy logos, proprietary screenshots, app UI, icons, copy, or original artwork unless you have rights to use them.
