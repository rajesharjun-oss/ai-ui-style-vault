| Element | Value | Token |
| --- | --- | --- |
| badges | 6px | `--radius-badges` |
| inputs | 8px | `--radius-inputs` |
| buttons | 8px | `--radius-buttons` |
| cards | 16px | `--radius-cards` |
| large cards | 20px | `--radius-large-cards` |
| pills | 9999px | `--radius-pills` |
| icon containers | 99999px | `--radius-icon-containers` |

## Shape Rules

- Buttons, inputs, and badges use the compact 8px control family.
- Cards use 16px or 20px radius.
- Pills and circular icon containers can be fully rounded.
- Keep spacing snapped to 8/12/16/24/40 style intervals.
