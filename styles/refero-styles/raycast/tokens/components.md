# Components

## Glass Navigation Bar

Floating pill navigation with 8px radius, 1px `#363739` border, transparent dark fill, and backdrop blur around 48px. Use white brand text, Ash nav links, and a neutral Mist download button.

## Neutral Filled Button

Mist `#e6e6e6` fill, Iron `#454647` text, Inter 13-14px medium, 8px radius, 8px 12px padding, optional small platform icon, and no chromatic fill.

## Ghost Nav Link

Transparent link with Ash text at 13-14px. Hover to white. No separate border, fill, or rounded container.

## Feature Card With Key Shadow

16px radius, 24px padding, dark/transparent surface, and the key-shadow inset stack. Use for features, extension highlights, and showcase blocks.

## Edge-Highlight Card

16-20px radius, transparent fill, 1px `#363739` edge, and inset highlight. Use for hover or featured variants.

## Inset Input Field

8px radius with subtle white-tinted fill. Use white typed text and Ash placeholder text. It should read as a recessed well.

## Badge Tag

Graphite fill, white text, 6px radius, and compact horizontal padding. Use for versions, beta labels, and categories.

## Circular Icon Container

Full-circle icon backing with dark fill and 20px padding. Use 24-32px glyphs or product icons inside.

## Hero Gradient Banner

Full-bleed dark hero with centered headline and dramatic red/blue abstract geometry. This is the loud visual exception; the rest of the page returns to dark restraint.

## Footer Meta Strip

Centered Geist Mono 12px row in Smoke with pipe-separated version, platform, and install metadata.

## App Window Mockup

Dark app UI mockup with command bar, result list, extension icons, rounded frame, and a tiny coral selection highlight.
