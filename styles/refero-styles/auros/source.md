## What To Preserve

Auros reads as a market infrastructure interface: mostly black, compact, numerical, and terminal-like, but with controlled cyan, blue, green, and violet glow to create a live-trading feel. Its strongest cues are pill controls, glassy dashboard panels, ticker rails, orbital/network imagery, and dense market-data rows.

## What To Avoid Copying

Do not copy the original logo, exact site layout, exact marketing copy, or screenshot composition. Use the tokens and behavior patterns to create new screens that feel related: trading dashboards, API docs, risk views, exchange/liquidity cards, and infrastructure status panels.

## Build Context

This bundle is meant for AI-assisted UI implementation. Use the markdown files for product/design intent, and use the `code/` files for direct token import when building with CSS variables or Tailwind v4.
