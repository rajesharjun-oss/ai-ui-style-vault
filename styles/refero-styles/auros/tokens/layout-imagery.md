# Layout And Imagery

## Layout Patterns

- Full-bleed black hero with a constrained 1280px content grid.
- Oversized hero type paired with a floating terminal or dashboard artifact.
- Glass panels arranged as dashboard clusters: metrics, chart, order book, status stream.
- Pill nav and CTA group near the top of the screen.
- Horizontal ticker rail for live markets, volumes, spreads, exchange names, or status labels.
- Dense table sections with mono numerics and subtle row hover.
- Split information bands where text is short and product UI carries the weight.

## Imagery

- Use abstract infrastructure imagery: glowing global maps, orbital rings, market networks, data trails, chart lines, and particle fields.
- Keep imagery dark and functional; it should support the trading-command mood.
- If using product screenshots, frame them as terminal panels or dashboard tiles.
- Avoid bright stock photography, lifestyle scenes, and generic corporate illustration.

## Responsive Notes

- On mobile, keep hero text large but clamp it, move dashboard panels into a vertical stack, and preserve ticker rails as horizontally scrollable elements.
- Keep table rows compact; avoid turning dense market data into oversized cards unless the screen is very narrow.
- Preserve clear positive/negative color semantics on every breakpoint.
