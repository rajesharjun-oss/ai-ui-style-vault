# Auros Style Reference

## Creative Direction

Build an abyss-black trading command deck with refractive cyan and blue data light. The interface should feel institutional and technical rather than consumer SaaS: compact labels, mono numerics, market rows, glass panels, and glowing live indicators.

## Visual Priorities

1. Start with near-black page surfaces.
2. Use blue for primary action and focused state.
3. Use cyan for secondary glow, hover, chart pulse, and infrastructure traces.
4. Use green only for live/gain/liquidity meaning.
5. Use red only for risk/loss/sell pressure.
6. Use violet as an atmospheric depth layer, not as a normal UI accent.
7. Keep cards transparent or dark graphite, with thin borders and deep shadows.
8. Keep data dense and readable; this style should feel like a financial terminal, not a spacious marketing page.

## Screen Composition

Use full-bleed dark sections with a constrained 1280px content width. Hero screens should mix oversized tight display text with a floating terminal/dashboard artifact, ticker rail, metric cards, or luminous network/map. Product sections should be built as bands of dashboards, table rows, market cards, API panels, and status modules.

## Material Language

Use translucent panels over glow, thin gridline borders, rounded cards at 18px to 28px, and pill controls at 999px. Use blur sparingly for navigation, hero panels, ticker rails, and modal-like trading surfaces.

## AI Implementation Notes

When generating a UI from this style, ask the model to implement the structure first: header, hero, market panel, ticker rail, data table, status cards, and chart area. Then apply tokens. The style is strongest when glow is attached to meaningful data or focal elements instead of used as decoration everywhere.
