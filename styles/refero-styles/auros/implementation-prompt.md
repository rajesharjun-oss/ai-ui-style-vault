# Implementation Prompt

Create an original dark fintech/trading interface inspired by the Auros Refero style.

Use a near-black abyss canvas with glassy dashboard panels, pill CTAs, market ticker rails, compact metric cards, dense data tables, and subtle orbital/network imagery. Use Satoshi for headings and interface copy, and Space Mono for tickers, numerics, terminal labels, and data rows.

Apply this hierarchy:

- Background: `#02030a` and `#07080f`
- Cards/panels: `#0d111a` and `#151824`
- Borders/gridlines: `#2b3040` with low alpha
- Primary action: `#0066ff`
- Secondary glow: `#00d8ff`
- Positive/live state: `#39ff88`
- Risk/loss state: `#ff4d6d`
- Premium/metric highlight: `#ffd166`
- Atmospheric depth: `#7c3cff`

Keep the layout information-dense but calm. Use thin dividers, muted labels, mono numbers, small uppercase captions, and tight chart/tool panels. Place blue/cyan/violet light as beams, halos, nodes, and data trails rather than as a full page background.

Do not copy Auros brand assets, exact screenshots, exact page sections, or marketing text. Generate a new product screen that only borrows the token logic and mood.
