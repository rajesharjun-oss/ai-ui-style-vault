# Implementation Prompt

Use the AREA 17 style language for this UI.

Create a monochrome editorial agency interface: pure white canvas, Graphite text, Suisse Intl typography, flat surfaces, hairline borders, left-aligned oversized type, and one electric yellow signal. The UI should feel confident enough to leave space empty.

Core rules:

- Use `#ffffff` as the page canvas.
- Use `#1a1a1a` for main text, headlines, nav links, and most UI.
- Use `#e6e6e6` for every border and divider.
- Use `#f2f2f2` for quiet secondary card surfaces.
- Use `#f2ede9` only for occasional warm editorial cards.
- Use `#fdf313` only as a single accent, usually a bottom announcement bar.
- Do not introduce other chromatic colors.
- Use Suisse Intl if available; otherwise use Inter, Sohne, GT America, or Manrope.
- Set display headlines at 55px, 1.10 line-height, and tight negative tracking.
- Left-align headlines and body copy.
- Use 8px radius for cards, buttons, inputs, and images.
- Use 4px radius only for nav details.
- Use 9999px radius only for rare pills or tags.
- Use no shadows, glows, blur effects, or glossy depth.

Recommended structure:

- Minimal top nav with mark on the left and text links on the right.
- Large left-aligned editorial headline with generous top spacing.
- Ghost links and outlined buttons instead of loud CTAs.
- Full-bleed cinematic video or photography block after the headline.
- Sparse editorial sections with 80px to 192px vertical gaps.
- Occasional Fog or Cream Stone cards for quiet content grouping.
- Fixed bottom Electric Yellow announcement bar as the sole color strike.

Avoid:

- Centered SaaS-style hero layouts.
- Colorful agency gradients.
- Heavy card grids.
- Drop shadows.
- Rounded 16px+ cards.
- Decorative icons and stock illustrations.
- More than one yellow accent at a time.

The result should feel like an agency portfolio built from type, whitespace, hairlines, and a single bright interruption.
