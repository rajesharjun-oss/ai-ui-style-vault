# Colors

| Name | Hex | Use |
| --- | --- | --- |
| Pure White | `#ffffff` | Page canvas, input fields, inverse text on dark surfaces |
| Graphite | `#1a1a1a` | Primary text, headlines, body copy, navigation links |
| True Black | `#000000` | Logo mark fill, select borders, deepest shadow tone if needed |
| Hairline | `#e6e6e6` | Borders, dividers, outlined control strokes, card edges |
| Fog | `#f2f2f2` | Secondary card surfaces, disabled button fills, quiet elevation layers |
| Cream Stone | `#f2ede9` | Warm editorial feature-card surface |
| Muted | `#949494` | Secondary links, metadata, subdued captions |
| Dim | `#757575` | Tertiary text, low-priority helper copy |
| Disabled | `#cccccc` | Disabled controls and inactive fills |
| Electric Yellow | `#fdf313` | Announcement bar and the only chromatic accent in the system |

## Palette Rules

- Keep the entire UI monochrome except Electric Yellow.
- Use Electric Yellow as a singular signal, not general decoration.
- Use Hairline for borders and dividers.
- Use Fog and Cream Stone for flat surface shifts instead of shadows.
- Do not add other accent colors.
