# Colors

## Palette

| Name | Value | Token | Role |
|---|---:|---|---|
| Nero | `#000000` | `--color-nero` | Page canvas, hero overlay, nav, footer, primary product surfaces |
| Bianco | `#ffffff` | `--color-bianco` | Text on dark surfaces, light section background, outline strokes |
| Giallo | `#ffc700` | `--color-giallo` | Primary CTA, active state, small icon accent, brand punctuation |
| Concrete | `#f2f2f2` | `--color-concrete` | Light gray editorial panel and feature background |
| Silver | `#b0b0b0` | `--color-silver` | Secondary captions, inactive nav, muted metadata |
| Graphite | `#4d4d4d` | `--color-graphite` | Dividers, disabled controls, subtle icon strokes |

## Usage

- Start dark: the dominant surface is Nero.
- Use Bianco for high-contrast text and sharp section reversals.
- Use Giallo sparingly. It should feel like ignition, not decoration.
- Use Silver for captions and secondary labels, especially on black.
- Use Graphite for dividers and inactive UI states.
- Keep the palette disciplined. Do not add playful or pastel support colors.
