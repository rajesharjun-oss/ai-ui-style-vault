# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Base unit | `4px` |
| Density | `compact` |
| Page max width | `1440px` for contained editorial blocks |
| Section gap | `80px` to `120px` |
| Card or panel padding | `20px` to `32px` |
| Element gap | `8px` to `16px` |
| Hero height | `80vh` to `100vh` |
| Navigation height | `80px` |

## Spacing Tokens

Use `4`, `8`, `10`, `12`, `16`, `20`, `24`, `28`, `32`, `40`, `48`, `52`, `56`, `60`, `64`, `80`, `100`, `110`, `120`, and `140`.

## Radius

| Element | Radius |
|---|---:|
| Navigation | `0px` |
| Buttons | `0px` |
| Cards | `0px` |
| Images | `0px` |
| Inputs | `0px` |
| Toggles | `0px` |
| Sections | `0px` |

## Shape Rules

- Everything is rectangular and exact.
- Do not use pills, rounded cards, soft modals, circular CTAs, or large border radii.
- Use divider lines and section boundaries instead of shadows.
- Keep grids hard-edged and aligned.
