# Typography

## Font Stack

- Primary: `LamboType`
- Fallback: `Arial Narrow`, `Inter Condensed`, `Helvetica Neue Condensed`, `Arial`, `sans-serif`
- Weights: `300`, `400`, `700`
- UI casing: uppercase

## Scale

| Purpose | Size | Line height | Weight | Tracking | Token |
|---|---:|---:|---:|---:|---|
| Caption | `13px` | `1.4` | `400` | `0.04em` | `--text-caption` |
| Body small | `14px` | `1.4` | `400` | `0.05em` for UI | `--text-body-sm` |
| Body | `16px` | `1.5` | `400` | `0` | `--text-body` |
| Subheading | `20px` | `1.2` | `400` | `0` | `--text-subheading` |
| Heading small | `24px` | `1.17` | `400` or `700` | `0` | `--text-heading-sm` |
| Heading | `32px` | `1.13` | `700` | `0.01em` | `--text-heading` |
| Heading large | `64px` | `1` | `300` or `700` | `0.01em` | `--text-heading-lg` |
| Display | `80px` | `1` | `700` | `0.01em` | `--text-display` |

## Rules

- Use uppercase for nav labels, CTA labels, specs, categories, and model names.
- Use large condensed display type for vehicle names and hero statements.
- Use Silver captions to separate metadata from primary copy.
- Avoid friendly rounded typefaces, bubbly weights, and decorative serif display text.
- Keep long paragraphs rare; this style favors sharp product statements and technical labels.
