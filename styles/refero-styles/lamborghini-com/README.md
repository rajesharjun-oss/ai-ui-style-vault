# Lamborghini.com

AI-ready Refero style bundle for Lamborghini.com.

- Source: https://styles.refero.design/style/c9c5be5a-aaa1-4338-9681-8378d2e24fbd
- Reference site: https://www.lamborghini.com
- Captured: 2026-07-28
- Theme: dark
- Mood: black showroom with giallo shock
- Industry: automotive, luxury, performance cars

## Use This Style For

- Luxury automotive, motorsport, performance hardware, and premium product launches
- Sites that need full-bleed product photography or video as the main design event
- Sharp, dramatic interfaces with black, white, and one disciplined accent color
- Product configurators, model landing pages, event pages, and editorial brand stories

## Files

- `source.md` records the source URL and capture context.
- `DESIGN.md` is the main human-readable design reference.
- `implementation-prompt.md` is a direct prompt for an AI coding agent.
- `style.json` is a structured summary for indexing and retrieval.
- `tokens/` contains focused notes for colors, type, spacing, components, guidelines, layout, and imagery.
- `code/` contains CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` reserves the screenshot slot for manual or automated captures.

## Core Signature

Lamborghini.com is hard-edged automotive theater: pure black, white, one yellow action color, all-caps condensed type, zero radius, no soft decoration, and full-bleed car imagery that carries the emotional load.
