# Portal

Portal is a light editorial-iOS style system: a twilight gradient hero, paper-white content sections, retro serif headlines, crisp Inter UI text, one iOS-blue functional accent, and rounded cards lifted by pale glow rings instead of heavy shadows.

- Source: https://styles.refero.design/style/b9aeb945-2f6e-4557-9115-e3ff3a8f8dc8
- Reference site: https://useportal.net
- Captured: 2026-07-28
- Theme: light
- Best for: client portals, lightweight SaaS, project dashboards, premium productivity tools, editorial product pages

## Use This When Building

Open with one atmospheric dusk gradient hero, then drop into quiet light sections on `#f7f7f7`. Use Perfectly Nineties-style serif headlines at 36-48px only, Inter for every UI element, and Signal Blue only for actions, active states, links, and small product highlights. Keep cards and mockups rounded, white, and softly outlined.
