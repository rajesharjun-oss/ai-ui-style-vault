# Components

## Hero Pill Button

- Role: primary CTA on the gradient hero
- Radius: 50px
- Background: `#ffffff`
- Text: `#000000`
- Font: Inter, 14px to 16px, weight 600
- Padding: 14px 24px
- Border: none
- Use as the most visible hero action.

## Ghost Pill Button

- Role: secondary CTA or cancel action
- Radius: 50px
- Background: transparent
- Border: 1.5px solid `#000000`
- Text: `#000000`
- Font: Inter, 14px to 16px, weight 500
- Padding: 12px 22px
- Never fill it with a secondary accent.

## Floating Nav Capsule

- Background: `#ffffff`
- Radius: 22px
- Border: 1px solid transparent or pale ring
- Elevation: 5px Ash Mist glow ring
- Padding: 8px 16px
- Top margin: 16px to 24px
- Brand mark left, nav links right.
- Nav links: Inter 14px, weight 500, black.

## Device Mockup Card

- Outer background: `#ffffff`
- Radius: 22px to 30px
- Elevation: 5px Ash Mist glow ring
- Inner screen radius: about 16px
- Place it partly overlapping the bottom of the hero.

## Editorial Content Block

- Reading width: 640px to 720px
- Heading: Perfectly Nineties 36px, weight 400, line-height 1
- Body: Inter 16px, weight 400, Graphite, line-height 1.35
- Paragraph gap: 16px to 20px
- Section gap: 80px to 120px

## Brand Mark Icon

- Circular icon with blue-to-violet gradient.
- White paper-plane or forward-arrow glyph inside.
- Pair with Portal wordmark in Inter 18px weight 600.
- Icon-to-text gap: 8px.

## Project Card

- Background: `#ffffff`
- Radius: 16px to 22px
- Border or glow: pale Ash Mist
- Padding: 20px
- Title: Inter 16px, weight 600
- Metadata: Inter 14px, Smoke
- Status badges below.

## Status Badge

- Radius: 50px
- Font: Inter 12px, weight 500
- Padding: 4px 10px
- Neutral: Ash Mist background
- Active: Signal Blue tint or Signal Blue text

## Nav Link Item

- Font: Inter 14px, weight 500
- Text: `#000000`
- Padding: 4px 8px
- No underline.
- Hover: opacity around 0.6.

## Soft Glow Ring

- Use `0 0 0 5px #f7f7f7`.
- Apply to cards, mockups, nav capsule, and floating product images.
- Treat it as elevation replacement, not decoration.

## Hero Gradient Background

- Full-bleed section.
- Use the vertical dusk gradient.
- Add dark landscape or horizon silhouettes along the bottom 15-20% if useful.
- Keep this as the only atmospheric surface.
