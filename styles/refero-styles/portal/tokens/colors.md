# Colors

## Core Palette

| Name | Value | Use |
|---|---:|---|
| Signal Blue | `#007aff` | CTAs, active states, brand icon highlights, inline links, product UI status moments |
| Ink Black | `#000000` | Headings, primary borders, button text |
| Graphite | `#3e3e3e` | Body text and softer sustained reading |
| Smoke | `#636363` | Muted helper text, metadata, subtle borders |
| Paper White | `#ffffff` | Cards, nav capsule, mockup frames, white button fills |
| Ash Mist | `#f7f7f7` | Page canvas, pale glow rings, soft elevation halos |

## Hero Gradient

```css
linear-gradient(180deg, #4a7ff2 0%, #7b7ed8 30%, #c98ab5 65%, #e8a87c 100%)
```

| Stop | Value | Role |
|---|---:|---|
| Hero Blue | `#4a7ff2` | Sky-blue top of gradient |
| Hero Violet | `#7b7ed8` | Violet middle band |
| Hero Mauve | `#c98ab5` | Warm mauve descent |
| Hero Coral | `#e8a87c` | Warm sunset base |

## Rules

- Use exactly one chromatic accent: Signal Blue.
- Use the gradient only for the hero atmosphere.
- Keep content sections on Ash Mist with Paper White cards.
- Do not use black text directly on gradient surfaces.
- Do not use Signal Blue for large decorative fills.
- Do not introduce a second accent color.
