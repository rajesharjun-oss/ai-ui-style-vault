# Typography

## Display Serif

- Family: Perfectly Nineties Regular
- Substitute: Playfair Display, DM Serif Display, or Recoleta
- Weight: 400
- Sizes: 36px and 48px
- Line-height: 1
- Letter spacing: normal
- Use for H1 and H2 only.

The serif is the personality anchor. Do not use it for body text, labels, buttons, captions, or product UI.

## UI Sans

- Family: Inter
- Substitute: SF Pro Text, system UI, or Helvetica Neue
- Weights: 400, 500, 600
- Sizes: 10px, 12px, 14px, 16px, 18px
- Line-height: 1.2 to 1.35
- Letter spacing: about -0.02em
- Use for body, nav, buttons, labels, links, badges, metadata, and product UI.

## Type Scale

| Token | Size | Weight | Line Height | Tracking | Use |
|---|---:|---:|---:|---:|---|
| `micro` | 10px | 400-500 | 1.2 | -0.2px | tiny UI metadata |
| `caption` | 12px | 400-500 | 1.2 | -0.24px | captions and badges |
| `body-sm` | 14px | 400 | 1.3 | -0.28px | small body and labels |
| `body` | 16px | 400 | 1.35 | -0.32px | body copy |
| `heading-sm` | 18px | 500-600 | 1.35 | -0.36px | compact UI heading |
| `heading` | 36px | 400 | 1 | 0 | serif H2 |
| `display` | 48px | 400 | 1 | 0 | serif hero headline |

## Rules

- Keep body text at 14px or 16px.
- Do not exceed weight 600 in Inter.
- Do not use the serif below 36px.
- Keep UI text slightly tight for a native app feel.
