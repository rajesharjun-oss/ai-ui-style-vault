# Implementation Prompt

Build a premium light client-portal or productivity interface in the Portal style.

Start with a full-bleed twilight gradient hero using sky blue, violet, mauve, and warm coral. Add a floating white nav capsule near the top, with a gradient circular logo mark, small Inter nav links, and a soft pale glow ring. Place a rounded device or product mockup overlapping the bottom of the hero.

After the hero, use an Ash Mist `#f7f7f7` page canvas with white cards. Give cards and images generous radii: 22-30px for cards and 30-40px for images. Use a pale `#f7f7f7` glow ring as the main depth language rather than normal drop shadows.

Use Perfectly Nineties or a similar retro editorial serif for display headings only at 36-48px, weight 400, line-height 1. Use Inter for body, nav, buttons, labels, badges, metadata, and product UI. Body text should be 14-16px, line-height 1.30-1.35, letter-spacing about -0.02em.

Use Signal Blue `#007aff` only for functional accents: primary actions, active states, inline links, brand icon highlights, and product UI status moments. Do not introduce a second accent color. Do not use Signal Blue for large surface fills.

Avoid heavy shadows, sharp card corners, body text below 14px, black text directly on gradient areas, decorative blue backgrounds, and dense multi-column marketing grids. The result should feel like a soft native iOS app wrapped in an editorial landing page.
