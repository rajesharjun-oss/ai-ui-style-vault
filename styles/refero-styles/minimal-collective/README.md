# Minimal Collective

AI-ready Refero style bundle for Minimal Collective.

- Source: https://styles.refero.design/style/94c15607-2f19-4dc4-9aec-2b40f28b754f
- Reference site: https://minimalcollective.digital
- Captured: 2026-07-28
- Theme: dark
- Mood: stark editorial black with gallery restraint
- Industry: design studio, creative agency, digital portfolio

## Use This Style For

- Design studios, creative agencies, art direction portfolios, and editorial microsites
- Interfaces that need restraint, confidence, and gallery-like black space
- Portfolio pages where photography, typography, and negative space are the main materials
- Brand systems that should feel minimal, severe, and curated rather than friendly or colorful

## Files

- `source.md` records the source URL and capture context.
- `DESIGN.md` is the main human-readable design reference.
- `implementation-prompt.md` is a direct prompt for an AI coding agent.
- `style.json` is a structured summary for indexing and retrieval.
- `tokens/` contains focused notes for colors, type, spacing, components, guidelines, layout, and imagery.
- `code/` contains CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` reserves the screenshot slot for manual or automated captures.

## Core Signature

Minimal Collective is a black-gallery editorial system: pure black canvas, white text, one muted gray, PolySans in a single weight, extreme display scale, crisp hairlines, ghost pills, overlapping photography, and no color accent at all.
