# AI Implementation Prompt

Build a stark black editorial portfolio interface inspired by Minimal Collective.

Use a strict dark gallery system with pure black canvas, white typography, one muted gray, PolySans regular, oversized display type, hairline borders, ghost pills, and overlapping photography. The interface should feel severe, composed, and art-directed.

Requirements:

- Use only black, white, and muted gray. Do not add any chromatic accent.
- Use PolySans if licensed. Otherwise use Suisse Int'l, Neue Haas Grotesk, Inter, Arial, or a clean geometric sans.
- Use only regular font weight unless a fallback requires subtle compensation.
- Create hierarchy through scale, tracking, whitespace, and image placement.
- Use huge display typography at 96px to 180px on desktop with tight negative tracking.
- Use small uppercase nav, labels, and metadata with wide letter spacing.
- Use thin white or gray hairline dividers instead of shadows.
- Use ghost pill buttons only: transparent fill, white border, white text.
- Use square editorial photography, overlapping image stacks, and sparse captions.
- Avoid color CTAs, gradients, soft shadows, glassmorphism, illustrated icons, rounded cards, and dense dashboard layouts.

Hero recipe:

Create a full black hero with sparse top navigation, a giant white display headline, a small uppercase gray descriptor, a white outlined pill CTA, and one or two overlapping square images. Let the composition breathe and keep the word count low.

Case study recipe:

Use a full-width row with a hairline divider, large white title, muted uppercase category/date, one square image, and a ghost pill link. No card background, no radius, and no shadow.
