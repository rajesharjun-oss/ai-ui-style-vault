# Layout And Imagery

## Layout Model

- Use Black as a continuous page canvas.
- Pin navigation and metadata to edges or corners.
- Use enormous type as the main architecture.
- Let images overlap type or each other with precise alignment.
- Separate work entries with hairline dividers.
- Avoid contained card grids.
- Use whitespace as an active design material.

## Imagery

- Use editorial photography, studio imagery, fashion, art direction, product, or portfolio visuals.
- Favor high contrast and deliberate cropping.
- Use square or hard rectangular crops with no radius.
- Allow overlap, but keep the composition sparse and exact.
- Avoid stock business photos, colorful illustrations, icons, or generic SaaS screenshots.

## Motion

- Motion should be restrained and linear.
- Use fade, sharp reveal, slow image parallax, or precise text slide.
- Avoid bouncy easing, playful hover tricks, and noisy continuous animation.
