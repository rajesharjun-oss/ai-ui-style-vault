# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Base unit | `4px` |
| Density | `spacious` |
| Page max width | `1440px` |
| Section gap | `120px` |
| Element gap | `24px` |
| Nav padding | `24px` to `40px` |
| Hero vertical padding | `96px` to `160px` |

## Spacing Tokens

Use `4`, `8`, `12`, `16`, `20`, `24`, `32`, `40`, `48`, `64`, `80`, `96`, `120`, `144`, and `160`.

## Radius

| Element | Radius |
|---|---:|
| Ghost buttons | `999px` |
| Badges | `999px` |
| Cards | `0px` |
| Images | `0px` |
| Inputs | `0px` |
| Sections | `0px` |

## Shape Rules

- Use square image crops and square content regions.
- Use pill radius only for ghost controls and small badges.
- Do not make rounded cards.
- Do not use shadow elevation.
- Use thin borders and hard alignments to create structure.
