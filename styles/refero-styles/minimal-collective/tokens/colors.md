# Colors

## Palette

| Name | Value | Token | Role |
|---|---:|---|---|
| Black | `#000000` | `--color-black` | Page canvas, hero surface, primary background |
| White | `#ffffff` | `--color-white` | Primary text, outlines, active marks, hairlines |
| Ash | `#a3a3a3` | `--color-ash` | Secondary text, metadata, inactive labels |
| Line | `#2b2b2b` | `--color-line` | Low-contrast dividers and structural hairlines |

## Usage

- Keep Black dominant.
- Use White for the main typographic and outline system.
- Use Ash only for secondary metadata and quiet explanation.
- Use Line for subtle dividers when pure white is too loud.
- Do not add a brand accent color, CTA hue, or decorative gradient.
