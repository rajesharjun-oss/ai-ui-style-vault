|---|---:|
| Density | comfortable |
| Base unit | 4px |
| Max width | 1200px |
| Section gap | 64px to 80px |
| Card padding | 28px |
| Element gap | 8px to 16px |

## Border Radius

| Element | Radius |
|---|---:|
| Icons | 4px |
| UI controls | 10px |
| Cards | 24px |
| Large cards | 40px |
| Panels | 42px |
| Buttons and pills | 9999px |

## Elevation

| Name | Value | Token |
|---|---|---|
| Subtle inset | `rgba(255, 255, 255, 0.1) 0px 0px 0px 1px inset` | `--shadow-subtle` |

Use inset hairlines, translucency, and backdrop blur rather than external shadows.
