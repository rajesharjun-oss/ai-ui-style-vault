# Typography

## Families

| Family | Token | Fallback | Role |
|---|---|---|---|
| DM Sans | `--font-dm-sans` | Inter, system-ui | Display, body, navigation, buttons, and most UI. |
| Geist | `--font-geist` | Inter, system-ui | Section headings, feature titles, and dense product/editorial copy. |
| system-ui | `--font-system-ui` | system-ui | Rare fallback for generic UI text. |

## Rules

- Use DM Sans for the main voice.
- Set the 72px hero display at weight 500.
- Use Geist for feature and section emphasis.
- Use 600 only in secondary Geist headings, not hero type.
- Do not use 700 or heavier.
- Tighten display tracking at 72px and 40px.
