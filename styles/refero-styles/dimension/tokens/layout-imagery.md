# Layout And Imagery

## Layout

- Use a full-bleed Void Canvas shell.
- Center content inside a 1200px max-width rail.
- Use a split hero: text and feature bullets on one side, product mockup on the other.
- Float the frosted nav instead of using a traditional full-width bar.
- Use 64px to 80px vertical gaps between sections.
- Use glass cards for feature panels and dark non-glass rows for lists.
- Use numbered rows for capability sections.
- Keep sections sparse and intentional.

## Imagery

- Use product UI screenshots, laptop mockups, integration tiles, AI workspace surfaces, and simple glyph icons.
- Use warm-to-cool hero gradients sparingly.
- Use Dusk Violet as a soft spotlight or gradient line wash.
- Avoid photography, lifestyle imagery, multicolor icon systems, solid violet UI, and decorative background shapes.
