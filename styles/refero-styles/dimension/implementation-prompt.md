# Implementation Prompt

Build a dusk-lit dark AI workspace interface in the Dimension style.

Use Void Canvas (`#0a0a0a`) as the page background and Graphite (`#161616`) for elevated dark surfaces. Use Bone (`#ededed`) for readable body text, Ash (`#c2c2c2`) for secondary copy, Slate (`#686868`) for metadata, Smoke (`#b2b2b2`) for disabled labels, and Hairline (`#e5e5e5`) for 1px borders. Use Snow White (`#ffffff`) only for the primary pill CTA, key headline text, and product mockup surfaces. Use Dusk Violet (`#6b62f2`) only as a low-opacity glow or gradient wash. Never use violet as a solid fill, button, text color, or card background.

Typography should feel restrained. Use DM Sans for hero display, body, buttons, navigation, and most UI. Hero type is 72px, weight 500, line-height 1, and -2.52px tracking. Body text is 16px/1.5. Use Geist for feature headings and section-level product copy, especially 32px/600, 36px/500, or 48px/500. Avoid 700+ weights.

Use a 4px base unit, 1200px max width, 64px to 80px section gaps, 28px card padding, and 8px to 16px element gaps. Shape is a key signature: 9999px for primary buttons, nav links, and tags; 10px for UI controls; 24px for glass cards; 40px to 42px for large panels. Do not use box-shadow for elevation. Use frosted translucency, backdrop blur, inset hairlines, and surface contrast.

Expected components:

- Floating frosted nav: Graphite/translucent surface, 19px radius, 4px backdrop blur, 1px Hairline border, compact pill links, logo, and white CTA.
- White pill CTA: Snow White fill, Graphite text, 9999px radius, DM Sans 14px to 16px.
- Ghost nav button: transparent, reduced-opacity white text, 1px Hairline border, 9999px radius.
- Hairline ghost button: transparent, Bone or Smoke text, 1px Hairline border, 10px radius, tight padding.
- Frosted glass feature card: rgba(212, 212, 212, 0.1), 24px radius, translucent Hairline border, no shadow.
- Gradient hero panel: warm amber/coral to cobalt atmosphere, DM Sans display heading, bullet feature rows, white pill CTA, laptop/product mockup.
- Numbered accordion rows: Bone title left, Ash two-digit number right, no card shell.
- Device mockup: top corners 40px, bottom corners 0px, screenshot bleeding to edges.

The page should feel dark, quiet, precise, and editorial. Avoid new brand colors, photography, solid violet surfaces, heavy card shadows, loud gradients behind every section, and bold hero type.
