# Dimension

Source: Refero Styles  
URL: https://styles.refero.design/style/fbcf9cbb-7c6b-449d-862a-bce521a8ab1d  
Reference site: https://www.dimension.dev  
Captured: 2026-07-28

Dimension is a dusk-lit AI workspace style: matte-black canvas, frosted glass panels, pill-shaped controls, restrained medium-weight headlines, warm gray text, and one violet glow used only as a soft gradient wash. It should feel quiet, precise, editorial, and product-native.

Use this folder as an AI implementation brief. The most useful files are:

- `DESIGN.md` for the full style interpretation.
- `implementation-prompt.md` for a copy-ready prompt to hand to an AI builder.
- `style.json` for structured metadata.
- `code/css-variables.css` for CSS custom properties and component recipes.
- `code/tailwind-v4.css` for Tailwind v4 theme tokens.
- `code/design-tokens.json` for machine-readable tokens.

Core cues:

- Canvas: `#0a0a0a` Void Canvas.
- Elevated surface: `#161616` Graphite.
- Frosted panels: `rgba(212, 212, 212, 0.1)` over dark surfaces.
- Readable text: `#ededed` Bone, softer than pure white.
- Secondary text: `#c2c2c2` Ash and `#686868` Slate.
- CTA fill and occasional headline text: `#ffffff` Snow White.
- Hairlines: `#e5e5e5`, usually 1px and translucent.
- Accent: `#6b62f2` Dusk Violet only inside glow/gradient washes.
- Main font: DM Sans for display, body, and UI.
- Secondary font: Geist for section headings and denser editorial/product copy.
- Shape: 9999px buttons and tags, 10px UI corners, 24px glass cards, 40px to 42px large panels.
- Depth: no shadows; rely on translucency, backdrop blur, hairlines, and surface contrast.

This is best for AI workspaces, developer tools, productivity apps, agents, collaboration tools, integration hubs, and dark product landing pages.
