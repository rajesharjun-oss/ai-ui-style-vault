# Colors

| Name | Hex | Use |
| --- | --- | --- |
| Ember Orange | `#ff4f00` | Brand mark, filled buttons, key highlights, small icon accents |
| Iris Ink | `#2b2358` | Illustration-only violet accent, never UI chrome, buttons, or text |
| Cream Paper | `#fffefb` | Primary canvas, card surfaces, input backgrounds |
| Parchment | `#f8f4f0` | Secondary surface, section bands, soft elevated cards |
| Stone Linen | `#eceae3` | Hairline borders, dividers, muted surface tints |
| Driftwood | `#c5c0b1` | Muted borders, disabled backgrounds, low-contrast dividers |
| Ash Mist | `#b7b6b3` | Disabled text, placeholders, very subtle borders |
| Ink Brown | `#201515` | Primary text, dark UI elements, logo wordmark |
| Bark | `#36342e` | Secondary headings, nav text, medium-emphasis body copy |
| Coffee Stone | `#413735` | Tertiary text, resting links, breadcrumb text |
| Stone Gray | `#939084` | Muted helper text, captions, metadata, compliance lines |
| Obsidian | `#000000` | Maximum-contrast icons, footer text, logo detail only |

## Palette Rules

- Use Cream Paper instead of stark white.
- Use Ink Brown instead of pure black for primary text.
- Use Ember Orange only for filled buttons, the brand mark, and small icon accents.
- Keep Ember Orange under about 5 percent of the layout.
- Use Iris Ink only inside illustrations.
- Avoid cool blue-gray neutrals.
