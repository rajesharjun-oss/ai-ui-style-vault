# Typography

## Families

- Functional UI: Inter.
- Display: Degular Display.
- Serif accent: GT Alpina.
- Fallbacks: Inter, Bricolage Grotesque, Space Grotesk, Newsreader, Source Serif 4.

## Weights

- Inter: 400, 500, 600, 700.
- Degular Display: 500, 600.
- GT Alpina: 250, 300.

## Degular Display

- Use for hero headlines, section headings, and uppercase eyebrow labels.
- Use positive tracking: 0.020em at 14px, 0.033em at 30px, 0.042em at 40px, 0.071em at 80px.
- Enable `"ss01"` if available.
- Do not tighten this face.

## GT Alpina

- Use once per page for editorial lift.
- Use weight 250 or 300.
- Use 40px or 48px.
- Use tracking around -0.040em.
- Never use for body, nav, forms, cards, or buttons.
