# Implementation Prompt

Use the Zapier style language for this UI.

Create a warm automation/productivity interface that feels like a sunlit maker's notebook: cream paper canvas, warm brown text, a single vivid orange action color, open-tracked editorial headings, paper-thin cards, and product screenshots or app-icon workflow cards as the main visual language.

Core rules:

- Use `#fffefb` as the primary page canvas and card background.
- Use `#f8f4f0` for secondary bands and feature cards.
- Use `#201515` for primary text and dark UI.
- Use `#36342e`, `#413735`, and `#939084` for secondary, tertiary, and muted text.
- Use `#eceae3` and `#c5c0b1` for hairline borders and dividers.
- Use `#ff4f00` only for primary filled buttons, the logo glyph, and small icon accents.
- Keep orange under about 5 percent of the layout.
- Never use `#2b2358` in UI controls; reserve it for illustrations only.
- Use Inter for nav, body, buttons, forms, captions, and card text.
- Use Degular Display for hero and section headings with positive letter spacing.
- Use GT Alpina weight 250 once per page for a magazine-like heading if appropriate.
- Use 20px radius for buttons, 8px for cards, 4px for inputs and tags, 32px for large panels.
- Avoid heavy shadows; use warm hairline borders.

Recommended structure:

- Full-width announcement bar if needed.
- Sticky 64px Cream Paper nav with logo left, links center, and orange Sign up button right.
- Hero with a 2-column split: left editorial headline and CTA stack, right illustration or product visual.
- Trust logo strip in flat grayscale.
- Product sections with centered 960px product frame on warm photographic blur.
- Template or integration sections with 3-column Cream Paper cards.
- Feature cards on Parchment surfaces with small orange icon accents.
- Footer with compact warm-brown link groups.

Avoid:

- Cool blue-gray neutrals.
- Stark white pages.
- Pure black as main text.
- Large orange section backgrounds.
- Tightening Degular Display.
- Using GT Alpina for UI or body text.
- Heavy shadows and glossy SaaS cards.

The result should feel practical, warm, editorial, and automation-focused.
