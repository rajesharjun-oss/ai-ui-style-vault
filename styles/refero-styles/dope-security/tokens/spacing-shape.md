# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Density | comfortable |
| Base unit | 4px |
| Max width | 1200px |
| Section gap | 120px |
| Card padding | 40px |
| Element gap | 16px |

## Scale

`4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 72, 80, 96, 128, 136, 160`

## Radii

| Element | Value |
|---|---:|
| Small controls | 6px |
| Buttons | 8px |
| Cards | 19.2px |
| Pills | 1584px |

## Shape Rules

- Use 19.2px for cards.
- Use 8px for action buttons.
- Use 6px for compact controls.
- Use huge pill radius for card CTAs.
- Avoid 0px and 4px action buttons.
- Avoid shadows; use hairlines.
