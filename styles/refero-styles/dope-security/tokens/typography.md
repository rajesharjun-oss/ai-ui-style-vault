# Typography

## Whyte Inktrap

- Token: `--font-whyte-inktrap`
- Fallback: Inter, General Sans
- Weights: 300, 400, 500, 700
- Sizes: 10px to 88px
- Role: body, nav, buttons, links, and most headings.

## Whyte Inktrap Mono

- Token: `--font-whyte-inktrap-mono`
- Fallback: JetBrains Mono, IBM Plex Mono
- Weight: 400
- Sizes: 14px and 74px
- Line height: 0.9 to 1.5
- Letter spacing: 0.2em
- Role: stamped section headings and coordinate/data stamps.

## GrandSlang

- Token: `--font-grandslang`
- Fallback: Tiempos Headline, Lora Italic
- Weights: 300, 400
- Sizes: 32px, 50px, 64px, 88px, 146px
- Line height: 0.8 to 1.5
- Letter spacing: -0.03em
- Role: hero and large display phrases only.

| Role | Size | Line Height | Letter Spacing | Token |

| Heading | 48px | 1.20 | -0.48px | `--text-heading` |
| Heading LG | 64px | 1.20 | -0.64px | `--text-heading-lg` |
| Section Stamp | 74px | 0.90 | 14.8px | `--text-section-stamp` |
| Display | 88px | 0.80 | -2.64px | `--text-display` |

## Rules

- Use Whyte Inktrap as the default UI face.
- Use mono stamps as full-width section signposts.
- Use GrandSlang only at 32px and above.
- Do not mix mono stamps and GrandSlang on the same line.
