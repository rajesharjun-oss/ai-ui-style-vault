# AI Implementation Prompt

Build a polished UI in the dope.security style.

Use a midnight terminal aesthetic with a near-black `#090909` canvas, `#f7f9fa` text and hairlines, frosted navigation, and a single vivid `#af50ff` Signal Violet accent. The result should feel like premium cybersecurity crossed with luxury travel editorial.

Typography:

- Use Whyte Inktrap-style type for body, nav, buttons, links, and most headings.
- Use Whyte Inktrap Mono for section stamps: uppercase, 74px, 0.2em tracking.
- Use GrandSlang-style italic only for hero/display phrases at 88px to 146px.
- Do not use GrandSlang for body, nav, labels, or small text.

Layout:

- Use full-bleed dark sections with a centered 1200px inner container.
- Hero should be split: large editorial type on the left and translucent boarding-pass card on the right.
- Use 120px section gaps.
- Keep body copy left-aligned with generous side margins.
- Use comparison cards up to four columns, connected by route-line graphics.

Components:

- Frosted nav: rgba(51,50,72,0.7), blur(10px), 1px bottom Ash border.
- Filled action button: Near Black fill, 1px Almost White border, 8px radius, 16px padding.
- Ghost pill CTA: Pink Wash fill, 1584px radius, 20px by 32px padding.
- Compact outlined button: 6px radius, 1px white border, faint white fill.
- Cards: 19.2px radius, 40px padding, no shadow.
- Divider: 0.5px or 1px low-opacity Almost White stroke.

Strict rules:

- Do not use violet as body text, border color, or full-page background.
- Do not add a second accent color.
- Do not use shadows for cards.
- Do not mix mono stamps and GrandSlang on one line.
- Do not use centered body copy.
- Do not use button radii other than 8px or huge pill CTAs.
