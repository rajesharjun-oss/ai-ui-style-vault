## What To Preserve

dope.security is not a generic neon security palette. The system is 95 percent achromatic and one violet signal. It pairs geometric inktrap UI type, stamped mono headings, and occasional brush-italic display type. It uses atmospheric hero photography and then returns to text, rules, cards, and sparse violet beacons.

The page relies on:

- Near Black as a full-bleed void canvas.
- Almost White as the primary text and hairline border color.
- Signal Violet as a rationed fill/glow/accent, not a general theme color.
- Whyte Inktrap for most UI and body.
- Whyte Inktrap Mono for stamped section labels.
- GrandSlang italic only for very large hero/display moments.
- Frosted sticky nav with blur and a hairline bottom border.
- 19.2px cards and translucent panels.
- 0.5px to 1px separators instead of shadows.
