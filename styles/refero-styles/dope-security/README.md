dope.security is a midnight terminal system with violet beacons: near-black canvas, white hairlines, frosted navigation, Whyte Inktrap UI, stamped mono section headings, and GrandSlang italic hero drama. It feels like luxury travel editorial crossed with a security terminal.

Use this folder as an AI implementation brief. The most useful files are:

- `DESIGN.md` for the full style interpretation.
- `implementation-prompt.md` for a copy-ready prompt to hand to an AI builder.
- `style.json` for structured metadata.
- `code/css-variables.css` for CSS custom properties and component recipes.
- `code/tailwind-v4.css` for Tailwind v4 theme tokens.
- `code/design-tokens.json` for machine-readable tokens.

Core cues:

- Canvas: `#090909` Near Black.
- Primary text and borders: `#f7f9fa` Almost White.
- Section labels: `#f0f0f0` Soft White.
- Muted UI: `#828384` Steel, `#6b6b6b` Ash, `#474747` Graphite.
- Accent: `#af50ff` Signal Violet, used sparingly as signal lighting.
- Supporting tint: `#e1bdff` Lavender Mist.
- Primary UI type: Whyte Inktrap.
- Section stamp type: Whyte Inktrap Mono, uppercase, 74px, 0.2em tracking.
- Display accent: GrandSlang italic at 88px to 146px only.
- Geometry: 19.2px cards, 8px action buttons, 6px compact controls, huge pill CTAs.
- Surfaces: flat, translucent, hairline separated, and almost shadowless.

This is best for cybersecurity products, secure web gateways, AI security tools, enterprise security marketing, premium command-center pages, and atmospheric technical sites.
