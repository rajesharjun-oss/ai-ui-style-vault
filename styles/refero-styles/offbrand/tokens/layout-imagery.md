# Layout And Imagery

## Layout

- Use a full-viewport hero.
- Place stacked display type over or near the sphere.
- Position the sphere right-of-center.
- Keep content inside a 1400px max-width container.
- Use generous vertical space between sections: 76px to 119px.
- Use asymmetric content blocks: label and link on the left, body copy on the right.
- Use a strict 2 by 5 client logo grid.
- Use large rectangular project cards with grid-paper backgrounds.
- Use concentric circle ornaments to link sections visually.
- Keep navigation minimal or nearly absent.

## Imagery

Use:

- One iridescent CSS gradient sphere.
- Product renders and screenshots on white project cards.
- Flat client logos.
- Subtle grid-paper textures.
- Thin concentric circle ornaments.

Avoid:

- Lifestyle photography.
- Stock imagery.
- Extra abstract illustrations.
- Repeated gradient objects.
- Image cards with rounded corners.
- Busy decorative icon systems.
