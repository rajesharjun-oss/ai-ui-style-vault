# Typography

## Primary Family

```css
font-family: "Ataero Retina OB Edition", "Neue Haas Grotesk Display", Inter, "Suisse Intl", system-ui, sans-serif;
```

Use Ataero Retina OB Edition as the only typeface. The listed fallbacks are acceptable for prototypes, but the real typeface is core to the brand.

## Scale

| Token | Size | Weight | Line Height | Letter Spacing |
| --- | ---: | ---: | ---: | ---: |
| `caption` | 11px | 400 | 1.4 | 0.55px |
| `body-sm` | 15px | 400 | 1.4 | 0.15px |
| `body` | 18px | 400 | 1.4 | 0.23px |
| `subheading` | 34px | 400 | 1.0 | 0.44px |
| `heading-sm` | 46px | 400 | 1.0 | 0.6px |
| `heading` | 70px | 400 | 0.8 | 0.91px |
| `heading-lg` | 76px | 400 | 0.8 | 0.99px |
| `display` | 103px | 400 | 0.8 | 1.34px |

## Rules

- Do not introduce a second typeface.
- Use weight 400 for nearly everything.
- Use weight 700 only for small labels or navigation when needed.
- Use all caps for display headlines and section labels.
- Use positive letter spacing across the system.
- Keep body text between 15px and 18px.
- Keep body paragraphs left aligned.
