# Components

## Hero Gradient Sphere

- Role: signature brand visual.
- Shape: circle.
- Size: roughly 50 percent of viewport height, often around 600px.
- Position: right-of-center, behind display text.
- Fill: iridescent gradient at 255deg.
- Border: none.
- Shadow: none.
- Motion: none.
- Use once per page.

## Display Headline

- Role: main expressive typographic statement.
- Font: Ataero Retina OB Edition.
- Size: 70px to 103px.
- Weight: 400.
- Line height: 0.80.
- Letter spacing: around 0.013em.
- Color: `#1d1d1d`.
- Case: all caps.
- Surface: `#e5e4e0`.
- No text shadow, gradient, or decoration.

## Ghost Text Link

- Role: primary interactive element.
- Text: `#1d1d1d`.
- Background: none.
- Border: none.
- Radius: 10px hit area.
- Type: 15px, weight 400.
- Padding: 5px 0.
- Optional trailing ASCII arrow `->`.
- Hover: underline or arrow reveal.

## Section Label

- Role: quiet section identification.
- Type: 11px, weight 400, all caps.
- Letter spacing: 0.05em.
- Color: `#1d1d1d`.
- Align left.
- Use generous space below before body content.

## Client Logo Cell

- Role: logo grid unit.
- Fill: `#ffffff`.
- Border: none on the cell; grid uses `#bfbebe` hairlines between cells.
- Radius: 0px.
- Shadow: none.
- Logo: centered, about 60 percent cell width.
- Grid: 2 rows by 5 columns on desktop.

## Featured Work Card

- Role: project showcase tile.
- Fill: `#ffffff`.
- Radius: 0px.
- Shadow: none.
- Border: none or faint grid-paper overlay.
- Background detail: subtle dot-grid or line-grid in parchment tone.
- Title: 46px Ataero Retina OB, weight 400, `#1d1d1d`.
- Image or render sits below title.

## Concentric Circle Ornament

- Role: subtle geometric atmosphere.
- Stroke: 1px `#bfbebe` or Ink at 20 percent opacity.
- Fill: none.
- Use 2 to 3 nested rings.
- Position behind sphere, headline, or viewport focal point.
- No animation.

## Scroll Indicator

- Role: hero navigation prompt.
- Text: `SCROLL` plus down indicator.
- Type: 11px, all caps, 0.05em tracking.
- Color: `#1d1d1d`.
- Position: bottom-right, about 30px inset.
- Keep minimal.

## Founder Intro Block

- Role: two-column intro section.
- Left column: section label at 15px all caps and ghost link below.
- Right column: body copy at 18px, line-height 1.4.
- Column gap: 19px.
- Surface: Parchment.
- Vertical padding: 76px or more.

## All Work Filter Button

- Role: portfolio filter/navigation control.
- Style: ghost button.
- Border: `1px solid #1d1d1d`.
- Radius: 10px.
- Padding: 8px 19px.
- Type: 11px, all caps, 0.05em tracking.
- Text: `#1d1d1d`.
- Hover: Ink fill with Parchment text.
