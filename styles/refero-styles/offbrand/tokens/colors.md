# Colors

| Token | Value | Use |
| --- | --- | --- |
| `--offbrand-parchment` | `#e5e4e0` | Page canvas and section backgrounds |
| `--offbrand-ink` | `#1d1d1d` | Text, headings, link borders, all dark UI marks |
| `--offbrand-paper` | `#ffffff` | Elevated card surfaces, logo cells, project card canvases |
| `--offbrand-ash` | `#bfbebe` | Hairline borders, subtle dividers, structural outlines |
| `--offbrand-stone` | `#cdcdc9` | Secondary panel surface and quiet separation |
| `--offbrand-iridescent-sphere` | `linear-gradient(255deg, rgb(250, 203, 14), rgb(240, 107, 168) 30%, rgb(120, 186, 230) 65%, rgb(255, 255, 255))` | One hero gradient sphere only |

## Usage Rules

- Use `#e5e4e0` as the exclusive page-level canvas.
- Use `#1d1d1d` for all text and dark UI marks.
- Use `#ffffff` only to lift project cards and logo cells above the canvas.
- Use `#bfbebe` for thin structural lines.
- Use the gradient only as one large sphere in the hero.
- Do not create colored buttons, borders, cards, or small accents.
