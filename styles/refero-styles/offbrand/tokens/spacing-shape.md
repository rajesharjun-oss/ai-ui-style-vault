# Spacing And Shape

## Spacing

| Token | Value | Use |
| --- | ---: | --- |
| `unit` | 4px | Base spacing unit |
| `5` | 5px | Ghost text link vertical padding |
| `6` | 6px | Fine tuning |
| `8` | 8px | Filter button padding |
| `15` | 15px | Compact content gap |
| `19` | 19px | Standard element and column gap |
| `30` | 30px | Card padding and scroll inset |
| `32` | 32px | Local layout rhythm |
| `46` | 46px | Display-scale spacing |
| `76` | 76px | Section gap low end |
| `119` | 119px | Section gap high end |
| `max-width` | 1400px | Page container |

## Radius

| Token | Value | Use |
| --- | ---: | --- |
| `card` | 0px | Project cards and white surfaces |
| `image` | 0px | Renders and screenshots |
| `link` | 10px | Ghost text link hit areas |
| `input` | 10px | Input controls |
| `button` | 10px | Filter buttons and ghost actions |

## Shape Rules

- Cards and images are sharp.
- Interactive elements use exactly 10px radius.
- Do not use pill controls.
- Do not use soft card rounding.
