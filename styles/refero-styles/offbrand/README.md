## Use This Style When

Use OFF+BRAND. when the interface should feel like an editorial agency spread on warm printed stock: typographic, restrained, monochrome, geometric, and quietly architectural. It fits creative studios, brand agencies, portfolio pages, founder-led consultancies, and case-study sites where one chromatic hero object should carry all visual emotion.

## Quick DNA

- Warm parchment canvas instead of white or gray.
- One custom typeface drives the whole system.
- One iridescent gradient sphere appears in the hero only.
- Cards and project tiles are sharp: 0px radius.
- Links, buttons, and inputs use 10px radius.
- No shadows, colored fills, button gradients, or card elevation.
- Thin hairlines, concentric circles, strict logo grids, and grid-paper project cards.
