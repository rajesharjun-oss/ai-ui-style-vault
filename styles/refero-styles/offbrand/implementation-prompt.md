# Implementation Prompt

Build a UI in the OFF+BRAND. style.

Create a warm parchment editorial studio page. It should be mostly monochrome: parchment canvas, black ink text, white project surfaces, ash hairlines, and one large iridescent sphere in the hero. The interface should feel like a printed agency portfolio, not a colorful SaaS page.

Use these hard rules:

- Page canvas: `#e5e4e0`.
- Text and dark marks: `#1d1d1d`.
- Card and logo-cell surface: `#ffffff`.
- Hairline border: `#bfbebe`.
- Secondary panel: `#cdcdc9`.
- Hero sphere gradient: `linear-gradient(255deg, rgb(250, 203, 14), rgb(240, 107, 168) 30%, rgb(120, 186, 230) 65%, rgb(255, 255, 255))`.
- Use the gradient only once as a large hero sphere.
- Do not use colored fills on buttons, cards, sections, or backgrounds.
- Do not introduce any other chromatic accents.
- Use Ataero Retina OB Edition as the only typeface. Fallback only for mockups: Neue Haas Grotesk Display, Inter, Suisse Intl, system-ui.
- Display type should be 70px to 103px, weight 400, all caps, line-height 0.80.
- Section labels should be 11px, all caps, letter-spacing 0.05em.
- Body text should be 15px to 18px, left aligned.
- Cards and images use 0px radius.
- Links, buttons, and inputs use 10px radius.
- No shadows, glows, gradients outside the sphere, or elevation effects.

Build a full-viewport hero with a large stacked typographic headline overlapping a 600px iridescent sphere positioned right-of-center. Add a minimal ghost text link with a trailing arrow and a small bottom-right scroll indicator. Below, add a two-column founder intro, a strict 2 by 5 client logo grid with ash hairlines, and sharp project cards with subtle grid-paper backgrounds.
