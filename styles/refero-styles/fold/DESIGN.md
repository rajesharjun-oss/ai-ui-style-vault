# Fold - Style Reference

Fold feels like a Bauhaus fintech poster on a cool fog surface. It is bright, spacious, and blunt: big navy type, white floating cards, tight pill controls, and crisp object illustrations.

## Visual Thesis

- Use Fog White as the page canvas.
- Use Midnight Navy as the main text and authority color.
- Use Cornflower Steel for structure, borders, icon strokes, and secondary UI.
- Use Electric Blue only for links, active nav, and tiny accent dots.
- Use white cards with navy-tinted shadows.
- Use one huge 100px hero headline with extreme negative tracking.
- Use flat, crisp 3D-ish object illustrations instead of photography.

## Core Ingredients

- Canvas: Fog White `#f0f1f5`.
- Cards: Pure White `#ffffff`.
- Text and primary action: Midnight Navy `#20294c`.
- Structure: Cornflower Steel `#375390`.
- Link accent: Electric Blue `#459af8`.
- Rare shock: Voltage Yellow `#ffff00`.
- Shape: 12px cards, 16px images, 24px nav/panels, 9999px buttons/tags.
- Typography: GT Walsheim Pro with poster-scale compressed hero.

## Page Composition

Use a centered hero with a cluster of floating lifestyle-object illustrations, followed by a 100px headline and 18px support copy. Continue with white app cards, bank connection panels, category tag flows, map/pin illustrations, and a persistent QR download module. Keep spacing generous and content contained to 1200px.

## Color Behavior

The system is cool and restrained. Electric Blue is not a button fill. Use Midnight Navy for filled buttons and text. Use Cornflower Steel for borders and icons. Use Voltage Yellow only as a single rare highlight card.

## Type Behavior

GT Walsheim Pro carries almost everything. The signature is the 100px, weight-700 hero with -0.125em tracking and tight line-height. Body is 18px and calmer. GT America can appear sparingly for compressed display moments.
