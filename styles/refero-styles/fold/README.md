# Fold

Fold is a bright fintech poster style system: cool fog canvas, deep navy typography, a 100px compressed hero headline, white floating cards, navy-tinted shadows, pill controls, and crisp 3D-style object illustrations.

- Source: https://styles.refero.design/style/4d1d50ff-18b8-4acf-a356-48eb5c414711
- Reference site: https://fold.money
- Captured: 2026-07-28
- Theme: light
- Best for: fintech apps, personal finance products, consumer banking, spending analytics, app landing pages

## Use This When Building

Use Fog White as the canvas and Midnight Navy as the main ink. Make the hero headline huge, tight, and poster-like. Keep cards white with navy-tinted shadows. Use pill buttons and tags, 12px cards, Electric Blue only for links and tiny accents, and rare Voltage Yellow for one shock card at most.
