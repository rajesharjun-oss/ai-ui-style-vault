# Layout And Imagery

## Layout

- Max-width: about 1200px.
- Full-bleed Fog White canvas.
- Hero is centered: object cluster, large headline, support paragraph, then next section.
- Use 48px vertical gaps between major sections.
- Alternate centered bands with 2-column asymmetric bands.
- Keep body content spacious, usually below 60% viewport width.
- Sticky nav is a centered pill near the top.
- QR download module may pin bottom-left.

## Imagery

- Use crisp 3D-style object illustrations.
- No photography.
- No abstract gradients.
- No decorative patterns.
- Objects should have crisp vector edges and small contact shadows.
- Use true-to-life object colors rather than duotone styling.
- Use thin-line maps and product UI cards for feature explanations.
- Use Cornflower Steel for icon strokes and map pins.

## Surfaces

| Level | Name | Value | Purpose |
|---|---|---:|---|
| 0 | Fog Canvas | `#f0f1f5` | Page background |
| 1 | Card White | `#ffffff` | Default card surface and elevated panels |
| 2 | Mist Wash | `#dddfe9` | Nested panels and subtle section background |
| 3 | Voltage Pop | `#ffff00` | Rare featured callout surface |

## Motion

- Keep interaction motion quick and simple.
- Object illustrations can float subtly if needed.
- Avoid large parallax, gradient animation, or overly playful bounce.
