# Colors

## Brand

| Name | Value | Use |
|---|---:|---|
| Midnight Navy | `#20294c` | Primary text, hero headlines, filled buttons, fintech authority |
| Cornflower Steel | `#375390` | Borders, icon strokes, secondary text, structural elements |
| Abyss | `#042939` | Deep illustration borders and dark image frames |
| Hyacinth | `#788dba` | Rare outlined action border and subtle ghost button edge |

## Accent

| Name | Value | Use |
|---|---:|---|
| Electric Blue | `#459af8` | Inline links, active nav, tiny accent dots |
| Voltage Yellow | `#ffff00` | Rare highlight card or callout, once or twice per page max |

## Neutrals

| Name | Value | Use |
|---|---:|---|
| Dusk | `#676b89` | Secondary headings and mid-weight body |
| Smoke | `#979db5` | Captions, inverse labels, light text on dark surfaces |
| Silver Lining | `#c7cbdb` | Hairline borders and muted separators |
| Mist Gray | `#dddfe9` | Subtle borders, nested surfaces, soft washes |
| Fog White | `#f0f1f5` | Page canvas, nav backdrop, subtle card fills |
| Pure White | `#ffffff` | Card surfaces, button text on dark fills, elevated panels |

## Rules

- Use Midnight Navy for text and filled buttons.
- Use Cornflower Steel for borders, icons, and structure.
- Use Electric Blue only for links and tiny active accents.
- Do not fill buttons or large surfaces with Electric Blue.
- Use Voltage Yellow as a scarce visual shock only.
- Do not use pure black for text.
