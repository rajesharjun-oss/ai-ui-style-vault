# Components

## Filled Pill Button

- Background: `#20294c`
- Text: `#ffffff`
- Radius: 9999px
- Padding: 12px vertical, 16px horizontal
- Font: GT Walsheim Pro, 16px, weight 600
- Shadow: navy-tinted small shadow
- No border.

## Outlined Pill Button

- Background: transparent or white
- Border: 1.5px solid `#375390`
- Text: `#375390`
- Radius: 9999px
- Padding: 12px vertical, 16px horizontal
- No shadow.

## Hyperlink Text

- Color: Electric Blue
- Font: GT Walsheim Pro, 16px to 18px, weight 400
- Underline on hover only.
- No background or padding.

## Default Card

- Background: Pure White
- Radius: 12px
- Shadow: navy-tinted large shadow
- Padding: 24px
- Border: none
- Inner headings: Midnight Navy at 24px to 32px.

## Bank Connection Card

- Background: Pure White
- Radius: 12px
- Shadow: default card shadow
- Contains circular bank logo, bank name, uppercase account label, masked number, and row gaps.
- Label: Smoke, 10px uppercase, positive tracking.
- Masked number: Dusk, 16px.

## Voltage Highlight Card

- Background: Voltage Yellow
- Text: Abyss
- Radius: 12px
- Typography: GT Walsheim Pro, 24px to 32px, weight 600
- Use one per page maximum.
- Optional white top-edge highlight.

## Category Tag Pill

- Background: Fog White
- Radius: 9999px
- Icon: Cornflower Steel
- Text: Smoke, uppercase, 10px, weight 600, +0.4px tracking
- Padding: 6px vertical, 8px horizontal
- Gap: 8px between icon and label.

## Section Header

- Font: GT Walsheim Pro
- Size: 64px
- Weight: 700
- Color: Midnight Navy
- Tracking: -2.56px
- Line-height: 0.85
- Centered in hero, left-aligned in body sections.

## Hero Display Headline

- Font: GT Walsheim Pro
- Size: 100px
- Weight: 700
- Color: Midnight Navy
- Tracking: -12.5px
- Line-height: 0.91
- Max two lines.
- No competing text element should approach this scale.

## Merchant Map Pin

- Cornflower Steel teardrop pin.
- Sits on light Fog canvas.
- Static decorative or explanatory element.

## Download QR Code Module

- Fixed or persistent bottom-left card.
- Background: Mist Gray
- Radius: 12px
- Padding: 16px
- QR code: about 64px square.
- Label: Dusk, 14px, weight 400.

## Nav Pill

- Background: Fog White
- Radius: 24px
- Shadow: navy-tinted medium shadow
- Padding: 16px vertical, 32px horizontal
- Links: Midnight Navy, 16px, weight 600

## Transaction Amount Display

- Font: GT Walsheim Pro
- Size: 24px
- Weight: 600
- Color: Midnight Navy
- Tracking: -0.72px

## Illustration Object

- Crisp 3D-style object.
- No gradient or glow.
- Subtle contact shadow.
- Floats independently against Fog White.
- Examples: pizza, popcorn, phone, shoe, mango, notebook, media logo.
