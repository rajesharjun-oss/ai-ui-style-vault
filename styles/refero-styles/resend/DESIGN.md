# Resend Design Notes

Resend is a dark code-first infrastructure system. It feels like a premium email API console: black surfaces, crisp white text, graphite borders, code syntax, email previews, and calm developer utilities.

## Visual Principles

- Keep the canvas almost black.
- Use white text and graphite borders for the main hierarchy.
- Use violet only for code-related emphasis and active developer states.
- Treat code panels and email previews as primary imagery.
- Use tight spacing and square-ish surfaces for developer density.
- Keep decoration minimal and purposeful.

## Color System

The palette is black, graphite, gray, white, and violet. Violet is not a marketing gradient or general accent; it belongs to code, active states, and small highlights. Red, green, amber, and blue should appear only as semantic status colors.

## Typography

Domaine Display gives hero sections a premium editorial note. Commit Mono anchors code and API examples. Sans text carries product UI, nav, buttons, labels, and docs copy.

## Layout

Use a max width around 1200px. Build centered hero sections with a developer artifact underneath: code card, email preview, API call, terminal panel, or dashboard strip. Below, use grids of bordered panels and docs-like sections.

## Elevation

Cards use 1px graphite borders, not bright outlines. Shadows should be low-opacity black and only for floating overlays or clipped hero artifacts.
