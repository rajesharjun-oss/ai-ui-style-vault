# Implementation Prompt

Build a dark developer-tool interface inspired by Resend.

Use `#070707` as the page canvas and `#111111` or `#151515` for panels. Use `#ffffff` for primary text, `#b4b4b4` for readable body text, `#8f8f8f` for muted copy, and `#2a2a2a` for borders. Keep the palette monochrome except for `#8b5cf6` as a restrained code/developer accent.

Use Domaine Display or a refined editorial display font for hero headings. Use Commit Mono for code snippets, API keys, terminal prompts, and syntax. Use Inter or system sans for UI, nav, buttons, docs copy, and labels.

Use 12px radius for cards and code panels, 8px for buttons and inputs, 6px for tiny code controls, and 999px for pills. Normal cards should use `1px solid #2a2a2a` and no heavy shadows. Code panels can use a slightly brighter border and clipped overflow.

Build product primitives: black primary CTA with white text, outline button, code snippet panel, terminal card, email preview card, API key row, status badge, docs card, navigation bar, and developer dashboard preview. Make code and email artifacts the main visuals instead of abstract illustration.

Avoid bright gradients, wide color palettes, playful illustration, lifestyle photography, large rounded SaaS cards, and violet as a large background fill.
