# Color Tokens

## Brand And Accent

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Code Violet | `#8b5cf6` | `--color-code-violet` | Code identifiers, active developer states, focused highlights. |

## Dark Neutrals

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Black Velvet | `#070707` | `--color-black-velvet` | Page canvas and deepest background. |
| Carbon | `#0b0b0b` | `--color-carbon` | Secondary black surface. |
| Panel | `#111111` | `--color-panel` | Cards, nav, command surfaces. |
| Raised Panel | `#151515` | `--color-raised-panel` | Code panels and elevated cards. |
| Graphite | `#1f1f1f` | `--color-graphite` | Hover panels and secondary surfaces. |
| Border | `#2a2a2a` | `--color-border` | Hairline card borders and dividers. |
| Border Strong | `#3a3a3a` | `--color-border-strong` | Active card borders and code panel outlines. |

## Text

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| White | `#ffffff` | `--color-white` | Primary text and CTA text. |
| Body Gray | `#b4b4b4` | `--color-body-gray` | Body copy on dark. |
| Muted Gray | `#8f8f8f` | `--color-muted-gray` | Captions, helper text, muted metadata. |
| Disabled Gray | `#5f5f5f` | `--color-disabled-gray` | Disabled copy and inactive controls. |

## Semantic

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Success Green | `#22c55e` | `--color-success-green` | Delivered status, success, healthy state. |
| Warning Amber | `#f59e0b` | `--color-warning-amber` | Warning and pending state. |
| Danger Red | `#ef4444` | `--color-danger-red` | Failed email, destructive action, error state. |
| Info Blue | `#3b82f6` | `--color-info-blue` | Rare info state or docs note. |

## Rules

- Keep the interface black, white, and graphite by default.
- Use violet only for code and developer context.
- Use semantic colors only when state demands them.
- Do not make violet a large hero background.
