# Typography Tokens

## Fonts

| Font | Token | Role | Substitute |
| --- | --- | --- | --- |
| Domaine Display | `--font-domaine-display` | Hero headlines and major marketing display. | Georgia |
| Commit Mono | `--font-commit-mono` | Code, terminal, API keys, syntax, command rows. | JetBrains Mono |
| Sans | `--font-sans` | UI, body, nav, buttons, labels, docs copy. | Inter |

## Type Scale

| Role | Size | Line Height | Weight | Token |
| --- | --- | --- | --- | --- |
| code-xs | `11px` | `1.45` | `400` | `--text-code-xs` |
| caption | `12px` | `1.33` | `500` | `--text-caption` |
| body-sm | `14px` | `1.5` | `400` | `--text-body-sm` |
| body | `16px` | `1.5` | `400` | `--text-body` |
| body-lg | `18px` | `1.56` | `400` | `--text-body-lg` |
| subheading | `20px` | `1.4` | `500` | `--text-subheading` |
| heading-sm | `30px` | `1.2` | `500` | `--text-heading-sm` |
| heading | `48px` | `1.08` | `500` | `--text-heading` |
| display | `72px` | `1.0` | `500` | `--text-display` |

## Font Rules

- Use Domaine Display for large marketing statements only.
- Use Commit Mono only where content is code-like.
- Use sans for all navigation, forms, labels, buttons, and docs copy.
- Keep code text compact and aligned.
- Avoid playful or rounded typefaces.
