# Layout And Imagery

## Layout Grammar

Resend uses developer-platform composition: centered hero copy, precise CTA row, and a strong technical artifact below. The visual system should feel like a polished API console rather than a generic SaaS landing page.

## Common Layouts

- Hero with Domaine headline, short sans subhead, CTA row, and code/email artifact.
- Code panel beside email preview.
- API key and DNS setup rows.
- Feature cards with docs-like descriptions.
- Email status dashboard with delivered, bounced, and failed states.
- Docs section with code snippets and copy buttons.
- Footer with compact monochrome links.

## Imagery

- Use code snippets, email templates, inbox previews, DNS records, API logs, terminal commands, and dashboard cards.
- Avoid lifestyle photos, abstract 3D shapes, mascot illustration, and colorful backgrounds.
- Keep technical artifacts legible.

## Motion

- Use quick `150ms` to `200ms` hover and focus transitions.
- Panels can fade in, but avoid playful bounce.
- Code animations should be subtle and readable.
