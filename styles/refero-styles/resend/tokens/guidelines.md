# Guidelines

## Do

- Use black velvet surfaces and graphite borders.
- Use white as the main CTA color.
- Use violet only for code and developer-oriented states.
- Use Domaine Display for hero headlines.
- Use Commit Mono for code, terminal, API keys, and syntax.
- Use email previews and code snippets as primary visuals.
- Keep developer UI compact and precise.
- Use 12px cards and code panels.

## Don't

- Do not use violet as a full hero background.
- Do not add rainbow syntax everywhere.
- Do not use playful illustrations or lifestyle photography.
- Do not use large rounded consumer cards.
- Do not add bright gradients.
- Do not use serif display inside dense UI.
- Do not make docs or API rows visually loud.
