# Spacing And Shape Tokens

## Spacing

| Purpose | Value |
| --- | --- |
| Density | compact |
| Max width | `1200px` |
| Section gap | `96px` |
| Card padding | `24px` |
| Element gap | `12px` |

## Radius

| Element | Value | Token |
| --- | --- | --- |
| tiny controls | `6px` | `--radius-tiny` |
| buttons | `8px` | `--radius-button` |
| cards and code panels | `12px` | `--radius-card` |
| pills | `999px` | `--radius-pill` |

## Borders And Elevation

- Default border: `1px solid #2a2a2a`.
- Strong border: `1px solid #3a3a3a`.
- Normal card shadow: none.
- Overlay shadow: `0 16px 48px rgba(0,0,0,0.35)`.
- Use clipped overflow on code and email preview panels.
