# Resend

Source: https://styles.refero.design/style/0d914ef0-fa84-4c60-a9aa-cef0b5eb6e5d

Product/site reference: https://resend.com

## Snapshot

- **Mood:** Black velvet developer platform with violet code light and email-infrastructure precision.
- **Theme:** Dark, monochrome, developer-first, code-led.
- **Core grammar:** Near-black canvas, white text, graphite 1px borders, Domaine display, Commit Mono code, violet code identifiers, clipped email/code panels.
- **Best for:** Developer tools, email API platforms, infrastructure SaaS, docs sites, code-first product pages.

Resend is a quiet dark developer system. The interface stays almost entirely black, white, and graphite. The drama comes from precision: thin borders, clipped panels, monospace code, polished email previews, and one restrained violet used mainly in developer/code contexts.

## Fast Build Notes

- Use `#070707` as the canvas and `#111111` for raised surfaces.
- Use `#ffffff` for primary text and `#8f8f8f` for secondary copy.
- Use `#2a2a2a` for hairline borders.
- Use `#8b5cf6` only for code, syntax, active developer states, or focused highlights.
- Use Domaine Display for hero and large marketing headings.
- Use Commit Mono for code, terminal, and API snippets.
- Use Inter or system sans for normal UI and body text.
- Use code panels, email previews, and API artifacts as visual assets.
