# Amaterasu Design Reference

## North Star

Build a dark cinematic sanctuary for an AI or research product. The page should feel quiet, clinical, and celestial: teal light in the atmosphere, white text floating over darkness, and deep violet outlines acting as the only UI structure.

The system should not feel like a typical SaaS dashboard. It should feel like a controlled observation room.

## Theme

- Mode: dark.
- Hero: full-bleed dark portrait or atmospheric image.
- Primary text: polar white.
- Structural ink: cosmic violet.
- Atmosphere: teal gradients and photographic light only.
- Elevation: none.
- Controls: thin outlined pills.

## Color System

Core colors:

- Cosmic Violet: `#1b2978` for outlined CTA borders, heading text on light sections, and the only chromatic UI structure.
- Twilight Indigo: `#19366c` for secondary borders and gradient origins.
- Aurora Teal: `#75cdd6` for atmospheric light, never as a UI control color.
- Cyan Glow: radial gradient for directional teal light.
- Cosmic Violet Wash: violet gradient for atmospheric panels.
- Polar White: `#ffffff` for text on dark hero and light section surfaces.
- Obsidian: `#000000` for deepest contrast and text on white.
- Silver Slate: `#7488a5` for subtle strokes and secondary UI lines.
- Cerulean Mist: `#579dc0` for decorative SVG strokes.
- Storm Shadow: `#466187` for muted focus or hover glow.

The palette is disciplined. Teal is atmosphere, not an interface color.

## Typography

Primary body and mid-heading family: TWKLausanne-250.  
Display family: TWKLausanne-200.  
Label family: NeoSansPro-Medium.

Substitutes:

- Body: Inter, Sohne, or Manrope.
- Display: Inter Tight 200, Manrope 200, or a geometric sans at its lightest available weight.
- Labels: Space Grotesk uppercase with manual wide tracking.

Type scale:

- Label micro: 10px, line-height 1.5 to 3.0, letter-spacing 0.16em to 0.32em, uppercase.
- Label large: 20px, line-height 1.2, uppercase.
- Body: 16px, line-height 1.2, weight 400.
- Body large: 20px, line-height 1.4, weight 400.
- Statement copy: 26px, line-height 1.23, weight 400.
- Subheading: 24px, line-height 1.2, weight 700.
- Mid heading: 32px to 40px, line-height 1.1 to 1.13, weight 400.
- Display small: 50px, line-height 1.0, letter-spacing -0.040em, weight 400.
- Display medium: 60px, line-height 1.0, letter-spacing -0.033em, weight 400.
- Display large: 80px, line-height 1.0, letter-spacing -0.025em, weight 400.

The display type should whisper. Do not make the hero bold.

## Layout

- Hero: full-bleed dark image.
- Text: floats inside 40-60px negative space.
- Main CTA: outlined pill, not a filled block.
- Sections: dark atmospheric panels or clean light surfaces using violet as ink.
- Content rail: use a practical 1180-1200px max width.
- Section rhythm: generous, around 96-120px.
- Element spacing: 24px base with wider 40-60px pauses.

## Shape

- Primary controls: pill outlines.
- Pill radius: 9999px or visual 20px pill radius.
- Borders: 1px hairlines.
- Cards: avoid unless absolutely needed.
- Images: full-bleed or clean rectangular panels.

## Imagery

Use cinematic, low-light, teal-directed imagery:

- Profile portraits.
- Atmospheric research scenes.
- Dark clinical spaces.
- Teal-lit abstract panels.
- Sparse line illustrations in muted cyan strokes.

Avoid stock dashboards, bright product screenshots, and generic AI gradient blobs.

## Elevation

Use no box shadows. Depth comes from:

- Full-bleed photography.
- Dark-to-teal atmosphere.
- Radial cyan glow.
- Violet hairline outlines.
- Negative space.

No card needs a shadow. No modal needs a glow.

## AI Build Notes

Start with the hero image and typography. If the page feels empty, increase the negative space or tune the atmospheric gradient before adding UI furniture.
