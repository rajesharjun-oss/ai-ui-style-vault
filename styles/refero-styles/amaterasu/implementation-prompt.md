# AI Implementation Prompt

Build the UI in the Amaterasu style: a dark cinematic AI brand page that feels like a celestial teal sanctuary.

Use a full-bleed dark hero image or portrait with teal atmospheric light. Put polar-white text over the darkness, and use Cosmic Violet `#1b2978` as the only structural UI ink. Teal should appear through photography and gradients only, never as a button, link, or body text color.

Core rules:

- Use `#ffffff` for primary text on dark surfaces.
- Use `#1b2978` for outlined button borders, important outlines, and headings on light surfaces.
- Use `#19366c` for secondary violet borders and gradient origins.
- Use `#75cdd6` only as atmospheric light.
- Use TWKLausanne-200 style display text at 50-80px, weight 400, line-height 1.0, with negative tracking.
- Use TWKLausanne-250 style body copy at 16-26px.
- Use NeoSansPro-Medium style all-caps labels at 10-12px with 0.16em to 0.32em letter-spacing.
- Keep text floating in 40-60px negative space.
- Use thin outlined pill CTAs with transparent backgrounds.
- Use compact pill padding and hairline violet borders.
- Use radial cyan glow and violet wash gradients only as atmospheric panels.
- Use zero box-shadow elevation.

Avoid filled heavy CTAs, card shadows, bright dashboards, decorative UI teal, bold hero type, multicolor accents, and generic AI gradient blobs.

The result should feel restrained, clinical, cinematic, and quietly premium.
