# Spacing And Shape

## Spacing

| Purpose | Value | Notes |
| --- | ---: | --- |
| Content max width | 1200px | Practical normalized rail |
| Hero negative space | 40-60px | Text floats in quiet space |
| Section gap | 96-120px | Cinematic pacing |
| Element gap | 24px | Default stack gap |
| Label gap | 16px | Space between marker and heading |
| Pill padding | 10px 18px | Compact outlined controls |
| Paragraph max width | 560px | Keep copy sparse |

## Shape

| Element | Value | Notes |
| --- | ---: | --- |
| Pill controls | 9999px | Use for CTAs and nav chips |
| Visual pill radius | 20px | Source describes pill controls with 20px radius |
| Hairline border | 1px | Violet or slate outlines |
| Cards | 0px | Avoid card-heavy layouts |
| Hero image | 0px | Full-bleed photographic field |

## Borders

Use thin hairline outlines:

- `1px solid #1b2978` for primary outline structure.
- `1px solid #7488a5` for subtle secondary lines.

## Shape Rules

- Use pills for controls.
- Avoid rectangular filled CTAs.
- Avoid card surfaces when spacing and image atmosphere can separate content.
- Do not use shadow for shape definition.
