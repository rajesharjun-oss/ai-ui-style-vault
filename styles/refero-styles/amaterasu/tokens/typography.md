# Typography

## Families

- Body and mid headings: `TWKLausanne-250`
- Display: `TWKLausanne-200`
- Labels: `NeoSansPro-Medium`
- Fallback: `Inter, Manrope, Arial, Helvetica, sans-serif`

Use the light display cut for presence through restraint. Use the label face as spatial markers.

## Type Scale

| Role | Size | Line Height | Tracking | Weight | Notes |
| --- | ---: | ---: | ---: | ---: | --- |
| Micro label | 10px | 1.5-3.0 | 0.16em-0.32em | 400 | Uppercase nav, scroll cues, markers |
| Large label | 20px | 1.2 | 0 | 400 | Larger marker labels |
| Body | 16px | 1.2 | 0 | 400 | Standard UI and short copy |
| Body large | 20px | 1.4 | 0 | 400 | Descriptive body copy |
| Statement | 26px | 1.23 | 0 | 400 | Quiet editorial copy |
| Subheading | 24px | 1.2 | 0 | 700 | Emphasized sub-headings |
| Mid heading | 32-40px | 1.1-1.13 | 0 | 400 | Architectural mid-tier headings |
| Display small | 50px | 1.0 | -0.040em | 400 | Display links and compact hero text |
| Display medium | 60px | 1.0 | -0.033em | 400 | Section display |
| Display large | 80px | 1.0 | -0.025em | 400 | Hero display |

## Rules

- Keep display weight at 400.
- Do not make hero text bold.
- Use aggressive negative tracking for display text.
- Use extreme positive tracking for uppercase labels.
- Keep labels tiny and spatial.
- Keep body copy short and airy.

## Responsive Notes

On mobile, reduce display type to 42-56px while preserving light weight and tight tracking. Keep uppercase labels wide-tracked, but avoid long label strings that wrap awkwardly.
