# Guidelines

## Do

- Use a dark full-bleed cinematic hero.
- Let teal come from photography and atmospheric gradients.
- Use Cosmic Violet as the only structural UI ink.
- Keep display typography light, large, and tightly tracked.
- Use wide-tracked uppercase labels as spatial markers.
- Use outlined pill CTAs.
- Leave 40-60px of breathing room around key text.
- Use zero box shadows.

## Do Not

- Do not use teal as button, link, or body text color.
- Do not add heavy filled CTAs.
- Do not use card shadows or modal glows.
- Do not build dense dashboard grids.
- Do not use bold hero display type.
- Do not introduce warm brand colors.
- Do not add decorative gradient blobs unrelated to the hero atmosphere.

## Implementation Priorities

1. Choose a strong dark teal-lit hero image.
2. Set the text system: light display, workhorse body, wide label.
3. Establish Cosmic Violet as the outline and ink color.
4. Build transparent pill CTAs.
5. Add atmospheric gradient panels with no elevation.
6. Keep secondary sections sparse.

## Common Failure Modes

- The style becomes generic AI if teal becomes a button color.
- The hero loses its quiet power when display type is bold.
- Shadows make the system feel like ordinary SaaS.
- Too many panels turn the sanctuary into a dashboard.
