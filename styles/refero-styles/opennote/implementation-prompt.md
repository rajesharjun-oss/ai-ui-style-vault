# AI Implementation Prompt

Build a light Opennote-inspired AI notes or research interface.

Use `#fffdf8` as the page background, not pure white. The page should feel like warm paper. Use `#0a0a0a` for primary text, body copy, and icon strokes. Use `#e5e5e5` for all hairline borders and dividers. Avoid shadows completely.

Typography:

- Use IowanOld for all hero text, section headings, feature titles, and any type above 24px.
- If IowanOld is not available, use Source Serif Pro, Tiempos Text, PT Serif, or a similar old-style serif.
- Use serif display weight 400. Do not bold the serif.
- Use SuisseIntl for body, navigation, buttons, form labels, captions, and footer text.
- If SuisseIntl is not available, use Inter, Sohne, Helvetica Neue, or system sans-serif.
- Body copy should be 16px with 1.5 line height.
- Hero and section headings should be 42px to 48px, centered where appropriate.

Layout:

- Create a transparent header with a 1px `#e5e5e5` bottom border.
- Header left: wordmark. Header center: simple 14px nav links. Header right: outlined ghost button.
- Hero should be a centered single-column stack with a small line illustration, two-line serif headline, and one Sepia CTA.
- Use generous vertical space: 80px to 120px around the hero, 64px to 96px between sections.
- Add a monochrome logo strip directly on the ivory canvas, with no cards or captions.
- Use one full-width Ink Violet feature panel as a visual reset. Do not repeat it many times.
- Use paper cards in simple centered grids for feature content.

Components:

- Primary CTA: `#512906` background, `#fffdf8` text, 10px radius, 14px SuisseIntl, padding 8px 16px, no border, no shadow.
- Secondary ghost button: transparent, 1px `#d1d1d1` border, `#0a0a0a` text, 10px radius, padding 8px 16px.
- Ink Violet panel: `#242d64` background, ivory text, generous 40px to 64px padding, serif heading, sans-serif body.
- Feature card: `#fffdf8` background, 1px `#e5e5e5` border, 10px radius, 24px padding, no shadow.
- Tabs: text-only, inactive `#8c8c8c`, active `#0a0a0a` with an underline.
- Decorative illustrations: black line drawings with optional small `#ffc934` wash. Keep them loose and sparse.

Rules:

- Do not use pure white as the main background.
- Do not introduce blue SaaS accents.
- Do not use shadows, glows, or glass effects.
- Do not make yellow interactive.
- Do not use sans-serif for headings above 24px.
- Do not bold the serif headlines.
- Do not stack multiple Sepia filled CTAs in one viewport.

The final UI should feel like a quiet research notebook: warm, spacious, editorial, and useful.
