# Spacing And Shape

## Spacing

- Base unit: 8px.
- Density: comfortable.
- Page max width: 1200px.
- Section gap: 64px.
- Large hero breathing room: 80px to 120px.
- Card padding: 24px.
- Element gap: 16px.

## Radius

| Element | Value | Notes |
| --- | --- | --- |
| Tags | 10px | Same family radius as cards and buttons |
| Cards | 10px | Paper-card corners |
| Buttons | 10px | Book-label feeling, not pill-shaped |

## Elevation

- No shadow system.
- Use 1px borders and whitespace.
- Use Ink Violet as a major visual reset, not stacked elevation.
