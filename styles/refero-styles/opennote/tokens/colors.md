# Colors

## Paper And Ink

| Name | Value | Token | Use |
| --- | --- | --- | --- |
| Ivory Page | `#fffdf8` | `--color-ivory-page` | Primary canvas, page background, card surface |
| Ink Charcoal | `#0a0a0a` | `--color-ink-charcoal` | Primary text, body copy, icon strokes |
| Pressed Black | `#000000` | `--color-pressed-black` | Illustration fill, SVG marks, fine ink details |
| Graphite Rule | `#e5e5e5` | `--color-graphite-rule` | Hairline borders, dividers, card outlines, image frames |
| Smoke | `#8c8c8c` | `--color-smoke` | Muted helper text, captions, secondary metadata |
| Ash Border | `#d1d1d1` | `--color-ash-border` | Button borders and outlined-control frames |
| Slate Body | `#474747` | `--color-slate-body` | Secondary body copy and subdued icon detail |
| Soft Halo | `#f9f9f9` | `--color-soft-halo` | Alternate surface and recessed panels |

## Ink Accents

| Name | Value | Token | Use |
| --- | --- | --- | --- |
| Sepia | `#512906` | `--color-sepia` | Primary action fill and key accent text |
| Ink Violet | `#242d64` | `--color-ink-violet` | Full-bleed feature panel and deep accent surface |
| Forest Ink | `#0c3b1a` | `--color-forest-ink` | Secondary accent text, category tags, decorative strokes |
| Oxblood | `#5e0831` | `--color-oxblood` | Rare highlight or pull-quote accent |
| Margin Yellow | `#ffc934` | `--color-margin-yellow` | Decorative highlighter wash only |

## Rules

- Use Ivory Page instead of pure white.
- Use Sepia as the only filled CTA color.
- Use Ink Violet once as a major contrast panel.
- Use Margin Yellow only as illustration wash, never as button or badge fill.
- Keep blue, green, and red accents out unless they are one of the named ink colors.
