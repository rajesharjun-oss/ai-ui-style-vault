## What To Preserve

Letters is a clinical-documentation style with one atmospheric opening move: a soft open-sky gradient hero. Below the hero, everything becomes clean and white: centered section headings, large rounded feature cards, near-black pill CTAs, and small surgical-blue icons, waveform elements, and document micro-graphics.

## What To Avoid Copying

Do not copy the original logo, screenshots, UI text, app mockups, wordmark, document samples, or page layout. Use the token system and component logic to create original healthtech, documentation, transcription, or medical workflow interfaces.

## Build Context

This bundle is meant for AI-assisted UI implementation. Use the markdown files for design intent, and use the `code/` files for direct token import when building with CSS variables or Tailwind v4.
