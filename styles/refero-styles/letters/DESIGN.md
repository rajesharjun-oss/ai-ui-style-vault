# Letters Style Reference

## Creative Direction

Create a calm medical documentation interface that opens under a soft blue sky, then resolves into a sterile white clinical workspace. The mood should feel lightweight and trustworthy: one atmospheric hero, then precise product cards, gentle shadows, rounded pills, and small blue functional marks.

## Visual Priorities

1. Use the sky gradient only in the hero band.
2. Use `#ffffff` for the main page and card canvas.
3. Use `#f5f5f5` for alternate sections and secondary surfaces.
4. Use `#070709` for filled CTAs and primary text.
5. Use `#2597d0` only for icons, waveform players, mic/envelope glyphs, and tiny accents.
6. Keep all major headings centered.
7. Use 100px radius for buttons, tags, and pill controls.
8. Keep feature-card shadows large, blue-tinted, and very low opacity.

## Screen Composition

Use a full-bleed sky-gradient hero with centered headline, centered subtext, and a near-black CTA pill. Transition into white content sections with 80px to 120px vertical breathing room. Feature sections use centered headings followed by 2-column large rounded cards for documents, transcription, upload, before/after, and waveform use cases.

## Material Language

Surfaces should feel medical-instrument light: thin borders, soft white cards, generous padding, minimal texture, and restrained blue punctuation. Depth exists, but only through very soft, wide shadows.

## AI Implementation Notes

When generating a UI from this style, do not make a medical dashboard. Build a calm landing/product page with clear clinical-document components: upload drop zones, generated letter cards, handwritten-before/typed-after transformations, waveform players, and simple doctor workflow modules.
