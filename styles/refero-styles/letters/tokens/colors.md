# Colors

## Palette

| Name | Value | Token | Role |
|---|---:|---|---|
| Obsidian | `#070709` | `--color-obsidian` | Primary text, filled CTA buttons, and dark UI surfaces |
| Paper White | `#ffffff` | `--color-paper-white` | Page background, card surfaces, and button text |
| Cloud Gray | `#f5f5f5` | `--color-cloud-gray` | Secondary card surfaces and section backgrounds |
| Sky Tint | `#d7e6f5` | `--color-sky-tint` | Blue-toned shadow tint and subtle selected highlight |
| Charcoal | `#60606c` | `--color-charcoal` | Body text, secondary copy, and muted borders |
| Slate | `#8b8b8b` | `--color-slate` | Tertiary text and inactive border states |
| Ink | `#151515` | `--color-ink` | Heading color and strong dividers |
| Surgical Blue | `#2597d0` | `--color-surgical-blue` | Icon strokes, mic glyph, waveform player, and small functional accents |

## Hero Gradient

```css
--gradient-sky-gradient: linear-gradient(180deg, #779bc1 0%, #9abfda 58%, #cbdcec 100%);
```

## Rules

- Surgical Blue is only for icons, waveforms, mic/envelope glyphs, checkmarks, and tiny accents.
- Do not use Surgical Blue as a button fill, card fill, or long text color.
- Use Obsidian for all filled CTAs.
- Use the sky gradient only in the hero.
