# Spacing And Shape

## Spacing

| Token | Value | Use |
| --- | ---: | --- |
| `4` | 4px | Small status dots, micro gaps |
| `6` | 6px | Dot sizes, tiny spacing |
| `8` | 8px | Compact element gap |
| `9` | 9px | Fine UI tuning |
| `10` | 10px | Fine UI tuning |
| `11` | 11px | Fine UI tuning |
| `12` | 12px | Card padding, compact groups |
| `16` | 16px | Nav/link spacing, inner groups |
| `20` | 20px | Small section padding |
| `24` | 24px | Content group spacing |
| `28` | 28px | Glass container padding or radius |
| `32` | 32px | Button and block rhythm |
| `36` | 36px | Medium visual gap |
| `40` | 40px | Large radius and content gap |
| `52` | 52px | Feature card padding |
| `72` | 72px | Large feature card padding |
| `max-width` | 1200px | Page container |

## Radius

| Token | Value | Use |
| --- | ---: | --- |
| `minimum` | 4px | Small visible UI elements |
| `inner-card` | 8px | Deal rows, prospect items |
| `input` | 12px | Inputs and search fields |
| `pipeline-card` | 16px | Kanban columns and prospect cards |
| `container` | 16px to 40px | Feature sections and outer frames |
| `glass` | 28px to 48px | Frosted containers |
| `pill` | 9999px | Buttons, tags, nav items |

## Shape Rules

- Hard visible corners should not appear.
- Buttons and nav CTAs should be pills.
- Use a two-tier card system: smaller inner cards, larger outer containers.
- Use 40px radius for major feature cards when the layout has enough space.
