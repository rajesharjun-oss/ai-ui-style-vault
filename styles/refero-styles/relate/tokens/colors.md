# Colors

| Token | Value | Use |
| --- | --- | --- |
| `--relate-royal-signal` | `#145aff` | Main brand accent, links, logo mark, hero word highlight, active dots |
| `--relate-cobalt-glow` | `#3b82f6` | Blue washes, highlight backgrounds, small blue status dots |
| `--relate-mint-win` | `#16ca2e` | Small green status or short positive emphasis |
| `--relate-coral-lost` | `#f26052` | Small red/orange badge or negative status |
| `--relate-amber-pending` | `#ffa64d` | Pending status dot or short emphasis |
| `--relate-azure-focus` | `#0099ff` | Input focus ring glow |
| `--relate-midnight-ink` | `#020520` | Hero and section headings |
| `--relate-graphite-body` | `#14141e` | Body text, secondary headings, UI labels |
| `--relate-slate-caption` | `#374151` | Muted body text, nav labels, lists |
| `--relate-ash-helper` | `#6b7280` | Metadata, timestamps, helper text |
| `--relate-stone-divider` | `#e2e8f0` | Hairline borders, card edges, dividers |
| `--relate-lavender-wash` | `#f0f4fe` | Hero and feature block tint |
| `--relate-fog-surface` | `#f1f5f9` | Inputs, disabled states, grouping surfaces |
| `--relate-snow-canvas` | `#fcfcfc` | Page background, nav, neutral surface |
| `--relate-white-card` | `#ffffff` | Product UI cards and inner cards |

## Usage Rules

- Use `#145aff` as the dominant brand signal.
- Keep green, red, orange, and secondary blue as small status dots or tiny text accents.
- Avoid browser-default link blue.
- Do not stack several saturated accents in one component.
- Use cool light surfaces to keep the brand blue feeling switched on.
