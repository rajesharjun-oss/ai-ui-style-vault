# Typography

## Primary Family

```css
font-family: Inter, "DM Sans", Geist, Manrope, Arial, sans-serif;
```

Use Inter for headings, body, nav, buttons, and most product UI.

## Secondary And Mono

```css
font-family: Pretendard, Inter, Arial, sans-serif;
font-family: "Roboto Mono", "JetBrains Mono", "Geist Mono", monospace;
```

Use Pretendard only for localized Korean UI labels if needed. Use mono type only for code-adjacent labels or numerical callouts.

## Scale

| Token | Size | Weight | Line Height | Letter Spacing |
| --- | ---: | ---: | ---: | ---: |
| `caption` | 12px | 400 | 1.2 | 0 |
| `body-sm` | 14px | 400 | 1.43 | 0 |
| `body` | 16px | 400 | 1.63 | 0 |
| `subheading` | 20px | 400 | 1.4 | -0.16px |
| `heading-sm` | 22px | 500 | 1.4 | -0.2px |
| `heading` | 40px | 600 | 1.05 | -1.48px |
| `heading-lg` | 56px | 600 | 1.05 | -1.51px |
| `display` | 80px | 600 | 1.05 | -1.52px |

## Rules

- Use weights 400, 500, and 600 only.
- Use 600 for display and major section headings.
- Use 500 for nav links and subheadings.
- Use 400 for body and supporting copy.
- Use tight negative tracking on display type.
- Keep body copy at 14px to 16px.
