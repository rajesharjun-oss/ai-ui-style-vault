## Use This Style When

Use Relate when the interface should feel like a crisp modern CRM: cool white, rounded, bright, product-led, and friendly without becoming playful. It is a strong fit for sales tools, relationship databases, CRM dashboards, pipeline views, lightweight admin products, and SaaS onboarding pages.

## Quick DNA

- Cool white canvas with pale lavender-blue washes.
- One dominant brand signal: royal blue `#145aff`.
- Pill buttons, soft rounded containers, and no sharp interactive corners.
- Product UI screenshots do most of the visual work.
- Compact spacing with 8px to 12px element gaps.
- Large outer feature containers, smaller inner cards.
- Inter display type with tight negative tracking.
