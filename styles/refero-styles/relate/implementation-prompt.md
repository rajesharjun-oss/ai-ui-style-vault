# Implementation Prompt

Build a UI in the Relate style.

Create a cool-white CRM/SaaS interface with a bright canvas, near-black headings, one royal-blue brand signal, pill controls, soft lavender washes, and product UI cards that look like a modern sales pipeline. The page should feel compact, polished, rounded, and product-led.

Use these hard rules:

- Page canvas: `#fcfcfc`.
- Main card surface: `#ffffff`.
- Lavender wash: `#f0f4fe`.
- Input and subtle group surface: `#f1f5f9`.
- Heading text: `#020520`.
- Body text: `#14141e`.
- Secondary text: `#374151`.
- Helper text: `#6b7280`.
- Border: `#e2e8f0`.
- Main accent: `#145aff`.
- Focus blue: `#0099ff`.
- Small status dots may use `#3b82f6`, `#16ca2e`, `#f26052`, and `#ffa64d`.
- Do not use browser-default link blue.
- Do not add a second large brand color.
- Do not make CTA buttons heavy solid color blocks.
- Buttons, tags, and nav items should be pill-shaped.
- Inner cards use 8px radius.
- Inputs use 12px radius.
- Pipeline cards use 16px radius.
- Outer feature containers use 16px to 40px radius.
- Use Inter for all main UI text.
- Use weights 400, 500, and 600 only.
- Display headings should be 56px to 80px with tight negative tracking.

Build a centered hero with a small trust badge, a large Inter headline with one royal-blue highlighted word, short body copy, and a ghost-outline pill CTA. Place a soft blue/lavender wash or simple two-color gradient behind a large CRM product screenshot.

For product visuals, create Kanban pipeline columns with white cards, 4px to 6px status dots, company avatars, deal values, timestamps, assignee chips, and compact activity notes. Use soft tiny shadows on deal cards and larger soft shadows on major feature cards. Keep the whole interface bright, rounded, and calm.
