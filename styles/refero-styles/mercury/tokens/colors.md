# Color Tokens

## Brand

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Mercury Cobalt | `#546de5` | `--color-mercury-cobalt` | Primary CTA, active state, key product highlight. |

## Dark Neutrals

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Onyx | `#0f0f0f` | `--color-onyx` | Page canvas and deepest background. |
| Graphite | `#1c1c1c` | `--color-graphite` | Cards, nav, elevated panels. |
| Charcoal | `#242424` | `--color-charcoal` | Secondary panels and hover surfaces. |
| Deep Steel | `#2a2a2a` | `--color-deep-steel` | Dashboard panels and separators. |
| Border Steel | `#3a3a3a` | `--color-border-steel` | Hairline borders and card outlines. |
| Slate | `#5f5f5f` | `--color-slate` | Muted icons, secondary strokes. |

## Text And Light

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Linen | `#f7f4ef` | `--color-linen` | Warm primary headline text on dark. |
| White | `#ffffff` | `--color-white` | High-contrast text, CTA text. |
| Silver | `#c7c7c7` | `--color-silver` | Body copy on dark. |
| Ash | `#a3a3a3` | `--color-ash` | Secondary copy and metadata. |
| Smoke | `#8a8a8a` | `--color-smoke` | Muted nav, captions, disabled labels. |

## State

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Success Green | `#60a56c` | `--color-success-green` | Positive financial state, completed status. |
| Warning Gold | `#d6a64f` | `--color-warning-gold` | Risk, pending, or caution state. |

## Rules

- Use Mercury Cobalt only for action and active states.
- Use onyx and graphite for almost all surfaces.
- Use warm Linen for premium headline contrast.
- Keep state colors rare and tied to financial meaning.
