# Spacing And Shape Tokens

## Spacing

| Purpose | Value |
| --- | --- |
| Density | comfortable |
| Max width | `1200px` to `1280px` |
| Section gap | `96px` |
| Card padding | `24px` |
| Element gap | `12px` |

## Radius

| Element | Value | Token |
| --- | --- | --- |
| buttons | `6px` | `--radius-button` |
| cards | `12px` | `--radius-card` |
| inputs | `10px` | `--radius-input` |
| badges | `999px` | `--radius-badge` |

## Borders And Elevation

- Default border: `1px solid #3a3a3a`.
- Default card shadow: none.
- Subtle card shadow: `0 16px 48px rgba(0,0,0,0.18)`.
- Use shadows only for major product mockups or overlays.
