# Mercury

Source: https://styles.refero.design/style/3172cd4d-118a-4a16-a259-6b634d32322e

Product/site reference: https://mercury.com

## Snapshot

- **Mood:** Alpine fintech nightscape with calm banking precision and one cobalt action color.
- **Theme:** Dark, premium, finance-grade, product-led.
- **Core grammar:** Onyx page canvas, graphite cards, cool gray text, Arcadia typography, 12px cards, 6px buttons, one cobalt CTA, full-bleed mountain photography.
- **Best for:** Fintech sites, startup banking products, treasury dashboards, premium B2B SaaS, admin panels with calm financial data.

Mercury is a restrained dark banking system. It uses a near-black canvas, quiet graphite panels, one blue action color, and elegant editorial typography. The product should feel trustworthy, calm, and operational. Visual drama comes from mountain photography and atmospheric depth, not from gradients, neon color, or busy UI decoration.

## Fast Build Notes

- Use `#0f0f0f` as the page canvas and `#1c1c1c` for elevated cards.
- Use `#546de5` only for primary actions and critical product highlights.
- Use Arcadia or a finance-grade serif/sans hybrid for large headings.
- Use 12px card radius, 6px buttons, and 999px pills.
- Use subtle borders like `#3a3a3a` and no decorative shadows.
- Use mountain, terrain, and atmospheric photography as the main visual asset.
