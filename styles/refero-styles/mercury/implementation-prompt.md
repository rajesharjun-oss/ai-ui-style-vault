# Implementation Prompt

Build a premium dark fintech interface inspired by Mercury.

Use `#0f0f0f` as the primary page canvas and `#1c1c1c` for elevated cards. Use `#242424` and `#2a2a2a` for deeper panels and hover states. Use `#f7f4ef` or `#ffffff` for high-contrast text, and `#a3a3a3` or `#8a8a8a` for muted secondary text. Use `#3a3a3a` for hairline borders.

Use `#546de5` as the only strong action color. Apply it to primary CTAs, active product states, key links, and selected chart highlights. Do not add extra accent colors or neon treatments.

Use Arcadia or a refined editorial display font for hero and section headings. Use a clean sans such as Inter or system sans for UI, nav, labels, product data, and tables. Set display headings around `64px`, major headings around `48px`, body around `16px`, and nav around `14px`.

Use `6px` button radius, `12px` card radius, `10px` input radius, and `999px` badges. Cards should use `1px solid #3a3a3a` borders and very subtle shadows only when they need separation. Do not use bright gradients, glassmorphism, or decorative color fields.

Create layouts around founder banking: hero with full-bleed mountain or terrain photography, dark nav, compact CTA row, financial dashboard preview, treasury cards, account metric tiles, transaction rows, product benefit cards, and restrained legal/footer surfaces.
