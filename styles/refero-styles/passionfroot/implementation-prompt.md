# Implementation Prompt

Build a polished SaaS interface in the Passionfroot style.

Use a mixed dusk-and-paper visual system: a full or near-full viewport twilight hero, then warm parchment and cream content sections. Center the main layout in a 1200px max-width container. Use a large editorial serif headline (`new-kansas`, fallback `DM Serif Display`) and `Nunito Sans` for body copy, navigation, forms, and buttons.

Use `#f8f7f2` as the default page canvas, `#1d1d1c` for primary text, `#edeae4` and `#ffffff` for cards, and `#d8d6ce` for warm hairline borders. For the hero, use `#190922` as the deep base and blend it with violet, pink, coral, and orange accents. Do not make the interface monochrome; rotate pastel cards and small strokes through violet, pink, orange, teal, blue, yellow, and green.

Shape rules are strict: cards, inputs, and standard buttons use 12px radius; larger panels can use 16px or 24px; chips and tags use 9999px. Keep shadows soft, warm, and layered. Avoid harsh black shadows.

Components should feel lightweight: thin borders, compact spacing, pill chips, neutral filled buttons, simple underline tabs, and white cards layered over atmospheric artwork. Add a mascot, floating product UI cards, or cloud-like scene in the hero if imagery is needed.

Avoid heavy dashboard density, generic blue SaaS styling, pure-white page backgrounds, sharp corners, and large solid brand-color buttons.
