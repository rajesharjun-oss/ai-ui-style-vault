## Use This When

Use this style when a SaaS page should feel warm, creative, lightly magical, and polished without looking like a hard enterprise dashboard. It works well for creator tools, marketplaces, collaborative workspaces, onboarding flows, AI assistants, and product-led landing pages with a softer editorial voice.

The core behavior is a dusk-to-paper transition: a dark violet hero with clouds or atmospheric gradients, then warm parchment and cream panels with compact rounded components. Color should feel like joyful punctuation through pastel cards, icon strokes, and small decorative marks.

Build a centered 1200px layout with a full-viewport twilight hero, large serif display headlines, Nunito Sans body/UI text, parchment page backgrounds, 12px default component radius, 9999px chips, warm tinted shadows, pastel accent rotation, thin borders, and lightweight white or cream cards.
