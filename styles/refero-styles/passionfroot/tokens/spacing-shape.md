## Border Radius

| Element | Value |
|---------|-------|
| Cards | 12px |
| Inputs | 12px |
| Buttons | 12px |
| Large cards | 16px |
| Special panels | 24px |
| Tags and chips | 9999px |

## Shape Behavior

- The default component shape is a 12px rounded rectangle.
- Use 16px for larger cards that need a softer frame.
- Use 24px for hero product panels or special paper-on-sky surfaces.
- Use 9999px only for chips, tags, and true pills.
- Avoid arbitrary radii outside this vocabulary.
