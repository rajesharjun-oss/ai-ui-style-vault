# AI Implementation Prompt

Build a polished UI in the AI for Business style.

Use a warm-gray brutalist editorial showroom system: `#e5e5e5` page canvas, `#ffffff` cards, `#000000` text and inverted blocks, large rounded cards, no shadows, no gradients, and giant uppercase condensed display type. Use `#d1ffca` Mint Chip only for tags and link backgrounds, and `#fff100` Voltage Yellow only for tiny highlights.

Typography:

- Use SuisseIntlCond-style condensed type for all display headings.
- Display headings must be uppercase, weight 700, 48px to 130px, line-height 0.9, and tight tracked.
- Use SuisseIntl-style type for body, nav, buttons, cards, and secondary headings.
- Use SuisseIntlMono-style type for 12px labels, metadata, and technical annotations.

Layout:

- Use a full warm-gray page canvas, not white.
- Center content at about 1200px.
- Hero should be a split layout: massive headline left, tactile 3D product render right.
- Use an 8rem top nav with a centered floating 48px-radius pill.
- Alternate white cards, black inverted sections, and warm-gray open space.

Components:

- Filled dark button: black fill, white text, 8px radius, 16px by 24px padding.
- Ghost button: transparent, 1.5px Slate border, 4px radius.
- Standard card: white fill, 24px to 32px radius, 24px padding, no shadow.
- Inverted card: black fill, white text, 32px radius.
- Mint tag: mint fill, black text, 64px radius, 12px mono label.
- Large card: 64px radius for hero-bottom or major feature surfaces.

Strict rules:

- Do not add shadows.
- Do not add gradients.
- Do not use pure white as the page background.
- Do not make mint or yellow broad surface colors.
- Do not use mixed-case display headings.
- Do not use the condensed display face for body text.
