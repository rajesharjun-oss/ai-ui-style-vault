# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Density | comfortable |
| Base unit | 8px |
| Max width | 1200px |
| Section gap | 80px |
| Card padding | 24px |
| Element gap | 16px to 24px |

## Scale

`8, 16, 24, 40, 64, 80, 96`

## Radii

| Element | Value |
|---|---:|
| Buttons | 4px to 8px |
| Cards | 24px to 32px |
| Nav pill | 48px |
| Tags | 64px |
| Large cards | 64px |

## Shape Rules

- Use big rounded cards.
- Use a 48px floating nav pill.
- Keep buttons relatively square at 4px to 8px.
- Do not use shadows.
- Do not add card borders unless structurally required.
