# Implementation Prompt

Use the Seed style language for this UI.

Create a botanical-clinical interface that feels like a living organism under laboratory glass: warm off-white canvas, deep forest green brand surfaces, thin typography, generous spacing, pill controls, and almost no visual weight. The UI should feel scientific, calm, organic, and premium.

Core rules:

- Use `#fcfcf7` as the default page canvas, not pure white.
- Use `#1c3a13` for primary CTAs, dark product sections, nav emphasis, and brand text.
- Use `#d3fa99` only for small badges, sale tags, highlight pills, and active micro-states.
- Use transparent or very soft surfaces instead of shadows.
- Use 1000px radius for buttons, tags, badges, and pill controls.
- Use 16px card radius and 32px radius only for large feature cards.
- Use thin heading weights: 300 to 350 at 32px and larger.
- Keep body and controls at 400 to 500.
- Tighten large type slightly with negative tracking.
- Use mono type only for product codes, formula references, or ingredient specs.

Recommended structure:

- A sticky Snow White nav with brand wordmark, calm nav links, sign-in ghost action, and a Forest Depths primary CTA.
- A quiet hero with large thin display type, scientific product copy, a primary pill button, a secondary outline or text link, and clinical product imagery.
- Alternating Snow White and Forest Depths sections.
- Product cards embedded into the dark green section without shadows.
- Small Lime Pulse sale or new badges used sparingly.
- Educational content in airy two-column or modular cards with minimal borders.

Avoid:

- Heavy display fonts.
- Dense dashboard layouts.
- Strong shadows.
- Multicolor palettes.
- Gradients.
- Pure black-and-white starkness.
- Decorative visual noise.

The result should look premium and health-science focused, but still soft enough for a consumer wellness brand.
