# Spacing And Shape

## Spacing

| Purpose | Value |
| --- | --- |
| Density | Comfortable |
| Base unit | 8px |
| Max width | 1200px |
| Section gap | 64px |
| Card padding | 16px |
| Element gap | 8px |

Scale: 8px, 16px, 24px, 32px, 40px, 48px, 56px, 64px, 80px, 96px, 128px.

## Shape

| Element | Radius |
| --- | --- |
| Inputs | 8px |
| Cards | 16px |
| Large cards | 32px |
| Buttons | 1000px |
| Badges | 1000px |
| Tags | 1000px |
| Pill controls | 1000px |

## Rhythm

- Keep sections open and breathable.
- Use 64px as the normal gap between major sections.
- Use 80px to 128px for hero-to-content or product-family transitions.
- Keep component interiors compact: most card padding starts at 16px.
