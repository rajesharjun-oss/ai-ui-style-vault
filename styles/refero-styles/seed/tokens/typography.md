# Typography

## Families

- Primary: Seed Sans.
- Primary fallback: Inter, General Sans, Arial, sans-serif.
- Mono: Seed Sans Mono.
- Mono fallback: JetBrains Mono, IBM Plex Mono, monospace.

## Weights

- Headings: 300 to 350.
- Body: 400.
- Buttons and labels: 400 to 500.
- Avoid 600+ display weights.

## Usage

- Use thin display type for scientific calm.
- Use compact uppercase labels sparingly for product and promo metadata.
- Use mono for codes such as `DS-01`, `DM-02`, batch references, ingredient specs, and formula tables.
- Enable `"ss05"` when the font supports it.
