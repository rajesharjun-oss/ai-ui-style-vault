# Colors

| Name | Hex | Use |
| --- | --- | --- |
| Forest Depths | `#1c3a13` | Primary brand color, filled CTAs, dark product sections, nav surfaces, primary text |
| Lime Pulse | `#d3fa99` | Sale badges, new tags, highlight pills, small active accents |
| Sage Moss | `#757c5d` | Muted green product accent and botanical support |
| Olive Gold | `#9f995b` | Muted yellow-green wash and secondary botanical highlight |
| Eucalyptus | `#698e79` | Product variant accent and calm green-gray support |
| Ink | `#000000` | High-contrast light-surface text, used sparingly |
| Pewter | `#666666` | Secondary text, captions, helper copy |
| Ash | `#b3b3b3` | Disabled states, subtle borders, subdued copy |
| Frosted Glass | `#c4c7c4` | Translucent overlays and muted card surfaces |
| Warm Stone | `#eeeee9` | Secondary page bands and low-contrast sections |
| Snow White | `#fcfcf7` | Main canvas, light cards, inverse text on green |

## Palette Rules

- Make Forest Depths the main brand anchor.
- Keep Snow White warmer than pure white.
- Use Lime Pulse as a small signal, never as a broad background.
- Let secondary greens support product variation without competing with the core palette.
- Avoid additional saturated accents.
