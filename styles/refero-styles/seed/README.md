## Use This Style For

- Botanical-clinical product pages.
- Supplement, health, wellness, biotech, science-backed consumer brands.
- Premium ecommerce that needs calm credibility instead of hype.
- Interfaces where product formulas, ingredients, subscriptions, and education must feel precise.

## Design Memory

Seed feels like warm white paper in a greenhouse lab. The interface is nearly achromatic, with deep forest green doing the heavy brand work and one vivid lime accent reserved for badges and tiny flashes of emphasis. Components are weightless: pill buttons, 16px cards, no shadows, no gradients, and typography that stays thin, airy, and measured.
