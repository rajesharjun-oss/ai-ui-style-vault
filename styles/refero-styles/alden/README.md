# Alden

AI-ready Refero style bundle for Alden.

- Source: https://styles.refero.design/style/b6f25b86-ffcf-42f1-9f37-5e37d08cb4ce
- Reference site: https://joinalden.com
- Captured: 2026-07-28
- Theme: light
- Mood: cream-washed clinical calm with blue confidence marks
- Industry: healthcare, advisory care, patient support

## Use This Style For

- Healthcare, care navigation, wellness, medical advisory, and patient support sites
- Interfaces that need to feel calm, credible, human, and non-institutional
- Editorial landing pages with serif hero type, rounded care cards, and soft photo frames
- Products where an expert advisor, clinician, or concierge guide is central to the story

## Files

- `source.md` records the source URL and capture context.
- `DESIGN.md` is the main human-readable design reference.
- `implementation-prompt.md` is a direct prompt for an AI coding agent.
- `style.json` is a structured summary for indexing and retrieval.
- `tokens/` contains focused notes for colors, type, spacing, components, guidelines, layout, and imagery.
- `code/` contains CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` reserves the screenshot slot for manual or automated captures.

## Core Signature

Alden is warm editorial healthcare: white and parchment surfaces, large serif display moments, blue confidence highlights, sage pill CTAs, rounded advisor cards, and real care photography without heavy shadows or cold hospital polish.
