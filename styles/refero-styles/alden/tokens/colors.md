# Colors

## Palette

| Name | Value | Token | Role |
|---|---:|---|---|
| White | `#ffffff` | `--color-white` | Main page surface, card backgrounds, white text on sage CTAs |
| Parchment | `#f8f4ee` | `--color-parchment` | Warm hero side panels, testimonial blocks, subtle section wash |
| Ink | `#1f2937` | `--color-ink` | Main headings, body emphasis, logo text |
| Mist Blue | `#e8f5ff` | `--color-mist-blue` | Oversized highlight blocks behind key display words |
| Sky Signal | `#5aa9e6` | `--color-sky-signal` | Underlines, circles, badges, icon accents, focus borders |
| Sage | `#7f9b85` | `--color-sage` | Primary CTA fill, care-positive accent, photo frame accent |
| Deep Sage | `#617761` | `--color-deep-sage` | CTA hover state, emphasized tags, grounded controls |
| Stone | `#6b7280` | `--color-stone` | Body copy, secondary nav, explanatory text |
| Cloud Border | `#e5e7eb` | `--color-cloud-border` | Hairlines, card outlines, form borders |

## Usage

- Let White stay dominant.
- Use Parchment to warm key panels, not as an all-over beige theme.
- Use Ink for primary reading and Stone for supportive copy.
- Use Mist Blue as a broad highlight behind selected display words.
- Use Sky Signal as the confidence mark: underline, circle, focus ring, or icon accent.
- Use Sage for CTAs and moments of care-forward action.
