# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Base unit | `4px` |
| Density | `comfortable` |
| Page max width | `1180px` |
| Section gap | `96px` |
| Card padding | `24px` to `32px` |
| Element gap | `16px` |
| Nav height | `72px` to `80px` |

## Spacing Tokens

Use `4`, `8`, `12`, `16`, `20`, `24`, `28`, `32`, `36`, `40`, `48`, `56`, `64`, `72`, `80`, `96`, `112`, and `128`.

## Radius

| Element | Radius |
|---|---:|
| Buttons | `999px` |
| Badges | `999px` |
| Cards | `24px` |
| Images | `28px` |
| Inputs | `16px` |
| Sections | `32px` |
| Highlight blocks | `32px` |

## Shape Rules

- Use pill geometry for CTAs and badges.
- Use rounded cards and panels to create care-forward softness.
- Keep image frames rounded and warm.
- Do not use sharp enterprise rectangles.
- Do not use extreme glassmorphism or shadow depth.
