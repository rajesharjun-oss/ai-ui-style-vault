# AI Implementation Prompt

Build the UI in the Stykka style: a light, Scandinavian, photo-led showroom interface for kitchens or modular interiors.

Use a pure white canvas, black text, black 1px borders, and no extra accent colors. The emotional tone should come from large interior/product photography, not from gradients, shadows, colored panels, or illustrations.

Core rules:

- Use Inter as the primary font and keep most typography regular weight.
- Use large display headlines around 46px on desktop, line-height 1.05, tight negative tracking, weight 400.
- Use small uppercase labels at 14px, weight 500, with slight positive tracking.
- Keep body text 16px, line-height 1.5, regular weight.
- Use a max content width of 1280px and a strict 10px grid rhythm.
- Use 60-80px section gaps.
- Make the hero a full-bleed photograph, roughly full viewport height.
- Place a transparent absolute nav over the hero with left links, centered wordmark, and right language selector plus CTA.
- Use transparent outlined buttons: black text, 1px black border, 8px radius, 10px 18px padding, hover to black fill and white text.
- Use hard-edged image grids with 0px radius and 10-15px gutters.
- Use no drop shadows, no glass effects, no tinted card surfaces, no decorative gradients, and no rounded image containers.
- Use a full-width black footer with white text as the only large dark UI surface.

Component behavior:

- Feature grids should be image plus text only, not card surfaces.
- Inline text links should be black with a simple underline.
- If a spec or material note is needed, use Azeret Mono at 18px as a one-off callout.
- On mobile, collapse grids to one column, keep images hard-edged, and preserve generous whitespace.

The final result should feel practical, premium, quiet, and product-first.
