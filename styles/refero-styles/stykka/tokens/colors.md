# Colors

## Palette

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Gallery White | `#ffffff` | `--color-gallery-white` | Main canvas, section background, negative space |
| Press Black | `#000000` | `--color-press-black` | Text, borders, footer, inverse button hover |
| Plate Gray | `#f3f3f3` | `--color-plate-gray` | Optional quiet placeholder or inactive neutral |

## Color Behavior

Stykka is intentionally achromatic. Do not look for a conventional accent palette. The photographs supply warmth and depth, while the interface stays white and black.

Use black for:

- Primary and secondary text.
- 1px rules and outlines.
- Footer background.
- Button hover fills.

Use white for:

- Page canvas.
- Section backgrounds.
- Button text on black hover.
- Negative space around product imagery.

Use Plate Gray only when a technical state needs a visible neutral, such as skeleton loading, an image placeholder, or a disabled surface. It should not become a card system.

## Forbidden Color Moves

- No blue, green, orange, or purple UI accents.
- No tinted page backgrounds.
- No colored primary CTA.
- No black-to-transparent hero overlays.
- No gray card surfaces as a default layout device.
