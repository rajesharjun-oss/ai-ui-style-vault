# Typography

## Families

- Primary: `Inter`
- Fallback: `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`
- Supporting mono: `Azeret Mono`

Use Inter for almost everything. Use Azeret Mono only as a rare spec callout, dimension note, or builder detail.

## Type Scale

| Role | Size | Line Height | Tracking | Weight | Notes |
| --- | ---: | ---: | ---: | ---: | --- |
| Caption | 11px | 1.2 | 0.23px | 400 | Legal, micro labels |
| Label | 14px | 1.25 | 0.29px | 500 | Uppercase section labels and grid titles |
| Body small | 14px | 1.25 | 0.29px | 400 | Compact nav support text |
| Body | 16px | 1.5 | -0.37px | 400 | Paragraphs and product copy |
| Subheading | 22px | 1.2 | -0.79px | 400 | Short section intros |
| Heading small | 24px | 1.2 | -0.89px | 400 | Secondary headings |
| Heading | 30px | 1.1 | -1.2px | 400 | Main section headings |
| Display | 46px | 1.05 | -1.93px | 400 | Hero and major editorial headlines |
| Mono callout | 18px | 1.0 | -0.18px | 400 | One-off spec line |

## Rules

- Keep display type regular weight. Do not make it bold.
- Use tight negative tracking as size increases.
- Use uppercase labels sparingly and make them feel technical, not loud.
- Keep body copy readable and uncluttered.
- Avoid mixing in decorative serif or script fonts.

## Responsive Notes

On mobile, reduce display type to 34-38px while preserving regular weight and tight tracking. Keep line lengths compact and let images remain the dominant visual element.
