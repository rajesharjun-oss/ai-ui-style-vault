# Spacing And Shape

## Spacing

| Purpose | Value | Notes |
| --- | ---: | --- |
| Base rhythm | 10px | Use as the visible layout cadence |
| Max content width | 1280px | Center content inside full-width sections |
| Section gap | 60-80px | Keep pages spacious and editorial |
| Element gap | 10px | Default distance between image, title, and body |
| Image grid gutter | 10-15px | Tight and precise |
| Nav vertical padding | 20px | Transparent nav over hero |
| Button padding | 10px 18px | Compact but usable |

## Radius

| Element | Value | Notes |
| --- | ---: | --- |
| Images | 0px | Hard-edged photography is required |
| Buttons | 8px | Small radius, not pill-shaped |
| Tags | 8px | Use only if tags are required |
| Cards | 16px | Rare; Stykka usually avoids true card surfaces |

## Borders

Use 1px solid black rules. Borders should feel like construction lines or product drawing lines, not decorative framing.

## Shape Rules

- Do not round product images.
- Do not use pill buttons.
- Do not add floating card containers.
- Use whitespace before adding a border.
- Use a border before adding any shadow. In most cases, use no shadow at all.
