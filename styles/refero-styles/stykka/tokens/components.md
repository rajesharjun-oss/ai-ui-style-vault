# Components

## Transparent Top Nav

- Position: absolute over the hero.
- Background: transparent.
- Border: none.
- Shadow: none.
- Left cluster: simple text links.
- Center: wordmark text.
- Right cluster: language selector and outlined CTA.
- Padding: about 20px vertically.
- Typography: Inter 16px, weight 400 for links; 22-24px, weight 500 for wordmark.

Do not add blur, glass, or a sticky filled header unless the product flow absolutely requires it after scroll.

## Outlined CTA Button

- Text: Inter 16px, weight 500.
- Text color: black.
- Background: transparent.
- Border: 1px solid black.
- Radius: 8px.
- Padding: 10px 18px.
- Hover: black background, white text.
- Motion: short color transition only.

## Full-Bleed Hero

- Size: 100vw wide and roughly 100vh tall.
- Image: real product or interior photography.
- Overlay: none by default.
- Text block: lower-left third, aligned to the grid.
- Content: label, display headline, single CTA.

If text contrast is poor, choose a different crop before adding a dark overlay.

## Hero Label

- Font: Inter.
- Size: 14px.
- Weight: 500.
- Tracking: 0.29px.
- Case: uppercase.
- Color: white or black depending on image contrast.

## Display Headline

- Font: Inter.
- Size: 46px desktop.
- Line height: 1.05.
- Tracking: -1.93px.
- Weight: 400.

This is the main brand voice. Keep it calm and regular.

## Feature Grid Item

- Structure: image, title, body.
- Surface: none.
- Image radius: 0px.
- Gap: 10px.
- Title: 14-16px, uppercase, weight 500, slight positive tracking.
- Body: 16px, line-height 1.5, weight 400.
- Layout: 4 columns desktop, 2 columns tablet, 1 column mobile.

## Image Grid

- Use 2 or 3 columns depending on content.
- Gutters: 10-15px.
- Corners: 0px.
- Captions: optional and minimal.
- No borders, shadows, or frames.

## Language Selector

- Inline icon plus language text plus chevron.
- Icon: simple globe, 16px stroke.
- Text: Inter 16px, weight 400.
- Gap: around 8-10px inside the control.
- No filled pill background.

## Footer

- Background: black.
- Text: white.
- Full-width band.
- Typography: Inter 14-16px, regular.
- Include wordmark, links, and copyright.
- Avoid newsletter cards, social icon clusters, and decorative blocks.

## Mono Spec Callout

- Family: Azeret Mono.
- Size: 18px.
- Line height: 1.0.
- Tracking: -0.18px.
- Use for one short technical note or dimension-like line.
