## Use This When

Use this style when a product should feel premium, quiet, protective, and editorial. It works well for insurance, product protection, luxury commerce, high-trust SaaS, warranty products, memberships, and dark brand pages that need restraint instead of neon tech styling.

The key behavior is an almost achromatic system: black canvas, warm cream text, hairline borders, generous radius, giant serif display type, and one yellow-orange-purple gradient used only in decorative 3D shapes or tiny product accents.

## Implementation Snapshot

Build a dark editorial page with massive Recoleta-style serif headings, Oldschool Grotesk UI text, cream ghost pills, black filled pills on light surfaces, product cards in warm bone, and flat border-based separation. Do not turn the gradient into UI chrome.
