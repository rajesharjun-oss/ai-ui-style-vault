# Implementation Prompt

Build a polished Clyde-style interface: a dark luxury editorial page for a high-trust product, using a near-black canvas, warm cream typography, massive serif display headings, generous pill controls, and one decorative Solstice Gradient accent.

Use Obsidian (`#000000`) as the default page background. Use Bone (`#f6f6f4`) for text on dark surfaces, light sections, ghost button outlines, and card backgrounds. Use Paper (`#ffffff`) only for the brightest inner product containers. Use Char (`#1a1a1a`) and Slate (`#7d7d7d`) for subtle dark edges and mid-gray UI. The Solstice Gradient must stay decorative: abstract 3D shape, small product accent, or transition atmosphere only. Do not use it for buttons, text, borders, or normal UI surfaces.

Use a Recoleta-style serif for all headings 36px and above. Use Oldschool Grotesk or an Inter/Sohne-style fallback for body, nav, buttons, cards, labels, and UI. Display type should be large, weight 400, tightly tracked, and line-height 1.0 to 1.1. Body copy should be 15px to 21px, weight 300 or 400, quiet and measured.

Layout should use a full-bleed dark page canvas with a 1200px centered rail. Start with a warm Bone announcement bar, then a transparent nav over the dark canvas, then a full hero with an 80px to 125px serif headline and one floating gradient abstract object. Alternate into light Bone product sections, dark stats strips, and card-based proof sections. Keep section gaps around 80px.

Components should use 100px pill radius for buttons, tags, filters, and tabs. Cards use 16px radius, large panels use 38px, links use 12px, inputs use 4px. Use hairline borders for separation and no box shadows.

Before finishing, check that:

- The palette is almost entirely black, cream, white, and gray.
- The Solstice Gradient is decorative only.
- Primary actions are neutral filled or ghost pills.
- Display headings use serif type and negative tracking.
- Body and UI text use grotesk sans type.
- Cards are flat and border-defined.
- No new chromatic UI color has been invented.
