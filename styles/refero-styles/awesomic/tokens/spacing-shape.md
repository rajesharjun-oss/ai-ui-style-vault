## Shape Rules

- Use `12px` for tags and small controls.
- Use `14px` for buttons and inputs.
- Use `36px` for cards and large content surfaces.
- Use `10000px` pills only for navigation CTAs.
- Do not use visible sharp corners.
- Avoid card drop shadows; use 1px Cloud borders instead.
