# Guidelines

## Do

- Use Untitled Serif at weight `400` for all headings.
- Use ABC Diatype Mono for body copy, buttons, nav labels, badges, and functional UI text.
- Set buttons and tags to `100px` or `9999px` radius.
- Use Parchment (`#f6f3f1`) as the page canvas.
- Reserve Lake Blue (`#2b59d1`) for the single primary action per screen.
- Use `1px` Ash (`#cecac8`) borders and dividers.
- Apply uppercase and tight tracking to nav labels, buttons, and tag text.
- Use pastel gradients only for atmospheric washes and illustrations.

## Don't

- Do not set headings in bold or `600+` weight.
- Do not use pure white as the page background.
- Do not use Lake Blue outside the single primary action fill.
- Do not substitute a normal sans-serif for the monospace body font.
- Do not apply drop shadows to cards.
- Do not use corner radii below `16px` on cards or below `100px` on buttons.
- Do not introduce additional UI accent colors.
- Do not turn decorative pastel colors into functional UI colors.
