# Layout And Imagery

## Layout Rhythm

- Use a warm Parchment full-page canvas.
- Keep content within a wide max width around `1432px`.
- Hero sections can be centered and typographic, with mono supporting text below.
- Use `64px` section gaps and `40px` card padding.
- Feature cards can sit in bordered grids with generous spacing.
- FAQ sections use full-width rows with thin Ash dividers.
- Navigation is simple, horizontal, and low-chrome.

## Imagery

- Use custom data pipeline diagrams as the main visual language.
- Build diagrams from pill-shaped bordered nodes connected with thin curved lines.
- Include small mono icons inside nodes for data sources and destinations.
- Use soft radial or linear gradient washes behind hero and feature content.
- Use pastel colors only in diagrams, illustrations, and atmospheric fields.
- Use grayscale/desaturated partner logos in social proof rows.
- Avoid photography and generic product screenshots as the primary brand imagery.

## Pipeline Diagram Logic

- Nodes use Parchment fill, Ash border, and full pill radius.
- Lines use thin Ash strokes.
- Central hubs can carry a soft Mint or green radial glow.
- Keep the diagram calm, technical, and airy.

## Surface Strategy

- Page base: Parchment.
- Colored emphasis: Periwinkle Mist card.
- Dark emphasis: Ink announcement bar or Off-Black button.
- Borders: Ash hairlines.
- Decorative atmosphere: Coral, Sky Blue, Mint, Gold, Crimson gradient washes.
