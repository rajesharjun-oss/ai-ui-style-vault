# Colors

## Brand

| Name | Value | Token | Role |
|---|---:|---|---|
| Parchment | `#f6f3f1` | `--color-parchment` | Page canvas and majority surface fill. The warm off-white is the signature surface. |
| Lake Blue | `#2b59d1` | `--color-lake-blue` | Single primary action fill and strongest interactive accent. |

## Accent And Decorative Palette

| Name | Value | Token | Role |
|---|---:|---|---|
| Periwinkle Mist | `#cfdaf5` | `--color-periwinkle-mist` | Muted colored card surface, low-emphasis panels, and placeholder blocks. |
| Sky Blue | `#a0b5eb` | `--color-sky-blue` | Decorative gradient stop and pipeline flow line color. |
| Mint | `#a7fccd` | `--color-mint` | Supporting decorative accent in illustrations and washes. |
| Coral | `#ff9473` | `--color-coral` | Supporting decorative accent in gradient washes. |
| Gold | `#ecda98` | `--color-gold` | Warm decorative gradient stop. |
| Crimson | `#f37a0a` | `--color-crimson` | Deep warm decorative gradient stop. |

## Neutrals

| Name | Value | Token | Role |
|---|---:|---|---|
| Ink | `#000000` | `--color-ink` | Announcement bar surface and selected high-contrast contexts. |
| Off-Black | `#242424` | `--color-off-black` | Primary text and high-contrast neutral action fill. |
| Graphite | `#4e4d4d` | `--color-graphite` | Secondary text, body copy, and subheadings. |
| Smoke | `#797776` | `--color-smoke` | Muted helper text and tertiary links. |
| Ash | `#cecac8` | `--color-ash` | Hairline borders, card outlines, section dividers, and pipeline node outlines. |

## Surface Levels

| Level | Name | Value | Purpose |
|---:|---|---:|---|
| 1 | Parchment | `#f6f3f1` | Full-page warm canvas. |
| 2 | Periwinkle Mist | `#cfdaf5` | Elevated colored feature card surface. |
| 3 | Off-Black | `#242424` | Secondary buttons and inverted UI contexts. |
| 4 | Ink | `#000000` | Announcement bar. |
