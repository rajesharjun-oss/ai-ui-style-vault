# Components

## Announcement Bar

- **Role:** Top-of-page notification strip.
- **Style:** Full-width Ink bar, about `40px` tall, mono text in parchment/white, small pill action on the right.
- **Details:** A close icon may sit at the far right.

## Primary Pill Button - Blue

- **Role:** Primary conversion action.
- **Style:** Lake Blue fill, white text, ABC Diatype Mono `14px` uppercase, `100px` radius, `16px 32px` padding.
- **Details:** Can include a trailing arrow glyph.
- **Rule:** This is the only saturated filled UI control.

## Primary Pill Button - Black

- **Role:** Secondary conversion action.
- **Style:** Off-Black fill, white text, ABC Diatype Mono `14px` uppercase, `100px` radius, `16px 32px` padding.

## Ghost Pill Button

- **Role:** Tertiary or secondary navigation action.
- **Style:** Transparent fill, `1px #242424` border, Off-Black text, ABC Diatype Mono `14px` uppercase, `100px` radius.

## Text Link With Arrow

- **Role:** Directional text navigation.
- **Style:** Transparent, no border, Off-Black mono text, uppercase tracking, arrow suffix.

## Pipeline Node Tag

- **Role:** Labeled node in a data pipeline diagram.
- **Style:** Parchment fill, `1px #cecac8` border, `9999px` radius, small mono icon plus uppercase mono text.
- **Layout:** Nodes are connected by thin curved Ash lines.

## Feature Card

- **Role:** Product capability card with icon, title, and body.
- **Style:** Transparent or Parchment fill, `1px #cecac8` border, `40px` radius, `40px` padding.
- **Type:** Untitled Serif `24px` title, ABC Diatype Mono body in Graphite.
- **Rule:** No shadow.

## Elevated Feature Card - Periwinkle

- **Role:** Hero feature card or emphasis card.
- **Style:** Periwinkle Mist fill, `40px` radius, `40px` padding.
- **Visual:** Can include a large gradient illustration using Coral, Sky Blue, and Mint washes.
- **Rule:** Use sparingly as the one colored surface that draws attention.

## FAQ Accordion Item

- **Role:** Question and answer row.
- **Style:** Full-width row, `40px` vertical padding, `1px #cecac8` bottom border only.
- **Type:** Untitled Serif `24px`, weight `400`, Off-Black.
- **Icon:** Right-aligned chevron in Off-Black.

## Logo Strip

- **Role:** Social proof row.
- **Style:** Single horizontal row of grayscale/desaturated partner logos with generous gaps.
- **Rule:** No cards, borders, or logo containers.

## Gradient Atmospheric Wash

- **Role:** Decorative color field behind hero or feature content.
- **Style:** Large blurred gradient using Coral to Sky Blue or Sky Blue to Mint, at low-to-medium opacity.
- **Rule:** Soft and diffused, never sharp-edged or used as UI chrome.

## Navigation Bar

- **Role:** Primary site navigation.
- **Style:** Parchment or transparent background, logo left, mono uppercase nav links, action pills right.
- **Rule:** No visible nav border or shadow.

## Hero Section

- **Role:** First-screen headline and subtext.
- **Style:** Full-width Parchment background, centered content stack, Untitled Serif `80px` headline, mono subtext, two pill buttons.
- **Rule:** Typographic hero first; no generic background image.
