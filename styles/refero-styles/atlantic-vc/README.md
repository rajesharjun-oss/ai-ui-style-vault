Atlantic.vc is a midnight command-center system: pure black canvas, cold blue-white text, sparse electric-blue highlights, ignition-orange edge accents, Monument-style display type, and spaced monospace body copy. Components are deliberately restrained: outlined links, square-cornered buttons, soft 16px cards, and almost no elevation.

Use this folder as an AI implementation brief. The most useful files are:

- `DESIGN.md` for the full style interpretation.
- `implementation-prompt.md` for a copy-ready prompt to hand to an AI builder.
- `style.json` for structured metadata.
- `code/css-variables.css` for CSS custom properties and component recipes.
- `code/tailwind-v4.css` for Tailwind v4 theme tokens.
- `code/design-tokens.json` for machine-readable tokens.

Core cues:

- Canvas: `#000000` Deep Midnight.
- Subtle surface: `#0d0d0f` Charcoal Canvas.
- Card surface: `#2b2f33` Cool Stone.
- Primary text and borders: `#d8eaff` Ghost Ink.
- Muted text: `#6c757f` Muted Ash.
- Highlight: `#1f58f2` Electric Blue.
- Edge accent: `#ff4105` Ignition Orange.
- Display/nav: Monument style, 400 weight, tight tracking.
- Body/data: Mono style with generous tracking.
- Buttons: 0px radius, outlined or text-accented, not filled.

This is best for venture sites, frontier-tech portfolios, data rooms, speculative technology pages, command-center dashboards, and high-contrast dark editorial products.
