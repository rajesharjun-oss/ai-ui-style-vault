# Components

## Ghost Navigation Link

Transparent background, no border, no radius, Monument 400, Ghost Ink text. Use in header navigation and secondary text actions.

## Outlined Action Button

Transparent fill, 1px Ghost Ink border, Ghost Ink text, 0px radius, Monument 16px. Use as the primary CTA treatment.

## Text Accent Button

Transparent background, no border, 0px radius, Monument text in Ignition Orange. Use for focused action states, icon labels, and high-signal links.

## Standard Card

Cool Stone or Charcoal Canvas surface, 16px radius, no heavy border, no shadow. Keep padding restrained unless the content needs space.

## Hero Large Card

Charcoal Canvas surface, 24px radius, large internal padding. Use for hero modules, major statements, or immersive command-center panels.

## Company Grid

Dark full-bleed or horizontally scrolling grid. Use partner logos, blue-toned noise, Ghost Ink labels, and sparse dividers.

## Sticky Top Bar

Minimal dark sticky nav with Monument links. Action should be outlined or Ignition Orange text, not a large filled button.
