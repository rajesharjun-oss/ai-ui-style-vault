# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Density | comfortable |
| Base unit | 4px |
| Page max width | none |
| Section gap | 50px |
| Card padding | 24px |
| Element gap | 16px |

## Scale

`4, 8, 12, 16, 20, 24, 32, 80, 100, 148, 200, 240`

## Radii

| Element | Value |
|---|---:|
| Buttons | 0px |
| Navigation | 0px |
| Links | 8px |
| Cards | 16px |
| Large cards | 24px |

## Shape Rules

- Keep buttons and nav square.
- Use 16px cards for standard blocks.
- Use 24px cards for major hero modules.
- Avoid generic rounded SaaS controls.
- Avoid heavy shadows.
