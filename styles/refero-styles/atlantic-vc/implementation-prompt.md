# AI Implementation Prompt

Build a polished UI in the Atlantic.vc style.

Use a midnight command-center design system: pure black `#000000` canvas, `#0d0d0f` recessed surfaces, `#2b2f33` cards, `#d8eaff` Ghost Ink text and outlines, `#1f58f2` Electric Blue readouts, and `#ff4105` Ignition Orange action edges. The interface should feel like a precise venture or frontier-tech terminal.

Typography:

- Use Monument-style type for display headlines, navigation, and major text.
- Use Mono/Space Mono-style type for body copy, labels, technical text, and data.
- Keep Monument at 400 weight.
- Use negative tracking on large Monument headings.
- Use generous positive tracking on Mono body and caption text.

Layout:

- Use full-bleed dark sections with generous internal padding.
- Avoid a rigid page-wide max-width.
- Hero should be immersive, dark, and centered, with a huge Monument headline and sparse supporting mono copy.
- Use horizontally scrolling grids, centered text stacks, and large rounded dark cards.

Components:

- Navigation links: transparent, no radius, Monument, Ghost Ink.
- Primary CTA: outlined action button, transparent fill, 1px Ghost Ink border, 0px radius.
- Accent action: transparent text in Ignition Orange.
- Standard cards: Cool Stone or Charcoal Canvas, 16px radius, minimal decoration.
- Hero cards: Charcoal Canvas, 24px radius, very large internal padding.

Strict rules:

- Do not use light page backgrounds.
- Do not introduce any accent besides Electric Blue and Ignition Orange.
- Do not use filled CTA buttons.
- Do not round buttons.
- Do not use heavy shadows.
- Do not use generic SaaS cards or pastel gradients.
