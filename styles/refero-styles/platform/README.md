## Use This Style For

- Online galleries, art marketplaces, museum shops, curated catalog pages, and editorial art retail.
- Interfaces where artworks should carry every bit of color.
- Dense-but-elegant product grids with compact metadata.
- Pages that need a printed exhibition-catalog feel rather than a commercial ecommerce feel.

## Design Memory

PLATFORM is a white cube gallery translated into UI. The system uses pure white, pure black, compact MediumLLWeb type, 1px borders, zero shadows, and zero rounded corners. Hierarchy comes from a five-step type scale, 400 versus 500 weight, and gallery spacing. Artwork images are the only chromatic content.
