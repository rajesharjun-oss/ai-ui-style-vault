# Colors

| Name | Hex | Use |
| --- | --- | --- |
| Lamp Black | `#000000` | Primary text, card and nav borders, links, icons, structural UI |
| Graphite | `#808080` | Secondary captions, timestamps, de-emphasized metadata |
| Iron Gray | `#aaaaaa` | Tertiary captions, breadcrumb separators, fine print |
| Smoke Gray | `#b3b3b3` | Muted helper text, metadata captions, placeholder labels |
| Concrete Gray | `#cccccc` | Secondary borders, input outlines, disabled states |
| Ash Gray | `#dddddd` | Hairline dividers and subtle surface separation |
| Bone White | `#ffffff` | Page background, card surfaces, negative space |

## Palette Rules

- Use only black, white, and gray for UI.
- Never introduce chromatic UI colors.
- Let artwork imagery provide all color.
- Use black borders for structural separation.
- Use Ash Gray only for subtle bands and dividers.
