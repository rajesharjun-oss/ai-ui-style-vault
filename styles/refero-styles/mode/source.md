## Capture Notes

This bundle paraphrases the Refero style reference into implementation notes for AI-assisted UI building. The Refero style title is Modern Business Intelligence, and the referenced brand is Mode. The bundle uses `mode` as the folder name for easy lookup by brand.

## What To Preserve

- Pale Sage canvas instead of pure white.
- Deep Forest as the main text and dark-surface color.
- Chartreuse Lime as the only filled CTA accent.
- Grenette serif for all 36px and larger headings.
- Graphik for body, UI, buttons, navigation, labels, and eyebrows.
- 4px radius for buttons and inputs.
- 16px radius for cards, images, and large surfaces.
- No shadows; use color layering for hierarchy.
