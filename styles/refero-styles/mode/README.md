## Use This When

Use this style for business intelligence, analytics, dashboards, data notebooks, research tools, embedded reporting, data teams, and B2B products that should feel warm, editorial, and intelligent instead of cold or corporate.

## Core Idea

Mode uses a botanical editorial language: Pale Sage replaces sterile SaaS white, Deep Forest carries text and dark sections, Grenette serif headlines provide magazine-like authority, and a single Chartreuse Lime accent punctuates actions. Depth comes from sage, paper, forest, and chartreuse color layers rather than shadows.
