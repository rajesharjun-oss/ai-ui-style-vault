# Typography

## Fonts

- Display: `Grenette`
- Display fallback: `Fraunces`, `Source Serif 4`, `Tiempos Headline`, `serif`
- UI/body: `Graphik`
- UI fallback: `Inter`, `Sohne`, `Untitled Sans`, `ui-sans-serif`, `system-ui`

## Display Behavior

Use Grenette only at 36px and above. Keep it weight 400 with tight negative tracking. The serif shape and size create hierarchy, not bold weight.

## UI Behavior

Use Graphik for body, UI, buttons, navigation, and eyebrow labels. Weight 600 is reserved for nav and button labels, not body. Use uppercase tracking for 12px to 14px eyebrows.

## Scale

| Role | Size | Line Height | Weight | Tracking |
| --- | ---: | ---: | ---: | ---: |
| Caption | 12px | 1.2 | 500 | 0.72px |
| Body Small | 14px | 1.3 | 400 | 0 |
| Body | 16px | 1.3 | 400 | 0 |
| Subheading | 18px | 1.44 | 400 | 0 |
| Heading Small | 22px | 1.2 | 600 | 0 |
| Heading | 36px | 1.1 | 400 | -0.72px |
| Heading Large | 56px | 1.1 | 400 | -1.68px |
| Display | 96px | 0.9 | 400 | -2.98px |

## Rules

- Use Grenette for display and section headings at 36px and above.
- Do not use Graphik for display headlines.
- Do not apply the serif below 36px.
- Do not use bold 600+ for body or display text.
- Use uppercase Graphik with 0.06em tracking for eyebrow labels.
