# Implementation Prompt

Build a polished botanical business-intelligence interface inspired by the Mode Refero style system.

Use a Pale Sage canvas, Paper White elevated cards, Deep Forest typography, Grenette serif display headings, Graphik UI text, warm documentary workspace photography, and a single Chartreuse Lime action accent. The result should feel like BI in a sunlit greenhouse: confident, editorial, warm, and data-ready.

## Required Style Decisions

- Page background: Pale Sage `#eef2e3`.
- Elevated surfaces: Paper White `#fcfcfc`.
- Main text: Deep Forest `#043f2e`.
- Borders and ghost outlines: Ink Black `#000000`.
- Secondary text: Charcoal `#242423`.
- Primary action: Chartreuse Lime `#c8f169` with Ink Black text.
- Hover/active green: Forest Mid `#2a6f2b`.
- Data-viz secondary accent: Vivid Green `#78c51c`.
- Display font: Grenette or a Fraunces-like serif.
- UI font: Graphik or an Inter-like sans.
- Small controls: 4px radius.
- Cards and images: 16px radius.
- Shadows: none.

## Typography Direction

Use Grenette for headings at 36px and above only. Keep it weight 400 with tight negative tracking. Use Graphik for all UI, body, buttons, nav, labels, and eyebrows. Use uppercase Graphik 12px to 14px with 0.06em tracking for section eyebrows.

## Layout Direction

Create:

- A minimal top nav with left logo, centered links, and right CTA pair.
- A two-column hero with warm documentary photo and large Grenette headline.
- A Deep Forest stat card with chartreuse label details.
- Pale Sage and Paper White alternating sections.
- Feature cards with 16px radius and no shadow.
- 56px to 80px section gaps.

## Avoid

- Pure white page canvas.
- Box shadows.
- Graphik display headlines.
- Serif text below 36px.
- Multiple chromatic accents in one viewport.
- Radii other than 4px and 16px, except pill tags when needed.
- Staged stock photography.
- Duotone or overlay photo treatments.
