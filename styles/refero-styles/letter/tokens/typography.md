# Typography

## Font Families

| Role | Font | Token | Fallback |
| --- | --- | --- | --- |
| Display | Albra Sans | `--font-albra-sans` | GT Sectra, Tiempos Headline, Canela, Playfair Display, Georgia, serif |
| UI and body | Neufile Grotesk Extended | `--font-neufile-grotesk-extended` | Sohne, Inter, IBM Plex Sans, system-ui, sans-serif |

## Type Scale

| Role | Size | Weight | Line Height | Tracking | Token |
| --- | --- | --- | --- | --- | --- |
| caption | 13px | 400 | 1.4 | 0 | `--text-caption` |
| body | 16px | 400 | 1.4 | 0 | `--text-body` |
| subheading | 22px | 600 | 1.2 | 0.44px | `--text-subheading` |
| heading-sm | 28px | 400 or 500 | 1.3 | 0 | `--text-heading-sm` |
| heading | 46px | 600 | 1.2 | 0.92px | `--text-heading` |
| display | 80px | 600 | 1.1 | 1.6px | `--text-display` |

## Rules

- Never set major headlines in the sans face.
- Use 80px display only in the hero.
- Cap section titles at 46px.
- Use 22px serif for special product-card subheads.
- Use the extended grotesque for interface text, body copy, nav links, and buttons.
- Preserve positive tracking on serif headings.
