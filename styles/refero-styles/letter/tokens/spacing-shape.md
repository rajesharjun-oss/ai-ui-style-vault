# Spacing And Shape

## Layout Values

| Purpose | Value |
| --- | --- |
| Density | comfortable |
| Base unit | 4px |
| Page max width | 1200px |
| Section gap | 64-96px |
| Card padding | 32px |
| Element gap | 16px |
| Button padding | 12px vertical, 27px horizontal |

## Radius

| Element | Value | Token |
| --- | --- | --- |
| cards | 0px | `--radius-cards` |
| tags | 2px | `--radius-tags` |
| inputs | 2px | `--radius-inputs` |
| buttons | 2px | `--radius-buttons` |

## Shape Rules

- 2px radius is the standard for controls.
- Cards stay square at 0px radius.
- Avoid pill buttons, large radii, soft cards, and circular avatars.
- The near-square geometry should feel architectural and premium.
