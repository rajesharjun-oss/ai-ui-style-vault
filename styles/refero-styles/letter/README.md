# Letter

AI-ready Refero style bundle for a mixed dark/light private-banking gallery interface: black vault hero, bright editorial body sections, high-contrast serif headlines, extended grotesque UI text, square 2px controls, tinted product panels, and floating metallic 3D renders.

## Source

- Refero style: https://styles.refero.design/style/bcfc6cb0-1b39-4f3f-a95e-bd7b563b0efc
- Reference site: https://letter.co
- Captured: 2026-07-28
- Theme: mixed

## Use This When

- You need a premium finance, private banking, wealth, credit, investment, or card product.
- The UI should feel like a gallery exhibition rather than a conventional SaaS page.
- You want strong editorial type paired with precise, square, low-chrome controls.
- You can support the look with custom 3D metallic or prismatic product visuals.

## Bundle Contents

- `DESIGN.md` - complete AI style reference.
