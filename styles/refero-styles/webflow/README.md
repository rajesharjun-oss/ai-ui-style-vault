## Style Summary

Webflow is a crisp product-tool system: white canvas, near-black text, thin gray borders, generous section rhythm, precise rounded rectangles, and one hard-working blue for actions and active states. The page reads like a professional website builder showing its own interface inside clean browser-frame mockups.

Use this style when an AI needs a sharp SaaS/product marketing UI with high legibility, architectural headline type, browser chrome, cards, logo strips, and confident primary actions.

## What To Borrow

- `#146ef5` as the only meaningful interactive accent.
- Centered white hero with 56-80px weight-600 display typography.
- 1px `#d8d8d8` borders for structure at rest.
- 8px radius for cards, large containers, and image/mockup frames.
- 4px radius for buttons, tags, and inputs.
- 80px section gaps and 24px card padding.
- Realistic product mockups wrapped in browser chrome.
- Monochrome customer logo strips.
- Very limited decorative color: green and orange only inside inline illustration details.

## Avoid

- Extra UI accent colors.
- Resting card shadows.
- Fully rounded pill buttons.
- Soft pastel SaaS warmth.
- Serif or decorative display fonts.
- Dark-surface blue hover states.
- Arbitrary heading sizes outside the defined type scale.
