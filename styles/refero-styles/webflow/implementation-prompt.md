# AI Implementation Prompt

Build the UI in the Webflow style: a crisp, light, product-tool website for a SaaS builder or design platform.

Use a white `#ffffff` canvas, near-black `#080808` text, thin `#d8d8d8` borders, and `#146ef5` as the only meaningful interactive blue. The page should feel precise, architectural, and tool-like.

Core rules:

- Use WF Visual Sans Variable as the primary font, with Inter or system sans as fallback.
- Use display headlines at 56-80px on desktop, weight 600, line-height 1.04, letter-spacing -0.01em.
- Keep hero sections centered on white with no background image.
- Use body text around 16-20px, regular weight, with muted text in `#5a5a5a`.
- Use a 1200px max-width rail and a 12-column desktop grid.
- Use 80px section gaps, 24px card padding, and 16px card/grid gaps.
- Use 8px radius for cards, screenshots, images, and large product frames.
- Use 4px radius for buttons, inputs, tags, and badges.
- Use filled `#146ef5` primary buttons with white text.
- Use 1px `#d8d8d8` borders for resting cards and structure.
- Use shadows only on hover, browser-frame mockups, or sticky/floating elements.
- Show product value through realistic browser chrome and product UI screenshots.
- Use monochrome logo strips for social proof.
- Keep green `#60ed76` and orange `#ffa666` confined to inline illustration details, not UI controls.

Avoid pill buttons, resting-card shadows, extra accent colors, decorative fonts, hero photography, and arbitrary heading sizes.

The final result should feel like a professional website builder explaining itself through clean product UI.
