# Guidelines

## Do

- Use `#146ef5` as the only interactive blue.
- Use 56-80px weight-600 headlines on desktop.
- Use `#080808` text on `#ffffff` for high legibility.
- Use `#d8d8d8` 1px borders to define resting structure.
- Use 8px radius for cards, screenshots, and large containers.
- Use 4px radius for controls, inputs, and badges.
- Use 80px vertical section gaps and 24px card padding.
- Show product capability through browser-frame product mockups.
- Keep customer logo strips monochrome.

## Do Not

- Do not introduce extra chromatic UI colors.
- Do not use green or orange for buttons or status-heavy UI.
- Do not use fully rounded pill buttons.
- Do not apply shadows to resting cards.
- Do not set display headlines below 40px on desktop.
- Do not use weight 400 for hero display copy.
- Do not mix serif or decorative fonts into interface copy.
- Do not use arbitrary heading sizes inside a heading block.
- Do not place Webflow Blue directly on dark hover surfaces without a contrast-safe alternative.

## Implementation Priorities

1. Build a white page with a centered hero.
2. Establish the large weight-600 headline.
3. Add a primary `#146ef5` CTA.
4. Place product UI inside a browser-frame mockup.
5. Add a 3-column card row with 8px cards and 1px gray borders.
6. Use 80px section rhythm.
7. Add monochrome logo strips and restrained badges.

## Common Failure Modes

- The page becomes generic when the blue is diluted by extra colors.
- The system becomes too soft if buttons become pills.
- Resting shadows make the layout feel like a generic template.
- Lifestyle photography makes the page feel less like a builder tool.
