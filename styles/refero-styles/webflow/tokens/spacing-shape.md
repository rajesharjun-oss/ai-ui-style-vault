# Spacing And Shape

## Spacing

| Purpose | Value | Notes |
| --- | ---: | --- |
| Base unit | 4px | The spacing system compounds from a tight base unit |
| Max content width | 1200px | Centered page rail |
| Section gap | 80px | Default vertical rhythm |
| Card padding | 24px | Standard card inner spacing |
| Element gap | 16px | Card grids, form groups, and feature stacks |
| Hero support max width | 560px | Keeps hero copy controlled |
| Nav height | 56px | Sticky top navigation |
| Cookie banner max width | 380px | Fixed bottom-left consent block |

## Radius

| Element | Value | Notes |
| --- | ---: | --- |
| Buttons | 4px | Professional tool feel |
| Inputs | 4px | Matches controls |
| Tags and badges | 4px | No pills |
| Cards | 8px | Standard large container shape |
| Product screenshots | 8px | Browser mockup frame radius |
| Large containers | 8px | Panels, feature cards, image frames |

## Borders

Use `1px solid #d8d8d8` for resting cards, inputs, browser-frame lines, and layout structure.

## Shape Rules

- Do not use 9999px pill buttons.
- Use 8px radius for large surfaces.
- Use 4px radius for controls.
- Define resting structure with borders.
- Add shadow only for hover, browser mockups, or floating/sticky UI.
