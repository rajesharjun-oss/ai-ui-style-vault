Impossible Foods is a dark, aggressive food-brand poster system. It uses a velvet wine canvas, one impossible-red action color, giant condensed uppercase display type, flat burgundy product cards, crisp black hairline borders, pill CTAs, and food photography cropped in rough organic masks.
