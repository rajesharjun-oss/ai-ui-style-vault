# Colors

## Core Palette

| Name | Value | Token | Use |
| --- | --- | --- | --- |
| Velvet Wine | `#260212` | `--color-velvet-wine` | Page canvas and deepest section background |
| Burgundy Stage | `#4f0423` | `--color-burgundy-stage` | Section surfaces, card surfaces, lifted bands |
| Impossible Red | `#e10600` | `--color-impossible-red` | Primary action, active toggles, display text, icon emphasis |
| Blush Highlight | `#ffc7c6` | `--color-blush-highlight` | Soft secondary text, inactive toggles, tonal relief |
| Butcher Black | `#000000` | `--color-butcher-black` | Nav background, hairline borders, card outlines |
| Bone White | `#ffffff` | `--color-bone-white` | Nav text, button text, copy on dark surfaces |

## Application Notes

- Impossible Red is the only high-energy chromatic signal.
- Blush Highlight behaves like a soft gray in this system.
- Wine and burgundy create depth without shadows.
- Butcher Black anchors the sticky nav and card borders.
- Do not add success, warning, or informational colors unless the product requires a separate semantic layer.
