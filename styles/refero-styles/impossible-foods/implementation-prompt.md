# Implementation Prompt

Use the Home Page | Impossible Foods style for this UI.

Create a dark, aggressive food-brand interface on Velvet Wine (`#260212`) with Burgundy Stage (`#4f0423`) surfaces. Use Impossible Red (`#e10600`) as the only strong accent. Red is for primary action, active states, and giant display type only. Use Blush Highlight (`#ffc7c6`) for soft secondary text and inactive toggles. Use black for navigation and hairline borders, and white for text on dark surfaces.

Typography:

- Use sans-meat if available.
- Use a condensed display fallback such as Druk Wide or Knockout-style sans for giant headings.
- Use Inter or Sohne-style sans for fallback body and UI text.
- Display text should be uppercase, weight 700, 103px or larger.
- Hero display target: 160px, line-height 0.73, positive tracking around 0.06px.
- Body text should stay compact: 14px to 18px, line-height around 1.4.

Layout:

- Use a full-bleed dark canvas with centered content stacks.
- Top nav is sticky, full-width, and solid black.
- Hero is a centered display-type block with irregular food-photo masks around it.
- Product sections alternate between giant red display headings and product carousels.
- Product grids can use four columns.
- Use spacing for section separation, not divider lines.

Components:

- Primary CTA: `#e10600` fill, `#ffffff` text, 15px radius, 10px 14px padding, 14px uppercase sans-meat weight 500, caret at right.
- Ghost CTA: transparent, 1px white border, white text, same radius and padding.
- Filter toggle: 15px radius, 10px 16px padding, active red fill, inactive blush or white text.
- Product card: `#4f0423` surface, 12px radius, optional 1px black border, no shadow, product image on top, product name in uppercase blush or white.
- Feature card: same surface but 38px radius.
- Masked food image: irregular organic mask, no border, no shadow.

Avoid shadows, gradients, new colors, light backgrounds, serif fonts, soft SaaS cards, and red body copy. The final result should feel like a punk food poster with compact e-commerce controls.
