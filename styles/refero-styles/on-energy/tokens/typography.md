# Typography

## Family

| Role | Font | Fallback | Use |
| --- | --- | --- | --- |
| Primary | Univers Next Pro | Inter, Neue Haas Grotesk, Helvetica Neue | All display, headings, body, UI, nav, and buttons |

## Weights

| Weight | Role |
| --- | --- |
| 300 | Display, hero headlines, section headings, statement text |
| 400 | Body, nav, buttons, captions, UI |

## Type Scale

| Token | Size | Weight | Line height | Tracking |
| --- | --- | --- | --- | --- |
| Micro | 10px | 400 | 1.2 | normal |
| Caption | 12px | 400 | 1.2 | normal |
| Body Small | 14px | 400 | 1.2 | normal |
| Body | 16px | 400 | 1.2 | -0.02em |
| Heading | 24px | 300 | 1.17 | -0.48px |
| Heading Large | 36px | 300 | 1.13 | -1.44px |
| Display | 64px | 300 | 1 | -2.56px |

## Rules

- Never use 500, 600, or 700.
- Use tight tracking at 36px and above.
- Keep the display voice whisper-light, not bold.
- Use the same typeface everywhere for a binary 300/400 system.
