# ON.energy

AI-ready Refero style bundle for ON.energy.

- Source: https://styles.refero.design/style/31e00a99-6946-4f07-829a-b0904a39a20d
- Reference site: https://on.energy
- Captured: 2026-07-28
- Theme: mixed
- Mood: high-voltage caution yellow on midnight steel
- Industry: energy infrastructure, industrial hardware, power systems

## Use This Style For

- Industrial hardware and energy infrastructure landing pages
- Full-bleed product photography sites with a single high-contrast accent
- Technical brand pages that need restraint rather than decorative polish
- Interfaces organized by dark image sections, yellow statement panels, and industrial white content blocks

## Files

- `source.md` records the source URL and capture context.
- `DESIGN.md` is the main human-readable design reference.
- `implementation-prompt.md` is a direct prompt for an AI coding agent.
- `style.json` is a structured summary for indexing and retrieval.
- `tokens/` contains focused notes for colors, type, spacing, components, guidelines, layout, and imagery.
- `code/` contains CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` reserves the screenshot slot for manual or automated captures.

## Core Signature

ON.energy is a flat industrial-signage system: pure black, caution yellow, industrial white, whisper-light Univers display type, compact utilitarian controls, no gradients, no shadows, and full-bleed sections that act like discrete visual panels.
