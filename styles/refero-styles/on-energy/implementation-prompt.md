# Implementation Prompt

Use the ON.energy style for this UI.

Create a mixed industrial interface built from three full-bleed modes: dark product photography, full yellow statement sections, and industrial white content sections. Use Caution Yellow (`#fff313`) as the only strong chromatic signal. Use Midnight Steel (`#000000`) for dark surfaces and text on yellow. Use Industrial White (`#eeeeee`) for light sections and text on dark sections.

Typography:

- Use Univers Next Pro as the only typeface.
- If unavailable, use Inter or Helvetica Neue with only weights 300 and 400.
- Use weight 300 for all display and heading text.
- Use weight 400 for body, nav, buttons, and UI.
- Do not use 500, 600, or 700.
- Display: 64px, line-height 1, tracking -2.56px.
- Heading large: 36px, line-height 1.13, tracking -1.44px.
- Body: 16px, line-height 1.2.

Layout:

- Do not use a global max-width container for full-bleed dark, yellow, or white sections.
- Alternate dark image, yellow statement, and industrial white content sections.
- Use 120px major section gaps.
- Light content can use a 400px to 500px text column and 2-column image grid.
- Hero should use full-bleed dark hardware photography with a left-aligned white 64px headline.

Components:

- Yellow CTA: `#fff313` fill, black text, 6px radius, 7px 16px padding, 14px Univers 400, no shadow.
- Nav pill: `#333333` fill, `#eeeeee` text, 6px radius, 5px 14px padding, 14px Univers 400.
- Product highlight card: `#333333` or near-black, 9px radius, 24px padding, optional `#4b4b4b` border or yellow accent.
- News image card: image with 16px radius, title in 24px Univers 300.
- Section heading: 36px Univers 300, black, tight tracking.
- Body text: black on light/yellow sections, Aluminum `#afafaf` on dark.

Avoid shadows, gradients, large radii, yellow body text, lifestyle photography, decorative illustration, and heavy type weights. The final result should feel like precise industrial signage wrapped around real hardware.
