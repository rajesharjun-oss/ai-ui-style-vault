# Spacing And Shape

## Spacing

| Purpose | Value |
| --- | --- |
| Density | comfortable |
| Base unit | 8px |
| Max width | 1200px |
| Section gap | 80px |
| Card padding | 24px |
| Element gap | 8px |

## Scale

`8px`, `16px`, `24px`, `32px`, `40px`, `48px`, `56px`, `64px`, `80px`, `112px`, `128px`, `160px`, `176px`

## Radius

| Element | Value |
| --- | --- |
| Small cards | 8px |
| Cards | 20px |
| Large cards | 24px |
| List items | 28px |
| Buttons | 9999px |
| Icons | 9999px |

## Shape Rules

- Use full radius for buttons and icon containers.
- Use 20px for most cards.
- Use 24px for large cards.
- Avoid sharp corners.
