# Typography

## Primary Font

Name: `Monument Grotesk`

Fallbacks: Inter, General Sans, Sohne, system-ui, sans-serif

Role: every piece of text in the interface.

Rules:

- Use one typeface only.
- Use weight 400 only.
- Do not use bold, italic, light, serif, mono, or a secondary font.
- Let scale and whitespace create hierarchy.
- Use tight line-height for display text.
