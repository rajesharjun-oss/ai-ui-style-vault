# Colors

## Accent

| Name | Value | Role |
| --- | --- | --- |
| Cream Notice | `#ffe9bf` | Top announcement bar only. |

## Neutrals

| Name | Value | Role |
| --- | --- | --- |
| Ink | `#171717` | Primary text, wordmark, filled buttons, and navigation emphasis. |
| Carbon | `#222222` | Icon and decorative vector strokes. |
| Pewter | `#5e5e5e` | Helper text and emphasized secondary copy. |
| Slate | `#6f6f6f` | Secondary text, metadata, labels, and muted icons. |
| Ash | `#a0a0a0` | Tertiary text, disabled text, and placeholders. |
| Stone | `#c7c7c7` | Abstract 3D forms and pale decorative depth. |
| Graphite Hairline | `#e5e7eb` | Borders, dividers, card edges, and input borders. |
| Vellum | `#f3f3f3` | Secondary surfaces, publication logo cards, and hover washes. |
| Paper | `#ffffff` | Page canvas, cards, and product preview background. |

## Rules

- Keep the interface achromatic.
- Use Cream Notice only for the top strip.
- Use Ink as the primary action fill.
- Use Graphite Hairline for all borders and dividers.
- Avoid colored UI accents.
