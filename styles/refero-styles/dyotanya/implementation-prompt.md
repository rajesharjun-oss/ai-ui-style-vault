# Implementation Prompt

Use the Dyotanya style for this UI.

Create a light editorial sketchbook interface on warm paper (`#f5f5f3`). The page should feel hand-made and personal, with oversized thin serif typography, mixed roman and italic emphasis, black hand-drawn SVG line work, dusty-blue borders, circular images, and hard offset shadows.

Color:

- Canvas: `#f5f5f3`.
- Text and line art: `#000000`.
- Hard offset shadow: `#333333`.
- Card surface: `#ffffff`.
- Decorative border and soft action color: `#81aed9`.
- Stronger blue interactive state: `#55a1ea`.
- Inline links only: `#ff8562`.

Typography:

- Use Simeiz for hero and headings. If unavailable, use Playfair Display or DM Serif Display.
- Hero display: 80px, weight 300, line-height 1.
- Section headings: 46px to 48px, weight 300, line-height 1.
- Small headings: 24px to 30px, weight 300.
- Mix roman and italic words inside the same heading. Do not set whole headings in one style.
- Use Manrope for all functional UI: nav, buttons, captions, body support copy, forms, and labels.
- Use Manrope tracking around `-0.036em` for compact modern contrast.

Layout:

- Keep the page max width around 1200px.
- Use 80px section gaps.
- Use asymmetric placement, staggered cards, and open breathing room.
- The hero should be a flowing type composition with inline circular imagery and SVG squiggles, not a standard two-column marketing hero.
- Let hand-drawn lines connect text and cards.

Components:

- Pill CTA: 3000px radius capsule or 30px rounded button, 1.5px black border, hard `4px -4px 0 0 #333333` offset shadow, Manrope 14px medium uppercase text.
- Portfolio card: white surface, 30px radius, 1.5px `#81aed9` border, 48px padding, hard `5px -5px 0 0 #333333` shadow.
- Circular image: 120px radius with 1.5px black border.
- Input: 30px radius, 1.5px dusty-blue border, 20px horizontal padding.
- Decorative line: inline SVG path, 1.5px black stroke, no fill, organic curve.

Avoid corporate SaaS polish, grid-locked layouts, glassmorphism, gradients, soft drop shadows, sharp corners, icon-heavy UI, and coral backgrounds. Coral should appear only as inline navigable text.
