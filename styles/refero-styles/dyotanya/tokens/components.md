# Components

## Hero Serif Statement

- Background: Warm Paper.
- Font: Simeiz or a high-contrast display serif substitute.
- Size: 80px.
- Weight: 300 roman with 400 italic emphasis.
- Line height: 1.
- Add inline circular portrait or SVG line marks.

The hero should read like a flowing editorial statement, not a marketing grid.

## Pill CTA Button

- Radius: 3000px or 30px minimum.
- Border: 1.5px solid Ink Black.
- Fill: Pure White or Dusty Sky depending hierarchy.
- Shadow: `4px -4px 0 0 #333333`.
- Text: Manrope 14px, 500, uppercase.
- Color: Ink Black.

## Client Showcase Card

- Fill: Pure White.
- Radius: 30px.
- Border: 1.5px solid Dusty Sky.
- Padding: 48px.
- Shadow: `5px -5px 0 0 #333333`.
- Include a circular project image, serif title, small Manrope description, and section index.

## Circular Portrait Avatar

- Radius: 120px.
- Border: 1.5px solid Ink Black.
- Use inline with hero copy or at the top of project cards.

## Hamburger Menu Trigger

- Circular button around 40px.
- Border: 1.5px solid Ink Black.
- Hard offset shadow.
- Three simple black horizontal strokes.

## Hand-Drawn Line Decoration

- Inline SVG path.
- Stroke: Ink Black.
- Stroke width: 1.5px.
- Fill: none.
- Use organic curves, loops, and underlines.

## Section Index Marker

- Serif numeric labels such as 01, 02, 03.
- Weight: 300.
- Place near section titles or cards.

## Parenthetical Caption

- Manrope 14px.
- Wrap copy in literal parentheses.
- Position close to heading blocks.

## Input Field

- Radius: 30px.
- Border: 1.5px solid Dusty Sky.
- Horizontal padding: 20px.
- Text: Manrope 16px.
