# Typography

## Families

| Role | Font | Fallback | Use |
| --- | --- | --- | --- |
| Display | Simeiz | Playfair Display, DM Serif Display | Hero statements, section titles, editorial emphasis |
| UI | Manrope | Inter, DM Sans | Nav, buttons, labels, captions, forms, support copy |
| Serif Fallback | Times | Times New Roman | Plain serif fallback when custom display type is missing |
| Alt UI | Suisse Intl | Arial | Small extracted UI details if needed |

## Manrope UI Tracking

Use `-0.036em` tracking for functional Manrope UI text where compactness matters.

## Voice Rules

- Display headings should combine roman and italic words.
- The italic words should mark emotional or expressive emphasis.
- Do not set an entire hero headline in italic.
- Do not set an entire hero headline in plain roman.
- Keep Manrope away from headings above 20px.
