# Colors

## Brand

| Name | Value | Token | Use |
| --- | --- | --- | --- |
| Dusty Sky | `#81aed9` | `--color-dusty-sky` | Decorative card borders, inputs, soft action fills, brand strokes |

## Accent

| Cobalt Wash | `#55a1ea` | `--color-cobalt-wash` | Stronger blue interactive state and link-border emphasis |
| Coral Link | `#ff8562` | `--color-coral-link` | Inline link text only |

## Neutrals

| Name | Value | Token | Use |
| --- | --- | --- | --- |
| Ink Black | `#000000` | `--color-ink-black` | Primary text, line art, icon strokes, functional borders |
| Charcoal | `#333333` | `--color-charcoal` | Offset shadows, inverted surfaces, secondary dark text |
| Warm Paper | `#f5f5f3` | `--color-warm-paper` | Page background and analog paper canvas |
| Pure White | `#ffffff` | `--color-pure-white` | Card surfaces, button fills, bright light panels |

## Application Notes

- Warm Paper is the page background. Do not replace it with pure white.
- Coral Link is for inline text links only.
- Dusty Sky should appear mostly as borders and occasional soft action fill.
- Ink Black carries most information: text, lines, borders, and icon strokes.
- Charcoal is the shadow color for pasted-paper elevation.
