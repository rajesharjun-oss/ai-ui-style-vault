## Radius

| Element | Value |
| --- | --- |
| Body details | 1.5px |
| Cards | 20px to 30px |
| Inputs | 30px |
| Buttons | 30px |
| Pills | 3000px |
| Images | 120px |

## Elevation

| Element | Value | Token |
| --- | --- | --- |
| Cards | `5px -5px 0 0 #333333` | `--shadow-card-hard` |
| Buttons | `4px -4px 0 0 #333333` | `--shadow-button-hard` |

## Notes

- Use compact 10px to 20px gaps inside components.
- Use generous 80px section rhythm across the page.
- Use 48px padding inside showcase cards.
- Keep all depth hard-edged and unblurred.
