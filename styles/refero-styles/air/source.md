## What To Preserve

Air is a photographic, atmospheric creative platform style. The page lives on dark full-bleed sky/cloud imagery and translucent glass-like 3D forms. Product UI should be lightweight: ghost buttons, flat Haze cards, small radii, thin borders, no elevation, and restrained medium-weight sans typography.

## What To Avoid Copying

Do not copy the original logo, screenshots, cloud image, glass form, product copy, or exact page composition. Use the token system and component logic to create original creative operations, asset-library, photo/video workflow, or AI media tools.

## Build Context

This bundle is meant for AI-assisted UI implementation. Use the markdown files for design intent, and use the `code/` files for direct token import when building with CSS variables or Tailwind v4.
