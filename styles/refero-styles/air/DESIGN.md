# Air Style Reference

## Creative Direction

Create a dark, atmospheric creative workspace with full-bleed sky photography and translucent glass sculpture as the emotional layer. The UI should feel fast, light, and functional: bordered ghost controls, off-white cards, no shadows, no colored button fills, and one typographic flourish inside otherwise quiet sans-serif text.

## Visual Priorities

1. Use full-bleed photographic sections as the main visual language.
2. Use Black Void for the dark canvas behind atmospheric sections.
3. Use Haze for cards, inputs, and light surfaces on dark backgrounds.
4. Use Whiteout for text, borders, and strokes on dark surfaces.
5. Use Ink for text and borders on light surfaces.
6. Use Signal Blue only for links, tags, and short emphasized phrases.
7. Use Twilight Blue for heading text on dark backgrounds.
8. Avoid shadows, gradients, and colored filled buttons.

## Screen Composition

Use full viewport photographic hero sections with minimal top navigation. Keep content max width around 1150px for card grids and text areas, but let hero and atmospheric sections break full viewport. Use centered headlines, 2-column or 3-column content grids, Haze cards, photo grids, monochrome logo bars, and compact form cards.

## Material Language

Surfaces are flat. Cards float because they are light against dark photography, not because they cast shadows. Controls use thin borders and small radii. Buttons are ghost or light filled. Inputs alone use a tighter 4px radius.

## AI Implementation Notes

When generating a UI from this style, start with the photographic scene and place UI gently on top. The product should feel like a brand/asset system floating in the sky, not a dense dashboard. Keep the interface quiet enough for images to carry the feeling.
