# Typography

## Families

| Family | Token | Role |
|---|---|---|
| Control | `--font-control` | Primary interface typeface for nav, body, buttons, links, and ordinary headings |
| Control Compressed | `--font-control-compressed` | Ultra-large uppercase display statements |
| Control Cursive | `--font-control-cursive` | Italic accent word inside headlines |
| Control TNT | `--font-control-tnt` | Upright alternative display variant for feature headlines |

## Substitutes

- Control substitute: Inter or system-ui.
- Control Compressed substitute: Anton or Druk Wide.
- Control Cursive substitute: Caveat or Reenie Beanie.
- Control TNT substitute: Inter or another restrained sans.

## Type Scale

| Role | Size | Line Height | Weight | Token |
|---|---:|---:|---:|---|
| Caption | `13px` | `1.5` | `500` | `--text-caption` |
| Body | `16px` | `1.5` | `500` | `--text-body` |
| Subheading | `20px` | `1.4` | `500` | `--text-subheading` |
| Heading | `32px` | `1.1` | `500` | `--text-heading` |
| Heading Large | `56px` | `1` | `400` | `--text-heading-lg` |
| Display | `259px` | `0.85` | `900` | `--text-display` |

## Rules

- Use Control at weight 500 for body, nav, buttons, and links.
- Use weight 400 only for long-form body or cursive display accents.
- Do not set body text below 16px.
- Use Control Compressed rarely and only for massive uppercase statements.
- Break a headline with one Control Cursive word for personality.
