# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Density | `comfortable` |
| Base unit | `4px` |
| Max width | `1150px` |
| Section gap | `48px` |
| Card padding | `20px` |
| Element gap | `8px` |

## Scale

`4px`, `8px`, `12px`, `16px`, `20px`, `24px`, `32px`, `48px`, `52px`, `64px`, `80px`, `120px`

## Radius

| Element | Value |
|---|---:|
| Cards | `12px` |
| Pills | `9999px` |
| Images | `11px` |
| Inputs | `4px` |
| Buttons | `8px` |

## Elevation

- No card shadows.
- No glow effects.
- No glassmorphism for actual UI cards.
- Surfaces distinguish themselves with flat background contrast and 1px borders.
