# Eindhoven Design District

Refero style bundle for Eindhoven Design District.

- Source: https://styles.refero.design/style/c90b584e-de5b-4971-9e13-8ab991bd96c0
- Reference site: https://www.eindhovendesigndistrict.com
- Captured: 2026-07-28
- Theme: light
- Mood: graphic modernist poster, stark black-and-white contrast, rectilinear imagery, vivid color punctuation

## Use This When

Use this style when a site should feel cultural, graphic, editorial, and civic-modernist. It works well for design festivals, art districts, architecture programs, event directories, exhibitions, studios, and cultural guides where strong type and rectangular photography should carry the experience.

The key behavior is high contrast and clean geometry. Most of the system is black on white, with very few grays. Vivid red, pink, and blue are used as punctual blocks or content emphasis, not as a full UI color system.

## Implementation Snapshot

Build a light modernist page with Helvetica Now, large tight headlines, white canvas, black 1px borders, 0px rectangular images and cards, and 500px pill buttons. Add red, pink, or blue only as controlled poster-like punctuation.
