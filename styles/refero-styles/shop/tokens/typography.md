# Typography

## Families

| Family | Token | Fallback | Role |
|---|---|---|---|
| GTStandard-MRegular | `--font-gtstandard` | Shopify Sans, Inter, system-ui | Display, body, UI, navigation, product names, buttons, and metadata. |

## Rules

- Use GTStandard-MRegular-style type across the full interface.
- Use weight 400 for most text.
- Use weight 600 only for short UI emphasis.
- Use slight negative tracking for display and product names.
- Use slight positive tracking for labels.
