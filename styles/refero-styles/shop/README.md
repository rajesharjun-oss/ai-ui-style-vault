# Shop

Source: Refero Styles  
URL: https://styles.refero.design/style/4fa67bd1-f01d-454a-b522-4a0359ff9815  
Reference site: https://www.shop.app  
Captured: 2026-07-28

Shop is a clean commerce-discovery style: white and cool-mist surfaces, big rounded product cards, GT Standard typography, pill controls, product photography, and one vivid violet search/action color. The design feels airy, direct, friendly, and optimized for browsing.

Use this folder as an AI implementation brief. The most useful files are:

- `DESIGN.md` for the full style interpretation.
- `implementation-prompt.md` for a copy-ready prompt to hand to an AI builder.
- `style.json` for structured metadata.
- `code/css-variables.css` for CSS custom properties and component recipes.
- `code/tailwind-v4.css` for Tailwind v4 theme tokens.
- `code/design-tokens.json` for machine-readable tokens.

Core cues:

- Canvas: `#ffffff` Pure White.
- Secondary surface: `#f4f8fa` Mist Blue.
- Product cards: `#f0f4f5` Product Mist and `#f5f5f5` Soft Gray.
- Primary text: `#171717` Ink Black.
- Body/meta text: `#666666` Graphite and `#999999` Ash.
- Border: `#d9d9d9` Hairline.
- Accent: `#5433eb` Shop Violet for search/primary action only.
- Success: `#008060` Checkout Green for trusted commerce states only.
- Typography: GTStandard-MRegular for almost everything.
- Shape: 9999px nav/search/buttons/tabs, 28px product cards, 20px lower cards.
- Depth: product cards are mostly flat; use very light shadow only for floating search or overlay controls.

This is best for commerce discovery, marketplace search, shopping apps, creator storefronts, product grids, category browsing, and consumer recommendations.
