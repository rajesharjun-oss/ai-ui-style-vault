# Layout And Imagery

## Layout

- Use a full-bleed Just Black shell.
- Allow the 224px hero headline to dominate the viewport.
- Let the hero headline bleed toward the viewport edge.
- Use a 1280px rail for content sections after the hero.
- Separate tool feature blocks with full-width Surface 25 hairlines.
- Introduce every major section with a curly-bracket annotation.
- Use 2-column feature rows for tool sections.
- Use 2-column or 3-column grids only for showcase cards.

## Imagery

- Use organic gradient 3D-style shapes: pills, domes, liquid blobs, splashes, and internally lit forms.
- Tie illustration colors to the discipline mapping.
- Let shapes overlap text rather than sitting inside rigid frames.
- Avoid stock photography, dashboards, generic icons, conventional cards, neon glows, and cast shadows.
