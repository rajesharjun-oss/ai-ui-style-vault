# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Density | comfortable |
| Base unit | 4px |
| Max width | 1280px |
| Section gap | 80px |
| Card padding | 24px |
| Element gap | 16px |

## Border Radius

| Element | Radius |
|---|---:|
| Cards | 8px |
| Small tags | 8px |
| Buttons | 100px |
| Pills | 9999px |

## Elevation

Avoid external drop shadows. Organic gradient shapes should feel lit from within through gradients, not through cast shadows.
