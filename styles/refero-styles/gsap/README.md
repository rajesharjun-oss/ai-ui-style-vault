# GSAP

Source: Refero Styles  
URL: https://styles.refero.design/style/00537a20-e99e-4ef2-b119-c6f532c44cc9  
Reference site: https://gsap.com  
Captured: 2026-07-28

GSAP is an animated chalkboard style for a motion library: near-black canvas, warm cream type, huge carved typography, outlined pill buttons, curly-bracket section labels, and five vivid discipline colors used as taxonomy. It should feel expressive and kinetic without becoming a generic neon dark site.

Use this folder as an AI implementation brief. The most useful files are:

- `DESIGN.md` for the full style interpretation.
- `implementation-prompt.md` for a copy-ready prompt to hand to an AI builder.
- `style.json` for structured metadata.
- `code/css-variables.css` for CSS custom properties and component recipes.
- `code/tailwind-v4.css` for Tailwind v4 theme tokens.
- `code/design-tokens.json` for machine-readable tokens.

Core cues:

- Canvas: `#0e100f` Just Black, not pure black.
- Primary text and borders: `#fffce1` Surface Cream, not pure white.
- Nested surface: `#191919` Off Black.
- Hairlines: `#42433d` Surface 25.
- Muted text: `#7c7c6f` Surface 50.
- GSAP green: `#0ae448` to `#abff84` gradient.
- SVG label: `#ff8709` Orangey.
- Scroll label: `#fec5fb` Pink.
- Text label: `#9d95ff` Lilac.
- UI label: `#00bae2` Blue.
- Typography: Mori only, weight 400 for body/UI, 600 for large display and buttons.
- Hero: 224px, weight 600, line-height 0.9, -0.02em tracking.
- Buttons: outlined ghost pills, 100px radius, no solid fills.
- Section signature: curly-bracket annotations like `{ Tools }`.

This is best for animation libraries, creative developer tools, motion portfolios, interactive showcases, dark launch pages, and technical brand systems that need energy without full neon chaos.
