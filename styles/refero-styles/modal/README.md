# Modal

Modal is a dark developer-native style system: black server-room canvas, phosphor-green text, one vivid lime LED accent, Goga headlines, tight Inter UI type, terminal code windows, and 3D green product objects that glow against the void.

- Source: https://styles.refero.design/style/68c15685-5db9-4869-b71d-27240568c9d8
- Reference site: https://modal.com
- Captured: 2026-07-28
- Theme: dark
- Best for: developer platforms, cloud infrastructure, AI compute, terminal-native tools, technical product marketing

## Use This When Building

Use near-black surfaces, phosphor-pale text, and a single lime accent. Treat Lime Pulse as an LED, not a paint bucket: one filled lime element per viewport at most. Use Goga-style headings, Inter for UI/body, 8px cards, 12px buttons, green-tinted hairlines, code-window panels, and one rendered 3D object as the visual anchor.
