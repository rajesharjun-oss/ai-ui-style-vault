# Spacing And Shape

## Spacing

- Density: comfortable
- Base unit: 4px
- Max width: 1280px
- Section gap: 80px
- Card padding: 32px
- Element gap: 20px

## Scale

`4px`, `8px`, `12px`, `16px`, `20px`, `24px`, `28px`, `32px`, `36px`, `40px`, `48px`, `56px`, `64px`, `96px`, `128px`, `160px`

## Radius

| Element | Value |
|---|---:|
| Cards | 8px |
| Inputs | 8px |
| Buttons | 12px |
| Pills | 9999px |
| Icons | 0px |

## Elevation

```css
--shadow-nav: rgba(0, 0, 0, 0.1) 0px 10px 15px -3px, rgba(0, 0, 0, 0.1) 0px 4px 6px -4px;
```

Use shadow only for the navigation bar. Cards, buttons, and content panels should be flat, separated by surface color and 1px hairlines.
