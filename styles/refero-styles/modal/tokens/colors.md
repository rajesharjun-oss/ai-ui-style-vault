# Colors

## Brand And Accent

| Name | Value | Use |
|---|---:|---|
| Lime Pulse | `#7fee64` | Logo, hero CTA pill, active tags, hero phrase, 3D illustration base color |
| Phosphor White | `#ddffdc` | Headings, icon strokes, button text, high-emphasis readable text |
| Mint Frost | `#def0dd` | Light section canvas, card surface tint, soft highlight wash |

## Green Text Scale

| Name | Value | Use |
|---|---:|---|
| Sage 60 | `#8cab87` | Default body copy on black |
| Sage 40 | `#677d64` | Muted helper text and secondary descriptions |
| Moss 70 | `#9cbf93` | Eyebrow labels and section tags |
| Moss 80 | `#aed2a4` | Lead paragraphs and hero subhead |
| Fern Link | `#859984` | Inline links and tertiary navigation |
| Deep Fern | `#697368` | Small labels, microcopy, footer text, customer logos |

## Dark Surfaces

| Name | Value | Use |
|---|---:|---|
| Void Black | `#000000` | Page canvas and full-bleed hero |
| Ground Iron | `#181818` | Primary UI surface, filled button, card surface |
| Charcoal Rust | `#231c1c` | Warm-tinted dark code-window panels |
| Carbon Veil | `#212525` | Nav background, elevated surfaces, selected states |
| Phosphor Blue-Black | `#1f2a33` | Secondary hairline borders and dark dividers |
| Pine 15 | `#3e4a3c` | Low-emphasis interactive border |
| Circuit Border | `#485346` | Primary green-tinted hairline and ghost action border |

## Rules

- Use Lime Pulse as a fill on exactly one element per viewport.
- Do not use Lime Pulse as body text.
- Do not use raw white `#ffffff` or pure green `#00ff00`.
- Use Sage 60 for readable paragraphs.
- Use Phosphor White for headings, icons, and button text.
- Do not introduce non-green accent colors.
