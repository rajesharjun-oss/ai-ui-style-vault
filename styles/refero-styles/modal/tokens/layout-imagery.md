# Layout And Imagery

## Layout

- Use a full-bleed dark layout.
- Contain content at max-width 1280px.
- Hero is centered, not split.
- Content section rhythm: eyebrow, Goga heading, muted body copy, then code or visual content.
- Feature sections can be 2-column: text plus code/visual card.
- Workload cards can form a 3-column grid.
- Section gaps are about 80px.
- Do not use more than 3 columns for card grids.

## Imagery

- Use 3D glowing compute objects, especially a lime-to-emerald cube.
- Use isometric green icons for workload cards.
- Use terminal/code-window cards with syntax highlighting.
- Use customer logos as low-contrast muted green marks.
- Do not use photography.
- Do not use lifestyle imagery.
- Do not use generic colorful illustrations.

## Surfaces

| Level | Name | Value | Purpose |
|---|---|---:|---|
| 0 | Void | `#000000` | Hero, page canvas, full dark sections |
| 1 | Ground | `#181818` | Standard UI surface and filled controls |
| 2 | Carbon | `#212525` | Nav, elevated dark surfaces, selected states |
| 3 | Mint Frost | `#def0dd` | Rare light section canvas or soft card tint |
| 4 | Lime Pulse | `#7fee64` | Highest-emphasis active surface |

## Motion

- Use restrained state transitions.
- Let lime elements feel like a status LED.
- Avoid playful bounce, parallax, and animated decorative gradients.
- Glow may pulse subtly only for live/running status moments.
