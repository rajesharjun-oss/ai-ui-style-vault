# Components

## Primary Filled Button

- Background: `#181818`
- Text: `#ddffdc`
- Border: 1px solid `#ddffdc`
- Radius: 12px
- Padding: 32px
- Font: Inter Variable, 16px, weight 500
- Tracking: -0.352px
- Use when the action should be present but not lime-emissive.

## Ghost Outline Button

- Background: transparent
- Border: 1px solid `#ddffdc`
- Text: `#ddffdc`
- Radius: 12px
- Padding: 32px
- Font: Inter Variable, 16px, weight 500
- Use as secondary action beside primary filled buttons.

## Accent Pill Button

- Background: `#7fee64`
- Text: `#181818` or `#000000`
- Radius: 9999px
- Padding: 12px to 16px vertical, 20px to 24px horizontal
- Font: Inter Variable, 16px, weight 500
- Use one per viewport maximum.

## Outlined Ghost Link

- Background: transparent
- Border: 1px solid `#485346`
- Text: `#859984`
- Radius: 9999px
- Padding: 8px
- Font: Inter Variable, 14px, weight 500
- Use for learn-more style actions.

## Navigation Bar

- Background: `#212525`
- Backdrop blur: about 10px
- Border bottom: 1px solid `#1f2a33`
- Shadow: nav shadow only
- Height: about 64px
- Horizontal padding: 24px
- Logo left, nav links center, login and sign-up right.
- Sign-up uses Accent Pill Button treatment.

## Hero Section

- Background: `#000000`
- Centered text stack.
- Headline: Goga 64px, weight 500, line-height 1.
- First phrase may use Lime Pulse, remainder Phosphor White.
- Subhead: Inter 20px, Moss 80, max-width around 640px.
- CTAs: Accent Pill and Ghost Outline.
- Visual anchor: single glowing green 3D cube with radial halo.

## Code Window Card

- Background: `#181818` or `#212525`
- Radius: 12px to 16px
- Border: 1px solid `#485346`
- Top bar: traffic-light dots
- Content: monospaced syntax, such as Fira Mono
- Syntax colors: Lime Pulse keywords, Phosphor White strings, Sage 40 comments.
- No shadow.

## Workload Card

- Background: `#1f2a33` or `#181818`
- Radius: 8px
- Border: optional 1px `#485346`
- Padding: 32px
- Title: Goga 24px, Phosphor White
- Description: Inter 16px, Sage 60
- Top half: green isometric 3D icon.

## Eyebrow Label

- Font: Inter Variable, 12px, weight 500
- Transform: uppercase
- Tracking: 0.6px
- Color: `#9cbf93`
- Place 8px to 12px above heading.

## Customer Logo Strip

- Logo color: Deep Fern or Fern Link
- Height: 20px to 24px
- Horizontal spacing: 40px to 60px
- No borders or backgrounds.

## Section Divider

- 1px horizontal line in `#1f2a33`
- Span max-width content area.
- Use sparingly between content bands.

## Tag Or Chip

- Radius: 9999px
- Active background: Lime Pulse
- Neutral background: transparent with Circuit Border
- Font: Inter 12px, weight 500
- Padding: 4px 12px
- Use lime fill only for meaningful active/live/running states.
