# Modal - Style Reference

Modal feels like a phosphorescent terminal in a dark server room. The interface is almost entirely black and muted green, with one vivid lime element behaving like a live status LED.

## Visual Thesis

- Use black as the primary substrate, not just a dark mode.
- Use muted green-gray body text instead of white paragraphs.
- Reserve Lime Pulse for one high-emphasis filled element per viewport.
- Use Goga-style geometric headings with tight negative tracking.
- Use Inter Variable for nav, body, buttons, labels, and footer.
- Communicate depth through surface value shifts and green-tinted hairlines.
- Use code windows and 3D rendered compute objects instead of photography.

## Core Ingredients

- Canvas: Void Black `#000000`.
- Surfaces: Ground Iron `#181818`, Carbon Veil `#212525`, Charcoal Rust `#231c1c`.
- Accent: Lime Pulse `#7fee64`.
- Primary readable text: Phosphor White `#ddffdc`.
- Body text: Sage 60 `#8cab87`.
- Borders: Circuit Border `#485346` and Phosphor Blue-Black `#1f2a33`.
- Shape: 8px cards, 12px buttons, pill radius only for CTAs/tags.

## Page Composition

Use a centered-stack hero: Goga headline, muted green subhead, dual CTA row, then one glowing 3D cube or product object. Below, alternate void and slightly lighter dark sections. Each section should follow a clean technical rhythm: eyebrow, heading, body, then either a code window, a 2-column feature layout, or a 3-column workload card grid.

## Color Behavior

The palette is green-on-black and deliberately narrow. Do not add blue, purple, red, or normal white UI colors. Lime Pulse is for the logo, hero CTA, active tag, hero phrase, and rendered product objects. It should not become body text, background wallpaper, or a general decorative fill.

## Type Behavior

Goga owns H1-H4 and card titles. Inter handles UI and body. Both are tightly tracked. Enable Goga `ss01` and Inter `cv11` where the stack supports font features.
