# Implementation Prompt

Use the Athletics style language for this UI.

Create a dark editorial creative-studio interface that feels like a monograph on black velvet: Obsidian canvas, Charcoal section bands, huge thin serif headlines, quiet Sohne body text, pill buttons, hairline dividers, and no chromatic interface color. Color may appear only inside photography or an image-filled brand mark.

Core rules:

- Use `#000000` as the base page canvas.
- Use `#1d1d1d` for elevated section bands, cards, and input fields.
- Use `#ffffff` for all readable text and control foregrounds.
- Use `#d6d5d0` only for hairline borders and dividers.
- Never invert this to a light theme.
- Do not introduce colored buttons, colored links, colored badges, or colored backgrounds.
- Use Feature Deck only for display and section headlines at 72px and above.
- Use Feature Deck at 300 weight only.
- Track Feature Deck tightly: around -0.009em at 82px and -0.018em at 116px.
- Use Sohne for navigation, links, body copy, list items, forms, buttons, and footer.
- Use 9999px radius for tags and buttons.
- Use 8px radius only for rectangular cards or image containers.
- Do not use shadows, glows, gradients, or elevation effects.

Recommended structure:

- Minimal top nav: wordmark left, simple text links right, transparent over black.
- Centered hero: large image-filled brand mark, then 116px Feature Deck headline.
- Two-column section opener: small uppercase label plus 72px serif headline on the left, constrained 17px body copy on the right.
- Service index: A/B/C/D letter markers and 82px serif service names.
- Specialty tags as white pills on charcoal.
- Simple contact form with underline-only inputs and a white pill submit button.
- Full-bleed photography only for hero moments or case studies.

Avoid:

- Any chromatic UI accent.
- Cards with shadows.
- Rounded 16px+ cards.
- Serif body copy.
- Light theme sections.
- Decorative icons or illustrations.
- Dense grids.

The result should feel restrained, expensive, typographic, and confident.
