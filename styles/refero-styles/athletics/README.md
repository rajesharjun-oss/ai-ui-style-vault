## Use This Style For

- Creative studios, brand agencies, editorial portfolios, art-directed service pages, and high-confidence case-study sites.
- Interfaces where giant serif typography and negative space should do most of the work.
- Dark full-bleed pages with sparse components, service indexes, and photography-led brand moments.

## Design Memory

Athletics is a dark editorial monograph. The UI lives on Obsidian and Charcoal, with Paper White type, warm Ash hairlines, and no chromatic interface color. Feature Deck at 300 weight creates enormous whisper-light serif headlines, while Sohne handles everything functional. The only color should come from editorial photography or the image-filled brand mark.
