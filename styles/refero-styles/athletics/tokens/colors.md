# Colors

| Name | Hex | Use |
| --- | --- | --- |
| Obsidian | `#000000` | Base page canvas, deepest section backgrounds, footer, hero |
| Charcoal | `#1d1d1d` | Elevated section surfaces, card backgrounds, input fields |
| Ash | `#d6d5d0` | Hairline borders, dividers, input outlines, card edges |
| Paper White | `#ffffff` | Display text, body text, icon strokes, form controls on dark surfaces |

## Palette Rules

- Keep the interface purely monochrome.
- Use Obsidian for the base canvas.
- Use Charcoal only for elevated dark bands or cards.
- Use Paper White for all readable text.
- Use Ash only for hairline separators and input borders.
- Put chromatic color only inside photography or the brand mark.
