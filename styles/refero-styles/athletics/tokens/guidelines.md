# Guidelines

## Do

- Use Obsidian as the base canvas and Charcoal for elevated bands.
- Keep the experience dark-only.
- Set display headlines at 72px to 116px in Feature Deck 300.
- Use tight negative tracking on the serif display type.
- Use 9999px radius exclusively for tags and buttons.
- Use 8px only for rectangular cards or image containers.
- Apply 128px to 144px vertical padding for major section breaks.
- Annotate service indexes with uppercase single letters.
- Restrict all chromatic color to the brand mark or editorial photography.

## Do Not

- Do not introduce colored UI.
- Do not use Feature Deck for body copy, navigation, or functional text.
- Do not apply box-shadows or drop-shadows.
- Do not set display serif at 400 weight or above.
- Do not use gradients, glows, or colored backgrounds behind text.
- Do not use Ash as readable text.
- Do not add background fills to navigation or header areas.

## AI Implementation Notes

- If the page feels empty, increase type scale or vertical space rather than adding components.
- If hierarchy feels weak, use a small label plus huge serif headline.
- If the design feels too plain, add one strong editorial photo or image-filled mark, not UI color.
- If a component feels too app-like, remove chrome and keep it text-led.
