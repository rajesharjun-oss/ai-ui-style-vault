# Spacing And Shape

## Spacing

| Purpose | Value |
| --- | --- |
| Density | Comfortable |
| Base unit | 8px |
| Max width | 1440px |
| Section gap | 128px to 144px |
| Card padding | 24px |
| Element gap | 24px to 32px |

## Elevation

- No shadows.
- No glows.
- No gradients.
- Use flat surface shifts and 1px Ash hairlines only.
- Let typography create depth.
