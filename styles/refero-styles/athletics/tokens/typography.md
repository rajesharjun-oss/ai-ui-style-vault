# Typography

## Families

- Display: Feature Deck.
- Display fallback: GT Sectra Display Light, Canela, Domaine Display Thin, serif.
- Body: Sohne.
- Body fallback: Inter, Neue Haas Grotesk, Untitled Sans, Arial, sans-serif.

## Weights

- Feature Deck: 300 only.
- Sohne: 300 and 400.

## Type Scale

| Role | Size | Weight | Line Height | Tracking |
| --- | --- | --- | --- | --- |
| Body Small | 16px | 400 | 1.5 | 0 |
| Functional | 17px | 300 | 1.3 | 0 |
| Subheading | 22px | 300 | 1.3 | 0 |
| Heading | 72px | 300 | 1.1 | -0.009em |
| Heading Large | 82px | 300 | 1.05 | -0.009em |
| Display | 116px | 300 | 1.05 | -0.018em |

## Usage

- Use Feature Deck only at 72px and above.
- Use Feature Deck for hero headlines, section openers, and service index entries.
- Use Sohne for all functional UI and body copy.
- Pair small uppercase Sohne labels with giant Feature Deck headlines.
- Never use serif type for body copy.
- Never increase the display serif above weight 300.
