# Components

## Top Navigation Bar

- Background: transparent or Obsidian.
- Border: none.
- Shadow: none.
- Left: wordmark in 16px Sohne 400 Paper White.
- Right: text links in 16px Sohne 400 Paper White.
- Link gap: about 16px.
- No underline, no background fill, no color hover.

## Hero Mark And Display Headline

- Background: Obsidian.
- Layout: centered stack.
- Mark: large image-filled A logogram or equivalent brand mark.
- Headline: 116px Feature Deck, 300 weight, Paper White.
- Tracking: -0.018em.
- Color: only inside the photographic mark.

## Two-Column Section Opener

- Background: Charcoal.
- Left: uppercase 16px Sohne 400 label, then 72px Feature Deck 300 headline.
- Right: 17px Sohne 400 body copy, max width about 480px, line-height 1.5.
- Padding: 128px to 144px vertical.

## Specialty Tag

- Background: Paper White.
- Text: Obsidian.
- Radius: 9999px.
- Padding: about 8px vertical, 16px horizontal.
- Font: 16px Sohne 400.
- Border: none.
- Shadow: none.

## Service Index List

- Service names: 82px Feature Deck 300 Paper White.
- Line height: 1.05.
- Letter markers: uppercase A, B, C, D in 16px Sohne 400 Paper White.
- Layout: marker flush-left, service name aligned beside it.
- Dividers: none.
- Bullets: none.

## Hairline Divider

- Border: 1px solid Ash.
- Use between major zones only.
- Do not use as body text color.

## Pill Button

## Form Input
