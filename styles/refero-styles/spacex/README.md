## Use This When

Use this style when a page should feel cinematic, engineered, and extreme. It works well for aerospace, robotics, defense, hardware launches, scientific missions, high-performance engineering, and any product story where dramatic photography should dominate the interface.

The key rule is total restraint. There is no accent color, no card system, no filled CTA color, and no soft background layer. The UI is off-white technical type and hairline outlines over black or over full-bleed imagery.

## Implementation Snapshot

Build a single-column full-bleed dark experience. Use absolute black as every page surface, D-DIN-style uppercase technical typography, 48px all-caps headlines, 13px widely tracked body copy, ghost outline buttons, and text blocks anchored in the left third of cinematic spacecraft imagery.
