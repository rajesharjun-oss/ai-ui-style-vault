## Use This When

Use this style when a site should feel bright, accessible, spacious, and product-led without becoming sterile. It works well for website builders, creator tools, template marketplaces, AI creation products, and SaaS pages that need friendly confidence.

The key behavior is restraint inside brightness: white canvas, black type, hairline gray borders, pill buttons, generous section gaps, and one saturated Electric Blue for primary action. Lime, lemon, lavender, and violet are section punctuation, not general UI paint.
