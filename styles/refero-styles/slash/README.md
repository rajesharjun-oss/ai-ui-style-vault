# Slash

Source: Refero Styles  
URL: https://styles.refero.design/style/7c38e84b-aea0-4c8f-b3e9-60b994ee6c6b  
Reference site: https://www.slash.com  
Captured: 2026-07-28

Slash is a midnight fintech vault system: near-black canvas, editorial Ivy Presto serif headlines, compact Inter UI, copper category punctuation, and a gold chart gradient used only for financial data. The interface stays quiet through thin borders, pill controls, 10px cards, and almost no elevation.

Use this folder as an AI implementation brief. The most useful files are:

- `DESIGN.md` for the full style interpretation.
- `implementation-prompt.md` for a copy-ready prompt to hand to an AI builder.
- `style.json` for structured metadata.
- `code/css-variables.css` for CSS custom properties and component recipes.
- `code/tailwind-v4.css` for Tailwind v4 theme tokens.
- `code/design-tokens.json` for machine-readable tokens.

Core cues:

- Canvas: `#08080a` Obsidian.
- Card surface: `#040406` Onyx.
- Panel surface: `#121317` Carbon.
- Hairline borders: `#1c1d22` Graphite and `#2e3038` Slate.
- Default body text: `#e2e3e9` Bone.
- Primary emphasis: `#ffffff` Paper White.
- Editorial accent: `#cc9166` Copper, used only for category labels and editorial links.
- Chart accent: gilded gradient, used only for financial data visualization.
- Display: Ivy Presto, 28px and above only.
- UI/body: Inter, compact and readable.
- Controls: 9999px pills for buttons, inputs, tags, status; 10px cards; 2px nav underline.

This is best for fintech, corporate spend, banking tools, finance dashboards, premium SaaS, editorial finance content, and data-heavy product marketing.
