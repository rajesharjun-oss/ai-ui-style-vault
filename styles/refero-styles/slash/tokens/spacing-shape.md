# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Density | compact |
| Max width | 1216px |
| Section gap | 160px |
| Card padding | 24px |
| Element gap | 8px |

## Scale

`4, 6, 8, 9, 10, 12, 14, 16, 20, 22, 24, 32, 40, 48, 105, 224`

## Radii

| Element | Value |
|---|---:|
| Nav underline | 2px |
| Cards | 10px |
| Buttons | 9999px |
| Inputs | 9999px |
| Tags | 9999px |
| Icons | 9999px |
| Status indicators | 9999px |

## Shape Rules

- Use pills for buttons, inputs, tags, icon wells, and status.
- Use 10px radius for cards.
- Use 2px for nav underline indicators.
- Do not use shadows for elevation.
- Use hairline borders and surface steps.
