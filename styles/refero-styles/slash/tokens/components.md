# Components

## Primary Action Button

Paper White fill, black text, 9999px radius, Inter 14px/500, 10px by 20px padding, no border. Use only for the single most important action per viewport.

## Ghost Outline Button

Transparent fill, 1px Paper White border, Paper White text, 9999px radius, Inter 14px/500, 10px by 20px padding. Use for secondary actions.

## Pill Tag Button

Transparent fill, 1px Steel border, 9999px radius, 6px by 10px padding, Inter 12px to 14px. Use for categories, filters, and secondary inline actions.

## Hero Chart Card

Onyx surface, 10px radius, no visible border. Contains balance header, period filter pill, gilded gradient line chart, and spend-limit input.

## Transaction List Card

10px panel with dense rows, circular icon wells, merchant names, right-aligned amounts, and Slate hairline dividers.

## Testimonial Video Card

10px card, full-bleed image, dark gradient overlay at the bottom, white name text, muted title and company text. No border, no shadow.

## Blog Post Card

10px transparent card. Image top, Copper category eyebrow, date, white Inter title, and Mist read-time metadata.

## Email Capture Input

Transparent fill, 1px Paper White border, 9999px radius, Steel placeholder, larger left padding. Pair with the white primary pill.

## Navigation Link

Inter 14px, Fog inactive, Paper White active, no background, no border. Hover underline uses 2px radius.

## Stat Display

Ivy Presto number at 28px to 44px in Paper White, Inter 14px Fog caption below.

## Data Table Row

Transparent row, 1px Graphite bottom border, compact cells, Fog headers, Bone values, right-aligned numerics.
