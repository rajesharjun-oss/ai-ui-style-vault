# AI Implementation Prompt

Build a polished UI in the Slash style.

Use a dark fintech vault system: `#08080a` Obsidian page canvas, `#040406` Onyx cards, `#121317` Carbon panels, `#1c1d22` and `#2e3038` hairline borders, Bone body text, Paper White headings, and one warm Copper accent. The UI should feel like a premium financial product with editorial magazine restraint.

Typography:

- Use Ivy Presto-style serif for every display and heading at 28px and above.
- Use Inter for body, nav, controls, forms, tables, labels, and cards.
- Do not use Ivy Presto for body copy or small UI.
- Do not replace Ivy Presto with Inter for display text.

Layout:

- Use a 1216px centered max-width.
- Use 160px desktop section gaps.
- Hero should be split: left serif headline and email capture, right dark product dashboard card.
- Use dark card grids, testimonial media cards, blog cards, stat callouts, and dense tables.

Components:

- Primary CTA: white fill, black text, 9999px radius, Inter 14px/500, 10px by 20px padding. Use only once per viewport.
- Ghost CTA: transparent fill, 1px white border, white text, 9999px radius.
- Email input: transparent fill, 1px white border, 9999px radius, Steel placeholder.
- Card: Onyx or Carbon surface, 10px radius, hairline border only when needed.
- Blog card: transparent fill, image top, Copper category label, white Inter title, Mist metadata.
- Data table: transparent rows, Graphite dividers, Fog headers, Bone values, right-aligned numerics.

Strict rules:

- Do not add blue, green, purple, or other accents.
- Do not use Copper on buttons, icons, or large text blocks.
- Do not use pure white for long-form body copy.
- Do not use drop shadows.
- Do not apply the gilded gradient except to chart lines and financial data accents.
