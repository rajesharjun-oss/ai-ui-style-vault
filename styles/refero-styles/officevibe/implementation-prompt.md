# Implementation Prompt

Build in the Officevibe style: a warm editorial HR-product interface with cream paper canvas, serif italic headline accents, modern compressed sans headings, deep ink-navy cards, electric cobalt actions, and a persistent bottom chat widget.

Use these rules:

- Page canvas: `#f9f8f6`.
- Card and nav surface: `#ffffff`.
- Primary text: `#171417`.
- Editorial dark surface: `#0c1754`.
- Primary action: `#2545ff`.
- Soft cobalt chip: `#eaebf8`.
- Warm borders: `#f0e9e1`.
- Muted text: `#969696`.
- Input border: `#cccccc`.
- Display font: Martinaplantijn or GT Super Display.
- Modern sans: Abcfavoritvariable or ABC Diatype.
- UI/body font: Inter.
- Display large: 64px, serif, weight 400, line-height 1.
- Display: 48px, serif, weight 400, line-height 1.1.
- Heading large: 40px, Abcfavorit, weight 400, tracking -0.8px.
- Body: 16px, Inter 400, line-height 1.6.
- Buttons: 100px radius, 12px 24px padding.
- Cards: 16px radius, 32px padding.
- Inputs: 16px radius.
- Images: 24px radius.
- Section gap: 80px.
- Page max width: 1200px.

Design structure:

1. Warm Canvas navigation with Workleap-style wordmark, quiet nav links, login, and cobalt demo CTA.
2. Hero with a 48px to 64px serif headline where one phrase is italic.
3. Product dashboard or people-ops visual in a Paper White card.
4. Three-step card row with one Ink Navy card, one neutral Paper White card, and one cobalt-bordered accent card.
5. FAQ or content sections with cream borders.
6. Persistent bottom-center chat widget with suggestion chips.
7. Ink Navy footer.

Avoid:

- Generic cold-gray SaaS surfaces.
- Electric Cobalt body text.
- Blue section backgrounds.
- Heavy black shadows.
- Sharp buttons.
- Display headlines set in Inter.
- Long centered paragraphs.

The result should feel like a humane HR magazine article that became a product page.
