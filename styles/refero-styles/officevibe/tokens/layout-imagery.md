# Layout And Imagery

## Layout

- Use a centered 1200px max-width layout.
- Keep the page on Warm Canvas.
- Use 80px section gaps.
- Use editorial hero text with one italic phrase.
- Pair text with product dashboard visuals.
- Use three-card step rows.
- Alternate cream page sections with Ink Navy feature sections.
- Keep footer dark navy.
- Anchor chat widget bottom-center.

## Imagery

Use:

- Product dashboards.
- Survey widgets.
- Coaching cards.
- Chat assistant UI.
- Score gauges.
- Warm people-ops illustrations.
- Metric rows with gentle sentiment dots.

Avoid:

- Stock photography.
- Cold gray enterprise dashboards.
- Neon gradients.
- Generic abstract shapes.
- Overly technical developer-tool visuals.
