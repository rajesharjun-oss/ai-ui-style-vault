# Colors

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Ink Navy | `#0c1754` | `--color-ink-navy` | Display headings, dark feature cards, footer, editorial body color |
| Electric Cobalt | `#2545ff` | `--color-electric-cobalt` | Filled action buttons, active links, most important icon |
| Lavender Mist | `#eaebf8` | `--color-lavender-mist` | Tinted badges and soft cobalt highlight washes |
| Charcoal | `#171417` | `--color-charcoal` | Primary text, nav text, icon strokes |
| Graphite | `#222222` | `--color-graphite` | Secondary text, ghost button text, inactive nav labels |
| Stone | `#969696` | `--color-stone` | Helper text, placeholder content, metadata |
| Smoke | `#cccccc` | `--color-smoke` | Input borders, disabled states, neutral dividers |
| Cream Border | `#f0e9e1` | `--color-cream-border` | Hairline dividers, card borders, warm section separators |
| Warm Canvas | `#f9f8f6` | `--color-warm-canvas` | Page background and soft surface fills |
| Paper White | `#ffffff` | `--color-paper-white` | Cards, nav, inputs, button text on blue |

## Color Rules

- Keep the canvas warm, not white or cool gray.
- Use Cream Border for structure.
- Reserve Electric Cobalt for true actions and active states.
- Use Ink Navy for editorial weight and dark cards.
- Do not use cobalt for body text or large backgrounds.
