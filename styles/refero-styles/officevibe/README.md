# Officevibe

Light editorial HR-product style system captured from Refero Styles.

- Source: https://styles.refero.design/style/ced1c98f-d489-48f7-a01f-1fa59a07b706
- Reference site: https://officevibe.com
- Captured: 2026-07-28
- Theme: light
- Mood: editorial journal on warm cream paper

## Use This When

Use this style for HR products, employee engagement tools, survey software, workplace analytics, coaching products, people-ops dashboards, and SaaS pages that need to feel thoughtful, humane, and editorial instead of generic corporate.

## Core Idea

Officevibe is a warm cream product system with literary headline gestures. It combines a soft paper canvas, ink navy feature cards, electric cobalt actions, cream borders, and serif italic accents inside otherwise modern SaaS layouts. The persistent chat widget is part of the identity, not an add-on.
