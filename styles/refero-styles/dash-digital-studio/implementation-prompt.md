# Implementation Prompt - Dash Digital Studio Style

Build an original UI using the Dash Digital Studio Refero style as visual direction.

Create a strictly achromatic editorial gallery system on warm off-white paper. Use giant compressed uppercase typography, flat product photography, 2-up case study grids, hairline rules, and small dark pill actions. The interface should feel like a museum wall or design-studio archive, not a colorful SaaS landing page.

## Must Preserve

- Zero chromatic accent color.
- Bone `#f0f0f0` page background and Carbon Black `#2a2a2a` text.
- Linen `#fafafa` and Parchment `#f0edea` as subtle warm surface shifts.
- Founders Grotesk style type as the main family.
- Weight 300 only for display/section titles at 40px and above.
- Weight 400 for body, nav, meta, and labels.
- Display sizes around 70-101px with line-height 0.80-0.88.
- Negative tracking on all text, especially display.
- Uppercase nav, meta, project titles, and action labels.
- 0px radius on cards, images, and product frames.
- 999px radius only for pill buttons and tags.
- Shadowless, gradient-free, flat surface model.
- Full-bleed product photography in 2-up case study layouts.

## Avoid

- Copying Dash Digital Studio logos, work imagery, exact case studies, page copy, or proprietary layout details.
- Any color accent, including colored CTAs.
- Heavy borders beyond hairline rules.
- Rounded image corners.
- Drop shadows, glows, glassmorphism, gradients, or soft depth.
- Dense dashboard UI, icons, illustrations, or decorative graphics.
- Serif overuse; Editorial Neue style serif should be rare.

## Component Direction

Use the first viewport as a pure typographic hero: giant uppercase headline, tight leading, no visual card. Follow it with portfolio-style case study cards: meta row, title, full-bleed product image, dark pill CTA. Keep everything warm, flat, and exacting.
