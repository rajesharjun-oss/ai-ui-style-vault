# Layout And Imagery

## Layout

- Use a full-bleed light page on Bone.
- Keep content centered inside a 1440px max-width track.
- Start with a pure typographic hero, not a card-based hero.
- Use a 2-up case study grid with about 29px column gaps.
- Put uppercase discipline tags above project titles.
- Use generous 80-120px gaps between sections.
- Use hairline section rules sparingly.
- Keep client lists as table-like rows with simple borders.

## Imagery

- Use full-bleed product photography as the only imagery.
- Keep image radius at 0px.
- Do not add overlays, masks, gradients, or duotone treatments.
- Avoid lifestyle and people photography.
- Avoid icons and illustrations.
- Let the work imagery supply visual energy while the UI stays neutral.

## Composition Rules

- Alternate wide whitespace with dense case-study or brand rows.
- Do not alternate colorful section backgrounds.
- Keep the photographic grid raw and gallery-like.
- Use dark pill actions as compact dots of interaction.
- Use type and spacing as the main design material.
