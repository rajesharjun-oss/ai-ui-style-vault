# Components

## Pill Action Button

- Fill: `#2a2a2a`
- Text: `#fafafa`
- Radius: 999px
- Padding: about 4px vertical, 14px horizontal
- Type: 12px, uppercase, Founders Grotesk style, weight 400
- Use: case study actions, `VIEW WORK`, `VIEW CASE STUDY`, `MORE +`

## Text Nav Link

- Text: `#2a2a2a`
- Hover: optional shift to `#000000`
- Type: 12-14px, uppercase, weight 400
- Decoration: none
- Spacing: about 29px between items

## Brand Mark Wordmark

- Text-only wordmark
- Type: 12-14px, weight 400
- Color: `#2a2a2a`
- Avoid decorative icon unless using licensed brand asset

## Editorial Display Heading

- Size: 70-101px
- Weight: 300
- Case: uppercase
- Color: `#2a2a2a`
- Line height: 0.80-0.88
- Tracking: -0.0300em to -0.0600em
- Use: hero and section headlines

## Case Study Card

- Layout: two-up grid
- Gap: about 29px between columns
- Meta: uppercase 12px text
- Title: uppercase 22px text
- Image: full-bleed product photo, 0px radius, no border, no shadow
- CTA: dark pill action

## Meta Tag Row

- Type: 12px uppercase
- Color: `#2a2a2a`
- Separate disciplines with slash, plus, or compact text separators
- No fill, border, or icon

## Brand List Row

- Full-width row
- Border: 1px solid `#2a2a2a` bottom
- Left: uppercase brand name
- Right: uppercase service tags plus `MORE +` pill
- No alternating fills

## Project Image Frame

- Radius: 0px
- Border: none
- Shadow: none
- Overlay: none
- Use: raw rectangular product photography

## Text Input

- Border: 1px solid `#2a2a2a`
- Radius: 4px
- Background: transparent
- Type: 16px, weight 400
- Focus: border can shift to `#000000`; do not use colored focus rings
