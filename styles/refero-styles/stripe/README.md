# Stripe

Source: Refero Styles  
URL: https://styles.refero.design/style/48e5de76-05d5-4c4e-a269-c7c245b291ec  
Reference site: https://stripe.com  
Captured: 2026-07-28

Stripe is a cool-white fintech ledger style: deep navy text, whisper-light sohne-var typography, 4px precision geometry, hairline section dividers, paired CTA buttons, and a single indigo action color. It feels technical, calm, global, and operational.

Use this folder as an AI implementation brief. The most useful files are:

- `DESIGN.md` for the full style interpretation.
- `implementation-prompt.md` for a copy-ready prompt to hand to an AI builder.
- `style.json` for structured metadata.
- `code/css-variables.css` for CSS custom properties and component recipes.
- `code/tailwind-v4.css` for Tailwind v4 theme tokens.
- `code/design-tokens.json` for machine-readable tokens.

Core cues:

- Canvas: `#f5f7fb` Cloud Ledger.
- Card surface: `#ffffff` Paper White.
- Primary text: `#0a2540` Deep Navy.
- Secondary text: `#425466` Slate Ledger.
- Muted text: `#6b7c93` Blue Gray.
- Hairlines: `#e6ebf1` Border Mist and `#d6dee8` Grid Line.
- Accent: `#635bff` Indigo Action for primary CTAs, arrows, and active states.
- Typography: sohne-var, weight 300 for most headings and body.
- Body copy: 16px/1.56.
- Shape: 4px cards/buttons/inputs, 999px small pills.
- Depth: no shadows; use dividers, grids, and contrast.

This is best for fintech, payments, infrastructure SaaS, developer platforms, API products, enterprise dashboards, marketplaces, and global operations tools.
