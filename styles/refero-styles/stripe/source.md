## What To Preserve

Stripe uses a cool off-white canvas, deep navy typography, very light sohne-var type weights, precision 4px shapes, subtle grid and divider structure, and a single indigo action accent. The interface should feel financial, global, and infrastructure-grade without becoming heavy.

The page relies on:

- Cloud Ledger as the main page background.
- Paper White for cards, panels, and code blocks.
- Deep Navy for primary text, dark surfaces, and structural emphasis.
- Slate Ledger and Blue Gray for body copy and muted metadata.
- Indigo Action for the primary button, active links, arrows, and selected states.
- Green Ledger and Cyan Accent only as tiny data/status accents.
- sohne-var for nearly all text.
- 4px radius for cards, buttons, and inputs.
- Horizontal section rules and grid lines instead of shadows.
- Ledger-like charts, maps, terminal snippets, and table layouts as imagery.
