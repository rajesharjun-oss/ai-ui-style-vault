# Layout And Imagery

## Layout

- Use a centered 1080px content rail.
- Build sections with grid systems and horizontal divider lines.
- Place hero copy on the left and a product/data mockup on the right.
- Alternate Cloud Ledger sections with Paper White modules.
- Use dense product cards for charts, tables, API snippets, maps, and payment rails.
- Keep card content aligned to rows and columns.
- Use footer columns or sitemap grids, not decorative footer cards.

## Imagery

- Use product UI, ledger tables, world maps, charts, API snippets, terminal panels, payment flows, and payment logos.
- Keep visuals technical and data-bearing.
- Use subtle cool gradients only inside product graphics if needed.
- Avoid lifestyle photography, cartoon illustrations, decorative blobs, oversized icons, and gradient backgrounds behind content.
