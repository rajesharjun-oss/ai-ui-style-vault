# Implementation Prompt

Build a cool-white fintech infrastructure interface in the Stripe style.

Use Cloud Ledger (`#f5f7fb`) for the page canvas, Paper White (`#ffffff`) for cards and product panels, Deep Navy (`#0a2540`) for primary text and dark surfaces, Slate Ledger (`#425466`) for body copy, Blue Gray (`#6b7c93`) for captions, Border Mist (`#e6ebf1`) for dividers, and Grid Line (`#d6dee8`) for chart/table rules. Indigo Action (`#635bff`) is the main CTA and active-state color. Cyan, green, and amber may appear only as small chart/status accents.

Typography should be precise and light. Use sohne-var or a close Inter/system fallback across the whole interface. Large headings should be weight 300 with tight negative tracking. Body copy is 16px, weight 300 to 400, line-height 1.56. Buttons and nav links can use weight 500. Do not introduce serif or expressive display fonts.

Use a 4px base unit, 1080px content width, 80px section gaps, 24px card padding, and 16px element gaps. Cards, buttons, inputs, and code panels use 4px radius. Small pills can use 999px radius. Do not use shadows; use surface contrast, hairline borders, table rules, and section dividers.

Expected components:

- Top nav: logo left, compact links center, paired right CTAs, 14px to 15px sohne-var.
- Hero ledger block: left-aligned display heading, short copy, indigo primary CTA, secondary dark/navy CTA, right-side product mockup.
- Product mockup card: white surface, 4px radius, 1px Border Mist border, dense chart/table/code content.
- Data table: 13px to 14px rows, Border Mist dividers, Blue Gray metadata, Deep Navy values, small status chips.
- Code panel: Deep Navy or white, 4px radius, muted line numbers, indigo/cyan syntax accents.
- Metric tile: white card, caption, 31px value, optional small Green Ledger delta.
- Globe/map panel: cool blue-gray map or grid visualization with tiny indigo/cyan nodes.
- Payment method strip: icon row with hairline separators and compact labels.

The page should feel global, technical, financial, trustworthy, and operational. Avoid shadows, expressive illustrations, lifestyle photos, rounded SaaS cards, decorative gradients, heavy font weights, and extra accent colors.
