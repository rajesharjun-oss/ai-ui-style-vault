# Implementation Prompt

Create an original light productivity or personal CRM interface inspired by the Micro Refero style.

Use a warm paper background `#f5f5f5`, near-black ink text `#221f1c`, white product cards, thin borders, compact UI density, and a single full-bleed hero gradient from `#518bdb` to `#36bab8`. Pair a chunky editorial display face such as perfectlyNineties, Druk Wide, Climate Crisis, Recoleta, or Playfair Display 900 for hero and section headings with haffer, Inter, General Sans, or Geist Sans for product UI.

Build these elements:

- Top nav with small 8px-radius nav pills and right-aligned auth buttons.
- Centered hero with eyebrow pill, oversized display heading, subhead, dark filled CTA, and white secondary button.
- Floating product mockup container overlapping the hero and paper canvas.
- Product UI cards with white backgrounds, 1px hairline borders, 14px radius, avatars, timestamps, and optional unread dots.
- Context graph nodes with white backgrounds, 18px radius, marker-colored borders, and thin connecting lines.
- Soft pastel feature blocks using mint, peach, lavender, and teal mist.
- Search or AI prompt input with white background, low-opacity border, 8px radius, and blue focus ring.

Do not copy Micro brand assets, exact screenshots, page copy, or proprietary layouts. Generate a new screen that borrows the mood, token relationships, and component language only.
