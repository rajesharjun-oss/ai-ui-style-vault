## What To Preserve

Micro is a warm, paper-like productivity system. It opens with a single saturated blue-to-teal gradient hero, then settles into white app surfaces, hairline borders, compact product UI, pastel feature blocks, and category-colored icon accents. The signature tension is between chunky editorial display type and a quiet workhorse UI font.

## What To Avoid Copying

Do not copy the original logo, exact product screenshots, hero wording, navigation text, or visual composition. Use the token system and component logic to create original productivity, inbox, CRM, context graph, or AI workspace screens.

## Build Context

This bundle is meant for AI-assisted UI implementation. Use the markdown files for design intent, and use the `code/` files for direct token import when building with CSS variables or Tailwind v4.
