# Micro Style Reference

## Creative Direction

Create a calm productivity workspace that feels like ink on warm paper, opened by a single sunrise-like blue-to-teal gradient. The marketing layer can be expressive and editorial, but the app UI should be restrained, compact, useful, and precise.

## Visual Priorities

1. Use `#f5f5f5` as the page canvas and `#ffffff` as the product surface.
2. Use `#221f1c` instead of pure black for text.
3. Reserve the blue-to-teal gradient for the hero only.
4. Use `perfectlyNineties` or a heavy editorial substitute only for hero and section display headings.
5. Use `haffer` or a neutral sans for body copy, nav, buttons, and product UI.
6. Define surfaces with 1px borders and subtle shadows, not heavy elevation.
7. Use pastel washes for feature blocks.
8. Use marker colors categorically across icons, tags, graph nodes, and edges.

## Screen Composition

Use a full-bleed gradient hero with centered headline, centered subhead, compact button pair, and a product mockup that overlaps the transition into the paper canvas. Below the hero, use centered headings, product-led sections, 2-column text-plus-visual bands, 3-4 column feature grids, and a wide context graph visualization.

## Material Language

The system is flat-first and bordered. Buttons, inputs, and nav controls use 8px radius. Product rows use 14px. Large cards, feature blocks, and graph nodes use 18px. Shadows are subtle and secondary to hairline edges.

## AI Implementation Notes

When generating a UI from this style, build the page rhythm first: gradient hero, floating product mockup, warm paper section, compact product cards, context graph, pastel feature cards, and social proof row. Then apply the tokens. Avoid turning the whole page into a gradient or pastel collage.
