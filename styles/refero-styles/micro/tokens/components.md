# Components

## Dark Filled Button

- Role: Primary action on light backgrounds.
- Background: `#221f1c`
- Text: `#ffffff`
- Radius: `8px`
- Padding: `10px 16px`
- Font: haffer 500 at `14px`
- Optional pressed state: inset bottom shadow.

## White Filled Button

- Role: Secondary action on gradient hero.
- Background: `#ffffff`
- Text: `#221f1c`
- Radius: `8px`
- Padding: `10px 16px`
- No border or heavy shadow.

## Ghost Text Button

- Role: Tertiary or nav action.
- Background: transparent.
- Text: `#221f1c` on light or `#ffffff` on gradient/dark.
- Radius: `8px`
- Padding: `8px 12px`
- Hover reveals the affordance.

## Pill Nav Tab

- Background: transparent.
- Active background: `#f5f5f5`
- Text: `#221f1c`
- Icon/chevron: `#797267`
- Radius: `8px`
- Padding: `6px 12px`
- Font: haffer 500 at `14px`.

## Product Card

- Role: Inbox row, task row, person record, company record.
- Background: `#ffffff`
- Border: `1px solid rgba(0, 0, 0, 0.065)`
- Radius: `14px`
- Padding: `12px 16px`
- Primary text: `#221f1c`
- Secondary text: `#797267`
- Optional avatar: 32px circle.
- Optional unread dot: `#518bdb`.

## Context Graph Node

- Background: `#ffffff`
- Radius: `18px`
- Padding: `16px`
- Accent border: `2px` to `3px` in Teal Pulse, Coral Marker, Orchid Marker, or Azure Action.
- Connections: 1px lines in `#797267` at `0.4` opacity.
- Use for relationship visualizations and data nodes.

## Soft Pastel Feature Block

- Background: one of `#cbfbf1`, `#f8ebd8`, `#ede9fe`, or `#cff2ef`.
- Radius: `18px`
- Padding: `32px`
- No border, no shadow.
- Headline: haffer 600 at `20px` to `24px` in `#221f1c`.
- Body: haffer 400 at `14px` in `#797267`.

## Search / Prompt Input

- Background: `#ffffff`
- Border: `1px solid rgba(39, 39, 42, 0.12)`
- Radius: `8px`
- Padding: `10px 14px`
- Placeholder: `#8c8a88`
- Focus: 2px ring in `#518bdb`.
- Optional leading search or sparkle icon in `#797267`.

## Sidebar Nav Item

- Background: transparent.
- Active background: `#f5f5f5`
- Row height: `20px`
- Padding: `0 12px`
- Radius: `8px`
- Text: haffer 400 at `14px`, active weight 500.
- Icon: 16px in `#797267`, active `#221f1c`.

## Badge / Tag

- Background: transparent or `#f5f5f5`
- Text: `#221f1c`
- Radius: `9999px`
- Padding: `4px 10px`
- Font: haffer 500 at `12px`
- Colored state: marker color at 0.15 opacity background with full marker color text.

## Logo Strip

- One horizontal row of 5-6 monochrome logos.
- Color: `#221f1c`
- Gap: `48px` to `64px`
- No enclosing card.

## Floating Audio Player
