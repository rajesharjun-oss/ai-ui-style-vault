# Layout And Imagery

## Layout Patterns

- Full-bleed gradient hero at the top of the page.
- Centered hero stack: eyebrow pill, oversized display headline, subhead, button pair, floating product mockup.
- Product mockup overlaps the transition from gradient sky to warm paper canvas.
- Centered section headings and centered supporting copy for marketing sections.
- 2-column text-plus-visual sections for feature explanation.
- 3-4 column grids for pastel feature blocks.
- Wide context graph visualization followed by compact feature cards.
- Top navigation with left wordmark, centered nav pills, and right auth buttons.
- Product UI screenshots use a classic productivity shell: left sidebar, top utility bar, main content area.

## Imagery

- Keep imagery sparse and product-led.
- Use product UI screenshots, inbox rows, context graphs, cards, and prompt inputs as the main visual material.
- Use the context graph as the most illustrative moment: white nodes with marker-colored borders connected by fine gray lines.
- Use multicolor icons from the named marker palette.
- Avoid lifestyle photography, stock imagery, heavy 3D, and generic illustration systems.

## Responsive Notes

- On mobile, keep the gradient hero but reduce display heading size and keep line lengths short.
- Stack product mockups and feature blocks vertically.
- Preserve product card borders and compact spacing.
- Let graph views scroll horizontally or collapse into a vertical relationship list.
