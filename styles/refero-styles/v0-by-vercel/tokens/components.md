# Components

## Primary CTA Button

- Background: `#171717`
- Text: `#ffffff`
- Radius: 8px
- Padding: about 8px 12px
- Font: GeistSans 14px/500
- Use for main actions such as sign up or submit.

## Ghost Navigation Link

- Background: transparent
- Text: `#666666`
- Border: none by default
- Font: GeistSans 14px/400
- Use for secondary nav actions.

## Prompt Suggestion Chip

- Background: transparent
- Border: 1px solid `#eaeaea`
- Text: `#666666`
- Radius: 6px
- Padding: 4px 8px
- Font: GeistSans around 13px
- Use below or around the main prompt input.

## Filter Pill Button

- Background: `#ffffff`
- Text: `#171717`
- Border: 1px solid `rgba(0, 0, 0, 0.08)`
- Radius: 9999px
- Use for template categories and content filters.

## Main Prompt Input

- Background: `#ffffff` or transparent interior on a white container
- Border: 1px solid `#eaeaea`
- Radius: 12px
- Placeholder: `#666666`
- Font: GeistSans 16px/400
- Focus: subtle outer glow, not a saturated color ring.

## Header Divider

- Full-width 1px solid `#eaeaea`
- Separates sticky header from page content.

## Template Card

- Background: `#ffffff`
- Radius: 12px
- Shadow: subtle ring plus small vertical shadow
- Content: raw product preview thumbnail or user-generated output
- No decorative frame beyond the card itself.

## Template Gallery

- 3-column desktop grid
- Large whitespace above and below
- Cards hold the visual content; surrounding chrome remains monochrome.
