# Typography

## Families

- Sans: `"GeistSans", "Inter", system-ui, sans-serif`
- Mono: `"GeistMono", "IBM Plex Mono", ui-monospace, monospace`

Font features: `zero`, `ss09`, `ss05`

## Roles

| Role | Size | Family | Weight | Line Height | Tracking | Use |
|---|---:|---|---:|---:|---:|---|
| Technical | 10px | GeistMono | 400 | 1.5 | 0 | Tiny stats and aligned metadata |
| Small UI | 13px to 14px | GeistSans | 400 to 500 | 1.4 to 1.5 | 0 | Nav, chips, utility labels |
| Button | 14px | GeistSans | 500 | 1.25 | 0 | CTAs and action buttons |
| Body | 16px | GeistSans | 400 | 1.5 | 0 | Body text and input copy |
| Heading | 24px | GeistSans | 600 | 1.25 | negative | Smaller section headings |
| Section Heading | 32px | GeistSans | 600 | 1.17 | -1.28px | Template and content headings |
| Display | 48px | GeistSans | 600 | 1.0 | -2.88px | Hero/display headlines |

## Guidance

- Use GeistSans for all normal text.
- Use GeistMono only for tiny technical annotations.
- Apply progressively tighter tracking at 24px and larger.
- Do not use bold 700+ weights.
- Do not substitute system fonts when Geist is available.
