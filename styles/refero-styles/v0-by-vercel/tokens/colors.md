# Colors

| Name | Value | Token | Role |
|---|---:|---|---|
| Paper White | `#ffffff` | `--color-paper-white` | Card surfaces, pill backgrounds, text on dark buttons |
| Canvas | `#fafafa` | `--color-canvas` | Primary page background |
| Line | `#eaeaea` | `--color-line` | Borders, headers, dividers, ghost buttons, chips, inputs |
| Subtext | `#666666` | `--color-subtext` | Secondary text, navigation links, placeholder text |
| Icon | `#7d7d7d` | `--color-icon` | Inactive icons and tertiary UI elements |
| Ink | `#171717` | `--color-ink` | Primary text, headlines, primary button backgrounds |
| Onyx | `#000000` | `--color-onyx` | Logo, icons, maximum-contrast text only |

## Guidance

- Keep UI chrome achromatic.
- Use Canvas for the page background.
- Use Ink for primary text and filled actions.
- Use Line for all borders and dividers.
- Let template previews provide visual color.
- Do not introduce saturated accent colors.
