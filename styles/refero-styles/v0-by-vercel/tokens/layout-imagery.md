# Layout And Imagery

## Layout Pattern

The core page structure is:

1. Full-width header with a 1px Line bottom border.
2. Centered hero stack.
3. Large prompt input.
4. Suggestion chips.
5. Filter pills for templates or categories.
6. 3-column template card gallery.
7. Large whitespace between sections.

## Grid

- Use a generous max width around 1440px.
- Keep the page centered.
- Use 3-column card grids on desktop.
- Stack cards cleanly on mobile.
- Avoid sidebars, dense rails, and heavy dashboard structures.

## Imagery

Use:

- Product-generated template previews.
- Raw UI output screenshots.
- User-created visual content inside cards.

Avoid:

- Decorative illustrations.
- Gradients.
- Background images.
- Atmospheric hero media.
- Stock photography.
- Branded accent art outside content previews.
