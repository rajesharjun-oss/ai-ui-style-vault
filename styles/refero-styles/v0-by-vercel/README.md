# v0 by Vercel

Functional schematic on a stark drafting table: an achromatic AI builder interface with Canvas background, GeistSans typography, black primary actions, bordered suggestion chips, compact radii, and generous whitespace.

Use this style when you want an AI builder, prompt interface, template gallery, developer tool, or utility product to feel precise, quiet, modern, and command-focused.

## Files

- `source.md`: Source URL, reference site, capture notes, and scope.
- `DESIGN.md`: Human-readable design breakdown.
- `implementation-prompt.md`: Prompt for an AI builder to implement the style.
- `style.json`: Structured design metadata.
- `tokens/`: Markdown token notes by category.
- `code/`: CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md`: Placeholder for future manual screenshots.

## Quick Use

1. Use `Canvas` for the page background.
2. Use `Ink` for primary text and primary button fills.
3. Use `Line` for borders and dividers.
4. Use GeistSans everywhere and GeistMono only for tiny technical stats.
5. Use 8px radius for buttons, 12px for cards and prompt inputs, 6px for small chips, and 9999px for filter pills.
6. Keep UI chrome achromatic. Let user-generated previews provide the only visual color.
