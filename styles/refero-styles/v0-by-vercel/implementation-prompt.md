# AI Implementation Prompt

Build a polished, responsive interface in the v0 by Vercel style.

The interface should feel like a precise AI builder: achromatic, spacious, centered, and utility-first. The prompt input is the hero. Avoid decorative media, gradients, saturated UI colors, and soft marketing clutter.

Core rules:

- Use `#fafafa` as the page background.
- Use `#ffffff` for cards, filters, and elevated surfaces.
- Use `#171717` for primary text and primary button fills.
- Use `#666666` for secondary copy and placeholders.
- Use `#eaeaea` for all dividers, chip borders, input borders, and header borders.
- Use GeistSans for all text, with GeistMono only for tiny technical stats.
- Use aggressive negative tracking on headings 24px and larger.
- Use 8px radius for buttons, 12px radius for cards and prompt inputs, 6px radius for small suggestion chips, and 9999px for filter pills.
- Use shadows only on cards, modals, or popovers, never on buttons or inputs.

Recommended layout:

1. Full-width header with a 1px Line bottom border, quiet nav links, and a black primary CTA.
2. Centered hero stack with a compact headline and a large prompt input.
3. Suggestion chips below or inside the prompt area.
4. Filter pills for template categories.
5. A 3-column template card gallery using white cards, 12px radius, and restrained card shadow.
6. Large vertical whitespace between major sections.

Make the experience feel like a tool waiting for the user's command.
