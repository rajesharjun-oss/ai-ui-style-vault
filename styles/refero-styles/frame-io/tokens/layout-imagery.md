# Layout And Imagery

## Layout Patterns

- Full-bleed dark gradient canvas with centered 1280px content.
- Split hero: left copy and CTA stack, right product UI mockup.
- Slim top navigation with ghost links and pill CTAs.
- Four-column feature grid made from transparent typographic blocks.
- Product visual bands using violet-bordered app screenshots.
- Full-width video showcase blocks with minimal player chrome.
- Sections breathe with 80px vertical gaps.

## Imagery

- Product UI is the main imagery: media thumbnails, video review threads, timeline panels, comments, versions, and approval flows.
- Cinematic stills and video previews can appear below the fold.
- Use no stock photography, abstract illustration, or decorative 3D.
- Icons should be thin outline icons, 24px, single-color Iris Glow.
- Keep video/player chrome minimal so the creative work leads.

## Responsive Notes

- On mobile, stack hero copy above product mockup.
- Preserve left alignment for body copy.
- Reduce display size while keeping tight tracking.
- Convert four-column features into one or two columns.
- Keep pill CTAs and 10px product frames intact.
