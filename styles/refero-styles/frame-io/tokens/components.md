# Components

## Pill Navigation Button

- Role: Primary action in the top nav.
- Background: `#fcfcfc`
- Text: `#0a0a13`
- Radius: `100px`
- Padding: `12px 20px`
- Font: FrameGothic `14px`, weight `500`
- Border: none.
- Shadow: none.

## Ghost Nav Link

- Role: Secondary nav items.
- Background: transparent.
- Text: `#fcfcfc`
- Font: FrameGothic `14px`, weight `400`
- Border: none.
- Hover: underline only; no background shift.

## Sign In Text Link

- Background: transparent.
- Text: `#fcfcfc`
- Font: FrameGothic `14px`, weight `400`
- Border: none.
- This should feel like the lightest interactive element.

## Hero CTA Pill

- Background: `#fcfcfc`
- Text: `#0a0a13`
- Radius: `100px`
- Padding: `14px 28px`
- Font: FrameGothic `14px`, weight `500`
- Shadow: none.

## Ghost CTA Button

- Background: transparent.
- Text: `#fcfcfc`
- Border: `1px solid #fcfcfc`
- Radius: `100px`
- Padding: `14px 28px`
- Font: FrameGothic `14px`, weight `400`
- Hover: invert to Carbon Vellum fill.

## Announcement Banner

- Full-width top strip.
- Background: blue-to-violet dark gradient.
- Text: `#fcfcfc`, `13px`, centered.
- Height: about `40px`.
- Optional dismiss mark at the right.

## Eyebrow Label

- Font: NeueMachinaInktrap.
- Size: `12px`.
- Weight: `400`.
- Letter spacing: `0.06em`.
- Line height: `0.90`.
- Color: `#6199f6` or Smoke.
- Use only above section headlines.

## Display Headline

- Font: FrameGothic.
- Weight: `400`.
- Size: `48px` to `80px`.
- Line height: `0.96` to `1.02`.
- Letter spacing: `-1.92px` to `-3.6px`.
- Color: `#fcfcfc`.

## Subheadline Paragraph

- Font: FrameGothic.
- Size: `18px`.
- Weight: `400`.
- Line height: `1.30`.
- Color: `#757580`.
- Max width: about `560px`.
- Align left.

## Feature Column Card

- Transparent background.
- No border.
- No card surface.
- Icon: 24px outline in Iris Glow.
- Heading: FrameGothic `18px`, weight `500`, Carbon Vellum.
- Body: FrameGothic `14px`, Smoke or Ash.
- Grid: four columns with `24px` gap.

## Product UI Mockup Container

- Background: product-native dark UI, usually Graphite.
- Radius: `10px`.
- Border: `1px solid #4f4f80`.
- Shadow: `inset 0 0 0 1px #4f4f80, 0 0 60px rgba(79, 79, 128, 0.15)`.
- Use for app screenshots, review threads, timeline panels, and version stacks.

## Video Showcase Player

- Radius: `10px`.
- Border: `1px solid #4f4f80`.
- Shadow: `0 24px 48px rgba(0, 0, 0, 0.5)`.
- Play button: Iris Glow circle around `48px`, about `60%` opacity.
- Caption strip: `12px` Smoke.

## Section Divider

- Prefer no physical divider.
- If needed, use `1px solid #2a2a32`.
