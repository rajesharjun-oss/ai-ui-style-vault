# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Density | `comfortable` |
| Base unit | `8px` |
| Max width | `1280px` |
| Section gap | `80px` |
| Card padding | `24px` |
| Element gap | `24px` |

## Scale

`8px`, `16px`, `24px`, `32px`, `40px`, `48px`, `56px`, `80px`, `96px`, `144px`, `160px`, `176px`

## Radius

| Element | Value |
|---|---:|
| Nav | `100px` |
| Cards | `10px` |
| Pills | `100px` |
| Buttons | `100px` |
| Dividers | `1px` |
| Feature cards | `24px` |

## Elevation

```css
--shadow-product-frame: inset 0 0 0 1px #4f4f80, 0 0 60px rgba(79, 79, 128, 0.15);
--shadow-video-player: 0 24px 48px rgba(0, 0, 0, 0.5);
```

Buttons, nav items, and pills should not use shadows.
