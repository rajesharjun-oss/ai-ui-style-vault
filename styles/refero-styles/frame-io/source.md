## What To Preserve

Frame.io is a dark creative-workspace style. It uses a near-black blue-purple canvas, a single vivid blue accent, muted violet borders around product imagery, large compressed geometric sans headlines, and thin editorial components. The UI should frame creative work rather than compete with it.

## What To Avoid Copying

Do not copy the original logo, Adobe mark, product screenshots, film stills, video thumbnails, navigation copy, or exact page layout. Use the token system and component logic to create original video review, creative collaboration, media library, approval, workflow, or production tools.

## Build Context

This bundle is meant for AI-assisted UI implementation. Use the markdown files for design intent, and use the `code/` files for direct token import when building with CSS variables or Tailwind v4.
