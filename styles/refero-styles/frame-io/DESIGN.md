# Frame.io Style Reference

## Creative Direction

Create a dark cinematic workspace that feels like a quiet projection room. The page should be almost monochrome, with a single iris-blue signal and muted violet halos around product/video surfaces. Type and product imagery carry the drama; the UI should stay thin, editorial, and restrained.

## Visual Priorities

1. Use `#0a0a13` as the main canvas, never flat black alone.
2. Layer at least one cosmic gradient over every major dark background.
3. Use `#6199f6` as the only chromatic UI accent.
4. Use `#4f4f80` for violet product-frame borders and atmospheric halos.
5. Use `#fcfcfc` for primary text and inverse pill fills.
6. Use `#757580` and `#a3a3b3` for secondary and tertiary copy.
7. Use 100px radius for nav items, pills, and buttons.
8. Use 10px radius and a 1px violet border for product/video frames.

## Screen Composition

Use a full-bleed dark canvas with content constrained to 1280px. The hero should be a split composition: left text stack with eyebrow, compressed display headline, body, and CTA pills; right product UI mockup in a violet-bordered frame. Below, alternate between text-led bands, product mockup bands, four-column feature blocks, and cinematic video showcases.

## Material Language

This style is not a card-heavy SaaS UI. Feature "cards" are really typographic columns with icons, headings, and body text on transparent backgrounds. The only framed surfaces are product UI mockups and video players. Buttons and nav items rely on fill/border contrast rather than shadows.

## AI Implementation Notes

When generating a UI from this style, build the dark gradient stage first, then place product/video assets on it. Keep product screenshots, review threads, media thumbnails, timeline panels, and video players as the primary imagery. Use Iris Glow sparingly: icons, eyebrow labels, active states, links, and small feature marks.
