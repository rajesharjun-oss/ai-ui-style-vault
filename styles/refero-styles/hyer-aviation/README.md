# Hyer Aviation

Source: Refero Styles  
URL: https://styles.refero.design/style/f61cf515-ccd5-4494-bdd1-be9fe4d7258c  
Reference site: https://www.flyhyer.com  
Captured: 2026-07-28

Hyer Aviation is a luxury aviation editorial style: vast tight-tracked headlines, a mostly monochrome white and ink system, one restrained clay accent, pill-shaped actions, and a sculptural aircraft hero image. It should feel premium, architectural, calm, and exact.

Use this folder as an AI implementation brief. The most useful files are:

- `DESIGN.md` for the full style interpretation.
- `implementation-prompt.md` for a copy-ready prompt to hand to an AI builder.
- `style.json` for structured metadata.
- `code/css-variables.css` for CSS custom properties and component recipes.
- `code/tailwind-v4.css` for Tailwind v4 theme tokens.
- `code/design-tokens.json` for machine-readable tokens.

Core cues:

- Main structure: `#000d10` Deep Ink on `#ffffff` Pure White.
- Dark bands: `#0f0f1c` Midnight Hull and `#151623` Charcoal Deck.
- Muted text: `#8e8e95` Cool Ash.
- Hairlines: `#d5d3d4` Pebble.
- Accent: `#bc7155` Clay Ember, used once for a featured card or focal offer.
- Typography: HelveticaNowDisplay, weight 700 for headlines from 23px upward.
- Body copy: 18px, weight 400, line-height 1.61.
- Actions: 1000px pill buttons and circular icon buttons.
- Cards: hard-edged white panels or one hard-edged clay feature card.
- Elevation: no shadows; use surface contrast and hairlines.

This is best for aviation, luxury travel, concierge services, premium logistics, destination products, and high-end booking experiences.
