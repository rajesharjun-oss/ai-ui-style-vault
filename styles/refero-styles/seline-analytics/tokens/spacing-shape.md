# Spacing And Shape

## Core Values

| Purpose | Value |
|---------|-------|
| Density | compact |
| Base unit | 4px |
| Page max width | 1200px |
| Section gap | 96px |
| Card padding | 24px |
| Element gap | 8px |

## Radius

| Element | Value | Token |
|---------|-------|-------|
| Tags | 9999px | `--radius-tags` |
| Cards | 10px | `--radius-cards` |
| Icons | 4px | `--radius-icons` |
| Inputs | 6px | `--radius-inputs` |
| Buttons | 9999px | `--radius-buttons` |
| Feature card | 16px | `--radius-feature-card` |

## Shadows

| Name | Value | Token |
|------|-------|-------|
| md | `rgba(0, 0, 0, 0.05) 0px 4px 16px 0px` | `--shadow-md` |
| sm | `rgba(0, 0, 0, 0.1) 0px 4px 6px -1px, rgba(0, 0, 0, 0.1) 0px 2px 4px -2px` | `--shadow-sm` |
| subtle | `rgba(0, 0, 0, 0.05) 0px 1px 2px 0px` | `--shadow-subtle` |
| xl | `rgba(17, 12, 46, 0.12) 0px 12px 45px 0px` | `--shadow-xl` |

## Shape Rules

- Buttons and tags are full pills.
- Cards use 10px radius.
- Product preview uses 16px radius.
- Inputs use 6px radius.
- Reserve shadow-xl for the hero dashboard preview.
