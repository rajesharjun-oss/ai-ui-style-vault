# Implementation Prompt - Seline Analytics Style

Build an original UI using the Seline Analytics Refero style as visual direction.

Create a calm analytics product page on warm stone paper. Use Roobert-style 400-weight headings, Inter body/UI type, flat white cards, 1px stone borders, pill CTAs, one cyan accent, one cyan-highlighted phrase per headline, and a single elevated dashboard preview as the hero proof object.

## Must Preserve

- Stone Canvas `#fafaf9` as the page background.
- Pure White `#ffffff` only for elevated cards, nav, inputs, and dashboard frames.
- Stone Border `#e8e6e5` as the main structural line.
- Ink Black `#0c0a09` for primary text.
- Warm Gray `#78716c` for body and nav text.
- Cyan Signal `#3ba6f1` as the only filled CTA color.
- Cyan Edge `#3398e1` and Sky Wash `#c1e1f7` for one highlighted phrase per headline.
- Roobert-style display text at 32px and 52px, weight 400.
- Inter for body, nav, captions, labels, and dense UI.
- Pill buttons with 9999px radius and 8px by 16px padding.
- One elevated dashboard preview with `--shadow-xl`.

## Avoid

- Copying Seline logos, mascot art, screenshots, exact product UI, customer quotes, page copy, or proprietary layouts.
- Adding new accent colors.
- Heavy shadows on ordinary content cards.
- Using Inter for headings.
- Using pure white as the page background.
- Neutral or dark filled primary buttons.
- Gradients, glassmorphism, or decorative color washes.
- Multiple cyan highlight spans in one headline.

## Component Direction

Lead with a calm analytics hero: warm canvas, left-aligned headline, one highlighted cyan phrase, short gray copy, cyan pill CTA, ghost pill CTA, partner/trust row, and one floating dashboard preview. Keep the rest of the page border-led and quiet.
