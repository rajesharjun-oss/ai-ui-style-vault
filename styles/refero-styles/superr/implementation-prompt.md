# Implementation Prompt

Build in the Superr style: a warm cream-paper landing page led by photographed notebooks, sticker labels, hand-drawn marker captions, lowercase gelica display type, and dark outlined pill actions.

Use these rules:

- Canvas: `#fdfbf9`.
- Secondary surface: `#f7efe9`.
- Headline text: `#2b1a07`.
- Text and borders: `#171717`.
- Marker accent: `#ff6f1e`.
- Darker orange support: `#ce500a`.
- Sticker-only colors: `#3b82f6`, `#ff66cf`, `#22c55e`.
- Display font: gelica or a rounded display substitute.
- Supporting UI font: Geist, Inter, Sohne, or General Sans.
- Display: 104px, weight 600, line-height 1.08, lowercase, normal tracking.
- Body: 20px, weight 500, line-height 1.5.
- Buttons: Cream Paper fill, 1.5px Charcoal border, 20px radius, 28px horizontal padding, 10px to 11px vertical padding.
- Cards: 12px radius, 32px padding.
- Tags: 20px radius.
- Inputs: 8px radius.
- Footer top radius: 56px.
- Section gap: 64px.
- Element gap: 12px.

Design structure:

1. Top-left small hand or pointing brand icon.
2. Top-right outlined pill CTA.
3. Hero split: left headline and copy, right tilted notebook product photo.
4. Add handwritten Marker Orange captions and hand-drawn arrows pointing to objects.
5. Add sticker illustrations at random 5 to 15 degree rotations.
6. Use product photos of notebooks, pencils, and labels as primary visual content.
7. End with a Marker Orange footer brand band.

Avoid:

- Filled CTA buttons.
- Sticker colors in functional UI.
- Capitalized headlines.
- Letter spacing on display text.
- Heavy shadows.
- Centered multi-line headline stacks.
- Gradients, glassmorphism, neon, abstract graphics, or 3D renders.

The result should feel tactile, matte, warm, and object-led.
