## Use This When

Use this style for playful education products, notebook or stationery brands, kid-adjacent software, creative tools, pre-order pages, tactile product launches, and warm object-led landing pages.

## Core Idea

Superr is a cream-paper product page built around real photographed objects: notebooks, pencils, sticker labels, and hand-marker captions. The system is playful but restrained. Marker Orange is the only functional accent, sticker colors are decorative only, and actions use outlined cream pills rather than filled buttons.
