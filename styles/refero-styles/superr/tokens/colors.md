# Colors

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Cream Paper | `#fdfbf9` | `--color-cream-paper` | Page canvas, cards, button fills |
| Dew Drop | `#f7efe9` | `--color-dew-drop` | Secondary surface tint |
| Cocoa Ink | `#2b1a07` | `--color-cocoa-ink` | Headline color and decorative borders |
| Charcoal | `#171717` | `--color-charcoal` | Text, borders, strokes, structural edges |
| True Black | `#000000` | `--color-true-black` | Highest-emphasis hard edge cases |
| Shadow Mist | `#bebcbb` | `--color-shadow-mist` | Soft shadow base |
| Marker Orange | `#ff6f1e` | `--color-marker-orange` | Captions, highlights, underlines, footer band |
| Burnt Sienna | `#ce500a` | `--color-burnt-sienna` | Darker orange accent support |
| Sky Sticker | `#3b82f6` | `--color-sky-sticker` | Sticker illustration color only |
| Bubblegum Sticker | `#ff66cf` | `--color-bubblegum-sticker` | Sticker illustration color only |
| Sprout Sticker | `#22c55e` | `--color-sprout-sticker` | Sticker illustration color only |

## Color Rules

- Keep the page on Cream Paper, never pure white.
- Use Dew Drop for subtle warm panels.
- Use Marker Orange only for marker-like moments.
- Do not use sticker colors for UI controls, links, or badges.
- Charcoal is the only structural ink.
- Use Cocoa Ink for warm headline presence.
