# Colors

| Token | Value | Use |
| --- | --- | --- |
| `--limon-black-olive` | `#1d0b0d` | Page background, hero canvas, footer, dark surface |
| `--limon-forest-ink` | `#103b15` | Text, links, dividers, and dark accent surfaces on cream |
| `--limon-lemon-zest` | `#f7ea48` | Filled CTA, display accent on dark, highlight punctuation |
| `--limon-warm-cream` | `#fcf9f0` | Light content sections, menu panels, editorial body sections |
| `--limon-sage-mist` | `#dbe2dc` | Hairline dividers, subtle borders, muted accents |
| `--limon-pure-white` | `#ffffff` | Icon strokes, active nav outline, punctuation on dark |

## Usage Rules

- Use `#1d0b0d` as the default dark canvas.
- Use `#fcf9f0` for content-light breathing sections.
- Use `#f7ea48` only as filled CTA color or display accent on dark.
- Use `#103b15` for text and links on cream sections.
- Do not add extra accent hues.
- Do not dilute lemon yellow into pale tints.
