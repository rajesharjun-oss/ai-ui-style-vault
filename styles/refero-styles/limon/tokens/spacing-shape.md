# Spacing And Shape

## Spacing

| Token | Value | Use |
| --- | ---: | --- |
| `unit` | 4px | Base spacing unit |
| `4` | 4px | Icon gap and micro rhythm |
| `8` | 8px | Tight spacing |
| `12` | 12px | CTA vertical padding |
| `16` | 16px | CTA horizontal padding |
| `20` | 20px | Hero sub-line gap and body rhythm |
| `30` | 30px | Card padding and photo-to-caption gap |
| `40` | 40px | Grid row gap and circular utility size |
| `60` | 60px | Section gap |
| `120` | 120px | Large hero or image breathing space |
| `max-width` | 1200px | Page container |

## Radius

| Token | Value | Use |
| --- | ---: | --- |
| `cards` | 0px | Food cards and images |
| `badges` | 1px | Active nav badges and small UI |
| `inputs` | 1px | Form controls |
| `buttons` | 1px | CTA and outlined controls |
| `circular` | 40px | Back-to-top button only |

## Shape Rules

- The system is intentionally near-square.
- Do not use 8px to 12px rounded corners.
- Do not round food images.
- Reserve circular shape for the back-to-top utility only.
