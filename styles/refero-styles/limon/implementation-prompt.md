# Implementation Prompt

Build a UI in the Limon style.

Create a dark restaurant editorial interface with a black-olive canvas, warm cream content sections, deep forest typography, a single lemon-yellow CTA accent, and large edge-to-edge food photography. The page should feel like an evening brasserie menu: warm, confident, sharp-edged, and food-first.

Use these hard rules:

- Main canvas: `#1d0b0d`.
- Cream section background: `#fcf9f0`.
- Forest text/link color: `#103b15`.
- Lemon accent: `#f7ea48`.
- Divider/border color: `#dbe2dc`.
- White detail color: `#ffffff`.
- Use `#f7ea48` as filled CTA background or display text on dark sections.
- Do not place lemon CTA blocks on warm cream sections.
- Do not introduce any other accent hue.
- Do not use shadows, glows, or gradients.
- Do not round cards or images.
- Use 0px radius on cards and 1px radius on buttons, inputs, and badges.
- Reserve circular geometry for a 40px back-to-top button only.
- Use VenusCom as the main typeface, with DM Sans, Outfit, or Plus Jakarta Sans as fallback.
- Use positive letter spacing everywhere.
- Use 0.04em to 0.06em tracking for display text above 46px.
- Do not use negative tracking.

Build a dark full-bleed hero with large lemon display text layered near food photography, plus a warm cream sub-line. Use a full-bleed dark navigation bar with uppercase links and a centered wordmark. Use warm cream sections for menu grids: large square food photos with no chrome, captions below, body copy, and a ghost ORDER NOW link in forest green with a small right arrow.

Keep the page flat and editorial. The food images should be the only elements with physical presence.
