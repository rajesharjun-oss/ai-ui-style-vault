# Pirsch Analytics

Source: https://styles.refero.design/style/e4b9d41a-8165-47dd-818a-5f6810046ea9

Product/site reference: https://pirsch.io

## Snapshot

- **Mood:** Warm notebook analytics with black ink structure and sunshine-yellow action.
- **Theme:** Light, compact, privacy-focused, hand-built SaaS.
- **Core grammar:** Cream paper canvas, black 2px outlines, no shadows, DM Sans only, yellow CTA, mint analytics highlights, tight dashboard primitives.
- **Best for:** Privacy analytics tools, technical SaaS sites, developer tools, data dashboards, open-source product pages.

Pirsch Analytics feels like a product dashboard drawn on warm paper. It avoids glossy SaaS effects and instead uses strong ink-like borders, compact typography, flat yellow buttons, and mint data highlights. The result is friendly but technical: approachable enough for a landing page, structured enough for analytics UI.

## Fast Build Notes

- Use `#fffffb` as the page canvas and `#f5f1e6` as the warm secondary surface.
- Use `#111111` for ink-like text and borders.
- Use `2px solid #111111` for important cards and controls.
- Use `#ffda6e` for primary CTAs and emphasis panels.
- Use `#3db09c` and `#063c36` for analytics and positive data moments.
- Use DM Sans everywhere.
- Keep cards nearly square with `3px` radius and no shadows.
