# Spacing And Shape Tokens

## Spacing

| Purpose | Value |
| --- | --- |
| Density | compact |
| Base unit | `4px` |
| Max width | `1200px` |
| Section gap | `96px` |
| Card padding | `32px` |
| Element gap | `16px` |

| Element | Value | Token |
| --- | --- | --- |
| buttons | `7px` | `--radius-button` |
| cards | `3px` | `--radius-card` |
| inputs | `0px` | `--radius-input` |
| tabs | `0px` | `--radius-tab` |

## Borders And Elevation

- Important border: `2px solid #111111`.
- Light border: `1px solid #d8d5cc`.
- Default shadow: none.
- Elevation comes from borders, fill color, and spacing.
