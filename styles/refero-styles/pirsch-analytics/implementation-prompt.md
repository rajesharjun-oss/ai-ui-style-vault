# Implementation Prompt

Build a warm, privacy-focused analytics SaaS interface inspired by Pirsch Analytics.

Use `#fffffb` as the main page canvas and `#f5f1e6` for alternate paper sections or muted panels. Use `#111111` as primary text and the main structural border color. Important cards, buttons, inputs, and dashboard panels should use `2px solid #111111` borders. Avoid shadows entirely.

Use `#ffda6e` as the primary CTA and emphasis color. Use `#3db09c` and `#063c36` for analytics highlights, success states, privacy badges, and positive chart elements. Keep other colors secondary and state-driven.

Use DM Sans throughout. Use 58px/1.1 and weight 800 for display headlines, 44px/1.2 for large section headings, 30px/1.2 for card headings, 16px/22px for body, and 11px uppercase heavy captions for labels. Do not introduce serif, monospace, or decorative fonts.

Use `3px` card radius, `7px` button radius, `0px` inputs/tabs where appropriate, and `999px` for pill badges. Keep density compact: 16px element gaps, 32px card padding, and 96px section gaps.

Build product primitives such as primary yellow CTA, black outline secondary button, paper dashboard card, metric tile, chart card, table row, privacy badge, nav link, and analytics status pill. Keep the interface flat, readable, and border-led.
