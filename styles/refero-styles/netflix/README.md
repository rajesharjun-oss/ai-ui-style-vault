## Style Summary

Netflix is a theatrical streaming style: pure black canvas, one urgent red accent, high-contrast white typography, dimmed poster imagery, horizontal content shelves, and gradient feature cards that create depth without shadows. The UI should feel like an infinite digital shelf inside a dark cinema lobby.

Use this style when an AI needs a streaming landing page, media browsing interface, movie poster shelf, subscription signup page, or dark entertainment dashboard.

## What To Borrow

- Pure black `#000000` as the main page background.
- Netflix Red `#e50914` as the only saturated accent.
- Netflix Sans or a utilitarian sans substitute as the single typeface.
- Large 56px hero headlines and 100px ranking numerals.
- Centered hero signup flow over a dimmed poster collage.
- Horizontal content carousels and vertical poster cards.
- 4px buttons and inputs; 16px large cards.
- Feature cards using a deep blue-purple gradient instead of box shadows.
- Secondary copy in silver gray.
- Minimal header focused on logo, language, and sign-in actions.

## Avoid

- Using any saturated accent besides Netflix Red.
- Adding box shadows as the depth system.
- Using light or gray page backgrounds.
- Outlining primary buttons.
- Adding a crowded multi-link navigation header.
- Mixing in extra type families.
- Softening the geometry into rounded SaaS cards.
