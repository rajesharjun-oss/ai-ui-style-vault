# Typography Tokens

## Family

Primary:

- Preferred: `Netflix Sans`
- Substitutes: Roboto, Inter, system sans

Use one sans family across all UI. The style depends on typographic consistency, not expressive font mixing.

## Weights

- 400 for body copy, footer links, and low-emphasis labels.
- 500 for utility controls and compact actions.
- 700 for hero headlines and strong CTA labels.
- 900 for feature-card headings and ranking numerals.

## Type Scale

| Role | Size | Line Height | Tracking | Weight | Use |
|---|---:|---:|---:|---:|---|
| Caption | 13px | 1.5 | 0 | 400 | Footer links, small metadata |
| Body | 16px | 1.5 | 0 | 400 | Main body text, card copy, form text |
| Subheading | 20px | 1.25 | 0 | 500 | Supporting statements |
| Heading small | 24px | 1.2 | 0 | 900 | Feature card headings |
| Heading | 56px | 1.17 | 0 | 700 | Hero headlines |
| Display | 100px | 1 | 0 | 900 | Ranking numerals |

## Rules

- Keep line lengths short in hero and signup copy.
- Avoid decorative letter spacing.
- Do not use serif or display fonts.
- Use large numerals as graphic objects in poster shelves.
