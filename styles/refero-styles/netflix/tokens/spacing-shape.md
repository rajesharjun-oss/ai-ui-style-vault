# Spacing And Shape Tokens

## Spacing

| Purpose | Value |
|---|---:|
| Base unit | 4px |
| Page max width | 1280px |
| Section gap | 48px |
| Card padding | 24px |
| Element gap | 16px |

## Shape

| Element | Radius |
|---|---:|
| Buttons | 4px |
| Inputs | 4px |
| Promotional banner | 8px |
| Large content cards | 16px |
| Poster art | 0-4px unless focus treatment requires more |

## Borders

- Input border: `1px solid #5a5a5a`.
- Utility button border: `1px solid #808080`.
- Avoid heavy outlines on content imagery.

## Layout Notes

- Use full-bleed black sections.
- Center core content inside a 1280px rail.
- Keep horizontal shelves spacious enough for poster art to breathe.
- Do not use generic card padding everywhere; poster shelves should feel image-first.
