# Color Tokens

## Palette

| Token | Value | Role |
|---|---:|---|
| Netflix Red | `#e50914` | Logo, primary CTAs, active indicators, urgent interaction |
| Feature Card Base | `#1d153f` | Token base for gradient feature cards |
| Feature Card Gradient | `linear-gradient(149deg, #192247, #210e17)` | Secondary feature-card depth |
| Deep Space | `#000000` | Main page and section backgrounds |
| Graphite | `#2d2d2d` | Subtle surfaces and component backgrounds |
| Charcoal | `#414141` | Inactive controls and deeper components |
| Slate | `#5a5a5a` | Input borders and interactive element borders |
| Ash | `#808080` | Placeholder text and quiet icons |
| Silver | `#b3b3b3` | Footer links and secondary copy |
| Chalk White | `#ffffff` | Headings, body text, and icon fills |

## Usage

- Use `#000000` for the base page and all primary sections.
- Use `#e50914` only for the brand mark, primary CTA, and active or urgent states.
- Use `#ffffff` for primary content text.
- Use `#b3b3b3` for quieter links and secondary copy.
- Use `#5a5a5a` for input and utility-control borders.
- Use the feature-card gradient to create depth without shadow.

## Avoid

- Do not introduce blue, green, yellow, or purple as action colors.
- Do not make the background gray.
- Do not use red for decorative fills everywhere.
- Do not make every card gradient; reserve it for feature blocks.
