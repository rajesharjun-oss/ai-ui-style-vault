# Components

## Top Navigation Bar

Sticky full-width dark header on `#08090a` with a 1px bottom border in `#23252a`. Use the logo and primary nav links on the left or center, with login and a sign-up pill on the right. Links use Fog Text and brighten to Snow.

## Outlined Pill Button

Primary and secondary high-emphasis action.

- Radius: 9999px.
- Border: 1px solid `#f7f8f8`.
- Background: transparent.
- Text: `#f7f8f8`.
- Type: Inter 14px, weight 510.
- Padding: 8px 16px.
- Hover: keep outline identity; optionally shift background to `#141516`.

## Ghost Text Button

Tertiary action and nav link.

- No border.
- No fill.
- Text: `#8a8f98`.
- Hover text: `#f7f8f8`.
- Padding: 8px horizontal.

## Search Input

Compact global search or changelog filter.

- Background: `#141516`.
- Border: 1px solid `#23252a`.
- Radius: 4px.
- Height: about 32px.
- Placeholder: `#8a8f98`.
- Focus: shift border to `#34343a`.

## Section Tab Nav

Horizontal row below the title. Active tab uses Snow and weight 510. Inactive tabs use Fog Text. Avoid chunky indicators; the active state can be just text color and weight.

## Date Marker

Small changelog label with an optional 6px dot and muted date text. Use around 13px text in Fog Text. Keep it aligned with the entry content.

## Changelog Entry Heading

Use 24px to 32px Inter Variable, weight 510, Snow, and compact line height. Optional hash anchor can appear beside the heading on hover.

## App Connector Icon Grid

Use dark rounded tiles, around 64px square, with 8px radius, 1px `#23252a` border, and centered white glyphs. Arrange in a tidy grid with 16px gaps.

## Command Reference Card

Use for code-like examples, product references, or generated command snippets.

- Background: `#1c1c1f`.
- Border: 1px solid `#23252a`.
- Radius: 4px.
- Padding: 12px 16px.
- Font: Berkeley Mono.

## Body Paragraph

Use 15px to 16px Inter, weight 400, line-height 1.5 to 1.6, and Mist Text. Links can use Snow with medium weight and underline only on hover.
