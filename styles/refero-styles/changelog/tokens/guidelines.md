# Guidelines

## Do

- Use `#08090a` as the full-page canvas.
- Use `#f7f8f8` for headings, logo, outlined buttons, and key text.
- Keep all action buttons pill-shaped.
- Use Inter Variable weight 510 for headings and active controls.
- Use weight 590 for emphasis instead of generic heavy bold.
- Apply the gray surface stack carefully: `#08090a`, `#141516`, `#1c1c1f`, `#23252a`, `#2d2e31`.
- Use 1px hairline borders in `#23252a` or `#34343a`.
- Keep Berkeley Mono limited to technical accents.
- Keep the spacing compact and tied to a 4px base.
- Let UI screenshots, icon grids, and code cards provide visual interest.

## Do Not

- Do not add filled colorful CTAs.
- Do not use gradient buttons or large chromatic fills.
- Do not use heavy card shadows.
- Do not use 600/700 type weights as the default heading voice.
- Do not use radii larger than 8px on cards, screenshots, or code blocks.
- Do not make Berkeley Mono the primary reading font.
- Do not add lifestyle photography or friendly decorative illustration.
- Do not break the compact rhythm with oversized marketing gaps.
- Do not overuse accent dots or status colors.

## Accessibility Notes

- Snow on Onyx Canvas has strong contrast and should be used for critical text.
- Mist Text is best for body copy; Fog Text is better for metadata and helper text.
- When using small muted labels, verify contrast against the chosen surface.
- Preserve visible focus styles even if the visual language is quiet.
