# Colors

## Core Neutrals

| Name | Value | Token | Use |
| --- | --- | --- | --- |
| Onyx Canvas | `#08090a` | `--color-onyx-canvas` | Page background and full-bleed base |
| Carbon Surface | `#141516` | `--color-carbon-surface` | Cards, inputs, and subtle raised surfaces |
| Graphite Surface | `#1c1c1f` | `--color-graphite-surface` | Nested panels, icon tiles, and code snippets |
| Smoke Surface | `#23252a` | `--color-smoke-surface` | Hover surfaces and primary border tone |
| Iron Surface | `#2d2e31` | `--color-iron-surface` | Pressed state and highest dark surface |
| Void | `#030404` | `--color-void` | Deep recess and absolute dark accent |

## Borders

| Name | Value | Token | Use |

| Ash Border | `#34343a` | `--color-ash-border` | Dividers, table rows, and list separators |

## Text

| Name | Value | Token | Use |
| --- | --- | --- | --- |
| Steel Text | `#62666d` | `--color-steel-text` | Tertiary labels and low-emphasis icons |
| Pewter Text | `#7f7f80` | `--color-pewter-text` | Disabled text and placeholder-tier copy |
| Fog Text | `#8a8f98` | `--color-fog-text` | Metadata, timestamps, muted nav, and helper text |
| Mist Text | `#d0d6e0` | `--color-mist-text` | Body copy and secondary descriptions |
| Snow | `#f7f8f8` | `--color-snow` | Headings, logo, primary text, and outlined CTA border |

## Rules

- Keep the interface monochrome.
- Treat `#f7f8f8` as the main signal color.
- Use border and surface value changes instead of colored fills.
- If a small status accent is needed, make it content-driven and rare.
- Never turn this style into a blue, purple, or gradient CTA system.
