# Spacing And Shape

## Spacing

- Base unit: 4px.
- Density: compact.
- Main content width: 640px to 720px.
- Wider section width: up to 1080px.
- Section gap: 48px.
- Card padding: 16px.
- Element gap: 8px.

## Radius

| Element | Value | Notes |
| --- | --- | --- |
| Navigation pills | 9999px | Use for nav chips and active pill controls |
| Tags | 4px | Compact label corners |
| Cards | 8px | Maximum card feel; keep it crisp |
| Icons | 4.4625px | Small technical tile radius |
| Inputs | 4px | Squared technical controls |
| Buttons | 9999px | Primary and secondary actions |

## Shadows And Elevation

- Prefer `rgb(62, 62, 68) 0px 0px 0px 1px` for a subtle stroke-like effect.
- Use inset strokes sparingly for elevated control surfaces.
- Avoid blurred card shadows. Depth should come from surface value shifts.
