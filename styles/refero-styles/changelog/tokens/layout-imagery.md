# Layout And Imagery

## Layout Pattern

- Full-bleed dark canvas.
- Sticky top navigation with a 1px divider.
- Centered content column for prose and release entries.
- Wider max-width only for icon grids, product screenshots, or navigation bands.
- Single-column changelog flow.
- Compact tab navigation near the page title.
- Dated entries stacked vertically with 48px gaps.

## Content Width

- Prose and changelog body: 640px to 720px.
- Wide sections: up to 1080px.
- Keep release content readable and left-aligned.

## Imagery

Use visual content as evidence, not decoration:

- Product UI screenshots.
- App connector icon grids.
- Small command or code cards.
- Inline technical diagrams.
- Dark interface captures with 4px to 8px radius.

Avoid:

- Lifestyle photography.
- Big abstract renders.
- Colorful decorative illustration.
- Full-bleed image hero treatments.
- Generic SaaS card collages.

## Motion

If motion is used, keep it subtle:

- Opacity transitions for preview media.
- Slight border color changes on hover.
- Small text color transitions.
- No bouncy or playful motion.
