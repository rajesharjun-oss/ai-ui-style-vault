## Style Summary

Changelog is a Linear-style release-notes system: a near-black engineering notebook with compact spacing, stacked graphite surfaces, precise Inter Variable typography, and rare Berkeley Mono details. It avoids colorful SaaS decoration. The design gets its confidence from white-on-black contrast, 1px borders, pill controls, and strict typographic rhythm.

Use this style when an AI needs to build a changelog, developer docs page, product update feed, release-notes archive, command-center dashboard, or quiet technical marketing surface.

## What To Borrow

- Onyx Canvas `#08090a` as the full-page background.
- Snow `#f7f8f8` for headings, logo, key borders, and outlined CTAs.
- Mist Text `#d0d6e0` for readable body copy on dark.
- Fog Text `#8a8f98` for metadata, dates, helper text, and quiet navigation.
- Inter Variable with custom 510 and 590 weights for the Linear-like voice.
- Berkeley Mono only for code references, commands, and technical callouts.
- 9999px action pills with transparent backgrounds and white borders.
- Compact 4px spacing rhythm with 48px section gaps.
- 4px to 8px radii for cards, inputs, icon tiles, screenshots, and code blocks.
- Surface depth from gray steps and 1px borders, not blurred shadows.

## Avoid

- Filled primary buttons in blue, purple, or gradient colors.
- Large chromatic accents or decorative gradients.
- Heavy shadows, glassmorphism, and glossy effects.
- Card radii larger than 8px, except for pill controls.
- Using Berkeley Mono for full paragraphs or major headings.
- 600/700 display weights when 510/590 can carry the hierarchy.
- Lifestyle photography, playful illustration, or marketing-card clutter.
