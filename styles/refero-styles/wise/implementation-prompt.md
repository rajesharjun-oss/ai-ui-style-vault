# Implementation Prompt

Use the Wise style for this UI.

Create a light fintech interface with Paper (`#ffffff`) as the default canvas, Forest Ink (`#163300`) as the dominant brand dark, and Lime Voltage (`#9fe870`) as the sparse action and active-state accent. The page should feel confident, global, clean, and friendly.

Typography:

- Use Wise Sans 900 for hero and major display headlines from 89px to 105px.
- If Wise Sans is unavailable, use Inter Black 900 with tight tracking.
- Use Inter for body, nav, labels, forms, feature rows, and smaller headings.
- Display headings should use line-height around 0.85 and negative tracking around -3.15px at 105px.
- Do not use Inter for display type above 60px.

Color:

- Body text: Charcoal `#454745`.
- Display text: Obsidian `#0e0f0c` or Forest Ink `#163300`.
- Muted text and input borders: Pebble `#868685` or Slate `#6a6c6a`.
- Soft surfaces: Fog `#e8ebe6` and Linen Mist `#e2f6d5`.
- Dark sections: Forest Ink `#163300`.
- Active state and main action: Lime Voltage `#9fe870`.

Layout:

- Use a centered max-width of about 1200px.
- Use 64px to 80px section gaps.
- Alternate white, fog, pale green, and dark green sections.
- Hero should be a centered massive display headline with a large globe or money illustration near the lower edge.
- Use three-column feature rows and five-column country grids on desktop.
- Keep top nav around 64px tall with a segmented pill switcher.

Components:

- Primary CTA: full pill radius, Lime Voltage fill, Forest Ink or Charcoal text, Inter 500 16px, 11px 24px padding.
- Secondary CTA: underlined Forest Ink text link, Inter 500 16px.
- Outlined account button: white fill, 1px Forest Ink border, full pill radius.
- Segmented control: full pill container; active segment lime, inactive transparent.
- Country item: circular 56px flag, Forest Ink label, underline on hover.
- Dark section card: Forest Ink background, 28px radius, 40px padding, lime headline, white body.
- Input: 10px radius, 1px Pebble border, 12px 16px padding, Forest Ink focus border.

Avoid pure black body text, sharp-corner buttons, many lime accents in one view, decorative gradients, glows, heavy drop shadows, and generic blue fintech styling.
