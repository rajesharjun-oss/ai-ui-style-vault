# Wise

AI-ready Refero style bundle for Wise.

- Source: https://styles.refero.design/style/367c0c6e-73a7-441c-a8ff-91d139ac60dc
- Reference site: https://wise.com
- Captured: 2026-07-28
- Theme: light
- Mood: deep moss with lime voltage
- Industry: finance, money transfer, global banking, fintech

## Use This Style For

- Fintech and banking landing pages with a confident but friendly voice
- Global money transfer, currency, payments, or account dashboards
- Product pages that need a strong green brand system without decoration-heavy UI
- Interfaces where pill controls, flags, dark green sections, and giant display type create the identity

## Files

- `source.md` records the source URL and capture context.
- `DESIGN.md` is the main human-readable design reference.
- `implementation-prompt.md` is a direct prompt for an AI coding agent.
- `style.json` is a structured summary for indexing and retrieval.
- `tokens/` contains focused notes for colors, type, spacing, components, guidelines, layout, and imagery.
- `code/` contains CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` reserves the screenshot slot for manual or automated captures.

## Core Signature

Wise is a clean finance system built from deep forest green, sparse lime action, massive Wise Sans display type, pill-shaped controls, circular flag masks, and alternating white, pale green, fog, and dark green sections. It feels confident and global without relying on gradients or heavy decoration.
