# Colors

## Brand

| Name | Value | Token | Use |
| --- | --- | --- | --- |
| Forest Ink | `#163300` | `--color-forest-ink` | Dominant dark, dark sections, nav text, primary copy, icon strokes |
| Lime Voltage | `#9fe870` | `--color-lime-voltage` | Primary action fill, active tabs, dark-section emphasis |
| Spruce | `#054d28` | `--color-spruce` | Secondary dark green and dark-section depth |
| Linen Mist | `#e2f6d5` | `--color-linen-mist` | Pale green highlight wash, tinted cards, hover states |

## Supporting Accents

| Name | Value | Token | Use |
| --- | --- | --- | --- |
| Signal Blue | `#0b4c72` | `--color-signal-blue` | Low-frequency supporting accent |
| Alarm Red | `#cb272f` | `--color-alarm-red` | Low-frequency supporting accent, not default status color |

## Neutrals

| Name | Value | Token | Use |
| --- | --- | --- | --- |
| Charcoal | `#454745` | `--color-charcoal` | Body text and dense UI |
| Obsidian | `#0e0f0c` | `--color-obsidian` | Display text and maximum contrast headings |
| Pebble | `#868685` | `--color-pebble` | Muted copy, placeholders, input borders |
| Slate | `#6a6c6a` | `--color-slate` | Supporting copy and helper labels |
| Fog | `#e8ebe6` | `--color-fog` | Card surfaces, soft panels, dividers |
| Paper | `#ffffff` | `--color-paper` | Page canvas and inverted surfaces |

## Application Notes

- Forest Ink is the brand-dark default, not pure black.
- Lime Voltage needs spacing around it so it reads as punctuation.
- Do not use Lime Voltage for body text on light backgrounds.
- Fog and Linen Mist create light-section variety without decoration.
