# Components

## Primary CTA Pill Button

- Fill: Lime Voltage.
- Text: Charcoal or Forest Ink.
- Font: Inter 500, 16px.
- Radius: 9999px.
- Padding: 11px 24px.
- Border: none.
- Shadow: none.

Use one lime primary action per visible section.

## Outlined Pill Button

- Fill: Paper.
- Border: 1px solid Forest Ink.
- Text: Forest Ink.
- Radius: 9999px.
- Font: Inter 500, 16px.
- Use for secondary account actions such as sign up.

## Text Link Button

- Text: Forest Ink.
- Font: Inter 500, 16px.
- Underlined.
- No border and no background.

## Top Navigation Bar

- Background: Paper.
- Height: about 64px.
- Left logo.
- Center segmented switcher for Personal, Business, Platform.
- Right cluster: flag/language, Help, Log in, Sign up.

## Segmented Tab Control

- Full pill container.
- Active segment: Lime Voltage fill, Charcoal text.
- Inactive segment: transparent, Charcoal text.
- Height: about 40px.
- Segment padding: about 12px horizontal.

## Display Headline

- Font: Wise Sans.
- Weight: 900.
- Size: 89px to 105px.
- Line height: 0.85.
- Tracking: tight negative.
- Color on light: Obsidian or Forest Ink.
- Color on dark: Lime Voltage.

## Feature Row

- Three columns on desktop, one column on mobile.
- Icon: 24px Charcoal stroke.
- Heading: Inter 700, 18px, Obsidian.
- Body: Inter 400, 16px, Pebble.
- Use about 24px gap between icon and heading.

## Country Grid Item

- Flag: circular 56px thumbnail.
- Label: Inter 500, 16px, Forest Ink.
- Gap: 12px.
- Hover: underline label.
- Desktop: 5-column grid with about 32px row gap.

## Dark Section Card

- Background: Forest Ink.
- Radius: 28px.
- Padding: 40px.
- Headline: Lime Voltage.
- Body: Paper.
- Includes inset white currency selector card.

## Currency Selector Pill

- White pill inside dark card.
- Left: circular flag and country name.
- Right: outlined Change button.
- Use full pill radius and 8px vertical padding.

## Input Field

- Radius: 10px.
- Border: 1px solid Pebble.
- Padding: 12px 16px.
- Font: Inter 400, 16px.
- Focus: Forest Ink border with no glow ring.

## Floating QR Badge

- Fixed bottom-right.
- Background: Forest Ink.
- Radius: 16px.
- Width: about 120px.
- QR code in Paper.
- Label: Lime Voltage, Inter 500, 12px.
