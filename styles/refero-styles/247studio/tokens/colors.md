# Color Tokens

## Palette

| Token | Value | Role |
|---|---:|---|
| Pure White | `#ffffff` | Main canvas, cards, inverted text on dark surfaces |
| Ink Black | `#000000` | Primary text, logo, borders, labels, dark actions |
| Obsidian | `#1f1f1f` | Dark sections, footer, inverted editorial moments |
| Graphite Wash | `#333333` | Dark panels, overlays, subdued dark surfaces |
| Slate | `#666666` | Secondary body copy, muted UI, secondary labels |
| Steel | `#808080` | Tertiary text, captions, grayscale logo placeholders |
| Fog | `#999999` | Muted hero line, inactive states, pale supporting copy |
| Pale Mist | `#cccccc` | Hairline borders, disabled states, field outlines |
| Vapor | `#e6e6e6` | Soft dividers, inputs, card fills, placeholders |
| Ash | `#f2f2f2` | Alternating bands, image placeholder fill, quiet containers |

## Usage

- Use `#ffffff` as the default page background.
- Use `#000000` for important text, logo marks, and highest-contrast UI.
- Use `#999999` for the muted italic hero line.
- Use `#cccccc` and `#e6e6e6` for borders and structural dividers.
- Use `#1f1f1f` only when the page needs an inverted section or footer.
- Use `#f2f2f2` for image placeholders and soft section contrast.

## Action Color

There is no distinct action color. Buttons should be black, white, or gray:

- Primary: black fill, white text.
- Secondary: white fill, black text, black or pale gray border.
- Disabled: vapor or pale mist background with steel text.

## Avoid

- Do not add blue, purple, orange, or green as a CTA color.
- Do not use gradients.
- Do not use colorful badge systems.
- Do not rely on translucent overlays unless they remain neutral gray.
