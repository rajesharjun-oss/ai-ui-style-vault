# Typography Tokens

## Families

Display and brand:

- Preferred: `247 grotesk`
- Fallbacks: Inter, Neue Haas Grotesk, Sohne, system sans
- Feature: `font-feature-settings: "ss01";`

Body and utility:

- Preferred: `Ntbau`
- Fallbacks: Sohne, Inter, Untitled Sans, system sans
- Use for copy, captions, addresses, and metadata.

## Display Rules

- Keep large display text weight 400.
- Use weight 500 for labels, compact buttons, and short emphasis.
- Use italic only as a deliberate editorial contrast, especially for the muted hero line.
- Avoid negative letter spacing. The source reads better with natural spacing and precise line breaks.

## Hero Type

- Line 1: 73px, black, normal style, weight 400.
- Line 2: 73px, `#999999`, italic, weight 400.
- Keep line-height exactly 1.
- Avoid centered alignment unless the whole page is redesigned around it.

## Microcopy

- Use 10-11px labels for side notes, grid numbers, and section eyebrows.
- Use uppercase only for short labels.
- Keep metadata sparse and aligned to the grid.
