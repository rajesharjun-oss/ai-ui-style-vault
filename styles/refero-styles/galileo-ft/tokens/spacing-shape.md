# Spacing And Shape

## Layout Values

| Purpose | Value |
| --- | --- |
| Density | comfortable |
| Base unit | 4px |
| Page max width | 1200px |
| Section gap | 64px |
| Card padding | 32px |
| Element gap | 9px |

## Radius

| Element | Value | Token |
| --- | --- | --- |
| tags | 17px | `--radius-tags` |
| cards | 35px | `--radius-cards` |
| inputs | 35px | `--radius-inputs` |
| buttons | 48px | `--radius-buttons` |

## Shape Rules

- Buttons and nav pills are strongly rounded at 48px.
- Cards, panels, and inputs use 35px radii.
- Tab pills use 17px radii.
- Do not use sharp 0px or 4px interactive corners.
