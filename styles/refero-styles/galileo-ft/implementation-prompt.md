# Implementation Prompt

Build the UI in the Galileo-ft Refero style.

Create a deep-space fintech command-deck interface. Use a near-black navy page canvas, dark indigo cards, lavender hairline borders, ultrathin geometric typography, cobalt primary actions, and a restrained teal supporting signal. The design should feel premium, flat, technical, and calm.

Color rules:

- Page background: `#03081a`.
- Dark card/panel surface: `#020626`.
- Hairline border: `#292f66`.
- Muted border/disabled: `#4d5499`.
- Secondary text/link border: `#aab1f2`.
- Tertiary text: `#7a83cc`.
- Primary text: `#ffffff`.
- Primary filled action: `#3d50fc`.
- Supporting signal: `#05e0e0`.
- Full-bleed banner gradient only: `linear-gradient(90deg, #05a1c9 0%, #3d50fc 100%)`.

Typography rules:

- Use Plain/Inter Thin-style ultrathin type for all large headings.
- Never use 600 or 700 weight for headlines.
- Large headings at 42px or larger use weight 100 and about -0.02em tracking.
- Hero headline: 56-83px, weight 100, white, line-height 1.0-1.1.
- Body: 16px, weight 300, readable line height.
- Eyebrow: 10px uppercase, 0.25em tracking.

Layout rules:

- Max content width: 1200px.
- Outer gutters: 32-64px.
- Section gap: 64px.
- Hero split: ultrathin heading left, large 3D glass sculpture or product mockup right.
- Product sections can use 2-column text-plus-dashboard layouts.
- Use rounded dashboard cards and tab pill navigation.

Component rules:

- Primary button: `#3d50fc` fill, white text, 48px radius, 22px by 14px padding, no shadow.
- Ghost button: transparent, 1px white border, white text, 48px radius.
- Dark card: `#020626`, 1px `#292f66` border, 35px radius, 32px padding, no shadow.
- Light card: white surface, violet/lilac border, 35px radius, 32px padding.
- Tab pill: active cobalt fill, 17px radius; inactive transparent with faint violet border.
- Links use a 1px Quartz Lavender bottom border instead of normal underlines.

Avoid heavy headline weights, drop shadows, sharp corners, multiple vivid accents on one surface, gradients inside cards, and additional dark canvas colors.
