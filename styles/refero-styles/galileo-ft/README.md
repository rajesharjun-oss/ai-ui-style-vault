# Galileo-ft

AI-ready Refero style bundle for a deep-space fintech interface: near-black navy canvas, ultrathin display typography, cobalt primary actions, lavender hairline structure, generous radii, and restrained 3D glass/product visuals.

## Source

- Refero style: https://styles.refero.design/style/10a77cbd-7847-4e1b-a09e-447ebad0f7c6
- Reference site: https://www.galileo-ft.com
- Captured: 2026-07-28
- Theme: dark

## Use This When

- You need a premium fintech, banking infrastructure, payments, API, data platform, or financial operations interface.
- The UI should feel like a dark observatory or command deck rather than a generic dashboard.
- You want one electric action color, thin typography, and flat architectural depth.

## Bundle Contents

- `DESIGN.md` - complete AI style reference.
- `implementation-prompt.md` - drop-in prompt for AI implementation.
- `style.json` - structured metadata and searchable summary.
- `tokens/` - colors, typography, spacing, components, guidelines, layout, and imagery.
- `code/` - CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` - screenshot capture notes.
