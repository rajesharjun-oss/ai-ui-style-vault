monopo saigon is a monochrome editorial gallery system with one theatrical exception: a full-viewport iridescent hero atmosphere. The interface itself stays black, white, and gray. Typography does the heavy lifting through monumental Roobert headlines, whisper-light 78px section statements, tiny labels, sharp 0px content corners, and full 75px pill controls.

Use this folder as an AI implementation brief. The most useful files are:

- `DESIGN.md` for the full style interpretation.
- `implementation-prompt.md` for a copy-ready prompt to hand to an AI builder.
- `style.json` for structured metadata.
- `code/css-variables.css` for CSS custom properties and component recipes.
- `code/tailwind-v4.css` for Tailwind v4 theme tokens.
- `code/design-tokens.json` for machine-readable tokens.

Core cues:

- Interface palette: black, white, and grays only.
- Hero media: one liquid iridescent wash, sage to amber to oxblood.
- Primary type: Roobert, weights 300, 400, 600.
- Display headline: up to 225px, weight 400.
- Whisper headline: 78px, weight 300.
- Geometry: 0px radius for cards, images, inputs, and links; 75px radius only for buttons and tags.
- Motion: patient glide transitions using `cubic-bezier(0.19, 1, 0.22, 1)` across 0.8s to 1.25s.

This is best for editorial studios, creative portfolios, immersive agency sites, campaign archives, gallery-like case studies, and text-led brand experiences.
