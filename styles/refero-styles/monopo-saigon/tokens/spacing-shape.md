## Scale

## Radii

| Element | Value |
|---|---:|
| Buttons | 75px |
| Tags | 75px |
| Cards | 0px |
| Images | 0px |
| Inputs | 0px |
| Text links | 0px |

## Shape Rules

- Use 75px radius only for buttons and tags.
- Use 0px radius for cards, images, inputs, links, nav text, and project rows.
- Do not use radii between 1px and 74px.
- Do not use shadows to imply depth.
