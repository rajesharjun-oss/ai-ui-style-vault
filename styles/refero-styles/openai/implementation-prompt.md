# AI Implementation Prompt

Build a polished, responsive interface in the OpenAI style.

Use a pure white `Paper` canvas, OpenAI Sans or Inter fallback typography, black primary text, muted gray secondary text, and translucent black hairline borders. The interface should feel like a clean research publication and product entry point, not a colorful SaaS landing page.

Core rules:

- The only filled primary action is black with white text.
- Buttons, chips, tags, and inputs are full pills with `9999px` radius.
- Cards and images use a near-square `6px` radius.
- Do not use gradients, colored CTAs, colored section bands, card shadows, or decorative background blobs.
- Use 17px body text, 14px UI text, and a 48px editorial display headline when a hero or featured story is needed.
- Build hierarchy with whitespace, type scale, image size, and hairline borders.

Recommended layout:

1. A 64px white top nav with a text wordmark, simple nav links, search icon, login link, and one black `Try ChatGPT` pill CTA.
2. A centered hero area with a large short prompt or question and a wide pill search/prompt input.
3. A row of outlined pill suggestion chips below the input.
4. An editorial content section using an asymmetric grid: one large featured article card and smaller stacked article cards.
5. A quiet multi-column footer with small text links.

Use the token files in this folder for exact colors, spacing, shape, and typography.
