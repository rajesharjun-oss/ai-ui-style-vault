# Layout And Imagery

## Layout Pattern

The core page structure is:

1. Minimal text-led top navigation.
2. Centered hero with a prompt/search input.
3. Row of outlined pill suggestion chips.
4. Asymmetric editorial grid below the hero.
5. Quiet multi-column footer.

Keep the page highly scannable. Do not over-panel the canvas. Most sections should feel like composed editorial spreads, not boxed modules.

## Grid

- Max width: about 1200px.
- Use generous side margins.
- For content lists, favor a two-column editorial grid on desktop.
- Let one feature item be much larger than the supporting items.
- On mobile, stack in a single column with the feature first.

## Imagery

Use images that feel real, editorial, and product-relevant:

- Product screenshots.
- Research and lab-adjacent photography.
- People at work or in conversation.
- Abstract but restrained research imagery.

Avoid:

- Neon technology backgrounds.
- 3D mascot art.
- Bright gradients.
- Generic SaaS illustrations.
- Dark dramatic hero images.
