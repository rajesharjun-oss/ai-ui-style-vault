# Components

## Filled Action Button

- Background: `#000000`
- Text: `#ffffff`
- Radius: `9999px`
- Typography: 14px, 500
- Padding: 8px 20px
- Use for the single most important action only.

## Outlined Pill Button

- Background: transparent
- Border: 1px solid `rgba(0,0,0,0.12)`
- Text: `#000000`
- Radius: `9999px`
- Typography: 13px to 14px, 500
- Use for prompt chips, filters, and secondary actions.

## Ghost Text Button

- Background: transparent
- Border: none
- Text: `#000000` or `#666666`
- Hover: `rgba(0,0,0,0.04)`
- Use for nav, breadcrumbs, login, and quiet links.

## Search Or Prompt Input

- Background: `#ffffff`
- Border: 1px solid `rgba(0,0,0,0.12)`
- Radius: `9999px`
- Text: `#000000`
- Placeholder: `#666666`
- Typography: 16px, 400
- Padding: 10px 24px, with larger left padding when an icon is present.

## Article Card

- Background: transparent or `#ffffff`
- Image radius: 6px
- Shadow: none
- Typography-led content below or beside image
- Use image scale and headline size for hierarchy.

## Top Navigation

- Height: about 64px
- Background: `#ffffff`
- Links: 14px, 500, black
- Actions: ghost `Log in`, filled black `Try ChatGPT`
- Keep the nav text-led and low-friction.

## Footer

- Background: `#ffffff`
- Multi-column text links
- Small type, mostly Graphite
- No newsletter block unless the product specifically needs it.
