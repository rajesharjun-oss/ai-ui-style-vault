# Spacing And Shape

## Spacing

| Purpose | Value | Notes |
|---|---:|---|
| Density | comfortable | Calm editorial rhythm |
| Base unit | 4px | Build spacing in 4px steps |
| Max width | 1200px | Contained content width |
| Nav height | 64px | Quiet product navigation |
| Section gap | 32px to 64px | Use whitespace instead of colored bands |
| Inline gap | 8px to 16px | Chips, nav items, small actions |
| Button padding | 8px 20px | Compact pill buttons |
| Search input padding | 10px 24px | Add extra left padding if using a search icon |

## Shape

| Element | Radius | Notes |
|---|---:|---|
| Buttons | 9999px | Full pill |
| Tags and chips | 9999px | Full pill |
| Inputs | 9999px | Full pill |
| Cards | 6px | Near-square editorial geometry |
| Images | 6px | Match card radius |
| Utility surfaces | 4px | Only for tiny supporting UI |

## Elevation

- Card shadows: none.
- Panel shadows: none.
- Use hairline borders, image size, and spacing to separate elements.
