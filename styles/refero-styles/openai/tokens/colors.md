# Colors

| Name | Value | Token | Role |
|---|---:|---|---|
| Obsidian | `#000000` | `--color-obsidian` | Primary text, filled action button, strongest emphasis |
| Graphite | `#666666` | `--color-graphite` | Captions, helper text, muted labels, secondary nav |
| Smoke | `#8f8f8f` | `--color-smoke` | Tertiary text, disabled states, placeholders, icon strokes |
| Paper | `#ffffff` | `--color-paper` | Page background, cards, inputs, nav |
| Ash | `#f1f1f1` | `--color-ash` | Subtle surface fills, hover states, language selector style surfaces |
| Hairline | `rgba(0,0,0,0.12)` | `--color-hairline` | Borders, dividers, outlines |
| Whisper | `rgba(0,0,0,0.04)` | `--color-whisper` | Tiny hover and support accent |

## Guidance

- Use `#000000` as the only filled CTA color.
- Use `Paper` as the dominant canvas.
- Use `Hairline` for most visible structure.
- Do not add colored accents, gradients, or tinted section backgrounds.
