# OpenAI

Research lab notebook at noon: a quiet, editorial product surface built from white space, near-black typography, pill controls, and one black primary action.

Use this style when you want an AI, research, docs, or product interface to feel calm, high-trust, text-led, and precise. The main visual memory is simple: a pure white canvas, black OpenAI Sans type, hairline borders, a pill search/prompt input, and an asymmetric editorial content grid.

## Files

- `source.md`: Source URL, reference site, capture notes, and scope.
- `DESIGN.md`: Human-readable design breakdown.
- `implementation-prompt.md`: Prompt for an AI builder to implement the style.
- `style.json`: Structured design metadata.
- `tokens/`: Markdown token notes by category.
- `code/`: CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md`: Placeholder for future manual screenshots.

## Quick Use

1. Use `Paper` white for the whole page.
2. Use `Obsidian` black for text and the only filled CTA.
3. Keep buttons, tags, and inputs fully pill-shaped.
4. Keep cards and images nearly square with a 6px radius.
5. Use hairline borders and whitespace instead of color panels or shadows.
