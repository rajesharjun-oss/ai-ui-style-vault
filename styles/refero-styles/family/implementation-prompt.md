# Implementation Prompt

Build a polished light crypto/product page in the Family style.

Use a warm cream page canvas (`#fbfaf9`) with a centered 1200px content container. Set display and hero headings in the custom `Family` typeface at 44px to 68px, weight 500, with tight tracking. Use Inter for all body copy, navigation, cards, buttons, forms, and labels.

Keep the UI flat and pressed into paper. Feature cards should be white or stone-toned, 10px radius, 32px padding, and defined by a 1px inset border in `#f2f0ed`. Avoid heavy shadows; the only exception is a sparingly used dark feature card.

Use `#121212` for the primary filled pill CTA, 32px radius, with cream or white text. Use `#f6f4ef` for a secondary sand pill. Use `#ff3e00` for inline demo links and accent text. Use `#0086fc` for inline actionable text, not filled buttons.

Add flat, hand-drawn illustration clusters around the hero or key sections. Use sky blue, orange, yellow, green, pink, and violet as illustration fills. Keep these accents asymmetrical and decorative so the centered copy remains the focus.

Avoid gradients, glossy cards, blue filled CTAs, pure white page backgrounds, dense dashboard layouts, arbitrary border radii, and generic enterprise SaaS styling.
