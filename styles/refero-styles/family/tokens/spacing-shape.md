# Spacing And Shape

## Spacing

| Purpose | Value |
|---------|-------|
| Density | comfortable |
| Base unit | 4px |
| Max width | 1200px |
| Section gap | 80px to 120px |
| Card padding | 32px |
| Element gap | 8px to 12px |

## Scale

```text
4px, 8px, 12px, 16px, 20px, 24px, 28px, 32px, 36px, 48px, 60px, 76px, 80px, 92px, 96px, 104px
```

## Border Radius

| Element | Value |
|---------|-------|
| Small marks | 2px |
| Badges | 6px |
| Nav | 10px |
| Cards | 10px |
| Large panels | 17px to 24px |
| Buttons | 32px |
| Illustration shapes | 40px to 72px |
| Pills | 9999px |

## Shape Behavior

- Use 10px as the default UI radius.
- Use 32px for pill CTAs.
- Use 9999px for true pills only.
- Use larger organic radii only inside illustrations.
- Avoid random radius values outside the core vocabulary.
