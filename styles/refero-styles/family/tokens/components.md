# Components

## Hero

- Centered headline and supporting copy.
- Flat illustration clusters flanking the text.
- Cream canvas base with wide whitespace.
- Keep illustrations asymmetrical and away from the main text block.

## Navigation

- Warm cream or transparent surface.
- Compact labels in Heading Charcoal.
- Secondary login-style action can be ghost text.
- Primary nav CTA is a small dark pill.

## Primary CTA

- Background: `#121212`.
- Text: cream or white.
- Radius: 32px.
- Compact horizontal padding around 14px.
- Use this as the only strong filled action.

## Secondary CTA

- Background: `#f6f4ef`.
- Text: `#121212`.
- Radius: 32px.
- Pair with the dark primary CTA.

## Inline Demo Link

- Text link only.
- Color: `#ff3e00`.
- Underlined.
- No filled background.

## Feature Cards

- Background: `#ffffff` or `#f2f0ed`.
- Radius: 10px.
- Padding: 32px.
- Border: 1px inset `#f2f0ed`.
- Avoid visible drop shadows.

## Dark Feature Card

- Background: `#000000` or `#121212`.
- Use sparingly for a single high contrast feature.
- Soft shadow is acceptable here because the surface is dark.
