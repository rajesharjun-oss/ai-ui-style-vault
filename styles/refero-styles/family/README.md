## Use This When

Use this style when a product should feel friendly, secure, flat, and quietly playful. It works well for crypto wallets, fintech onboarding, consumer apps, product education, feature grids, and lightweight marketing pages that need charm without losing trust.

The key behavior is paper-first restraint: a cream canvas, warm charcoal text, 10px hairline cards, compact pill buttons, and colorful illustration accents. Most UI chrome stays neutral while orange and blue mark interactive text.
