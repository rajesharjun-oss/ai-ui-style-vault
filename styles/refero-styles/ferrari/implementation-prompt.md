# Implementation Prompt

Build the UI in the Ferrari Refero style.

Use a cinematic black editorial system: full-bleed dark sections, edge-to-edge product photography, tiny uppercase type, wide letter spacing, sharp 0px geometry, and hairline dividers. The interface should be calm and restrained. Avoid app chrome. The product image should do the emotional work.

Color rules:

- Primary background: `#000000`.
- Secondary dark surface: `#181818`.
- Borders and dark dividers: `#303030`.
- Primary text and icons: `#ffffff`.
- Muted text: `#8f8f8f` or `#666666`.
- Red accent: `#da291c` only for hover, focus, active state, or a small signal accent.
- Do not create a filled red CTA.

Typography rules:

- Use a FerrariSans-like sans: Inter, Helvetica Neue, Arial Narrow, or system-ui if no brand font exists.
- Use uppercase for nav, labels, buttons, links, captions, and most display copy.
- Keep interface copy between 11px and 13px.
- Use 16px medium weight for hero and section headlines.
- Add wide tracking, especially at small sizes.

Layout rules:

- Use full-viewport or near-full-viewport sections.
- Let photography bleed to all edges with no rounding, frames, or padding.
- Keep layout mostly centered and single-column.
- Use 1px hairline dividers only when structure is needed.
- Cards are flat rectangles with 0px radius, no shadows, and no elevation.

Component rules:

- Navigation links are transparent text-only controls.
- CTAs are text links with simple arrow affordances, not filled buttons.
- Icon buttons are 16px white outlined icons with transparent backgrounds.
- One full-radius pill is allowed only for filters or tags.
- Footer is full-width near-black with small uppercase links.

Avoid rounded buttons, colorful panels, gradients, shadows, decorative illustrations, stock-like lifestyle imagery, and any UI treatment that competes with the photography.
