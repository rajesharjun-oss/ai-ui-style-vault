# Typography

## Font Families

| Role | Font | Token | Fallback |
| --- | --- | --- | --- |
| Primary | FerrariSans | `--font-ferrarisans` | Inter, Helvetica Neue, Arial Narrow, system-ui, sans-serif |
| Body extraction | Body-Font | `--font-body-font` | Inter, Helvetica Neue, Arial Narrow, system-ui, sans-serif |

Use a clean condensed or narrow sans when the real brand font is unavailable. Enable `"ss01"` if the selected font supports it.

## Typography Rules

- Use uppercase for navigation, buttons, labels, links, metadata, and captions.
- Keep most interface text between 11px and 13px.
- Use 16px medium type for hero statements and section titles.
- Tracking should be wider at smaller sizes.
- Avoid heavy display weights; the style is quiet and precise.
