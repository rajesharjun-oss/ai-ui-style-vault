## Border Radius

| Element | Value | Token |
| --- | --- | --- |
| cards | 0px | `--radius-cards` |
| buttons | 0px | `--radius-buttons` |
| tags | 0px | `--radius-tags` |
| full pill | 9999px | `--radius-full` |

## Shape Rules

- Keep cards, panels, image frames, and buttons at 0px radius.
- Use the full pill only for category filters or status tags.
- Do not add soft surfaces, rounded rectangles, or floating panels.
