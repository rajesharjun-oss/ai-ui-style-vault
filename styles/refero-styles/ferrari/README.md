# Ferrari

AI-ready Refero style bundle for a dark automotive editorial interface: black full-bleed panels, cinematic vehicle photography, small uppercase typography, sharp 0px geometry, and a single red interaction signal.

## Source

- Refero style: https://styles.refero.design/style/80164adf-a898-4f7c-bce7-12f3f62e1649
- Reference site: https://ferrari.com
- Captured: 2026-07-28
- Theme: dark

## Use This When

- You need a premium automotive, gallery, luxury product, or cinematic editorial screen.
- The UI should feel quiet, exacting, and image-led instead of app-like.
- The product photography should be the hero and the interface should recede.

## Bundle Contents

- `DESIGN.md` - complete AI style reference.
- `implementation-prompt.md` - drop-in prompt for asking an AI agent to build with this style.
- `style.json` - structured summary for indexing/search.
- `tokens/` - colors, typography, spacing, components, guidelines, and layout notes.
- `code/` - CSS variables, Tailwind v4 tokens, and JSON design tokens.
- `screenshots/README.md` - screenshot capture notes.

## Implementation Notes

Use this as an inspiration reference, not as an official Ferrari brand kit. Do not copy logos, proprietary images, or exact brand assets unless you have rights to use them.
