## Use This When

Use this style for loud brand microsites, creator pages, youth culture campaigns, editorial launches, playful age gates, character-driven landing pages, candy-colored product stories, and anything that should feel like a single printed poster instead of a conventional SaaS screen.

## Core Idea

Flying Papers is a flat violet stage with oversized display type, cartoon mascot energy, and a small saturated confetti palette. Every screen should behave like one bold poster: one dominant headline, one supporting character or illustration, one inline action, and lots of violet breathing room.
