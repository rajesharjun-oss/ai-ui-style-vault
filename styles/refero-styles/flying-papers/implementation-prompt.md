# Implementation Prompt

Build in the Flying Papers style: a loud full-bleed poster page on a Dusk Violet stage with giant display type, a flat cartoon mascot, and one small outlined action.

Use these rules:

- Page background: `#8584bd`.
- Main display accent: `#f4ed36`.
- Softer display accent: `#f9cc73`.
- Nested violet surface: `#61609a`.
- Light card or cream button surface: `#f9f5f2`.
- Text on cream: `#1a1a1a`.
- Hard outlines and text on yellow: `#000000`.
- Accent cards: `#f8c1ba`, `#b5c995`, `#ac4f98`, or `#c94245`.
- Display font: ObviouslyVariable or a wide condensed substitute.
- Display weight: 800-900.
- Display range: 184px to 341px for hero moments.
- Display line-height: 0.80 to 0.85.
- Display tracking: 0.02em.
- Disable contextual alternates: `font-feature-settings: "calt" 0;`.
- Mono labels: Bergen Mono or JetBrains Mono at 12px, line-height 0.80.
- Cards: 6px radius, 17px padding, flat fill, no shadow.
- Buttons and tags: 100px radius.
- Section gap: 40px.
- Element gap: 17px.

Composition:

1. Use a full viewport Dusk Violet canvas.
2. Put a centered Hi-Vis Yellow wordmark at the top.
3. Add one enormous headline that fills 60-80 percent of the viewport.
4. Add a mascot illustration with thick black outlines and flat 2-3 color fills.
5. Add one outlined Hi-Vis Yellow pill action and one small underlined mono text link.
6. If you add cards, make them flat paint swatches on the violet stage.

Avoid:

- White or cream page backgrounds.
- Filled yellow CTA buttons.
- Drop shadows.
- Glows.
- Gradients.
- Glass or blur effects.
- Uniform SaaS card grids.
- More than two accent colors in one composition.

The result should feel like a printed cartoon poster, not a product dashboard.
