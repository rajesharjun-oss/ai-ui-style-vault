# Layout And Imagery

## Layout

- Use full-bleed poster layouts.
- Avoid traditional max-width constraints for hero type.
- Keep the whole page on Dusk Violet.
- Build each viewport around one idea.
- Use one huge headline, one mascot, and one action.
- Use loose 2-column or 3-column card arrangements lower on the page.
- Keep cards irregular and content-sized instead of identical dashboard tiles.

## Imagery

Use:

- Cartoon mascots.
- Thick black outlines.
- Flat 2-3 color fills.
- Simple line icons.
- Stamped mono labels.
- Color swatch cards.

Avoid:

- Photography.
- 3D renders.
- Gradient illustration.
- Glossy shading.
- Glassmorphism.
- UI screenshots as the main hero.

The type carries the message. The mascot carries the mood.
