# Typography

## Primary Typeface

NotionInter is the core voice.

- Use for: body, navigation, labels, buttons, product headings, cards, testimonials, and hero display.
- Substitute: Inter.
- Weights: 400, 500, 600, 700.
- UI labels and nav: weight 500.
- Editorial light-section headings: weight 600.
- Hero display: weight 700.

## Editorial Accent

Lyon Text is a rare serif pause.

- Use for: one feature title, editorial accent, or pull-quote-like section.
- Substitute: Source Serif Pro.
- Weight: 400.
- Size: about 32px.
- Avoid using it for small text, labels, navigation, buttons, or product UI.

## Notes

- Keep body text between 14px and 20px.
- Use one heading weight per section.
- Tighten tracking as type gets larger.
- Let the hero be the only truly heavy 700-weight moment.
