# Spacing And Shape

## Spacing

- Base unit: 4px.
- Density: comfortable.
- Page max width: 1200px.
- Section gap: 80px.
- Card padding: 24px.
- Element gap: 16px.

## Radius

| Element | Value | Notes |
| --- | --- | --- |
| Tags | 9999px | Full pill only for tag and badge shapes |
| Cards | 12px | Product screenshots, feature cards, testimonial cards |
| Small | 5px | Tiny chips and inline elements only |
| Badges | 9999px | Status labels and "New" pills |
| Inputs | 8px | Form controls |
| Buttons | 8px | CTA and ghost buttons |

## Elevation

- Hero mockups can use soft stacked shadows.
- Light-section cards should rely on white surface and radius.
- Avoid heavy shadows in editorial sections.
