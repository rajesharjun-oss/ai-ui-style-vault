# Typography

## Primary Typeface

- Family: Open Runde
- Substitute: Inter, DM Sans, Outfit, or a rounded geometric sans
- Weights: 500 and 600
- OpenType: stylistic set `ss01` when available
- Use for headings, body, nav, buttons, labels, and invoice UI.

## Caption Typeface

- Family: Caveat
- Substitute: Dancing Script or Kalam
- Weight: 600
- Sizes: 16px and 24px
- Use only for testimonial signatures and handwritten attribution moments.

## Type Scale

| Token | Size | Weight | Line Height | Tracking | Use |
|---|---:|---:|---:|---:|---|
| `eyebrow` | 11px | 600 | 1.62 | 0.22px | uppercase labels |
| `body-sm` | 14px | 500 | 1.43 | -0.28px | small body and captions |
| `body` | 16px | 500 | 1.5 | -0.32px | running copy and UI |
| `body-lg` | 22px | 500 | 1.29 | 0 | large copy |
| `subheading` | 24px | 600 | 1.33 | -0.72px | feature headings |
| `heading-sm` | 32px | 600 | 1.25 | -0.96px | section headings |
| `heading` | 40px | 600 | 1.2 | -1.2px | large section titles |
| `heading-lg` | 48px | 600 | 1.17 | -1.44px | hero support headings |
| `display` | 64px | 600 | 1.13 | -1.92px | hero display |

## Rules

- Use weight 600 for headings 20px and above.
- Use tight negative tracking for display and headings.
- Use weight 500 for body text.
- Use 11px uppercase labels with slight positive tracking.
- Do not use Caveat for body, nav, or headings.
