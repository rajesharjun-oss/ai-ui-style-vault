# Colors

## Brand And Accents

| Name | Value | Use |
|---|---:|---|
| Electric Blue | `#0098f2` | Checkmarks, payment rates, eyebrow labels, inline highlights |
| Iris | `#6c56fc` | Decorative invoice chips, secondary brand detail |
| Magenta | `#f200ca` | Decorative invoice chips and small graphic details |
| Leaf | `#5d9c06` | Supporting text accent, links, tags, short emphasized phrases |
| Coral | `#ff6363` | Small icon or mark accent |
| Ice | `#cfeafa` | Light blue highlight surfaces and callout washes |
| Lavender | `#e1e0fc` | Light violet feature blocks |
| Blush | `#f6d2f4` | Light pink cards and decorative highlight blocks |

## Neutrals

| Name | Value | Use |
|---|---:|---|
| Carbon | `#0f0f0f` | Deep body text and secondary dark actions |
| Midnight | `#0d111b` | Primary filled button background |
| Ink | `#1e1e1e` | Headings and primary body text |
| Smoke | `#666666` | Secondary body text and descriptions |
| Fog | `#8d8d8d` | Tertiary text, nav links, muted metadata |
| Ash | `#999999` | Placeholder and disabled text |
| Concrete | `#afb0b1` | Muted surface fills and inactive chip backgrounds |
| Mist | `#ccd1da` | Borders, input outlines, divider lines |
| Snow | `#f7fafc` | Subtle section backgrounds |
| Soft Surface | `#fafafa` | Feature card backgrounds and alternating bands |
| Paper | `#ffffff` | Page canvas, card surfaces, hero background |

## Rules

- Use Midnight for primary buttons, not Electric Blue.
- Use Electric Blue only for functional punctuation.
- Keep most screens white and near-monochrome.
- Do not use pure black for text or buttons.
- Do not use more than two chromatic accents on a single screen.
- Keep body text at Smoke or darker for readability.
