# Acctual

Acctual is a bright invoice-product style system: white paper canvas, compressed geometric headlines, near-black pill CTAs, electric-blue functional punctuation, and layered invoice mockups that feel like paper documents floating on glass.

- Source: https://styles.refero.design/style/aeefc294-a8f7-443d-b76a-538dddc29afe
- Reference site: https://acctual.com
- Captured: 2026-07-28
- Theme: light
- Best for: invoicing, payments, billing SaaS, fintech onboarding, finance operations tools

## Use This When Building

Keep the page mostly white. Use dark navy-black for primary actions, not bright brand colors. Let Electric Blue appear as small functional punctuation: checkmarks, rate callouts, eyebrow labels, and inline emphasis. Use Open Runde-style typography with tight tracking and rounded cards/pills to make the interface feel confident but approachable.
