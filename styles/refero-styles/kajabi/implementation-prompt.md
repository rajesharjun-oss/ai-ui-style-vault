# Implementation Prompt

Use the Kajabi style language for this UI.

Create an achromatic editorial interface that feels like a white gallery for human expertise. The UI should stay strict and quiet: pure white canvas, near-black text, rectangular black CTAs, 2px corners, no brand color, and warm human photography as the emotional center.

Core rules:

- Use `#ffffff` as the main page canvas.
- Use `#0a0a0a` for primary text, navigation, filled CTAs, and footer text.
- Use `#1f1f1e` only for dark section bands and video framing.
- Do not introduce any chromatic UI color.
- Use Haffer if available; otherwise use Inter, Sohne, or General Sans.
- Use 400 weight for most headlines and let size create hierarchy.
- Reserve 600 weight for stats or numerical display, not marketing headlines.
- Apply negative tracking only to display type at 40px and above.
- Use 2px radius for buttons, inputs, cards, and images.
- Use 9999px radius only for category tabs and tag pills.
- Keep buttons, inputs, and ordinary cards flat with no shadows.

Recommended structure:

- Thin white top nav with logo left, center links, Login text link, and black Start Free Trial button.
- Centered hero with 60px display headline, 20px supporting copy, and email input plus attached CTA.
- Full-width strip of expert portrait cards with names and titles overlaid at the bottom.
- Centered stats row with large numbers and muted labels.
- Charcoal video section with centered headline, tab pills, video frame, and optional floating course content card.
- Final two-column signup section on white.

Avoid:

- Colorful CTAs or pastel SaaS panels.
- Rounded 8px or 12px component corners.
- Heavy shadows.
- Decorative illustrations.
- Body text with letter spacing.
- Pure black `#000000`; use `#0a0a0a`.

The result should feel precise, editorial, human, and premium without looking cold.
