# Colors

| Name | Hex | Use |
| --- | --- | --- |
| Paper White | `#ffffff` | Page canvas, card surfaces, inverse text on dark backgrounds |
| Ink Black | `#0a0a0a` | Primary text, filled CTA buttons, navigation, footer |
| Charcoal | `#1f1f1e` | Dark section backgrounds, video frame borders, elevated dark surfaces |
| Smoke | `#333333` | Input text, focused form borders, higher-emphasis neutral copy |
| Stone | `#535250` | Secondary body text, muted helper text, subdued list and border accents |
| Driftwood | `#949189` | Tertiary text, icon strokes, subtle borders |
| Sand | `#bcb9ae` | Link borders at rest, muted borders, decorative dividers |
| Graphite | `#d4d3ce` | Stronger form borders, table separators, visible dividers |
| Ash | `#e0dedc` | Hairline borders, card outlines, dividers between content blocks |
| Mist | `#e9e8e7` | Light surface tint, input backgrounds, secondary card surfaces |

## Palette Rules

- Keep the interface 100 percent achromatic.
- Use Ink Black instead of pure black.
- Use Paper White as the gallery-wall canvas.
- Use Charcoal only for dark bands and video framing.
- Let photography and video provide the only real color.
