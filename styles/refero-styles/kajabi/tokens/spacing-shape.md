# Spacing And Shape

## Spacing

| Purpose | Value |
| --- | --- |
| Density | Comfortable |
| Base unit | 4px |
| Max width | 1280px |
| Section gap | 64px to 80px |
| Card padding | 20px |
| Element gap | 12px to 24px |

Scale: 4px, 8px, 12px, 16px, 20px, 24px, 32px, 40px, 44px, 64px, 68px, 120px.

## Shape

| Element | Radius |
| --- | --- |
| Buttons | 2px |
| Inputs | 2px |
| Cards | 2px |
| Images | 2px |
| Pills | 9999px |
| Floating course overlays | 8px |

## Surface Rules

- Use flat surfaces by default.
- Do not add shadows to buttons, standard cards, or input fields.
- Allow subtle lift only for content cards floating above a video frame.
- Keep the rectangular 2px corner as the signature.
