# Guidelines

## Do

- Use `#0a0a0a` for all filled buttons and primary text.
- Set all rectangular UI to 2px radius.
- Use 9999px radius only for category tabs and tag pills.
- Let photography and video carry all color.
- Apply tight tracking at display sizes 40px and above.
- Maintain 64px to 80px vertical breathing room between major sections.
- Use Haffer 400 for headlines and rely on scale for hierarchy.

## Do Not

- Do not introduce chromatic brand colors.
- Do not use 8px or 12px radius on buttons, cards, or inputs.
- Do not use 600+ weight for marketing headlines.
- Do not add drop shadows to standard buttons, inputs, or cards.
- Do not use colored section backgrounds beyond Charcoal inversion.
- Do not letter-space body text.
- Do not use icon strokes thinner than 1.5px or thicker than 2px.

## AI Implementation Notes

- If the UI feels too cold, add better human photography rather than color.
- If the UI feels too plain, increase type scale or section spacing rather than adding decoration.
- If a component feels too modern SaaS, reduce its radius back to 2px and remove shadow.
- If hierarchy is unclear, use size, spacing, and dark bands before adding color.
