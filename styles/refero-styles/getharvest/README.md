# Getharvest

Source: Refero Styles  
URL: https://styles.refero.design/style/1eee9aa2-1e23-4675-9f6e-fb98c93969bd  
Reference site: https://www.getharvest.com  
Captured: 2026-07-28

Getharvest is a golden-hour productivity style: warm cream canvas, white floating product cards, soft tactile radii, one vivid orange action color, and warm-tinted shadows. It feels friendly, professional, and quietly editorial.

Use this folder as an AI implementation brief. The most useful files are:

- `DESIGN.md` for the full style interpretation.
- `implementation-prompt.md` for a copy-ready prompt to hand to an AI builder.
- `style.json` for structured metadata.
- `code/css-variables.css` for CSS custom properties and component recipes.
- `code/tailwind-v4.css` for Tailwind v4 theme tokens.
- `code/design-tokens.json` for machine-readable tokens.

Core cues:

- Canvas: `#fff8f1` Cream Canvas, never plain white for the page.
- Cards and inputs: `#ffffff` Paper White.
- Primary text: `#1d1e1c` Ink Black, warm near-black.
- Body text: `#615f5c` Warm Stone.
- Main accent: `#fa5d00` Harvest Flame for CTAs, links, active states, and brand marks.
- Atmospheric accent: `#fee3b5` Marigold Glow, decorative only.
- Shadow tone: `#e3d6c5` Parchment Shadow and warm orange glow.
- Functional font: MuotoWeb for navigation, UI, body, buttons, and most headings.
- Hero font: Monarch only for 72px emotional display moments.
- Shape: 16px buttons, inputs, and images; 20px cards.
- Depth: soft, warm-tinted shadows, never cold blue-gray shadows.

This is best for productivity SaaS, time tracking, invoicing tools, small business software, workflow dashboards, reporting products, and friendly B2B landing pages.
