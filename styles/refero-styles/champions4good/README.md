# Champions4good

AI-ready Refero style bundle for Champions4good.

- Source: https://styles.refero.design/style/e02671e1-ba31-465f-bb7f-b124bf91ab5e
- Reference site: https://www.champions4good.club
- Captured: 2026-07-28
- Theme: dark
- Mood: midnight sports broadside on a plum-dark wall
- Industry: sports, community, social impact, club

## Use This Style For

- Sports clubs, athlete communities, charity campaigns, and social-impact membership sites
- Landing pages that need giant condensed poster type and a small set of focused controls
- Dark club-brand systems with one lavender accent and very little decorative color
- Sites where typography, line icons, and plum-to-white section contrast carry the visual identity

## Files

- `source.md` records the source URL and capture context.
- `DESIGN.md` is the main human-readable design reference.
- `implementation-prompt.md` is a direct prompt for an AI coding agent.
- `style.json` is a structured summary for indexing and retrieval.
- `tokens/` contains focused notes for colors, type, spacing, components, guidelines, layout, and imagery.
- `code/` contains CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` reserves the screenshot slot for manual or automated captures.

## Core Signature

Champions4good is a midnight sports broadside: Deep Plum ground, Lavender Shock type, Druk Condensed poster words pushed to the viewport edges, quiet Neue Montreal UI chrome, pill toggles, compact lavender actions, and hard rhythm changes into white display sections.
