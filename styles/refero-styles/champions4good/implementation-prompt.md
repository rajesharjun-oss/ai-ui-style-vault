# AI Implementation Prompt

Build a dark sports-club poster interface inspired by Champions4good.

Use Deep Plum as the main dark canvas, Lavender Shock as the only major accent on dark sections, Druk Condensed Super Desktop for oversized poster headings, Neue Montreal for all UI and body text, compact pill controls, and strong dark-to-white section breaks. The page should feel like a vintage sports club broadside, not a conventional SaaS landing page.

Requirements:

- Use Druk Condensed Super Desktop for display words and section headings. If unavailable, use Oswald 700, Bebas Neue, or Anton as a fallback.
- Use Neue Montreal for navigation, buttons, body, and supporting copy. If unavailable, use Inter, Manrope, or DM Sans.
- Set display type line-height between 0.78 and 0.85.
- Use Lavender Shock only on Deep Plum or other dark sections.
- Use Mint Signal and Amber Pulse only as small badge or transition accents under 20% of a viewport.
- Use 9999px radius for buttons, toggles, and pill controls.
- Use 14px radius and 20px padding for cards.
- Keep navigation transparent over dark sections.
- Break page rhythm with Paper White sections and black Druk display type.
- Avoid shadows, gradients, serif display type, card-heavy SaaS composition, center-aligned display headlines, and large photography-led hero sections.

Hero recipe:

Create a full-bleed Deep Plum hero. Add a transparent 64px navigation bar. Place two centered 80x48px sport toggle pills above the hero text, one filled Lavender Shock and one outlined. Set the main headline in Druk Condensed at 187px to 317px, Lavender Shock, line-height 0.78, and push words close to the viewport edges. Use Neue Montreal 58px for small connector words.

Light section recipe:

Create a Paper White section with a left-aligned Druk Condensed display block at 187px, black or charcoal fill, line-height 0.85, and generous white space to the right. Add supporting Neue Montreal body copy in Slate.
