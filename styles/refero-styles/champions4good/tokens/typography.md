# Typography

## Font Stacks

- Display: `Druk Condensed Super Desktop`, `Oswald`, `Bebas Neue`, `Anton`, sans-serif
- UI/body: `Neue Montreal`, `Inter`, `Manrope`, `DM Sans`, sans-serif
- System fallback: `Arial`, system-ui, sans-serif

## Rules

- Use Druk Condensed for the brand voice and all major display text.
- Use Neue Montreal for practical UI and human-sized copy.
- Keep display line-height under 1.0.
- Use slightly positive tracking on condensed display words.
- Keep UI text quiet enough that the poster typography dominates.
