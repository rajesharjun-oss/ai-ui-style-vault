# Colors

## Palette

| Name | Value | Token | Role |
|---|---:|---|---|
| Deep Plum | `#23002b` | `--color-deep-plum` | Hero canvas, dark section backgrounds, page-level ground |
| Lavender Shock | `#e894ff` | `--color-lavender-shock` | Main accent on dark ground, display type, buttons, active toggles |
| Espresso Brown | `#291900` | `--color-espresso-brown` | Warm near-black cards, dark UI surfaces, warm borders |
| Ink Teal | `#002629` | `--color-ink-teal` | Cool near-black cards, deep text, cool borders |
| Slate | `#333333` | `--color-slate` | Body text on light sections, icon strokes, dense UI text |
| Charcoal | `#121212` | `--color-charcoal` | Headlines on light sections, near-black emphasis |
| Black | `#000000` | `--color-black` | Maximum-contrast text and display fills on white sections |
| Paper White | `#ffffff` | `--color-paper-white` | Light section canvas, reverse text, light card surfaces |
| Mint Signal | `#93ffe4` | `--color-mint-signal` | Small badge accents, highlight washes, functional punctuation |
| Amber Pulse | `#ffac47` | `--color-amber-pulse` | Small warm accent, secondary badges, energy markers |

## Usage

- Use Deep Plum as the main emotional ground.
- Use Lavender Shock against Deep Plum, not against white.
- Use Paper White for hard layout rhythm breaks.
- Use Espresso Brown and Ink Teal for dark card variants.
- Use Mint Signal and Amber Pulse only as small punctuation colors.
- Avoid adding extra hues.
