# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Base unit | `8px` |
| Density | `comfortable` |
| Page max width | `1200px` |
| Section gap | `64px` |
| Card padding | `20px` |
| Element gap | `8px` |
| Nav height | `64px` |
| Sport toggle size | `80px x 48px` |

## Spacing Tokens

Use `3`, `4`, `5`, `8`, `9`, `10`, `11`, `12`, `16`, `20`, `32`, `40`, `48`, `64`, `160`, and `192`.

## Radius

| Element | Radius |
|---|---:|
| Tags | `6px` |
| Cards | `14px` |
| Special elements | `24px` |
| Pills | `9999px` |
| Buttons | `9999px` |

## Shape Rules

- Use 9999px radius for every button and pill.
- Use 6px minimum radius on interactive elements.
- Use 14px radius for cards.
- Do not use shadows.
- Use flat layers and high contrast section shifts.
