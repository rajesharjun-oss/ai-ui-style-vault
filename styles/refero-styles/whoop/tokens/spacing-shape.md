|---------|-------|
| Density | comfortable |

| Card padding | 24px to 32px |
| Element gap | 15px to 24px |

## Border Radius

| Element | Value |
|---------|-------|
| Small elements | 8px |
| Cards | 24px |
| Images | 24px |
| Medium rounded | 30px |
| Pills | 300px |
| Buttons | 300px |

## Shape Behavior

- Every button is a pill.
- Cards and photographic tiles use 24px radius.
- Avoid square button geometry.
- Do not use shadows as the primary depth tool.
- Keep section transitions stark and full-bleed.
