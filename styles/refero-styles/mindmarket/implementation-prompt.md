# Implementation Prompt

Build a warm illustrated editorial interface in the MindMarket style.

Use Cream Paper `#f5f1e4` as the main page canvas. Do not use pure white as the background; reserve white for elevated cards, the floating nav, and inset content blocks. Use Ink Black `#2c2e2a` for primary text, borders, and icons. Avoid pure black for large body text on cream.

Use Inter as the only typeface. Display headlines should be enormous: 140-144px, weight 500, line-height 0.95, and letter-spacing around -0.06em. Section headings can shrink to 53-81px, but primary page headings should not drop below 53px. Body and navigation can sit around 15-20px.

Make the interface soft and sticker-like. Use 50px radius for cards, buttons, and nav containers. Use 63.75px for illustration containers and 10px for small chips or micro-elements. Avoid sharp 0-4px corners on major UI.

Use Fresh Grass `#8ed462` as the structural brand accent for nav strokes, borders, toggle fills, and small highlights. Use Sky Pop `#2ba0ff`, Coral Pop `#ff705d`, and Sunshine Pop `#f5e211` as decorative illustration accents, not semantic states. CTA buttons can use light/white pill treatments with one small colored circle icon as the action affordance.

Use flat paper-cut character illustrations directly on the cream canvas. Avoid photography, gradients, shadows, product screenshots, and heavy UI chrome. The page should feel editorial, breathable, human, and printed.
