# Colors

## Brand And Accent

| Name | Value | Use |
|---|---:|---|
| Fresh Grass | `#8ed462` | Navigation strokes, card borders, toggle fills, decorative highlights |
| Sky Pop | `#2ba0ff` | Illustration accent, card border accent, small icon dots |
| Coral Pop | `#ff705d` | Tags, focused UI edges, service-level action buttons, illustration accent |
| Sunshine Pop | `#f5e211` | Footer highlight and warm illustration accent |

## Neutrals

| Name | Value | Use |
|---|---:|---|
| Pure Ink | `#000000` | Icon fills and maximum-contrast details |
| Ink Black | `#2c2e2a` | Primary text, icons, nav borders, dominant hairlines |
| Stone Gray | `#80827f` | Muted body text and secondary link borders |
| Hairline Mist | `#d5d5d4` | Subtle nav dividers and low-contrast borders |
| Sandstone | `#e0dbce` | Recessed or secondary surface tone |
| Cream Paper | `#f5f1e4` | Dominant page background and soft card surface |
| Pure White | `#ffffff` | Elevated cards, floating nav, inset content blocks |

## Rules

- Use Cream Paper as the page background.
- Reserve Pure White for elevation.
- Use Ink Black instead of pure black for main text on cream.
- Use Fresh Grass as the only brand-structural accent in UI chrome.
- Treat Sky Pop, Coral Pop, and Sunshine Pop as decorative accents, not semantic states.
- Do not use more than one chromatic accent inside a single UI component.
