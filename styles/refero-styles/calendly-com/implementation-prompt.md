# AI Implementation Prompt

Build a Calendly.com-inspired light scheduling SaaS interface.

Use Cloud `#f8f9fb` as the page canvas, Paper `#ffffff` for cards, Ink Navy `#0b3558` for all main text and icons, Slate Gray `#476788` for secondary copy, Hairline `#d4e0ed` for borders, Pebble `#f0f3f8` for inputs and badges, and Signal Blue `#006bff` for primary action fills and selected states.

Use a Gilroy-like geometric humanist sans for all text. Display headings should be bold and confident: 50px, 68px, or 80px at weight 700. Buttons use 18px weight 600. Body uses 16px weight 400. Keep letter spacing normal.

Core layout:

- 64px sticky top nav with logo left, centered menu, and right CTA cluster.
- Two-column hero with large navy headline and sign-in buttons on the left.
- Right-side booking widget card on a white surface with blue-tinted shadow.
- Coral Magenta or Sky Cyan decorative blob behind every product visual, offset 20px to 40px.
- Trust logo strip beneath hero.
- Centered section headers followed by two-column product feature blocks.
- Footer on Cloud background with compact link columns.

Core components:

- Signal Blue primary CTA, 8px radius, white 18px/600 text.
- Ink Navy secondary CTA, 8px radius, white text.
- Google and Microsoft social sign-in buttons with provider icons.
- Elevated product card with 16px radius and blue-tinted shadow stack.
- Booking widget with organizer info, date grid, and selected time slots.
- Feature accordion with active Signal Blue icon and inactive Mist Gray labels.
- Pebble pill badge with Deep Cobalt text.

Do not use pure black for body text, neutral black shadows, pill-shaped buttons, decorative blob colors as UI fills, background gradients, photography, or crowded grids.
