## Use This Style When

Use Calendly.com when an interface should feel like a calm, confident scheduling workspace: cool near-white canvas, navy text, white product cards, vivid blue primary actions, and friendly product mockups softened by decorative magenta and cyan blobs. It fits scheduling, booking, calendar, CRM, onboarding, integrations, and polished light-mode SaaS pages.

## Quick DNA

- Ink Navy is the main text color, not pure black.
- Signal Blue is the only primary CTA fill.
- Cards sit on Cloud canvas with 16px to 24px radii.
- Product visuals are white booking widgets or UI screenshots.
- Decorative magenta and cyan blobs sit behind product cards.
- Elevation uses blue-tinted shadows, never neutral black shadows.
- Buttons use an intentional 8px radius, not pills.
- Gilroy-style typography carries everything from body to 80px headlines.
