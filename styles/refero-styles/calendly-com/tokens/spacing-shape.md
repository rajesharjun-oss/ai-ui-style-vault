# Spacing And Shape

## Spacing

| Purpose | Value |
| --- | --- |
| Density | comfortable |
| Base unit | 8px |
| Max width | 1200px |
| Section gap | 48px to 64px |
| Card padding | 24px |
| Element gap | 8px to 16px |

## Scale

`8px`, `16px`, `24px`, `32px`, `40px`, `48px`, `56px`, `64px`, `72px`, `96px`

## Radius

| Element | Value |
| --- | --- |
| Small details | 4px |
| Inputs | 8px |
| Buttons | 8px |
| Product cards | 16px |
| Feature panels | 24px |
| Badges | 9999px |

## Shape Rules

- Buttons should be 8px radius, not pills.
- Product cards should be 16px radius.
- Feature panels should be 24px radius.
- Badges can be pills.
