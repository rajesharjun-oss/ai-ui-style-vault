# Colors

## Brand

| Name | Value | Role |
| --- | --- | --- |
| Ink Navy | `#0b3558` | Primary text, headings, icons, dark CTA fills, and nav links. |
| Signal Blue | `#006bff` | Primary CTA fill, active nav, selected states, and link accents. |
| Deep Cobalt | `#004eba` | Badge text and informational labels. |

## Accent

| Name | Value | Role |
| --- | --- | --- |
| Coral Magenta | `#e55cff` | Decorative blob behind product cards. |
| Sky Cyan | `#0099ff` | Decorative blob behind product cards and accent washes. |

## Neutrals

| Name | Value | Role |
| --- | --- | --- |
| Carbon | `#0a0a0a` | Logo glyphs and pure-black fallback only. |
| Slate Gray | `#476788` | Secondary copy, helper text, and muted labels. |
| Mist Gray | `#a6bbd1` | Disabled text, inactive feature labels, and light icon strokes. |
| Hairline | `#d4e0ed` | Card borders, input borders, dividers, and underlines. |
| Pebble | `#f0f3f8` | Badge backgrounds, input fills, subtle dividers, and hover washes. |
| Cloud | `#f8f9fb` | Page canvas, footer, and secondary surface. |
| Paper | `#ffffff` | Cards, elevated panels, and text on dark fills. |

## Rules

- Use Ink Navy instead of pure black for regular text.
- Use Signal Blue only for primary actions and selected states.
- Use Coral Magenta and Sky Cyan only as decorative blobs.
- Use Deep Cobalt for informational badges, not CTAs.
