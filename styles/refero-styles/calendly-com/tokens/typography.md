# Typography

## Primary Font

Name: `Gilroy`

Fallbacks: Manrope, Inter, system-ui, sans-serif

Role: all interface text.

Rules:

- Use weight 700 for hero and section headlines.
- Use weight 600 for buttons and subheads.
- Use weight 500 for card titles, labels, and emphasized inline text.
- Use weight 400 for body copy.
- Keep letter spacing normal.
