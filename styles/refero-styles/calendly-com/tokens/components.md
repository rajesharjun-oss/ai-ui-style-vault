# Components

## Primary CTA Button

Signal Blue fill, white 18px/600 text, 8px radius, no border, and compact or comfortable horizontal padding.

## Dark CTA Button

Ink Navy fill, white 18px/600 text, 8px radius. Use as secondary filled action or Microsoft sign-in variant.

## Ghost Text Link

Ink Navy text, no background, no border, no padding. Use 14px to 18px and weight 500 or 600.

## Outlined White Button

Transparent fill, white 1px border, white text, and 4px radius. Use on dark or image backgrounds only.

## Social Sign-In Button

Full-width provider button with logo left and text right. Google uses Paper fill, Ink Navy text, and Hairline border. Microsoft uses Ink Navy fill and white text.

## Elevated Product Card

Paper surface, 16px radius, blue-tinted shadow stack, and usually no padding when screenshot fills the card.

## Feature Accordion Item

Active state uses Ink Navy heading and Signal Blue icon. Inactive state uses Mist Gray text. Add Hairline divider below.

## Pill Badge

Pebble-tinted background, Deep Cobalt 12px/500 text, full radius, and 4px by 8px padding.

## Trust Logo Strip

Single muted logo row in Mist Gray, centered, no card or border.

## Booking Widget Card

White scheduling UI preview with organizer info, date grid, time slots, and Signal Blue selected states.

## Section Header Block

Centered 50px to 68px bold heading in Ink Navy, Slate Gray support copy, and optional CTA.

## Footer

Cloud background with link columns, Slate Gray uppercase headings, and Ink Navy links.
