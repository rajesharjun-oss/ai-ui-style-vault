# Layout And Imagery

## Layout

- Announcement bar and nav are full-width.
- Main content is constrained to a 1200px max-width container.
- Hero is a centered stack.
- Use primary plus ghost CTA pairing.
- Add social proof below the hero CTA row.
- Use a full-width client logo strip.
- Alternate centered section headings with two-column feature blocks.
- Use 64px section gaps and 48px feature column gaps.
- No sidebar and no dark-mode feature bands.

## Imagery

Use product screenshots:

- Spatial video room views.
- Chat panels.
- Avatar bubbles.
- Polls.
- Collaboration controls.
- Product UI cards.

Logo strips can use native brand colors. Avoid lifestyle photography, abstract illustrations, decorative 3D, or unrelated stock imagery.
