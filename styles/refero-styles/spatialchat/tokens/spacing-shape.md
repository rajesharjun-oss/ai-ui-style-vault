## Shadows

| Name | Value | Token |
| --- | --- | --- |
| Subtle | `rgba(0, 0, 0, 0.06) 0 1px 2px 0` | `--shadow-subtle` |
| Medium | `rgba(0, 0, 0, 0.06) 0 4px 16px 0` | `--shadow-md` |
| Large | `rgba(0, 0, 0, 0.06) 0 4px 28px 0` | `--shadow-xl` |

Never use shadows darker than 6 percent black or with a colored tint.
