## Use This When

Use this style for modern SaaS marketing pages, virtual collaboration tools, video workspace products, event platforms, remote work products, product-led landing pages, and any interface that needs to feel confident, friendly, and clean without becoming playful.

## Core Idea

SpatialChat is an airy white-and-violet SaaS system. Most of the interface is grayscale on a Cloud off-white canvas, with Paper white cards and a single Brand Violet accent. The design rhythm is wide and calm: centered hero stacks, paired CTAs, product screenshot cards, social proof rows, and alternating two-column feature sections.
