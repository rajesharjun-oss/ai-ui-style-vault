# AI Implementation Prompt

Build a polished UI in the Altitude style.

Use a dark editorial finance visual system: a `#181818` carbon canvas, gray surface layers from `#111111` to `#323232`, bone-white text, thin borders, compact data UI, and one saturated accent, `#2b7fff`.

Typography:

- Use Libre Baskerville only for hero and section headlines.
- Use Inter for body text, nav, forms, buttons, tables, cards, labels, and captions.
- Use Fira Code only for terminal, command, code, and data-identifier contexts.
- Serif headlines should be weight 400 or 500, never bold.

Layout:

- Center content in a 1200px max-width container.
- Use a simple 64px top nav.
- Create a centered hero with a large serif headline, muted Inter subhead, restrained action, and thin mountain-ridge line art.
- Alternate dark product sections with one light workflow-card/grid section.
- Use 80px section spacing, 8px internal gaps, and 12px default card padding.

Components:

- Buttons: 4px radius, neutral dark surface or transparent fill, thin border, Inter 14px.
- Cards: 8px radius, `#1f1f1f` or `#262626`, 1px border, no heavy shadow.
- Large images: 16px radius, muted mountain landscape or terminal screenshot composition.
- Tables: compact Inter 13px rows, thin `#262626` dividers, small uppercase headers in Fog.
- Code/terminal: Fira Code, Graphite Card background, Slate border, small tracked labels.

Strict rules:

- Do not add extra accent colors.
- Do not use gradients, glassmorphism, glow effects, bokeh, or decorative 3D shapes.
- Do not use saturated semantic colors for status. Use text weight, borders, and tracking first.
- Do not make the interface playful. It should feel like a private financial research terminal.
