# Altitude

Source: Refero Styles  
URL: https://styles.refero.design/style/0e971626-ca51-45ba-acf6-35a53c561b2c  
Captured: 2026-07-28

Altitude is a dark editorial finance interface: near-black gray layers, bone-white serif display type, quiet Inter UI text, terminal-like Fira Code details, and a single blue accent used as functional punctuation. It is strongest for AI finance, research terminals, portfolio dashboards, intelligence products, and data-heavy tools that need to feel serious without becoming visually noisy.

Use this folder as an AI implementation brief. The most important files are:

- `DESIGN.md` for the full style interpretation.
- `implementation-prompt.md` for a copy-ready prompt to hand to an AI builder.
- `style.json` for structured metadata.
- `code/css-variables.css` for CSS custom properties and component recipes.
- `code/tailwind-v4.css` for Tailwind v4 theme tokens.
- `code/design-tokens.json` for machine-readable tokens.

Core cues:

- Background: `#181818` Carbon Canvas, with `#111111` Obsidian as the deepest layer.
- Primary text: `#eeeeee` Bone.
- Accent: `#2b7fff` Voltage Blue, used sparingly for links, focus, selected states, and data-terminal accents.
- Display font: Libre Baskerville, weight 400 or 500 only.
- UI/body font: Inter.
- Code/data font: Fira Code with wide tracking.
- Shape: 4px controls, 8px cards, 16px large image containers.
- Rhythm: compact element gaps, 12px cards, 80px section gaps.

Do not turn this into a colorful dashboard. The style depends on monochrome discipline, thin borders, restrained radii, and occasional mountain/editorial imagery.
