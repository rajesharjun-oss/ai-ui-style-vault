# Colors

| Name | Value | Token | Role |
|---|---:|---|---|
| Carbon Canvas | `#181818` | `--color-carbon-canvas` | Primary page background and main dark field. |
| Obsidian | `#111111` | `--color-obsidian` | Deepest layer for footers and contrast wells. |
| Graphite Card | `#1f1f1f` | `--color-graphite-card` | Cards, inputs, terminal panes, and contained surfaces. |
| Slate Elevated | `#262626` | `--color-slate-elevated` | Hover states, table rows, raised panels, and dividers. |
| Iron Peak | `#323232` | `--color-iron-peak` | Highest dark surface for dropdowns, popovers, and active rows. |
| Bone | `#eeeeee` | `--color-bone` | Primary text and bright structural lines. |
| Ash | `#e4e4e4` | `--color-ash` | Secondary borders and light card outlines. |
| Fog | `#a4a19b` | `--color-fog` | Muted helper text, icons, captions, and disabled labels. |
| Smoke | `#5e5d59` | `--color-smoke` | Low-emphasis copy and very subtle separators. |
| Pewter | `#4b4b4b` | `--color-pewter` | Deep borders and table separators. |
| Pure White | `#ffffff` | `--color-pure-white` | Max-emphasis details and light contrast panels. |
| Voltage Blue | `#2b7fff` | `--color-voltage-blue` | Only saturated accent for links, focus rings, active states, and terminal highlights. |
| Mid Navy | `#1a365d` | `--color-mid-navy` | Restrained blue depth for icons and thin graphic details. |

## Rules

- Keep the interface almost fully achromatic.
- Use blue only when the state or link needs emphasis.
- Do not add red, green, yellow, purple, or orange semantic systems unless the product absolutely requires them.
- Prefer border, weight, and tracking to communicate status before reaching for color.
