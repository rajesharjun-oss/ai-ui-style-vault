# Typography

## Display

- Family: Libre Baskerville
- Token: `--font-libre-baskerville`
- Fallback: Source Serif Pro, Lora, Crimson Text, serif
- Use: hero, page title, section opener
- Weights: 400, 500
- Tracking: `-0.025em`

Do not use this serif for body text, badges, nav, buttons, form controls, tables, or captions.

## UI And Body

- Family: Inter
- Token: `--font-inter`
- Fallback: system-ui, -apple-system, Segoe UI, sans-serif
- Use: all functional interface text
- Weights: 400, 500, 600, 700

Use positive tracking for tiny uppercase data labels and badges.

## Code And Terminal

- Family: Fira Code
- Token: `--font-fira-code`
- Fallback: JetBrains Mono, IBM Plex Mono, monospace
- Use: code, terminal, query, command, and data identifier contexts
- Weights: 400, 600
- Tracking: `0.1em`
