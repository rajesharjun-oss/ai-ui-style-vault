# Components

## Neutral Button

Transparent or Graphite Card background, 1px Slate or Pewter border, 4px radius, Inter 14px/600, Bone label. Avoid loud filled buttons unless the product already demands it.

## Inline Link

Inter 14px/500 in Voltage Blue. Use it as the main chromatic action treatment.

## Serif Section Header

Libre Baskerville 36-72px, weight 400, Bone on dark or Carbon Canvas on light. Pair with Fog Inter supporting text.

## Dark Card

Graphite Card fill, Slate Elevated border, 8px radius, 12px padding. Use for compact analytics, dashboard modules, and terminal-adjacent UI.

## Light Workflow Tile

Pure White or light stone panel, Ash border, 8px radius, 12-24px padding, Mid Navy outline icon, dark Inter label.

## Terminal Window

Graphite Card background, Slate border, 8px radius, compact chrome, Fira Code content, and small tracked labels.

## Data Table

Inter 13px rows with Bone text, Fog metadata, Slate row dividers, and optional alternating Slate Elevated rows. Header labels should be 10-11px uppercase with positive tracking.

## Badge

4px radius, small Inter text, positive tracking, neutral fill. Voltage Blue appears only for active or selected state.

## Image Container

16px radius, large muted alpine photography, no blur overlays, no stock lifestyle framing. Pair images with terminal screenshots or thin mountain ridge artwork.
