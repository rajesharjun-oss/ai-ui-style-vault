# Colors

| Token | Value | Use |
| --- | --- | --- |
| `--hungry-tiger-tiger-gold` | `#faae33` | Primary action, filled buttons, active nav, display type, icon strokes |
| `--hungry-tiger-ember-rust` | `#823513` | Dominant canvas, hero, primary full-page surface |
| `--hungry-tiger-saffron-glow` | `#9f531b` | Secondary warm accent, decorative border, mid-tone text |
| `--hungry-tiger-chili-red` | `#d1255c` | Rare heat-level badge or alert highlight |
| `--hungry-tiger-charred-clove` | `#281006` | Deepest surface and text on gold CTA |
| `--hungry-tiger-dark-spice` | `#402011` | Cards, inputs, ghost fills, body/support text |
| `--hungry-tiger-cardamom-brown` | `#6b2e12` | Input borders, subtle dividers, muted inline elements |

## Usage Rules

- Keep the system warm-brown and gold.
- Use `#faae33` as the only large accent.
- Use `#d1255c` only for rare heat badges.
- Do not dilute the palette with white, blue, green, or cool neutrals.
- Build depth with brown value shifts, not shadows.
