# Typography

## Display Family

```css
font-family: Salmond, "Druk Wide", Antonio, "Bebas Neue", Inter, sans-serif;
```

Use Salmond across almost the entire system. It should dominate hero headlines, section titles, nav, badges, labels, and buttons.

## Body Microcopy Family

```css
font-family: Graphikx, Inter, Geist, "Untitled Sans", sans-serif;
```

Use Graphikx only at 13px weight 500 for quiet functional microcopy where Salmond is too loud.

## Scale

| Token | Size | Weight | Line Height | Letter Spacing |
| --- | ---: | ---: | ---: | ---: |
| `caption` | 11px | 500 | 1.2 | 0.02em |
| `micro` | 13px | 500 | 1.0 to 1.3 | -0.02em to 0.01em |
| `subheading` | 18px | 500 | 1.2 | 0.01em |
| `heading-sm` | 29px | 500 or 700 | 1.1 | -0.005em |
| `heading` | 65px | 700 | 0.95 | -0.01em |
| `heading-lg` | 101px | 700 | 0.9 | -0.016em |
| `display` | 195px | 700 | 0.8 | -0.02em |
| `display-xl` | 213px | 700 | 0.8 | -0.02em |

## Rules

- Hero and section display type should sit at 130px to 213px whenever possible.
- Large display line-height should be 0.80 to 0.90.
- Tighten tracking as type gets larger.
- Small labels should use slight positive tracking.
- Do not introduce a second display typeface.
- Keep body copy at 18px or below.
