# Spacing And Shape

## Spacing

| Token | Value | Use |
| --- | ---: | --- |
| `4` | 4px | Tight badge padding |
| `6` | 6px | Fine spacing and card radius |
| `8` | 8px | Ghost button vertical padding |
| `9` | 9px | Fine offset |
| `10` | 10px | Standard element gap |
| `12` | 12px | Card padding low end, pill input padding |
| `14` | 14px | Fine UI rhythm |
| `16` | 16px | Card padding high end |
| `17` | 17px | Ghost button horizontal padding |
| `20` | 20px | Filled CTA horizontal padding |
| `24` | 24px | Medium layout spacing |
| `26` | 26px | Fine layout offset |
| `28` | 28px | Medium layout offset |
| `32` | 32px | Larger local spacing |
| `42` | 42px | Product/type composition spacing |
| `80` | 80px | Section gap low end |
| `120` | 120px | Section gap high end |
| `192` | 192px | Poster-scale vertical offset |
| `max-width` | 1440px | Wide page maximum |

## Radius

| Token | Value | Use |
| --- | ---: | --- |
| `card` | 6px | Product, recipe, or content cards only |
| `badge` | 9999px | Tags and category labels |
| `input` | 9999px | Email/search/form fields |
| `button` | 9999px | Filled and outline controls |
| `icon` | 9999px | Circular icon containers |

## Shape Rules

- Controls must be full pills.
- Do not use 6px on buttons, badges, inputs, or icon containers.
- Cards may use 6px radius, but no shadows.
- Product photography should not live in rounded frames.
