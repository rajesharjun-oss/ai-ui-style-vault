## Use This Style For

- AI developer platforms, API pages, model launch pages, technical product marketing, and research-oriented landing pages.
- Interfaces that need to feel restrained, precise, and engineering-led.
- Pages where product screenshots, code panels, terminal mocks, and technical tabs should replace photography.
- Conversion pages that need one black pill CTA and otherwise quiet supporting actions.

## Design Memory

xAI is a warm-white technical editorial system. The page is mostly Paper and Cream, with Jet Ink as the single primary action color. Oversized universalSansDisplay headlines create authority through scale rather than weight. GeistMono adds the developer tone through code snippets, tabs, and terminal mockups. Color is rationed to beta badges, terminal dots, and rare ambient gradient warmth.

## Files

- `DESIGN.md` - full style reference for designers and AI builders.

- `tokens/` - readable token notes by category.

- `code/tailwind-v4.css` - Tailwind v4 theme tokens.
- `code/design-tokens.json` - machine-readable token export.
- `screenshots/README.md` - guidance for adding local visual captures.
