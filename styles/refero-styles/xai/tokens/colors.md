# Colors

| Name | Hex | Use |
| --- | --- | --- |
| Jet Ink | `#0a0a0a` | Primary text, filled CTA buttons, logo mark, main hierarchy anchor |
| Charcoal | `#151515` | Dark code-block surface behind terminal demos |
| Slate | `#3b3b3b` | Muted heading variant and secondary section labels |
| Steel | `#545454` | Mid-weight body text, inline stats, spec lines |
| Fog | `#858585` | Secondary text, icon strokes, inactive nav items, link copy |
| Pewter | `#9d9d9d` | Tertiary text, metadata, decorative fills |
| Dove | `#d5d9e2` | Hairline borders, input rings, button focus outlines |
| Sand | `#f2ede5` | Warm wash backgrounds, subtle highlight zones, beta pill surface |
| Cream | `#f9f8f6` | Card surfaces, secondary panels, tag backgrounds |
| Paper | `#ffffff` | Page background, button text on filled CTAs, icon foreground on dark surfaces |
| Ember | `#ff5f57` | Terminal traffic-light red dot only |
| Sunbeam | `#ffbd2e` | Terminal yellow dot and rare novelty signal |
| Sprout | `#28c840` | Terminal traffic-light green dot only |

## Palette Rules

- Use Jet Ink for the primary filled CTA and main text.
- Use Paper for the canvas and Cream for elevated panels.
- Use Sand for beta or warm wash moments only.
- Use terminal dot colors only inside code-block mockups.
- Do not use chromatic colors for buttons or links.
