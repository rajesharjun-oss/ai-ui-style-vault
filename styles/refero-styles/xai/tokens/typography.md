# Typography

## Families

- UI and body: universalSans.
- UI fallback: Inter, system-ui, sans-serif.
- Display: universalSansDisplay.
- Display fallback: Sohne, GT America, Inter Display, sans-serif.
- Mono: GeistMono.
- Mono fallback: Geist Mono, JetBrains Mono, monospace.

## Weights

- universalSans: 400 and 500.
- universalSansDisplay: 400 and 500.
- GeistMono: 400 and 700.

## Usage

- Use universalSans for nav, body, buttons, cards, labels, and inline links.
- Use universalSansDisplay for H1/H2 only.
- Use GeistMono for terminal blocks, code snippets, metadata, and language tabs.
- Keep display headlines close to 1.0 line-height.
- Do not use body text below 14px or above 18px.
- Use size and spacing before weight for hierarchy.
