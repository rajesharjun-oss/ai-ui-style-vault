# Spacing And Shape

## Spacing

| Purpose | Value |
| --- | --- |
| Density | Comfortable |
| Base unit | 4px |
| Max width | 1200px |
| Section gap | 80px |
| Card padding | 40px |
| Element gap | 12px |

Scale: 4px, 8px, 12px, 16px, 20px, 24px, 32px, 40px, 48px, 64px, 96px, 144px.

## Shape

| Element | Radius |
| --- | --- |
| Inputs | 6px |
| Small cards | 8px |
| Cards | 16px |
| Terminal mockups | 12px |
| Buttons | 9999px |
| Tags | 9999px |
| Language tabs | 9999px |

## Elevation

- Subtle ring: `rgba(10, 10, 10, 0.15) 0px 0px 0px 1px`.
- Sticky header: `rgba(0, 0, 0, 0.1) 0px 20px 25px -5px, rgba(0, 0, 0, 0.1) 0px 8px 10px -6px`.
- Elevated cream card: `rgba(0, 0, 0, 0.06) 0px 0px 0px 1px, rgba(15, 23, 42, 0.18) 0px 18px 40px -24px`.

## Rhythm

- Use 80px section gaps.
- Use 40px padding in pricing or large comparison cards.
- Use 12px element gaps in compact UI groups.
- Keep cards quiet and cream rather than heavily elevated.
