# Layout And Imagery

## Layout

- Use a 1200px max-width container on a full-bleed Paper canvas.
- Keep 80px vertical rhythm between sections.
- Use a centered text-first hero.
- Place two CTA pills below the hero copy.
- Follow with a 2-column product-card row.
- Use text-left and code-panel-right feature splits.
- Use a 4-column news index with no card surfaces.
- Use 2-column pricing or API access tier cards.
- Keep navigation as one sticky top bar with horizontal links and right-aligned actions.

## Section Patterns

- Hero: display headline, short body copy, primary black pill, ghost secondary.
- Product cards: Cream surfaces with UI mockups, code demos, waveform panels, or image generation previews.
- Developer block: Charcoal terminal mockup with GeistMono content and language tabs.
- Feature split: copy on left, product screenshot or code panel on right.
- News index: image, date metadata, title, no card wrapper.
- Pricing or access CTA: Cream cards, generous padding, checklist rows.

## Imagery

- Use product screenshots, chat threads, code editors, API snippets, waveform cards, terminal panels, and warm gradient mockups.
- Avoid lifestyle photography, stock images, 3D renders, human figures, and decorative illustration.
- Large radial gradient warmth can sit behind code panels, but it should read as ambient glow rather than a visual asset.
- Icons are stroke-based, around 1.5px, Fog by default and Jet Ink on hover.
