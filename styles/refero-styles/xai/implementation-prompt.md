# Implementation Prompt

Use the xAI style language for this UI.

Create a restrained warm-white AI/developer product interface: huge quiet headlines, cream product cards, black pill CTAs, technical mono snippets, flat surfaces, and almost no color. The page should feel like a frontier AI lab product page, not a generic SaaS site.

Core rules:

- Use `#ffffff` for the page canvas.
- Use `#f9f8f6` for elevated cream cards and secondary panels.
- Use `#f2ede5` only for subtle warm washes and beta pill surfaces.
- Use `#0a0a0a` for text, logo marks, and the single primary filled CTA.
- Use `#858585` for secondary text and inactive nav links.
- Use `#d5d9e2` for hairline borders and focus rings.
- Do not use chromatic CTA colors.
- Use universalSans for body, nav, buttons, cards, labels, and links.
- Use universalSansDisplay only for H1/H2.
- Use GeistMono for code, terminal panels, metadata, and language tabs.
- Set major headlines near 1.0 line-height with tight negative tracking.
- Use 9999px radius for buttons, tags, and language tabs.
- Use 16px radius for major cream cards, 8px for small cards, 12px for terminal blocks, and 6px for inputs.
- Use cream surfaces and a single hairline ring instead of shadow stacks.

Recommended structure:

- Sticky 64px nav with logo, horizontal menu links, compact outlined action, and filled black pill CTA.
- Centered hero with a 72px quiet display headline, short body copy, and two CTA pills.
- 2-column product-card row for chat/code or media/code demos.
- Feature sections with text-left and code-panel-right layouts.
- Cream cards containing terminal mockups, waveform panels, API snippets, and product screenshots.
- Language tab pills beneath code blocks.
- 4-column news index with no card surfaces.
- 2-column pricing or API access CTA with cream tier cards.

Avoid:

- Colorful SaaS gradients for CTA.
- Lifestyle photography or people imagery.
- Heavy shadows.
- Rounded intermediate radii that are not part of the system.
- Body text outside the 14px to 18px range.
- Bold headlines.

The result should feel minimal, technical, warm, precise, and editorial.
