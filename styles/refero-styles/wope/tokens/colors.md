# Colors

## Brand

| Name | Value | Role |
| --- | --- | --- |
| Ultraviolet Core | `#713dff` | Primary violet accent, active links, luminous highlights, and focal glow. |
| Lilac Beam | `#b7a4fb` | Cool flare color for light rays and glow edges. |
| Horizon Glow | `#8562ff` | Brighter violet midpoint for underlit hero effects. |

## Neutrals

| Name | Value | Role |
| --- | --- | --- |
| Night Violet | `#0a0118` | Global canvas, dark cards, footer, and screenshot frames. |
| Void Plum | `#0c0616` | Deep UI detail and occasional dark text on pale treatments. |
| Dim Fog | `#85808c` | Inactive icons, tertiary copy, and subtle separators. |
| Ash Lilac | `#9b96b0` | Body copy, nav links, labels, and supporting UI. |
| Muted Steel | `#d2d0dd` | Brighter secondary copy and section support text. |
| Soft Quartz | `#ffffff` | Headings, high-emphasis copy, icons, borders, and button text. |

## Rules

- Keep the canvas dark violet.
- Use violet accents only for glow, active links, and focal lighting.
- Do not introduce teal, green, orange, or other bright accents.
- Use translucent white borders rather than opaque outlines.
