# Typography

## Primary UI Font

Name: `Inter V`

Fallbacks: Inter, system-ui, sans-serif

Role: navigation, body copy, links, buttons, badges, inputs, captions, and smaller headings.

Rules:

- Use 400 for body.
- Use 500 for controls and links.
- Use 700 for compact emphasis.
- Use negative tracking for most UI text.
- Use wide positive tracking only for utility labels.

## Display Font

Name: `Rebond Grotesque`

Fallbacks: Sora, Inter, system-ui, sans-serif

Role: hero statements and major section titles.

Rules:

- Use only for headline moments.
- Use weight 700.
- Use 56px and 72px for major sections.
- Do not use for buttons, labels, body copy, or dense UI.
