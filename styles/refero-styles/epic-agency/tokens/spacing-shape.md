# Spacing And Shape

## Spacing

| Purpose | Value | Notes |
|---|---:|---|
| Density | compact | Tight controls with theatrical hero space |
| Base unit | 4px | Core spacing rhythm |
| Max width | 1200px | Contained stage for content |
| Control gap | 4px to 12px | Navigation, labels, chips |
| Card padding | 20px to 32px | Dark cards and project panels |
| Section gap | 50px to 120px | Allow cinematic spacing |
| Hero gap | 80px to 120px | Use large gaps around display type and media |

## Shape

| Element | Radius | Notes |
|---|---:|---|
| Menu item | 0px | Useful for technical, compact nav states |
| Panel | 10px to 20px | Dark depth surfaces |
| Button | 20px to 30px | Rounded premium actions |
| Chip | 9999px or softly rounded | Signal tags and metadata |
| Media block | 10px to 20px | Match panel scale |

## Elevation

- Prefer layered dark color, thin borders, and glow over standard shadows.
- Use atmospheric depth around celestial visuals.
- Avoid default drop-shadow-heavy SaaS cards.
