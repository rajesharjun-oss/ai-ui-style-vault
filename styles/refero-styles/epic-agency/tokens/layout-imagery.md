# Layout And Imagery

## Layout Pattern

The core page structure is:

1. Compact dark navigation.
2. Cinematic hero with oversized Sang Bleu display text.
3. Celestial or orbital visual as a first-viewport anchor.
4. Rounded action cluster or signal chips.
5. Dark portfolio, capability, or launch cards.
6. Compact dark footer.

## Grid

- Use a contained max width near 1200px.
- Let the hero breathe with oversized display type.
- Use compact grids for services, capabilities, and project metadata.
- Use dark card stacks or framed rows for portfolio content.
- On mobile, preserve the dark mood but reduce display size aggressively.

## Imagery

Use:

- 3D celestial objects.
- Orbital diagrams.
- Dark star maps.
- Luminous map-like surfaces.
- Premium editorial project imagery framed in dark panels.

Avoid:

- Generic stock people.
- Flat pastel SaaS illustration.
- Bright all-white screenshot sections.
- Default gradient blob backgrounds.
