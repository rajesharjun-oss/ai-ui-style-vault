# EPIC Agency

Deep-space digital agency command center: a theatrical dark UI built from violet-black surfaces, Sang Bleu display type, Inter utility text, compact spacing, and celestial 3D imagery.

Use this style when you want an agency, portfolio, creative studio, launch page, or premium strategy interface to feel cosmic, high-concept, and cinematic while still remaining structured and navigable.

## Files

- `source.md`: Source URL, reference site, capture notes, and scope.
- `DESIGN.md`: Human-readable design breakdown.
- `implementation-prompt.md`: Prompt for an AI builder to implement the style.
- `style.json`: Structured design metadata.
- `tokens/`: Markdown token notes by category.
- `code/`: CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md`: Placeholder for future manual screenshots.

## Quick Use

1. Start with a near-black violet canvas.
2. Use Sang Bleu only for large expressive display moments.
3. Use Inter for navigation, body, buttons, captions, and functional UI.
4. Use lavender and mist for readable text on dark surfaces.
5. Use gold, ember, and green as tiny signal accents, never as broad fills.
6. Add celestial or orbital imagery as a hero anchor.
