# AI Implementation Prompt

Build a polished, responsive interface in the EPIC agency style.

The page should feel like a cinematic dark agency site: violet-black canvas, pale lavender text, dramatic Sang Bleu display typography, compact Inter UI controls, and celestial or orbital 3D imagery as the main visual anchor.

Core rules:

- Use `#110329` as the dominant page canvas and `#1b0642` for dark depth surfaces.
- Use Sang Bleu or a graceful serif only for hero-scale and statement-scale text.
- Use Inter for navigation, buttons, body text, captions, forms, and all operational UI.
- Use `#cfc1ff`, `#dbc9ff`, and `#f4efff` for readable text on dark surfaces.
- Use gold, ember, and green only as tiny signal accents.
- Use compact spacing for controls, but allow large theatrical hero gaps.
- Avoid ordinary white SaaS cards, rainbow gradients, and generic stock imagery.

Recommended layout:

1. A compact dark top nav with small Inter labels.
2. A first viewport with a huge Sang Bleu headline, short Inter support copy, and a rounded CTA cluster.
3. A celestial 3D or orbital visual that anchors the hero.
4. Dark portfolio or service cards with soft radius, thin borders, lavender copy, and tiny gold or violet markers.
5. A signal-heavy section for capabilities, awards, launches, or project status.
6. A restrained dark footer with compact link columns.

Make the interface feel premium, mysterious, art-directed, and technically precise.
