# Typography

## Family

| Role | Font | Fallback | Use |
| --- | --- | --- | --- |
| Primary | Saans | Inter, Manrope, ui-sans-serif, system-ui | All UI, body, nav, headlines, logo text, and utility controls |

## Weights

| Weight | Role |
| --- | --- |
| 300 | Light editorial display |
| 380 | Default UI and body voice |
| 570 | Declarative display and emphasis |
| 790 | Rare black-weight display |

## Scale

| Token | Size | Weight | Line height | Tracking |
| --- | --- | --- | --- | --- |
| Micro UI | 12px | 380 | 1.14 | 0.6px or 0.05em |
| Small UI | 14px | 380 | 1.2 | 0.05em for uppercase |
| Body | 16px | 380 | 1.43 | 0.8px |
| Large UI | 18px | 380 | 1.2 | 0.05em for uppercase |
| Utility Large | 20px | 380 | 1.2 | 0.05em for uppercase |
| Display Small | 47px | 300 or 570 | 1.0 to 1.14 | -0.025em |
| Display Medium | 79px | 300 or 570 | 1.0 to 1.14 | -0.025em |
| Display Large | 106px | 300 or 570 | 1.0 to 1.14 | -0.025em |
| Display Hero | 130px | 300 | 1.08 | -3.25px |
| Display Max | 245px | 300 | 1.0 | -0.025em |

## Rules

- Use one typeface only.
- Treat the jump from 20px to 47px as a register change.
- Do not add 24px, 30px, 36px, or 40px headings.
- Uppercase UI labels need positive tracking to remain legible and editorial.
