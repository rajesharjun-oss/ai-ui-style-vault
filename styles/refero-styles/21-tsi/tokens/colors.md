# Colors

## Core

| Name | Value | Token | Use |
| --- | --- | --- | --- |
| Black Void | `#000000` | `--color-black-void` | Page canvas, black sections, deepest base |
| Paper White | `#ffffff` | `--color-paper-white` | Primary text, nav labels, hairline rules, ghost button borders |
| Smoke | `#4d4d4d` | `--color-smoke` | Muted borders, body card edges, secondary structural lines |

## Photographic Color

| Name | Value | Token | Use |
| --- | --- | --- | --- |
| Crimson Heat | `#b62b1a` | `--color-crimson-heat` | Photo mood reference only; never a UI fill |

## Application Notes

- UI chrome should use only Black Void, Paper White, and occasional Smoke.
- Crimson Heat is a photography direction, not a button or background color.
- Do not introduce gray fills except where a flat body card needs a muted border.
- The primary action is not a color shift; it is a white-outlined ghost pill.
