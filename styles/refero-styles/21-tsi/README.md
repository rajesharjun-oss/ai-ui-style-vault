## Use This Style For

- Luxury fashion pages with full-bleed editorial photography
- Black-canvas brand sites where restraint matters more than density
- Product or campaign pages that need cinematic red-and-black atmosphere
- Minimal navigation systems using ghost controls and tiny uppercase labels

## Files

- `source.md` records the source URL and capture context.
- `DESIGN.md` is the main human-readable design reference.
- `implementation-prompt.md` is a direct prompt for an AI coding agent.
- `style.json` is a structured summary for indexing and retrieval.
- `tokens/` contains focused notes for colors, type, spacing, components, guidelines, layout, and imagery.
- `code/` contains CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` reserves the screenshot slot for manual or automated captures.

## Core Signature

21 TSI is an austere fashion-editorial system. The UI is almost entirely black and white: true-black canvas, white Saans type, a single top hairline, and transparent pill controls. The only chromatic heat comes from crimson editorial photography, not from buttons, backgrounds, gradients, or UI accents.
