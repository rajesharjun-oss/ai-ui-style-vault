# Integrated Biosciences

Integrated Biosciences is a dark scientific editorial system: black lab-bench canvas, one precise lime signal color, strict uppercase labels, hairline rule geometry, and unrounded panels that feel like sequenced research plates.

- Source: https://styles.refero.design/style/80099f79-72b7-4367-b2e9-6a3d4a3e9e6a
- Reference site: https://www.integratedbio.com
- Captured: 2026-07-28
- Theme: dark
- Best for: biotech, life sciences, research AI, clinical data tools, scientific company sites

## Use This When Building

Use a black or near-black page with ultra-thin rule lines and a single lime accent. Keep every component flat and square. Let typography feel precise by using one geometric sans family across display, body, labels, and UI. Data and science imagery should be framed like lab evidence, not like lifestyle marketing.
