# Typography

## Primary Typeface

- Family: Aspekta
- Substitute: Inter, Geist Sans, Helvetica Neue, or Arial
- Weight: 400 for nearly everything
- Style: geometric, technical, clear

## Type Scale

| Token | Size | Line Height | Tracking | Use |
|---|---:|---:|---:|---|
| `micro-label` | 11px | 1.4 | 0.16em | uppercase meta labels |
| `label` | 13px | 1.45 | 0.08em | nav, tags, table labels |
| `body` | 16px | 1.55 | 0 | paragraphs and descriptions |
| `lead` | 20px | 1.4 | 0 | section intros |
| `heading` | 36px | 1.05 | 0 | card and section titles |
| `display-sm` | 56px | 0.98 | -0.01em | hero sub-display |
| `display` | 76px | 0.95 | -0.015em | primary hero headline |

## Rules

- Use one type family across the whole UI.
- Keep most text weight at 400.
- Use uppercase with tracking for scientific labels.
- Keep body text Mist or Soft White, depending on contrast needs.
- Do not use serif typography, playful monospace, or decorative display faces.
