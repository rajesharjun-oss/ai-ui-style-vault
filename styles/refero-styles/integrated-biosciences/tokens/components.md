# Components

## Primary Signal Button

- Fill: `#cef79e`
- Text: `#000000`
- Radius: 0
- Border: 1px solid `#cef79e`
- Font: Aspekta, 13-16px, 400
- Letter spacing: 0.08em if uppercase
- Use for the highest-value CTA only.

## Outline Button

- Fill: transparent
- Text: `#f4f4f4` or `#cef79e`
- Border: 1px solid `#424242` or `#cef79e`
- Radius: 0
- Hover: swap to lime border or lime fill.

## Scientific Nav

- Background: black or transparent
- Thin bottom border
- Uppercase labels
- Wide letter spacing
- Active state can use lime text or a 1px lime underline.

## Research Card

- Background: `#0c0c0c` or `#1a1a1a`
- Border: 1px solid `#363636`
- Radius: 0
- Padding: 24px to 40px
- Include uppercase metadata, title, short summary, and optional evidence image.

## Data Plate

- Background: `#000000`
- Border: 1px solid `#424242`
- Radius: 0
- Use lime for one active line, dot, cell, or marker.
- Keep labels small and uppercase.

## Image Plate

- Square-corner image container.
- Use microscopy, cells, lab hardware, molecule maps, or technical charts.
- Prefer monochrome, green-tinted, or low-saturation scientific imagery.
- Add a thin border or rule-based caption.

## Badge Or Tag

- Radius: 0
- Border: 1px solid `#424242`
- Text: uppercase Aspekta, 11-13px
- Active or selected tags may use lime border and lime text.
