# Colors

## Signal

| Name | Value | Use |
|---|---:|---|
| Bio Signal | `#cef79e` | Primary scientific accent, selected states, active markers, data highlights |

## Neutrals

| Name | Value | Use |
|---|---:|---|
| Void | `#000000` | Main page canvas and deepest panels |
| Lab Black | `#0c0c0c` | Secondary dark section background |
| Graphite | `#1a1a1a` | Flat card and image-plate surfaces |
| Carbon | `#222222` | Subtle raised panels and hover states |
| Slate | `#363636` | Dark borders and form surfaces |
| Rule | `#424242` | Hairline dividers and scientific grid lines |
| Mist | `#9f9f9f` | Muted body text, captions, secondary labels |
| Soft White | `#f4f4f4` | Primary dark-mode text |
| Pure White | `#ffffff` | High-emphasis text and simple icons |

## Rules

- Use Bio Signal as the only chromatic accent.
- Keep charts and diagrams monochrome plus lime.
- Use grays to separate hierarchy, not shadow.
- Do not introduce blue, orange, pink, or purple accents.
- Never use lime for large decorative backgrounds unless the whole screen is intentionally inverted.
