# Spacing And Shape

## Spacing

- Density: sparse and technical
- Base unit: 4px
- Max content width: 1240px
- Section gap: 80px to 120px
- Card padding: 24px to 40px
- Element gap: 12px to 20px

## Scale

`4px`, `8px`, `12px`, `16px`, `20px`, `24px`, `32px`, `40px`, `48px`, `64px`, `80px`, `96px`, `120px`, `160px`

## Shape

| Element | Radius |
|---|---:|
| Buttons | 0px |
| Cards | 0px |
| Image plates | 0px |
| Inputs | 0px |
| Tables | 0px |
| Badges | 0px |

## Borders

- Use 1px borders.
- Preferred border colors: `#363636`, `#424242`, and occasionally `#cef79e`.
- Use rules to define structure instead of shadows.
