# Implementation Prompt

Build a dark scientific interface in the Integrated Biosciences style.

Use a black laboratory canvas with flat surfaces, square corners, hairline borders, and a single lime accent color (`#cef79e`). Keep the palette extremely restrained: black, dark graphite, cool grays, white, and lime only. Use color as signal, not decoration.

Use one geometric sans family across the whole product. Prefer Aspekta; if unavailable, use Inter, Helvetica Neue, or Geist Sans. Keep text mostly weight 400. Use uppercase labels with wide tracking for section markers, data tags, nav links, and scientific metadata. Keep display type clean, technical, and unsentimental.

Create layouts with rule-based grids, large negative space, square image plates, research-card rows, dark chart panels, and evidence-like microscopy or data imagery. Use 1px borders in dark gray or lime. Buttons should be rectangular with 0 radius. Primary actions can be lime text on black, black text on lime, or a lime-outlined control depending on emphasis.

Avoid gradients, glows, rounded SaaS cards, playful icons, multiple accent colors, drop shadows, and warm editorial decoration. The result should feel like a precision biotech lab report turned into a product interface.
