# Layout And Imagery

## Layout Model

- White printed page.
- Top navigation with links left and checkbox filters right.
- Large wordmark row below nav.
- Strict 3-column grid for editorial cards.
- 30px gaps, about 35px side gutters.
- Bordered feature cards break the image grid without changing the palette.
- No sticky/sidebar pattern is needed.

## Imagery

- Use editorial photography and reportage images.
- Use native aspect ratios.
- Use square corners.
- Keep images full-column.
- Avoid image frames unless building a bordered feature card.

## Avoid

- Decorative illustrations.
- Rounded thumbnails.
- Gradient overlays.
- Drop shadows.
- UI mockup styling.
- Color-coded tags.
