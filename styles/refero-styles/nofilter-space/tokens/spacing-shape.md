# Spacing And Shape

## Spacing

| Purpose | Value | Notes |
|---|---:|---|
| Side padding | 35px | Grid gutter and page breathing room |
| Grid row gap | 30px | Editorial card rows |
| Grid column gap | 30px | 3-column layout |
| Wordmark bottom margin | 40px | Separates header from grid |
| Section group margin | 40-60px | Between content groups |
| Featured card padding | 35px | Square bordered cards |
| Filter group gap | 20px | Between nav/filter items |

## Shape

| Element | Value | Notes |
|---|---:|---|
| Cards | 0px | Square editorial surface |
| Images | 0px | Native rectangular crop |
| Featured cards | 0px | Printed box feel |
| Checkbox | 12px | 1px square |
| Border width | 1px | Ink hairline |

## Depth

- No box shadows.
- No z-axis.
- No raised cards.
- Use borders and whitespace only.
