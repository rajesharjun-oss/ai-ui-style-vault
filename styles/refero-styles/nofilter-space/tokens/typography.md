# Typography

## Family

| Role | Preferred Font | Fallbacks | Notes |
|---|---|---|---|
| Whole system | pragmatica | Helvetica Neue, Arial, Inter, sans-serif | Plain editorial sans for nav, wordmark, headlines, meta, and filters |

## Scale

| Token | Size | Line Height | Weight | Usage |
|---|---:|---:|---:|---|
| `--text-nav` | 12px | 1.2 | 400 | FEED, ABOUT, filters |
| `--text-meta` | 12px | 1.2 | 400 | Author and date |
| `--text-body` | 14px | 1.4 | 400 | Short descriptions |
| `--text-headline` | 24px | 1.14 | 400 | Editorial card headlines |
| `--text-featured` | 30px | 1.14 | 400 | Bordered feature cards |
| `--text-wordmark` | 35px | 1.14 | 400 | NOFILTER. SPACE |

## Rules

- Use one typeface.
- Use weight 400 throughout.
- Do not add bold emphasis unless absolutely necessary.
- Keep tracking at 0.
- Use size and placement instead of font variety.
