# Nofilter.space

AI-ready Refero style bundle for Nofilter.space.

- Source: https://styles.refero.design/style/4235ebdc-a070-46ef-abbf-692151449bea
- Reference site: https://www.nofilter.space
- Captured: 2026-07-28
- Theme: light
- Mood: austere editorial grid on white paper
- Industry: media, editorial, publishing, reportage, culture

## Use This Style For

- Editorial, magazine, archive, culture, and reportage websites
- Interfaces that should feel like a printed broadsheet or image index rather than a SaaS product
- Layouts where typography, whitespace, and exact grid alignment carry all visual hierarchy
- AI-generated sites that need a strict monochrome reference with zero decorative styling

## Files

- `source.md` records the source URL and capture context.
- `DESIGN.md` is the main human-readable design reference.
- `implementation-prompt.md` is a direct prompt for an AI coding agent.
- `style.json` is a structured summary for indexing and retrieval.
- `tokens/` contains focused notes for colors, type, spacing, components, guidelines, layout, and imagery.
- `code/` contains CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` reserves the screenshot slot for manual or automated captures.

## Core Signature

Nofilter.space is a printed-surface editorial system: Paper White background, Ink `#333333` text and hairlines, Carbon `#000000` only for emphasis, Pragmatica typography, 0px image radius, square bordered cards, 35px gutters, 3-column grids, and absolutely no shadows, gradients, rounded cards, or accent colors.
