# Implementation Prompt

Build a polished, responsive editorial/media interface in the Nofilter.space Refero style.

Use a strict printed-surface system: Paper `#ffffff` background, Ink `#333333` for all text, borders, hairlines, and checkbox strokes, and Carbon `#000000` only for rare emphasis. Do not introduce any brand accent color.

Typography must use `Pragmatica` or a close fallback such as Helvetica Neue, Arial, or Inter. Use one type family only. Keep weights at 400. Use 12px for nav/filter/meta, 24px for editorial card headlines, 30px for featured-card headlines, and 35px for the wordmark.

Layout rules:

- Use a white full-page canvas.
- Use a 3-column editorial grid on desktop.
- Use 30px row and column gaps.
- Use about 35px side padding/gutters.
- Use 40-60px spacing between content groups.
- Use 0px radius for images and cards.
- Use 1px Ink borders for featured cards and controls.
- Use no shadows, no gradients, no blur, no surface elevation.

Component rules:

- Top nav has FEED and ABOUT on the left, filter checkboxes on the right.
- Wordmark reads NOFILTER. SPACE in 35px Pragmatica.
- Image cards are image-first with 24px headline and 12px byline/date.
- Featured cards are white, square, bordered, and padded 35px.
- Checkbox filters are simple 12px squares with uppercase labels.

Do not make this look like SaaS. Avoid rounded cards, colored buttons, decorative icons, card shadows, glass effects, hero gradients, thick borders, and soft spacing. Precision is the visual identity.
