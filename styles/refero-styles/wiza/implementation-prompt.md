# Implementation Prompt

Use the Wiza style for this UI.

Create a light SaaS contact-data interface with white surfaces, soft lavender gradient sections, deep violet headlines, compact Inter data UI, and floating product screenshot cards. Use Deep Iris (`#26114a`) for headline weight and filled primary actions. Use Royal Amethyst (`#3e0079`) only for links, focus, accent strokes, and small icon highlights. Use Mist Violet (`#edecff`) for soft tags and tinted sections.

Typography:

- Use Britti Sans 500 for headings from 24px to 64px.
- Keep Britti Sans line-height exactly 1.
- Use Inter for nav, body, buttons, inputs, badges, tables, captions, and dense product UI.
- Keep Inter compact: 12px captions, 14px table rows, 16px body and buttons.

Layout:

- Use a centered 1200px max-width container.
- Use 64px to 80px section gaps.
- Hero should be full-bleed white-to-lavender gradient with centered headline, subtext, dual CTA buttons, and floating product screenshot frame.
- Alternate white sections and light lavender tinted sections.
- Use centered heading blocks with optional pill tags, then two-column or three-column card grids.

Components:

- Filled button: Deep Iris fill, white text, Inter 500 16px, 8px radius, 16px 24px padding.
- Ghost button: transparent, 1px Deep Iris border, Deep Iris text, same dimensions as filled button.
- Pill nav/tag: 1440px radius, Inter 500, Mist Violet active or tag background.
- Data table: white/Paper alternating rows, 1px Mist borders, Inter 12px headers, Inter 14px cells.
- Product screenshot: white 8px card, soft blue-tinted layered shadow, floats over lavender gradient.
- Profile card: white 8px card, 32px avatar, 14px name, 12px metadata.
- Input: 8px radius, 1px Mist border, Royal Amethyst focus ring.

Avoid lifestyle photography, extra accent colors, heavy shadows, rounded photo illustrations, loose Britti Sans headings, body text directly on gradients, and generic blue SaaS styling.
