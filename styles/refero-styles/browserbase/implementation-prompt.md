# Implementation Prompt

Build a polished Browserbase-style interface: a light, editorial developer-tool page with giant geometric headlines, mono metadata, flat pastel panels, black pill CTAs, and one signal orange accent.

Use a mostly monochrome palette: black text on white canvas, Graphite muted copy, and pastel surfaces for grouping. Use Signal Orange (`#ff4500`) only for inline headline highlight boxes, focused edges when needed, and the full footer band. Do not use orange as the primary button fill. Primary buttons must be black pills with white text.

Typography should use a GT Planar-style display face for headings, a plain sans for body/UI, and a mono face for metadata. Headings should be tight and editorial, with negative tracking. Body copy should be 16px, regular, and practical. Mono labels should be 14px uppercase with positive letter spacing.

Layout should start with a white nav and black pill CTA, move into a full-bleed hero on a blue-gray mist background, then continue through centered editorial section headers, logo strips, feature cards, code/terminal blocks, browser mockups, and a full-width orange footer. Keep major sections spaced 64px to 96px apart.

Components should be flat. Use 4px radius for cards, 50px radius for action buttons, 1px borders, and no shadows. Feature cards can use Lavender Mist, code blocks can use Blue Gray Mist or Sky Tint, and logo cards can use Faint Slate.

Before finishing, check that:

- Primary CTAs are black, not orange.
- There is at most one orange highlight per headline.
- Body text is black or Graphite only.
- Cards are flat and shadowless.
- Display type is tracked tight.
- Mono labels are small, uppercase, and tracked out.
- No photography is used.
