- Mood: editorial developer terminal, broadsheet headline system, single orange punctuation, pastel technical cards

## Use This When

Use this style when a developer tool, API platform, automation product, or AI infrastructure site should feel editorial and technical at the same time. It works especially well for data-heavy product marketing, code-adjacent SaaS, documentation-adjacent landing pages, and feature pages that need strong headlines without becoming visually loud.

The key behavior is discipline: orange is a typographic accent and footer moment, not the CTA color. Primary actions are black pills. Depth comes from pastel surface changes and hairline borders, not shadows.
