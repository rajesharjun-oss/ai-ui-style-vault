# Components

## Primary Pill Button

- Background: Ink Black.
- Text: Paper White.
- Font: plain, 16px, weight 500.
- Padding: 8px 21px.
- Radius: 50px.
- Border: none.
- Use for all main actions.

## Ghost Button

- Background: transparent.
- Text: Ink Black.
- Border: 1px solid Ink Black.
- Same padding and radius as the primary pill.
- Optional icon at the right with a 6px gap.

## Orange Highlight Box

- Inline within a headline.
- Background: Signal Orange.
- Text: Ink Black.
- Radius: 0px to 2px.
- Padding: about 2px 6px.
- One highlight per headline.

## Navigation Bar

- Paper White background.
- Soft Lavender Mist bottom border.
- Logo on the left.
- Plain 16px nav links.
- Login/signup text links and black pill CTA on the right.
- Keep spacing compact.

## Feature Card

- Lavender Mist background.
- 4px radius.
- 16px to 24px padding.
- No shadow.
- Use a browser mockup, heading, Graphite body copy, and optional black pill action.

## Logo Card

- Faint Slate background.
- 4px radius.
- Centered grayscale logo.
- Tight row or grid gaps.

## Code Or Terminal Card

- Blue Gray Mist or Sky Tint background.
- 4px radius.
- Mono label at top.
- White input or code fields inside.
- Good for search, automation, or API examples.

## Browser Window Mockup

- White surface.
- 1px Lavender Mist border.
- 3px radius.
- Three small Blue Gray Mist dots in the top bar.
- Simplified monochrome UI inside.

## Mono Eyebrow Label

- gtStandardMono or fallback mono.
- 14px.
- Uppercase.
- 0.06em tracking.
- Ink Black or Graphite.

## Footer Band

- Signal Orange background.
- Ink Black text.
- Full-bleed.
- Plain centered links and metadata.
