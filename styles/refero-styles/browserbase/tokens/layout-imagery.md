# Layout And Imagery

## Layout

Use a full-bleed hero followed by a centered 1200px content rail. Alternate section types so the page feels editorial but still product-driven.

Suggested order:

1. White nav with black pill CTA.
2. Hero on Blue Gray Mist with giant headline, subtitle, and CTA stack.
3. Logo strip using Faint Slate cards.
4. Centered section headers with orange highlight boxes.
5. Two-column product rows with code cards or browser mockups.
6. Four-column feature card grid.
7. Full-width Signal Orange footer.

## Composition

The hero can be expressive, but most content should be orderly and compact. Use whitespace and pastel panels rather than visible grid lines.

## Imagery

Use digital-native imagery:

- pixel art data mountains
- dot textures
- terminal cursors
- code blocks
- browser-window mockups
- simplified product UI
- mono geometric icons

## Avoid

- Photography.
- 3D glossy illustrations.
- Stock SaaS people scenes.
- Colorful gradients.
- Complex decorative backgrounds.
- Heavy shadows.
