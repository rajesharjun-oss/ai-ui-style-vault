# Guidelines

## Do

- Use black filled pill buttons for primary actions.
- Use one orange highlight box inside important headlines.
- Keep the interface mostly monochrome.
- Use pastel surfaces for feature grouping.
- Apply tight tracking to display headlines.
- Use small tracked mono labels for metadata.
- Use flat cards with 1px borders instead of shadows.
- Use pixel, dot, terminal, code, and browser-window imagery.

## Don't

- Do not use orange as the normal CTA background.
- Do not use browser default blue links.
- Do not add box shadows to cards.
- Do not make buttons full 999px capsules.
- Do not use display type for body copy.
- Do not add multiple orange highlights in a single headline.
- Do not use photography.
- Do not use colorful text for normal body copy.

## Accessibility Notes

- Keep black-on-white and black-on-pastel contrast strong.
- Use visible keyboard focus, especially for black and ghost pill buttons.
- Do not rely on orange alone to communicate state.
- Make pixel or mockup imagery decorative unless it contains critical product information.
