# ChatGPT

Light achromatic utility interface style system captured from Refero Styles.

- Source: https://styles.refero.design/style/52a007ed-ad1b-46a6-bd44-b76f91df6d0c
- Reference site: https://chatgpt.com
- Captured: 2026-07-28
- Theme: light
- Mood: graphite ink on warm paper

## Use This When

Use this style for chat interfaces, writing tools, AI workspaces, command centers, document editors, notes apps, knowledge tools, and productivity surfaces where text content should dominate and product chrome should recede.

## Core Idea

ChatGPT is an achromatic utility system. A soft Sidebar Mist rail, Pure White conversation canvas, Graphite Ink text, system UI fonts, 10px controls, compact spacing, and hairline borders create a calm workspace for reading and writing. Meaning comes from layout, weight, hover veil, and position instead of color.
