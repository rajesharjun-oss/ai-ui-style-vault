# Guidelines

## Do

- Use Graphite Ink for all primary text and icons.
- Reserve pure black for pressed states, tooltips, scrims, and inverted surfaces.
- Keep the interface achromatic.
- Use 6px element gaps and 24px section gaps.
- Use 10px radius for buttons, sidebar items, and cards.
- Use the full pill radius only for account CTA controls.
- Render all text in the system font stack.
- Express elevation with 1px Hairline borders.
- Use Hover Veil for every hover state.
- Center the main conversation at a comfortable reading width.

## Do Not

- Do not introduce any chromatic accent color.
- Do not use shadows for elevation.
- Do not set body text or icons to pure black.
- Do not mix pill and 10px radii inside the same control type.
- Do not use text larger than 24px.
- Do not add default background fills to navigation rows.
- Do not load custom webfonts.
- Do not add decorative imagery.
