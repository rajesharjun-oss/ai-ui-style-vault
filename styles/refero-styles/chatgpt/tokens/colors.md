# Colors

## Palette

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Sidebar Mist | `#f9f9f9` | `--color-sidebar-mist` | Sidebar and secondary surface backgrounds |
| Pure White | `#ffffff` | `--color-pure-white` | Main canvas, panels, and elevated surfaces |
| Graphite Ink | `#0d0d0d` | `--color-graphite-ink` | Primary text, headings, and icon fills |
| Mid Ash | `#5d5d5d` | `--color-mid-ash` | Secondary text, labels, metadata, and icons |
| Hollow | `#8f8f8f` | `--color-hollow` | Tertiary text, disabled states, helper copy |
| Hairline | `#0000001a` | `--color-hairline` | 1px borders and dividers |
| Hover Veil | `#0000000d` | `--color-hover-veil` | Hover state wash |
| Ink Press | `#000000` | `--color-ink-press` | Pressed or inverted surfaces, tooltips, scrims |
| Deep Charcoal | `#00000080` | `--color-deep-charcoal` | Modal scrim overlay |
| Edge Gray | `#e6e6e6` | `--color-edge-gray` | Stronger divider or inactive surface |

## Usage

This is a fully achromatic interface. Do not introduce brand blue, status green, alert red, or decorative accent colors. State is communicated through weight, hover fill, border, and position.
