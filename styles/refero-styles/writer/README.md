- Reference site: https://writer.com
- Captured: 2026-07-28
- Theme: light
- Mood: editorial AI atelier on a white marble newsroom canvas

## Use This When

Use this style for enterprise AI products, agent platforms, writing tools, knowledge systems, AI governance, productivity suites, content operations, and polished B2B software that should feel editorial, confident, and approachable.

## Core Idea

WRITER uses a near-white editorial canvas, centered Poppins display headlines, one vivid violet word highlight, pill-shaped controls, and soft 12px cards. It alternates white content sections with dark resource bands, while CanelaDeck-style serif body accents add an editorial undertone to otherwise geometric product UI.
