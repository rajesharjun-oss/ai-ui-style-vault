# Spacing And Shape

## Spacing

| Purpose | Value |
| --- | --- |
| Density | comfortable |
| Base unit | 4px |
| Page max width | 1200px |
| Section gap | 80px to 120px |
| Card padding | 24px |
| Element gap | 12px to 16px |

## Scale

`4px`, `8px`, `12px`, `16px`, `20px`, `24px`, `28px`, `32px`, `40px`, `60px`, `80px`, `112px`

## Radius

| Element | Value |
| --- | --- |
| Cards | 12px |
| Images | 12px |
| Icons | 12px |
| Buttons | 60px |
| Inputs | 72px |
| Large pills | 82px |

## Elevation

Use minimal elevation. Prefer whitespace, background contrast, and Mist borders. Do not add drop shadows to cards or buttons.
