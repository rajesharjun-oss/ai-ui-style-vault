# Colors

## Palette

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Orchid Accent | `#a95ef8` | `--color-orchid-accent` | One highlighted word in display headlines |
| Iris Brand | `#5551ff` | `--color-iris-brand` | Scarce violet action and outline accent |
| Lavender Wash | `#e4e9ff` | `--color-lavender-wash` | Soft section wash and subtle separation |
| Cobalt Spark | `#007aff` | `--color-cobalt-spark` | Low-frequency decorative or product detail accent |
| Ink Black | `#000000` | `--color-ink-black` | Main text, headings, strong borders, icons |
| Pure White | `#ffffff` | `--color-pure-white` | Page canvas, cards, inputs, button text |
| Obsidian | `#27272b` | `--color-obsidian` | Dark section background and neutral filled buttons |
| Graphite | `#2d2d2d` | `--color-graphite` | Dark surface level and secondary dark fills |
| Slate | `#666666` | `--color-slate` | Helper text, placeholders, metadata |
| Ash | `#bdbdbd` | `--color-ash` | Placeholder text and low-priority labels |
| Fog | `#d2d4d7` | `--color-fog` | Muted text, secondary borders, disabled states |
| Mist | `#e4e7ed` | `--color-mist` | Hairline borders, dividers, subtle card edges |
| Privacy Banner Gradient | `linear-gradient(50deg, #f7c8ed 50px, #e5ecff 130px, #e5ecff 100%)` | `--gradient-privacy-banner` | Soft announcement banner wash |

## Usage

Orchid Accent is for one highlighted word in a display headline. Iris Brand is for scarce action accents. The rest of the interface should be monochrome, using Pure White, Ink Black, Obsidian, and light border grays.
