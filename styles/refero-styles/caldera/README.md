# Caldera

Caldera is a warm, volcanic, infrastructure-focused brand system. It pairs a pumice paper canvas with oversized black compressed headlines, ember-orange action surfaces, violet halftone hero fields, sulfur-yellow status tags, and softly inflated 40px containers.

Use this folder as an AI implementation brief. The most useful files are:

- `DESIGN.md` for the full style interpretation.
- `implementation-prompt.md` for a copy-ready prompt to hand to an AI builder.
- `style.json` for structured metadata.
- `code/css-variables.css` for CSS custom properties and component recipes.
- `code/tailwind-v4.css` for Tailwind v4 theme tokens.
- `code/design-tokens.json` for machine-readable tokens.

Core cues:

- Canvas: `#e3ded8` Pumice, not white.
- Text: `#000000` Lava Black for display impact.
- Accent: `#ff6828` Ember Orange for primary actions, borders, tags, and important UI states.
- Secondary accent: `#6c35ff` Violet for halftone/developer-grid moments.
- Status accent: `#e8ff50` Sulfur only for small tags and badges.
- Display: PP Neue Montreal style, very large, tight tracking, weight 530.
- UI/body: DM Sans, mostly medium weight.
- Shape: 40px rounded cards/buttons, 800px pills, 32px inputs.

This is best for blockchain infrastructure, developer platforms, rollup tooling, web3 dashboards, network-status products, and technical launch pages.
