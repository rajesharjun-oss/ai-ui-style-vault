# Typography

## Display

- Family: PP Neue Montreal
- Token: `--font-pp-neue`
- Fallback: Arial Narrow, Helvetica Neue Condensed, Inter Tight, sans-serif
- Weight: 530
- Use: hero headlines, section headlines, large product claims
- Tracking: tight, about `-3px` to `-5.76px` at display sizes

## UI And Body

- Family: DM Sans
- Token: `--font-dm-sans`
- Fallback: Inter, system-ui, sans-serif
- Weight: 500 for normal UI, 600 for emphasis
- Use: body copy, buttons, labels, forms, cards, navigation, captions

## Type Scale

| Role | Size | Line Height | Letter Spacing | Token |
|---|---:|---:|---:|---|
| Micro | 14px | 1.1 | 0 | `--text-micro` |
| Body | 16px | 1.25 | 0 | `--text-body` |
| Body LG | 24px | 1.15 | 0 | `--text-body-lg` |
| Heading | 48px | 1.05 | -1.44px | `--text-heading` |
| Display | 128px | 0.95 | -5.76px | `--text-display` |

## Rules

- Do not use serif type.
- Avoid thin weights.
- Keep display text oversized and tight.
- Let medium-weight DM Sans carry the product UI.
