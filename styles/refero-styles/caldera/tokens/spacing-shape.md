# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Density | spacious |
| Base unit | 4px |
| Max width | 1280px |
| Section gap | 160px |
| Card padding | 40px |
| Element gap | 16px |

## Scale

`4, 8, 12, 16, 20, 24, 32, 40, 48, 56, 64, 80, 96, 120, 160, 200`

## Radii

| Element | Value |
|---|---:|
| Buttons | 40px |
| Inputs | 32px |
| Cards | 40px |
| Chips and tags | 800px |
| Modals | 48px |
| Hero visual | 56px |

## Shape Rules

- Cards and buttons should feel inflated and friendly.
- Tags should be full capsules.
- Avoid sharp enterprise-dashboard geometry.
- Avoid small 8px SaaS cards.
