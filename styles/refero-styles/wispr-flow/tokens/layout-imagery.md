# Layout And Imagery

## Layout

- Use centered 1200px max-width content inside full-bleed section backgrounds.
- Start with a floating cream navigation pill.
- Build hero around a centered 120px serif headline on cream canvas.
- Place one primary lavender CTA beneath the subtitle.
- Alternate cream sections and dark chambers.
- Use 64px to 96px vertical gaps.
- Use text-left and visual-right feature sections.
- Use side-by-side comparison cards for data or performance comparisons.
- Footer can be a full-width dark band.

## Imagery

Use:

- Flat phone mockups.
- Waveform visualizers.
- App icon parades.
- Curved text arcs.
- Hand-drawn lavender underlines.
- Blurred atmospheric photo layers only inside dark feature cards.

Avoid:

- Stock photography as page background.
- Abstract gradients.
- Glossy 3D renders.
- Heavy illustration systems.
- Product images without borders or chamber context.
