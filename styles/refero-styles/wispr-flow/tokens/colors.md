# Colors

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Lavender Whisper | `#f0d7ff` | `--color-lavender-whisper` | Primary CTA fill and accent card surfaces |
| Forest Ink | `#034f46` | `--color-forest-ink` | Secondary brand surface, badges, inner dark-panel cards |
| Ember Glow | `#ffa946` | `--color-ember-glow` | Live states, active mic indicators, notification dots |
| Vast Ink | `#1a1a1a` | `--color-vast-ink` | Primary text, borders, dark section backgrounds |
| Charcoal | `#222222` | `--color-charcoal` | Secondary button and nav text |
| Fog | `#8a8a80` | `--color-fog` | Muted captions, helper text, de-emphasized labels |
| Lumen Stone | `#e4e4d0` | `--color-lumen-stone` | Subtle dividers, nav pill background, low-contrast separation |
| Lumen Cream | `#ffffeb` | `--color-lumen-cream` | Main canvas, cream cards, button fills, light text on dark |
| Pure White | `#ffffff` | `--color-pure-white` | Badge borders on dark, icon strokes, light text on color |

## Color Rules

- Lavender Whisper is the only primary CTA fill.
- Forest Ink is secondary, not an alternative primary CTA.
- Ember Glow is only for live or active punctuation.
- Vast Ink owns text, borders, and dark chambers.
- Lumen Cream is the page canvas and cream surface.
- Do not add blue, generic green, or other action colors.
