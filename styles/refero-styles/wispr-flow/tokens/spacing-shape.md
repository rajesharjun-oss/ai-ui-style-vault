| Purpose | Value |
| --- | --- |
| Density | Comfortable |
| Base unit | 8px |
| Page max width | 1200px |
| Section gap | 64px to 96px |
| Card padding | 32px |
| Element gap | 8px to 16px |

| Element | Value |
| --- | --- |
| Inputs | 12px |
| Buttons | 12px |
| Cards | 32px |
| Badges | 9999px |
| Sections | 40px to 80px |

## Borders

Interactive controls use:

```css
border: 2px solid #1a1a1a;
```

On dark surfaces, use Lumen Cream or Pure White borders.

## Elevation

No box shadows. Use fill alternation, 2px borders, and oversized radius.
