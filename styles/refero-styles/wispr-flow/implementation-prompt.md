# Implementation Prompt

Build in the Wispr Flow style: a warm editorial software page with a Lumen Cream canvas, Vast Ink dark chambers, Eb Garamond display headlines, Figtree UI text, 2px ink borders, lavender primary actions, and no shadows.

Use these rules:

- Page canvas: `#ffffeb`.
- Primary text and borders: `#1a1a1a`.
- Dark chamber background: `#1a1a1a`.
- Cream text on dark: `#ffffeb`.
- Primary action fill: `#f0d7ff`.
- Secondary brand fill: `#034f46`.
- Live active accent: `#ffa946`.
- Muted captions: `#8a8a80`.
- Subtle divider: `#e4e4d0`.
- Display font: Eb Garamond or Cormorant Garamond.
- UI and body font: Figtree or Inter.
- Display: 120px, weight 400, line-height 0.85, tracking -3.6px.
- Heading large: 64px, weight 400, line-height 0.95, tracking -1.92px.
- Heading: 48px, weight 400, line-height 0.95.
- Body: 20px, Figtree 400, line-height 1.3.
- Buttons: 12px radius, 2px Vast Ink border.
- Cards: 32px radius, 32px padding.
- Dark sections: 40px to 80px radius.
- Section gap: 64px to 96px.
- Element gap: 8px to 16px.
- No box shadows.

Design structure:

1. Floating cream nav pill with 2px ink border.
2. Centered serif hero headline on cream canvas.
3. Lavender primary CTA with 2px ink border.
4. Alternate cream sections and dark rounded chambers.
5. Use dark feature cards with Lumen Cream text.
6. Use phone mockups, waveform visualizers, app icon rows, and comparison cards.
7. Use Forest Ink badges and Ember Glow active dots sparingly.

Avoid:

- Blue CTAs.
- Gradient fills.
- Box shadows.
- Bold display serif.
- Small card radius.
- Centered body copy.
- Generic SaaS blue, green, or red status colors.

The result should feel like warm print editorial design with modern voice-product controls.
