# Quizlet

AI-ready Refero style bundle for Quizlet.

- Source: https://styles.refero.design/style/528eb1d4-8508-4dc6-87b4-c7b92d648dac
- Reference site: https://quizlet.com
- Captured: 2026-07-28
- Theme: light
- Mood: color-coded classroom on white
- Industry: productivity, education, learning, study tools, consumer SaaS

## Use This Style For

- Study, education, productivity, and knowledge apps that need to feel friendly and focused
- Interfaces built around cards, search, study sets, carousels, and learning-product previews
- Product pages where one saturated violet-blue accent should carry all interactive emphasis
- Light SaaS layouts with cool gray canvas, white cards, pill actions, and pastel feature panels

## Files

- `source.md` records the source URL and capture context.
- `DESIGN.md` is the main human-readable design reference.
- `implementation-prompt.md` is a direct prompt for an AI coding agent.
- `style.json` is a structured summary for indexing and retrieval.
- `tokens/` contains focused notes for colors, type, spacing, components, guidelines, layout, and imagery.
- `code/` contains CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` reserves the screenshot slot for manual or automated captures.

## Core Signature

Quizlet is a cool, card-based learning system: Chalk Canvas page background, Paper White study cards, Ink Charcoal text, Iris Bolt as the only saturated accent, 200px pill buttons, 8px content cards, 24px pastel feature cards, Hurme-style geometric typography, and light shadows used only for nav bars and elevated cards.
