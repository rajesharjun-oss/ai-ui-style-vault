# Spacing And Shape

## Spacing

| Purpose | Value | Notes |
|---|---:|---|
| Page max width | 1200px | Centered content rail |
| Section gap | 80px | Major vertical rhythm |
| Large card padding | 24px | Promotional/feature areas |
| Study card padding | 16px | Compact content cards |
| Element gap | 8px | Inline and stacked UI spacing |
| Search padding | 8px 16px | Header search bar |
| Button padding | 10px 20px to 10px 24px | Primary and outlined pills |

## Radius

| Element | Value | Notes |
|---|---:|---|
| Primary buttons | 200px | Signature pill shape |
| Search bar | 200px | Pill search field |
| Content cards | 8px | Study set cards and white panels |
| Feature cards | 24px | Hero carousel category cards |
| Utility badges | 4px | Store badges and dropdown details |
| Carousel arrows | 40px diameter | Circular control |

## Elevation

- Nav and raised card: `rgba(40,46,62,0.1) 0px 4px 16px 0px`
- Interactive button: `rgba(40,46,62,0.1) 0px 2px 4px 0px`
- Icon inset: `rgba(0,0,0,0.3) 0px 0px 1px 0px inset`
- Do not stack multiple shadow layers.
