# Implementation Prompt

Build a polished, responsive learning/productivity interface in the Quizlet Refero style.

Use a light, cool classroom system: Chalk Canvas `#f6f7fb` page background, Paper White `#ffffff` cards, Ink Charcoal `#282e3e` text, Slate Veil `#586380` metadata, Mist Border `#d9dde8` hairlines, Lilac Wash `#edefff` promo sections, and Iris Bolt `#4255ff` as the only saturated action color.

Typography should use `hurme_no2-webfont` or `Hurme Geometric Sans`; substitute Inter if needed. Body is 16px/24px weight 400. Buttons use weight 600. Feature labels can use weight 700. Hero display is 44px/55px weight 700.

Layout rules:

- Center content in a 1200px max-width rail.
- Use 80px between major sections.
- Use 8px element gaps.
- Use 16px padding for study-set cards and 24px for larger cards/sections.
- Use 200px radius for primary pills and search bars.
- Use 8px radius for normal cards and 24px radius for pastel feature cards.
- Use white cards on gray canvas and lilac bands for promotional sections.

Component rules:

- Primary buttons are Iris Bolt filled pills with white text.
- Ghost links are plain Iris Bolt text with hover underline.
- Study-set cards are white, bordered, 8px radius, and compact.
- Feature cards are pastel, 24px radius, with white inset panels.
- Search bars are gray filled pills with no visible border.
- Navigation is white, compact, slightly elevated, and search-centered.
- Product imagery should look like flashcards, study guides, diagrams, quizzes, and UI panels.

Do not introduce extra saturated colors, square off primary buttons, use pure black for normal body text, stack shadows, put cards directly on lilac without white inset panels, or use Mist Border as a fill.
