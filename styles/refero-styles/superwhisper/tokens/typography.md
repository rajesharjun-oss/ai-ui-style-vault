# Typography

## Families

- Sans: `"Inter", system-ui, sans-serif`
- Mono: `"JetBrains Mono", ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`

## Roles

| Role | Size | Family | Weight | Line Height | Tracking | Use |
|---|---:|---|---:|---:|---:|---|
| Mono Label | 11px to 12px | JetBrains Mono | 500 | 1.33 | 0 | Models, latency, timestamps, command labels |
| UI | 14px | Inter | 500 | 1.43 | 0 | Nav, buttons, chips |
| Body | 16px | Inter | 400 | 1.6 | 0 | Product copy and descriptions |
| Transcript | 17px | Inter | 400 | 1.65 | 0 | Recognized speech and transcript text |
| Card Title | 20px | Inter | 600 | 1.3 | -0.01em | Feature and app panel titles |
| Section Heading | 36px | Inter | 700 | 1.1 | -0.03em | Major sections |
| Hero | 64px | Inter | 700 | 0.98 | -0.05em | First-screen headline |

## Guidance

- Use Inter for normal UI and body content.
- Use JetBrains Mono only for technical metadata.
- Keep transcript text readable and slightly more generous.
- Avoid decorative typefaces.
