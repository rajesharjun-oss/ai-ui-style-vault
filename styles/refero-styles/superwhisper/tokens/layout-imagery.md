# Layout And Imagery

## Layout Pattern

The core page structure is:

1. Dark nav header with one gradient CTA.
2. Centered hero with voice-first headline and short copy.
3. Large voice recorder panel with waveform and transcript preview.
4. Command chip and model badge cluster.
5. Feature card grid on charcoal glass.
6. Workflow section showing transcript, automation output, and commands.
7. Pricing or plan section with pill toggle.
8. Dark footer with muted links.

## Grid

- Use max width around 1200px.
- Use 80px to 112px section gaps.
- Use 12px to 20px app panel gaps.
- Use glass cards and transcript panels as the primary product proof.
- Stack recorder, transcript, and command chips on mobile.

## Imagery

Use:

- Voice recorder controls.
- Waveform bars and dots.
- Transcript cards.
- Command chips.
- Model badges.
- Automation outputs.
- Keyboard-shortcut and privacy labels.

Avoid:

- Stock microphone photos.
- Generic AI head graphics.
- Unrelated cosmic illustrations.
- Large decorative blobs.
- Full-screen noisy gradients.
