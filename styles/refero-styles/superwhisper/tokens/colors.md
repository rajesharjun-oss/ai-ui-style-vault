# Colors

| Name | Value | Token | Role |
|---|---:|---|---|
| Obsidian | `#030712` | `--color-obsidian` | Deepest canvas and page background |
| Deep Space | `#0a0f1c` | `--color-deep-space` | Radial gradient base and large section backgrounds |
| Charcoal Glass | `#111827` | `--color-charcoal-glass` | Cards, panels, command surfaces, input backgrounds |
| Slate Border | `#1f2937` | `--color-slate-border` | Borders, dividers, dark outlines |
| Iron | `#374151` | `--color-iron` | Muted fills, inactive controls, subtle separators |
| Cool Gray | `#9ca3af` | `--color-cool-gray` | Secondary text and metadata |
| Mist | `#e5e7eb` | `--color-mist` | Primary body text on dark |
| White | `#ffffff` | `--color-white` | Highest contrast text, CTA labels, selected icons |
| Electric Violet | `#8b5cf6` | `--color-electric-violet` | Primary brand energy and gradient start |
| Neon Teal | `#22d3ee` | `--color-neon-teal` | Gradient end, active voice status, waveform peaks |
| Aurora Cyan | `#06b6d4` | `--color-aurora-cyan` | Supporting voice accent and active highlights |
| Indigo Glow | `#6366f1` | `--color-indigo-glow` | Secondary gradient stop and focus detail |
| Pink Pulse | `#ec4899` | `--color-pink-pulse` | Tiny recording or expressive accent |
| Success Mint | `#34d399` | `--color-success-mint` | Success state, completed transcription, online state |
| Amber Signal | `#fbbf24` | `--color-amber-signal` | Warning or attention state |

## Guidance

- Keep Obsidian and Deep Space dominant.
- Use Charcoal Glass for product surfaces.
- Use violet-to-teal gradients for primary action and voice state.
- Use Pink, Mint, and Amber only for tiny status states.
- Do not introduce unrelated neon colors.
