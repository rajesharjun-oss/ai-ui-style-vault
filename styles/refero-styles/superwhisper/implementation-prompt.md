# AI Implementation Prompt

Build a polished, responsive interface in the Superwhisper style.

The interface should feel like a dark, private voice-AI cockpit: near-black canvas, frosted charcoal panels, Inter typography, JetBrains Mono metadata, violet-to-teal gradients, pill voice controls, waveform visualization, transcript cards, and compact command chips.

Core rules:

- Use `#030712` and `#0a0f1c` as the dark page canvas.
- Use `#111827` for cards, panels, command surfaces, and input backgrounds.
- Use `#1f2937` for borders and dividers.
- Use `#e5e7eb` and `#ffffff` for primary text.
- Use `#9ca3af` for secondary text and metadata.
- Use `#8b5cf6`, `#6366f1`, and `#22d3ee` for the main gradient action system.
- Use Inter for UI and JetBrains Mono only for model names, latency, timestamps, status labels, and command details.
- Use pill shapes for CTAs, voice recorder controls, and command chips.
- Use glass cards, subtle borders, and controlled glows. Do not make every surface glow.

Recommended layout:

1. Dark nav header with small links and one gradient pill CTA.
2. Centered hero with compact headline, short privacy/productivity copy, and voice action CTA.
3. Large voice recorder panel with waveform, status, model badge, and transcript preview.
4. Feature grid of charcoal glass cards with small gradient icons.
5. Workflow section showing command chips, transcript snippets, and automation outputs.
6. Pricing or plan section with pill segmented toggle.
7. Dark footer with muted links and minimal noise.

Make the product feel fast, private, technical, and voice-first.
