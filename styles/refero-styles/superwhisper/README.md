# Superwhisper

Midnight dictation cockpit with aurora glass: a dark voice-AI product style with near-black surfaces, frosted charcoal cards, violet-to-teal gradients, pill controls, waveform visuals, and compact technical metadata.

Use this style when you want a voice AI, transcription, recording, automation, developer productivity, or command palette interface to feel fast, private, technical, and a little futuristic.

## Files

- `source.md`: Source URL, reference site, capture notes, and scope.
- `DESIGN.md`: Human-readable design breakdown.
- `implementation-prompt.md`: Prompt for an AI builder to implement the style.
- `style.json`: Structured design metadata.
- `tokens/`: Markdown token notes by category.
- `code/`: CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md`: Placeholder for future manual screenshots.

## Quick Use

1. Use `Obsidian` and `Deep Space` for the page canvas.
2. Use frosted `Charcoal Glass` cards with subtle borders.
3. Use `Electric Violet` to `Neon Teal` gradients for one primary action path.
4. Use Inter for most text and JetBrains Mono only for models, latency, timestamps, and command labels.
5. Use pill buttons and rounded voice controls.
6. Use waveform and transcript visuals rather than generic hero illustrations.
