# Layout And Imagery

## Layout

- Center content inside a 1300px max-width rail.
- Use 24px outer padding.
- Keep the top nav transparent and about 52px tall.
- Put logo and wordmark left, compact nav links center, and actions right.
- Lead the hero with light-weight display text and paired CTAs.
- Place a wide product mockup card below or beside the hero copy.
- Use one horizontal logo trust strip.
- Alternate feature sections between text and screenshot columns.
- Use 64px to 96px section gaps.
- Keep the footer as a simple multi-column sitemap on the canvas.

## Imagery

- Use real product screenshots, IDE windows, code panes, agent plans, diffs, terminal panels, and chat integrations.
- Frame screenshots inside Bone cards with warm paper elevation.
- Use macOS-style window chrome where appropriate.
- Use monochrome customer wordmarks inside Linen trust tiles.
- A muted warm landscape can support the hero, but it should not compete with product UI.
- Avoid people photography, decorative illustrations, abstract gradients, and loud chromatic icons.
