# Components

## Primary Filled Button

Ink fill, Parchment text, 4px radius, compact padding, CursorGothic 14px/400. This is the strongest page-level CTA.

## Secondary Filled Button

Linen fill, Ink text, 4px radius, matching compact padding. Pair beside the primary action.

## Ghost Text Button

Transparent background, muted Ink text, no border, 4px focus radius, underline on hover.

## Amber Action Button

Amber fill, light cream text, 4px radius, compact product-UI padding. Use inside mockups and IDE-like workflows.

## Forest Action Button

Forest fill, Parchment text, 1px same-color border, 4px radius. Use for selected product actions and focused conversion moments inside UI chrome.

## Product Mockup Card

Bone background, 4px radius, warm hairline border, 24px padding, and warm paper elevation. Use it to frame product screenshots, IDE windows, and feature visuals.

## Logo Trust Tile

Linen surface with a monochrome Ink logo at reduced opacity. Keep it compact and arranged in a single row.

## Window Mockup Frame

Mac-style controls, muted title, file tabs, code panels, terminal areas, and berkeleyMono labels. The mockup should feel like actual product UI.

## Navigation Bar

Transparent 52px top bar. Logo and wordmark left, compact nav links center, text/ghost/filled actions right.

## Terminal Input Field

Transparent or Bone background, 1px warm border, 4px radius, 10px by 12px padding, berkeleyMono 12px, muted prompt glyph.

## Footer Link Column

No container. Use CursorGothic 14px/500 for headings and 13px Ash links with 8px row gaps.

## Mono Metadata Tag

Transparent, borderless, berkeleyMono 12px Ash. Use for file names, model labels, statuses, timestamps, and command metadata.
