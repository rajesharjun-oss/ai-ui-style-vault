# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Density | compact |
| Base unit | 4px |
| Max width | 1300px |
| Section gap | 64px to 96px |
| Card padding | 24px |
| Element gap | 8px |

## Border Radius

| Element | Radius |
|---|---:|
| Cards | 4px |
| Tiles | 4px |
| Inputs | 4px |
| Buttons | 4px |
| Modals | 8px |

## Elevation

| Name | Token | Use |
|---|---|---|
| Product mockup | `--shadow-product-mockup` | Large screenshot cards and IDE mockup frames. |
| Flyout | `--shadow-flyout` | Menus and popovers. |
| Subtle ring | `--shadow-subtle-ring` | Paper-like inset/ring emphasis. |

Use warm shadows sparingly. Most separation should come from paper surfaces and hairline borders.
