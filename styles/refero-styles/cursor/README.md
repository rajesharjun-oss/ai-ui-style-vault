# Cursor

Source: Refero Styles  
URL: https://styles.refero.design/style/4e3b4717-84c8-4599-baaf-a343c3d619b6  
Reference site: https://cursor.com  
Captured: 2026-07-28

Cursor is a warm parchment developer-product style: cream canvas, warm ink text, sharp 4px geometry, restrained typography, and a small ember accent for links and emphasis. The visual tone is closer to an editorial technical journal than a glossy SaaS page.

Use this folder as an AI implementation brief. The most useful files are:

- `DESIGN.md` for the full style interpretation.
- `implementation-prompt.md` for a copy-ready prompt to hand to an AI builder.
- `style.json` for structured metadata.
- `code/css-variables.css` for CSS custom properties and component recipes.
- `code/tailwind-v4.css` for Tailwind v4 theme tokens.
- `code/design-tokens.json` for machine-readable tokens.

Core cues:

- Canvas: `#f7f7f4` Parchment, not pure white.
- Card surface: `#f2f1ed` Bone.
- Primary text/action: `#26251e` Ink, not pure black.
- Hairline structure: `#cdcdc9` Stone.
- Accent: `#f54e00` Ember for inline links and short emphasis only.
- Supporting product accents: `#c08532` Amber and `#34785c` Forest.
- Display/UI font: CursorGothic, weight 400 for headings.
- Editorial texture: EB Garamond for selected prose and subheads.
- Developer texture: berkeleyMono for code, paths, tags, and metadata.
- Shape: compact 4px radius almost everywhere; 8px only for modals.
- Depth: flat paper surfaces with hairline borders and warm soft shadows.

This is best for developer tools, AI coding products, technical docs, IDE websites, changelog pages, product launch pages, and calm productivity software.
