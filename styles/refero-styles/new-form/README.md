# New Form

Light editorial financial-broadsheet style system captured from Refero Styles.

- Source: https://styles.refero.design/style/1a519123-071a-449f-b5df-0def73ed7f35
- Reference site: https://www.newformcap.com
- Captured: 2026-07-28
- Theme: light
- Mood: editorial broadsheet in a green room

## Use This When

Use this style for venture capital, financial editorials, investment firms, research publications, crypto funds, institutional newsletters, thesis pages, and typographic landing pages that should feel like a printed broadsheet with a vivid green marker accent.

## Core Idea

New Form is almost entirely typographic. A warm Bone White canvas, near-black editorial surfaces, monumental serif display type, tiny uppercase micro-labels, grayscale-green photography, and one saturated Highlighter Green accent create a financial newspaper rhythm. Green behaves like a marker swipe, not a general decorative palette.
