# Typography

## Fonts

- UI and grotesque display: `TWK Lausanne`
- UI fallback: `Inter`, `Sohne`, `Neue Haas Grotesk`, `ui-sans-serif`, `system-ui`
- Main display serif: `PP Mondwest`
- Main display fallback: `GT Sectra`, `Tiempos Headline`, `Recoleta`, `serif`
- Secondary display: `Editorial New`
- Secondary display fallback: `GT Super`, `Domaine Display`, `Canela`, `serif`
- Link serif: `Times`, `Times New Roman`, `serif`

## Font Roles

TWK Lausanne handles micro-labels, navigation, buttons, compact body, and large grotesque headings.

PP Mondwest handles the largest editorial hero headlines. It should be huge, tightly tracked, and dense.

Editorial New handles lighter secondary display passages.

Times handles old-school underlined text links and browser-serif details.

## Rules

- Use PP Mondwest for 165px to 295px hero display type.
- Use -0.04em tracking at the largest display sizes.
- Use line-height 0.9 for serif display.
- Use TWK Lausanne 11px uppercase labels with small positive tracking.
- Do not set body copy above 18px.
- Do not use a sans-only display treatment.
