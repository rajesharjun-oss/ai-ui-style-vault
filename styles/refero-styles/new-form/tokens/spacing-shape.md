| Purpose | Value |
| --- | --- |
| Density | spacious |

| Section gap | 80px |

## Radius

| Element | Value |
| --- | --- |
| Buttons | 5px |
| Pills and ghost blocks | 10px |
| Images | 14px |
| Round utility only | 9999px |

## Shadows

Only the green button gets a shadow, and it must be green-tinted.

```css
--shadow-lg: rgba(16, 94, 29, 0.45) 1px 8px 20px 0px;
--shadow-lg-2: rgba(18, 146, 39, 0.25) 1px 8px 20px 0px;
```
