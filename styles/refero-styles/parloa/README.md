# Parloa

Source: Refero Styles  
URL: https://styles.refero.design/style/c90e63f8-76c1-4159-9460-29e0d18751ae  
Reference site: https://www.parloa.com  
Captured: 2026-07-28

Parloa is a warm editorial SaaS style: cream paper canvas, dark ink navigation, thin serif display headings, precise Geist UI text, flat white cards, and a vivid orange accent used like a highlighter mark. It feels like a premium magazine spread for an AI product, not a standard dashboard.

Use this folder as an AI implementation brief. The most useful files are:

- `DESIGN.md` for the full style interpretation.
- `implementation-prompt.md` for a copy-ready prompt to hand to an AI builder.
- `style.json` for structured metadata.
- `code/css-variables.css` for CSS custom properties and component recipes.
- `code/tailwind-v4.css` for Tailwind v4 theme tokens.
- `code/design-tokens.json` for machine-readable tokens.

Core cues:

- Canvas: `#ebe9e1` Canvas Cream.
- Cards: `#ffffff` Paper White, 0px radius, 1px Hairline border.
- Primary text/action/dark surface: `#1f1c1b` Ink Black.
- Dark secondary surface: `#2d2724` Espresso.
- Muted copy: `#a69b92` Stone.
- Borders: `#d9d6ce` Hairline and `#c7c1b7` Cobblestone.
- Accent: `#ff7714` Highlighter Orange for outlines, links, icon strokes, and small marks only.
- Headings: Exposure30 serif, weight 350 to 400.
- Body/UI: Geist, 300 to 600, with body at 16px/1.5.
- Shape: 0px cards, 2px tags/buttons/inputs, never above 4px.
- Depth: no shadows; use paper contrast and hairline borders.

This is best for AI customer service products, B2B SaaS, enterprise AI sites, editorial landing pages, customer story hubs, and premium service software.
