# Typography

## Families

| Family | Token | Fallback | Role |
|---|---|---|---|
| Exposure30 | `--font-exposure30` | Fraunces, Playfair Display, DM Serif Display | Display headings only. |
| Geist | `--font-geist` | Inter, Manrope, system-ui | Body, nav, buttons, labels, forms, metadata, and UI. |

## Rules

- Use Exposure30 only for headings.
- Use weight 350 for display headings at 42px and above.
- Do not use 600+ weights for serif headings.
- Use Geist for every non-heading element.
- Keep body at 16px, weight 400, line-height 1.5.
- Use 500 to 600 only for button labels and emphasis.
