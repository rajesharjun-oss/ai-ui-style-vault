## Spacing

| Purpose | Value |
|---|---:|
| Base unit | 8px |
| Page max width | 1200px |
| Section gap | 80px |
| Card padding | 16px |
| Element gap | 16px |

## Borders

- Default border: `1px solid #dedfe1`.
- Strong border: `1px solid #000000`.
- Utility/input border: `1px solid #dedfe1`.

## Shadows

- Button: `rgba(0, 0, 0, 0.04) 0px 2px 4px 0px`.
- Hero widget: `rgba(0, 0, 0, 0.04) 0px 2px 4px 0px, rgba(0, 0, 0, 0.08) 0px 8px 32px 0px`.

## Layout Notes

- Respect the 8px scale.
- Use 80px vertical section rhythm.
- Use bands instead of nested cards.
- Keep component corners near-rectangular.
