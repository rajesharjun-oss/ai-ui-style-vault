# Layout And Imagery

## Page Composition

- Use full-width bands.
- Center content in a 1200px container.
- Open with a light hero on cloud canvas.
- Alternate dark and light sections after the hero.
- Close with a dark subscribe band and footer.

## Hero

- Two-column layout.
- Left: 56px display headline, body copy, CTA pair.
- Right: floating chart widget on white card surface.
- Use chart widget shadow only here.

## Data Imagery

- Use line charts, tabbed widgets, dashboards, and abstract market trajectories.
- Use pale lavender fill under chart lines.
- Use blue chart strokes sparingly inside actual data visualizations.
- Keep surrounding UI monochrome.

## Report Grid

- Use 3-4 column report card grids.
- Each card needs a border if placed on a light surface.
- Report covers can use deep navy or dark gradients, but the UI system should remain neutral.

## Logo Strip

- Use monochrome partner logos.
- Place them on cloud canvas.
- Keep logos at uniform height around 24px.
- Do not use colored logo variants.

## Motion

- Use subtle chart reveals, fade-ins, or accordion motion.
- Avoid playful bounces, glowing trails, or decorative parallax.
