# Typography Tokens

## Families

Primary UI:

- Preferred: Inter
- Substitute: Inter from Google Fonts or system sans
- Use for body copy, nav, buttons, labels, cards, headings, and subheadings.

Hero display:

- Preferred: Fraktion
- Substitute: Sohne Breit Halbfett or another geometric bold sans
- Use only for the primary hero H1.

## Weights

- 400 for body copy.
- 500 for controls, navigation, labels, and badges.
- 700 for headings, card titles, and hero display.

## Type Scale

| Role | Size | Line Height | Tracking | Weight | Family |
|---|---:|---:|---:|---:|---|
| Caption | 12px | 1.4 | 0 | 500 | Inter |
| Body small | 14px | 1.5 | 0 | 400 | Inter |
| Body | 16px | 1.5 | 0 | 400 | Inter |
| Subheading | 20px | 1.4 | 0 | 500 | Inter |
| Heading small | 24px | 1.3 | 0 | 700 | Inter |
| Heading | 32px | 1.2 | 0 | 700 | Inter |
| Display | 56px | 1.2 | 0 | 700 | Fraktion |

## Rules

- Use Inter for nearly everything.
- Reserve the custom display face for the hero H1.
- Keep letter spacing normal.
- Use uppercase labels only when short and sparse.
- Do not use decorative serif, mono, or script faces for product UI.
