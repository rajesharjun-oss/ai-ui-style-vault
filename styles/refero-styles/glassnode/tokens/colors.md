# Color Tokens

## Palette

| Token | Value | Role |
|---|---:|---|
| Pure Black | `#000000` | Text, icons, strong contrast, primary filled actions |
| Obsidian | `#1a1a1a` | Dark sections, footer, announcement bar |
| Graphite | `#333333` | Secondary headings and nav text |
| Iron | `#5a5a5a` | Muted body copy and helper text |
| Slate | `#666666` | De-emphasized paragraphs |
| Steel | `#808080` | Placeholders, disabled states, input borders |
| Fog | `#a0a0a0` | Muted text, icon strokes, subtle dark-band copy |
| Ash | `#bfbfbf` | Light dividers and icon strokes |
| Mist | `#dedfe1` | Hairline borders, card outlines, dividers |
| Cloud | `#edeff2` | Page canvas and spaces between bands |
| Paper | `#f7f8fa` | Light section backgrounds and inset panels |
| White | `#ffffff` | Cards, inputs, elevated surfaces, text on dark |
| Glacier Tint | `#e2e7fc` | Soft accent wash, selected state, chart fill |
| Badge Slate | `#6f6f6f` | Small uppercase labels and tags |

## Surface Stack

| Level | Name | Value | Purpose |
|---|---|---:|---|
| 0 | Canvas | `#edeff2` | Page background between content bands |
| 1 | Surface | `#f7f8fa` | Light section background and subtle panels |
| 2 | Card | `#ffffff` | Cards, inputs, and elevated light surfaces |
| 3 | Dark Band | `#1a1a1a` | Dark statement sections and footer |
| 4 | Accent Wash | `#e2e7fc` | Pale emphasis and chart fills |

## Usage

- Use `#000000` and `#1a1a1a` as action colors.
- Use `#dedfe1` for the default border.
- Use `#e2e7fc` only as soft emphasis or chart fill.
- Use `#edeff2` as the global canvas.
- Use `#ffffff` for cards and inputs.

## Avoid

- Do not introduce saturated CTA colors.
- Do not add colorful gradients.
- Do not use colored icon fills.
- Do not put white cards on white sections without borders.
