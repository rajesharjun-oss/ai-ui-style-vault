# Implementation Prompt - Perplexity AI Style

Build an original UI using the Perplexity AI Refero style as visual direction.

Create a warm-paper answer engine interface with a fixed left sidebar, narrow centered main column, category nav, large central search input, mode chips, and a two-column suggestion grid. Keep the UI flat, compact, and parchment-toned, with Deep Teal reserved for active states.

## Must Preserve

- Parchment `#faf8f5` as the page canvas.
- Soft Paper `#fdfbfa` for suggestion cards.
- Warm Mist `#d1d1cd` as hairline border color.
- Ink `#27251e` for primary text and filled action buttons.
- Graphite `#72706b` for secondary text and inactive nav.
- Deep Teal `#016a71` only for active nav, selected chips, badge fills, and search glow.
- pplxSans-style type with weights 400 and 500 only.
- Main content max width around 900px.
- Search input width around 640px.
- Cards at 16px radius, inputs at 12px, ghost buttons at 6px, chips at 9999px.
- Suggestion-card shadow only: `rgba(0,0,0,0.08) 0px 1px 2px 0px`.

## Avoid

- Copying Perplexity logos, exact UI copy, screenshots, product names, or proprietary layouts.
- Adding a second accent color.
- 600+ font weights.
- Pure white surface takeover.
- Teal text in body content.
- Heavy shadows, gradients, blur effects, decorative imagery, photography, or screenshots.
- Wide marketing-page layouts; keep it app-like and narrow.

## Component Direction

Lead with the application frame: left rail, centered search, chips, and suggestion cards. The search input is the hero object. Let spacing, hairline borders, and Deep Teal selected states do the design work.
