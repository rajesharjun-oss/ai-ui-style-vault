# Layout And Imagery

## Layout

- Use a fixed left sidebar about 260px wide.
- Use a centered main column capped at 900px.
- Keep the central search input around 640px wide.
- Put category nav above the search area.
- Place suggestion cards in a two-column grid.
- Use 32px section gaps and 8px element gaps.
- Keep layout app-like, not marketing-like.

## Imagery

- Do not use photography.
- Do not use illustrations.
- Do not use product screenshots.
- Use simple monochrome glyph icons only.
- Let typography, spacing, and selected states carry identity.

## Composition Rules

- The search input is the hero object.
- Sidebar and main column should feel calm and paper-like.
- Deep Teal appears only in selected states.
- Suggestion cards are soft sheets, not elevated panels.
