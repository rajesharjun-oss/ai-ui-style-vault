# AI Implementation Prompt

Build the UI in the Dylanbrouwer style: a bold mixed-theme brutalist portfolio for a designer or creative studio.

Use concrete light fields, black ink, sharp media blocks, massive warped display typography, and one ember-orange accent. The page should feel like a printed exhibition poster translated into a website.

Core rules:

- Use `#efefee` as the main page field and `#f7f7f7` as the lighter card/foreground surface.
- Use `#161616` for text, borders, and dark surfaces.
- Use `#f7601b` as the only vivid accent.
- Use Tilt Warp for huge display type.
- Use Sohne or a clean grotesk for body text.
- Set the largest display type around 288px desktop, weight 400, uppercase, line-height 0.85, with very tight negative tracking.
- Use 76px headings and 44px project titles.
- Keep body copy around 18px with tight, direct line-height.
- Use a 6px base grid, 1200px max width, 144px section gaps, 24px card padding, and 18px element gaps.
- Keep large surfaces, cards, project images, and media frames at 0px radius.
- Use 9999px radius only for nav pills, tags, filters, and small capsules.
- Use no resting shadows.
- Use hard-edged project imagery and editorial screenshots.
- Use compact uppercase metadata labels.

Avoid soft gradients, rounded cards, decorative shadows, extra accent colors, warm beige branding, generic SaaS hero layouts, and small polite display type.

The result should be dramatic, sparse, type-led, and portfolio-first.
