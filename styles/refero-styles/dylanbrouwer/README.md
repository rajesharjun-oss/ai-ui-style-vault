## Style Summary

Dylanbrouwer is a brutalist portfolio system with oversized warped display type, bone-white gallery fields, hard black boundaries, and a single ember-orange accent. It feels like a printed exhibition poster brought into a portfolio website: sharp, sparse, loud in scale, and restrained in color.

Use this style when an AI needs to build a bold designer portfolio, creative studio page, or editorial case-study index where type and hard image blocks carry most of the personality.

## What To Borrow

- Massive Tilt Warp display type at poster scale.
- Bone-white and concrete fields with black ink and no soft elevation.
- Ember orange as the only chromatic accent.
- Sharp-cornered project cards and media.
- Pill-only nav controls, tags, and compact filters.
- Large whitespace rhythm based on a 6px grid.
- Horizontal project-gallery composition with oversized thumbnails.
- Minimal metadata in compact uppercase labels.
- No shadows, no soft cards, no rounded image frames.

## Avoid

- SaaS-style card shadows.
- Generic rounded rectangles.
- Blue, purple, green, or multicolor accents.
- Small hero typography.
- Gradients used as decoration.
- Excessive body copy.
- Warm beige branding or soft editorial styling.
