# Layout And Imagery

## Page Structure

1. Poster masthead with massive display typography.
2. Sticky or top pill navigation.
3. Sparse intro or metadata strip.
4. Sharp project gallery.
5. Work index rows or case-study list.
6. Full-bleed dark transition panel.
7. Contact or footer with oversized type.

## Grid

- Max rail: 1200px.
- Base rhythm: 6px.
- Gallery gutter: 24px.
- Desktop: 2-column or asymmetric project layouts.
- Mobile: single-column, but keep display type cropped and graphic.

## Imagery Rules

Use:

- Project screenshots.
- Editorial image crops.
- Portfolio case-study visuals.
- Hard-edged web captures.
- Black and white or low-saturation visuals.

Avoid:

- Soft lifestyle photography.
- Rounded device mockups.
- Generic stock images.
- 3D SaaS renders.
- Decorative abstract gradients.

## Composition

Let large type and images create impact. Use fewer elements at larger scale. Keep metadata small and precise so the page feels curated rather than busy.
