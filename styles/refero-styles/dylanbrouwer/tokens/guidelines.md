# Guidelines

## Do

- Use enormous display typography as the main visual event.
- Keep large surfaces and media sharp.
- Use ember orange as the only vivid accent.
- Use black borders instead of shadows.
- Keep copy short and editorial.
- Use pill shapes only for small controls.
- Let project imagery feel cropped, direct, and hard-edged.
- Preserve dramatic vertical gaps.

## Do Not

- Do not use resting shadows.
- Do not round project images or large cards.
- Do not introduce extra accent colors.
- Do not build a generic SaaS hero.
- Do not make the masthead small.
- Do not use soft gradients or blurred decorative backgrounds.
- Do not overfill sections with body copy.
- Do not turn every label into an orange badge.

## Implementation Priorities

1. Establish concrete, bone, cinder, and ember tokens.
2. Build a poster masthead with huge Tilt Warp type.
3. Add pill navigation and a sparse metadata layer.
4. Build sharp project cards or a work index.
5. Add hard-edged media blocks.
6. Use a dark panel for contrast only when it supports the sequence.

## Common Failure Modes

- The design becomes ordinary when the display type is too small.
- Orange loses power when used everywhere.
- Rounded cards make the style feel like a template.
- Shadows weaken the printed poster quality.
