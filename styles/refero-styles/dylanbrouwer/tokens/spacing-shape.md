# Spacing And Shape

## Spacing

| Purpose | Value | Notes |
| --- | ---: | --- |
| Base unit | 6px | Core rhythm |
| Max width | 1200px | Main content rail |
| Section gap | 144px | Dramatic portfolio pacing |
| Card padding | 24px | Project and information blocks |
| Element gap | 18px | Labels, titles, body copy |
| Metadata gap | 12px | Compact index and pill spacing |
| Gallery gutter | 24px | Sharp project grids |

## Radius

| Element | Value | Notes |
| --- | ---: | --- |
| Global surfaces | 0px | Default shape |
| Project cards | 0px | Sharp and editorial |
| Media frames | 0px | No rounded screenshots |
| Large sections | 0px | Full-bleed block logic |
| Nav pills | 9999px | Small controls only |
| Tags and chips | 9999px | Small controls only |

## Borders

Use 1px solid `#161616` for strong boundaries and 1px solid `#d5d5d5` for quieter dividers on light sections.

## Shape Rules

- Large objects are sharp.
- Small controls can be pills.
- Do not use 8px rounded SaaS cards.
- Do not soften images.
- Do not add shadows to create separation.
