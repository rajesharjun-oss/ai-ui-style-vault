# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Density | `comfortable` |
| Base unit | `4px` |
| Max width | `1200px` |
| Section gap | `64-96px` |
| Card padding | `28-42px` |
| Element gap | `14-21px` |

| Element | Value |
|---|---:|
| Nav | `7px` |
| Cards | `14px` |
| Badges | `999px` |
| Buttons | `14px` |

## Elevation

- No box shadows.
- No glassmorphism.
- No colored card borders.
- Use layered fills for hierarchy: cream, keylime, mint, sage, slate.
