# Ease Health Style Reference

## Creative Direction

Create a calm healthtech interface that feels like a botanical clinical document printed on cream paper. Avoid tech gloss. The system should feel warm, serious, editorial, and operational: soft green panels, slate-blue product showcases, forest ink type, no shadows, and large serif questions/headlines.

## Visual Priorities

1. Use `#fffefc` as the page canvas.
2. Use `#0f3e17` for every primary heading, link, icon stroke, and filled action.
3. Layer surfaces using cream, keylime, mint, sage, then slate.
4. Use `#b6ced5` only for product screenshots and demo panels.
5. Use no box shadows on cards, buttons, or panels.
6. Use 14px radius for cards and buttons.
7. Use 999px radius for badges and tags.
8. Set all display headings in a weight-300 serif.

## Screen Composition

Use a centered 1200px container with 64px to 96px vertical section gaps. The hero should work as a two-column split: a keylime or sage editorial panel for the message and CTA, and a slate panel for crisp white product preview cards. Below the hero, alternate cream sections and tinted panels in a botanical rhythm.

## Material Language

This style is flat, paper-like, and shadowless. Depth is not created by elevation; it is created by sequencing tinted surfaces from cream to keylime to mint to sage to slate. Product preview cards can be white/cream on the slate panel, but they should remain flat.

## AI Implementation Notes

When generating a UI from this style, build the surface rhythm first: cream canvas, keylime hero message panel, slate product preview panel, sage feature cards, cream FAQ rows, and a monochrome logo strip. Keep the page generous and editorial, not dense like a hospital admin dashboard.
