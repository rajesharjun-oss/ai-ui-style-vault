## What To Preserve

Ease Health uses a clinical-botanical language: warm cream paper, layered keylime/mint/sage surfaces, a cool slate product preview panel, and a single deep forest-green ink for headings, links, and actions. The typographic personality is the key signal: light-weight serif display headings paired with a quiet humanist sans for UI and body copy.

## What To Avoid Copying

Do not copy the original logo, product mockups, investor logos, hero wording, navigation copy, or exact page layout. Use the token system and component logic to create original healthtech, behavioral health, clinic operations, EHR, CRM, RCM, or care coordination interfaces.

## Build Context

This bundle is meant for AI-assisted UI implementation. Use the markdown files for design intent, and use the `code/` files for direct token import when building with CSS variables or Tailwind v4.
