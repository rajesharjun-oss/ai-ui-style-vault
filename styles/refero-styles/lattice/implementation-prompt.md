# AI Implementation Prompt

Build a polished, responsive interface in the Lattice style.

The interface should feel like a calm people-operations workspace: warm off-white canvas, soft blue-green dashboard panels, rounded white cards, compact Inter Tight typography, amber primary CTA, teal secondary actions, and delicate abstract people/productivity imagery.

Core rules:

- Use `#f4f3ef` as the main page canvas.
- Use `#282a2a` for primary text instead of pure black.
- Use `#c6d7db`, `#749f99`, and `#d7e7ea` for large calm panels and dashboard washes.
- Use `#e7ae3c` for one primary CTA only.
- Use `#477d78` for secondary buttons, selected filters, and active states.
- Use rounded cards and panels; avoid sharp square geometry.
- Keep dashboards tidy, low-pressure, and scannable.
- Use people/team/productivity metaphors rather than abstract tech spectacle.

Recommended layout:

1. A warm paper page with compact top navigation and one amber CTA.
2. A hero with a people-ops headline, short supporting copy, and a large mist-blue dashboard panel.
3. Product cards showing reviews, goals, engagement, feedback, and employee growth.
4. Soft metric cards, survey bars, team/person tiles, and pill filters.
5. Calm testimonial or customer proof section with muted green or paper cards.
6. A restrained footer with warm neutral text links.

Make the product feel supportive, trustworthy, organized, and human.
