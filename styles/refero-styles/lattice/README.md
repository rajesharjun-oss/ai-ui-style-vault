# Lattice

Mist over a people-ops dashboard: a calm HR/productivity interface with warm off-white canvas, desaturated blue-green panels, compact rounded cards, Inter Tight headings, and small amber or teal accents.

Use this style when you want a people platform, HR tool, feedback product, survey dashboard, team workspace, or lightweight analytics surface to feel supportive, organized, and human without becoming decorative.

## Files

- `source.md`: Source URL, reference site, capture notes, and scope.
- `DESIGN.md`: Human-readable design breakdown.
- `implementation-prompt.md`: Prompt for an AI builder to implement the style.
- `style.json`: Structured design metadata.
- `tokens/`: Markdown token notes by category.
- `code/`: CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md`: Placeholder for future manual screenshots.

## Quick Use

1. Use `Warm Paper` as the page canvas.
2. Use `Mist Blue` and `Muted Green` for hero panels and soft dashboard surfaces.
3. Use charcoal text, not pure black.
4. Use 8px card/input radius and 9999px only for small pills.
5. Use Amber Glow for the one primary CTA and Teal Accent for secondary action states.
6. Keep imagery abstract, diagrammatic, and people-ops adjacent.
