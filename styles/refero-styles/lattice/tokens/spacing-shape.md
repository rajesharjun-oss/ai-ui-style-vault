# Spacing And Shape

## Spacing

| Purpose | Value | Notes |
|---|---:|---|
| Density | comfortable | Calm product rhythm |
| Base unit | 4px | Token foundation |
| Max width | 1180px | Main contained layout |
| Element gap | 12px to 20px | Cards, controls, dashboard rows |
| Card padding | 20px to 28px | Insight and people cards |
| Panel padding | 32px to 48px | Hero and large product panels |
| Section gap | 72px to 96px | Marketing/product storytelling rhythm |

## Shape

| Element | Radius | Notes |
|---|---:|---|
| Card | 16px | Default card shape |
| Panel | 20px to 24px | Larger hero/dashboard surfaces |
| Input | 10px to 12px | Soft but functional |
| Button | 9999px or 12px | Pill for marketing CTAs, 12px for app controls |
| Pill | 9999px | Filters and status chips |

## Elevation

- Use subtle borders and color separation first.
- Shadows should be low-contrast and optional.
- Do not make heavy floating SaaS cards.
