# Layout And Imagery

## Layout Pattern

The core page structure is:

1. Warm Paper page canvas.
2. Compact top navigation with one amber CTA.
3. Hero copy paired with a large mist-blue dashboard panel.
4. Product cards for reviews, goals, feedback, engagement, and growth.
5. People cards, survey bars, metric cards, and pill filters.
6. Calm proof, testimonial, or customer section.
7. Warm neutral footer.

## Grid

- Use a max width around 1180px.
- Use two-column or asymmetric hero layouts on desktop.
- Use soft card grids for product features and metrics.
- Stack clearly on mobile.
- Avoid dense enterprise dashboard layouts as the first impression.

## Imagery

Use:

- Abstract people/team illustrations.
- Rounded dashboard UI snippets.
- Survey bars and engagement charts.
- Employee profile cards.
- Soft organic shapes in blue, green, amber, coral, and lavender.

Avoid:

- Dark cyber visuals.
- Neon AI gradients.
- Glossy 3D.
- Generic office stock photos.
- Sharp technical grid imagery.
