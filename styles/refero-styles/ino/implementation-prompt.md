# AI Implementation Prompt

Build a quiet jewelry-gallery commerce interface inspired by INO.

Use a light neutral system with white canvas, black micro typography, pale product fields, a single wide sans typeface, zero-padded product cards, small utility controls, and bottom navigation with circular indicators. The product photography should carry the luxury feeling.

Requirements:

- Use Sequel100Wide if licensed. Otherwise use Eurostile Extended, Neue Haas Grotesk Display, Inter Tight, Arial, or another wide geometric sans.
- Use one font weight only: 400.
- Keep text small. Use 11px to 18px for most visible type.
- Use uppercase micro labels with generous tracking.
- Use only neutral colors: white, black, chalk, fog, and stone.
- Do not add a brand accent color or colored CTA.
- Make product cards almost empty: zero padding, pale image field, no shadow, no heavy border, minimal name and price metadata.
- Use bottom navigation with tiny labels and circular active markers as a signature element.
- Use 4px radius only for utility buttons and inputs. Keep product image fields and page sections visually square.
- Use product photography of jewelry or small luxury objects on pale backgrounds.
- Avoid large marketing hero type, saturated colors, shadows, gradients, rounded card-heavy ecommerce layouts, and decorative icons.

Hero or landing recipe:

Create a white gallery page with a sparse top utility row, a large centered product image on a chalk field, tiny uppercase product or collection metadata, and a bottom navigation strip with circular indicators. Keep the page calm and object-focused.

Product grid recipe:

Create a 2- to 4-column grid. Each item uses a pale chalk/fog image field, zero padding, no shadow, a tiny uppercase product name, a small price line, and a thin bordered add/control action when needed.
