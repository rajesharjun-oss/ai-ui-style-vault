# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Base unit | `4px` |
| Density | `comfortable` |
| Page max width | `1440px` |
| Section gap | `88px` |
| Product card padding | `0px` |
| Element gap | `16px` |
| Product grid gap | `24px` to `40px` |
| Bottom nav height | `64px` to `88px` |

## Spacing Tokens

Use `4`, `6`, `8`, `10`, `12`, `16`, `20`, `24`, `32`, `40`, `48`, `64`, `72`, `88`, `104`, and `128`.

## Radius

| Element | Radius |
|---|---:|
| Buttons | `4px` |
| Inputs | `4px` |
| Product cards | `0px` |
| Product image fields | `0px` |
| Sections | `0px` |
| Circle indicators | `50%` |

## Shape Rules

- Keep product regions square and almost invisible.
- Use 4px radius only for small utility controls.
- Use circular indicators for bottom nav and state markers.
- Do not use pill CTAs, large rounded cards, or soft ecommerce tiles.
