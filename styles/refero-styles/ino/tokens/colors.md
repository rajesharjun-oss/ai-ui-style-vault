# Colors

## Palette

| Name | Value | Token | Role |
|---|---:|---|---|
| White | `#ffffff` | `--color-white` | Page canvas, negative space, primary retail surface |
| Ink | `#000000` | `--color-ink` | Primary text, icons, hairline controls, active indicators |
| Chalk | `#f7f7f5` | `--color-chalk` | Product image fields, quiet gallery blocks, subtle item panels |
| Fog | `#eeeeea` | `--color-fog` | Secondary surfaces, dividers, hover fields, light overlay panels |
| Stone | `#9a9a94` | `--color-stone` | Metadata, captions, disabled state, quiet footer text |

## Usage

- Keep White dominant.
- Use Ink for all primary text and active marks.
- Use Chalk and Fog for barely visible product fields and separators.
- Use Stone only for quiet metadata and secondary utility labels.
- Do not introduce a colored accent, tinted CTA, or decorative gradient.
