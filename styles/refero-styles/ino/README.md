# INO

AI-ready Refero style bundle for INO.

- Source: https://styles.refero.design/style/57388b47-f789-441f-8b8d-13f1838a9ac6
- Reference site: https://www.inostudios.com
- Captured: 2026-07-28
- Theme: light
- Mood: clinical jewelry gallery in paper white
- Industry: jewelry, luxury retail, product gallery

## Use This Style For

- Jewelry, watches, objects, fine accessories, and quiet luxury commerce
- Product galleries where the item should feel inspected rather than advertised
- Minimal retail pages with bottom navigation, tiny uppercase type, and high whitespace
- Catalogs that need restraint, object focus, and gallery-like precision

## Files

- `source.md` records the source URL and capture context.
- `DESIGN.md` is the main human-readable design reference.
- `implementation-prompt.md` is a direct prompt for an AI coding agent.
- `style.json` is a structured summary for indexing and retrieval.
- `tokens/` contains focused notes for colors, type, spacing, components, guidelines, layout, and imagery.
- `code/` contains CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` reserves the screenshot slot for manual or automated captures.

## Core Signature

INO is a near-silent jewelry gallery: white canvas, black micro type, pale product fields, one wide sans typeface at one weight, tiny uppercase labels, bottom navigation with circle indicators, and product imagery given almost all of the visual attention.
