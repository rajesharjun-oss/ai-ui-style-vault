## What To Preserve

Vercel uses a near-white canvas, near-black text, hairline borders, tight Geist Sans display type, Geist Mono labels, and terminal-like product proof. Color is nearly absent. The only routine chromatic accent is Terminal Green for confirmations and short technical emphasis. Decorative gradients can exist in marketing visuals, but never as general UI color.

The page relies on:

- Paper White as the main page background.
- Pure White as one-step elevated card and input surface.
- Obsidian for primary text, filled buttons, dark cards, and list markers.
- Charcoal and Stone for readable secondary copy.
- Hairline for card/button rings.
- Carbon only for the triangle glyph and SVG marks.
- Geist Sans for display, body, nav, cards, and buttons.
- Geist Mono for uppercase labels, metadata, code blocks, CLI output, and tiny stamps.
- 6px radius for cards, buttons, and rectangular containers.
- Stacked border rings instead of drop shadows.
- CLI panels and triangle-mark command prefixes as the product demo language.
