# Typography

## Families

| Family | Token | Fallback | Role |
|---|---|---|---|
| Geist Sans | `--font-geist-sans` | Inter, system-ui | Display, body, navigation, buttons, cards, and product copy. |
| Geist Mono | `--font-geist-mono` | JetBrains Mono, ui-monospace | Labels, metadata, code blocks, CLI output, uppercase eyebrows, and tiny stamps. |

## Rules

- Use Geist Sans for reading and display.
- Use Geist Mono for every label, code, metadata, and CLI surface.
- Set headings at weight 400 to 450.
- Never use 300, 600, or 700 for headlines.
- Keep display line-height at 1.
- Tighten tracking at 30px, 56px, and 64px.
