# Layout And Imagery

## Layout

- Use a 1280px centered content rail.
- Use 24px to 48px horizontal padding.
- Keep the full page on Paper White.
- Use no section color shifts.
- Build the hero as three zones: headline, triangle mark, metadata stack.
- Separate sections with 96px to 128px whitespace.
- Use 2-column and 3-column feature card grids.
- Keep the nav as a single 64px sticky horizontal bar.

## Imagery

- Use the triangle mark as the primary graphic.
- Use CLI output panels, light-mode product screenshots, integration cards, framework logos, and grayscale customer wordmarks.
- Avoid photography, decorative illustration, 3D renders, broad gradients, and generic icon packs.
