# Vercel

Source: Refero Styles  
URL: https://styles.refero.design/style/f24daf3a-d43f-4dec-85a9-8ac1d5148a03  
Reference site: https://vercel.com  
Captured: 2026-07-28

Vercel is a disciplined monochrome developer style: near-white paper canvas, tight Geist Sans headlines, tiny Geist Mono labels, 6px precision corners, hairline border rings, and functional product demos that look like terminal output. It should feel like a typeset engineering notebook.

Use this folder as an AI implementation brief. The most useful files are:

- `DESIGN.md` for the full style interpretation.
- `implementation-prompt.md` for a copy-ready prompt to hand to an AI builder.
- `style.json` for structured metadata.
- `code/css-variables.css` for CSS custom properties and component recipes.
- `code/tailwind-v4.css` for Tailwind v4 theme tokens.
- `code/design-tokens.json` for machine-readable tokens.

Core cues:

- Canvas: `#fafafa` Paper White.
- Elevated cards and inputs: `#ffffff` Pure White.
- Primary text/action fill: `#171717` Obsidian.
- Body copy: `#4d4d4d` Charcoal.
- Muted copy: `#666666`, `#7d7d7d`, `#8f8f8f`, `#a8a8a8`, `#c9c9c9`.
- Borders: `#ebebeb` Hairline.
- Graphic mark: `#000000` Carbon, reserved for the triangle and SVG fills.
- Accent: `#297a3a` Terminal Green for command confirmations and tiny text accents only.
- Typography: Geist Sans for reading and display, Geist Mono for labels and code.
- Shape: 6px cards, buttons, and bordered containers; 9999px only for tight nav pills.
- Depth: no drop shadows; use stacked hairline rings.

This is best for developer platforms, deployment tools, API products, infrastructure dashboards, CLI-first SaaS, docs portals, and technical product launches.
