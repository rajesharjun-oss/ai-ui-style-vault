Build requirements:

- Build an original interface inspired by the reference, not a copy of Dala.
- Do not use Dala logos, brand assets, exact screenshots, exact marketing copy, or proprietary layouts.
- Preserve the pure black canvas, oversized weight-400 headings, weight-200 body copy, sparse two-column
  layout, single violet CTA, amber emphasis, and particle-constellation hero logic.
- Use Electric Iris (`#8052ff`) for the singular primary action.
- Use Saffron Spark (`#ffb829`) for emphasis labels, highlight text, and accent links.
- Avoid cards with fills, borders, shadows, pricing-table grids, dashboard UI, product screenshots,
  decorative gradients in components, or multiple filled buttons in one view.
- Implement responsive typography so large display text does not overflow on mobile.
- Implement accessible semantics, visible keyboard focus states, loading states, empty states,
  validation states, and safe error states.
- For real apps, enforce authentication and authorization on the server, not only in the UI.
- Document assumptions, environment variables, and setup steps.

Suggested direction:

Create a spacious AI or knowledge-search landing page with a full-bleed black stage, a massive headline,
lightweight body copy, a single violet CTA, amber label text, and a custom particle-field visualization
that acts as the main brand image.
