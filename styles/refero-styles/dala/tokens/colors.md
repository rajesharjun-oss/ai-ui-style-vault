# Colors

## Brand

| Name | Value | Token | Role |
|---|---:|---|---|
| Electric Iris | `#8052ff` | `--color-electric-iris` | Primary action buttons, brand marks, active states, and the only saturated filled UI color. |

## Accent

| Name | Value | Token | Role |
|---|---:|---|---|
| Saffron Spark | `#ffb829` | `--color-saffron-spark` | Warm emphasis text, accent links, labels, and small attention marks. |
| Deep Verdant | `#15846e` | `--color-deep-verdant` | Secondary accent tint, logo/particle gradient stop, and subtle chromatic depth. |

## Neutrals

| Name | Value | Token | Role |
|---|---:|---|---|
| Void | `#000000` | `--color-void` | Full-page canvas, all section backgrounds, and the primary negative space. |
| Bone White | `#ffffff` | `--color-bone-white` | Headlines, body text, active nav text, and icon fills. |
| Ash Gray | `#9a9a9a` | `--color-ash-gray` | Muted nav text, secondary labels, ghost links, and inactive text. |
| Silver Mist | `#bdbdbd` | `--color-silver-mist` | Tertiary body text, captions, and quiet support copy. |

## Surface Levels

| Level | Name | Value | Purpose |
|---:|---|---:|---|
| 0 | Void Canvas | `#000000` | Full page and all major section backgrounds. |
| 1 | Deep Verdant Tint | `#15846e` | Subtle accent depth for brand visuals. |
| 2 | Electric Iris | `#8052ff` | Highest interactive surface for filled actions only. |

## Quick Color Reference

- **Canvas:** `#000000`
- **Primary text:** `#ffffff`
- **Secondary text:** `#9a9a9a`
- **Tertiary text:** `#bdbdbd`
- **Primary action:** `#8052ff`
- **Emphasis:** `#ffb829`
- **Borders:** none by default
