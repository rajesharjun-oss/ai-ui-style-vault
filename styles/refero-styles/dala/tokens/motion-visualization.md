# Motion And Visualization

## Particle Visualization

- Use a dense constellation of small outlined triangles.
- Let particles form an organic neural, brain, cloud, or distributed-knowledge shape.
- Use violet, amber, teal, magenta, blue, and nearby saturated colors.
- Keep particle strokes thin, around `1px` to `2px`.
- Add sparse ambient particles around the main shape at lower opacity.
- The visualization can animate slowly, but should feel quiet and atmospheric.

## Motion Rules

- Use restrained motion that feels like drifting intelligence, not a game effect.
- Avoid bouncy transitions, heavy parallax, and busy background motion.
- Primary button hover should be simple: slight brightness, text clarity, or subtle transform.
- Navigation hover can move inactive gray links to white.
- Respect reduced-motion preferences.

## Implementation Hint

For a web build, use canvas, SVG, or WebGL for the particle field. Generate an original shape using
noise, point-cloud masks, or scripted geometry rather than copying a screenshot.
