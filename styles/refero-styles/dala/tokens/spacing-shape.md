# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Density | comfortable |
| Base unit | `6px` |
| Max width | `1280px` |
| Section gap | `60px` to `120px` |
| Card padding | `24px` to `38px` |
| Element gap | `6px` to `18px` |

## Elevation

- Use no shadows.
- Use no borders or dividers by default.
- Let whitespace, scale, and color contrast create hierarchy.
- Elements should feel like they float on the black stage.

## Shape Rules

- Use `24px` as the shared soft radius.
- Buttons feel pill-like because their height is compact relative to the radius.
- Portraits use rounded rectangles, usually near `24px`.
- Do not use framed cards or bordered containers as a layout crutch.
