# Dala - Design Reference

> Pure black AI brand stage with oversized weight-400 typography, ultra-light body copy, a single violet
> action color, amber emphasis, and a vivid particle constellation as the hero identity.

## Theme

Dala is a dark-stage AI product style. The page uses true black as the only large surface, then lets
large white type, one violet CTA, amber emphasis marks, and a procedural constellation visual carry the
entire brand impression.

The design should feel spacious, sculptural, and quiet. It avoids dashboards, cards, pricing grids,
product screenshots, borders, shadows, and dense UI. The main layout language is oversized left-aligned
typography paired with a large abstract particle visual.

## Core Visual Rules

- Keep all major sections on `#000000`.
- Use `#8052ff` as the only filled button/background accent.
- Use `#ffb829` for warm emphasis, small labels, or highlight links.
- Use PPNeueMontreal-style typography: huge weight-400 headings and 18px weight-200 body text.
- Let scale and whitespace create hierarchy; avoid bold type and containers.
- Use particle/constellation visuals as the signature imagery.
- Keep components minimal: one primary pill, ghost text links, image/portrait blocks, and typographic sections.

## Implementation Notes

Start from `code/css-variables.css` or `code/tailwind-v4.css`. Build primitives for a pure black stage,
large responsive display headings, ultra-light body copy, violet pill CTAs, ghost links, particle-field
visuals, team portrait cards, and minimal carousel indicators.

For original work, keep the system logic but replace source-specific brand marks, screenshots, names,
copy, and exact compositions.
