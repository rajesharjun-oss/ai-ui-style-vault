# Components

## Primary Filled Button

- Background: `#dad7de`
- Text: `#08080a`
- Radius: 3px
- Padding: about 8px 14px
- Font: system stack, 14px, weight 500
- Shadow: `#31313a 0 -1px 0 0`
- Use for main actions such as sign up or start creating.

## Ghost Or Outlined Button

- Background: transparent
- Border: 1px solid Fog or Pearl
- Text: Pearl
- Radius: 3px
- Use for secondary navigation actions.

## Chromatic Link

- Text: Pearl
- Underline: 1px Lavender Beam or Iris Glow border-bottom
- Use as the only chromatic signal in body content.
- Keep the text itself neutral.

## Announcement Pill

- Fill: dark surface
- Border: thin Pearl at low opacity
- Radius: 3px
- Font: system stack, 13px
- May include a tiny Lavender Beam dot or star.
- Place above hero headlines or feature cards.

## Hero Gradient Banner

- Base: Void
- Atmosphere: lower-center violet radial gradient
- Stack: eyebrow pill, Overused Grotesk headline, 18px subhead, primary filled button.
- Use generous vertical breathing room.
- Keep the aurora as the only atmospheric image.

## Card Surface

- Fill: Graphite or transparent over Charcoal panel.
- Radius: 10px
- Border: 1px Pearl at low opacity.
- Padding: 30px
- Use for feature blocks, content cards, and gallery items.

## Social Proof Logo Strip

- Logos: monochrome Ash or Fog.
- Label: small muted Ash text.
- Layout: centered horizontal row.
- No colored logos.

## Navigation Bar

- Transparent over Void.
- Left: logo glyph and wordmark in Pearl.
- Right: text links, primary Sign Up, ghost Login.
- Vertical padding: about 16px.
- Item gaps: about 19px.
- Not sticky by default.

## Text Input

- Background: Graphite.
- Border: 1px Fog.
- Radius: 3px.
- Font: system stack, 14px.
- Placeholder: Ash.
- Focus border: Lavender Beam.

## Icon

- Stroke-based, 1px to 1.5px.
- Default: Fog.
- Active: Pearl.
- No filled or multicolor icon styles.

## Section Header Stack

- Centered stack.
- Heading: 48px to 64px Overused Grotesk in Chalk.
- Subhead: 18px system font in Fog.
- Optional action below.
- Spacing: 40px to 60px between major elements.
