# Colors

## Accent

| Name | Value | Use |
|---|---:|---|
| Lavender Beam | `#ab8ff1` | Link underlines, focus states, accent strokes, aurora highlight |
| Iris Glow | `#8960f0` | Link hover, deeper aurora endpoint, violet emphasis |
| WebGL Aurora | `radial-gradient(circle, rgb(142, 108, 228), rgb(114, 79, 201))` | Hero atmospheric light burst |

## Neutrals

| Name | Value | Use |
|---|---:|---|
| Void | `#08080a` | Page canvas and deepest surface |
| Charcoal | `#0d0d12` | Section backgrounds, panels, modals |
| Graphite | `#17171c` | Card surfaces and nested containers |
| Slate | `#25252d` | Elevated surface fill and hover states |
| Iron | `#31313a` | Dividers, secondary UI, key-line shadow |
| Ash | `#62626f` | Muted helper text and inactive icons |
| Fog | `#8b8e9c` | Secondary text, placeholders, icon strokes |
| Pearl | `#aeaac0` | Primary body text, card borders, dominant foreground |
| Chalk | `#dad7de` | Bright display text, borders, cream CTA fills |

## Rules

- Use violet only for links, focus states, accent strokes, and the aurora.
- Do not fill buttons with violet.
- Use the neutral stack for depth.
- Use Chalk for primary filled buttons.
- Do not add extra chromatic colors.
- Do not promote Iron or Chalk into unrelated CTA treatments.
