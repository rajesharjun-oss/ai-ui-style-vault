# Implementation Prompt

Build a dark creative software interface in the Unicorn Studio style.

Use a matte black canvas `#08080a`, then create depth with tiny steps: Charcoal `#0d0d12`, Graphite `#17171c`, and Slate `#25252d`. Avoid heavy drop shadows. Primary body text should be Pearl `#aeaac0`, muted helper text Ash `#62626f`, and bright display text Chalk `#dad7de`.

Use a violet WebGL aurora as the only atmospheric image: a lower-center radial gradient from violet to iris on the dark canvas. Use Lavender Beam `#ab8ff1` and Iris Glow `#8960f0` for link underlines, focus states, and the aurora. Do not make violet-filled buttons or large decorative UI blocks.

Use Overused Grotesk or a tight display sans for headings. Apply aggressive negative tracking: around -0.063em at 64px and above, -0.040em at 32-48px, and -0.030em around 26px. Keep weights 400-500. Use the system stack for body/UI at 16px, line-height 1.4, and tracking around -0.01em.

Use 3px radius for buttons, tags, inputs, and announcement pills. Use 10px radius only for cards. Primary buttons are light cream `#dad7de` with near-black text `#08080a`, compact padding, and a dark cap-edge key-line `box-shadow: #31313a 0 -1px 0 0`. Secondary buttons are transparent with Pearl or Fog borders.

Avoid friendly rounded SaaS shapes, colored CTA fills, heavy shadows, extra accent colors, weights above 600, line-height above 1.4 for body, and state communication based on more color. The result should feel architectural, precise, and atmospheric.
