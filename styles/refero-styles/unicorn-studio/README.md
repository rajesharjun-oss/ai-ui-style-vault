# Unicorn Studio

Unicorn Studio is a near-black WebGL/editorial style system: smoked-glass surfaces, prismatic violet aurora light, tightly tracked Overused Grotesk headlines, pearl-gray copy, cream primary buttons, and sharp 3px UI controls.

- Source: https://styles.refero.design/style/6bd8007f-01bc-46cc-8599-b396a39c1474
- Reference site: https://www.unicorn.studio
- Captured: 2026-07-28
- Theme: dark
- Best for: WebGL tools, creative coding products, 3D design platforms, portfolio builders, atmospheric software sites

## Use This When Building

Use near-black value steps for depth and a single violet aurora as the chromatic voice. Keep primary actions light cream on dark, never violet-filled. Use Overused Grotesk or a tight display sans with aggressive negative tracking, system-font body copy, 10px cards, 3px buttons, and violet only for link underlines, focus states, and hero atmosphere.
