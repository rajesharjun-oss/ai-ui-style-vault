# Unicorn Studio - Style Reference

Unicorn Studio feels like violet WebGL light behind smoked glass. Most of the system is nearly black, but the hero lets one prismatic aurora break through the void.

## Visual Thesis

- Use a matte near-black canvas.
- Communicate depth through subtle surface value steps.
- Let violet appear as aurora light, link underline, or focus state only.
- Keep primary actions light cream on dark.
- Use 3px micro-radii for buttons, tags, and inputs.
- Use 10px radius only for cards.
- Use extremely tight display tracking.
- Let type and one atmospheric gradient do the visual work.

## Core Ingredients

- Canvas: Void `#08080a`.
- Panel step: Charcoal `#0d0d12`.
- Card step: Graphite `#17171c`.
- Elevated step: Slate `#25252d`.
- Foreground: Pearl `#aeaac0`, Chalk `#dad7de`.
- Accent: Lavender Beam `#ab8ff1` and Iris Glow `#8960f0`.
- Hero visual: radial violet WebGL aurora.
- Primary button: Chalk fill with Void text and dark key-line.

## Page Composition

Use a minimal transparent nav over the canvas, then a centered hero with an eyebrow pill, tight 64px display headline, 18px muted subheading, cream CTA, and lower-center violet radial aurora. Follow with logo strip, centered section headers, and content cards on dark value-stepped surfaces.

## Color Behavior

This is monochrome plus violet. Lavender Beam is not a general CTA color and should not fill buttons. Violet should be the path, the focus signal, and the aurora. Most interaction states should use border opacity, text opacity, or surface shifts instead of more color.

## Type Behavior

Overused Grotesk is the signature display face. Use large size and tight tracking instead of heavy weight. System font handles body, UI, navigation, buttons, and cards with subtle -0.01em tracking.
