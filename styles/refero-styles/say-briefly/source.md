This bundle paraphrases the Refero style reference into implementation notes for AI-assisted UI building. It preserves the system intent, color roles, typography behavior, spacing, component recipes, layout rhythm, and visual constraints without copying the source text wholesale.

## What To Preserve

- Cream Paper canvas.
- Forest Ink as the sole structural color.
- Highlighter Yellow marker wash behind words, not CTA fill.
- Bricolage Grotesque display headlines with positive tracking.
- Inter for functional UI and body.
- Roboto Mono for micro-labels and metadata.
- 6px button radius, 12px card radius, 16px nav radius.
- Minimal shadows, except subtle button lift and yellow nav glow.
