# Implementation Prompt

Build a polished creative-studio interface inspired by the Say Briefly Refero style system.

Use Cream Paper, Forest Ink, chunky Bricolage Grotesque display headlines, Inter UI text, Roboto Mono micro-labels, yellow marker-style word highlights, and scattered sticky-note pastel cards. The experience should feel like a smart agency sketchbook: warm, handmade, and clear.

## Required Style Decisions

- Page canvas: Cream Paper `#fcfaf5`.
- Primary text, links, borders, and CTAs: Forest Ink `#1a3300`.
- Word highlight wash: Highlighter Yellow `#ffe95c`.
- Hairlines: Pencil Gray `#b6b6b6`.
- Muted helper copy: Whisper Gray `#f1f1f1`.
- Pastels: Sticky Note Teal `#a8e5e5`, Mint `#d5f5c2`, Blush `#f6d0ff`, Terracotta `#cb5521`.
- Display font: Bricolage Grotesque, weight 800.
- UI/body font: Inter.
- Mono labels: Roboto Mono.
- Button radius: 6px.
- Card radius: 12px to 16px.
- Nav radius: 16px.
- Tags: 9999px.

## Typography Direction

Use Bricolage Grotesque only for large display type, at 55px to 90px, weight 800, line-height 1, and positive 0.04em to 0.05em tracking. Use Inter for body, buttons, nav, subheads, and cards. Use Roboto Mono for utility labels and technical metadata.

## Layout Direction

Create:

- A warm cream canvas.
- A rounded nav bar with a Pencil Gray border and subtle yellow glow.
- A centered hero with a small yellow badge, chunky headline, highlighted words, subhead, CTA, reassurance caption, and logo strip.
- Sticky-note feature cards in sparse pastel fills.
- Hand-drawn sketch elements as background atmosphere.
- 64px section rhythm and 16px element gaps.

## Avoid

- Bricolage below 40px.
- Highlighter Yellow as CTA fill.
- A second primary brand color.
- Heavy shadows.
- Sharp 0px corners.
- Large pastel section backgrounds.
- Glossy 3D or polished SaaS gradients.
