# Layout And Imagery

## Layout

- Canvas: Cream Paper.
- Max width: 1200px.
- Section gap: 64px.
- Element gap: 16px.
- Hero: centered badge, chunky display headline, subhead, CTA, reassurance caption, and logo strip.
- Navigation: rounded cream container with border and yellow glow.
- Cards: sticky-note-like blocks in sparse pastel fills.

## Imagery And Illustration

Use:

- Hand-drawn line sketches.
- Tiny playful icons.
- Marker-highlight treatments.
- Sticky-note card surfaces.
- Simple doodle-like decorations.

Avoid:

- Glossy 3D.
- Heavy gradients.
- Stock photography as the main visual language.
- Corporate SaaS illustration packs.
- Large decorative pastel floods.

## Composition Notes

The style can be playful, but it still needs strong hierarchy. Use Forest Ink to keep the page legible and grounded, then add yellow and pastel accents as expressive punctuation.
