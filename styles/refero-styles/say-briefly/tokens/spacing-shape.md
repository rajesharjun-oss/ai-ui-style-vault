## Shadows

Use shadows sparingly. Subtle button lift is allowed; heavy drop shadows are not. The nav can use a large low-opacity yellow glow as a signature atmospheric effect.

```css
--shadow-subtle: rgba(0, 0, 0, 0.05) 0px 1px 2px 0px;
--shadow-subtle-2: rgba(0, 0, 0, 0.1) 0px 1px 3px 0px, rgba(0, 0, 0, 0.1) 0px 1px 2px -1px;
--shadow-nav-glow: rgba(255, 235, 90, 0.01) 0px 527px 211px 0px, rgba(255, 235, 90, 0.05) 0px 297px 178px 0px, rgba(255, 235, 90, 0.09) 0px 132px 132px 0px, rgba(255, 235, 90, 0.1) 0px 33px 72px 0px;
```
