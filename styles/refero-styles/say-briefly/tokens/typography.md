# Typography

## Fonts

- Display: `Bricolage Grotesque`
- Display fallback: `Archivo Black`, `Mulish`, `ui-sans-serif`, `system-ui`
- UI/body: `Inter`
- UI fallback: `system-ui`, `-apple-system`, `Segoe UI`, `sans-serif`
- Mono: `Roboto Mono`
- Mono fallback: `JetBrains Mono`, `IBM Plex Mono`, `ui-monospace`, `monospace`

## Display Behavior

Use Bricolage Grotesque only for display headlines. It should be weight 800, large, line-height 1, and positively tracked. Do not use it below 40px or for body and controls.

## UI Behavior

Use Inter for functional text: nav, buttons, body, cards, subheads, labels, and captions. Use Roboto Mono for micro-labels and technical metadata.

## Rules

- Do not use Bricolage for body, nav, buttons, or small UI.
- Use 18px to 20px Inter body copy with 1.5 line height for comfortable reading.
- Use Inter 500 to 600 for labels and subheads.
- Use Inter 700 only where strong section labeling is needed.
- Use mono only for utility or technical label moments.
