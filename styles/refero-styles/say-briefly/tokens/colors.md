# Colors

## Palette

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Forest Ink | `#1a3300` | `--color-forest-ink` | Primary text, CTA fill, links, nav borders, card borders |
| Highlighter Yellow | `#ffe95c` | `--color-highlighter-yellow` | Word highlight wash, badge backgrounds, accent fills |
| Cream Paper | `#fcfaf5` | `--color-cream-paper` | Page canvas, card surfaces, nav background |
| Pencil Gray | `#b6b6b6` | `--color-pencil-gray` | Nav borders and quiet dividers |
| Whisper Gray | `#f1f1f1` | `--color-whisper-gray` | Muted helper text and secondary labels |
| Sticky Note Teal | `#a8e5e5` | `--color-sticky-note-teal` | One-off pastel action or selected state |
| Sticky Note Mint | `#d5f5c2` | `--color-sticky-note-mint` | One-off pastel action or selected state |
| Sticky Note Blush | `#f6d0ff` | `--color-sticky-note-blush` | Decorative card or button fill |
| Terracotta | `#cb5521` | `--color-terracotta` | Warm decorative card accent |

## Usage

Forest Ink is the only chromatic authority. Highlighter Yellow is a marker wash and should not become the CTA color. Pastels are sticky-note accents for individual cards or secondary paths, never full-section themes.
