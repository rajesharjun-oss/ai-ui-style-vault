# LUNCH

LUNCH is a fashion-editorial commerce style system: one dark cinematic runway hero, a singular chrome wordmark moment, then a quiet warm-parchment catalog with sharp product photography, underlined text links, and lilac used as a restrained brand punctuation.

- Source: https://styles.refero.design/style/cd3fbf9d-8d35-411b-9e69-89a03018b677
- Reference site: https://lunchconcept.com
- Captured: 2026-07-28
- Theme: mixed
- Best for: fashion concept stores, editorial lookbooks, boutique commerce, product galleries, art-directed catalogs

## Use This When Building

Use photography as the visual engine. Open with a full-bleed dark hero and one oversized wordmark spectacle, then switch to a warm parchment product gallery with nearly invisible UI. Keep all corners square, avoid filled buttons, and make interaction feel like underlined editorial text.
