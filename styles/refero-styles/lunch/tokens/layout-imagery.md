# Layout And Imagery

## Layout

- Hero is full-bleed and viewport-height.
- Post-hero sections use a centered max-width around 1280px.
- Intro copy sits in a narrow 600px to 700px centered column.
- Product gallery uses 4-5 columns with 5px gutters.
- Vertical breathing room is 60px to 80px in editorial sections.
- Product grid density is compressed and flush.
- Footer closes with a full-width Lilac Veil band.

## Imagery

- Use dramatic full-bleed fashion photography in the hero.
- Use dark, high-contrast studio lighting for the opening image.
- Use clean product or lookbook photography on light backgrounds for the grid.
- Keep images sharp-edged and flush with adjacent images.
- Avoid illustration, icon systems, abstract graphics, and decorative UI images.
- Let the hero wordmark overlap the subject.

## Surfaces

| Level | Name | Value | Purpose |
|---|---|---:|---|
| 0 | Editorial Canvas | `#f4f1e4` | Intro, product grid, post-hero content |
| 1 | Hero Void | `#000000` | Dark full-bleed photographic hero context |
| 2 | Ivory Mist | `#fcfaf1` | Light warm surface and product panels |
| 3 | Brand Whisper | `#b8aad0` | Announcement bar, footer, sold-out state |

## Motion

- Keep movement minimal and editorial.
- Use basic opacity or image reveal transitions if needed.
- Avoid playful motion, hover bounces, parallax, and animated gradients.
