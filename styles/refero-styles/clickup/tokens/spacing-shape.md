# Spacing And Shape

## Spacing

| Token | Value | Use |
| --- | ---: | --- |
| `unit` | 4px | Base spacing unit |
| `4` | 4px | Compact nav pill padding |
| `8` | 8px | Tight row gaps |
| `12` | 12px | Element gap, check list gap |
| `16` | 16px | Card and badge padding |
| `20` | 20px | Ghost button horizontal padding |
| `24` | 24px | CTA padding and large local gap |
| `28` | 28px | Card padding |
| `32` | 32px | Screenshot card/image gap |
| `40` | 40px | Dark feature padding low end |
| `48` | 48px | Large type/layout rhythm |
| `52` | 52px | Display size and spacing token |
| `56` | 56px | Display size and spacing token |
| `72` | 72px | Large block spacing |
| `80` | 80px | Section gap |
| `100` | 100px | Large layout rhythm |
| `max-width` | 1200px | Page container |

## Radius

| Token | Value | Use |
| --- | ---: | --- |
| `input` | 9px | Inputs and compact fields |
| `card` | 12px | Standard cards and dark feature cards |
| `image` | 16px | Product screenshot and image corners |
| `large-card` | 20px | Large dark or premium feature surfaces |
| `tag` | 100px | Feature tags |
| `badge` | 9999px | Status badges |
| `button` | 9999px | Primary, secondary, and nav buttons |

## Shape Rules

- Buttons, badges, and tags are fully pill-shaped.
- Do not mix square and pill buttons in the same control group.
- Use 12px cards and 16px screenshots.
- Use 20px for large feature cards only.
