## Usage Rules

- Use `#202020` instead of pure black for large text and filled actions.
- Use violet only for brand identity and short badge/status moments.
- Use blue for links, outlines, checkmarks, and active tag text.
- Keep the general UI grayscale.
- Use gradients only for signature premium effects, not normal cards.
