# Layout And Imagery

## Layout

- Use a centered 1200px max-width container.
- Top flow: announcement bar, nav, hero split, social proof logos, illustration section, awards grid, stats, footer.
- Hero uses two columns.
- Left hero column: large 80px headline, benefit check list, filled dark CTA, feature tag pills.
- Right hero column: dense product screenshot at full column width.
- Section gaps: about 80px.
- Internal gaps: 8px to 12px.
- Award sections can use text left and badge grid right.
- Stats bands use oversized numbers and compact captions.

## Imagery

Use:

- Product UI screenshots.
- Task rows, inbox panels, docs, chats, dashboards.
- Status pills and avatar clusters.
- Grayscale trusted-by logos.
- Award badge grids.
- Gray line-art illustrations as secondary visuals.

Avoid:

- Lifestyle photography.
- Stock people photos.
- Abstract hero gradients replacing product UI.
- Hero videos.
- Heavy decorative illustration systems.

## Gradient And Motion Notes

- Conic rainbow border is the main expressive animated moment.
- Use it on one hero CTA or premium feature element.
- Primary cyan-to-magenta gradient can appear in premium text or brand word treatment.
- Dark fade belongs on contrast panels.
- Keep continuous motion limited to one focal element per viewport.
