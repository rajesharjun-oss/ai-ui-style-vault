## Use This Style When

Use ClickUp when the interface should feel like a high-confidence productivity dashboard brochure: clean white canvas, oversized bold claims, dense real product UI, status pills, avatar clusters, and compact rounded controls. It fits productivity tools, project management apps, workflow platforms, task dashboards, and SaaS pages that need to show busy software clearly.

## Quick DNA

- White canvas with grayscale structure and occasional pale gray section bands.
- Near-black filled pill CTA as the main action.
- Brand violet is for identity badges and short status moments, not primary CTAs.
- Signal blue is for links, outlined actions, checkmarks, and lightweight interactivity.
- Plus Jakarta Sans display headings at 48px to 80px with heavy weight and tight negative tracking.
- Buttons, tags, badges, and avatars use full pill/circle geometry.
- Real product screenshots anchor the page.
- One rotating conic-gradient border can appear per section as the expressive brand moment.
