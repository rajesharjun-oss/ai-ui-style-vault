# Implementation Prompt

Build a UI in the ClickUp style.

Create a bright productivity dashboard brochure with a white canvas, huge heavy Plus Jakarta Sans headlines, compact pill controls, a black primary CTA, real product screenshots, status pills, avatar clusters, grayscale social proof, and one expressive conic-gradient border effect.

Use these hard rules:

- Canvas: `#ffffff`.
- Main heading and primary CTA fill: `#202020`.
- Maximum display/stat text: `#090c1d`.
- Secondary text: `#646464`.
- Tertiary text: `#838383`.
- Default border: `#e8e8e8`.
- Hairline border: `#d4d4d4`.
- Card surface: `#f8f9fa`.
- Section band: `#e9ebf0`.
- Brand violet: `#6647f0`.
- Signal blue: `#0091ff`.
- Use Brand Violet only for identity badges, Brain-style tags, and short brand/status labels.
- Do not use violet as a primary CTA fill.
- Use Signal Blue only for links, outlined action borders, checkmarks, and active tag text.
- Use `#202020`, not pure black, for large text and primary filled buttons.
- Buttons, badges, tags, and nav pills should use 9999px pill radius.
- Cards use 12px radius; large cards use 20px.
- Product screenshots use 12px to 16px radius and can be slightly lifted.
- Use Plus Jakarta Sans at 650 to 800 for display text 34px and above.
- Use tracking around `-0.04em` for 48px and larger display text.
- Use Inter for body, captions, and dense card text.
- Use Sometype Mono only for uppercase tracking-wide labels.
- Maintain a 4px spacing base.

Build a two-column hero. The left column should contain an 80px display headline, checkmark benefit list, black filled pill CTA, and feature tag pills. The right column should show a real product dashboard screenshot with dense task rows, status pills, avatars, side navigation, and panels. Add a trusted-by grayscale logo row and later sections for awards, stats, and a dark feature panel. Use one conic-gradient border element per section at most.
