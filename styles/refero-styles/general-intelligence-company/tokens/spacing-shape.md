# Spacing And Shape

## Spacing

| Purpose | Value |
| --- | --- |
| Density | comfortable |
| Base unit | 4px |
| Max width | 1200px |
| Section gap | 32px to 64px |
| Editorial vertical gap | 64px to 96px |
| Card padding | 16px |
| Element gap | 8px to 12px |

## Scale

`4px`, `8px`, `12px`, `16px`, `20px`, `24px`, `32px`, `40px`, `48px`, `64px`, `80px`

## Radius

| Element | Value |
| --- | --- |
| Button | 4px or 8px |
| Card | 12px or 16px |
| Diagram card | 16px |
| Large illustrated surface | 24px |
| Nav pill | 50px |

## Shape Rules

- Use 8px for most controls.
- Use 12px to 16px for white content cards.
- Use 24px for large illustrated panels and frosted hero cards.
- Reserve full pill geometry for the floating nav only.
