# Colors

## Brand

| Name | Value | Role |
| --- | --- | --- |
| Signal Blue | `#41a1cf` | Action outline, link accent, and small interaction emphasis. |
| Cerulean | `#0081c0` | Rare saturated atmospheric surface, not normal UI chrome. |

## Neutrals

| Name | Value | Role |
| --- | --- | --- |
| Ink Black | `#171717` | Strong text and foreground. |
| Dusk | `#1f1f29` | Rare filled dark button or deep surface. |
| Twilight | `#282834` | Neutral outlines, nav border, icon strokes. |
| Graphite | `#2c2c2c` | Headings and important body text. |
| Charcoal | `#444141` | Standard body text and UI labels. |
| Ash | `#646464` | Muted descriptions and helper copy. |
| Fog | `#b4b8b4` | Disabled states and tertiary borders. |
| Mist | `#dee2de` | Signature green-tinted hairline border. |
| Linen | `#f9faf7` | Inputs and subtle surface wash. |
| Parchment | `#fefffc` | Warm page canvas. |
| Paper | `#ffffff` | Cards, footer, and clean content sections. |

## Rules

- Keep the interface 95 percent neutral.
- Use Signal Blue as a line, link, or outline.
- Use Cerulean only when a section needs a rare atmospheric color moment.
- Prefer warm near-blacks over `#000000`.
- Use `#dee2de` repeatedly so the edge language feels intentional.
