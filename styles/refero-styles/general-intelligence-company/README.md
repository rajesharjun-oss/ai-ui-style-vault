Reference site: https://www.generalintelligencecompany.com

Captured: 2026-07-28

## Use This Style When

Use General Intelligence Company when an interface should feel like a literary AI company, research journal, or thoughtful editorial product. It works best for calm intelligence tools, founder-facing sites, research labs, technical writing, and agent products that need confidence without looking like a loud SaaS dashboard.

## Quick DNA

- Warm parchment page canvas with clean white content sections.
- Custom display serif does the emotional work above 27px.
- Compact neutral sans handles body, navigation, labels, and buttons.
- Palette is mostly warm neutrals with one blue outline accent.
- Borders are green-tinted 1px hairlines.
- Navigation is a floating frosted pill.
- Illustrated scenes and diagram cards create the page rhythm.
- Buttons stay quiet: transparent outlines first, dark fill only rarely.
