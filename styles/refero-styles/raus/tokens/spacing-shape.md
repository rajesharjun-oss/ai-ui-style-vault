# Spacing And Shape

## Spacing

| Purpose | Value | Notes |
|---|---:|---|
| Density | comfortable | Calm booking flow |
| Base unit | 4px | Token foundation |
| Max width | 1200px | Centered layout |
| Section gap | 96px | Major vertical rhythm |
| Element gap | 16px | Cards, controls, metadata |
| Card padding | 24px to 32px | Cabin and editorial cards |
| Booking panel width | 360px | Desktop side panel |
| Map marker size | 40px | Circular marker buttons |
| CTA padding | 12px 20px | Primary booking pill |

## Shape

| Element | Radius | Notes |
|---|---:|---|
| Cards | 20px | Standard location and editorial cards |
| Booking card | 24px | Main booking panel |
| Buttons | 9999px | Full pill |
| Inputs | 12px | Date and search controls |
| Map markers | 9999px | Circular or pill markers |

## Elevation

Card shadow:

```css
0 20px 50px -24px rgba(37, 35, 31, 0.08)
```

Map marker shadow:

```css
0 8px 20px -8px rgba(37, 35, 31, 0.25)
```

Keep shadows warm, soft, and low-contrast.
