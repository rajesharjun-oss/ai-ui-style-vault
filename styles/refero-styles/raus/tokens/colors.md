# Colors

| Name | Value | Token | Role |
|---|---:|---|---|
| Charcoal Ink | `#25231f` | `--color-charcoal-ink` | Primary text, headings, dark UI, map labels |
| Warm Paper | `#f7f4ed` | `--color-warm-paper` | Page canvas and main warm background |
| Pure White | `#ffffff` | `--color-pure-white` | Elevated cards, nav surfaces, modal surfaces |
| Parchment Border | `#e8e0d2` | `--color-parchment-border` | Hairline borders, input outlines, separators |
| Stone Gray | `#8f887d` | `--color-stone-gray` | Secondary text, metadata, helper copy |
| Campfire Ochre | `#c98a3f` | `--color-campfire-ochre` | Primary booking CTA and warm action highlights |
| Forest Green | `#1f4f3a` | `--color-forest-green` | Map markers, nature icons, selected location accents |
| Sand | `#d8c6a3` | `--color-sand` | Map panels, contour-line backgrounds, muted outdoor washes |
| Linen Wash | `#f1ece3` | `--color-linen-wash` | Muted section bands, input fills, nested panels |
| Taupe | `#b7a98d` | `--color-taupe` | Disabled states, tertiary labels, inactive map detail |

## Guidance

- Use Warm Paper as the page canvas.
- Use Charcoal Ink for text rather than hard black.
- Use Campfire Ochre for the main booking CTA only.
- Use Forest Green for map markers and outdoor accents.
- Use Sand and Linen Wash for map and section surfaces.
- Avoid generic travel blue and neon accents.
