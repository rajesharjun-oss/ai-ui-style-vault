# Typography

Primary family: `"Inter", system-ui, sans-serif`

Optional mono family: `ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`

## Roles

| Role | Size | Weight | Line Height | Tracking | Use |
|---|---:|---:|---:|---:|---|
| Micro | 12px | 500 | 1.33 | 0 | Map labels, metadata, tiny tags |
| Small UI | 14px | 500 | 1.43 | 0 | Nav, filters, buttons |
| Body | 16px | 400 | 1.6 | 0 | Descriptions and main copy |
| Lead | 18px | 400 | 1.55 | 0 | Intro copy and hero support |
| Card Title | 24px | 600 | 1.25 | -0.01em | Cabin cards and booking titles |
| Section | 40px | 600 | 1.1 | -0.03em | Major section headings |
| Hero | 64px | 600 | 0.95 | -0.05em | First-screen headline |

## Guidance

- Keep typography quiet, clear, and non-decorative.
- Use monospace only for coordinates or technical map details.
- Do not use ornate travel serif typography.
- Do not use tiny body text for booking details.
