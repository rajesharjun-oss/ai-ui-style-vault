# Raus

Trail-map cabin ledger: a warm travel booking style with paper surfaces, topographic map panels, rounded cabin cards, forest-green markers, and a single campfire-ochre action color.

Use this style when you want a travel, outdoor stay, cabin booking, retreat, hospitality, map-led marketplace, or nature-adjacent planning interface to feel calm, tactile, and quietly premium.

## Files

- `source.md`: Source URL, reference site, capture notes, and scope.
- `DESIGN.md`: Human-readable design breakdown.
- `implementation-prompt.md`: Prompt for an AI builder to implement the style.
- `style.json`: Structured design metadata.
- `tokens/`: Markdown token notes by category.
- `code/`: CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md`: Placeholder for future manual screenshots.

## Quick Use

1. Use `Warm Paper` as the main canvas.
2. Use `Charcoal Ink` for text, not harsh black.
3. Use `Campfire Ochre` for the main booking CTA.
4. Use `Forest Green` for map markers, location icons, and nature accents.
5. Use rounded cabin cards, topographic map panels, and product-real stay imagery.
6. Keep the interface warm, quiet, and map-led.
