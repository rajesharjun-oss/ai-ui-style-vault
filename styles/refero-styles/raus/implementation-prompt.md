# AI Implementation Prompt

Build a polished, responsive interface in the Raus style.

The interface should feel like a warm cabin booking ledger laid over a folded trail map. Use a paper canvas, rounded stay cards, custom topographic map panels, forest-green location markers, and one campfire-ochre booking action.

Core rules:

- Use `#f7f4ed` as the page canvas.
- Use `#25231f` for primary text instead of pure black.
- Use `#ffffff` for elevated booking cards and modal surfaces.
- Use `#e8e0d2` for hairline borders and input outlines.
- Use `#8f887d` for secondary copy.
- Use `#c98a3f` for the main booking CTA and warm action highlights.
- Use `#1f4f3a` for map markers, selected location states, and nature accents.
- Use 9999px pill buttons, 20px cards, 24px booking panels, and 12px inputs.
- Use real cabin/nature photography and custom topographic linework.
- Avoid default map tiles, generic hotel marketplace blue, glossy effects, and dense table layouts.

Recommended layout:

1. Warm top navigation with simple text links and an ochre booking CTA.
2. Hero or search section with a large topographic map panel and booking/search controls.
3. Map/list split for browsing cabins or stays.
4. Rounded location cards with image, price pill, metadata, and soft shadow.
5. Sticky booking panel with dates, guests, price details, and one ochre CTA.
6. Editorial sections with quiet nature photography and trail-map details.

Make the experience feel calm, grounded, outdoorsy, and easy to book.
