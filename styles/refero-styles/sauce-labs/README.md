# Sauce Labs

Sauce Labs is a dark engineering-console style system: obsidian green-black canvas, crisp white type, neon-green action signals, bright mint content cards, large rounded product panels, and isometric testing/product illustrations.

- Source: https://styles.refero.design/style/d271a6c4-942f-4abf-a3de-66795f15f031
- Reference site: https://saucelabs.com
- Captured: 2026-07-28
- Theme: dark
- Best for: developer tools, QA platforms, testing dashboards, enterprise engineering SaaS, AI operations pages

## Use This When Building

Use a deep obsidian canvas with light mint cards as the main rhythm. Reserve Neon Pulse for primary actions, active tabs, stat numbers, announcement strips, and conversion moments. Use big pill buttons, 60px large cards, 20px nested cards, uppercase micro-eyebrows, and isometric product mockups.
