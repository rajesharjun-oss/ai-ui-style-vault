# Colors

## Brand And Accents

| Name | Value | Use |
|---|---:|---|
| Neon Pulse | `#3ddc91` | Filled primary buttons, selected states, active tabs, stat numbers, announcement bars |
| Mint Whisper | `#97ddbc` | Green wash for illustrations, soft emphasis, and highlight backgrounds |
| Signal Yellow | `#ffcd48` | Warm accent inside isometric illustrations and product mockups |

## Neutrals And Surfaces

| Name | Value | Use |
|---|---:|---|
| Pure Black | `#000000` | SVG icon fills and high-contrast decorative strokes |
| Charcoal | `#070f0f` | Maximum-contrast overlays and modals |
| Deep Abyss | `#0e1a19` | Nested dark cards, logo tiles, dark surface depth |
| Obsidian Shell | `#132322` | Primary page background, navigation, dark structural canvas |
| Graphite Fill | `#424f4f` | Icon fills and decorative SVG strokes on light sections |
| Slate Text | `#828786` | Muted copy, captions on light backgrounds, secondary labels |
| Stone Border | `#b2b6b4` | Medium borders and secondary dividers on light cards |
| Fog Border | `#d0d3d3` | Hairline dividers and quiet borders on light surfaces |
| Mint Frost | `#edf7f5` | Light content cards, feature panels, bright counterpoint surfaces |
| Pure White | `#ffffff` | Text on dark surfaces, product screenshot panels, light canvases |

## Rules

- Use Neon Pulse only for action or live signal.
- Do not use green for decorative non-interactive elements.
- Use Mint Frost as a card surface, not as the page canvas.
- Use Deep Abyss for nested depth inside Obsidian Shell.
- Keep Signal Yellow inside illustrations and mockups.
- Do not add additional chromatic accent colors.
