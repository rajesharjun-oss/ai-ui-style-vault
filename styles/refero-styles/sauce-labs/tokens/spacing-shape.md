# Spacing And Shape

## Spacing

- Density: comfortable
- Base unit: 8px
- Max width: 1200px
- Section gap: 80px
- Card padding: 24px
- Element gap: 24px

## Scale

`8px`, `16px`, `24px`, `32px`, `40px`, `48px`, `56px`, `64px`, `72px`, `80px`, `96px`

## Radius

| Element | Value |
|---|---:|
| Small elements | 10px |
| Cards | 20px |
| Tabs | 56px |
| Buttons | 56px |
| Large cards | 60px |

## Elevation

```css
--shadow-md: rgba(0, 0, 0, 0.04) 1px 0px 9px 2px;
```

Use shadow only as a quiet lift for large light content cards. Most depth should come from dark/light surface alternation.
