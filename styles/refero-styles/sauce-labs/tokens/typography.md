# Typography

## Body And UI Typeface

- Family: Aeonik
- Substitute: Inter
- Weight: 400
- Sizes: 15px, 16px, 18px, 20px, 24px
- Line-height: 1.20 to 1.50
- Tracking: -0.08px at 16px body, 0.96px at 24px subheading
- OpenType: `ss01` and `cv11` when available
- Use for paragraphs, buttons, nav items, cards, forms, and normal UI text.

## Display And Eyebrow Typeface

- Family: AeonikFono
- Substitute: Inter Display
- Weights: 400 and 500
- Sizes: 9px, 14px, 16px, 24px, 32px, 40px, 48px, 64px
- Line-height: 1.10 to 1.30
- Tracking: 0.45px at 9px, about 0.05em for structural display
- Use for display, headings, stat numbers, and uppercase eyebrow labels.

## Type Scale

| Token | Size | Weight | Line Height | Tracking | Use |
|---|---:|---:|---:|---:|---|
| `body-sm` | 14px | 400 | 1.45 | 0 | small body |
| `body` | 16px | 400 | 1.5 | -0.08px | default body |
| `body-lg` | 18px | 400 | 1.45 | 0 | lead copy |
| `subheading` | 24px | 400 | 1.4 | 0.96px | section support |
| `heading-sm` | 32px | 400 | 1.22 | 0 | small heading |
| `heading` | 40px | 400-500 | 1.2 | 0 | section heading |
| `heading-lg` | 48px | 500 | 1.12 | 0 | large heading |
| `display` | 64px | 500 | 1.1 | 0 | hero headline |

## Rules

- Keep body text weight at 400.
- Keep display text at weight 400 or 500.
- Use 9px uppercase AeonikFono labels above section headlines.
- Do not make headings heavy or bold.
