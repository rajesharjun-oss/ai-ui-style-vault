# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Density | comfortable |
| Base unit | 8px |
| Max width | 1200px |
| Section gap | 80px |
| Card padding | 24px |
| Element gap | 16px |

## Spacing Scale

| Name | Value | Token |
|---|---:|---|
| 8 | 8px | `--spacing-8` |
| 16 | 16px | `--spacing-16` |
| 24 | 24px | `--spacing-24` |
| 32 | 32px | `--spacing-32` |
| 40 | 40px | `--spacing-40` |
| 56 | 56px | `--spacing-56` |
| 80 | 80px | `--spacing-80` |

## Border Radius

| Element | Radius |
|---|---:|
| Inputs | 5px |
| Nested cards | 16px |
| Cards | 20px |
| Badges | 800px |
| Buttons | 800px |

## Elevation

| Name | Value | Token |
|---|---|---|
| Dark card | `none` | `--shadow-none` |
| Filled pill | `rgba(0, 0, 0, 0.05) 2px 2px 0px 0px, rgb(255, 255, 255) 0px -1px 0px 0px inset, rgb(255, 255, 255) 1px 0px 0px 0px inset, rgb(255, 255, 255) -1px 0px 0px 0px inset, rgb(255, 255, 255) 0px 1px 0px 0px inset` | `--shadow-filled-pill` |
| Input lift | `rgba(0, 0, 0, 0.05) 2px 2px 0px 0px` | `--shadow-input` |

Cards should not use drop shadows. Their definition comes from light borders and stacked surface steps.
