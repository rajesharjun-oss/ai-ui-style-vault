# Components

## Hero Headline

Calsans 88px/300, Pure White, line-height 0.96, 0.056em tracking. Optional first phrase can use Phosphor Mint.

## Filled Pill Button

Pure White fill, Void Canvas text, 800px radius, 12px by 24px padding, Geist 16px/500. This is the single primary action style.

## Ghost Pill Button

Transparent fill, 1px Pure White border, Pure White text, 800px radius, 12px by 24px padding, Geist 16px/400.

## Dark Surface Card

Carbon Plate fill, 1px Fog border, 20px radius, 24px padding, no shadow. The light border defines the card edge.

## Phosphor Accent Card

Phosphor Mint fill, 20px radius, 24px padding, optional Fog border. Use at most once per viewport.

## Code Surface

Obsidian fill, 16px radius, 16px to 20px padding, code-like Geist 13px to 14px text, Graphite copy, subtle syntax accents.

## Navigation Bar

Void Canvas background, about 64px height, logo left, centered Geist 14px links, inactive Slate Mute text, active Pure White or Current Blue text, right-side contact link and filled pill CTA.

## Activity Row

Avatar circle, commit or PR message in Geist 14px/500 Pure White, metadata in 12px Graphite, status dot, 10px vertical padding, Iron Edge row dividers.

## Input Field

Carbon Plate fill, Iron Edge border at rest, Deep Signal focus border, 5px radius, 12px padding, Geist 14px, Pure White text, Cinder placeholder.

## Status Badge

Outlined pill badge, 800px radius, 2px by 8px padding, Geist 11px to 12px, wide tracking. Use Verdant Edge or Deep Signal border/text.

## Section Header

Uppercase Geist 12px eyebrow with wide tracking in Ice Blue or Steel Iris, followed by Calsans 56px/300 heading.

## 3D Product Visual Block

Rendered dark product visual with glowing edges, curved tracks, light ribbons, and geometric objects on a dark gradient ground.

## Footer Link Column

Geist 14px/500 Pure White heading, 13px to 14px Graphite links, 8px to 16px vertical gaps, four-column grid.
