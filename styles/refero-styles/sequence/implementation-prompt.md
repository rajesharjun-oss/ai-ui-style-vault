# Implementation Prompt

Build a polished Sequence-style interface: a light finance-editorial product page with a near-white canvas, compact grayscale UI, one violet primary action, and product screenshot cards as the main visual material.

Use Paper White (`#ffffff`) as the base page surface. Use Bone (`#f7f7f7`), Fog (`#f1f1f1`), Silver (`#efefef`), Ash (`#e5e7eb`), and Mist (`#d1d9e4`) for recessed UI, borders, rows, and inputs. Use Graphite (`#1d1d20`) for headings, Iron (`#505050`) for body text, Steel (`#757575`) for muted text, and Smoke (`#92939e`) for disabled or placeholder text. Use Violet Pulse (`#a565ff`) only for the single filled primary CTA, focus accents, active icons, and brand glow. Indigo Ink is for links and secondary emphasis, not button fills.

Typography should use TWK Lausanne for body, nav, cards, labels, buttons, and most headings. Use a light Moderat Serif only for the largest 40px to 46px h1 display headline. Use SF Mono only for 10px code or technical annotations. Keep the page compact and precise: 14px body, 16px larger body, 24px small headings, 40px to 46px display.

Layout should use a fixed top nav, 1200px centered container, 24px gutters, and 80px section gaps. The hero should be centered with eyebrow, serif h1, paragraph, CTA pair, and a floating product screenshot grid below. Product suite sections should alternate text and UI mockups. Use customer logo strips, integration tiles, cards, tables, forms, and diagrams instead of photography.

Components should be restrained: 8px cards, 4px inputs, 9999px buttons and badges, 1px Ash borders, subtle ring shadows, and no heavy elevation. The primary button should have a Violet Pulse fill and a low-opacity Iris Glow halo. Secondary buttons are white or transparent with Silver borders.

Before finishing, check that:

- There is only one filled violet CTA per screen.
- No extra chromatic colors were introduced.
- Moderat Serif appears only in the largest display headline.
- Product visuals are UI mockups, not lifestyle photos.
- Cards use 8px radius and buttons use pill radius.
- Borders and tight shadows, not heavy shadows, create depth.
