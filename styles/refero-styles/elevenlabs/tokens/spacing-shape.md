# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Density | `comfortable` |
| Base unit | `4px` |
| Max width | `1280px` |
| Section gap | `96-125px` |
| Card padding | `32px` |
| Element gap | `8-16px` |

## Radius

| Element | Value |
|---|---:|
| Tags | `9999px` |
| Buttons | `9999px` |
| Inputs | `4px` |
| Cards | `20px` |
| Large cards | `24px` |
| Small elements | `4-10px` |

## Elevation

- Most surfaces are flat.
- Use hairline borders before shadows.
- When needed, use near-invisible hard-edge shadows or inset borders.
- Avoid heavy blurred elevation.
