# ElevenLabs Style Reference

## Creative Direction

Create a warm editorial AI audio interface that feels like a Bauhaus notebook printed on cream paper. The UI should be 97% achromatic: eggshell, taupe, warm gray, and black. Product moments can glow with violet and orange, but the interface chrome stays black, cream, and stone.

## Visual Priorities

1. Use `#fdfcfc` as the page canvas, never pure white.
2. Use `#f5f3f1` for warm taupe cards and section bands.
3. Use `#ebe8e4` for hairline borders and dividers.
4. Use `#000000` for primary text and filled buttons.
5. Use Waldenburg weight 300 for all headings at 32px and up.
6. Use Inter 400/500 for everything below display size.
7. Use 9999px radius for buttons, tags, and tab pills.
8. Keep violet and orange exclusive to product visuals.

## Screen Composition

Use a full-width editorial layout with a 1280px centered content column and 64px outer gutters. Hero layout can be asymmetric: left-aligned display heading, right-aligned description, and pill button pair. Below the hero, use one large taupe feature panel, tab pills, audio sphere visuals, trust logos, hairline dividers, and calm editorial sections.

## Material Language

The surface system is paper-like and flat. Most cards have no shadow. When elevation is needed, use near-invisible hard-edge shadows or inset hairlines. Avoid blur, glass, gradients in UI surfaces, heavy drop shadows, and bright CTA colors.
