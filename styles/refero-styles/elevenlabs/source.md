## What To Preserve

ElevenLabs is warm-white minimalism: eggshell canvas, black ink type, warm taupe surfaces, hairline borders, and pill-shaped controls. The brand expression comes from whisper-weight display headings and product visuals where vivid violet and orange appear as audio-sphere sparks. Those colors should not migrate into buttons, nav links, badges, borders, or text.

## What To Avoid Copying

Do not copy the original wordmark, product screenshots, audio sphere composition, page copy, navigation labels, trust logos, or exact layout. Use the token system and component logic to create original voice AI, creator, agent, or audio developer product screens.

## Build Context

This bundle is meant for AI-assisted UI implementation. Use the markdown files for design intent, and use the `code/` files for direct token import when building with CSS variables or Tailwind v4.
