# Guidelines

## Do

- Use `#000000` as the only canvas color.
- Use `#343755` only for singular dominant CTAs.
- Use 500px radius for pill controls and tags.
- Use Times at `16px` and line-height `1.88` for body copy.
- Use `1px #4d4d4d` borders to define cards.
- Use `backdrop-filter: blur(4px)` for overlay panels.
- Keep nbarchitekt at `10px` to `12px` for nav and metadata.
- Use nbarchitekt `14px` weight `700` for button labels.
- Let the 3D scene carry color, light, and spectacle.

## Don't

- Do not introduce new chromatic accents.
- Do not use box shadows on UI elements.
- Do not use solid white or solid gray card backgrounds.
- Do not set body text in nbarchitekt.
- Do not use radii between `5px` and `500px` for controls.
- Do not add UI gradients.
- Do not use light-theme components on bright areas.
- Do not let chrome compete with the rendered world.
