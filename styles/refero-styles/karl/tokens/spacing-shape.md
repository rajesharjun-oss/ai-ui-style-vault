# Spacing And Shape Tokens

## Spacing

| Purpose | Value |
| --- | --- |
| Density | comfortable |
| Base unit | `4px` |
| Section gap | `45px` |
| Card padding | `0px` |
| Element gap | `20px` |
| Nav link padding | `10px 20px` |

## Spacing Scale

| Name | Value | Token |
| --- | --- | --- |
| 10 | `10px` | `--spacing-10` |
| 20 | `20px` | `--spacing-20` |
| 45 | `45px` | `--spacing-45` |

## Shape

| Element | Value | Role |
| --- | --- | --- |
| cards | `0px` | Conventional cards are absent. |
| globe | `1440px` | Circular or oval focal surfaces. |
| pills | `0px` | No pill controls. |
| buttons | `0px` | No button shape language. |

## Shape Rules

- Use `1440px` radius only for circles and ovals.
- Do not use small UI radii for cards or buttons.
- Keep section and illustration edges hard and flat.
- Do not use shadows or gradients for perceived elevation.
