# Color Tokens

## Brand

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Signal Yellow | `#ffe600` | `--color-signal-yellow` | Full-bleed page and section canvas. |
| Globe Azure | `#007fff` | `--color-globe-azure` | Large circular globe/focal surface and display-text backing. |

## Accent

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Roof Coral | `#ef3b2c` | `--color-roof-coral` | Illustration-only accent, especially roofs and small drawn details. |

## Neutrals

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Charcoal Ink | `#333333` | `--color-charcoal-ink` | Nav text, active nav rule, illustration linework, dark copy. |
| Cloud White | `#ffffff` | `--color-cloud-white` | Display text on blue, clouds, window fills, white drawn elements. |

## Rules

- Signal Yellow is the canvas, not a highlight.
- Globe Azure is a focal composition color, not a generic button color.
- Roof Coral stays inside artwork.
- Charcoal Ink is the only UI ink.
- Cloud White can sit directly on Globe Azure or appear as flat illustration.
