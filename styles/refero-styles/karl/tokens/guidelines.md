# Guidelines

## Do

- Use `#ffe600` as the full-bleed background for the whole scene.
- Use Changa One, weight `400`, for expressive display and section text.
- Use very tight display line-height so large text stacks like poster type.
- Use `1440px` radius for globe/circle/oval focal elements.
- Keep nav links at `14px` Arial with `10px 20px` padding.
- Mark active nav using only a centered `20px` `#333333` bottom rule.
- Put white display text directly on blue or yellow color fields.
- Create depth with stacked illustration layers.
- Transition between sections with hard cuts.

## Don't

- Do not place the yellow canvas inside a white or gray page wrapper.
- Do not apply shadows, glows, blur, gradients, or glass effects.
- Do not use small radii like `4px`, `8px`, or `12px` for UI components.
- Do not introduce a second expressive font.
- Do not use bold or light variants for Changa One.
- Do not center content inside a traditional max-width column.
- Do not create cards, feature grids, neutral dividers, or dense UI panels.
- Do not use coral for UI chrome, links, buttons, or borders.
