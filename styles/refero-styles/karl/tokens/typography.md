# Typography Tokens

## Fonts

| Font | Token | Role | Substitute |
| --- | --- | --- | --- |
| Changa One | `--font-changa-one` | Expressive display, headlines, section signage. | Bowlby One, Lilita One, Sniglet |
| Arial | `--font-arial` | Nav links only. | Helvetica, Inter, system sans |

## Type Scale

| Role | Size | Line Height | Weight | Token |
| --- | --- | --- | --- | --- |
| caption | `12px` | `20px` / `1.67` | `400` | `--text-caption` |
| body | `14px` | `20px` / `1.43` | `400` | `--text-body` |
| subheading | `20px` | `25px` / `1.25` | `400` | `--text-subheading` |
| heading-sm | `32px` | `32px` / `1.0` | `400` | `--text-heading-sm` |
| heading | `50px` | `40px` / `0.8` | `400` | `--text-heading` |
| display | `75px` | `54px` / `0.72` | `400` | `--text-display` |

## Usage

- Use Changa One at one weight only: `400`.
- Do not fake bold, condensed, or light variants.
- Let the chunky forms and tight leading create impact.
- Use Arial only for the top nav and practical UI chrome.
- Keep letter spacing normal.
