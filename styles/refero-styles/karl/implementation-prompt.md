# Implementation Prompt

Build a light, full-bleed illustrated portfolio interface inspired by Karl.

Use `#ffe600` as the unbroken page and section background. Do not wrap the page in a neutral body color, centered card, or white container. Create each section as a viewport-height illustrated scene with hard transitions between scenes.

Use a large solid `#007fff` circle or oval with `1440px` radius as the main focal surface. Anchor it from the bottom of the viewport so it feels like a globe rising into frame. Place white `#ffffff` Changa One display text on top of the blue surface. Use tight line-heights: around `75px / 54px` for display and `50px / 40px` for large intro statements. Rotate individual lines slightly when following the globe arc.

Use Changa One, weight 400, for all expressive text. Use Arial, weight 400, at `14px / 20px`, uppercase, only for the nav. The nav should be a centered top row with no background. Each link gets `10px 20px` padding. The active link uses only a centered `20px` wide `#333333` border-bottom.

Use `#333333` as the only dark ink for nav, linework, and body text. Use `#ef3b2c` only inside illustrations, such as house roofs. Do not use coral for UI chrome, links, buttons, or borders.

Keep all UI flat. Do not add box-shadows, glows, blurs, gradients, conventional cards, button fills, icons, photo assets, or dense content grids. Let stacked flat vector layers create depth: yellow sky, blue globe, white clouds, coral roofs, gray houses, and charcoal linework.
