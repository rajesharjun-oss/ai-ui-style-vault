# Karl

Source: https://styles.refero.design/style/dd8b7191-a992-4dab-88f8-f67e8819b461

Product/site reference: https://karlgonsalves.com

## Snapshot

- **Mood:** Pop-up storybook portfolio on a saturated sunny-yellow canvas.
- **Theme:** Light, flat, illustrated, full-bleed.
- **Core grammar:** Yellow viewport, blue circular globe, white Changa One display text, minimal Arial nav, no card UI.
- **Best for:** Motion design portfolios, playful studio sites, full-screen editorial scenes, illustration-led personal pages.

Karl is useful when you want the interface itself to feel like an illustrated scene. Most web UI conventions disappear: there are no cards, shadows, grids, buttons, or dense sections. The visual identity comes from full-viewport flat vector compositions, a tiny utilitarian nav row, and chunky display type placed directly on color fields.

## Fast Build Notes

- Use `#ffe600` as the full-page canvas, not as an accent.
- Use `#007fff` for the circular globe/focal surface.
- Use Changa One at large sizes with intentionally tight line-height.
- Use Arial only for the top nav.
- Use `#333333` as the only UI/text ink.
- Keep everything flat: no shadows, glows, blurs, or neutral wrappers.
- Let illustration layers create depth.
