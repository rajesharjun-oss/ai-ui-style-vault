# Colors

| Name | Hex | Use |
| --- | --- | --- |
| Midnight Wine | `#421d24` | Primary action buttons, announcement banner, footer, warm maroon anchor |
| Royal Violet | `#714cb6` | Inline links, short emphasized phrases, text accents only |
| Lilac Mist | `#d4c7ff` | Secondary surface fills, light badges, ghost button backgrounds |
| Deep Lagoon | `#0c4243` | Dark feature band background, used sparingly |
| Ink Charcoal | `#292827` | Primary text, headings, icons, warm near-black |
| Stone Gray | `#666666` | Secondary body text, helper copy, muted descriptions |
| Soft Mist | `#e3e3e2` | Hairline borders, card outlines, dividers |
| Warm Parchment | `#f2f0eb` | Page canvas and dominant warm editorial surface |
| Paper White | `#ffffff` | Elevated cards, floating UI overlays, text on dark surfaces |

## Palette Rules

- Use Warm Parchment as the page canvas.
- Use Midnight Wine as the single filled CTA color.
- Reserve Royal Violet for inline links only.
- Use Lilac Mist for secondary controls and active suite tabs.
- Use Paper White only when a card or overlay needs to lift.
- Do not introduce blue, green, or red accents.
