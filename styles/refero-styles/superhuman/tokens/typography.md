# Typography

## Family

- Primary: Super Sans VF.
- Fallback: Inter, Sohne, General Sans, Arial, sans-serif.
- Use one typeface across the system.

## Weights

- 460: signature light-cut voice for large text.
- 500: compact emphasis.
- 540: body emphasis and select display moments.
- 600: occasional label emphasis.
- 700: small bold labels only, never headlines.

## Type Scale

| Role | Size | Weight | Line Height | Tracking |
| --- | --- | --- | --- | --- |
| Caption | 12px | 500 | 1.5 | 0 |
| Body Small | 14px | 460 | 1.5 | 0 |
| Body | 16px | 460 | 1.2 | 0 |
| Label Bold | 19px | 700 | 1.5 | 0 |
| Subheading | 26px | 460 | 1.3 | 0 |
| Heading Small | 28px | 540 | 1.14 | -0.62px |
| Heading Large | 49px | 460 | 1.2 | -1.32px |
| Display | 64px | 540 | 0.96 | -1.8px |

## Usage

- Use weight 460 for all headings at 28px and above.
- Use 540 only when a heading needs more density.
- Keep display tracking tight.
- Keep body text at zero tracking.
- Do not use weight 700+ for headlines.
- Enable `"ss01"` if supported.
- Use tabular numerals in product UI cards.
