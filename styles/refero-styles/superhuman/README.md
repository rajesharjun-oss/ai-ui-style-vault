## Use This Style For

- Email clients, productivity suites, executive SaaS, premium collaboration tools, and editorial product launches.
- Interfaces that combine cinematic photography with polished software UI.
- Pages where a warm paper canvas, maroon action, violet links, and floating glass product cards should feel premium.

## Design Memory

Superhuman sits between editorial photography and software UI. The page canvas is warm parchment, never pure white. Deep maroon owns primary actions, violet is reserved for links, lilac is a light secondary surface, and product cards float over golden-hour photography without drop shadows. The system feels expensive because it is quiet.
