# Implementation Prompt

Use the Superhuman style language for this UI.

Create a warm editorial productivity interface: parchment canvas, cinematic golden-hour photography, translucent product UI cards, deep maroon primary CTA, violet inline links, light lilac secondary controls, and Super Sans variable typography. The result should feel premium and calm, not like a generic SaaS template.

Core rules:

- Use `#f2f0eb` as the full-page canvas.
- Use `#292827` for primary text and icons.
- Use `#421d24` as the only filled primary CTA color.
- Use `#714cb6` only for inline links and short emphasized text.
- Use `#d4c7ff` for secondary light button surfaces or tab active states.
- Use `#ffffff` only for elevated cards or floating UI overlays.
- Use Super Sans VF if available; otherwise use Inter, Sohne, or General Sans.
- Use weight 460 for headlines at 28px and above.
- Do not use weight 700 or higher for headlines.
- Use 16px radius for cards, primary buttons, and floating UI.
- Use 8px radius for tabs and small buttons.
- Use 999px radius for announcement pills.
- Do not add drop shadows to cards.
- Use backdrop blur for the sticky header on scroll.

Recommended structure:

- Top announcement pill in Midnight Wine.
- Sticky transparent header with backdrop blur on scroll.
- Cinematic hero with product cards floating over the photo.
- Primary maroon CTA and secondary lilac/outlined action.
- Trust logo row with square white cells.
- Suite tab strip for products such as Mail, Grammarly, Coda, and Go.
- White suite product cards on parchment.
- One Deep Lagoon dark feature band.
- Midnight Wine footer with multi-column links.

Avoid:

- Pure white page canvas.
- Blue, green, or red accents.
- Violet button fills.
- Card drop shadows.
- Heavy headline weights.
- Centered long body copy.

The result should feel like editorial photography and high-performance software met on warm paper.
