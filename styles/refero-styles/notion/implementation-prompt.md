# Implementation Prompt

Build a warm, notebook-like productivity SaaS interface inspired by Notion.

Use `#f6f5f4` as the full page canvas. Place white `#ffffff` cards and panels on top with `12px` radius, `24px` padding, and `1px solid rgba(0,0,0,0.08)` borders. Do not add shadows to normal content cards. Reserve shadows for the sticky nav and large product UI mockup only.

Use `#0075de` as the single filled primary CTA color. Secondary actions should use a soft blue ghost treatment with `#e6f3fe` background and blue text, or transparent text-button styles. Do not create multiple filled CTA colors.

Use NotionInter or Inter as the main font. Large headlines should feel compact and confident with negative tracking: around `96px` with `-4.608px`, `72px` with `-2.016px`, and `54px` with `-1.89px`. Body text stays at normal tracking. Use Lyon Text or Source Serif Pro only for occasional editorial intros at `18px` or `32px`.

Create a hero with a centered stack: decorative avatar character marks, large two-line headline, inline highlight pill around one verb, editorial subhead, two-button CTA row, and a large product UI mockup. Use accent colors like `#ffb110`, `#f64932`, `#62aef0`, and `#02093a` for feature block backgrounds and highlight pills.

Use `8px` radius for buttons, `12px` for rectangular cards, `4px` for compact outline controls, and `9999px` for pills. Keep motion at `200ms ease` for hovers and transitions; use spring or bounce only for small decorative marks.
