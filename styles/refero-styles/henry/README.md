# Henry

AI-ready Refero style bundle for a warm monochrome editorial broadside: cream paper, warm ink, massive display typography, full-bleed Paper/Ink inversions, 12px-only radius, and no chromatic accent.

## Source

- Refero style: https://styles.refero.design/style/ff4b9eff-dc0b-4886-bd65-c2f5e9069318
- Reference site: https://henry.codes
- Captured: 2026-07-28
- Theme: mixed

## Use This When

- You need an editorial portfolio, studio page, literary product, design manifesto, publication, or type-led personal site.
- The page should feel like a printed broadside or zine rather than a SaaS interface.
- You can let typography, scale, and inversion carry the whole composition.

## Bundle Contents

- `DESIGN.md` - complete AI style reference.
- `implementation-prompt.md` - drop-in prompt for AI implementation.
- `style.json` - structured style summary for search/indexing.
- `tokens/` - colors, typography, spacing, components, guidelines, layout, and imagery.
- `code/` - CSS variables, Tailwind v4 tokens, and JSON design tokens.
- `screenshots/README.md` - screenshot capture notes.

## Implementation Notes

Use this as an inspiration reference, not as an official Henry Codes brand kit. Do not copy original images, copy, client lists, typefaces, artwork, or exact page layouts unless you have rights to use them.
