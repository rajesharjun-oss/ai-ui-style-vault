# Implementation Prompt

Build the UI in the Henry Refero style.

Create a warm monochrome editorial broadside. The page should feel printed on cream paper with warm near-black ink. Use full-bleed section inversions, enormous display typography, tight neo-grotesque UI text, and monochrome halftone imagery. Do not make it look like a SaaS landing page.

Color rules:

- Default background: Paper `#fafafa`.
- Primary text and dark sections: Headline Ink `#2a2722`.
- Inverted text on dark sections: Paper `#fafafa`.
- Support neutrals only: `#3e3b36`, `#666666`, `#9f9f9f`, `#b3b3b3`, `#eeeeee`.
- No chromatic accents. No blue links. No red/green/yellow state colors.
- No colored CTA fills.

Typography rules:

- Use Louize Display-style serif for all section-defining headlines.
- Use Louize/Louize Display for centered editorial copy in dark inverted sections.
- Use Manuka-style ultra-condensed display sans only for huge mastheads at 226-371px.
- Use Neue Montreal-style sans for nav, body, labels, metadata, and UI controls.
- Body/UI tracking is tight: around -0.01em or equivalent negative px values.
- Do not center-align Neue Montreal body copy.

Layout rules:

- Use full-bleed Paper and Ink bands.
- Do not use a conventional max-width SaaS container.
- Hero can be split: huge headline left, monochrome halftone plate right.
- Use 64-96px gaps between major sections.
- Leave most of the page as empty Paper or Ink.
- Dense areas are limited to ticker strips and footer/byline metadata.

Component rules:

- Radius is always 12px for cards, buttons, and tags.
- Coming-soon tags are outlined ghost pills with 12px radius and no fill.
- Rules and dividers are 1px lines in Paper or Ink.
- Buttons are typographic controls, not filled colored CTAs.
- Imagery is monochrome halftone only.
- No shadows, gradients, glows, glass, blur, icon systems, pricing grids, or feature cards.

The final result should feel like a type-led editorial broadsheet: two or three huge words, a strict Paper/Ink binary, and almost no ornamental UI.
