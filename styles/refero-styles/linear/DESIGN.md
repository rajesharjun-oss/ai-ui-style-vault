# Linear Design Notes

Linear is a midnight command center. Its interface feels precision-machined: near-black surfaces, 0.5px to 1px graphite borders, tight Inter typography, and a single electric acid-lime action. The system lets product UI provide texture while the surrounding chrome stays quiet.

## Visual Principles

- Treat darkness as the substrate, not as decoration.
- Use acid lime sparingly as a functional flashlight.
- Let hairline borders and surface levels replace shadows.
- Keep type crisp, compact, and subtly tight.
- Use Berkeley Mono only for technical metadata.
- Let issue cards, kanban boards, and AI panels be the main visual texture.

## Color System

The normal interface is a progression from Void to Carbon to Obsidian to Graphite. Text lives in Paper, Mist, Fog, and Ash. Acid Lime is the only chromatic action color. Pulse Green, Coral Red, Signal Teal, Iris Violet, and Lavender are supporting accents for tags, labels, and informational decoration, not primary actions.

## Typography

Use Inter Variable for almost everything. Weights sit in a restrained 400 to 510 band, with tight tracking on body and display type. Use Berkeley Mono only for issue IDs, command shortcuts, code-like labels, and technical metadata.

## Layout

Use a 1200px max-width container, 96px section rhythm, 24px card padding, and compact 8px internal gaps. Prefer product UI layouts: kanban columns, issue cards, AI agent panels, command bars, and status rows.

## Elevation

Elevation is mostly surface color and borders. Use `#23252a` hairlines and inset borders. Avoid ambient shadows on normal cards. The acid-lime CTA may use a subtle inset stack because it is the highest-energy chrome element.
