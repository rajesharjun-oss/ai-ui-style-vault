# Implementation Prompt

Build a dark developer-product interface inspired by Linear.

Use `#08090a` as the page canvas. Use `#0f1011` for card surfaces and nav bars, `#161718` for deeper elevated panels, and `#23252a` for borders, dividers, and ghost outlines. Use `#ffffff` for hero text, `#d0d6e0` for secondary headings and button text, `#8a8f98` for tertiary text, and `#62666d` for muted metadata.

Use `#e4f222` as the only chromatic primary action. It can appear on one primary button, active nav indicators, and focused product states. Do not use additional chromatic CTA colors. Supporting accent colors can appear only in tags, status chips, or informational marks.

Use Inter Variable for UI, body, nav, buttons, and headings. Apply tight tracking, roughly `-0.022em` for larger display and `-0.011em` for primary buttons. Use Berkeley Mono only for issue IDs, keyboard shortcuts, code-like metadata, and technical labels.

Use compact component geometry: 6px button radius, 12px maximum card radius, 9999px pills, 24px card padding, 8px element gaps, and 96px section gaps. Separate cards with hairline borders, not drop shadows.

Build product primitives: acid-lime CTA, neutral sign-up pill, nav text button, ghost outline button, status badge row, issue card, kanban column, command palette, AI agent panel, and product dashboard frame.
