# Layout And Imagery

## Layout Grammar

Linear uses product-led dark command-center layouts. Surfaces are mostly full-bleed midnight with centered content, compact nav, and precise product UI artifacts.

## Common Layouts

- Centered hero with tight headline, short body, CTA row, and product UI preview.
- Dark top nav with neutral sign-up pill.
- Kanban board preview with issue cards and agent panels.
- AI workflow panel with compact rows and active lime indicator.
- Status badge rows and pill filters.
- Feature grids using graphite cards and restrained text hierarchy.
- Docs or changelog sections with mono metadata.

## Imagery

- Use product UI, issue boards, command palettes, agent panels, code-like metadata, and abstract grid geometry.
- Avoid lifestyle photography, colorful illustration, and generic gradient blobs.
- Keep visuals dark, sharp, and inspection-friendly.

## Motion

- Use precise `150ms` to `220ms` transitions.
- Hover states should be subtle: border lift, text brighten, or low-opacity fill.
- Avoid bounce, parallax, and expressive motion.
