# Color Tokens

## Core Surfaces

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Void | `#08090a` | `--color-void` | Page canvas and full-bleed background. |
| Carbon | `#0f1011` | `--color-carbon` | Card surfaces, product screenshot frames, nav containers. |
| Obsidian | `#161718` | `--color-obsidian` | Elevated surfaces and nested panels. |
| Graphite | `#23252a` | `--color-graphite` | Subtle borders, dividers, ghost button outlines. |
| Smoke | `#383b3f` | `--color-smoke` | Higher-contrast hairlines and section separators. |

## Text

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Paper | `#ffffff` | `--color-paper` | Primary headings, hero type, max-contrast emphasis. |
| Bone | `#e5e5e6` | `--color-bone` | Near-white fills and high-contrast button text. |
| Mist | `#d0d6e0` | `--color-mist` | Secondary headings, button text on dark surfaces. |
| Fog | `#8a8f98` | `--color-fog` | Tertiary text, placeholder copy, icon fills. |
| Ash | `#62666d` | `--color-ash` | Muted body text, inactive icons, metadata. |

## Accent

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Acid Lime | `#e4f222` | `--color-acid-lime` | Primary action buttons and active nav indicators. |
| Pulse Green | `#27a644` | `--color-pulse-green` | Supporting green tag outlines and focused UI edges. |
| Coral Red | `#eb5757` | `--color-coral-red` | Supporting error/highlight wash, not a CTA. |
| Signal Teal | `#02b8cc` | `--color-signal-teal` | Decorative information icon fill. |
| Iris Violet | `#6366f1` | `--color-iris-violet` | Tag and badge fills. |
| Lavender | `#8b5cf6` | `--color-lavender` | Secondary tag fills and category indicators. |

## Rules

- Use Acid Lime as the only chromatic CTA.
- Keep normal surfaces in the Void, Carbon, Obsidian, Graphite range.
- Do not use chromatic text for body copy.
- Use supporting accent colors only in tags, labels, and informational marks.
