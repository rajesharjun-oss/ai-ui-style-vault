# Spacing And Shape Tokens

## Spacing

| Purpose | Value |
| --- | --- |
| Density | compact |
| Max width | `1200px` |
| Section gap | `96px` |
| Card padding | `24px` |
| Element gap | `8px` |

## Radius

| Element | Value | Token |
| --- | --- | --- |
| buttons | `6px` | `--radius-button` |
| cards and panels | `12px` | `--radius-card` |
| issue cards | `8px` | `--radius-issue-card` |
| tags and pills | `9999px` | `--radius-pill` |

## Borders And Elevation

- Hairline border: `0.5px solid #23252a`.
- Standard border: `1px solid #23252a`.
- Strong border: `1px solid #383b3f`.
- Card shadows are generally avoided.
- Product hero artifacts can use `0 4px 32px rgba(8,9,10,0.6)`.
