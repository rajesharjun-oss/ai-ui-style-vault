# Guidelines

## Do

- Use `#08090a` as the full-bleed canvas.
- Use `#e4f222` as the only chromatic action color.
- Use hairline graphite borders instead of card shadows.
- Keep buttons at `6px` radius and cards at `12px` max.
- Use Inter Variable for normal UI and headings.
- Use Berkeley Mono only for issue IDs, shortcuts, and metadata.
- Keep component spacing compact.
- Let product UI be the main visual texture.

## Don't

- Do not use decorative gradients on buttons, cards, or text.
- Do not introduce extra CTA colors.
- Do not use large radii above `12px` on cards or panels.
- Do not use shadows to separate normal cards from the canvas.
- Do not use chromatic text for body copy.
- Do not use Berkeley Mono for headings or marketing copy.
- Do not make the UI feel like a generic dark SaaS dashboard.
