# AI Implementation Prompt

Build a Revolut-inspired monochrome fintech interface.

Use `#ffffff` as the main canvas, `#1f1f1f` as the main text and dark-section color, `#f7f7f7` for recessed list groups, and `#c9c9cd` for hairline borders. Keep the UI almost completely grayscale. The only saturated UI color should be a top promotional strip using `linear-gradient(to right, #1227fd, #6fa0ff)`.

Use an Aeonik Pro-like display font for headings and hero text. Keep it at weight 500 or lower, with tight negative tracking and very tight line-height at large sizes. Use Inter for body copy, buttons, labels, nav, badges, and forms.

Controls should be pill-shaped. Use 9999px radius for buttons, tags, inputs, and selector pills. Use 20px radius for list containers and 22.5px radius for cards. Avoid shadows on normal cards and buttons; use borders, surface shifts, and section contrast instead.

Core components to include:

- Full-bleed sky-photo hero with white 88px display headline.
- Dark pill CTA and translucent ghost pill over photography.
- Top blue gradient promo bar.
- Dark navigation header with wordmark, nav links, login, and sign-up pill.
- Phone preview card overlapping the lower edge of a hero image.
- Dark pricing section with three white rounded tier cards.
- Recessed list container for grouped rows or FAQ items.
- Trust badge grid with sparse spacing and muted captions.
- Muted section headers in `#717173`.

Photography should carry the emotional tone: high-key sky, clouds, pale blues, white light, and candid human subjects. Do not use generic abstract graphics, 3D objects, illustrations, or extra accent colors.
