## Use This Style When

Use Revolut when the interface should feel like a modern fintech or banking product with editorial restraint: mostly monochrome UI, full-bleed cloud photography for atmosphere, pill-shaped controls, large tightened display type, and crisp border-led separation. It fits banking, payments, subscriptions, pricing pages, mobile finance apps, and conversion-heavy consumer fintech landing pages.

## Quick DNA

- White and near-black form the main UI world.
- Full-bleed sky photography carries color and emotion.
- Aeonik-style display headings stay medium weight, never heavy.
- Inter-style UI text handles dense controls and body copy.
- Every important control is a pill.
- Cards and lists separate with hairline borders, not shadows.
- The only chromatic UI accent is a blue promo gradient.
- Pricing modules flip to dark sections with white tier cards.
