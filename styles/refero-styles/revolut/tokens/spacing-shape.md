## Radius

| Element | Value |
| --- | --- |
| Buttons | 9999px |
| Tags | 9999px |
| Inputs | 9999px |
| Small controls | 12px |
| Lists | 20px |
| Cards | 22.5px |

## Shape Rules

- Pills are the signature control shape.
- Use 9999px radius for all primary controls.
- Use 20px for grouped list containers.
- Use 22.5px for pricing cards and phone preview cards.
- Do not use square primary actions.
