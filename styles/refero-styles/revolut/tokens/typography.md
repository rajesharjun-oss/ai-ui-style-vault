# Typography

## Display Font

Name: `Aeonik Pro`

Fallbacks: Inter, DM Sans, Manrope, system-ui, sans-serif

Role: marketing display, hero headlines, section headings, and emphasis paragraphs.

Rules:

- Use weight 500 for major headings.
- Do not exceed weight 500 for display type.
- Tighten letter spacing at every display size.
- Let scale and tracking provide authority instead of boldness.

## Body Font

Name: `Inter`

Fallbacks: system-ui, sans-serif

Role: body copy, navigation, buttons, labels, badges, forms, and dense UI.

Rules:

- Use 16px for the default body and control layer.
- Use 12px with positive tracking for uppercase micro-labels.
- Use 600 for important button labels.
- Keep body letter spacing slightly tight or neutral.
