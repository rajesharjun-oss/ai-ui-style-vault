# Colors

## Brand

| Name | Value | Role |
| --- | --- | --- |
| Cobalt Wash | `linear-gradient(to right, #1227fd, #6fa0ff)` | Top promotional offer strip only. |

## Neutrals

| Name | Value | Role |
| --- | --- | --- |
| Pure Black | `#000000` | Maximum contrast blocks and text where needed. |
| Ink | `#1f1f1f` | Main text, dark navigation, footer, dark bands, and filled dark buttons. |
| Graphite | `#4c4c4c` | Tertiary copy and minor muted surfaces. |
| Slate | `#717173` | Muted labels, section headers, badge text, and quiet state feedback. |
| Ash Grey | `#c9c9cd` | Hairline borders, dividers, and disabled borders. |
| Mist | `#f7f7f7` | Recessed grouped rows and secondary containers. |
| Bone | `#ffffff` | Page canvas, cards, white buttons, and text on dark fills. |

## Rules

- Keep UI surfaces grayscale.
- Use the blue gradient only on the promotional bar.
- Let photography supply color.
- Separate surfaces with `#c9c9cd` hairlines and `#f7f7f7` recessed fills.
- Use `#1f1f1f` for conversion-heavy dark bands.
