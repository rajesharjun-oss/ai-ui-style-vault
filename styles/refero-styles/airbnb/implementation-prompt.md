# Implementation Prompt

Build a UI in the Airbnb style.

Create a quiet white travel marketplace interface where property photography is the primary visual language. Use a soft off-white canvas, white listing cards, compact Cereal-style typography, rounded image cards, and one coral-red action accent.

Use these hard rules:

- Page canvas: `#f7f7f7`.
- Card and input surface: `#ffffff`.
- Primary text: `#222222`.
- Secondary text: `#6a6a6a`.
- Placeholder/disabled text: `#c1c1c1`.
- Hairline borders and dividers: `#ebebeb`.
- Muted skeleton surface: `#dddddd`.
- Only accent: `#ff385c`.
- Pressed accent: `#e00b41`.
- Use Rausch only for logo, search submit, active wishlist hearts, and one primary action per surface.
- Do not add additional accent colors.
- Body text should be 14px/400 with 1.43 line-height.
- UI labels should be 16px/500.
- Section titles should be 22px/500 with -0.02em tracking.
- Search bar, buttons, badges, avatars, and icon buttons are 9999px radius.
- Listing cards and images use 12px radius.
- Ghost buttons use 8px radius.
- Do not use borders or shadows on listing cards.
- Keep property imagery full-bleed in the card frame.

Build a fixed 80px top nav with Rausch logo, centered category tabs, and right-side utility controls. Make the search capsule the hero: a centered white pill with segmented Where, When, and Who fields, plus a 48px Rausch circular submit button. Below, create horizontal listing rows with full-bleed 1:1 property images, Guest Favorite badges, wishlist heart buttons, listing title, metadata, price, and rating.
