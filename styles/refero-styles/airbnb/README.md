Captured: 2026-07-28

## Use This Style When

Use Airbnb when the interface should feel like a quiet travel marketplace: soft white canvas, photo-first listing cards, compact typography, pill search controls, and one coral-red action signal. It fits lodging marketplaces, local experiences, booking flows, real estate browsing, hospitality directories, and any product where imagery should carry the emotional weight.

## Quick DNA

- Off-white page canvas with white listing surfaces.
- Property photography is the primary visual language.
- Rausch coral `#ff385c` is the only accent.
- Body copy is compact at 14px.
- Listing cards are flat, borderless, and image-first.
- Search bar, buttons, hearts, badges, and icon controls are pills or circles.
- Shadows are reserved for elevated overlays like the search bar, menus, and popovers.
