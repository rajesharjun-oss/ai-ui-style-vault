# Spacing And Shape

## Spacing

| Token | Value | Use |
| --- | ---: | --- |
| `unit` | 4px | Base spacing unit |
| `4` | 4px | Tight label and icon gap |
| `8` | 8px | Small UI padding |
| `12` | 12px | Card padding, image-to-text gutter, row gap |
| `16` | 16px | Ghost button padding |
| `20` | 20px | Local grouping |
| `24` | 24px | Section title spacing |
| `28` | 28px | Local layout rhythm |
| `32` | 32px | Larger local gap |
| `40` | 40px | Desktop horizontal page padding and nav controls |
| `44` | 44px | Touch target support |
| `48` | 48px | Search submit, heart target, section gap |
| `max-width` | 1440px | Constrained page maximum |

## Radius

| Token | Value | Use |
| --- | ---: | --- |
| `input` | 8px | Inputs and secondary controls |
| `ghost-button` | 8px | Ghost outline buttons and category buttons |
| `card` | 12px | Listing cards and listing images |
| `image` | 12px | Listing images |
| `search-bar` | 9999px | Main search capsule |
| `badge` | 9999px | Guest favorite badges |
| `button` | 9999px | Pill buttons and circular icon controls |
| `avatar` | 9999px | Avatar and icon circles |

## Shape Rules

- Use exactly two normal card radii: 12px and 14px.
- Use full pills for interactive capsules and circles.
- Do not introduce inconsistent intermediate radii.
- Do not border listing cards.
