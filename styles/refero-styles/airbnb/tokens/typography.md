# Typography

## Primary Family

```css
font-family: "Airbnb Cereal VF", Circular, Inter, "DM Sans", system-ui, sans-serif;
font-feature-settings: "salt" on;
```

Use Airbnb Cereal VF or a close geometric sans fallback across the entire interface.

## Scale

| Token | Size | Weight | Line Height | Letter Spacing |
| --- | ---: | ---: | ---: | ---: |
| `caption` | 11px | 400 | 1.18 | 0 |
| `metadata` | 12px | 400 | 1.33 | 0 |
| `small` | 13px | 400 | 1.23 | 0 |
| `body` | 14px | 400 | 1.43 | 0 |
| `ui` | 16px | 500 | 1.25 | 0 |
| `subheading` | 20px | 600 | 1.2 | -0.18px |
| `heading-sm` | 22px | 500 | 1.18 | -0.44px |
| `card-title-emphasis` | 21px | 700 | 1.43 | 0 |
| `heading` | 28px | 700 | 1.43 | 0 |

## Rules

- Use 14px/400 as the main content size.
- Use 16px/500 for search labels and nav labels.
- Use 22px/500 for row section titles.
- Do not use 700 for body or metadata.
- Use tight negative tracking only on larger title moments.
