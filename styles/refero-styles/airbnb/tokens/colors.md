# Colors

| Token | Value | Use |
| --- | --- | --- |
| `--airbnb-rausch` | `#ff385c` | Logo, search submit, active wishlist hearts, primary action punctuation |
| `--airbnb-rausch-600` | `#e00b41` | Pressed and dark-state accent variant |
| `--airbnb-hof` | `#222222` | Primary text, headings, icon strokes, inverse backgrounds |
| `--airbnb-foggy` | `#6a6a6a` | Secondary text, metadata, helper copy, disabled icons |
| `--airbnb-grey-500` | `#c1c1c1` | Disabled text, placeholders, muted icon strokes |
| `--airbnb-deco` | `#dddddd` | Skeleton placeholders and disabled card states |
| `--airbnb-bebe` | `#ebebeb` | Hairline borders, input underlines, dividers |
| `--airbnb-faint` | `#f7f7f7` | Page canvas, footer, hover state |
| `--airbnb-white` | `#ffffff` | Listing cards, input fields, modals, overlays |

## Usage Rules

- Use Rausch only for logo, search submit, active hearts, and one primary action per surface.
- Do not add any other accent hue.
- Keep listing content mostly Hof and Foggy.
- Use Faint as page canvas and White as elevated card surface.
- Use Bebe only for hairline dividers and underlines.
