# Components

## Floating Search Bar

- Role: primary global search input.
- Shape: full-width capsule, 9999px radius.
- Surface: `#ffffff`.
- Max width: about 880px.
- Fields: Where, When, Who.
- Labels: 16px/500, Hof.
- Placeholder: 14px/400, Foggy.
- Dividers: vertical Bebe hairlines.
- Submit: 48px Rausch circle with white search icon.
- Shadow: layered soft overlay shadow.
