# Layout And Imagery

## Layout

- Use a full-bleed marketplace layout.
- Internal desktop horizontal padding is around 40px.
- Search bar is the hero, not a large headline.
- Top navigation is fixed and around 80px high.
- Listing sections stack vertically.
- Each section is roughly 320px tall with horizontal overflow.
- Use around 48px vertical gaps between sections.
- Listing rows can show about seven cards across on desktop.
- Footer uses a 3-column link grid on Faint.

## Imagery

Use:

- Real property photography.
- Warm interiors and exteriors.
- 1:1 listing image crops.
- Full-bleed photos within card frames.
- Monochrome outlined icons.

Avoid:

- Illustrations.
- 3D renders.
- Abstract graphics.
- Heavy filters.
- Duotones.
- Decorative image borders.
