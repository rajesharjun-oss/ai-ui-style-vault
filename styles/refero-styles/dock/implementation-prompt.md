# AI Implementation Prompt

Build a polished, responsive interface in the Dock style.

The page should feel like a warm cream-paper B2B workspace with one vivid cobalt action color. Use product screenshots and rounded ivory cards as the main visuals. Keep the design calm, trustworthy, and product-real.

Core rules:

- Use `#fcf8ed` as the main page canvas.
- Use `#fffdf8` for cards, product mockup frames, and content panels.
- Use `#16042c` for primary text and headings.
- Use `#776f64` for secondary copy.
- Use `#e8dcc8` for borders and dividers.
- Use `#385bff` for the single primary CTA color, active links, focus rings, and selected states.
- Use pill buttons with `9999px` radius.
- Use 24px card radius and 18px screenshot radius.
- Use real product screenshots or UI composites, not decorative stock imagery.
- Keep section gaps generous and avoid dense dashboards on the first screen.

Recommended layout:

1. Sticky cream header with logo, Warm Gray nav links, sign-in ghost link, and a cobalt pill CTA.
2. Two-column hero with Roobert headline and support copy on the left, layered product screenshot cards on the right.
3. Three-column feature card grid on an ivory or morning-mist surface.
4. Product workflow section with screenshot cards and cobalt active states.
5. Testimonial or customer proof section using soft quote cards.
6. Centered CTA band with one cobalt pill action.

Make it feel like a premium client workspace that is easy to trust and easy to act on.
