# Dock

Sunlit cream paper with a cobalt pulse: a warm SaaS workspace style with cream canvas, ivory product cards, rounded screenshot frames, Roobert typography, and one vivid blue action color.

Use this style when you want a sales, customer workspace, document workflow, client portal, knowledge hub, or polished B2B SaaS interface to feel calm, trustworthy, and product-real.

## Files

- `source.md`: Source URL, reference site, capture notes, and scope.
- `DESIGN.md`: Human-readable design breakdown.
- `implementation-prompt.md`: Prompt for an AI builder to implement the style.
- `style.json`: Structured design metadata.
- `tokens/`: Markdown token notes by category.
- `code/`: CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md`: Placeholder for future manual screenshots.

## Quick Use

1. Use `Paper Cream` as the page canvas.
2. Use `Ivory Card` for product cards and screenshot frames.
3. Use `Velvet Ink` for text and `Warm Gray` for secondary copy.
4. Use `Electric Cobalt` for one primary CTA and active link states.
5. Use 9999px pill buttons and 24px rounded cards.
6. Prefer real product screenshots over decorative illustrations.
