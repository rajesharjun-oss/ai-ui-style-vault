# Layout And Imagery

## Layout Pattern

The core page structure is:

1. Sticky cream header with hairline border.
2. Two-column hero with text and cobalt CTA on the left.
3. Product screenshot stack or large screenshot card on the right.
4. Alternating Paper Cream and Morning Mist sections.
5. Three-column feature card grids.
6. Product workflow sections with screenshot cards.
7. Testimonial or proof cards.
8. Centered CTA band.

## Grid

- Use max width around 1280px.
- Use two-column hero on desktop.
- Use three-column feature grids where possible.
- Stack cleanly on mobile.
- Avoid permanent sidebars or dense rails on marketing surfaces.

## Imagery

Use:

- Real product screenshots.
- Client portal previews.
- Document workspace UI.
- Clean UI composites.
- Rounded screenshot cards with subtle shadow.

Avoid:

- Generic stock photography.
- Heavy decorative illustration.
- Neon abstract art.
- Pure white page backgrounds.
- Unframed screenshots on harsh canvases.
