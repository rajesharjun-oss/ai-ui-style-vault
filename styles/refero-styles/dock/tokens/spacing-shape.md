# Spacing And Shape

## Spacing

| Purpose | Value | Notes |
|---|---:|---|
| Density | comfortable | Calm SaaS rhythm |
| Base unit | 4px | Token foundation |
| Max width | 1280px | Centered layout |
| Header height | about 72px | Sticky cream nav |
| Element gap | 16px | Cards, copy, controls |
| Section gap | 96px to 128px | Major vertical rhythm |
| Card padding | 32px | Feature and testimonial cards |
| Screenshot padding | 12px to 16px | Product screenshot cards |
| Logo cloud gap | 48px to 64px | Social proof spacing |
| CTA padding | 14px 24px | Primary cobalt pill |

## Shape

| Element | Radius | Notes |
|---|---:|---|
| Buttons | 9999px | Full pill |
| Tags | 9999px | Full pill |
| Cards | 24px | Soft content surfaces |
| Product screenshots | 18px | Inner UI frames |
| Inputs | 12px | Functional controls |

## Elevation

Product screenshot:

```css
0 24px 64px rgba(22, 4, 44, 0.08),
0 8px 24px rgba(22, 4, 44, 0.06)
```

Card hover:

```css
0 12px 32px rgba(22, 4, 44, 0.06)
```

Use shadows sparingly and keep them warm and low-contrast.
