# Colors

| Name | Value | Token | Role |
|---|---:|---|---|
| Velvet Ink | `#16042c` | `--color-velvet-ink` | Primary text, headings, footer text, high-contrast UI |
| Paper Cream | `#fcf8ed` | `--color-paper-cream` | Page-level canvas |
| Ivory Card | `#fffdf8` | `--color-ivory-card` | Cards, product mockup frames, content panels |
| Hairline Beige | `#e8dcc8` | `--color-hairline-beige` | Borders, dividers, soft separators |
| Warm Gray | `#776f64` | `--color-warm-gray` | Secondary text and descriptions |
| Soft Tan | `#c9bda6` | `--color-soft-tan` | Tertiary labels, placeholder text, quiet metadata |
| Electric Cobalt | `#385bff` | `--color-electric-cobalt` | Primary CTA, active links, focus rings, selected states |
| Cobalt Hover | `#2748e8` | `--color-cobalt-hover` | Hover and active state for cobalt actions |
| Dark Cobalt | `#1530b8` | `--color-dark-cobalt` | Deep blue state and high-contrast active detail |
| Pale Blue | `#eef2ff` | `--color-pale-blue` | Blue-tinted hover background and subtle active surface |
| Morning Mist | `#f6f0e4` | `--color-morning-mist` | Alternate cream section bands and nested panels |
| Pure White | `#ffffff` | `--color-pure-white` | Button text on cobalt and screenshot interiors |

## Guidance

- Use Paper Cream as the dominant canvas.
- Use Ivory Card for product and content surfaces.
- Use Electric Cobalt for the primary CTA and selected states only.
- Use Warm Gray for body support copy.
- Use Hairline Beige for borders.
- Do not introduce a second saturated accent.
