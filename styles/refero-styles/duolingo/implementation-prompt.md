# Implementation Prompt - Duolingo Style

Build an original UI using the Duolingo Refero style as visual direction.

Create a playful education or learning interface on a pure white canvas. Use rounded display type, saturated green progress moments, Spark Blue interactive links, mid-gray body text, sticker-like buttons with 12px radius, thick 2px borders, and large flat character illustrations. The result should feel friendly, encouraging, and easy to scan.

## Must Preserve

- Paper White `#ffffff` as the main canvas.
- Eager Green `#58cc02` for progress, display headings, primary CTA fills, and footer band.
- Spark Blue `#1cb0f6` for links and outlined secondary actions.
- Pencil Gray `#777777` for body copy.
- Charcoal `#4b4b4b` for dark hero headings.
- Feather-style rounded display typography at 48-64px.
- Duolingo-sans style body typography at 17px/500.
- 12px radius for buttons, pills, links, and nav items.
- 2px borders on outlined controls.
- White sections with text-left and illustration-right rhythm.
- Full-bleed green footer band.
- Secondary illustration colors staying inside artwork, not UI chrome.

## Avoid

- Copying Duolingo logos, exact mascot art, exact screenshots, product copy, or proprietary layout details.
- Colored body paragraphs.
- Sharp corners.
- Gradients, shadows, glass effects, or heavy depth.
- Using display type below 48px.
- Applying illustration-only colors to buttons, nav, forms, or links.
- Green-on-green or blue-on-green actions without contrast checks.

## Component Direction

Use a friendly first viewport with a neutral dark headline, green primary CTA, blue outlined secondary CTA, and one playful illustration. Keep the layout simple: headline, paragraph, CTA, illustration, repeat. Let progress green and rounded type do the brand work.
