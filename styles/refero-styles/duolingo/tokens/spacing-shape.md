# Spacing And Shape

## Core Values

| Purpose | Value |
|---------|-------|
| Density | comfortable |
| Base unit | 4px |
| Max width | 1200px |
| Section gap | 80-120px |
| Card padding | 16-24px |
| Element gap | 12px |
| Section height | 800-900px |
| Body max width | 480px |
| Footer vertical padding | 48px |

## Radius

| Element | Value | Token |
|---------|-------|-------|
| Links | 12px | `--radius-links` |
| Buttons | 12px | `--radius-buttons` |
| Nav items | 12px | `--radius-nav-items` |
| Pills | 12px | `--radius-pills` |

## Borders

- Outlined controls use `2px solid #afafaf`.
- Colored outlines may use the control color, but keep the chunky sticker feel.
- Avoid shadows and gradients.
