# AI Implementation Prompt

Build a polished enterprise collaboration interface inspired by Atlassian.

Use a white and cloud product surface, navy text, bold Atlassian blue actions, bright secondary system colors, rounded SaaS cards, product screenshots, integration grids, and restrained friendly illustration. The design should feel trustworthy, practical, and collaborative.

Requirements:

- Use Charlie Display and Charlie Text if licensed. Otherwise use Inter, Arial, or a clean product sans.
- Use Navy and Slate for primary text and secondary text.
- Use Atlassian Blue for the main CTA, active states, links, and key product emphasis.
- Keep backgrounds mostly White, Cloud, or Pale Blue.
- Use rounded cards, pill CTAs, compact tabs, status chips, and clean form controls.
- Include product screenshots, workflow diagrams, integration logos, or feature grids as the main visual proof.
- Use secondary colors for icon tiles, status states, charts, and small illustration shapes.
- Add confetti or geometric accent shapes sparingly around hero or announcement sections.
- Use clear enterprise layout: nav, hero, proof band, feature grid, product panel, customer proof, footer.
- Avoid dark luxury palettes, serif editorial typography, excessive gradients, glassmorphism, messy collage, and cartoon-heavy scenes.

Hero recipe:

Create a white or pale blue hero with a large navy headline, Slate support copy, one blue primary CTA, one secondary text or ghost CTA, and a large rounded product screenshot panel. Add two or three small colored accent shapes only around the edge of the composition.

Feature grid recipe:

Create a 3-column grid of white cards on Cloud. Each card uses a small colored icon tile, bold navy title, Slate body copy, optional blue link, 12px to 16px radius, and a thin cloud border.
