# Colors

## Palette

| Name | Value | Token | Role |
|---|---:|---|---|
| Atlassian Blue | `#0052cc` | `--color-atlassian-blue` | Primary CTA, brand action, active nav, selected state |
| Bright Blue | `#0065ff` | `--color-bright-blue` | Links, hover states, product highlights, emphasis |
| Navy | `#172b4d` | `--color-navy` | Headings, strong text, primary navigation |
| Slate | `#42526e` | `--color-slate` | Body copy, secondary labels, inactive text |
| Cloud | `#f4f5f7` | `--color-cloud` | Page bands, card backgrounds, separators |
| White | `#ffffff` | `--color-white` | Main page surface and card fill |
| Purple | `#6554c0` | `--color-purple` | Icon tiles, charts, product family accents |
| Teal | `#00b8d9` | `--color-teal` | Workflow accents, illustration details, status |
| Green | `#36b37e` | `--color-green` | Success states, healthy status, positive chips |
| Yellow | `#ffc400` | `--color-yellow` | Warning, highlights, confetti accents |
| Red | `#ff5630` | `--color-red` | Error states, urgent badges, illustration accents |

## Usage

- Use White and Cloud as the dominant surfaces.
- Use Navy for strong reading hierarchy.
- Use Slate for secondary content.
- Use Atlassian Blue as the decisive action color.
- Use secondary colors as a system palette for icon tiles, charts, status, and confetti.
- Avoid using every secondary color in one component.
