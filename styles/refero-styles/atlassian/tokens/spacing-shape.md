# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Base unit | `4px` |
| Density | `comfortable` |
| Page max width | `1200px` |
| Section gap | `96px` |
| Card padding | `24px` |
| Element gap | `16px` |
| Product UI gap | `12px` to `24px` |
| Marketing hero padding | `80px` to `120px` |

## Spacing Tokens

Use `4`, `8`, `12`, `16`, `20`, `24`, `32`, `40`, `48`, `56`, `64`, `80`, `96`, `120`, and `144`.

## Radius

| Element | Radius |
|---|---:|
| Buttons | `999px` or `8px` depending on context |
| Cards | `16px` |
| Screenshots | `20px` |
| Inputs | `8px` |
| Chips | `999px` |
| Sections | `24px` |

## Shape Rules

- Use rounded elements, but keep them professional.
- Product UI can use 8px radius for compact controls.
- Marketing CTAs and chips can use pill radius.
- Cards and screenshot frames should feel soft but not childish.
- Avoid sharp brutalist boxes and over-rounded toy-like cards.
