# Layout And Imagery

## Layout Model

- Start with a clear top navigation and direct hero.
- Use White or pale blue hero surfaces with strong Navy headline copy.
- Put product screenshots or workflow visuals near the hero.
- Follow with proof bands, integration grids, and feature card sections.
- Use Cloud bands to separate content-heavy sections.
- Use structured footer columns for product, solution, resource, and company links.
- Keep product UI demos denser than marketing sections, but still calm.

## Imagery

- Use product screenshots, dashboards, workflow diagrams, integration logos, and collaboration illustrations.
- Favor clean vector or screenshot compositions over generic office stock.
- Use colored accent shapes only to support hierarchy.
- Avoid dark moody product photography, fashion imagery, luxury object lighting, and unrelated lifestyle shots.

## Motion

- Motion should be helpful and product-led.
- Use tab transitions, screenshot swaps, gentle card reveals, and diagram path animation.
- Avoid bouncy toy-like animation or constant decorative motion.
