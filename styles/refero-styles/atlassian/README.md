# Atlassian

AI-ready Refero style bundle for Atlassian.

- Source: https://styles.refero.design/style/c08ebca5-87d4-4c19-a5d7-ae5e670dae11
- Reference site: https://www.atlassian.com
- Captured: 2026-07-28
- Theme: mixed
- Mood: enterprise blue with collaborative confetti
- Industry: software, collaboration, productivity, developer tools

## Use This Style For

- SaaS, collaboration, project management, developer tooling, and work management sites
- Enterprise landing pages that need trust, clarity, and approachable energy
- Product dashboards that need structured blue accents, cards, tabs, and integration grids
- Brand pages that mix clean product UI with friendly illustrations and light motion

## Files

- `source.md` records the source URL and capture context.
- `DESIGN.md` is the main human-readable design reference.
- `implementation-prompt.md` is a direct prompt for an AI coding agent.
- `style.json` is a structured summary for indexing and retrieval.
- `tokens/` contains focused notes for colors, type, spacing, components, guidelines, layout, and imagery.
- `code/` contains CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` reserves the screenshot slot for manual or automated captures.

## Core Signature

Atlassian is clear enterprise software with friendly teamwork energy: blue-led hierarchy, white and cloud surfaces, navy text, rounded cards, pill CTAs, product screenshots, integration grids, and small celebratory shapes that support the work without overwhelming it.
