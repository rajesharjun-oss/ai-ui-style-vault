# Colors

## Action

| Name | Value | Token | Use |
| --- | --- | --- | --- |
| Vermillion Signal | `#e42b0c` | `--color-vermillion-signal` | Filled CTAs, selected conversion states, connector nodes |
| Sunset Flux | `linear-gradient(94deg, #ff0201 -33.85%, #ff7802 -1.54%, #ff0201 73.55%)` | `--gradient-vermillion-signal` | Top-nav conversion button only |

| Vellum | `#f5f5f5` | `--color-vellum` | Main page canvas |

## Rules

- Vermillion is action-only.
- Sunset Flux is nav-only.
- Keep the rest of the system monochrome.
- Use Slate 900 for text before reaching for Ink Black.
- Use Vellum and Paper to create a quiet surface rhythm.
