# Spacing And Shape

## Spacing

- Base unit: 8px.
- Density: comfortable but information-rich.
- Page max width: 1200px.
- Section gap: 64px.
- Card padding: 24px to 32px.
- Element gap: 16px.

## Elevation

- Standard shadow: `rgba(0, 0, 0, 0.1) 0px 1px 3px 0px, rgba(0, 0, 0, 0.1) 0px 1px 2px -1px`.
- Never exceed a 3px shadow offset.
- Prefer borders and surface changes over heavy depth.
