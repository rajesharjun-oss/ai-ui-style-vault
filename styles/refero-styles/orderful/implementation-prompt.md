# AI Implementation Prompt

Build a light Orderful-inspired B2B logistics or enterprise SaaS interface.

Use `#f5f5f5` as the page canvas and `#ffffff` for cards. Use `#101828` for display and heading text, `#4a5565` for body copy and labels, and `#e5e7eb` for card borders. Use `#e42b0c` as the only filled action color. Do not introduce any other bright accent.

Typography:

- Use telegraf as the primary font. If unavailable, use Inter, Sohne, Suisse Int'l, or system sans-serif.
- Use display weights between 300 and 500.
- Do not set display text in 700 weight.
- Use body text at 16px to 18px, weight 400, line-height 1.5.
- Use uppercase eyebrow labels at 12px, weight 500, letter-spacing 0.3px.
- Use modernGothic only for special 14px link or body registers if needed.

Layout:

- Create a sticky white nav, 64px tall, with a 1px `#e5e7eb` bottom border.
- Use a 1200px centered container.
- Build a split hero: left text and CTA, right product visual tile.
- Hero headline: 72px telegraf, weight 300, `#101828`, line-height 1, letter-spacing -2.16px.
- Use 64px gaps between major sections.
- Add a white logo strip and a three-column feature card grid.
- Use a testimonial block with quote, customer image, and stat row.

Components:

- Primary CTA: `#e42b0c` background, white text, 8px radius, uppercase 14px to 16px telegraf weight 500, 16px 24px padding, trailing arrow.
- Nav conversion button: Sunset Flux gradient, white uppercase text, 8px radius, 12px 20px padding.
- Carbon secondary action: `#1f1f1f` background, white text, 8px radius.
- Feature card: `#ffffff` background, 1px `#e5e7eb` border, 8px radius, 32px padding.
- Product visual tile: white outer tile with dark inner panels, vermillion connector nodes, and a brand-logo grid.
- Stat block: 60px thin number, 14px muted label, no card chrome.
- Text input: white background, 1px `#d4d4d4` border, 8px radius, 48px height.

Rules:

- Use 8px radius for all core UI.
- Do not use pill shapes.
- Use vermillion only for action surfaces or active conversion signals.
- Do not use vermillion for decorative text-only links.
- Keep shadows small and two-layer at most.
- Avoid abstract decorative gradients.
- Keep imagery product-led and operational.

The finished UI should feel like a precise enterprise command sheet: calm, dense, monochrome, and punctuated by one decisive vermillion action.
