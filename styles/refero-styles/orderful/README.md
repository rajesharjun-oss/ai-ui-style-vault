## Style Summary

Orderful is an industrial B2B command-deck style: matte vellum canvas, white cards, strong black typography, precise 8px geometry, sparse shadows, and a single vermillion signal for primary action. It feels like a logistics dispatch sheet turned into a polished SaaS interface.

Use this style when an AI needs an enterprise SaaS homepage, logistics dashboard, EDI product page, B2B operations site, case-study page, or product-led command-center interface.

## What To Borrow

- Vellum `#f5f5f5` as the main page canvas.
- Paper `#ffffff` for cards and primary content surfaces.
- Slate 900 `#101828` for headings and display text.
- Slate 600 `#4a5565` for body copy, icons, and eyebrows.
- Vermillion `#e42b0c` as the only filled action color.
- Sunset Flux gradient only for the top-nav conversion button.
- Telegraf as the workhorse typeface, with Inter or Suisse-style fallback.
- Display text at 48px to 72px with tight negative tracking.
- Universal 8px radius across nav, cards, images, inputs, tags, and buttons.
- 8px base spacing with 64px section gaps.
- Product UI mockups, brand grids, metrics, and grayscale trust logos.

## Avoid

- Any radius other than 8px for core UI.
- A second saturated accent color.
- Using vermillion for non-action decoration.
- Heavy shadows or deep elevation.
- Body text below 14px.
- Display headings in weight 700.
- Pill buttons or pill badges.
- Abstract decorative gradients or lifestyle imagery.
