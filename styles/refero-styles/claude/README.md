# Claude

Source: Refero Styles  
URL: https://styles.refero.design/style/47cb86b6-cb2d-41c8-94ba-8607cd7c41cd  
Reference site: https://claude.ai  
Captured: 2026-07-28

Claude is a warm parchment editorial product style: ink-like near-black text on bone paper, soft white cards, restrained serif headings, calm sans UI, and a single clay accent used as a small decorative breath. It should feel thoughtful, printed, and humane rather than glossy or typical SaaS.

Use this folder as an AI implementation brief. The most useful files are:

- `DESIGN.md` for the full style interpretation.
- `implementation-prompt.md` for a copy-ready prompt to hand to an AI builder.
- `style.json` for structured metadata.
- `code/css-variables.css` for CSS custom properties and component recipes.
- `code/tailwind-v4.css` for Tailwind v4 theme tokens.
- `code/design-tokens.json` for machine-readable tokens.

Core cues:

- Canvas: `#f8f8f6` Bone Parchment, never pure white for large backgrounds.
- Card surface: `#ffffff` Paper White.
- Nested surface: `#efeeeb` Soft Stone.
- Text: `#121212` Carbon Ink, warm near-black.
- Secondary text: `#373734` Graphite.
- Muted text: `#7b7974` Ashen and `#9c9a92` Pebble.
- Hairlines: `#b7b7b5` Mist and `#e7e6e1` Chalk.
- Accent: `#d97757` Clay for decorative marks only.
- Footer: `#000000` Obsidian, the only true black area.
- Display font: Anthropic Serif at 24px to 30px, weight 400.
- UI font: Anthropic Sans at 11px to 24px, mostly 400 to 580.
- Shape: 8px controls, 16px cards, 24px elevated/pricing cards.

This is best for AI assistants, research tools, knowledge products, pricing pages, editorial SaaS, help centers, and quiet productivity tools.
