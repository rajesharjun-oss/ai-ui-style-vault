# Implementation Prompt

Build a product-first athletic ecommerce interface in the Nike.com style.

Use a monochrome UI palette only: Obsidian `#111111`, Paper White `#ffffff`, Concrete Gray `#e5e5e5`, Soft Mist `#f5f5f5`, Steel `#707072`, and Faint Gray `#9e9ea0`. Do not introduce any UI accent color. Product photography should be the only source of saturation.

Use Helvetica Now-style typography for almost everything. Keep normal UI text compact, between 12px and 20px, with weights 400 and 500 only. Use a Nike Futura-style display face at 76px for hero headlines only; all smaller section titles should use Helvetica-style display medium at 20px to 24px.

Use sharp-edged product imagery and cards. Product cards, category image tiles, and photo containers have 0 radius, no border, no shadow, and edge-to-edge imagery. Buttons are the exception: every button is a 30px pill. Search fields and nav rounded controls use 24px radius.

Layout should alternate stark full-bleed dark hero sections with white product grids. Use hairline Concrete Gray dividers and whitespace for structure. The navigation stays minimal on white with no shadow, no blur, and no decorative background fill.

Avoid gradients behind text, decorative patterns, colorful UI badges, shadows, rounded cards, and multiple CTA styles. The UI should feel flat, fast, compact, and product-led.
