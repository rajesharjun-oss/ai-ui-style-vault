# Nike.com

Nike.com is a product-first monochrome commerce system: white gallery walls, sharp product photography, almost invisible UI chrome, pill CTAs, and one oversized sport-display headline moment.

- Source: https://styles.refero.design/style/d7ace114-0548-41f5-a2ff-2afbf32be94d
- Reference site: https://nike.com
- Captured: 2026-07-28
- Theme: mixed
- Best for: athletic commerce, fashion retail, product drops, editorial ecommerce, brand-led product grids

## Use This When Building

Keep the interface black, white, and gray. Let product photography provide all color. Use flat product cards, sharp image edges, hairline dividers, compact Helvetica-style UI text, and 30px pill buttons. Reserve the 76px Futura-style display type for hero headlines only.
