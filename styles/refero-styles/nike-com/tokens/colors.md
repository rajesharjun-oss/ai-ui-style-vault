# Colors

## Monochrome Palette

| Name | Value | Use |
|---|---:|---|
| Obsidian | `#111111` | Primary text, dark icons, dark pill fills, editorial dark sections |
| Steel | `#707072` | Secondary text, footer links, muted helper copy, icon outlines |
| Faint Gray | `#9e9ea0` | Disabled icon strokes, tertiary affordances, low-emphasis borders |
| Concrete Gray | `#e5e5e5` | Hairline borders, dividers, grid separators, subtle input outlines |
| Soft Mist | `#f5f5f5` | Search field fill, tag backgrounds, secondary surface tint |
| Paper White | `#ffffff` | Page background, product cards, button text on dark fills, icon strokes |

## Rules

- Use no UI accent color.
- Product photography supplies all color and energy.
- Use Obsidian and Paper White for CTA contrast.
- Use Steel for secondary text and footer links.
- Use Concrete Gray for separators instead of shadows.
- Do not add colored badges, colorful links, or brand-color fills.
