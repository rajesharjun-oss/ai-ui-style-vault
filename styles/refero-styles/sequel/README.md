## Use This When

Use this style for private membership networks, founder communities, family-office tools, high-trust advisory brands, premium media, member stories, invite-only products, and quiet luxury experiences that should feel discreet instead of flashy.

## Core Idea

Sequel is a pure-black cinematic system with no chromatic color. Warm portraiture, Lamp Cream action buttons, frosted glass badges, and soft editorial typography create the feeling of a private screening room. Elevation comes from tone, blur, and light, not from conventional card shadows.
