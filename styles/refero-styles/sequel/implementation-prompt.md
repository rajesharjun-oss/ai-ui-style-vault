# Implementation Prompt

Build a polished dark interface inspired by the Sequel Refero style system.

Use a pure black canvas, warm cinematic portrait imagery, restrained editorial typography, and a single warm off-white CTA color. The product should feel like a private screening room for a high-trust founder or membership network.

## Required Style Decisions

- Background: `#000000`.
- Primary action: Lamp Cream `#f5f5f0` with black text.
- Text: Pure White for primary text and Smoke `#999999` for secondary text.
- Elevated surfaces: Charcoal `#202020`, with no conventional shadow.
- Borders: Graphite `#333333` or Pure White only when needed.
- No chromatic accent color.
- No decorative gradients except a dark scrim over images for readability.
- Buttons, badges, and chips must be full pills.
- Cards and media should use 10px radius.
- Use large, sparse headlines with negative tracking.
- Use Bradford-like italic serif for only one emotional word in a headline.
- Use warm, dimly lit, documentary-style photography.

## Layout Direction

Create a cinematic page with:

- Transparent top navigation over the hero.
- Full-bleed hero media or a very large media panel.
- One cream primary CTA and one optional white-outline secondary CTA.
- Large editorial headline sections.
- Warm portrait cards with frosted badges.
- Generous section gaps around 96px to 120px.

## Component Direction

Primary buttons should be cream pills. Secondary buttons should be white outline pills. Badges should use translucent glass with blur. Cards should be flat charcoal blocks or full-bleed media cards, never bright panels.

## Avoid

- Blue, purple, gold, green, red, or any other chromatic accent.
- Drop shadows on cards, images, or panels.
- Overly bright gray backgrounds.
- Heavy borders around media.
- Loud SaaS-style gradients.
- Bold 700+ typography.
- Full serif headlines.
