# Metaview

Source: Refero Styles

Metaview is a dark AI product surface: a near-black green-tinted control room, flat product cards, whisper-light geometric typography, and one vivid mint signal for action and selection. The style is precise, quiet, and instrument-like.

Use this folder as an AI implementation brief. The most useful files are:

- `DESIGN.md` for the full style interpretation.
- `implementation-prompt.md` for a copy-ready prompt to hand to an AI builder.
- `style.json` for structured metadata.
- `code/css-variables.css` for CSS custom properties and component recipes.
- `code/tailwind-v4.css` for Tailwind v4 theme tokens.
- `code/design-tokens.json` for machine-readable tokens.

Core cues:

- Canvas: `#000a06` Deep Forest.
- Cards: `#0a1a14` Pine Bark, with `#161818` Charcoal only for true overlays.
- Accent: `#7affb4` Electric Mint, used only for the primary CTA, active tabs, and live status.
- Subtle accent: `#e3ffef` Mint Whisper for selected tab backgrounds and pale outlines.
- Borders: `#01051b` Abyssal Indigo.
- Text: `#ffffff` Paper White, with `#5e6262` Ash Gray for body copy.
- Type: Euclid Circular A style, with 300-weight display headings and tight negative tracking.
- Data: Onsite SemiMono style for counts, IDs, candidate metrics, and technical micro-copy.

This is best for AI recruiting tools, agent dashboards, product-led SaaS, dark control panels, chat/product mockups, and technical conversion pages.
