## Core Signature

Fey is a nocturnal finance terminal with Apple-like restraint: Fey Ink canvas, Calibre typography, 99px pill controls, 16px floating product cards, heavy black halo shadows, tight 48-54px display headlines, and color used only as signal: Ember for highlighted words, Signal blue for active navigation, and Growth green for financial action/status.
