# Implementation Prompt

Build a polished, responsive fintech interface in the Fey Refero style.

Use a dark finance-showroom system: Fey Ink `#0b0b0b` as the primary canvas, Fey Charcoal `#191919` for product cards, Fey Obsidian `#131313` for nested containers, Fey White `#ffffff` for primary text, Fey Graphite `#868f97` for secondary copy, Fey Mist `#cccccc` for strokes, Fey Ember `#ffa16c` for one warm highlighted word, Fey Signal `#479ffa` for active navigation, and Fey Growth `#4ebe96` for positive market movement.

Typography must use `Calibre` or a close substitute such as Inter, Satoshi, or General Sans. Use one type family only. Display headlines are 48-54px, weight 700, line-height 1.0-1.1, and letter-spacing around -0.08em. Body is 14px/1.5 weight 400. Nav and labels are 12-14px weight 500-600.

Layout rules:

- Center content in a 1200px max-width rail.
- Use 64px between major sections.
- Use 10-16px element gaps.
- Use 18-24px card padding.
- Use 16px radius on product cards.
- Use 99px radius for buttons, nav pills, badges, and dock controls.
- Use heavy black halo shadows around product mockups.
- Use product UI screenshots/mockups as the primary visual language.

Component rules:

- Pill nav controls are transparent with Graphite text and a Signal underline when active.
- Primary actions are ghost-like, white/black, and halo-lit, not chromatic filled buttons.
- Product cards float with `rgba(0,0,0,0.8) 0px 0px 44px 0px`.
- Insider transaction cards use avatar, name, company, and Buy/Sell pills.
- Status badges are tiny 99px pills and carry market meaning.
- Dock navigation is a rounded dark pill with monoline icons and a separated search button.
- Use one colored word at most in any headline.

Do not introduce a second typeface, use flat pure black as the main canvas, use filled chromatic CTA buttons, add decorative colors, stack multiple shadows, or apply positive/zero tracking to display headlines.
