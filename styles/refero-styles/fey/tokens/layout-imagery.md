# Layout And Imagery

## Layout Model

- Center content in a 1200px max-width rail.
- Keep the page full-bleed Fey Ink.
- Hero is a large floating product dashboard mockup followed by a compact headline.
- Use top-bar navigation only.
- Alternate dark bands and constrained content sections.
- Use 3-up feature grids for showcase cards.
- Use horizontally scrollable rows for highlights.
- Use a floating dock control over a dramatic dark product/stone image.

## Imagery

- Product UI mockups are the primary visual language.
- Show stock pages, portfolio dashboards, market-cap graphs, news feeds, and insider transaction rows.
- Use circular avatar crops only inside finance/product context.
- Use monoline icons at 1.5-2px stroke.
- A rough 3D stone/sculpture can be used behind dock navigation, lit on black.

## Avoid

- Lifestyle photography.
- Abstract illustration as the primary asset.
- Decorative color fills.
- Flat pure-black surfaces without halo depth.
- Generic dashboard density without product-showcase staging.
