# Colors

## Neutrals

| Name | Hex | Token | Usage |
|---|---:|---|---|
| Fey White | `#ffffff` | `--color-fey-white` | Primary text, hairlines, key values |
| Fey Ink | `#0b0b0b` | `--color-fey-ink` | Main canvas and core dark cards |
| Fey Charcoal | `#191919` | `--color-fey-charcoal` | Product mockup cards and feature panels |
| Fey Obsidian | `#131313` | `--color-fey-obsidian` | Nested cards and input wells |
| Fey Graphite | `#868f97` | `--color-fey-graphite` | Secondary copy, disabled labels, muted borders |
| Fey Mist | `#cccccc` | `--color-fey-mist` | Icon strokes, subtle links, tertiary borders |
| Fey Smoke | `#525252` | `--color-fey-smoke` | Deep dividers and low-emphasis strokes |
| Fey Pale | `#e6e6e6` | `--color-fey-pale` | Ghost outlines and light strokes |
| Fey Ash | `#999999` | `--color-fey-ash` | Low-emphasis borders and secondary text |
| Fey Abyss | `#000000` | `--color-fey-abyss` | Shadow base and deepest backdrops |

## Accents

| Name | Hex | Token | Usage |
|---|---:|---|---|
| Fey Ember | `#ffa16c` | `--color-fey-ember` | Warm headline highlight and warm gradient terminus |
| Fey Signal | `#479ffa` | `--color-fey-signal` | Active nav underline and cool trust accent |
| Fey Growth | `#4ebe96` | `--color-fey-growth` | Positive finance signals, Buy pills, market movement |
| Fey Frost | `#b6d6ff` | `--color-fey-frost` | Cool showcase gradient accent |
| Fey Volt | `#d6fe51` | `--color-fey-volt` | Electric highlight gradient accent |

## Behavior

- Treat color as signal.
- Use Fey Ink instead of pure black for page background.
- Use Fey White for primary values and headlines.
- Use Growth for finance/status meaning.
- Use Signal for navigation, not semantic status.
- Use Ember for one highlighted headline word at most.
