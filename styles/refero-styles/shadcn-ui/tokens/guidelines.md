# Guidelines

## Do

- Use monochrome surfaces for almost every UI decision.
- Use `#09090b` for primary text and primary button fill.
- Use `#71717b` for muted copy and metadata.
- Use `#e4e4e7` as the main hairline border color.
- Use 18px radius for interactive controls.
- Use 24px radius for cards, popovers, command palettes, and modals.
- Use Geist Mono only for technical text, code, and shortcuts.
- Keep most UI text at `14px`.
- Use red only for destructive and error states.
- Use small shadows only for floating overlays.

## Don't

- Do not add brand accent colors for decoration.
- Do not use red for normal links, icons, or highlights.
- Do not add heavy shadows to cards.
- Do not use large editorial typography.
- Do not use photos, illustrations, or gradients as primary decoration.
- Do not make card corners smaller than control corners.
- Do not spread monospace across normal body or nav text.
- Do not make compact admin UI feel like a marketing hero.
