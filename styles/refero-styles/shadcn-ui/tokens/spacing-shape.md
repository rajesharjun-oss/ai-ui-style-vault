# Spacing And Shape Tokens

## Spacing

| Purpose | Value |
| --- | --- |
| Density | compact |
| Base unit | `4px` |
| Max width | `1200px` to `1400px` |
| Section gap | `64px` |
| Card padding | `24px` |
| Element gap | `8px` |

## Spacing Scale

| Name | Value | Token |

## Radius

| Element | Value | Token |
| --- | --- | --- |
| tiny embedded elements | `8px` | `--radius-tiny` |
| interactive controls | `18px` | `--radius-control` |
| cards and overlays | `24px` | `--radius-card` |
| pills | `9999px` | `--radius-pill` |

## Borders And Elevation

- Default border: `1px solid #e4e4e7`.
- Default card shadow: none.
- Overlay shadow: `0 4px 6px -1px rgba(0,0,0,0.1), 0 2px 4px -2px rgba(0,0,0,0.1)`.
- Avoid heavy elevation and decorative shadows.
