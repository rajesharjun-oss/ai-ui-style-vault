# Layout And Imagery

## Layout Grammar

Use developer-tool structure: sidebars, top bars, command palettes, tabbed panels, card grids, and documentation layouts. The design should feel like a set of composable primitives, not a decorated landing page.

## Common Layouts

- Docs page with left sidebar, content column, and right table of contents.
- Component gallery with preview panels and code tabs.
- Settings page with two-column sections and compact forms.
- Dashboard cards in a 12-column grid.
- Command palette centered over a dim or plain background.
- Table-heavy admin page with compact filters and actions.

## Imagery

- Avoid decorative illustration and lifestyle photography.
- Use interface previews, code blocks, diagrams, or simple icon glyphs when visual support is needed.
- Keep visuals inside bordered preview panels.

## Composition Signatures

- Dense but readable nav sidebars.
- White cards with gray borders.
- Muted gray code or preview surfaces.
- Small pills and command shortcuts.
- Few colors, strong hierarchy, precise spacing.
