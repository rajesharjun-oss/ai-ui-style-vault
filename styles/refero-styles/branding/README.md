# Branding

AI-ready Refero style bundle for Branding.

- Source: https://styles.refero.design/style/4d4772a3-e1da-415f-a6d7-658dcefdcecd
- Reference site: https://www.svz.io
- Captured: 2026-07-28
- Theme: dark
- Mood: black gallery wall with arterial red punctuation
- Industry: agency, creative studio, brand strategy, editorial portfolio

## Use This Style For

- Dark creative agency and brand-studio websites
- Editorial portfolio pages where typography is the primary art direction
- Experiences that need black canvas, bone-white type, and a single rare red accent
- Sites that should feel like gallery signage, fashion editorial, or an art-directed manifesto

## Files

- `source.md` records the source URL and capture context.
- `DESIGN.md` is the main human-readable design reference.
- `implementation-prompt.md` is a direct prompt for an AI coding agent.
- `style.json` is a structured summary for indexing and retrieval.
- `tokens/` contains focused notes for colors, type, spacing, components, guidelines, layout, and imagery.
- `code/` contains CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` reserves the screenshot slot for manual or automated captures.

## Core Signature

Branding is an uncompromising dark editorial system: Void Canvas background, Bone White oversized display type, Kmr Waldenburg as the main voice, Editorialnew as a serif italic whisper, Dirtyline as ornamental spectacle, 8px hairline cards, ghost CTAs, and Arterial Red used like a punctuation mark rather than a broad fill.
