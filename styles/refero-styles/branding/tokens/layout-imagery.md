# Layout And Imagery

## Layout Model

- Use full-bleed Void Canvas.
- Avoid a global max-width container.
- Compose with large internal padding and asymmetry.
- Hero can be full viewport with 80-160px display type.
- Navigation is transparent and floats on the dark canvas.
- Alternate Void Canvas sections with rare Linen panels.
- Use 2-3 column card grids only when the content needs grouping.
- Use 24px gaps in card grids.

## Imagery

- Use high-contrast editorial photography.
- Favor surreal or fashion-editorial textures such as animal patterns, collage, and dark close crops.
- Let imagery bleed full-bleed with no rounded frame.
- Use oversized geometric background shapes in dark surface tones.
- Use minimal 1px arrows and line icons.

## Avoid

- Product screenshots as the primary visual language.
- Rounded thumbnail galleries.
- Lifestyle stock photography.
- Bright illustrative systems.
- Multicolor accents.
- 3D product mockups.
