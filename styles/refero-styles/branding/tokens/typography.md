# Typography

## Families

| Role | Preferred Font | Fallbacks | Notes |
|---|---|---|---|
| Primary display/UI | Kmr Waldenburg | Neue Haas Grotesk Display, Inter, Arial | Display, nav, body, buttons, labels |
| Serif italic companion | Editorialnew | Editorial Old, Playfair Display Italic, Georgia | Small connective words inside display compositions |
| Ornament | Dirtyline 36 Daysoftype 2022 | Tobias, Rogue Serif, Playfair Display | Single-letter or short ornamental moments |
| Quiet fallback | system-ui | -apple-system, Segoe UI, Arial | Micro-copy only when Kmr is too expressive |

## Rules

- Use Kmr Waldenburg as the default system voice.
- Use tight tracking for large caps.
- Track nav labels outward.
- Use Editorialnew italic only as connective tissue.
- Use Dirtyline only for one-letter or tiny spectacle moments.
- Keep body text compact at 14px and 1.5 line height.
