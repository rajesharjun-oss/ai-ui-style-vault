# Components

## Ghost CTA Link

- Text: Bone White.
- Font: Kmr Waldenburg, 12px, uppercase, weight 400.
- Tracking: about 0.071em.
- Decoration: diagonal arrow icon.
- Box: none.
- Padding: 32px vertical, 8px horizontal.

## Discovery Call Outlined Button

- Border: 1px Ash.
- Text: Bone White.
- Radius: 8px.
- Padding: 12px 24px.
- Font: 12px uppercase tracked Kmr Waldenburg.
- Include a diagonal arrow icon.

## Primary Red Action

- Background: Arterial Red.
- Text: Bone White.
- Radius: 9999px.
- Padding: compact pill.
- Use rarely for high-intent actions.

## Hero Display Headline

- Font: Kmr Waldenburg.
- Size: 160px.

- Transform: uppercase.

- Tracking: -12.8px.

## Section Transition Headline

## Bordered Brand Card

- Radius: 8px.

## Standard Card

- Background: Void Canvas or Linen.

## Hairline Link

- Font: Kmr Waldenburg, 12-14px, uppercase.
