# Spacing And Shape

## Spacing

| Purpose | Value | Notes |
|---|---:|---|
| Page max width | none | Full-bleed editorial canvas |
| Section gap | 48-64px | Main vertical rhythm |
| Hero breathing room | 80px | Use around display-heavy moments |
| Element gap | 24px | Between cards, nav groups, and editorial blocks |
| Card padding | 12-24px | Compact but deliberate |
| Footer padding | 48px minimum | Full-bleed footer panel |

## Radius

| Element | Value | Notes |
|---|---:|---|
| Nav containers | 3px | Tiny utility rounding only |
| Cards | 8px | Standard dark/light cards |
| Outlined buttons | 8px | Discovery call action |
| Large cards | 14.4px | Rare oversized content blocks |
| Accent pills/dots | 9999px | Red action pills or dots |

## Depth

- Avoid traditional drop shadows.
- Use 1px hairline borders.
- Use white inset highlight on dark cards: `rgba(255,255,255,0.2) 0px 2px 5px 0px inset`.
- Use surface tone shifts instead of elevation stacks.
