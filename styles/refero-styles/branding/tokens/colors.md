# Colors

## Brand

| Name | Hex | Token | Usage |
|---|---:|---|---|
| Arterial Red | `#fe1e34` | `--color-arterial-red` | Sole saturated accent, featured borders, dots, CTA fill |
| Crimson Pure | `#ff0000` | `--color-crimson-pure` | Typographic underline/fill accent only |

## Dark Surfaces

| Name | Hex | Token | Usage |
|---|---:|---|---|
| Void Canvas | `#080808` | `--color-void-canvas` | Main page background |
| Absolute Black | `#000000` | `--color-absolute-black` | Deepest surface, overlays, decorative shapes |
| Charcoal Plate | `#171617` | `--color-charcoal-plate` | Footer and off-void panels |
| Smoke Plate | `#262525` | `--color-smoke-plate` | Secondary dark surfaces and image treatments |
| Graphite Lift | `#393939` | `--color-graphite-lift` | Subtle elevated card surface |

## Light And Muted

| Name | Hex | Token | Usage |
|---|---:|---|---|
| Bone White | `#fcfcfc` | `--color-bone-white` | Primary text, borders, icon strokes |
| Linen | `#f3efef` | `--color-linen` | Inverted body panels and light editorial sections |
| Ash | `#d4d2d2` | `--color-ash` | Secondary text, nav labels, subtle borders |
| Pebble | `#b5b2b2` | `--color-pebble` | Tertiary text and disabled borders |
| Iron | `#525252` | `--color-iron` | Link underlines, dividers, separators |

## Behavior

- Keep the system near-monochrome.
- Use Arterial Red as punctuation, not paint.
- Use Linen as the only major light surface.
- Use Bone White and Ash for the majority of visible UI lines.
- Avoid gradients and extra accent colors.
