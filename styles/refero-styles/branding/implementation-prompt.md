# Implementation Prompt

Build a polished, responsive dark agency interface in the Branding/SVZ Refero style.

Use a full-bleed dark editorial system: Void Canvas `#080808` as the main page background, Bone White `#fcfcfc` for primary text and hairlines, Linen `#f3efef` for rare inverted panels, Charcoal Plate `#171617` and Smoke Plate `#262525` for secondary dark surfaces, and Arterial Red `#fe1e34` as the only saturated accent.

Typography is the product. Use `Kmr Waldenburg` for display, nav, body, buttons, and labels. Use `Editorialnew` italic at weight 300 for soft connective words inside large display lines. Use `Dirtyline 36 Daysoftype 2022` for rare ornamental single-letter spectacle. Substitute Neue Haas Grotesk Display or Inter for Kmr Waldenburg, Playfair Display Italic for Editorialnew, and an expressive calligraphic display face for Dirtyline.

Layout rules:

- Use a full-bleed dark canvas with no fixed max-width container.
- Use 48-64px section gaps and 24px element gaps.
- Use internal section padding rather than framed page cards.
- Set hero type at 80-160px, weight 700, all caps, very tight tracking.
- Keep nav transparent over the void.
- Use 8px card and outlined-button radius.
- Use 1px hairline borders.
- Use Linen panels sparingly as the only bright reading surface.

Component rules:

- CTAs are usually ghost editorial links with a diagonal arrow icon.
- The Discovery Call button is an outlined 8px rectangle with Ash border.
- Filled red buttons or red dots are rare and high-intent only.
- Featured project cards can use a red 1px border.
- Standard dark cards use hairline borders and optional white inset highlight.
- Footer is Charcoal Plate with Bone White text.
- Decorative background shapes should be huge, dark, and bleeding off-canvas.

Do not use conventional SaaS gradients, colorful icon sets, soft rounded cards, drop shadows, bright secondary colors, sticky white nav bars, or product-dashboard density.
