# Layout And Imagery

## Layout

- Reference site: https://twomuch.studio
- Max-width and section rhythm should follow the source spacing tokens.
- Respect the source theme: light.
- Build responsive layouts that keep source hierarchy intact.

## Imagery

- Use media and imagery patterns from the reference site.
- Primary screenshot reference: https://images.refero.design/styles/refero.design/image/c583446e-7b8d-477d-9dd0-898bb0e27a2f.jpg
- Preview poster reference: https://images.refero.design/styles/refero.design/image/bb415b2f-c81e-4b59-b4e9-d46e7f2f9bd1.jpg
- Avoid unrelated stock imagery or decoration that changes the style voice.

## Motion

Use restrained motion that supports the source style: hover, focus, subtle transitions, and no unnecessary spectacle.
