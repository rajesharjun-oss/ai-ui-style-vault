# Implementation Prompt

Build a UI in the Visitors style.

Create a bright analytics product interface with white canvas, carbon text, lavender primary action, pill controls, OpenRunde typography, hairline dashboard panels, and restrained functional category colors. The page should feel like a clean engineering blueprint for analytics software.

Use these hard rules:

- Canvas: `#ffffff`.
- Primary text: `#181925`.
- Secondary text: `#666666`.
- Muted text: `#999999`.
- Border/gridline: `#e8e8e8`.
- Subtle section surface: `#fafafa`.
- Input/ghost fill: `#f5f5f5`.
- Primary action: `#918df6`.
- Register nav action only: `#9580ff`.
- Positive metric text: `#33c758`, paired with background `#def6e4`.
- Realtime category: `#2c78fc`.
- Performance category: `#ffa600`.
- Profiles category: `#d6409f`.
- Chart fill or illustration accent only: `#ff3e00`.
- Use Lavender only for primary buttons and selected states.
- Use Iris only for register or nav emphasis.
- Do not mix multiple accent colors in one component.
- Use OpenRunde for all UI text.
- Display headline should be 60px, weight 600, line-height 1.13, letter-spacing -3px.
- Use 9999px radius for buttons, chips, and tags.
- Cards use 16px radius, tables use 24px, inputs/images use 8px.
- Use 1px Fog borders on cards and tables.
- Avoid dramatic shadows.

Build a centered hero with an announcement chip, 60px headline, supporting text, Lavender primary CTA, ghost secondary CTA, and partner logos. Below it, add a full-width sky-to-lavender gradient band with a floating white dashboard mockup containing metrics, charts, tabs, visitor profiles, and data tables. Keep the UI flat, bordered, and readable.
