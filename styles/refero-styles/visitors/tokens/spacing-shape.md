# Spacing And Shape

## Spacing

| Token | Value | Use |
| --- | ---: | --- |
| `unit` | 4px | Base spacing unit |
| `4` | 4px | Tight micro spacing |
| `8` | 8px | Nav padding, compact gaps |
| `12` | 12px | Dashboard metric padding |
| `16` | 16px | Element gap and local stacks |
| `20` | 20px | Button horizontal padding |
| `24` | 24px | Mid-size grouping |
| `32` | 32px | Card padding and feature vertical padding |
| `48` | 48px | Large layout rhythm |
| `64` | 64px | Section gap |
| `max-width` | 1200px | Page container |

## Radius

| Token | Value | Use |
| --- | ---: | --- |
| `image` | 8px | Product screenshots and images |
| `input` | 8px | Inputs and compact controls |
| `card` | 16px | Metric and dashboard cards |
| `table` | 24px | Data table containers and pricing tier cards |
| `button` | 9999px | CTAs and ghost buttons |
| `tag` | 9999px | Chips, tags, announcement pills |

## Shape Rules

- Buttons, chips, and tags are always pills.
- Do not use rectangular buttons.
- Cards should remain rounded but not pill-like.
- Tables get the largest structural radius.
