# Colors

| Token | Value | Use |
| --- | --- | --- |
| `--visitors-carbon` | `#181925` | Primary text, headings, nav links |
| `--visitors-paper-white` | `#ffffff` | Base canvas, card surfaces, button fills |
| `--visitors-linen` | `#fafafa` | Subtle background sections and table rows |
| `--visitors-mist` | `#f5f5f5` | Ghost fills, input fields, disabled surfaces |
| `--visitors-fog` | `#e8e8e8` | Hairline borders, table gridlines, card edges |
| `--visitors-ash` | `#999999` | Muted text, placeholders, inactive nav |
| `--visitors-graphite` | `#666666` | Secondary text, captions, light-button text |
| `--visitors-lavender` | `#918df6` | Primary action and selected states |
| `--visitors-iris` | `#9580ff` | Register nav button and deeper lavender emphasis |
| `--visitors-mint` | `#33c758` | Positive metric text when paired with Mint Wash |
| `--visitors-mint-wash` | `#def6e4` | Positive metric callout background |
| `--visitors-amber` | `#ffa600` | Performance category accent |
| `--visitors-sky` | `#2c78fc` | Realtime category, announcement chip, links |
| `--visitors-magenta` | `#d6409f` | Visitor profiles category and icon accent |
| `--visitors-ember` | `#ff3e00` | Chart fill and illustration accent only |

## Usage Rules

- Use Lavender for the primary CTA and selected states only.
- Use Iris only for a register/nav emphasis button.
- Pair Mint with Mint Wash for positive metric callouts.
- Keep Sky, Amber, and Magenta scoped to feature categories.
- Use Ember for chart fills and illustration, not chrome.
- Do not mix multiple accent colors in one component.
