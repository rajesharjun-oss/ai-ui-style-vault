# Layout And Imagery

## Layout

- Use full-width vertical sections.
- Center content in a 1200px max-width container.
- Hero is a centered stack: announcement chip, headline, subtext, dual CTA, partner logos.
- Follow hero with a sky-to-lavender band holding a floating dashboard mockup.
- Feature sections can use centered three-column icon grids.
- Product sections can use alternating two-column text and product layouts.
- Use generous 64px section spacing.
- Keep internal dashboard/card gaps around 16px.
- Navigation is a centered floating pill bar.
- Footer is minimal with multi-column links.

## Imagery

Use:

- Dashboard screenshots.
- Analytics cards and chart panels.
- Data tables.
- Visitor profile panels.
- Realtime lists.
- Small grayscale partner logos.
- Single-color icons inside 40px Lavender circles.

Avoid:

- Lifestyle photos.
- People-first imagery.
- Abstract decorative imagery replacing dashboard UI.
- Heavy illustrated icon systems.
- Accent colors without feature meaning.

## Gradient Notes

- Use sky-to-lavender gradient only as a full-bleed hero band behind dashboard mockups.
- Use shimmer gray for skeleton loading states.
- Use pale sky gradients for chart fills.
- Never put gradients on buttons, cards, or text.
