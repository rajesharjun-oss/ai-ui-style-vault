# Typography

## Primary Family

```css
font-family: OpenRunde, Inter, "DM Sans", "Geist Sans", system-ui, sans-serif;
```

Use OpenRunde across the system: headings, body, buttons, nav, cards, tables, and labels.

## Scale

| Token | Size | Weight | Line Height | Letter Spacing |
| --- | ---: | ---: | ---: | ---: |
| `caption` | 12px | 400 | 1.33 | -0.32px |
| `body` | 16px | 400 | 1.5 | -0.32px |
| `subheading` | 18px | 500 | 1.33 | -0.32px |
| `heading-sm` | 24px | 500 | 1.17 | -0.31px |
| `heading` | 36px | 500 | 1.22 | -0.61px |
| `heading-lg` | 48px | 500 | 1.0 | -0.34px |
| `display` | 60px | 600 | 1.13 | -3px |

## Rules

- Use weight 500 for headings and buttons.
- Use weight 400 for body and captions.
- Use weight 600 for the main display headline.
- Use negative tracking throughout.
- Do not make headings pure black; use Carbon.
