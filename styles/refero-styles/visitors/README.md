## Use This Style When

Use Visitors when the interface should feel like a clean analytics product: bright white, engineered, fast, flat, and credible. It is a good fit for dashboards, privacy analytics, metrics products, realtime monitoring, revenue panels, visitor profiles, and SaaS marketing pages that need a calm white surface with one clear conversion color.

## Quick DNA

- White canvas with restrained grayscale structure.
- Lavender `#918df6` is the primary CTA and selected-state color.
- OpenRunde drives the full UI with tight negative tracking.
- Buttons, chips, and tags are full pills.
- Dashboard cards use hairline Fog borders and minimal soft elevation.
- Positive metrics pair Mint text with Mint Wash backgrounds.
- Feature colors are functional categories, not decoration.
- Hero is centered text and CTA stack followed by a dashboard mockup in a lavender/sky band.
