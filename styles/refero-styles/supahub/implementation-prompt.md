# AI Implementation Prompt

Build the UI in the Supahub style: a bright, friendly SaaS feedback platform with white space, vivid violet actions, rounded product surfaces, floating mockups, gradient orbs, and testimonial walls.

Use Voltage Violet `#862fe7` as the only primary action color. Use white `#ffffff` as the main canvas, Midnight Ink `#111827` for text, Mist `#d8e0ea` for borders, and Slate `#6b7589` for supporting copy.

Core rules:

- Use Bricolage Grotesque for display and heading text at 20px and above.
- Use Inter for body copy, buttons, nav, captions, testimonials, and dense UI.
- Set hero display type around 56px, weight 600, line-height 1.0, letter-spacing around -1.4px.
- Keep hero display text inside a 680-720px column.
- Use Inter 12px uppercase labels with 0.1em tracking.
- Use Inter 16px body text and 18px supporting paragraphs.
- Use 1200px max-width page rails.
- Use a 4px base spacing scale.
- Use 12px radius for buttons, 24px for testimonial cards, 16px for product preview cards, and 9999px for avatars, tags, and badges.
- Use filled violet primary CTAs with white text.
- Use ghost secondary buttons with transparent fill, 1px dark border, and 12px radius.
- Place decorative violet, pink, and amber gradient orbs behind product preview cards, never behind text or buttons.
- Use testimonial cards with white background, 1px Mist border, 24px radius, and avatar plus star details.
- Use one soft shadow only for floating product preview cards.

Avoid promoting pink, amber, or mint to primary actions, using Bricolage below 20px, stretching display headlines across the full page, heavy shadows, and enterprise-gray dashboard density.

The result should feel sunny, confident, rounded, and product-feedback focused.
