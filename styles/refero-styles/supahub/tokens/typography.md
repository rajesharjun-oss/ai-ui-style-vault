# Typography

## Families

- Display and headings: `Bricolage Grotesque`
- Body and UI: `Inter`
- Display fallback: `Space Grotesk`

Bricolage makes calm confident declarations. Inter translates those declarations into readable interface copy.

## Type Scale

| Role | Size | Line Height | Tracking | Family | Notes |
| --- | ---: | ---: | ---: | --- | --- |
| Caption / eyebrow | 12px | 1.5 | 1.2px | Inter | Uppercase labels, weight 700 |
| Body small | 14px | 1.6 | 0 | Inter | Nav, metadata, testimonial handles |
| Body | 16px | 1.75 | 0 | Inter | Main body and UI copy |
| Subheading | 20px | 1.5 | 0 | Inter or Bricolage | Larger support copy |
| Heading small | 24px | 1.3 | -0.6px | Bricolage | Small cards and panels |
| Heading | 32px | 1.2 | -0.8px | Bricolage | Section headings |
| Display | 56px | 1.0 | -1.4px | Bricolage | Hero and major headlines |

## Rules

- Do not use Bricolage below 20px.
- Do not use Inter for hero display duty.
- Keep large Bricolage text tightly tracked.
- Use Inter 12px uppercase labels with 0.1em tracking.
- Keep hero and display copy inside a 680-720px column.
- Use weight 600 for major display emphasis, 400 for calmer display copy.

## Responsive Notes

On mobile, reduce display type to 40-44px while keeping tight tracking and clean line breaks. If line breaks become awkward, rewrite the heading before making it tiny.
