## Layout Values

- Page max width: 1200px.
- Display headline column: 680-720px.
- Feature band vertical padding: 80px.
- Card padding: 24px.
- Button padding: 16px 24px.
- Hero copy max width: around 680px.

## Radius

| Element | Value | Notes |
| --- | ---: | --- |
| Nav | 8px | Header controls |
| Buttons | 12px | Primary and ghost actions |
| Images | 16px | Product previews |
| Cards | 24px | Testimonials and content cards |
| Featured card | 40px | Large hero/product cards |
| Pills | 9999px | Avatars, tags, badges |

## Shadows

Surface differentiation is mostly color and border based.

Use:

- Button inset ring: `rgba(11, 61, 121, 0.16) 0 0 0 1px inset`.
- Product preview shadow: `0 20px 40px rgba(124, 58, 237, 0.15)`.

Do not create a broad card hover shadow system.
