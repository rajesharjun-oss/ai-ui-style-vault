# Color Tokens

## Brand And Commerce

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Apple Blue | `#0071e3` | `--color-apple-blue` | Primary CTA, buy button, active commerce action. |
| Link Blue | `#0066cc` | `--color-link-blue` | Inline links, secondary CTA text, learn-more links. |

## Neutrals

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Deep Ink | `#1d1d1f` | `--color-deep-ink` | Main headlines and highest contrast text. |
| Body Ink | `#333333` | `--color-body-ink` | Secondary high-emphasis body text. |
| Mid Graphite | `#424245` | `--color-mid-graphite` | Nav text, body copy, product labels. |
| Graphite | `#6e6e73` | `--color-graphite` | Captions, eyebrows, secondary text. |
| System Gray | `#86868b` | `--color-system-gray` | Legal text, inactive copy, muted labels. |
| Hairline | `#d2d2d7` | `--color-hairline` | Borders, dividers, tile separations. |
| Frost | `#f5f5f7` | `--color-frost` | Page bands, product tiles, nav wash. |
| Soft Frost | `#fbfbfd` | `--color-soft-frost` | Hero product background and clean product stage. |
| Pure White | `#ffffff` | `--color-pure-white` | Main page canvas and card surfaces. |
| Black | `#000000` | `--color-black` | Footer text, device silhouettes, deep contrast. |

## State

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Green | `#008009` | `--color-green` | Environmental values, trade-in, availability, positive state. |
| Product Red | `#bf4800` | `--color-product-red` | New or promotional product status. |

## Rules

- Use white and frost for almost all surfaces.
- Use Apple Blue only for commerce actions and selected links.
- Use Link Blue for text links and learn-more actions.
- Keep state colors rare and tied to meaning.
- Do not add decorative accent colors.
