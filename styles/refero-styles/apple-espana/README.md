# Apple Espana

Source: https://styles.refero.design/style/c9cabb96-32fa-4896-837a-f2497ce1c856

Product/site reference: https://www.apple.com/es/

## Snapshot

- **Mood:** Bright retail theater with pure white staging, frosted navigation, and impossibly close product imagery.
- **Theme:** Light, premium, product-led, commerce-ready.
- **Core grammar:** SF Pro typography, white and frost surfaces, large centered product images, blue commerce CTAs, hairline borders, pill buttons.
- **Best for:** Premium product pages, device launches, consumer electronics, accessory stores, comparison pages, retail commerce flows.

Apple Espana is a product-first retail language. The page should feel like a pristine showroom: white or near-white surfaces, very large product imagery, centered hierarchy, tight SF Pro typography, and tiny blue actions. It avoids decorative UI because the product itself is the decoration.

## Fast Build Notes

- Use `#ffffff`, `#fbfbfd`, and `#f5f5f7` as the main surfaces.
- Use `#1d1d1f` for headlines and `#6e6e73` for muted text.
- Use `#0071e3` for filled buy buttons and `#0066cc` for text links.
- Use SF Pro or system Apple fonts.
- Use large centered product imagery as the primary visual element.
- Use pill CTAs with very large radius.
- Use 28px to 32px radius for product tiles.
- Avoid decorative cards, heavy shadows, and unrelated accent colors.
