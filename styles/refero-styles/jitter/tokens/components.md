# Components

## Navigation Header

- Background: `#ffffff`
- Height: about 64px
- Logo and links: `#19171c`
- Links: Inter 14px to 16px, weight 500
- CTA: dark filled pill button
- Behavior: sticky on scroll

## Dark Filled Pill Button

- Background: `#19171c`
- Text: `#ffffff`
- Radius: 50px
- Padding: 10px to 12px vertical, 20px to 24px horizontal
- Font: Inter 14px to 16px, weight 500 to 600
- Use for nav-level and overlay CTAs.

## Violet Filled Pill Button

- Background: `#7a40ed`
- Text: `#ffffff`
- Radius: 50px
- Padding: 16px 32px
- Font: Inter 16px, weight 600
- Use once as the hero CTA.

## Pill Badge Or Tag

- Radius: 40px
- Background: Lavender Mist, Volt, or Lilac Wash
- Text: Deep Plum or Ink
- Font: Inter 12px to 14px, weight 500
- Use as a one-per-section kicker above headings.

## Animation Preview Card

- Background: `#ffffff`
- Radius: 40px
- Padding: 0
- Media: edge to edge
- Shadow: four-layer diffuse preview shadow
- Use for template previews, animation screenshots, and motion examples.

## Logo Cloud Strip

- Background: Studio Off-White canvas
- Intro text: Slate, Inter 14px/500
- Logos: Ink, roughly 20px to 24px tall
- Gap: 40px to 60px
- No separators.

## Hero Section

- Layout: centered stack
- Elements: badge, 80px TWK Lausanne headline, one violet CTA, logo cloud
- No hero image.

## Two-Column Feature Section

- One column: 40px to 48px TWK Lausanne heading and Inter copy
- Other column: Animation Preview Card
- Alternate order between sections.

## Template Card Grid

- Horizontal-scrolling row

- Cards use 40px radius and diffuse shadow
