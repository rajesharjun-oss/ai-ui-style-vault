# Spacing And Shape

## Spacing

| Purpose | Value | Notes |
|---|---:|---|
| Density | spacious | Large vertical rhythm on a soft canvas |
| Base unit | 4px | Token foundation |
| Max width | 1200px | Centered page content |
| Section gap | 80px to 120px | Major bands separated by whitespace |
| Column gap | 40px to 64px | Text/media feature sections |
| Dark button padding | 10px to 12px vertical, 20px to 24px horizontal | Nav and overlay CTAs |
| Hero CTA padding | 16px 32px | Larger singular violet action |
| Badge padding | 4px to 8px vertical, 12px to 16px horizontal | Kicker labels |

## Shape

| Element | Radius | Notes |
|---|---:|---|
| Buttons | 50px | Capsule shape |
| Cards | 40px | Pillow preview cards |
| Preview tiles | 40px | Edge-to-edge media |
| Badges and tags | 40px | Rounded kicker labels |
| Dark input | 26px | Rounded but less pill-like |
| Menu button | 9999px | Perfect circle |

## Elevation

Use the diffuse preview-card shadow:

```css
0 152px 61px rgba(25, 23, 28, 0.01),
0 85px 51px rgba(25, 23, 28, 0.05),
0 38px 38px rgba(25, 23, 28, 0.09),
0 9px 21px rgba(25, 23, 28, 0.10)
```

Avoid hard, single-layer shadows.
