# Colors

| Name | Value | Token | Role |
|---|---:|---|---|
| Studio Off-White | `#f2f1f3` | `--color-studio-off-white` | Page canvas and recessed section backgrounds |
| Pure White | `#ffffff` | `--color-pure-white` | Cards, elevated panels, preview tiles, text on dark fills |
| Hairline Gray | `#e5e4e7` | `--color-hairline-gray` | Subtle borders, divider lines, muted card backgrounds |
| Soft Mist | `#97979b` | `--color-soft-mist` | Muted secondary text and placeholder labels |
| Slate | `#6e6e73` | `--color-slate` | Body copy in card contexts and secondary text |
| Ink | `#19171c` | `--color-ink` | Primary text, nav links, dark buttons, high-contrast blocks |
| Pure Black | `#000000` | `--color-pure-black` | Icon fills and maximum-contrast surfaces only |
| Eclipse Violet | `#7a40ed` | `--color-eclipse-violet` | Singular hero CTA and rare brand emphasis |
| Deep Plum | `#17082c` | `--color-deep-plum` | Dark violet heading warmth and text on violet tags |
| Lilac Wash | `#a981ff` | `--color-lilac-wash` | Violet decorative accent and highlighted labels |
| Lavender Mist | `#cab3f8` | `--color-lavender-mist` | Pill badge and soft violet highlight washes |
| Electric Blue | `#00b2ff` | `--color-electric-blue` | Animated rings, icon accents, card border highlights |
| Sky Tint | `#e6f4ff` | `--color-sky-tint` | Cool blue-tinted card backgrounds and washes |
| Ice Blue | `#a9dbff` | `--color-ice-blue` | Decorative fills inside animated graphics |
| Volt | `#f5ff63` | `--color-volt` | Electric yellow-green tag/status accent |

## Guidance

- Use Studio Off-White as the dominant canvas.
- Use Pure White for preview cards and elevated panels.
- Use Ink instead of pure black for primary text and dark buttons.
- Use Eclipse Violet once per view for the hero CTA.
- Use Electric Blue and Volt only as small highlights.
- Avoid adding extra accent colors.
