# Guidelines

## Do

- Use Studio Off-White as the page canvas.
- Use one Eclipse Violet CTA in the hero.
- Use dark Ink fill for navigation CTAs.
- Use 50px radius on buttons.
- Use 40px radius on cards, badges, and preview tiles.
- Use TWK Lausanne at hero scale with tight tracking and compressed line-height.
- Use Inter for UI and body text.
- Use the four-layer diffuse shadow stack on elevated preview cards.
- Keep accent color sparse.

## Do Not

- Do not use sharp corners or radii below 20px.
- Do not place the violet CTA in the navigation bar.
- Do not use pure black for default body text or button fills.
- Do not use hard-edged or single-layer shadows.
- Do not use Volt on dark backgrounds without dark text.
- Do not set display type above 26px in Inter.
- Do not introduce a fourth chromatic accent beyond violet, blue, and Volt.
