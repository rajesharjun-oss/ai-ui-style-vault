# Layout And Imagery

## Layout Pattern

The core page structure is:

1. Sticky white top nav.
2. Centered hero stack with badge, headline, CTA, and logo cloud.
3. Spacious off-white section bands.
4. Alternating two-column feature sections.
5. Horizontal-scrolling preview/template card row.
6. Sparse footer with Ink and violet links.

## Grid

- Use max width around 1200px.
- Use large vertical gaps between sections.
- Avoid sidebars and persistent rails.
- Keep hero typographic and centered.
- Use preview cards as the main visual engine.
- Stack feature sections cleanly on mobile.

## Imagery

Use:

- Animation software screenshots.
- Template preview tiles.
- Motion artifacts and video frames.
- Floating UI mockups.
- Rounded cards with edge-to-edge media.
- Small electric blue or Volt highlights inside motion examples.

Avoid:

- Stock photography.
- Generic illustration-first hero pages.
- Dense enterprise dashboards.
- Extra accent colors.
- Sharp rectangular screenshots.
