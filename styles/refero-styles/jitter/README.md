# Jitter

Kinetic playground in Swiss precision: a soft off-white motion-design site with huge rounded preview cards, pill CTAs, tight TWK Lausanne display type, Inter UI copy, violet brand sparks, and diffuse floating shadows.

Use this style when you want a motion tool, creative editor, template gallery, video product, or design SaaS interface to feel playful, crisp, and premium without getting visually noisy.

## Files

- `source.md`: Source URL, reference site, capture notes, and scope.
- `DESIGN.md`: Human-readable design breakdown.
- `implementation-prompt.md`: Prompt for an AI builder to implement the style.
- `style.json`: Structured design metadata.
- `tokens/`: Markdown token notes by category.
- `code/`: CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md`: Placeholder for future manual screenshots.

## Quick Use

1. Use `Studio Off-White` as the page canvas.
2. Use `Ink` for primary text and dark nav-level CTAs.
3. Use one `Eclipse Violet` hero CTA per view.
4. Use 50px radius for buttons and 40px radius for cards, badges, and preview tiles.
5. Use the four-layer diffuse shadow stack on elevated preview cards.
6. Use TWK Lausanne for display/headings and Inter for body/UI.
