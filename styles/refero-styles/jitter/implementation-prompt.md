# AI Implementation Prompt

Build a polished, responsive interface in the Jitter style.

The interface should feel like a light motion-design playground with Swiss precision: soft off-white canvas, huge rounded white preview cards, pill buttons, tight TWK Lausanne display type, Inter UI copy, one violet hero CTA, dark nav CTA, sparse blue/Volt highlights, and soft floating shadows.

Core rules:

- Use `#f2f1f3` as the page canvas.
- Use `#19171c` for primary text and dark filled nav-level CTAs.
- Use `#7a40ed` for a single hero CTA only.
- Use `#00b2ff` and `#f5ff63` only for small highlights, tags, animation details, and status-like moments.
- Use 50px radius for buttons.
- Use 40px radius for cards, badges, and preview tiles.
- Avoid radii below 20px.
- Use TWK Lausanne or Inter Tight fallback for large headings and hero display.
- Use Inter for nav, buttons, body copy, badges, forms, and cards.
- Use the four-layer diffuse shadow on animation preview cards.

Recommended layout:

1. Sticky white navigation with Ink links, a ghost login link, and a dark pill CTA.
2. Centered hero stack with one pill badge, an 80px TWK Lausanne headline, one violet CTA, and a logo cloud.
3. Wide off-white whitespace between sections.
4. Two-column feature blocks with large heading/copy on one side and rounded animation preview card on the other.
5. Horizontal-scrolling template/animation card row with white 40px cards and diffuse shadows.
6. Clean footer with Ink text and sparse violet links.

Make the product feel creative, precise, bouncy, and premium without becoming a rainbow interface.
