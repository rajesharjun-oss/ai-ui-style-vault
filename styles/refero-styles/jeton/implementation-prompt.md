# Implementation Prompt - Jeton Style

Build an original UI using the Jeton Refero style as visual direction.

Use a light editorial fintech system: white canvas, warm Ink Roast text, one dominant Signal Orange accent, huge tight-set headings, spacious layout, and rounded geometric UI. The page should feel premium, sparse, warm, and confident, closer to a financial magazine spread than a dense SaaS dashboard.

## Must Preserve

- Dominant white canvas with minimal background alternation.
- Signal Orange `#f73b20` as the primary accent.
- Ink Roast `#360802` for body and heading text.
- Geometric grotesque type using Sequel Sans if available, otherwise Inter, Manrope, or DM Sans.
- Font weights limited to 400, 450, and 500.
- Headlines at 72-155px with 0.9-1.0 line-height.
- Positive letter spacing: 0.01em on display, 0.03em on small labels/buttons.
- 16px radius for cards and inputs; 12px for primary buttons; 84px or 9999px for pills.
- Section gaps around 80px or more.
- Minimal elevation, using only the documented orange glass shadow or inverted content-card shadow.
- Category colors only for specific feature groups, not as general decoration.

## Avoid

- Copying Jeton logos, product screenshots, exact page copy, or proprietary layouts.
- Dense dashboards, heavy tables, cramped cards, or small all-over text.
- More than one primary accent color.
- Bold 600+ type.
- Heavy drop shadows, gradients everywhere, or decorative borders.
- Pure black body text.
- Sharp corners on interactive controls.

## Component Direction

Create hero, nav, cards, inputs, and CTAs with generous whitespace and exact token use. Make the first viewport strongly signal the product category through oversized typography and simple fintech-oriented UI controls, not through a marketing hero card.
