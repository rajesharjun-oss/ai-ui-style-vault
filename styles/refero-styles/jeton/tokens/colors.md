# Colors

## Brand

| Name | Value | Token | Use |
|------|-------|-------|-----|
| Signal Orange | `#f73b20` | `--color-signal-orange` | Primary brand accent for CTAs, links, icons, and key emphasis. |
| Brand Orange Tint | `#f84d35` | `--color-brand-orange-tint` | Softer brand orange for small active states and tiny UI marks. |

## Text And Neutrals

| Name | Value | Token | Use |
|------|-------|-------|-----|
| Ink Roast | `#360802` | `--color-ink-roast` | Primary heading, body, and input text. |
| Paper White | `#ffffff` | `--color-paper-white` | Dominant page canvas and card surface. |
| Carbon Black | `#000000` | `--color-carbon-black` | Utility labels and icons only. |
| Ash Grey | `#ababab` | `--color-ash-grey` | Disabled states, placeholder text, and low-emphasis dividers. |
| Sand Wash | `#e7dcdb` | `--color-sand-wash` | Warm neutral wash and soft separators. |

## Soft Surfaces

| Name | Value | Token | Use |
|------|-------|-------|-----|
| Linen Blush | `#fdedea` | `--color-linen-blush` | Warm card, input, and row surface. |
| Citrus Wash | `#f5ffbb` | `--color-citrus-wash` | Pale highlight surface. |
| Mint Wash | `#bcffbb` | `--color-mint-wash` | Soft green emphasis or funding surface. |
| Brand Tint Alpha | `rgba(247,59,32,0.05)` | `--surface-category-tint` | Subtle category and input tint. |
| Frosted Glass | `#ffffff1a` | `--surface-frosted-glass` | Translucent floating panel overlay. |

## Category Accents

| Name | Value | Token | Use |
|------|-------|-------|-----|
| Coral Red | `#fb2d54` | `--color-coral-red` | Exchange or currency feature category. |
| Cobalt Blue | `#477ee9` | `--color-cobalt-blue` | Send or transfer feature category. |
| Emerald Green | `#34c771` | `--color-emerald-green` | Add, funding, or positive feature category. |

## Rules

- Use Signal Orange as the only general-purpose accent.
- Use category colors only when a feature group needs semantic separation.
- Use Ink Roast instead of pure black for readable body copy.
- Keep white as the dominant surface.
- Warm tints should be quiet, not full-page color floods.
