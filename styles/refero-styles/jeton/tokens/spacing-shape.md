# Spacing And Shape

## Core Values

| Purpose | Value |
|---------|-------|
| Density | comfortable |
| Base unit | 4px |
| Max width | 1200px |
| Section gap | 80px |
| Card padding | 16px |
| Element gap | 8px |

## Border Radius

| Element | Value | Token |
|---------|-------|-------|
| Links | 8px | `--radius-links` |
| Buttons | 12px | `--radius-buttons` |
| Cards | 16px | `--radius-cards` |
| Inputs | 16px | `--radius-inputs` |
| Nav | 84px | `--radius-nav` |
| Pills | 9999px | `--radius-pills` |

| Name | Value | Token |
|------|-------|-------|
| Floating Glass Panel | `rgba(247, 59, 32, 0.1) 0px 8px 24px 0px, rgba(247, 59, 32, 0.05) 0px 2px 8px 0px` | `--shadow-lg` |
| Content Card | `rgba(0, 0, 0, 0.05) 0px -4px 16px 0px` | `--shadow-md` |

## Shape Rules

- Cards and inputs default to 16px radius.
- Primary buttons use 12px radius.
- Nav and special pill controls use 84px or 9999px radius.
- Avoid square corners on interactive UI.
- Prefer whitespace over borders for section separation.
