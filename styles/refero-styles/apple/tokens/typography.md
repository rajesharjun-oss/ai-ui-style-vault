# Typography

## Families

| Family | Token | Role |
|---|---|---|
| SF Pro Display | `--font-sf-pro-display` | Product names, display headlines, and large feature text |
| SF Pro Text | `--font-sf-pro-text` | Body, nav, buttons, subheads, labels, and footer |

## Substitutes

- Use Inter or system-ui if SF Pro is unavailable.

## Type Scale

## Weight Rules

- Use weight 300 for subheads and editorial descriptors.
- Use weight 400 for body copy and standard actions.
- Use weight 600 for product names, nav emphasis, and button text when needed.
- Reserve weight 700 for editorial lockups or promotional art, not product-name headings.
