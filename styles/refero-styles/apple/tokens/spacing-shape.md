# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Density | `comfortable` |
| Base unit | `4px` |
| Max width | `1440px` |
| Text max width | `980px` |
| Section gap | `64px` |
| Card padding | `24px` |
| Element gap | `12px` |

## Scale

`4px`, `8px`, `12px`, `16px`, `20px`, `24px`, `40px`, `48px`, `56px`, `64px`

## Radius

| Element | Value |
|---|---:|
| Cards | `8px` |
| Images | `8px` |
| Inputs | `8px` |
| Tags | `980px` |
| Buttons | `980px` |

## Elevation

- Product images may use `rgba(0, 0, 0, 0.22) 3px 5px 30px 0px`.
- Buttons, nav, cards, and panels use no shadows.
- Use hairline borders and surface shifts instead.
