# Colors

## Brand

| Name | Value | Token | Role |
|---|---:|---|---|
| Apple Blue | `#0071e3` | `--color-apple-blue` | Filled action buttons and selected states only |
| Link Blue | `#0066cc` | `--color-link-blue` | Outlined action borders and inline links |
| Signal Blue | `#2997ff` | `--color-signal-blue` | Decorative borders, image outlines, icon strokes, and atmospheric emphasis |

## Neutrals

| Name | Value | Token | Role |
|---|---:|---|---|
| Onyx | `#000000` | `--color-onyx` | Heading borders, nav borders, and dark image backgrounds |
| Carbon | `#1d1d1f` | `--color-carbon` | Primary text, heading borders, nav rules, and card borders |
| Smoke | `#333333` | `--color-smoke` | Secondary text, nav fills, button borders |
| Graphite | `#474747` | `--color-graphite` | Tertiary nav text, nav borders, link borders |
| Ash | `#707070` | `--color-ash` | Footer text, list borders, muted body text |
| Mist | `#858585` | `--color-mist` | Hairline strokes, icon strokes, button borders |
| Pebble | `#e2e2e5` | `--color-pebble` | Button background fills, disabled surfaces |
| Frost | `#f5f5f7` | `--color-frost` | Page canvas, section backgrounds, footer surface |
| Ice | `#f4f8fb` | `--color-ice` | Barely-blue elevated surface wash and button text on dark |

## Rules

- `#0071e3` is only for filled buttons and selected states.
- `#0066cc` is for links and outlined actions.
- `#2997ff` is decorative or atmospheric only.
- Do not mix the three blues in a single component.
- Chrome is flat: no shadows on buttons, nav, or cards.
