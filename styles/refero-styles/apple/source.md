## What To Preserve

Apple is a product-as-hero system. The canvas is near-white, the chrome is almost invisible, and product photography or lifestyle imagery carries the page. Typography does much of the work: SF Pro Display and SF Pro Text use precise negative tracking, 17px body copy, light subheads, and product-name headings that avoid unnecessary boldness.

## What To Avoid Copying

Do not copy Apple logos, product renders, device imagery, exact page layouts, service marks, copy, or navigation text. Use the token system and component logic to create original consumer-product, hardware, ecommerce, or promotional product pages.

## Build Context

This bundle is meant for AI-assisted UI implementation. Use the markdown files for design intent, and use the `code/` files for direct token import when building with CSS variables or Tailwind v4.
