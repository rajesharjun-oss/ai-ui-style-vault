# Implementation Prompt

Create an original light consumer-product or premium ecommerce page inspired by the Apple Refero style.

Use a full-bleed `#f5f5f7` canvas, near-black text `#1d1d1f`, and centered product-first sections. Use `#0071e3` only for filled primary action buttons, `#0066cc` only for outlined secondary actions and links, and `#2997ff` only for decorative product accents. Avoid shadows on cards, nav, and buttons.

Use SF Pro Display or Inter/system-ui for large headings, and SF Pro Text or Inter/system-ui for body, nav, buttons, and subheads. Body text should be 17px with `-0.016em` tracking. Subheads and editorial descriptors should use weight 300. Product-name headings should not exceed weight 600.

Build these elements:

- Global nav bar with 12px links, hairline bottom border, and minimal icons.
- Sticky mini-nav with product name at 21px/600 and right-aligned action links.
- Full-bleed product hero with centered 56px/600 product name, 26px/300 tagline, and two 980px-radius buttons.
- Filled pill button: `#0071e3`, white text, 11px 15px padding, no shadow.
- Outlined pill button: transparent fill, 1px `#0066cc` border, `#0066cc` text.
- Full-bleed feature banner using product photography or a single product color wash.
- Service cards with full-bleed photography, 8px radius, white text overlays, and small pill actions.
- Flat footer with multi-column link grid and hairline dividers.

Do not copy Apple brand assets, product images, exact page copy, or proprietary layouts. Generate a new premium product page that borrows only the mood, token relationships, and component logic.
