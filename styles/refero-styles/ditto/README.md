# Ditto

AI-ready Refero style bundle for a warm, garden-inspired compliance SaaS interface: cream canvas, green-tinted card surfaces, vivid yellow pill CTAs, deep violet ink, serif headlines, Inter UI text, and organic decorative blobs behind product visuals.

## Source

- Refero style: https://styles.refero.design/style/e9001d5a-504d-47ed-aef0-d0d35fa86418
- Reference site: https://trustditto.com
- Captured: 2026-07-28
- Theme: light

## Use This When

- You need a friendly compliance, CSR, trust, sustainability, customer proof, or B2B workflow interface.
- The UI should feel warm and human rather than sterile or corporate.
- You want clear product screenshots, soft organic atmosphere, and highly legible CTA hierarchy.

## Bundle Contents

- `DESIGN.md` - complete AI style reference.
- `implementation-prompt.md` - drop-in prompt for AI implementation.
- `style.json` - structured metadata and searchable summary.
- `tokens/` - colors, typography, spacing, components, guidelines, layout, and imagery.
- `code/` - CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` - screenshot capture notes.

## Implementation Notes

Use this as an inspiration reference, not as an official Ditto brand kit. Do not copy logos, screenshots, proprietary blobs, photos, copy, fonts, or exact page layouts unless you have rights to use them.
