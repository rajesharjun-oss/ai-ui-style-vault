# Spacing And Shape

## Layout Values

| Purpose | Value |
| --- | --- |
| Density | comfortable |
| Base unit | 8px |
| Page max width | 1200px |
| Section gap | 48-80px |
| Card padding | 24-48px |
| Element gap | 12-16px |

## Spacing Scale

| Name | Value | Token |
| --- | --- | --- |
| 8 | 8px | `--spacing-8` |
| 16 | 16px | `--spacing-16` |
| 24 | 24px | `--spacing-24` |
| 32 | 32px | `--spacing-32` |
| 48 | 48px | `--spacing-48` |
| 64 | 64px | `--spacing-64` |
| 96 | 96px | `--spacing-96` |

## Radius

| Element | Value | Token |
| --- | --- | --- |
| nav | 1440px | `--radius-nav` |
| tags | 1440px | `--radius-tags` |
| icons | 1440px | `--radius-icons` |
| buttons | 1440px | `--radius-buttons` |
| cards | 24px | `--radius-cards` |
| images | 24-48px | `--radius-images` |

## Shape Rules

- Buttons, inputs, nav links, tags, and icon containers are pills.
- Cards use 24px radius.
- Images may use 24-48px radius.
- Avoid sharp corners below 16px on interactive controls.
