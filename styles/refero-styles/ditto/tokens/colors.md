# Colors

## Brand

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Deep Ink | `#130e30` | `--color-deep-ink` | Primary text, heading ink, borders, and dark pill buttons. |
| Hi-Yellow | `#ffe228` | `--color-hi-yellow` | Primary action fill and yellow decorative blob. |

## Decoration Only

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Moss Green | `#59e25d` | `--color-moss-green` | Organic blob behind product visuals only. |
| Fuchsia | `#e261e5` | `--color-fuchsia` | Organic blob behind product visuals only. |

## Neutrals

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Canvas | `#f9fbf2` | `--color-canvas` | Page background and lightest surface. |
| Soft Meadow | `#eff2e5` | `--color-soft-meadow` | Cards, nav, hero backdrop, and panels. |
| Slate | `#5f5c6e` | `--color-slate` | Muted helper text and secondary content. |
| Charcoal | `#222222` | `--color-charcoal` | Secondary dark text and supporting borders. |
| Onyx | `#000000` | `--color-onyx` | Logo mark, input borders, and fine details. |

## Usage

- Hi-Yellow is the only functional bright CTA color.
- Do not use Moss Green or Fuchsia for UI controls, badges, icons, or status.
- Use Deep Ink for primary text instead of pure black.
- Use Soft Meadow for cards, not pure white.
