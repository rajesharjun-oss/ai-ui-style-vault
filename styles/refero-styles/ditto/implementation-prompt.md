# Implementation Prompt

Build the UI in the Ditto Refero style.

Create a warm light compliance SaaS interface. Use a cream-green canvas, soft meadow cards, serif display headlines, Inter UI text, and high-contrast yellow pill CTAs. The mood should be optimistic, approachable, and product-forward, not clinical or corporate.

Color rules:

- Page background: `#f9fbf2`.
- Card/nav/background panels: `#eff2e5`.
- Primary text and structural ink: `#130e30`.
- Muted text: `#5f5c6e`.
- Primary CTA fill: `#ffe228`.
- Secondary dark pill fill: `#130e30`.
- Fine borders/logo details: `#000000`.
- Decorative blobs only: `#59e25d`, `#e261e5`, `#ffe228`, `#130e30`.

Typography rules:

- Use Hedvig Letters Serif for all headings at 22px and above.
- Use Inter for nav, body, forms, labels, buttons, cards, and footer.
- Hero headline: 48-64px, Hedvig Letters Serif, weight 700, line-height 1.0-1.1, tight tracking.
- Body text: 16px Inter, line-height 1.5, Deep Ink or Slate depending on priority.
- Small caps labels: Inter 500 at 10-12px, uppercase, tight tracking.

Layout rules:

- Max width: 1200px.
- Section gap: 48-80px.
- Card padding: 24-48px.
- Element gap: 12-16px.
- Hero is two-column: content and email capture left, product mockup with decorative blobs right.
- Feature grids can use three equal cards.
- Testimonials can use a horizontal carousel.

Component rules:

- Primary button: `#ffe228` fill, `#130e30` text, full pill radius, 12px by 24px padding, no shadow.
- Dark secondary button: `#130e30` fill, white text, full pill radius, 12px by 22px padding.
- Email input: white fill, 1px black border, pill radius, 12px by 22px padding.
- Cards: `#eff2e5`, 24px radius, 24-48px padding, no shadow and no border.
- Nav: `#eff2e5` background, logo left, Inter links center, CTA pair right.
- Decorative blobs sit behind product mockups only.

Avoid sharp controls, extra UI accent colors, green/pink buttons or badges, two yellow CTAs in one viewport, pure white card fields where Soft Meadow is intended, drop shadows, and generic sterile SaaS visuals.
