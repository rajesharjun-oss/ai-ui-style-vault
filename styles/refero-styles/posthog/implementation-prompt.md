# AI Implementation Prompt

Build a polished, responsive interface in the PostHog style.

The page should feel like a warm desktop OS for product development: a sandy corkboard-like canvas, white application windows, tiny radii, hairline borders, compact controls, file-manager sidebars, and flat illustrated objects.

Core rules:

- Use `#e1d7c2` as the page-level canvas. Do not use white as the outer background.
- Put primary content inside `#ffffff` application windows with 6px radius and 1px `#bfc1b7` borders.
- Use 4px radius for cards, buttons, inputs, toolbar controls, and hover states.
- Use 9999px radius only for small tags or status badges.
- Do not use shadows on cards or windows. Use hairline borders for structure.
- Use `#23251d` for primary text instead of pure black.
- Use `#eb9d2a` for the single filled primary CTA, `#b17816` for outlined secondary actions, and `#2f80fa` only for active states and live links.
- Use Open Runde for headings and body, IBM Plex Sans Variable for UI controls and navigation, and ui-monospace for code.
- Use flat illustrated decorations with olive outlines and selective amber, orange, green, and blue fills.

Recommended layout:

1. A minimal top nav over the Sandy Desk canvas with compact IBM Plex Sans links and one Amber CTA on the right.
2. A left file-manager sidebar with stacked icon entries.
3. A centered Application Window with a title bar, filename, toolbar row, tab bar, and content sections.
4. Content inside the window separated by hairline dividers, not colored panels.
5. A feature grid of white paper cards with tiny radii and no shadows.
6. A right-side flat illustration panel that can bleed off the edge of the viewport.

Make the interface feel friendly, technical, tactile, and slightly quirky without becoming messy or toy-like.
