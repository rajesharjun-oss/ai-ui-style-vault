# Components

## Application Window

- Background: `#ffffff`
- Border: 1px solid `#bfc1b7`
- Radius: 6px
- Shadow: none
- Padding: 16px to 32px
- Contains a title bar, toolbar, tab row, and content sections.

## Window Title Bar

- Height: about 36px
- Background: `#ffffff`
- Border bottom: 1px solid `#bfc1b7`
- Filename: IBM Plex Sans 13px/500, centered
- Optional effect: `backdrop-filter: blur(8px)`

## Sidebar File Entry

- Layout: vertical icon over label
- Icon: 16px to 20px
- Label: IBM Plex Sans 13px/500, `#4d4f46`
- Gap: 8px between icon and label
- Entry gap: 16px
- Hover: `#e5e7e0`, 4px radius
- Active: icon fill `#2f80fa`

## Amber CTA Button

- Background: `#eb9d2a`
- Hover: `#cd8407`
- Text: `#23251d`
- Radius: 4px
- Padding: 6px 12px
- Font: IBM Plex Sans 14px/500
- Use once per page.

## Outlined Action Button

- Background: transparent
- Border: 1.5px solid `#b17816`
- Text: `#b17816`
- Radius: 4px
- Padding: 6px 12px
- Use beside the filled amber CTA.

## Ghost Toolbar Button

- Background: transparent
- Text/icon: `#23251d`
- Radius: 4px
- Padding: 2px 4px
- Hover: `#e5e7e0`
- Use for utility toolbar controls.

## Tab Bar Item

- Inactive text: `#65675e`
- Active text: `#2f80fa`
- Active border: 2px solid `#2f80fa` on bottom
- Font: IBM Plex Sans 13px/500
- Padding: 10px 12px
