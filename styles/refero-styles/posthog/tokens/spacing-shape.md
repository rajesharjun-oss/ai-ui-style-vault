# Spacing And Shape

## Spacing

| Purpose | Value | Notes |
|---|---:|---|
| Density | compact | Workspace metaphor, not airy marketing page |
| Base unit | 4px | Most sizes snap to this rhythm |
| Page max width | 958px | Main application window width |
| Sidebar width | 60px to 100px | File-manager icon rail |
| Element gap | 8px | Toolbar and compact UI clusters |
| Section gap | 48px | Larger internal content rhythm |
| Card padding | 16px | Product feature cards |
| Window padding | 16px to 32px | Main application content |
| Title bar height | 36px | Window title bar |
| Tab padding | 10px 12px | Content tab items |
| Button padding | 6px 12px | Compact actions |
| Tag padding | 2px 8px | Small badges only |

## Shape

| Element | Radius | Notes |
|---|---:|---|
| Cards | 4px | System default |
| Inputs | 4px | System default |
| Buttons | 4px | System default |
| Hover states | 4px | Sidebar and toolbar hover |
| Windows | 6px | Main application window only |
| Tags | 9999px | Only small badges |

## Elevation

- Window shadow: none.
- Card shadow: none.
- Modal overlay: `rgba(0,0,0,0.25) 0px 25px 50px -12px`.
- Use borders, not shadows, to define structure.
