# Typography

## Families

- Brand/body: `"Open Runde", "Inter Tight", "DM Sans", system-ui, sans-serif`
- UI/control: `"IBM Plex Sans Variable", "IBM Plex Sans", "Inter", system-ui, sans-serif`
- Code: `ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`

## Roles

| Role | Size | Family | Weight | Line Height | Tracking | Use |
|---|---:|---|---:|---:|---:|---|
| Micro | 12px | IBM Plex Sans | 500 | 1.33 | 0 | Labels, tiny metadata, nav support |
| Caption | 14px | Open Runde or IBM Plex Sans | 400 | 1.43 | 0 | Captions and small copy |
| Body | 16px | Open Runde | 400 | 1.5 | 0 | Main body copy |
| Subheading | 19px | Open Runde | 500 to 600 | 1.56 | -0.025em | Card and section headings |
| Heading | 21px | Open Runde | 600 to 700 | 1.4 | -0.025em | Page headings inside windows |
| Large Heading | 24px | Open Runde | 700 to 800 | 1.33 | -0.025em | High-impact window headings |
| Display | 36px | Open Runde | 700 to 800 | 1.5 | 0 | Rare hero/display text |
| Code | 14px | ui-monospace | 400 | 1.43 | 0 | Inline code and technical metadata |

## Guidance

- Use Open Runde for headings, body, and brand personality.
- Use IBM Plex Sans for nav, buttons, labels, form controls, and toolbars.
- Use ui-monospace for code contexts only.
- Apply `-0.025em` tracking to Open Runde text at 18px and above.
- Do not mix type roles casually; the split is part of the system.
