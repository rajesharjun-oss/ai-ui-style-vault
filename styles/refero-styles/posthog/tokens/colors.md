# Colors

| Name | Value | Token | Role |
|---|---:|---|---|
| Sandy Desk | `#e1d7c2` | `--color-sandy-desk` | Outer page canvas, low-emphasis panels, placeholder blocks |
| Paper White | `#ffffff` | `--color-paper-white` | Application windows, primary cards, popovers |
| Cream Paper | `#fdfdf8` | `--color-cream-paper` | Secondary windows, warm off-white hover surfaces |
| Soft Linen | `#eeefe9` | `--color-soft-linen` | Nested cards, secondary buttons, subtle grouped surfaces |
| Pale Stone | `#e5e7e0` | `--color-pale-stone` | Hover backgrounds, selected items, disabled surfaces |
| Deep Moss | `#23251d` | `--color-deep-moss` | Primary text and headings |
| Olive Char | `#4d4f46` | `--color-olive-char` | Body text, secondary icons, SVG fills, sidebar labels |
| Sage Gray | `#65675e` | `--color-sage-gray` | Inactive tabs, muted text, tertiary content |
| Ash Green | `#9ea096` | `--color-ash-green` | Placeholders, disabled controls, low-emphasis icons |
| Faded Pewter | `#b3b3af` | `--color-faded-pewter` | Subtle dividers and softer border details |
| Warm Mist | `#bfc1b7` | `--color-warm-mist` | Primary hairline border |
| Signal Blue | `#2f80fa` | `--color-signal-blue` | Active states, live links, selected navigation |
| Amber Glow | `#eb9d2a` | `--color-amber-glow` | Single primary CTA |
| Dark Amber | `#cd8407` | `--color-dark-amber` | CTA hover and active state |
| Burnished Gold | `#b17816` | `--color-burnished-gold` | Outlined actions and amber-context links |
| Marigold | `#f1a82c` | `--color-marigold` | Decorative illustration fills and icon accents |
| Flame Orange | `#f54e00` | `--color-flame-orange` | Highlight backgrounds, feature tags, warm emphasis |
| Moss Green | `#6aa84f` | `--color-moss-green` | Supporting green wash and small badge fills |

## Guidance

- Use `Sandy Desk` as the page canvas.
- Use `Paper White` as the main application window surface.
- Use `Warm Mist` for borders and dividers.
- Use `Amber Glow` for one primary CTA per page.
- Use `Signal Blue` only for active states and live links.
- Use `Deep Moss` instead of pure black for text.
