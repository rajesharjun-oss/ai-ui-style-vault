# Guidelines

## Do

- Use Sandy Desk as the page canvas.
- Use Paper White for primary application windows.
- Use 4px radius for cards, buttons, and inputs.
- Use 6px radius only for main windows.
- Use 1px Warm Mist borders for separation.
- Use Amber Glow for one primary CTA per page.
- Use Burnished Gold for outlined secondary actions.
- Use Signal Blue only for active states, live links, and selected navigation.
- Use Open Runde for headings and body.
- Use IBM Plex Sans for controls, nav, labels, and toolbars.
- Use ui-monospace for code contexts.

## Do Not

- Do not use pure white as the outer page background.
- Do not use pure black for primary text.
- Do not add shadows to cards or windows.
- Do not use container radii larger than 6px.
- Do not introduce new accent colors.
- Do not use the PostHog spectrum gradient for UI controls.
- Do not use pill shapes on anything larger than a small tag.
- Do not trap decorative illustrations inside ordinary cards.
