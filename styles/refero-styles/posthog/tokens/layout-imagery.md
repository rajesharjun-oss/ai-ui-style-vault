# Layout And Imagery

## Layout Pattern

The core page structure is:

1. Sandy Desk page canvas.
2. Minimal top navigation with compact links and one amber CTA.
3. Left file-manager sidebar.
4. Centered Application Window around 958px max width.
5. Window title bar with filename and control dots.
6. Toolbar and tab bar inside the window.
7. Content sections separated by hairline dividers.
8. Right-side illustrated decoration that can bleed off edge.

## Grid

- Keep the main window centered.
- Use compact internal grids with 16px padding.
- Use hairline borders and tab rows for structure.
- Use 48px gaps for major sections inside the window.
- On mobile, stack the sidebar and window metaphors into a single-column card while keeping the sandy canvas.

## Imagery

Use:

- Flat illustrated people, tools, and product metaphors.
- Isometric-ish objects with thick outlines.
- Olive Char line work.
- Selective Marigold, Signal Blue, Flame Orange, and Moss Green fills.
- File, folder, toolbar, and window metaphors.

Avoid:

- Photography.
- Glossy 3D art.
- Glassmorphism.
- Generic SaaS abstract shapes.
- Large white full-page backgrounds.
