# PostHog

Warm paper desktop pinned to cork: a tactile devtools workspace with a sandy canvas, white app windows, tiny radii, hairline borders, Open Runde type, IBM Plex Sans controls, and amber/blue action signals.

Use this style when you want an analytics, developer tool, product OS, docs workspace, or internal product surface to feel friendly, technical, and handcrafted without becoming playful fluff.

## Files

- `source.md`: Source URL, reference site, capture notes, and scope.
- `DESIGN.md`: Human-readable design breakdown.
- `implementation-prompt.md`: Prompt for an AI builder to implement the style.
- `style.json`: Structured design metadata.
- `tokens/`: Markdown token notes by category.
- `code/`: CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md`: Placeholder for future manual screenshots.

## Quick Use

1. Use `Sandy Desk` as the outer page canvas.
2. Place primary content inside `Paper White` application windows.
3. Use 4px radius for most cards, buttons, and inputs.
4. Use 6px radius only for the main application window.
5. Use hairline borders instead of shadows.
6. Use Amber Glow for the one primary CTA, Signal Blue for active states, and Deep Moss for text.
