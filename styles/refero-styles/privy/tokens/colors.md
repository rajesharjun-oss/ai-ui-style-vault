# Colors

## Palette

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Canvas | `#ffffff` | `--color-canvas` | Page background, card surfaces, input fields |
| Obsidian Ink | `#010110` | `--color-obsidian-ink` | Primary text, borders, icons, filled CTAs |
| Carbon | `#111117` | `--color-carbon` | Full-bleed dark section background |
| Graphite | `#22222a` | `--color-graphite` | Dark-mode card and elevated panel surface |
| Fog | `#73737c` | `--color-fog` | Muted helper text and secondary copy |
| Ash | `#d9d9d9` | `--color-ash` | Hairlines, inactive washes, dotted patterns |
| Iris Pulse | `#635bff` | `--color-iris-pulse` | Announcement bar, link hover, small chart strokes |
| Deep Teal | `#072723` | `--color-deep-teal` | Decorative illustration wash only |

## Usage

Obsidian Ink is the structural color and should own text, borders, icons, and primary CTAs. Iris Pulse is intentionally narrow: use it for the top announcement bar, link hover, and small chart or decorative strokes only. Deep Teal belongs inside artwork, not normal UI controls.
