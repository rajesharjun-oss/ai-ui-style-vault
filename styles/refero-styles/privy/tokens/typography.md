# Typography

## Fonts

- Display: `ABC Favorit Variable`
- Display substitute: `GT Super`, `Tiempos Headline`, `Source Serif 4`, `Georgia`, `serif`
- UI/body: `Inter`
- UI fallback: `ui-sans-serif`, `system-ui`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `sans-serif`

## Display Behavior

Use the display face for headings at 26px and above. Keep weight at 400 for the most distinctive headline moments, with compact line-height and about -0.03em tracking. Do not substitute Inter for display headings.

## UI Behavior

Use Inter for paragraphs, nav links, captions, buttons, and product UI. Keep it tightly tracked around -0.02em. Use weight 500 for emphasis and button text. Reserve weight 700 for small label-like UI or footer group headings.

| Heading Small | 26px | 1.13 | 400 | -0.78px |

| Display | 76px | 1.03 | 400 | -2.28px |

## Rules

- Display headings above 26px should never be set in Inter.
- Do not bold display text.
- Use tight tracking for both display and UI text.
- Keep paragraph reading sizes at 16px to 18px.
- Use 12px to 15px for captions, nav labels, and compact controls.
