# Privy - Style Reference

## Positioning

Privy reads like a crisp editorial fintech page rather than a generic developer SaaS site. The brand expression comes from typographic confidence, severe contrast, and one controlled violet interruption. It should feel precise, technical, trustworthy, and slightly journalistic.

## Theme

- Theme: light
- Mood: ink-on-marble editorial spread
- Best fit: crypto infrastructure, auth, wallets, fintech APIs, developer platforms, payment rails, security products

## Visual Principles

1. Lead with white canvas and near-black ink.
2. Use violet only for an announcement bar, link hover, and small chart/decorative strokes.
3. Keep the main CTA near-black, never violet.
4. Use the display face at regular weight with tight tracking.
5. Keep components flat and minimal.
6. Use hairline borders for structure.
7. Reserve dark surfaces for full-bleed sections.

## Color System

| Token | Value | Role |
| --- | --- | --- |
| Canvas | `#ffffff` | Main page background, cards, input fields |
| Obsidian Ink | `#010110` | Primary text, borders, icons, filled CTAs |
| Carbon | `#111117` | Full-bleed dark section background |
| Graphite | `#22222a` | Dark feature card surface |
| Fog | `#73737c` | Muted copy, helper text, subdued borders |
| Ash | `#d9d9d9` | Hairlines, inactive washes, dotted pattern |
| Iris Pulse | `#635bff` | Announcement bar, link hover, chart strokes |
| Deep Teal | `#072723` | Decorative artwork wash only |

## Typography

Display typography is the signature. Use an ABC Favorit-like display face for all headings at 26px and above. If unavailable, use a high-contrast editorial substitute such as GT Super, Tiempos Headline, or Source Serif 4. Keep display weight at 400 and tracking at about -0.03em.

Use Inter for body, UI, navigation, buttons, captions, and small product interface copy. Inter should be tightly tracked at about -0.02em so it sits comfortably beside the display face.

## Spacing And Shape

- Density: comfortable
- Page max width: 1200px
- Section gap: 80px
- Card padding: 24px
- Element gap: 12px to 16px
- Cards and images: 8px radius
- Navigation: 8px radius
- Buttons and tags: 100px radius
- Tiny icon details: 2px radius

## Layout

Use centered 1200px content inside full-bleed background bands. The hero should use a split composition: editorial headline and CTAs on the left, product mockups and abstract decorative wash on the right. Below it, use partner logos, a full-bleed dark feature section, feature cards, product previews, and a white footer with a quiet dotted pattern.

The page rhythm alternates white, dark band, white. Do not treat the dark colors as a global dark-mode theme; they are special section surfaces.

## Imagery

Use abstract product art, phone mockups, dashboard previews, subtle green/teal washes, and architectural isometric line art. Avoid lifestyle photography, stock people, colorful gradients, or playful illustrations. Product UI should stay clean, white, and high-contrast.

## Components

### Primary Filled Button

Near-black fill, white text, 100px radius, Inter 15px weight 500, tight tracking, and no shadow. Use for main actions such as getting started.

### Ghost Outline Button

Transparent fill, 1px Obsidian Ink border, Obsidian Ink text, 100px radius. On hover, invert to near-black fill with white text.

### Header Pill Link

Small inline pill inside the announcement bar. Transparent fill, white border, white text, 100px radius, compact padding.

### Announcement Bar

Full-width Iris Pulse band above the nav. White centered text and optional right-side pill link. This is the strongest color moment in the system and should appear before the main navigation.

### Navigation Bar

White background, hairline bottom border, left logo, centered navigation links, and right action cluster. Use Inter at 14px to 15px. Keep height around 64px.

### Dark Feature Card

Graphite card on Carbon section background. Use 8px radius, 24px to 32px padding, monochrome line art, white heading, Fog body text, no border, and no shadow.

### Product Preview Panels

White cards with 8px radius, light dividers, clean tables, charts, and interface details. Violet may appear as a small chart stroke, not as a large fill.

### Footer

White background with a subtle Ash dotted or halftone pattern. Use four-column link groups, near-black headings, Fog links, and quiet social/icon row.

## Rules

- Use the display face for every heading above 26px.
- Keep display text at weight 400 with -0.03em tracking.
- Use Inter for body, UI, navigation, and buttons.
- Use Obsidian Ink for filled CTAs.
- Use Iris Pulse only for announcements, link hover, and small chart/decorative strokes.
- Use 8px radius for cards and images.
- Use 100px radius for buttons and tags.
- Use hairline borders and flat surfaces instead of shadows.
- Do not add additional accent colors.
- Do not use dark surfaces on normal light-mode pages outside full-bleed sections.
