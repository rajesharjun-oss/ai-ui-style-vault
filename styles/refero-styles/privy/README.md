# Privy

Light editorial crypto-fintech style system captured from Refero Styles.

- Source: https://styles.refero.design/style/78d9ece2-9033-479a-997a-ede94fc87fda
- Reference site: https://www.privy.io
- Captured: 2026-07-28
- Theme: light
- Mood: ink-on-marble editorial spread with a single violet announcement band

## Use This When

Use this style for crypto infrastructure, fintech developer tools, authentication products, wallet platforms, payments infrastructure, API products, and serious technical SaaS pages that should feel editorial, restrained, and high-trust.

## Core Idea

Privy is almost monochrome. A white canvas, near-black ink, tight custom display type, flat 8px cards, and 100px pill buttons create the foundation. A vivid violet band is used sparingly for announcements and link hover moments, while primary CTAs stay near-black.
