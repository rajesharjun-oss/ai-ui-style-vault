## Capture Notes

This bundle paraphrases the Refero style reference into implementation notes for AI-assisted UI building. It preserves the style intent, color roles, typography behavior, component rules, layout rhythm, and implementation tokens without copying the source text wholesale.

## What To Preserve

- White editorial canvas with near-black structural ink.
- Tight display typography above 26px.
- A single violet announcement/link accent.
- Near-black filled CTAs, not violet CTAs.
- 100px button/tag radius and 8px card/image radius.
- Flat surfaces with hairline borders instead of shadows.
- Full-bleed dark bands used as sectional moments, not a theme toggle.
