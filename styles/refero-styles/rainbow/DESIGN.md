# Rainbow Design Notes

Rainbow is a friendly consumer-wallet system. It feels bright and approachable, but not childish. The UI uses soft white surfaces, round controls, compact Inter type, and tiny pastel accents. The primary action language is black and confident, which keeps the colorful wallet context from becoming noisy.

## Visual Principles

- Keep the base interface neutral and very light.
- Use black for the most important action.
- Use rainbow colors only as localized accents.
- Let rounded cards and pill controls make the product feel friendly.
- Keep app and wallet data scannable through compact rows.
- Favor mobile-first spacing and touch targets.

## Color System

The main system is near-white, white, black, and muted grays. Accent hues are bright but small: blue, purple, pink, green, yellow, and orange should appear in icons, badges, token dots, app illustrations, and tiny status moments, not full-page floods.

## Typography

Use Inter throughout. Most product UI should live between 13px and 16px. Use 600 or 700 for balances, section headings, and CTA labels. Large marketing headings can scale up, but the wallet UI should remain compact.

## Layout

Use compact mobile-first panels, wallet cards, token rows, app-store CTAs, and rounded feature cards. Desktop layouts can center a phone/mockup column with supporting cards around it, but avoid dense enterprise-dashboard composition.

## Elevation

Normal cards use soft borders and very small shadows. Avoid heavy floating shadows. The product should feel soft and tactile, not glassy or skeuomorphic.
