# Implementation Prompt

Build a soft, consumer wallet interface inspired by Rainbow.

Use a near-white page canvas such as `#f9fafb` or `#f7f8fa`. Place white cards on top with `20px` radius, `20px` to `24px` padding, `1px solid rgba(0,0,0,0.06)` borders, and a tiny shadow like `0 4px 16px rgba(15,23,42,0.06)`.

Use Inter as the only font. Keep wallet UI compact: 13px for captions, 14px to 16px for rows and body text, 20px to 24px for card headings, and 48px to 64px for marketing display. Use weight 600 or 700 for balances, CTA labels, and important labels.

Use black `#111111` for the main filled CTA and white text. Secondary actions should be white or soft gray with neutral borders. Use 12px radius for buttons and inputs, 20px for cards, and 9999px for badges or token chips.

Use rainbow color sparingly. Accent colors can appear as token dots, small badges, app icons, status chips, and localized gradients. Do not make every button or section a different color. Keep normal text black and gray.

Build common primitives: wallet balance card, token row, NFT/media card, black primary CTA, secondary pill button, app-store button, rounded input, segmented tabs, pastel badge, and onboarding panel. Keep the interface touch-friendly and mobile-first.
