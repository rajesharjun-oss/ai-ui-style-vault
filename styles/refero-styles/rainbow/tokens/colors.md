# Color Tokens

## Core

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Ink | `#111111` | `--color-ink` | Primary text, primary CTA fill, strongest icons. |
| Canvas | `#f9fafb` | `--color-canvas` | Main page background. |
| Soft Canvas | `#f7f8fa` | `--color-soft-canvas` | Alternate section background and app shell. |
| Card | `#ffffff` | `--color-card` | Cards, panels, app-store buttons, wallet modules. |
| Border | `rgba(0,0,0,0.06)` | `--color-border` | Card borders, separators, control outlines. |
| Text Muted | `#6b7280` | `--color-text-muted` | Secondary text, captions, helper text. |
| Text Soft | `#9ca3af` | `--color-text-soft` | Disabled text, timestamps, low-priority labels. |

## Rainbow Accents

| Name | Value | Token | Role |
| --- | --- | --- | --- |
| Blue | `#3b82f6` | `--color-blue` | Wallet accent, links, selected states. |
| Purple | `#8b5cf6` | `--color-purple` | Token accent, decorative badge, gradient stop. |
| Pink | `#ec4899` | `--color-pink` | Tiny badge and playful status accent. |
| Green | `#22c55e` | `--color-green` | Success, positive change, verified state. |
| Yellow | `#facc15` | `--color-yellow` | Warning-light badge, collectible accent. |
| Orange | `#fb923c` | `--color-orange` | Warm accent and localized illustration color. |

## Rules

- Use black for primary actions.
- Keep page and card surfaces near-white.
- Use accent colors only in small, localized moments.
- Do not make each major section a different rainbow color.
- Use green only for positive/success states.
