# Spacing And Shape Tokens

## Spacing

| Purpose | Value |
| --- | --- |
| Density | compact |
| Base unit | `4px` |
| Max width | `1120px` |
| Section gap | `72px` |
| Card padding | `20px` to `24px` |
| Element gap | `12px` |

| Element | Value | Token |
| --- | --- | --- |
| controls | `12px` | `--radius-control` |

| phone mockups | `36px` | `--radius-phone` |
| pills | `9999px` | `--radius-pill` |

## Borders And Elevation

- Default card border: `1px solid rgba(0,0,0,0.06)`.
- Default card shadow: `0 4px 16px rgba(15,23,42,0.06)`.
- Use soft shadows only.
- Avoid heavy shadows, harsh outlines, and glassy blur.
