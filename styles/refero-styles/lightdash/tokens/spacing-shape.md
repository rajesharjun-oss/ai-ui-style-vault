# Spacing And Shape

## Spacing

| Purpose | Value |
| --- | --- |
| Base unit | 4px |
| Small gap | 8px |
| Default gap | 12px to 20px |
| Card padding | 24px to 32px |
| Section gap | 72px to 96px |
| Page max width | 1180px |

## Radius

| Element | Value |
| --- | --- |
| Buttons | 8px |
| Inputs | 8px |
| Cards | 12px |
| Code blocks | 12px |
| Large panels | 16px |
| Pills and badges | 999px |

## Elevation

| Name | Value |
| --- | --- |
| Card shadow | `0 18px 50px rgba(31, 41, 55, 0.10)` |
| Panel shadow | `0 8px 24px rgba(31, 41, 55, 0.08)` |
| Focus ring | `0 0 0 3px rgba(110, 86, 207, 0.22)` |

## Notes

- Keep controls compact with 8px radius.
- Use 12px cards for product and feature surfaces.
- Avoid large pill geometry except for labels, badges, and segmented controls.
