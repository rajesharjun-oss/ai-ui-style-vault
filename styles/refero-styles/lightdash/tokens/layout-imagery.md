# Layout And Imagery

## Layout

- Center content in an 1180px frame.
- Hero uses centered type, copy, button row, and screenshot preview.
- Supporting sections alternate Paper, Cloud, Mist Violet, and Pure White.
- Use two-column explanatory sections for product workflows.
- Use three-column feature cards for benefits.
- Use full-width screenshot bands for product proof.
- Use connector logo grids for ecosystem credibility.

## Hero Recipe

1. Paper or Mist Violet background.
2. Top nav with subtle white surface.
3. Britti Sans display headline.
4. Short Inter body explanation.
5. Primary violet CTA and secondary neutral CTA.
6. Large dashboard screenshot card.

## Imagery

- Use product screenshots first.
- Use charts, tables, SQL panels, metric cards, and connector logos.
- Illustrations should be simple and schematic.
- Avoid lifestyle photography and abstract blob backgrounds.

## Product Proof

Every visual should help explain the analytics workflow: building dashboards, exploring metrics, joining data sources, reviewing SQL, or sharing insights.
