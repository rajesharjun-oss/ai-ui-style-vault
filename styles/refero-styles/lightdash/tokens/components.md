# Components

## Primary CTA Button

- Fill: Electric Violet.
- Text: Pure White.
- Font: Inter 600, 15px.
- Radius: 8px.
- Padding: 12px 18px.
- Use once per primary action cluster.

## Secondary Button

- Fill: Pure White.
- Border: 1px solid Line Gray.
- Text: Slate Ink or Graphite.
- Font: Inter 600, 15px.
- Radius: 8px.

## Top Navigation

- White or warm translucent surface.
- Wordmark on the left.
- Product links in the center.
- Action cluster on the right.
- Use violet only for active or primary actions.

## Hero Product Frame

- Centered copy stack.
- Britti Sans display headline.
- Muted explanation text.
- Primary and secondary button row.
- Large dashboard screenshot card below.

## Dashboard Screenshot Card

- Surface: Pure White.
- Border: 1px solid Line Gray.
- Radius: 12px.
- Shadow: panel shadow.
- Content: tables, charts, SQL, metrics, sidebars.

## Feature Card

- Surface: Cloud or Pure White.
- Border: 1px solid Line Gray.
- Radius: 12px.
- Padding: 24px.
- Small violet icon or badge.

## Tabbed Comparison Panel

- Active tab: Electric Violet fill or violet text on Mist Violet.
- Inactive tabs: neutral text and transparent or white surface.
- Body: screenshot, workflow diagram, chart, or code snippet.

## Code Block

- Surface: Code Navy.
- Radius: 12px.
- Font: JetBrains Mono 13px.
- Include a small header label.

## Connector Logo Grid

- Grid of tiles.
- White or Cloud tile surfaces.
- Neutral borders.
- No heavy shadow.

## Metric Tile

- White surface.
- 12px radius.
- Small label, large metric, muted helper copy.
- Optional violet or periwinkle status mark.
