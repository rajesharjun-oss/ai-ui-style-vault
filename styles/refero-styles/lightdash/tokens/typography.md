# Typography

## Families

| Role | Font | Fallback | Use |
| --- | --- | --- | --- |
| Display | Britti Sans | Inter, ui-sans-serif | Hero and large section headings |
| UI | Inter | system-ui, sans-serif | Body, nav, buttons, forms, tabs, cards, tables |
| Code | JetBrains Mono | ui-monospace, SFMono-Regular | SQL snippets, query blocks, schema labels |

## Type Scale

| Token | Size | Weight | Line height | Tracking |
| --- | --- | --- | --- | --- |
| Caption | 12px | 500 | 1.4 | 0 |
| Label | 14px | 500 or 600 | 1.4 | 0 |
| Body | 16px | 400 | 1.55 | 0 |
| Body Large | 18px | 400 | 1.6 | 0 |
| Card Heading | 20px | 600 | 1.3 | 0 |
| Section Heading | 44px | 700 | 1.05 | -0.02em |
| Hero Display | 72px | 700 | 0.98 | -0.03em |
| Code | 13px | 400 | 1.55 | 0 |

## Rules

- Use Britti Sans only for big display moments.
- Use Inter for all operational UI.
- Keep code text mono and small.
- Avoid oversized display text inside cards or dashboards.
