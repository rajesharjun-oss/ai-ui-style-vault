# Lightdash

AI-ready Refero style bundle for Lightdash.

- Source: https://styles.refero.design/style/d0f65d12-a8e6-4631-99f7-bb7cdcd5b6c5
- Reference site: https://lightdash.com
- Captured: 2026-07-28
- Theme: light
- Mood: lavender console on paper
- Industry: analytics, business intelligence, data tooling, developer tools

## Use This Style For

- Analytics and BI product pages that need a friendly technical feel
- Data workflow SaaS pages with dashboard previews and documentation cues
- Developer-adjacent products that need warmth without becoming playful
- Landing pages where one soft violet accent organizes action and focus

## Files

- `source.md` records the source URL and capture context.
- `DESIGN.md` is the main human-readable design reference.
- `implementation-prompt.md` is a direct prompt for an AI coding agent.
- `style.json` is a structured summary for indexing and retrieval.
- `tokens/` contains focused notes for colors, type, spacing, components, guidelines, layout, and imagery.
- `code/` contains CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` reserves the screenshot slot for manual or automated captures.

## Core Signature

Lightdash is a soft analytics console on a warm paper canvas. It pairs near-black text with one confident violet accent, subtle lavender washes, Britti Sans display headings, Inter UI text, compact rounded controls, quiet card shadows, and product screenshots framed as functional proof.
