# Implementation Prompt

Use the Lightdash style for this UI.

Create a light analytics-product interface on warm Paper (`#fffdf8`) with Cloud (`#f7f5fb`) and Mist Violet (`#f5f4ff`) sections. Use Electric Violet (`#6e56cf`) as the primary action, active tab, and focus color. Keep violet sparse: one strong violet moment per visible section is enough.

Typography:

- Use Britti Sans for hero and large section headings only.
- Use Inter for body, nav, buttons, forms, tabs, cards, and table UI.
- Use JetBrains Mono only for SQL, schema names, query examples, and code blocks.
- Hero display should be around 72px, weight 700, line-height 0.98, tracking around -0.03em.
- Body copy should be 16px to 18px Inter at 1.55 to 1.6 line-height.

Color:

- Page canvas: `#fffdf8`.
- Primary text: `#121217`.
- Body text: `#6d6875` or `#2d2b35`.
- Borders: `#e5e1eb`.
- Card surfaces: `#ffffff` or `#f7f5fb`.
- Accent: `#6e56cf`.
- Pale violet wash: `#f5f4ff`.
- Code surface: `#1f2937`.

Layout:

- Use a centered max-width around 1180px.
- Use 72px to 96px section gaps.
- Hero is centered: display headline, short product explanation, button row, large dashboard screenshot card.
- Use two-column explanatory sections, three-column feature cards, full-width product screenshot bands, and connector logo grids.

Components:

- Primary CTA: Electric Violet fill, white text, Inter 600 15px, 8px radius, 12px 18px padding.
- Secondary button: white fill, Line Gray border, Slate Ink text, same radius and size.
- Screenshot card: white surface, 12px radius, Line Gray border, soft slate shadow.
- Feature card: Cloud or white surface, 12px radius, 24px padding, light border, small violet icon or badge.
- Code block: Code Navy, 12px radius, JetBrains Mono 13px, muted syntax colors.
- Tab panel: active state in violet or Mist Violet, inactive states neutral.

Avoid generic blue SaaS styling, heavy purple gradients, lifestyle imagery, mascots, dark-mode default, huge rounded cards, and decorative blobs. Product UI should be the main image language.
