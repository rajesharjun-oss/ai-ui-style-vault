# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Density | comfortable |
| Base unit | `8px` |
| Max width | `1200px` |
| Section gap | `96px` |
| Card padding | `24px` |
| Element gap | `24px` |

## Border Radius

| Element | Value | Token |
|---|---:|---|
| nav | `3px` | `--radius-nav` |
| buttons | `3px` | `--radius-buttons` |
| cards | `10px` | `--radius-cards` |
| large panels | `20px` | `--radius-largepanels` |

## Elevation

- Use no diffuse shadows.
- Depth comes from contrast and thin lines.
- A light `#eeeeee` card on `#101010` is the main elevation move.
- Hairlines and borders should do more work than blur or glow.

## Shape Rules

- Buttons and nav elements are compact and squared-off at `3px`.
- Cards use `10px`.
- Large panels use `20px`.
- Do not make the system soft with large pill radii or rounded blobs.
