# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Base unit | `8px` |
| Density | `comfortable` |
| Page max width | `1200px` |
| Section gap | `80px` |
| Card padding | `24px` |
| Element gap | `12px` to `16px` |
| Product frame padding | `24px` to `32px` |

## Spacing Tokens

Use `4`, `8`, `12`, `16`, `20`, `24`, `32`, `40`, `48`, `64`, `80`, `96`, and `120`.

## Radius

| Element | Radius |
|---|---:|
| Tags | `4px` |
| Images | `4px` |
| Cards | `8px` |
| Buttons | `8px` |
| Inputs | `8px` |

## Shape Rules

- Keep radii modest and industrial.
- Never round above 8px.
- Do not use pill buttons.
- Do not add drop shadows.
- Use hairline borders for separation.
