# Layout And Imagery

## Layout Model

- Use a dark atmospheric shell for hero and brand sections.
- Center a radial glow behind the focal visualization.
- Place one clean Signal Blue action near the main message.
- Insert white product UI frames into the dark shell.
- Use hairline borders and compact radii for product surfaces.
- Use data badges, timeline bars, command inputs, and metric cards as the repeated UI language.
- Keep the page max-width around `1200px`.

## Imagery

- Use abstract particle networks, data ribbons, command-center visuals, and product screenshots.
- Use Arc Cyan as glow only around the visualization.
- Use white document-like product UI to prove utility.
- Avoid warm photography, lifestyle stock, playful illustration, 3D cartoon objects, or unrelated abstract art.

## Motion

- Motion should feel like data flow.
- Use particle drift, timeline activation, subtle glow pulse, and product panel reveals.
- Avoid bouncy animation, confetti, and loud looping effects.
