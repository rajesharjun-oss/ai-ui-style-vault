# Colors

## Palette

| Name | Value | Token | Role |
|---|---:|---|---|
| Midnight Ink | `#00052e` | `--color-midnight-ink` | Primary canvas, hero backgrounds, deep feature surfaces |
| Signal Blue | `#0428cb` | `--color-signal-blue` | Filled CTA, active timeline bars, key visualization state |
| Arc Cyan | `#34fcff` | `--color-arc-cyan` | Atmospheric glow and particle halos only |
| Halo Violet | `#afb4db` | `--color-halo-violet` | Soft radial midtone between Signal Blue and Midnight Ink |
| Carbon | `#222222` | `--color-carbon` | Dark text on light surfaces, button text fallback |
| Slate Body | `#4f5166` | `--color-slate-body` | Body text on light product sections and secondary metadata |
| Mist | `#8185a0` | `--color-mist` | Tertiary text and disabled labels |
| Silver Border | `#dbdcdf` | `--color-silver-border` | Hairline dividers on light product surfaces and tables |
| White | `#ffffff` | `--color-white` | Product surfaces, cards, reverse text, document UI canvas |
| Radial Blue | `#06105a` | `--color-radial-blue` | Dark radial glow center behind the focal element |

## Usage

- Use Midnight Ink for the dark shell.
- Use Signal Blue with discipline; it should not appear on more than a few element types.
- Use Arc Cyan as light, glow, and particles only.
- Use Halo Violet as ambient midtone, not as a button or text color.
- Use White for product UI surfaces inside the dark environment.
- Use Silver Border for clean product UI hairlines.
- Do not introduce warm brand colors.
