# AI Implementation Prompt

Build a dark AI command-center interface inspired by Ameba.

Use Midnight Ink as the canvas, Signal Blue as the single authoritative action color, Arc Cyan only as particle glow, Halo Violet as an ambient radial midtone, F37 Bolton light headings, Open Sauce Sans body/UI text, IBM Plex Mono data labels, small industrial radii, hairline borders, and clean white product surfaces inserted into the dark shell.

Requirements:

- Use Midnight Ink `#00052e` for all hero, feature, and atmospheric sections.
- Use Signal Blue `#0428cb` only for the primary CTA, active timeline bars, and key visualization state.
- Use Arc Cyan `#34fcff` only for atmospheric glow or particles. Do not use it for text, buttons, or borders.
- Use Halo Violet `#afb4db` only as a radial glow bridge or ambient surface tint.
- Use F37 Bolton weight 300 for display headings at 54px and above with negative tracking.
- Use Open Sauce Sans for body text, UI labels, navigation, and form fields.
- Use IBM Plex Mono with tracked letter spacing for data, status, and system metadata.
- Use 8px radius for cards and buttons; use 4px for tags and images. Never go above 8px.
- Do not add drop shadows. Use hairline borders and the radial background glow for separation.
- Keep product UI surfaces white with 1px Silver Border hairlines.
- Avoid warm hues, glassmorphism, semi-transparent white cards, gradient buttons, and pill CTAs.

Hero recipe:

Create a Midnight Ink hero with a radial background wash from deep blue `#06105a` into `#00052e`. Add a large F37 Bolton weight 300 headline with tight negative tracking, Open Sauce body copy, one Signal Blue 8px-radius CTA, and an abstract particle/network visualization using Arc Cyan only as glow.

Product frame recipe:

Create a white product surface inside a dark browser chrome. Use Silver Border hairlines, a left sidebar, table/list rows, Open Sauce UI text, IBM Plex Mono status badges, 8px controls, and no shadows.
