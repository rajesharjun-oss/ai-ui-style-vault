## Use This Style For

- AI, data, operations, security, supply-chain, and command-center SaaS sites
- Dark product launches where one electric blue action color needs to feel authoritative
- Interfaces that mix atmospheric hero visuals with clean white product UI screenshots
- Dashboards that need monospaced metadata, hairline borders, and precise compact radii

## Files

- `source.md` records the source URL and capture context.
- `DESIGN.md` is the main human-readable design reference.
- `implementation-prompt.md` is a direct prompt for an AI coding agent.
- `style.json` is a structured summary for indexing and retrieval.
- `tokens/` contains focused notes for colors, type, spacing, components, guidelines, layout, and imagery.
- `code/` contains CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` reserves the screenshot slot for manual or automated captures.

## Core Signature

Ameba is a midnight AI control room: Midnight Ink canvas, Signal Blue as the single serious CTA color, Arc Cyan and Halo Violet only as atmospheric glow, F37 Bolton whisper-light headlines, Open Sauce Sans body text, IBM Plex Mono metadata, 8px max radius, and product UI shown as clean white document-like surfaces.
