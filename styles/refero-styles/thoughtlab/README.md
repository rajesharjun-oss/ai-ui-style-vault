# ThoughtLab

AI-ready Refero style bundle for ThoughtLab.

- Source: https://styles.refero.design/style/82d52a5f-b1bb-4a69-91a3-15a7eb8bbe99
- Reference site: https://www.thoughtlab.com
- Captured: 2026-07-28
- Theme: dark
- Mood: executive research terminal in pure black
- Industry: research, consulting, B2B intelligence, thought leadership

## Use This Style For

- Research, consulting, intelligence, strategy, and executive advisory websites
- Dark editorial sites with monumental typography and sparse content modules
- B2B brands that need severity, confidence, and publication-like authority
- Landing pages that use black, white, one crimson action color, and strict rectangular UI

## Files

- `source.md` records the source URL and capture context.
- `DESIGN.md` is the main human-readable design reference.
- `implementation-prompt.md` is a direct prompt for an AI coding agent.
- `style.json` is a structured summary for indexing and retrieval.
- `tokens/` contains focused notes for colors, type, spacing, components, guidelines, layout, and imagery.
- `code/` contains CSS variables, Tailwind v4 theme tokens, and JSON design tokens.
- `screenshots/README.md` reserves the screenshot slot for manual or automated captures.

## Core Signature

ThoughtLab is a severe black editorial system: pure black canvas, white type, one crimson action color, Sui as the single type family, huge uppercase display text, transparent cards, hairline inputs, square geometry, and no decorative depth.
