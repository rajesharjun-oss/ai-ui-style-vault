# Typography

## Font Stack

- Primary: `Sui`
- Fallback: `Inter`, `Helvetica Neue`, `Arial`, sans-serif
- Weights: `400`, `500`, `600`, `700`

## Type Scale

| Role | Size | Line height | Weight | Tracking | Token |
|---|---:|---:|---:|---:|---|
| Caption | `12px` | `1.3` | `500` | `0.04em` | `--text-caption` |
| Body small | `14px` | `1.45` | `400` | `0` | `--text-body-sm` |
| Input | `15px` | `1.2` | `400` | `0` | `--text-input` |

## Rules

- Use one type family only.
- Use uppercase for display and section scale text.
- Make display typography the primary visual event.
- Keep labels and UI text small, direct, and low ornament.
- Do not use serif, mono, condensed sports, or rounded friendly fonts.
