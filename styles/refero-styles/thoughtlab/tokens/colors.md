# Colors

## Palette

| Name | Value | Token | Role |
|---|---:|---|---|
| Black Void | `#000000` | `--color-black-void` | Page canvas, hero ground, footer, primary surface |
| White | `#ffffff` | `--color-white` | Primary text, strong dividers, high-contrast labels |
| Crimson Signal | `#ff0000` | `--color-crimson-signal` | Primary action, active state, small emphasis, alert marker |
| White Mist | `rgba(255,255,255,0.70)` | `--color-white-mist` | Secondary text, captions, muted explanatory copy |
| White Hairline | `rgba(255,255,255,0.10)` | `--color-white-hairline` | Subtle dividers, card borders, table rules |
| Deep Gray | `#121212` | `--color-deep-gray` | Near-black panel fill, code-like modules, quiet strips |
| Mid Gray | `#333333` | `--color-mid-gray` | Muted UI strokes, disabled text, light-section text if needed |
| Void Card | `rgba(0,0,0,0)` | `--color-void-card` | Transparent card fill |
| Glass Edge | `rgba(255,255,255,0.20)` | `--color-glass-edge` | Stronger border, active outline, input edge |

## Usage

- Use Black Void as the page canvas.
- Use White for main text and decisive lines.
- Use Crimson Signal for action and active emphasis only.
- Use White Mist for secondary text and quieter metadata.
- Use White Hairline and Glass Edge for structure.
- Do not introduce blue, purple, green, or warm decorative accents.
