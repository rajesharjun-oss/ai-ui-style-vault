# Spacing And Shape

## Spacing

| Purpose | Value |
|---|---:|
| Base unit | `4px` |
| Density | `spacious` |
| Page max width | `1200px` |
| Section gap | `150px` |
| Card padding | `24px` |
| Element gap | `12px` |
| Hero vertical padding | `120px` to `200px` |

## Spacing Tokens

Use `4`, `8`, `12`, `16`, `20`, `24`, `32`, `40`, `48`, `60`, `80`, `120`, `150`, and `200`.

## Radius

| Element | Radius |
|---|---:|
| Buttons | `0px` |
| Cards | `0px` |
| Inputs | `0px` |
| Images | `0px` |
| Sections | `0px` |

## Shape Rules

- Keep every functional surface rectangular.
- Use hairlines, not curves, to create structure.
- Do not add pills or rounded cards.
- Do not use shadows for hierarchy.
- Use strict grid alignment and negative space.
