# Components

## Filled Ember CTA

- Role: rare high-intent conversion action.
- Fill: `#fd5321`.
- Text: `#fcfbf8`.
- Border: none.
- Radius: 24px.
- Padding: 8px 24px.
- Type: AeonikPro 16px, weight 500, slight positive tracking.
- Use at most once per viewport.

## Arrow Pill Button

- Role: main inline movement action.
- Fill: `#001011`.
- Text: `#fcfbf8`.
- Radius: 44px.
- Padding: 6px 20px 6px 6px.
- Leading icon circle: 32px diameter, `#fcfbf8` fill, `#001011` arrow.
- Type: AeonikPro 16px, weight 500.
- Prefer this over Ember for ordinary "more" actions.

## Ghost Outlined Action

- Role: tertiary or subordinate action.
- Fill: transparent.
- Border: `1px solid #007aff`.
- Text: `#007aff`.
- Radius: 24px.
- Padding: 12px 24px.
- Do not fill with blue.

## Offer Card

- Role: two-column service or offering module.
- Fill: `#fcfbf8`.
- Border: `1px solid #c1c4c2`.
- Radius: 20px.
- Padding: 32px.
- Title: 24px AeonikPro 500, `#001011`.
- Body: 18px AeonikPro 400, `#0f1e1f`.
- Include a small circular arrow prefix if useful.
- No shadow.

## Case Study Card

- Role: story or portfolio card.
- Vertical composition.
- Top image container: about 4:3 ratio, 20px top radius, overflow hidden.
- Text block: 16px padding on Bone Canvas.
- Project name: 18px AeonikPro 500, `#001011`.
- Description: 16px AeonikPro 400, `#0f1e1f`.
- No shadow.

## Section Header

- Role: section opener.
- Split row: left label with 24px arrow circle, right parenthetical count.
- Label type: 18px AeonikPro 500.
- Bottom divider: 1px `#c1c4c2`.
- Optional centered headline below at 32px to 36px.

## Top Navigation

- Role: primary site nav.
- Surface: Bone Canvas with no visible blur or filled bar.
- Logo left: about 19px AeonikPro 500.
- Center links: 16px AeonikPro 400, `#0f1e1f`, 24px gap.
- Right side: one Ember CTA.
- Keep the bar thin and quiet.

## Carousel Navigation

- Role: story carousel controls.
- Button size: 32px circle.
- Fill: `#fcfbf8`.
- Icon: `#001011`.
- No border or shadow.
- Pair left/right at carousel edges.

## Badge Tag

- Role: inline metadata.
- Fill: `#fcfbf8`.
- Border: `1px solid #c1c4c2`.
- Radius: 8px.
- Padding: 4px 8px.
- Text: 14px to 16px AeonikPro 400, `#0f1e1f`.

## Text Hero

- Role: first viewport statement.
- Background: `#fcfbf8`.
- Text block max width: about 900px.
- Headline: 72px to 101px, weight 400 or 500, `#001011`, line-height 0.8 to 0.9.
- Body: 18px, `#0f1e1f`, max width around 60ch.
- CTA: centered arrow pill.
- No hero image.

## 3D Render Feature Block

- Role: visual interlude.
- Full-width object render with ample whitespace.
- Render style: chrome, glass, metallic, or abstract object.
- Accent: one Ember detail if needed.
- No caption overlay.
- No text over image.
