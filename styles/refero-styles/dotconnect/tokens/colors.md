# Colors

| Token | Value | Use |
| --- | --- | --- |
| `--dotconnect-bone-canvas` | `#fcfbf8` | Page background, card surface, light text on dark controls |
| `--dotconnect-charcoal-ink` | `#001011` | Primary text, headings, dominant borders, dark action fill |
| `--dotconnect-smoke-veil` | `#0f1e1f` | Secondary text, body-level borders, dark surface moments |
| `--dotconnect-ash-layer` | `#ededea` | Flat elevated surface, subtle hover fill, card background |
| `--dotconnect-mist-border` | `#c1c4c2` | Hairline borders, dividers, section separators |
| `--dotconnect-ember` | `#fd5321` | Rare brand punctuation, header CTA, high-intent conversion cue |
| `--dotconnect-signal-blue` | `#007aff` | Ghost-outline secondary action stroke and text only |

## Usage Rules

- Use Bone Canvas as the default page surface.
- Use Charcoal Ink for primary text and the normal filled action.
- Use Ember once per viewport at most.
- Use Signal Blue only as an outlined secondary action.
- Do not place blue or orange as broad backgrounds.
- Use Mist Border for all structural lines.
