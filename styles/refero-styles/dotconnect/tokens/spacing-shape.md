# Spacing And Shape

## Spacing

| Token | Value | Use |
| --- | ---: | --- |
| `unit` | 8px | Base spacing unit |
| `8` | 8px | Small spacing and badge radius |
| `16` | 16px | Card text block padding and compact stacks |
| `24` | 24px | Element gap, card padding, nav gap |
| `32` | 32px | Offer card padding |
| `48` | 48px | Pill radius and midsection spacing |
| `64` | 64px | Large block rhythm |
| `72` | 72px | Large display and spacing token |
| `80` | 80px | Hero and section padding token |
| `96` | 96px | Standard section gap |
| `160` | 160px | Major visual gap |
| `max-width` | 1200px | Page container |

## Radius

| Token | Value | Use |
| --- | ---: | --- |
| `badge` | 8px | Tags and inline metadata |
| `card` | 20px | Offer cards, case cards, surfaces |
| `image` | 20px | Case study image containers and 3D visual crops |
| `button` | 24px | Filled CTA and ghost outline buttons |
| `link` | 44px | Arrow pill button |
| `pill` | 48px | Full pill controls |

## Shape Rules

- Use 20px cards and 24px buttons as the main shape language.
- Use 44px to 48px only for pill controls.
- Do not mix 8px card corners into the main component family.
- Keep all shape decisions soft but technically restrained.
