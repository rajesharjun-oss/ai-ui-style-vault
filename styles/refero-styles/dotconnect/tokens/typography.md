# Typography

## Primary Family

```css
font-family: AeonikPro, Inter, Satoshi, "General Sans", Arial, sans-serif;
font-feature-settings: "dlig" on, "ss02" on, "ss08" on;
```

Use AeonikPro across most headings, body, nav, buttons, cards, and sections.

## Branded Display Variant

```css
font-family: DotConnect, AeonikPro, Inter, Satoshi, "General Sans", Arial, sans-serif;
font-feature-settings: "dlig" on, "ss02" on, "ss08" on;
```

Use DotConnect only for brand-name moments, hero statements, and special section headings.

## Scale

| Token | Size | Weight | Line Height | Letter Spacing |
| --- | ---: | ---: | ---: | ---: |
| `caption` | 16px | 400 | 1.5 | 0.16px |
| `body` | 18px | 400 | 1.4 | 0.18px |
| `body-dense` | 19px | 500 | 1.67 | 0.19px |
| `subheading` | 24px | 500 | 1.4 | -0.29px |
| `heading-sm` | 32px | 500 | 1.1 | -0.38px |
| `heading` | 36px | 500 | 1.1 | -0.72px |
| `heading-lg` | 72px | 500 | 0.9 | -1.8px |
| `display` | 101px | 500 | 0.8 | -2.53px |

## Rules

- Use weights 400 and 500 only.
- Use about `-0.025em` tracking at 72px and above.
- Use about `-0.012em` tracking at 32px to 36px.
- Use about `+0.010em` tracking at 16px to 19px.
- Keep body text between 16px and 21px.
- Body text is left aligned; display headlines may be centered.
