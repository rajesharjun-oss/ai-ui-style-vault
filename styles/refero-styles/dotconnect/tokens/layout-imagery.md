# Layout And Imagery

## Layout

- Use full-width Bone Canvas sections.
- Keep content centered inside a 1200px max-width container.
- Hero is text-led and centered.
- Use around 120px vertical padding in the hero.
- Alternate large text sections with abstract 3D render interludes.
- Use two-column grids for offers.
- Use three-column card rows or carousel patterns for stories.
- Use split section headers: label left, count right, hairline divider below.
- Use 24px column gaps.
- Keep the top nav thin: logo left, links center, Ember CTA right.

## Imagery

Use:

- Abstract 3D object renders.
- Metallic and glass forms.
- Chrome brain, network, or geometric studies.
- One small Ember detail inside otherwise neutral imagery.
- Abstract thumbnails for case studies.

Avoid:

- Photography.
- People.
- Lifestyle imagery.
- Text overlays on images.
- Busy illustration systems.
- Decorative icon sets.
- Image-heavy landing pages.
