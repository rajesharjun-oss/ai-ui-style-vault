## Use This Style When

Use (dot)connect when the interface should feel like a Swiss engineering blueprint with one warm spark: restrained, architectural, precise, text-led, and quietly premium. It works well for venture studios, consultancies, investor pages, technical agencies, executive networks, and refined B2B sites where typography and spacing should carry most of the brand.

## Quick DNA

- Warm off-white canvas with near-black typography.
- Ember orange appears once per viewport for high-intent emphasis.
- Signal blue is only for outlined secondary actions.
- Huge Aeonik-style headlines with aggressive negative tracking.
- Soft card radii: 20px cards, 24px buttons, 44px to 48px pills.
- Border-driven structure with no shadows, glows, gradients, or blur.
- Text is the hero; imagery appears as sparse 3D object interludes.
