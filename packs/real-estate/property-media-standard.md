# Real Estate Property Media Standard

Every property image, video, floorplan, site plan, map, render and 3D scene must record provenance and what it represents.

- Real property photography: identify as actual photography only when verified.
- Architectural CGI/render: label as render/artist impression where a reasonable user could mistake it for completed reality.
- Stock imagery: never present as the actual property, neighbourhood view or amenity.
- Generated imagery: concept-only unless explicitly used as an illustrative design study; never evidence of the listed property.
- Drone, map and neighbourhood claims require rights and truthful location context.

Keep gallery crops consistent and useful for spatial understanding. Avoid aggressive filters that materially misrepresent finishes, light, scale or views. Floorplans must remain legible on mobile with zoom/download alternatives where permitted.
