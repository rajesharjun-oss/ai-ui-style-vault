# Implement a Real Estate Website

Use only after the Business Research Gate is `ready` and `business-profile.json` validates. Read all pack files and complete `REAL_ESTATE_BUILD_CONTRACT.md` before implementation.

Define whether the business is a developer, brokerage, agency, property manager or mixed model. Establish the actual inventory model and source of truth for availability/price before implying live status.

Every property media item must carry provenance. Distinguish actual photography, render/artist impression, illustrative material and stock. Do not generate fake listings or operational facts.

When 3D is requested, add the 3D capability pack only when the model, site, spatial data or interaction materially supports property evaluation. Build a static gallery/floorplan fallback first.

Render and inspect discovery, listing, property detail, gallery, filters, map fallback, viewing enquiry, sold/reserved/unknown states, mobile and reduced motion before handoff.
