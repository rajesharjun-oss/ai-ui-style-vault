# Real Estate Motion Guidance

Use motion to reveal spatial sequence, gallery continuity, site context or verified development progression. Suitable techniques include restrained image transitions, map/list coordination, floorplan highlighting, scroll-linked architectural sections and purposeful 3D model inspection.

Do not delay property facts behind cinematic intros. Avoid perpetual camera movement, exaggerated parallax that distorts architecture, or unrelated luxury props. A 3D property model must correspond to the actual project or be clearly labelled illustrative. Support reduced motion and a static gallery/floorplan fallback.
