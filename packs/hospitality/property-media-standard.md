# Hospitality Property Media Standard

Use real, owner-supplied or licensed property photography wherever possible. Every room image should be associated with the correct room/property area. Do not use stock or generated interiors as if they depict the hotel.

Plan exterior, room, bathroom, amenity, dining, meeting and location imagery according to actual offerings. Generated conceptual media must be labelled and should not be used to imply existing facilities.

Avoid repetitive hero imagery and deceptive ultra-wide crops that materially misrepresent room scale.
