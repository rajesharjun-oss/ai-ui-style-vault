# Asset and Model Standard

Record source, creator, licence, attribution, original/runtime files, metrics, capability tiers and fallback for every model, texture, HDRI, animation, audio file, shader and code example. Unknown terms block production use.

Prefer glTF/GLB. Remove unused nodes, materials, clips, cameras and hidden geometry. Use real-world scale, instancing, LODs and tiered textures. Measure Meshopt/Draco and KTX2/Basis trade-offs. Keep source files outside the public bundle.

Licence classes: `reference-only`, `permissive-code-example`, `CC0`, `attribution-required`, `commercial-licence`, `per-item-terms`, `owner-provided`, `original`.
