# 3D & Immersive Web Implementation Prompt

Act as a senior product designer, content designer, 3D art director, accessibility specialist and performance-focused front-end engineer.

## Mandatory recipe step

Before coding, read `3d/AI_AGENT_RECIPE_STANDARD.md` and materialize the current recipe registry with:

```bash
python scripts/build-ai-agent-recipes.py
```

Select **one primary design-direction recipe** and, when useful, no more than **three supporting motion-pattern recipes**. External-reference recipes may inform abstract hierarchy/pacing only and cannot be the primary design definition. Record the selected recipe IDs in the build notes.

If the user does not name a recipe, infer the verified business domain, audience, primary task and page purpose; shortlist compatible recipes; reject semantically mismatched candidates; then choose the smallest sufficient implementation medium. If no immersive recipe materially improves the task, build without immersive 3D.

For every selected recipe, obey its `whenToUse`, `whenNotToUse`, composition, motion, implementation, asset, responsive, performance, accessibility/fallback, originality and acceptance-criteria instructions. Treat its `agentPrompt` as the executable recipe brief.

Before coding, prove the 3D purpose; compare simpler media; complete the 3D contracts; choose one style family, theme and blueprint; design the complete fallback; define licences, tiers and budgets.

Implement DOM-first, lazy-load the runtime, use one renderer where possible, optimise assets, synchronise DOM and scene state, implement all loading/error/context states, respect reduced motion/save-data and preserve the selected product-domain pack.

Before handoff, measure bundles, transfer, draw calls, triangles, texture/GPU memory, sustained FPS and first useful frame. Render all tiers and failure states and prove the primary task works without 3D. Validate every selected recipe's acceptance criteria before saying the build is complete.

## Semantic relevance gate

Complete `THREE_D_RELEVANCE_CONTRACT.md` before asset search. Primary visuals need relevance 4–5; secondary decoration needs at least 3. Reject unrelated spectacle, including category-inappropriate vehicles, fantasy objects, backgrounds or props. Validate the whole scene, not only the main model.

## Originality gate

External reference metadata is inspiration only. Never copy proprietary prompts, source code, media, branding, models, textures, exact layout or choreography. The finished work must be materially original and driven by the target business, not by a reference screenshot or title.
