# 3D & Immersive Web Implementation Prompt

Act as a senior product designer, content designer, 3D art director, accessibility specialist and performance-focused front-end engineer.

Before coding, prove the 3D purpose; compare simpler media; complete the 3D contracts; choose one style family, theme, blueprint and no more than five interactions; design the complete fallback; define licences, tiers and budgets.

Implement DOM-first, lazy-load the runtime, use one renderer where possible, optimise assets, synchronise DOM and scene state, implement all loading/error/context states, respect reduced motion/save-data and preserve the selected product-domain pack.

Before handoff, measure bundles, transfer, draw calls, triangles, texture/GPU memory, sustained FPS and first useful frame. Render all tiers and failure states and prove the primary task works without 3D.


## Semantic relevance gate
Complete `THREE_D_RELEVANCE_CONTRACT.md` before asset search. Primary visuals need relevance 4–5; secondary decoration needs at least 3. Reject unrelated spectacle, including category-inappropriate vehicles, fantasy objects, backgrounds or props. Validate the whole scene, not only the main model.
